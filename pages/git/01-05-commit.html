Commit

Saving changes in Git is done in two steps. First you choose which changes to include with git add, this is called staging. Then you save them with git commit.

See what has changed

status shows changed files, staged files and new files Git does not track yet. diff shows the changes line by line.

$ git status
$ git diff
$ git diff --staged

Stage changes

$ git add notes.txt
$ git add dir/
$ git add -A

-A stages all changes, including new and deleted files.

Unstage a file

Undo a git add. The changes in the file are kept.

$ git restore --staged notes.txt

Older guides use git reset notes.txt, which does the same.

Commit

$ git commit -m "Add notes about Git"

-a stages all changed files before committing, so you can skip git add. It does not include new files.

$ git commit -am "Fix typo in notes"

Without -m, Git opens an editor for the message.

Help

-h prints a short summary of the options for git commit. --help opens the full manual page, the same as git help commit.

$ git commit -h
$ git commit --help

More about commit

  • Write the message as a short summary of what the commit does, for example Add login page
  • Change the last commit with amend
  • See earlier commits with git log
