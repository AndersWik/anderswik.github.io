Clone

git clone copies a repository, with its whole history, to your computer. The remote it was copied from is saved as origin.

Clone a repository

Repositories can be cloned over HTTPS or SSH. SSH needs a key added to your account, but then you do not have to log in every time.

$ git clone https://github.com/user/project.git
$ git clone git@github.com:user/project.git

Choose the folder name

$ git clone git@github.com:user/project.git my-folder

Clone a specific branch

$ git clone --branch develop git@github.com:user/project.git

Only the latest version

--depth 1 skips the history and only downloads the latest commit. Much faster for large projects when you only need the files.

$ git clone --depth 1 https://github.com/user/project.git

Help

-h prints a short summary of the options for git clone. --help opens the full manual page, the same as git help clone.

$ git clone -h
$ git clone --help

More about clone
