Setup

A repository can be created from an existing folder with git init, or copied from somewhere else with git clone.

Create a repository

Go to the project folder and run init. Git creates the hidden folder .git where the history is stored.

$ cd my-project
$ git init

Connect to a remote

A remote is a copy of the repository on a server, for example on GitHub. The main remote is usually called origin.

$ git remote add origin git@github.com:user/my-project.git

List the remotes and their addresses.

$ git remote -v

Change the address of a remote

If the repository has moved, point origin to the new address.

$ git remote set-url origin git@github.com:user/new-name.git

Help

-h prints a short summary of the options for git init. --help opens the full manual page, the same as git help init.

$ git init -h
$ git init --help

More about setup

  • Set your name and email before the first commit, see Config
  • Send your commits to the remote with git push
  • A file called .gitignore lists files Git should not track, for example node_modules/ or *.log
