Cherry-picking

git cherry-pick copies a single commit from another branch to the current one. Useful when you need one fix from a branch, but not the rest of it.

Pick a commit

Find the hash with git log, switch to the branch that should get the commit and pick it.

$ git log --oneline new-feature
$ git switch main
$ git cherry-pick a1b2c3d

Pick several commits

$ git cherry-pick a1b2c3d e4f5a6b

Note where it came from

-x adds a line to the message with the hash of the original commit.

$ git cherry-pick -x a1b2c3d

Conflicts

Conflicts are resolved the same way as when merging. Then continue, or cancel.

$ git add notes.txt
$ git cherry-pick --continue
$ git cherry-pick --abort

Help

-h prints a short summary of the options for git cherry-pick. --help opens the full manual page, the same as git help cherry-pick.

$ git cherry-pick -h
$ git cherry-pick --help

More about cherry-picking

  • The copy gets a new hash, so the same change exists twice in the history
