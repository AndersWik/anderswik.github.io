Git

Git is a version control system. It keeps track of every change to the files in a project.

Basic ideas

  • Repository — a project folder that Git keeps track of. The history is stored in the hidden folder .git
  • Commit — a saved snapshot of the files, with a message that explains the change
  • Branch — a separate line of work, so you can try things without touching the main code
  • Merge — bring the changes from one branch into another
  • Remote — a copy of the repository on another computer, for example on GitHub or GitLab

Install on Linux

$ sudo apt install git

Install on macOS

macOS asks to install the Xcode Command Line Tools, which include Git, the first time you run git. For a newer version, use Homebrew.

$ brew install git

Install on Windows

Download Git for Windows, or use winget. It includes Git Bash, a terminal where the commands on these pages work the same way.

> winget install Git.Git

Help

--help lists the most common commands. git help followed by a command opens its manual page, and -h after a command prints a short summary of its options.

$ git --help
$ git help commit
$ git commit -h

Version

--version shows which version of Git is installed.

$ git --version
