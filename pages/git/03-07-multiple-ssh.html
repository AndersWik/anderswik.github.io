Multiple ssh keys

If you have several accounts on the same service, for example a private and a work account on GitHub, each needs its own SSH key. An SSH config file tells Git which key to use.

Create a key for each account

$ ssh-keygen -t ed25519 -C "you@example.com" -f ~/.ssh/id_ed25519_private
$ ssh-keygen -t ed25519 -C "you@work.example.com" -f ~/.ssh/id_ed25519_work

Add the .pub file of each key to the matching account.

Add the keys to the SSH config

Each Host is a nickname that points to the same server, but with a different key. IdentitiesOnly makes SSH use only that key.

$ nano ~/.ssh/config
Host github-private
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_private
  IdentitiesOnly yes

Host github-work
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_work
  IdentitiesOnly yes

Use the nickname

Replace github.com with the nickname when you clone or set the remote.

$ git clone git@github-work:company/project.git
$ git remote set-url origin git@github-private:user/project.git

Test that the right account answers.

$ ssh -T git@github-work
