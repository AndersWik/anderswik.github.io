Stash

git stash puts your uncommitted changes aside and gives you a clean working folder. Useful when you need to switch branch quickly but are not ready to commit.

Stash and bring back

$ git stash
$ git stash pop

pop brings back the latest stash and removes it from the list.

Give the stash a name

$ git stash push -m "half done login page"

Include new files

By default only tracked files are stashed. -u includes new, untracked files too.

$ git stash -u

Several stashes

$ git stash list
stash@{0}: On main: half done login page
stash@{1}: WIP on main: a1b2c3d Add notes

apply brings back a stash but keeps it in the list, and drop deletes it.

$ git stash show -p stash@{1}
$ git stash apply stash@{1}
$ git stash drop stash@{1}

Help

-h prints a short summary of the options for git stash. --help opens the full manual page, the same as git help stash.

$ git stash -h
$ git stash --help
