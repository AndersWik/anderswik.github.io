Tagging

A tag is a name for a specific commit that never moves, unlike a branch. Tags are mostly used to mark releases, like v1.0.

Create a tag

An annotated tag stores who made it, when, and a message. It is the kind to use for releases.

$ git tag -a v1.0 -m "First release"

A lightweight tag is only a name.

$ git tag v1.0

Tag an older commit by giving its hash.

$ git tag -a v0.9 a1b2c3d -m "Beta"

List and show tags

$ git tag
$ git show v1.0

Push tags

Tags are not pushed automatically.

$ git push origin v1.0
$ git push --tags

Delete a tag

$ git tag -d v1.0
$ git push origin --delete v1.0

Help

-h prints a short summary of the options for git tag. --help opens the full manual page, the same as git help tag.

$ git tag -h
$ git tag --help
