Log

git log shows the history of commits, newest first. Press q to quit, it uses the same keys as less.

Show the history

$ git log

Only the latest commit, or the latest five.

$ git log -1
$ git log -5

Short history

One line per commit.

$ git log --oneline

Show the branches as a graph

--all includes all branches, not just the current one.

$ git log --oneline --graph --all

Show which files changed

$ git log --name-only
$ git log --stat

Search the history

$ git log --author="Anders"
$ git log --grep="login"
$ git log -- notes.txt

Pretty format

--pretty=format chooses what to show and in which color: %h is the short hash, %d the branch names, %s the message and %an the author.

$ git log --graph --all --pretty=format:"%C(red)%h%C(reset) %C(green)%d%C(reset) %s %C(yellow)(%an)%C(reset)"

Help

-h prints a short summary of the options for git log. --help opens the full manual page, the same as git help log.

$ git log -h
$ git log --help

More about log

  • Save a long log command as an alias
  • git show followed by a hash shows what changed in that commit
  • git log in the documentation
