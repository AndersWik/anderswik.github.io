Config

Git stores your settings with git config. The most important ones are your name and email, which are saved in every commit you make.

Set your name and email

--global saves the setting for all repositories on the computer, in the file ~/.gitconfig.

$ git config --global user.name "Your Name"
$ git config --global user.email "you@example.com"

Show a setting

$ git config --global user.name
$ git config --global user.email

List all settings and where they come from.

$ git config --list --show-origin

Settings for one repository

Without --global the setting only applies to the current repository. Useful if you use a different email for work.

$ git config user.email "you@work.example.com"

Other useful settings

$ git config --global init.defaultBranch main
$ git config --global core.editor nano
$ git config --global pull.rebase false
  • init.defaultBranch — the name of the first branch in new repositories
  • core.editor — the editor Git opens for commit messages, see nano or vim
  • pull.rebase — whether git pull merges or rebases

Help

-h prints a short summary of the options for git config. --help opens the full manual page, the same as git help config.

$ git config -h
$ git config --help
