Amend

git commit --amend changes the last commit. Use it to fix the message, add a forgotten file or change the author.

Change the message

$ git commit --amend -m "New commit message"

Add forgotten files

Stage the files and amend. --no-edit keeps the old message.

$ git add .
$ git commit --amend --no-edit

Change the author

$ git commit --amend --author="New Name <new@example.com>" --no-edit

To change the author of an older commit, see Rebase.

Amend a pushed commit

Amend creates a new commit that replaces the old one. If the old commit was already pushed, you have to force push. Avoid this on branches that others work on.

$ git push --force-with-lease

Help

-h prints a short summary of the options for git commit. --help opens the full manual page, the same as git help commit.

$ git commit -h
$ git commit --help

More about amend

  • --force-with-lease is safer than --force, it refuses to overwrite commits someone else has pushed
  • To undo the last commit completely, see Reset
