Bisect

git bisect finds the commit that introduced a bug. You tell Git one commit where the bug exists and one where it did not. Git then checks out the commit in the middle and you test it. Each answer halves the number of commits left, so even long histories take only a few steps.

Find the bad commit

Start, mark the current commit as bad and an older one as good.

$ git bisect start
$ git bisect bad
$ git bisect good a1b2c3d

Git checks out a commit in between. Test it and answer.

$ git bisect good
$ git bisect bad

Repeat until Git prints is the first bad commit. Then go back to where you started.

$ git bisect reset

Let a script do the testing

If a script or test can tell good from bad, Git can run it for you. The script should exit with 0 for good and 1 for bad.

$ git bisect start HEAD a1b2c3d
$ git bisect run ./test.sh

Help

-h prints a short summary of the options for git bisect. --help opens the full manual page, the same as git help bisect.

$ git bisect -h
$ git bisect --help
