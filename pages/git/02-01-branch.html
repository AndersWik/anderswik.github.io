Branch

A branch is a separate line of work. Create a branch for each new feature or fix, so the main branch always has working code. The main branch is usually called main, or master.

List branches

The current branch is marked with *. -a also shows the branches on the remote.

$ git branch
$ git branch -a

Create a branch

$ git branch new-feature

This only creates the branch. To create it and move to it at once, see Checkout.

Rename a branch

$ git branch -m old-name new-name

Delete a branch

-d only deletes branches that are merged. -D deletes it anyway.

$ git branch -d new-feature
$ git branch -D new-feature

Delete the branch on the remote.

$ git push origin --delete new-feature

Help

-h prints a short summary of the options for git branch. --help opens the full manual page, the same as git help branch.

$ git branch -h
$ git branch --help
