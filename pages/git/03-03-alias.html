Alias

An alias is a short name for a Git command. Aliases are saved with git config.

Create an alias

After this, git ac "message" runs git commit -am "message".

$ git config --global alias.ac "commit -am"

Useful aliases

$ git config --global alias.st status
$ git config --global alias.co checkout
$ git config --global alias.br branch
$ git config --global alias.last "log -1"
$ git config --global alias.tree "log --oneline --graph --all"

List your aliases

$ git config --get-regexp alias

Remove an alias

$ git config --global --unset alias.ac

More about aliases

  • Aliases are stored in ~/.gitconfig under [alias], so you can also edit them there
  • Start an alias with ! to run a shell command, for example "!git fetch && git status"
