Checkout

git checkout moves between branches. Newer versions of Git split it into two simpler commands: git switch for branches and git restore for files. Both ways work.

Switch branch

$ git switch main
$ git checkout main

Create a branch and switch to it

$ git switch -c new-feature
$ git checkout -b new-feature

Go back to the previous branch

$ git switch -

Discard changes in a file

Put the file back to how it was in the last commit. The changes are lost.

$ git restore notes.txt
$ git checkout -- notes.txt

Look at an old commit

Checking out a commit hash lets you look at the files as they were. Git calls this a detached HEAD. Go back with git switch main.

$ git checkout a1b2c3d

Help

-h prints a short summary of the options for git switch. --help opens the full manual page, the same as git help switch. The same works for checkout and restore.

$ git switch -h
$ git switch --help

More about checkout
