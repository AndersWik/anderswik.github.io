Push and pull

git push sends your commits to the remote. git pull gets the commits others have pushed.

Push a new branch

The first time you push a branch, -u connects it to the branch on the remote. After that, a plain git push is enough.

$ git push -u origin new-feature
$ git push

Get changes from the remote

fetch downloads new commits but does not change your files. pull downloads and merges them into your branch.

$ git fetch
$ git pull

Force push

After amend or rebase the history is different from the remote, and a normal push is refused. --force-with-lease overwrites the remote, but only if nobody else has pushed in the meantime.

$ git push --force-with-lease

Help

-h prints a short summary of the options for git push. --help opens the full manual page, the same as git help push. The same works for pull and fetch.

$ git push -h
$ git push --help

More about push and pull

  • If git push is refused, run git pull first to get the new commits
