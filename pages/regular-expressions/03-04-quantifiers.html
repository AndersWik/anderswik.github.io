{ } Quantifiers

Braces ({}) tell how many times the character before them must occur.

Exact number of times

{2} finds the character exactly two times.

/^[0-9]{2}/

123: This text starts and ends 123

The regular expression finds two digits at the start of the line. The match is 12. The 3 is not part of the match.

Minimum number of times

{3,} finds the character three or more times.

/^[0-9]{3,}/

123: This text starts and ends 123

The regular expression finds three or more digits at the start of the line. The line starts with three digits, so the match is 123.

Range of times

{3,5} finds the character from three to five times.

/^[0-9]{3,5}/

1234567: This text starts and ends 1234567

The line starts with seven digits. The quantifier is greedy, so it finds the maximum number of digits. The match is the first five digits.

123: This text starts and ends 123

12: This text starts and ends 12

The first line has three digits at the start, so the match is 123. The second line has only two digits at the start, so there is no match.

Short forms

The quantities ?, * and + are short forms of quantifiers:

  • ? is the same as {0,1}.
  • * is the same as {0,}.
  • + is the same as {1,}.

More about quantifiers

  • Put a question mark after a quantifier to make it not greedy, for example {3,5}?. See Quantity.
