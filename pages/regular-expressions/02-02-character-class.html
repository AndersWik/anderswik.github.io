[ ] Character class

A character class tells which characters are a match. Write the characters between brackets ([]). The class finds one character that is in the brackets.

/[Aaw]/

A sentence with an a.

The regular expression finds each A, a and w. The class is case-sensitive, so [Aaw] does not find W.

Ranges

Use a hyphen (-) between two characters to make a range. The range includes all the characters from the first character to the last character.

/[0-9]/

1: This text starts and ends with number 1

The range 0-9 finds all the digits.

/[a-z]/

1: This text starts and ends with number 1

The range a-z finds all the lowercase letters. Each letter is a separate match. The T in "This" is not a match, because it is an uppercase letter. To find all letters, use [a-zA-Z], or use the i flag.

Not (inverted class)

Usually, the caret (^) means "starts with".

/^[0-9]/

1: This text starts and ends with number 1

The regular expression finds only the digit at the start of the line.

When the caret is the first character in the brackets, it means "not". The class then finds one character that is not in the brackets.

/[^0-9]/

1: This text starts and ends with number 1

The regular expression finds all the characters that are not digits. The spaces and the colon (:) are also matches.

Metacharacters in a character class

To find a metacharacter, put a backslash (\) before it. This is an escape.

/[\?]/

1: Will it work?

The regular expression finds the question mark. Without the backslash, ? is a quantity.

More about character classes

  • Short forms for usual classes, for example \d for [0-9], are in Predefined character classes.
