. Wildcard

The period (.) is a wildcard. It finds one character of any type, also spaces and tabs. It does not find a line break (\n).

/./

1: This text starts and ends 1

The wildcard finds each character in the line. Each character is a separate match.

A wildcard in a pattern

Use the wildcard when a character can change.

/t.xt/

text, tixt, t xt, txt

The pattern finds "t", one character of any type, and then "xt". "txt" is not a match, because the wildcard must find one character.

A period, not a wildcard

To find a real period, put a backslash (\) before it.

/\./

www.example.com

More about wildcards

  • Use the s flag to make the wildcard also find line breaks. See Flags.
  • .* finds all the characters to the end of the line. See Quantity.
