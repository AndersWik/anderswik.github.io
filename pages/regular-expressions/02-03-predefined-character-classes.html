\ Predefined character classes

A predefined character class is a short form of a usual character class. It starts with a backslash (\). The uppercase letter is the opposite of the lowercase letter. For example, \D finds all the characters that \d does not find.

\d Digit

\d finds one digit (0-9). It is the same as [0-9].

/\d/

1: This text starts and ends 1

The regular expression finds the two digits.

\D Not a digit

\D finds one character that is not a digit. It is the same as [^0-9].

/\D/

1: This text starts and ends 1

The regular expression finds all the letters, the spaces and the colon (:).

\w Word character

\w finds one word character. A word character is a letter (a-z or A-Z), a digit (0-9) or an underscore (_). It is the same as [a-zA-Z0-9_].

/\w/

1: This text starts and ends 1

The regular expression finds all the letters and digits. Each character is a separate match. The spaces and the colon are not matches.

\w does not find letters such as å, ä and ö.

\W Not a word character

\W finds one character that is not a word character. It is the same as [^a-zA-Z0-9_].

/\W/

1: This text starts and ends 1

The regular expression finds the colon and the spaces.

\s White space

\s finds one white space character: a space, a tab or a line break.

/\s/

1: This text starts and ends 1

The regular expression finds the spaces between the words.

\S Not white space

\S finds one character that is not white space.

/\S/

1: This text starts and ends 1

The regular expression finds all the characters, but not the spaces.

\b Word boundary

\b does not find a character. It finds a position. A word boundary is a position between a word character and a character that is not a word character. The start and the end of the line are also word boundaries.

Use \b to find a character at the start or at the end of a word.

/\bs/

1: This text starts and ends 1

The regular expression finds an s at the start of a word. Only "starts" starts with an s.

\B Not a word boundary

\B finds a position that is not a word boundary. The position is in a word, between two word characters.

/\Bs/

1: This text starts and ends 1

The regular expression finds an s that is not at the start of a word. The first s in "starts" is not a match, because it is at the start of the word.

More about predefined character classes

  • Make your own classes with brackets. See Character class.
  • To find a backslash, write two backslashes: \\.
