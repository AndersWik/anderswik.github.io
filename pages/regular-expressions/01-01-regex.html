Regular Expressions

A regular expression is a pattern of characters. You use it to find text that agrees with the pattern. The regular expression reads the text from left to right.

Other names for a regular expression are regex and regexp.

Test a regular expression

You can test a regular expression in a text editor. To use a regular expression in Visual Studio Code, do these steps:

  1. Push Ctrl+F to open the search box.
  2. Click the .* button in the search box.
  3. Write the regular expression in the search box.

The editor shows each match in the text.

The examples in these notes show all the matches in the text. The examples use the g flag (global). The highlighted text is a match:

This text is a match.

Start and end

# Start                 End
# ▼                     ▼
  /^[a-z]{3}-?[0-9]{3}$/i

In JavaScript, a regular expression starts and ends with a slash (/). In many other tools, for example the search box in an editor, you write only the pattern. You do not write the slashes.

This regular expression finds a Swedish car registration number, for example ABC-123 or abc123.

Pattern

#          Pattern
#             ▼
  /^[a-z]{3}-?[0-9]{3}$/i

The pattern is the characters between the two slashes. The pattern in the example has these parts:

  • ^ The match must start at the start of the line.
  • [a-z]{3} Three letters.
  • -? Zero or one hyphen. The hyphen is optional.
  • [0-9]{3} Three digits.
  • $ The match must stop at the end of the line.

Flags

#                        Flags
#                        ▼
  /^[a-z]{3}-?[0-9]{3}$/i

Flags come after the last slash. A flag changes how the regular expression finds matches. You can use more than one flag. For example, /abc/gi uses the flags g and i.

  • g Global. Find all the matches, not only the first match.
  • i Ignore case. [a-z] also finds the letters A to Z. In the example, ABC-123 is a match because of the i flag.
  • m Multiline. ^ and $ find the start and the end of each line, not only the start and the end of the text.
  • s Dot all. The wildcard . also finds line breaks.
  • u Unicode. The regular expression reads the text as Unicode characters. Use this flag for emoji and other special characters.
  • y Sticky. The match must start at the position where the last match stopped.

Metacharacters

A metacharacter is a character with a special function in a regular expression. Each metacharacter has a page in these notes.

  • ^ Starts with
  • $ Ends with
  • [] Character class
  • \ Escape and predefined character classes
  • . Wildcard (all characters, but not line breaks)
  • | Or
  • () Groups
  • ? * + Quantity (zero or one, zero or more, one or more)
  • {} Quantifiers

Starts with

When a pattern starts with ^, the match must be at the start of the line.

/^[ABC]/

ABCDEFG

The text starts with A, so A is a match. B and C are not matches, because they are not at the start of the line.

DEFGABC

There is no match. The text does not start with A, B or C.

Ends with

When a pattern ends with $, the match must be at the end of the line.

/[ABC]$/

DEFGABC

The text ends with C, so C is a match.

ABCDEFG

There is no match. The text does not end with A, B or C.

Wildcard

The wildcard . finds all characters, also spaces and tabs. It does not find line breaks.

To find a real period (.), put a backslash (\) before it. This is an escape. Then the period is a usual character, not a wildcard.

/\./

ABC.DEF.GHI.

The regular expression finds each period in the text.

Escape and predefined character classes

The backslash (\) has two functions:

  • It changes a metacharacter into a usual character. For example, \. finds a period and \? finds a question mark.
  • It makes predefined character classes. Each class finds one type of character.

The predefined character classes are:

  • \d Digit (0-9)
  • \D Not a digit
  • \w Word character (a-z, A-Z, 0-9 and _)
  • \W Not a word character
  • \s White space (space, tab and line break)
  • \S Not white space
  • \b Word boundary (the position between a word character and a character that is not a word character)
  • \B Not a word boundary

Character classes

Use brackets ([]) to make your own character class. The class finds one character that is in the brackets.

/[ADG]/

ABCDEFGHI

The regular expression finds A, D and G.

When ^ is the first character in the brackets, the class is inverted. The class then finds one character that is not in the brackets.

/[^ADG]/

ABCDEFGHI

The regular expression finds B, C, E, F, H and I.

Or

The vertical bar (|) means "or". The regular expression finds the pattern on the left side or the pattern on the right side.

/cat|dog/

A cat and a dog.

Quantity and quantifiers

A quantity tells how many times the character before it can occur.

  • ? Zero or one time
  • * Zero or more times
  • + One or more times
  • {3} Exactly three times
  • {3,} Three or more times
  • {3,5} From three to five times
/[0-9]+/

Room 12, floor 3.

The regular expression finds each group of one or more digits.

Groups

Parentheses (()) make a group. A group combines characters into one part of the pattern. A quantity after a group applies to all of the group.

/(ha)+/

He said haha.

The group (ha) occurs two times, so the match is haha.
