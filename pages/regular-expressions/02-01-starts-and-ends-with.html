Starts and ends with

^ and $ do not find characters. They find a position: the start or the end of the line.

^ Starts with

When a pattern starts with ^, the match must be at the start of the line.

/^[0-9]/

1: This text starts and ends with number 1

The regular expression finds the first 1. The last 1 is not a match, because it is not at the start of the line.

$ Ends with

When a pattern ends with $, the match must be at the end of the line.

/[0-9]$/

1: This text starts and ends with number 1

The regular expression finds the last 1. The first 1 is not a match, because it is not at the end of the line.

Starts and ends with

You can use ^ and $ in the same pattern. Then the pattern must agree with all of the line.

/^[0-9]+$/

12345

12345 is a number

The first line contains only digits, so all of the line is a match. The second line also contains letters, so there is no match.

More about starts and ends with

  • Use the m flag to find the start and the end of each line in a text with many lines. See Flags.
  • In brackets, ^ means "not". See Character class.
