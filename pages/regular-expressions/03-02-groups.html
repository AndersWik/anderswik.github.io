( ) Groups

Parentheses (()) make a group. A group combines character classes and other parts into a larger pattern. The group finds the full pattern, not only one character.

/([a-z]\s[a-z])/

1: This text starts and ends 1

The group finds a lowercase letter, a space, and one more lowercase letter. Each match is the last letter of a word, the space, and the first letter of the next word.

Quantifiers in a group

You can put quantifiers in a group.

/([a-z]{1,2}\s[a-z])/

1: This text starts and ends 1

The matches are is t, xt s, ts a and nd e.

[a-z]{1,2} finds one or two lowercase letters before the space. The regular expression always tries to find the longest match, so each match has two letters before the space. The last two matches touch each other.

Quantifier after a group

A quantifier after a group applies to all of the group.

/(ab)+/

ababa ab

The group (ab) occurs two times in the first word, so the first match is abab. The last a in the first word is not a match, because there is no b after it.

Lookahead

(?=...) is a lookahead. It examines the characters after the match, but they are not part of the match.

/a(?=r)/

1: This text starts and ends 1

The regular expression finds an a that has an r after it. The a in "starts" is a match. The a in "and" is not a match, because an n comes after it. The r is not part of the match.

More about groups

  • (?!...) is a negative lookahead. /a(?!r)/ finds an a that does not have an r after it.
  • A program can read the text that each group found. For example, in JavaScript, match[1] is the text of the first group.
