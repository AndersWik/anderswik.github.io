? * + Quantity

A quantity tells how many times the character before it can occur.

  • ? Zero or one time
  • * Zero or more times
  • + One or more times

Greedy and not greedy

Usually, a quantity is greedy. A greedy quantity finds as many characters as possible.

Put a question mark (?) after a quantity to make it not greedy. A quantity that is not greedy finds as few characters as possible.

? Zero or one

? finds the character before it zero times or one time. Use it for a character that is optional.

Greedy:

/^[0-9]?/

123: This text starts and ends 123

The greedy ? finds one digit if possible. The match is 1.

Not greedy:

/^[0-9]??/

123: This text starts and ends 123

The ? that is not greedy finds zero digits if possible. The match is empty, so the example shows no highlighted text.

* Zero or more

* finds the character before it zero or more times.

Greedy:

/^[0-9]*/

123: This text starts and ends 123

The greedy * finds all the digits at the start of the line. The match is 123.

Not greedy:

/^[0-9]*?/

123: This text starts and ends 123

The * that is not greedy finds zero digits if possible. The match is empty.

+ One or more

+ finds the character before it one or more times.

Greedy:

/^[0-9]+/

123: This text starts and ends 123

The greedy + finds all the digits at the start of the line. The match is 123.

Not greedy:

/^[0-9]+?/

123: This text starts and ends 123

The + that is not greedy finds as few digits as possible. It must find one digit, so the match is 1.

When to use a quantity that is not greedy

A quantity that is not greedy is usually followed by more of the pattern. The quantity then stops at the first position where the remaining pattern agrees.

Greedy:

/<.+>/

<b>bold</b>

The greedy .+ finds as many characters as possible. The match continues to the last > in the line.

Not greedy:

/<.+?>/

<b>bold</b>

The .+? that is not greedy stops at the first >. Each HTML tag is a separate match.

More about quantity
