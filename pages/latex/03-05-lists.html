Lists

LaTeX has three list environments: itemize for bullets, enumerate for numbers and description for terms.

Bullet list

\begin{itemize}
  \item Apples
  \item Pears
  \item Plums
\end{itemize}

Numbered list

\begin{enumerate}
  \item First
  \item Second
  \item Third
\end{enumerate}

Description list

\begin{description}
  \item[Host] The computer that runs the virtual machine.
  \item[Guest] The virtual machine.
\end{description}

Nested lists

Lists can be nested four levels deep. The bullet or number style changes on each level.

\begin{enumerate}
  \item Install
  \begin{enumerate}
    \item Download
    \item Run the installer
  \end{enumerate}
  \item Configure
  \begin{itemize}
    \item Set the language
  \end{itemize}
\end{enumerate}

Custom bullet

\begin{itemize}
  \item[--] With a dash
  \item[$\star$] With a star
\end{itemize}

enumitem

The enumitem package changes the numbering and spacing.

\usepackage{enumitem}

\begin{enumerate}[label=\alph*)]   % a) b) c)
\begin{enumerate}[label=\Roman*.]  % I. II. III.
\begin{enumerate}[start=5]         % start at 5
\begin{itemize}[noitemsep]         % no space between items
\begin{enumerate}[resume]          % continue the last list

More about lists

  • Refer to an item with \label and \ref, see cross references
  • For a task list, use \item[$\square$] with amssymb
