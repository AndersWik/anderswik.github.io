Packages

Packages add features to LaTeX. Load them in the preamble with \usepackage. Options go in square brackets.

Load a package

\usepackage{graphicx}
\usepackage[margin=2cm]{geometry}
\usepackage{amsmath,amssymb}

Language and characters

inputenc and fontenc make letters like å, ä and ö work with pdflatex. babel sets the hyphenation and words like Contents and Figure.

\usepackage[utf8]{inputenc}
\usepackage[T1]{fontenc}
\usepackage[swedish,english]{babel}   % the last one is the main language

Useful packages

\usepackage{amsmath}      % equations and align
\usepackage{amssymb}      % more math symbols
\usepackage{graphicx}     % images
\usepackage{booktabs}     % nicer tables
\usepackage{geometry}     % page margins
\usepackage{xcolor}       % colors
\usepackage{listings}     % source code
\usepackage{enumitem}     % customize lists
\usepackage{csquotes}     % quotation marks
\usepackage{siunitx}      % numbers and units
\usepackage{biblatex}     % bibliography
\usepackage{tikz}         % drawing
\usepackage{hyperref}     % clickable links, load it last

More about packages

  • Find packages on CTAN and read their manual with texdoc name
  • Load hyperref after the other packages
  • With xelatex and lualatex, use fontspec instead of inputenc and fontenc
  • A missing package gives the error File `name.sty' not found, see install
