Code listings

Source code must be shown exactly as written. verbatim prints text as it is, and listings and minted add syntax highlighting.

Verbatim

\begin{verbatim}
for i in range(10):
    print(i)
\end{verbatim}

Inline: \verb|ls -la|

listings

\usepackage{listings}

\begin{lstlisting}[language=Python]
for i in range(10):
    print(i)
\end{lstlisting}

\lstinputlisting[language=Bash]{script.sh}

listings style

\usepackage{xcolor}
\lstset{
  basicstyle=\ttfamily\small,
  keywordstyle=\color{blue},
  commentstyle=\color{gray},
  stringstyle=\color{red},
  numbers=left,
  frame=single,
  breaklines=true,
  showstringspaces=false
}

minted

minted uses Pygments and gives the best highlighting. It needs Python and -shell-escape.

\usepackage{minted}

\begin{minted}{python}
for i in range(10):
    print(i)
\end{minted}

\mintinline{bash}{ls -la}
\inputminted{bash}{script.sh}
$ sudo apt install python3-pygments
$ pdflatex -shell-escape document.tex

More about code listings

  • \verb cannot be used inside the argument of other commands, like \footnote
  • Any character can be used around \verb, as long as it is not in the code
