Cross references

Give something a name with \label and refer to it with \ref. LaTeX fills in the number. Compile twice.

Label and ref

\section{Results}
\label{sec:results}

As shown in Section~\ref{sec:results} on page~\pageref{sec:results}.
See Figure~\ref{fig:tux} and Table~\ref{tab:prices}.
See equation~\eqref{eq:energy}.

Prefixes

Prefixes are not needed, but they make the labels easier to keep apart.

sec:   section
fig:   figure
tab:   table
eq:    equation

Clickable links

hyperref makes all references, the table of contents and footnotes clickable. Load it last.

\usepackage{hyperref}
\hypersetup{colorlinks=true, linkcolor=blue, urlcolor=blue}

\url{https://www.anderswik.se}
\href{https://www.anderswik.se}{my site}
\href{mailto:someone@example.com}{send an email}

cleveref

\cref adds the word, like figure or section, for you. Load it after hyperref.

\usepackage{cleveref}

See \cref{fig:tux}.     % See figure 1.
\Cref{sec:results}      % Section 2

More about cross references

  • ?? in the PDF means the label is missing or you need to compile again
  • Use ~ before \ref so the number stays on the same line
