Page layout

The geometry package sets the paper size and margins.

Margins

\usepackage[margin=2.5cm]{geometry}
\usepackage[a4paper, top=3cm, bottom=3cm, left=2cm, right=2cm]{geometry}

Paper size

\usepackage[a5paper]{geometry}
\usepackage[letterpaper]{geometry}
\usepackage[paperwidth=10cm, paperheight=15cm]{geometry}

Landscape

\usepackage[landscape]{geometry}       % the whole document

\usepackage{pdflscape}                 % only some pages
\begin{landscape}
  A wide table.
\end{landscape}

Page numbers

\pagestyle{plain}       % number at the bottom, default
\pagestyle{empty}       % no number
\thispagestyle{empty}   % no number on this page

\pagenumbering{roman}   % i, ii, iii
\pagenumbering{arabic}  % 1, 2, 3

Change the margins in the middle

\newgeometry{margin=1cm}
A page with small margins.
\restoregeometry
