LaTeX

LaTeX is a system for writing documents. You write plain text with commands like \section{} and \textbf{}, and LaTeX turns it into a nicely typeset PDF. It is the standard for scientific papers, theses and anything with a lot of math.

You focus on the content and the structure. LaTeX takes care of the layout, numbering, references and table of contents.

Quick start

Save this as hello.tex and compile it.

\documentclass{article}

\begin{document}
Hello, world!
\end{document}
$ pdflatex hello.tex
$ xdg-open hello.pdf

Commands and environments

Commands start with a backslash. Required arguments go in curly braces and optional ones in square brackets.

\command
\command{argument}
\command[option]{argument}

An environment is a block that starts with \begin{name} and ends with \end{name}.

\begin{center}
  This text is centered.
\end{center}

Help

texdoc opens the documentation for a package. It is installed with TeX Live.

$ texdoc amsmath
$ texdoc geometry
$ pdflatex --help
