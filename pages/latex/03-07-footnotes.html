Footnotes

\footnote{} adds a number in the text and the note at the bottom of the page.

Footnote

Linux was first released in 1991.\footnote{Version 0.01, in September.}

Footnote mark and text apart

Useful in tables and titles, where \footnote does not work.

Some text\footnotemark{} in a table.
\footnotetext{The note.}

Margin note

Some text.\marginpar{A note in the margin}

More about footnotes

  • Put the footnote after the punctuation, with no space before it
  • The footmisc package changes the numbering and layout
