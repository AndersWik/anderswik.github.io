Errors

LaTeX stops and shows an error with a line number, marked with l.. The full messages are in the .log file. Fix the first error first, the others often follow from it.

Stop at an error

In the terminal, type x and Enter to stop, or Enter to continue.

$ pdflatex -halt-on-error document.tex
$ grep -n "^!" document.log

Undefined control sequence

A command is misspelled, or its package is not loaded.

! Undefined control sequence.
l.12 \includegraphic

Missing $ inserted

A math symbol like _ or ^ is used outside math mode. Escape it as \_ or put it in $...$.

! Missing $ inserted.

File not found

A package is not installed, see install, or the path to a file is wrong.

! LaTeX Error: File `tikz.sty' not found.

Environment ended by

A \begin does not match the \end.

! LaTeX Error: \begin{itemize} on input line 10 ended by \end{enumerate}.

Runaway argument

A curly brace is missing.

Runaway argument?
! File ended while scanning use of \textbf.

Warnings

LaTeX Warning: Reference `fig:tux' on page 1 undefined.
LaTeX Warning: There were undefined references.
LaTeX Warning: Label(s) may have changed. Rerun to get cross-references right.
Overfull \hbox (12.3pt too wide) in paragraph at lines 20--25

Compile again for references. Overfull hbox means a line sticks out into the margin, often because a long word or URL could not be hyphenated.

Start over

Old helper files can cause strange errors. Delete them and compile again.

$ latexmk -C
$ latexmk -pdf document.tex

More about errors

  • Comment out half the document to find where the error is
  • TeX Stack Exchange has an answer for almost every error message
