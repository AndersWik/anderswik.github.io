Spacing and breaks

LaTeX decides most of the spacing itself. An empty line starts a new paragraph, and several spaces count as one.

Paragraphs

This is the first paragraph.
This line is part of the same paragraph.

This is the second paragraph.

Line break

First line\\
Second line\newline
Third line

Page break

\newpage
\clearpage     % also prints all waiting figures and tables
\cleardoublepage

Vertical space

\vspace{1cm}
\vspace*{2cm}   % also at the top of a page
\smallskip
\medskip
\bigskip
\vfill          % fill the page

Horizontal space

A\hspace{1cm}B
A\quad B
A\qquad B
A\hfill B       % push B to the right

Indent

\noindent This paragraph is not indented.

\setlength{\parindent}{0pt}   % no indent anywhere
\setlength{\parskip}{1em}     % space between paragraphs instead

\usepackage{parskip}          % the same with a package

Line spacing

\usepackage{setspace}
\onehalfspacing
\doublespacing

\linespread{1.3}

More about spacing

  • Units: cm, mm, in, pt, em (width of an M) and ex (height of an x)
  • Avoid \\ to make space between paragraphs, use an empty line and \parskip
