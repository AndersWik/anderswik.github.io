Bibliography

References are stored in a .bib file and cited with \cite. biblatex with biber is the modern way. Only the sources you cite are listed.

The .bib file

Save this as references.bib. The first word after the brace is the key you cite with.

@book{knuth1984,
  author    = {Donald E. Knuth},
  title     = {The TeXbook},
  publisher = {Addison-Wesley},
  year      = {1984}
}

@article{doe2020,
  author  = {Jane Doe and John Smith},
  title   = {A study of penguins},
  journal = {Journal of Birds},
  volume  = {12},
  pages   = {1--10},
  year    = {2020}
}

@online{linux,
  author  = {{The Linux Foundation}},
  title   = {Linux},
  url     = {https://www.linuxfoundation.org},
  urldate = {2026-11-08}
}

biblatex

\usepackage[style=authoryear]{biblatex}
\addbibresource{references.bib}

\begin{document}
As shown by \textcite{doe2020}, penguins are great \parencite{knuth1984}.

\printbibliography
\end{document}

Compile

$ pdflatex document.tex
$ biber document
$ pdflatex document.tex

$ latexmk -pdf document.tex   # does all the steps

Cite commands

\cite{key}            % Doe 2020
\parencite{key}       % (Doe 2020)
\textcite{key}        % Doe (2020)
\cite[p.~5]{key}      % with a page
\cite{key1,key2}      % several sources
\nocite{*}            % list every source, also the ones not cited

Styles

style=numeric       % [1]
style=alphabetic    % [Knu84]
style=authoryear    % Knuth 1984
style=apa           % APA
style=ieee          % IEEE, needs biblatex-ieee

BibTeX

Older documents and many journal templates use BibTeX instead.

\bibliographystyle{plain}
\bibliography{references}
$ pdflatex document.tex
$ bibtex document
$ pdflatex document.tex
$ pdflatex document.tex

More about bibliography

  • Google Scholar and most journals can export a citation as BibTeX
  • Zotero and JabRef manage .bib files
  • Put names of organisations in double braces so they are not split into first and last name
