Install

LaTeX comes in a distribution with the programs and packages. TeX Live is used on Linux, MacTeX on macOS and MiKTeX or TeX Live on Windows. You can also write LaTeX online in Overleaf without installing anything.

Debian and Ubuntu

texlive is a good start. texlive-full has every package but is several gigabytes.

$ sudo apt update
$ sudo apt install texlive
$ sudo apt install texlive-latex-extra texlive-lang-european
$ sudo apt install texlive-full

Fedora

$ sudo dnf install texlive-scheme-medium

macOS

Download MacTeX from tug.org/mactex, or install it with Homebrew.

$ brew install --cask mactex

Windows

Download MiKTeX or TeX Live. MiKTeX installs missing packages automatically the first time they are used.

Check the installation

$ pdflatex --version
$ latexmk --version

Install packages

tlmgr is the TeX Live package manager. On Debian and Ubuntu, install packages with apt instead.

$ tlmgr search --global --file tikz.sty
$ sudo tlmgr install tikz
$ sudo tlmgr update --all

Editors

  • Overleaf — online, with collaboration and preview, overleaf.com
  • TeXstudio — a full LaTeX editor, sudo apt install texstudio
  • VS Code and VSCodium — with the LaTeX Workshop extension
  • Vim — with the vimtex plugin

More about installing
