Text formatting

Commands like \textbf{} format the text inside the braces. Switches like \bfseries change everything after them until the end of the group.

Bold, italic and more

\textbf{bold}
\textit{italic}
\emph{emphasis}
\underline{underlined}
\texttt{monospace}
\textsc{Small Caps}
\textsl{slanted}
\textsf{sans serif}
\textrm{roman}
\textup{upright}

Emphasis

\emph is italic in normal text and upright inside italic text. Use it for emphasis, and \textit only when you really want italic.

\emph{important}
\textit{This is \emph{really} important.}

Combine

\textbf{\textit{bold and italic}}

Switches

Curly braces make a group so the switch only affects the text inside.

{\bfseries bold text}
{\itshape italic text}
{\ttfamily monospace text}
{\scshape small caps}
{\sffamily sans serif}

Fonts

Packages change the font of the whole document. With xelatex or lualatex, fontspec can use any installed font.

\usepackage{lmodern}        % Latin Modern
\usepackage{mathpazo}       % Palatino
\usepackage{helvet}         % Helvetica
\renewcommand{\familydefault}{\sfdefault}   % sans serif everywhere

\usepackage{fontspec}       % xelatex and lualatex
\setmainfont{Liberation Serif}

More about text formatting

  • \underline does not break across lines, the ulem or soul packages do
  • \sout{text} from ulem strikes text through
  • See also font size and colors
