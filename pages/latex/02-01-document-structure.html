Document structure

Every LaTeX file has two parts. The preamble sets up the document: the class, packages and settings. The body between \begin{document} and \end{document} has the content.

A typical document

\documentclass[a4paper,12pt]{article}

% Preamble
\usepackage[utf8]{inputenc}
\usepackage[T1]{fontenc}
\usepackage[english]{babel}

\title{My report}
\author{Anders Wik}
\date{\today}

\begin{document}

\maketitle

\section{Introduction}
Some text.

\end{document}

Document classes

\documentclass{article}   % short documents and papers
\documentclass{report}    % longer documents with chapters
\documentclass{book}      % books, with left and right pages
\documentclass{letter}    % letters
\documentclass{beamer}    % presentations
\documentclass{memoir}    % flexible book class

Class options

\documentclass[a4paper]{article}          % paper size: a4paper, letterpaper
\documentclass[12pt]{article}             % font size: 10pt, 11pt, 12pt
\documentclass[twocolumn]{article}        % two columns
\documentclass[twoside]{article}          % different left and right pages
\documentclass[landscape]{article}        % landscape
\documentclass[draft]{article}            % mark overfull lines, skip images

Split into several files

\input inserts another file where it is written. \include also starts a new page and is meant for chapters.

\input{chapters/introduction}
\include{chapters/method}

More about document structure

  • Everything after \end{document} is ignored
  • The packages page lists useful packages for the preamble
  • The title page uses \title, \author and \date from the preamble
