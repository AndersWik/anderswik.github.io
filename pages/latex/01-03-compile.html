Compile

A .tex file is turned into a PDF by an engine. pdflatex is the classic one. xelatex and lualatex support Unicode and the fonts installed on your system.

Compile to PDF

$ pdflatex document.tex
$ xelatex document.tex
$ lualatex document.tex

Run twice

References, the table of contents and page numbers are written to helper files the first time and used the second time. Run the engine twice if you see ?? in the PDF.

$ pdflatex document.tex
$ pdflatex document.tex

latexmk

latexmk runs the engine, the bibliography tool and everything else as many times as needed.

$ latexmk -pdf document.tex        # pdflatex
$ latexmk -xelatex document.tex    # xelatex
$ latexmk -lualatex document.tex   # lualatex
$ latexmk -pdf -pvc document.tex   # rebuild every time the file is saved

Clean up

Compiling creates helper files like .aux, .log and .toc.

$ latexmk -c     # remove helper files, keep the PDF
$ latexmk -C     # remove helper files and the PDF

Useful options

$ pdflatex -interaction=nonstopmode document.tex   # do not stop on errors
$ pdflatex -halt-on-error document.tex             # stop at the first error
$ pdflatex -output-directory=build document.tex    # put the files in build/
$ pdflatex -shell-escape document.tex              # allow external programs, needed by minted

More about compiling

  • Errors and warnings are written to the .log file, see errors
  • Add helper files to .gitignore: *.aux *.log *.out *.toc *.fls *.fdb_latexmk *.synctex.gz
  • Only use -shell-escape with files you trust
