Font size

Size commands are switches. They change the size of all text after them until the end of the group.

Sizes

\tiny
\scriptsize
\footnotesize
\small
\normalsize
\large
\Large
\LARGE
\huge
\Huge

Change a part of the text

{\Large This is large.} This is normal.

\begin{small}
A small paragraph.
\end{small}

Exact size

\fontsize{size}{line spacing} followed by \selectfont.

{\fontsize{30}{36}\selectfont Big text}

Document font size

\documentclass[12pt]{article}

More about font size

  • The real size of \large depends on the document font size
  • End a paragraph with \par inside the group so the line spacing also changes
