Special characters

Some characters have a special meaning in LaTeX and must be escaped with a backslash to be printed.

Reserved characters

\#   \$   \%   \&   \_   \{   \}
\textbackslash
\textasciitilde
\textasciicircum

Comments

Everything after % on a line is a comment. The comment package can hide whole blocks.

This is shown. % This is a comment

\usepackage{comment}
\begin{comment}
This is not shown.
\end{comment}

Dashes

well-known      % hyphen
1990--2000      % en dash, for ranges
Wait---what?    % em dash
$-1$            % minus sign, in math

Spaces

Dr.~Smith       % non-breaking space
Mr.\ Smith      % normal space after a dot that is not the end of a sentence
10\,km          % thin space

Other symbols

\ldots          % ...
\copyright      % ©
\textregistered % ®
\texttrademark  % ™
\S              % §
\P              % ¶
\dag            % †
\pounds         % £
\euro           % € with the eurosym package
\LaTeX \TeX     % the logos

More about special characters

  • Write ``text'' or use csquotes for quotation marks
  • With xelatex and lualatex you can type most Unicode characters directly
  • Use Detexify to find the command for a symbol
