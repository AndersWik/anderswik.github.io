Images

The graphicx package adds \includegraphics. pdflatex reads PDF, PNG and JPG files.

Image

\usepackage{graphicx}

\includegraphics{images/penguin.png}

Size and rotation

\includegraphics[width=5cm]{penguin}
\includegraphics[width=0.5\textwidth]{penguin}
\includegraphics[height=3cm]{penguin}
\includegraphics[scale=0.5]{penguin}
\includegraphics[angle=90]{penguin}

Figure with caption

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.6\textwidth]{penguin}
  \caption{Tux the penguin}
  \label{fig:tux}
\end{figure}

Image folder

The file extension can be left out. Set where LaTeX looks for images in the preamble.

\graphicspath{{images/}{figures/}}

Images side by side

\usepackage{subcaption}

\begin{figure}[htbp]
  \centering
  \begin{subfigure}{0.45\textwidth}
    \includegraphics[width=\linewidth]{one}
    \caption{First}
  \end{subfigure}
  \hfill
  \begin{subfigure}{0.45\textwidth}
    \includegraphics[width=\linewidth]{two}
    \caption{Second}
  \end{subfigure}
  \caption{Two images}
\end{figure}

More about images

  • Use PDF or SVG converted to PDF for diagrams, so they stay sharp
  • Convert SVG with inkscape file.svg --export-type=pdf
  • The draft class option shows boxes instead of images, which compiles faster
  • Draw figures in LaTeX with TikZ
