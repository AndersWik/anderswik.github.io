Custom commands

Make your own commands for things you write often. Then a change in one place updates the whole document.

New command

\newcommand{\R}{\mathbb{R}}
\newcommand{\product}{\textsc{SuperApp}}

Let $x \in \R$. Download \product{} today.

With arguments

The number in square brackets is how many arguments the command takes. Use them with #1, #2.

\newcommand{\important}[1]{\textbf{\textcolor{red}{#1}}}
\newcommand{\abs}[1]{\left|#1\right|}
\newcommand{\pair}[2]{(#1, #2)}

\important{Back up first!}
$\abs{x}$ and $\pair{a}{b}$

Optional argument

The second square bracket is the default value of the first argument.

\newcommand{\greet}[1][world]{Hello, #1!}

\greet       % Hello, world!
\greet[you]  % Hello, you!

Change a command

\renewcommand{\contentsname}{Index}
\renewcommand{\figurename}{Picture}

New environment

\newenvironment{note}
  {\begin{quote}\textbf{Note:}}
  {\end{quote}}

\begin{note}
  Remember to save.
\end{note}

Counters

\newcounter{step}
\stepcounter{step}
Step \thestep
\setcounter{page}{5}

More about custom commands

  • \newcommand gives an error if the command already exists, \renewcommand if it does not
  • Put your commands in a file and load it with \input{commands}
  • The amsthm package makes theorem environments with \newtheorem{theorem}{Theorem}
