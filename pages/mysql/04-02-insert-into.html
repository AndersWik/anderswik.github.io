Insert into

insert into adds new rows to a table. Give the columns to fill in and a value for each of them. The values must match the data type of the column.

Insert into table

mysql> insert into mytable (column1) values ("Some value");

Insert several rows

mysql> insert into mytable (column1, column2) values ("First", "Value"), ("Second", "Value");
