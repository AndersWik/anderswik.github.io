Install

MySQL is a database server. The server runs as a service. Connect with the mysql client. Query by writing SQL. These notes show the most common commands, from creating a database to importing and exporting it.

Installation

$ sudo apt install mysql-server

Mysql secure installation

mysql_secure_installation asks a few questions to make the server safer, such as removing anonymous users and the test database. The answers can be given in advance. This example is for a Vagrant machine.

$ sudo mysql_secure_installation <<EOF

n
n
Y
Y
Y
Y
EOF

Restart

$ sudo service mysql restart

Log on

-u gives the user and -p asks for the password. When you are logged on the prompt changes to mysql>.

$ mysql -u root -p

Leave the client with exit.

mysql> exit
