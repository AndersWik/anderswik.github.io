Update

update changes rows that already exist. SET gives the new values and WHERE chooses the rows. Without WHERE every row in the table is changed.

Update

mysql> UPDATE mytable SET column1 = 'New value' WHERE id = 1;
mysql> UPDATE mytable SET column1 = 'New value', column2 = 'Other value' WHERE id = 1;
