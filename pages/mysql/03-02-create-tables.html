Create table

create table makes a new table in the selected database. Give each column a name and a data type, such as text, integer or boolean.

Create table

A table needs at least one column.

mysql> create table mytable (column1 text);

Columns

Some different ways to write the columns. Each line creates a new table, so drop mytable before you try the next one.

mysql> create table mytable (column2 boolean);

mysql> create table mytable (column1 text, column2 boolean);

Not null

NOT NULL means the column must always have a value.

mysql> create table mytable (column1 text NOT NULL);

mysql> create table mytable (column1 text NOT NULL, column2 boolean NOT NULL);

Primary key

PRIMARY KEY makes the column a unique id for each row. AUTO_INCREMENT gives every new row the next number automatically.

mysql> create table mytable (id integer PRIMARY KEY AUTO_INCREMENT);

mysql> create table mytable (id integer PRIMARY KEY AUTO_INCREMENT, column1 text NOT NULL, column2 text NOT NULL);
