Remote server

The mysql client can connect to a server on another machine. -h gives the host or ip and -P gives the port. The default port is 3306.

Connect

$ mysql -h {ip} -P 3306 -u {user} -p

Import database

$ mysql -h {ip} -P 3306 -u {user} -p {db name} < {db dump name}.sql

Export database

Exporting from a remote server can give this error when the user is not allowed to lock tables:

Got error: 1044: Access denied for user '' to database '' when using LOCK TABLES

Add --single-transaction to fix this.

$ mysqldump --single-transaction -h {ip} -P 3306 -u {user} -p {db name} > {db dump name}.sql
