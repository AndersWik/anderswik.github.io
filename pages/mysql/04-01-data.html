Data

Data is stored as rows in a table. Each column in a row has a data type, which decides what kind of value it can hold: a number, a text, a date or true and false. Choose the smallest type that fits the data. In this chapter you add rows with insert into, read them with select, change them with update and remove them with delete.

Numbers

  • TINYINT — small whole numbers, -128 to 127
  • INT or INTEGER — whole numbers, about -2 billion to 2 billion
  • BIGINT — very large whole numbers
  • DECIMAL(10,2) — exact numbers with decimals, good for money. 10 is the total number of digits and 2 the number of decimals.
  • FLOAT and DOUBLE — numbers with decimals that are close to the value but not always exact

Add UNSIGNED to only allow numbers that are zero or more, for example INT UNSIGNED.

Strings

  • CHAR(10) — text with a fixed length, here always 10 characters
  • VARCHAR(255) — text up to the given length, the most common type for names, emails and titles
  • TEXT — longer text, up to about 65 000 characters
  • LONGTEXT — very long text, such as whole articles
  • ENUM('small','medium','large') — one value from a fixed list

Strings are written inside quotes: 'Hello world'.

Booleans

BOOLEAN or BOOL holds true or false. MySQL stores it as TINYINT(1), where 0 is false and 1 is true. You can write TRUE and FALSE, but you get 1 and 0 back.

Dates and times

  • DATE — a date, '2026-11-07'
  • TIME — a time, '14:30:00'
  • DATETIME — a date and time, '2026-11-07 14:30:00'
  • TIMESTAMP — a date and time that can be set automatically when the row is created or changed
  • YEAR — a year, 2026

Other types

  • JSON — a JSON document
  • BLOB — binary data, such as a small file

NULL

NULL means that the value is missing. It is not the same as 0 or an empty string ''. A column can hold NULL unless it is created with NOT NULL. Find missing values with IS NULL, see select.

Example

A table where each row has a number, a string, a boolean, a decimal and a date.

mysql> create table products (
    id INT UNSIGNED PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    in_stock BOOLEAN NOT NULL DEFAULT TRUE,
    price DECIMAL(10,2),
    added DATE
);

mysql> insert into products (name, in_stock, price, added) values ('Lamp', TRUE, 199.90, '2026-11-07');

mysql> select * from products;
