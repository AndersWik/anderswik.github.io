Databases

A database is a collection of tables that belong together, for example all the tables used by one website or one application. One MySQL server can hold many databases, and each database is kept separate from the others. In MySQL a database is also called a schema.

Server, database, table and row

The data in MySQL is organized in levels:

  • Server — the MySQL program that runs on a machine. You connect to it with the mysql client.
  • Database — a named collection of tables on the server.
  • Table — holds the data in columns and rows, like a spreadsheet.
  • Row — one entry in a table, for example one user or one order.

Working with databases

List the databases on the server, create a new one and select it. Every command after use works on the selected database.

mysql> show databases;
mysql> create database mydatabase;
mysql> use mydatabase;
mysql> show tables;

System databases

A new server already has some databases that MySQL uses itself. Do not change or remove them.

  • mysql — users, privileges and settings
  • information_schema — information about all databases, tables and columns
  • performance_schema and sys — statistics about how the server performs

Names

Use short names with lowercase letters, numbers and _, such as my_shop. If a name has other characters, put it inside backticks, for example `my-shop`.
