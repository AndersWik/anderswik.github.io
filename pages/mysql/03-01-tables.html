Tables

The data in a database is stored in tables. A table looks like a spreadsheet. The columns decide what can be stored, and every row is one entry.

Columns and rows

Here is a table called users with three columns and three rows.

idnameactive
1Anna1
2Erik0
3Maria1
  • Column — has a name and a data type. Every value in the column must be of that type.
  • Row — one entry in the table, with a value for each column.

Primary key

Most tables have a column with a unique id for each row, called the primary key. It is often a number that MySQL counts up automatically with AUTO_INCREMENT. The id makes it easy to find, update or delete exactly one row.

Example

This creates the users table above and shows its columns.

mysql> create table users (id integer PRIMARY KEY AUTO_INCREMENT, name varchar(100) NOT NULL, active boolean);
mysql> describe users;
