Trim and concat

MySQL has functions to change text. TRIM removes text from the start or end of a value, and CONCAT joins text together. Use them with update to change many rows at once.

Trim trailing

Remove .com from the end of the value.

mysql> UPDATE `mytable` SET column1 = TRIM(TRAILING '.com' FROM column1);

Trim leading

Remove https:// from the start of the value.

mysql> UPDATE `mytable` SET column1 = TRIM(LEADING 'https://' FROM column1);

Only change the rows that start with //.

mysql> UPDATE `mytable` SET column1 = TRIM(LEADING '//' FROM column1) WHERE column1 LIKE '//%';

Concat

Add a / to the start of every value that does not already start with one.

mysql> UPDATE `mytable` SET column1 = CONCAT('/', column1) WHERE column1 NOT LIKE '/%';

IGNORE skips the rows that would give an error, for example when the new value already exists in a unique column.

mysql> UPDATE IGNORE `mytable` SET column1 = CONCAT('/', column1) WHERE column1 NOT LIKE '/%';
