Export

A database can be exported to a file with SQL, called a dump. The dump can be used as a backup or to move the database to another server, where it is imported again.

Export database

mysqldump is run in the terminal, not inside the mysql client.

$ mysqldump -u {user} -p {db name} > {db dump name}.sql

Example:

$ mysqldump -u root -p mydatabase > mydatabase.sql
