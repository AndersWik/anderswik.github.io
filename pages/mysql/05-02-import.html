Import

A dump made with export can be imported into a database. The database must exist first, see create database.

Import from the client

Inside the mysql client, select the database and run the dump with source.

mysql> use {db name};
mysql> source {path to db dump}/mysqldump.sql;

Example:

mysql> source /mysqldump.sql;

Import from the terminal

$ mysql -u {user} -p {db name} < {db dump name}.sql

Import multiple database dumps

Dry run

This loops over all files in the current directory that start with example_ and end with .sql. First do a dry run with echo to see which files are selected.

$ for SQL in example_*.sql; do echo $SQL; done

Import

This loops over all .sql files in the current folder. The password must be given in the command with the -p flag, written together with the password with no space. For example -p + root = -proot. The password is then saved in the shell history, so only do this on a development machine.

$ for SQL in *.sql; do mysql -u root "-proot" "mydatabase" < $SQL; done
