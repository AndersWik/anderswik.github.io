Troubleshooting

Some common errors and how to fix them.

Authentication plugin 'caching_sha2_password' cannot be loaded

Newer MySQL versions use caching_sha2_password to log on, which some older clients do not support. Change the user to the older mysql_native_password.

mysql> ALTER USER 'yourusername'@'localhost' IDENTIFIED WITH mysql_native_password BY 'yourpassword';
