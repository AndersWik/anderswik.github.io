Linux Playground

Try Linux commands in a pretend file system. Nothing here touches your computer, and reset puts every file back.

Tab completes names, ↑ and ↓ go through earlier commands, Ctrl+L clears the screen. In man, scroll with the arrow keys or Space and press q to quit.
