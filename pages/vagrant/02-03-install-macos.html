Install on macOS

The easiest way to install Vagrant on a Mac is with Homebrew.

Install Vagrant

$ brew tap hashicorp/tap
$ brew install hashicorp/tap/hashicorp-vagrant

You can also download the installer from HashiCorp and double click it.

Install a provider

Vagrant needs a provider to run the machines. Which one works depends on the processor in your Mac.

$ uname -m
  • x86_64 — an Intel Mac. VirtualBox, VMware Fusion and Parallels all work
  • arm64 — Apple silicon (M1 and later). Use VMware Fusion, Parallels or VirtualBox 7.1 or later, and pick boxes built for arm64

VirtualBox can also be installed with Homebrew.

$ brew install --cask virtualbox

With another provider than VirtualBox, tell Vagrant which one to use.

$ vagrant up --provider=vmware_desktop

Version

--version and -v show which version of Vagrant is installed.

$ vagrant --version
$ vagrant -v

More about Vagrant on macOS

  • Install Vagrant at HashiCorp
  • VMware needs an extra plugin, see VMware
  • Upgrade later with brew upgrade hashicorp/tap/hashicorp-vagrant
