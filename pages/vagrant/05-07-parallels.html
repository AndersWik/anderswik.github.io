Parallels

Parallels Desktop is a hypervisor for macOS that works well on Macs with Apple silicon. It needs the vagrant-parallels plugin, and Parallels Desktop Pro or Business edition. The Standard edition does not work with Vagrant.

Install

  1. Install Parallels Desktop
  2. Install the plugin
$ vagrant plugin install vagrant-parallels

Start a machine

$ vagrant up --provider=parallels

Settings

config.vm.provider "parallels" do |prl|
  prl.name = "dev"
  prl.memory = 2048
  prl.cpus = 2
  prl.update_guest_tools = true
end
  • update_guest_tools — update Parallels Tools in the machine when it starts. They are needed for synced folders

Apple silicon

On Macs with Apple silicon, the box must be built for ARM (arm64). The bento boxes have ARM versions for Parallels.
