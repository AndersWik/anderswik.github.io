libvirt

libvirt lets Vagrant use KVM, the hypervisor built into the Linux kernel. It is fast and free, and a good choice on Linux. It needs the vagrant-libvirt plugin.

Install

On Debian and Ubuntu the plugin is a normal package, see Install on Debian.

$ sudo apt install vagrant-libvirt libvirt-daemon-system
$ sudo usermod --append --groups libvirt $USER

With Vagrant from HashiCorp's repository, install the plugin with Vagrant instead. It needs the libvirt development files to build.

$ sudo apt install libvirt-dev
$ vagrant plugin install vagrant-libvirt

Start a machine

$ vagrant up --provider=libvirt

To make libvirt the default provider, add this to ~/.bashrc.

export VAGRANT_DEFAULT_PROVIDER=libvirt

Settings

config.vm.provider "libvirt" do |lv|
  lv.memory = 2048
  lv.cpus = 2
  lv.nested = true
end
  • nested — allow virtual machines inside the machine

Synced folders

Synced folders use NFS by default, which needs an NFS server on the host. virtiofs is a faster option that needs no server.

config.vm.synced_folder ".", "/vagrant", type: "virtiofs"

config.vm.provider "libvirt" do |lv|
  lv.memorybacking :access, :mode => "shared"
end

More about libvirt

  • The machines are normal libvirt machines and are also shown in virsh list and Virtual Machine Manager
  • The box must support libvirt, for example debian/bookworm64
