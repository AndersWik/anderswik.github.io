Vagrantfile

The Vagrantfile describes the virtual machine. Which box to use, how much memory it gets, its network, shared folders and what software to install. Vagrant looks for it in the folder you run the command from. The file is written in Ruby.

Create a Vagrantfile

Make a folder for the project and run init. It creates a Vagrantfile with lots of comments that explain the most common settings.

$ mkdir my-vm
$ cd my-vm
$ vagrant init bento/ubuntu-24.04

-m creates a minimal file without the comments.

$ vagrant init -m bento/ubuntu-24.04
Vagrant.configure("2") do |config|
  config.vm.box = "bento/ubuntu-24.04"
end

The "2" is the version of the configuration format, not of Vagrant. All settings go between do |config| and end.

A more complete example

This machine gets a host name, a fixed IP address, 2 GB of memory and 2 CPUs.

Vagrant.configure("2") do |config|
  config.vm.box = "bento/ubuntu-24.04"
  config.vm.hostname = "dev"
  config.vm.network "private_network", ip: "192.168.56.10"

  config.vm.provider "virtualbox" do |vb|
    vb.memory = 2048
    vb.cpus = 2
  end
end

Common settings

  • config.vm.box — the box to build the machine from
  • config.vm.box_version — use a specific version of the box, for example "1.1.0"
  • config.vm.hostname — the host name inside the machine
  • config.vm.network — networking and port forwarding
  • config.vm.synced_folder — folders shared with the host
  • config.vm.provider — settings for the provider, such as memory and CPUs
  • config.vm.provision — install software when the machine is created

Check the file

validate checks the Vagrantfile for mistakes without starting anything. After changing the file, run vagrant reload to apply the changes to a running machine.

$ vagrant validate
$ vagrant reload

Help

--help and -h show all options for init.

$ vagrant init --help
$ vagrant init -h
