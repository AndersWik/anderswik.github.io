Networking

Every Vagrant machine gets a NAT network. It lets the machine reach the internet and is what vagrant ssh uses, but other computers cannot reach the machine through it. To reach the machine, add one of the networks below to the Vagrantfile and run vagrant reload.

Forward a port

Port forwarding makes a port in the machine available on the host. Here, a web server on port 80 in the machine is opened at http://localhost:8080 on the host.

config.vm.network "forwarded_port", guest: 80, host: 8080

By default other computers on your network can reach the port too. host_ip limits it to your own computer.

config.vm.network "forwarded_port", guest: 80, host: 8080, host_ip: "127.0.0.1"

vagrant port lists the forwarded ports.

$ vagrant port

Private network

A private network, also called host-only, gives the machine its own IP address that only the host and other machines on the same network can reach. Good for development.

config.vm.network "private_network", ip: "192.168.56.10"

Newer versions of VirtualBox only allow addresses in 192.168.56.0/21 on Linux and macOS hosts. Other addresses must be added to /etc/vbox/networks.conf. You can also let the address be picked automatically.

config.vm.network "private_network", type: "dhcp"

Public network

A public network, also called bridged, connects the machine directly to your real network. It gets an address from your router and appears as a separate computer that everyone on the network can reach.

config.vm.network "public_network"

If the host has several network cards, Vagrant asks which one to use. Give the name to skip the question.

config.vm.network "public_network", bridge: "eth0"

Which one to use

  • Forwarded port — reach a single service, like a web server, from the host
  • Private network — reach the whole machine from the host, or connect several machines
  • Public network — let other computers on your network reach the machine

More about networking

  • Check the address inside the machine with ip: vagrant ssh -c "ip address"
  • Hyper-V ignores these settings, see Hyper-V
