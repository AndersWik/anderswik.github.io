Install on Debian

Debian has Vagrant in its own repositories. Together with libvirt it uses KVM, the hypervisor built into the Linux kernel, so you do not need VirtualBox.

Install Vagrant and libvirt

$ sudo apt install vagrant vagrant-libvirt libvirt-daemon-system

Give your user access

Add your user to the libvirt group, then log out and in again for it to take effect.

$ sudo usermod --append --groups libvirt $USER

Check that you are in the group. The command should print libvirt.

$ groups | grep -o libvirt

Start a machine

$ vagrant init debian/bookworm64
$ vagrant up --provider=libvirt
$ vagrant ssh

To skip --provider every time, make libvirt the default provider in ~/.bashrc.

export VAGRANT_DEFAULT_PROVIDER=libvirt

Version

--version and -v show which version of Vagrant is installed.

$ vagrant --version
$ vagrant -v

More about Vagrant on Debian

  • Vagrant on the Debian wiki
  • For a newer version, use HashiCorp's own repository, see Install on Ubuntu
