Share

vagrant share gives your machine a public URL, so someone else can see the web site you are working on. It is a plugin that uses ngrok to open the connection.

Install

Install the plugin, then download ngrok and put it in a folder in your PATH, for example /usr/local/bin.

$ vagrant plugin install vagrant-share

Share a machine

Run the command on the host, not inside the machine. It prints a URL that others can open. Press Ctrl + c to stop sharing.

$ vagrant share

No HTTP port found

If Vagrant says "Vagrant was unable to detect an HTTP port for your machine", it could not find a web server. Check that the web server is running in the machine, then tell Vagrant which port to use.

$ vagrant share --http 80

Or forward the port in the Vagrantfile, so Vagrant can find it by itself.

config.vm.network "forwarded_port", guest: 80, host: 8080

Without the plugin

If the plugin does not work with your version of Vagrant, forward the port as above and run ngrok yourself.

$ ngrok http 8080

Help

When the plugin is installed, --help and -h show all options for share.

$ vagrant share --help
$ vagrant share -h

More about share

  • vagrant share --ssh lets others log in to the machine with ssh
  • Anyone with the URL can reach the machine, so only share what you mean to
  • Vagrant Share in the documentation
