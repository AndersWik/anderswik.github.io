Global status

vagrant global-status lists all Vagrant machines on the computer, no matter which folder they are in.

$ vagrant global-status
id       name    provider   state    directory
-----------------------------------------------------------
1a2b3c4  default virtualbox running  /home/user/my-vm

Use the id

The id can be used with other commands, so you do not have to go to the folder first.

$ vagrant ssh 1a2b3c4
$ vagrant halt 1a2b3c4

Clean up the list

The list is a cache. If a machine or its folder was removed without vagrant destroy, it can still show up. --prune removes entries that no longer exist.

$ vagrant global-status --prune

Help

--help and -h show all options for global-status.

$ vagrant global-status --help
$ vagrant global-status -h
