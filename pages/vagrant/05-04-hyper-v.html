Hyper-V

Hyper-V is the hypervisor built into Windows 10 and 11 Pro, Enterprise and Education. Support for it is built into Vagrant, so no plugin is needed.

Turn on Hyper-V

Run PowerShell as administrator and restart the computer afterwards.

> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All

Start a machine

Vagrant needs administrator rights to use Hyper-V, so run the terminal as administrator.

> vagrant up --provider=hyperv

Network

Vagrant cannot set up networks in Hyper-V, so the networking settings in the Vagrantfile are ignored. When the machine starts, Vagrant asks which virtual switch to use. Default Switch works for most uses.

Synced folders

Synced folders use Windows file sharing (SMB). Vagrant asks for your Windows user name and password to set it up.

Settings

config.vm.provider "hyperv" do |h|
  h.vmname = "dev"
  h.memory = 2048
  h.cpus = 2
end

More about Hyper-V

  • Hyper-V can make VirtualBox slower when both are installed
  • The box must support hyperv
  • Hyper-V provider in the documentation
