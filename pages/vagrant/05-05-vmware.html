VMware

Vagrant can run machines with VMware Workstation on Linux and Windows, or VMware Fusion on macOS. It is a good choice on Macs with Apple silicon.

Install

  1. Install VMware Workstation or VMware Fusion
  2. Install the Vagrant VMware Utility from HashiCorp. It lets Vagrant talk to VMware
  3. Install the plugin
$ vagrant plugin install vagrant-vmware-desktop

Start a machine

The provider is called vmware_desktop for both Workstation and Fusion.

$ vagrant up --provider=vmware_desktop

Settings

VMware settings are set through vmx, the settings of the machine's configuration file.

config.vm.provider "vmware_desktop" do |v|
  v.vmx["memsize"] = "2048"
  v.vmx["numvcpus"] = "2"
  v.gui = true
end
