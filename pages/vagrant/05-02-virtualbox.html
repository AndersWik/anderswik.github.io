VirtualBox

VirtualBox is a free hypervisor from Oracle that works on Linux, Windows and macOS. Support for it is built into Vagrant, and it is the default provider, so no plugin or extra options are needed.

Install

Download VirtualBox from virtualbox.org and install it before you start a machine. Check that it is installed.

$ VBoxManage --version

Start a machine

VirtualBox is used when no other provider is chosen, but you can also name it.

$ vagrant up
$ vagrant up --provider=virtualbox

Settings

config.vm.provider "virtualbox" do |vb|
  vb.name = "dev"
  vb.memory = 2048
  vb.cpus = 2
  vb.gui = false
  vb.linked_clone = true
end
  • gui — show the machine's screen in a window
  • linked_clone — create new machines from a copy of the box instead of a full import. Faster and uses less disk

Settings that Vagrant has no option for can be set with customize, which runs VBoxManage modifyvm.

config.vm.provider "virtualbox" do |vb|
  vb.customize ["modifyvm", :id, "--clipboard-mode", "bidirectional"]
end

Guest Additions

Guest Additions are drivers installed in the machine. They are needed for VirtualBox synced folders and a better screen. Most boxes already have them installed.

Private network

On Linux and macOS, VirtualBox only allows host-only networks in the range 192.168.56.0/21. Use an address such as 192.168.56.10, or allow other ranges in /etc/vbox/networks.conf.

* 10.0.0.0/8 192.168.0.0/16
