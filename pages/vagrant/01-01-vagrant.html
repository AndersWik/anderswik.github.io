Vagrant

Vagrant is a command line tool from HashiCorp for creating and managing virtual machines. You describe the machine in the Vagrantfile. You can share the Vagrant file and everyone who uses the same file gets the same machine. This makes sure everyone have the same development environment.

Vagrant does not run the virtual machines itself. It uses a provider, such as VirtualBox, VMware, Hyper-V or libvirt.

Quick start

Create a folder, add a Vagrantfile with a box, start the machine and log in.

$ mkdir my-vm
$ cd my-vm
$ vagrant init bento/ubuntu-24.04
$ vagrant up
$ vagrant ssh

When you are done, stop the machine or remove it completely.

$ vagrant halt
$ vagrant destroy

What you will learn

  • Virtualization — hosts, guests and hypervisors
  • Install Vagrant on Debian, Ubuntu, macOS or Windows
  • Boxes — the ready made images machines are built from

  • Networking and multiple machines

Help

--help and -h list the most common commands. Add them after a command to see its options.

$ vagrant --help
$ vagrant -h
$ vagrant up --help

list-commands shows every command, including the less common ones.

$ vagrant list-commands

Version

--version and -v show which version of Vagrant is installed. vagrant version also checks if a newer version is available.

$ vagrant --version
$ vagrant -v
$ vagrant version
