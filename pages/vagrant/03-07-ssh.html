Ssh

vagrant ssh logs you in to the machine. You are logged in as the user vagrant, which can use sudo without a password. Type exit to leave.

$ vagrant ssh
$ exit

Run a single command

$ vagrant ssh -c "uptime"

Connect with ordinary ssh

ssh-config prints the address, port and key to use. Save it to a file to connect with ssh, scp or your editor.

$ vagrant ssh-config > vagrant-ssh.conf
$ ssh -F vagrant-ssh.conf default

Password and your own key

If you are asked for a password, the default is vagrant. To log in with your own key, add your public key to the end of authorized_keys inside the machine.

$ vagrant ssh
$ nano ~/.ssh/authorized_keys

Help

--help and -h show all options for ssh.

$ vagrant ssh --help
$ vagrant ssh -h

More about ssh

  • With several machines, give the name: vagrant ssh web
