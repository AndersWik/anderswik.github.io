Install on Ubuntu

HashiCorp has its own package repository with the latest version of Vagrant. These steps also work on Linux Mint and other distributions based on Ubuntu or Debian.

Check for virtualization support

The CPU needs virtualization support. If the command prints a number larger than 0, it is available.

$ grep -E -c '(vmx|svm)' /proc/cpuinfo

Install a provider

Vagrant needs a provider to run the machines. VirtualBox is the most common one.

$ sudo apt install virtualbox

Add the HashiCorp repository

Download HashiCorp's signing key and add the repository.

$ wget -O - https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp-archive-keyring.gpg
$ echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list

Install Vagrant

$ sudo apt update
$ sudo apt install vagrant

Vagrant is now updated together with the rest of the system.

Version

--version and -v show which version of Vagrant is installed.

$ vagrant --version
$ vagrant -v

More about Vagrant on Ubuntu

  • Install Vagrant at HashiCorp
  • On Linux Mint, use the code name of the Ubuntu version Mint is based on, for example noble or jammy, instead of $(lsb_release -cs)
  • To use KVM instead of VirtualBox, see Install on Debian
