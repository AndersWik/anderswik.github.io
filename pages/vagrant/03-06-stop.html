Stop

There are three ways to stop a machine. Run the commands in the folder with the Vagrantfile.

Pause the machine

suspend saves the state of the machine. It starts quickly and the machine is in the same state. The downside is the saved memory takes up disk space.

$ vagrant suspend
$ vagrant resume

Shut down the machine

halt shuts the machine down completely. Start it again with vagrant up. -f turns it off at once, like pulling the power cord.

$ vagrant halt
$ vagrant halt -f

Delete the machine

destroy stops the machine and deletes it. Files in synced folders, the Vagrantfile and the box are kept. vagrant up creates a new machine. -f skips the question.

$ vagrant destroy
$ vagrant destroy -f

Help

--help and -h show the options for each command.

$ vagrant halt --help
$ vagrant destroy -h

More about stopping

  • vagrant suspend --all-global pauses every running machine on the computer
  • See which machines are running with global-status
