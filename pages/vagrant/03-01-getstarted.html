Get started

This chapter covers the basics you need. You learn what boxes are, how to describe a machine in the Vagrantfile and how synced folders share files between the host and the machine. Then you use the commands to start, stop and log in to a machine, check its status and list all machines on the computer. The chapter ends with provisioning, which installs software in the machine automatically and snapshots that saves the state of a machine so you can go back to it later.
