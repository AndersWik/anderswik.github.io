Install on Windows

On Windows, Vagrant is installed with an ordinary installer or with winget. The commands below are run in PowerShell or the Command Prompt.

Check for virtualization support

Look for Virtualization Enabled In Firmware: Yes under Hyper-V Requirements. If it says No, turn on virtualization in the BIOS or UEFI settings.

> systeminfo

Install a provider

Vagrant needs a provider to run the machines. Install VirtualBox, or use Hyper-V which is included in Windows Pro, Enterprise and Education.

Install Vagrant

Download the installer from HashiCorp and run it, or use winget.

> winget install Hashicorp.Vagrant

The installer adds Vagrant to the PATH. Restart the computer when it asks you to, then open a new terminal.

Version

--version and -v show which version of Vagrant is installed.

> vagrant --version
> vagrant -v

More about Vagrant on Windows

  • Install Vagrant at HashiCorp
  • If vagrant is not found, check that C:\Program Files\Vagrant\bin (or C:\HashiCorp\Vagrant\bin in older versions) is in the PATH
  • VirtualBox and Hyper-V can get in each other's way. If machines are slow or do not start, use one of them
