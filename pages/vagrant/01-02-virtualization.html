Virtualization

Virtualization lets one physical computer run several virtual computers at the same time. Each virtual machine (VM) has its own operating system and acts like a separate computer, but shares the CPU, memory and disk of the real machine. Vagrant is built on top of this.

Host and guest

  • Host — the physical computer that runs the virtual machines
  • Guest — a virtual machine running on the host

Hypervisor

The hypervisor is the software that creates and runs virtual machines and shares the host's hardware between them. It is also called a Virtual Machine Monitor (VMM). There are two kinds:

  • Type 1 runs directly on the hardware, for example Hyper-V and KVM
  • Type 2 runs as a program on a normal operating system, for example VirtualBox and VMware Workstation

In Vagrant the hypervisor is called a provider.

Virtual machine image

An image is a file with a ready installed operating system that a virtual machine can start from. Vagrant calls its images boxes.

Hardware support

Virtual machines run much faster when the CPU supports virtualization: Intel VT-x or AMD-V. It is sometimes turned off in the BIOS or UEFI settings. On Linux you can check it with lscpu.

$ lscpu | grep Virtualization
Virtualization:                  VT-x

Why use virtual machines

  • Test software on another operating system without a second computer
  • Keep projects separated, each with its own tools and versions
  • Throw a machine away and start over in minutes
