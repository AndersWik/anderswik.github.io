Docker

The Docker provider runs containers instead of virtual machines. Containers start in seconds and use less memory, but they share the host's Linux kernel. Support for Docker is built into Vagrant, so no plugin is needed.

Install

Install Docker, see Get Docker. Check that it works.

$ docker run hello-world

Run an image

The Docker provider does not use a box. Set a Docker image instead.

Vagrant.configure("2") do |config|
  config.vm.provider "docker" do |d|
    d.image = "nginx"
    d.name = "web"
    d.ports = ["8080:80"]
  end
end
$ vagrant up --provider=docker

The web server is now open at http://localhost:8080.

Build from a Dockerfile

build_dir builds the image from a Dockerfile in the given folder.

config.vm.provider "docker" do |d|
  d.build_dir = "."
end

Commands

Most containers have no SSH server, so vagrant ssh does not work. Use the Docker commands instead.

$ vagrant docker-logs
$ vagrant docker-exec -it -- bash

If the image has an SSH server, set d.has_ssh = true to use vagrant ssh and provisioning.

More about Docker

  • Docker containers run Linux. On Windows and macOS, Docker Desktop runs them in a small virtual machine
  • For only containers, plain Docker or Docker Compose is often simpler than Vagrant
