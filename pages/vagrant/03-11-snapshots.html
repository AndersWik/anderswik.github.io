Snapshots

A snapshot saves the exact state of a machine so you can go back to it later. Take one before trying something risky, and restore it if things go wrong. Snapshots are built into Vagrant and work with most providers.

Save a snapshot

$ vagrant snapshot save clean

List snapshots

$ vagrant snapshot list

Restore a snapshot

$ vagrant snapshot restore clean

Delete a snapshot

$ vagrant snapshot delete clean

Quick snapshots

push takes a snapshot without a name, and pop restores the latest one and deletes it. Do not mix push and pop with save and restore.

$ vagrant snapshot push
$ vagrant snapshot pop

Help

--help and -h list all snapshot subcommands.

$ vagrant snapshot --help
$ vagrant snapshot -h
$ vagrant snapshot save -h

More about snapshots

  • With several machines, give the name first: vagrant snapshot save web clean
  • Snapshots take up disk space. Delete the ones you no longer need
  • Older guides use the plugin vagrant-vbox-snapshot. It is no longer needed
  • vagrant snapshot in the documentation
