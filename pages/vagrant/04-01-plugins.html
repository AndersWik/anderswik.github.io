Plugins

Plugins add new features to Vagrant, such as more providers, commands or provisioners.

Install a plugin

$ vagrant plugin install vagrant-hostmanager

List, update and remove plugins

$ vagrant plugin list
$ vagrant plugin update
$ vagrant plugin uninstall vagrant-hostmanager

Require plugins in the Vagrantfile

List the plugins a project needs in the Vagrantfile. Vagrant offers to install any that are missing when someone runs it.

Vagrant.configure("2") do |config|
  config.vagrant.plugins = ["vagrant-hostmanager"]
end

Many plugins also add their own settings to the Vagrantfile. Check the plugin's documentation.

Useful plugins

  • vagrant-libvirt — run machines with KVM on Linux
  • vagrant-vmware-desktop — run machines with VMware
  • vagrant-parallels — run machines with Parallels on macOS
  • vagrant-hostmanager — keeps /etc/hosts updated with the names of your machines
  • vagrant-share — share a machine over the internet

Help

--help and -h list all plugin subcommands.

$ vagrant plugin --help
$ vagrant plugin -h
$ vagrant plugin install -h

More about plugins

  • If plugins stop working after a Vagrant upgrade, run vagrant plugin repair, or vagrant plugin expunge to remove them all
