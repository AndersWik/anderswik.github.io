Synced folders

A synced folder is a folder that both the host and the virtual machine can see. You can edit code on your computer with your normal editor and run it inside the machine.

The default folder

The default folder is the folder where the Vagrantfile is. It is shared as /vagrant inside the machine.

$ vagrant ssh
$ ls /vagrant
Vagrantfile

Add a folder

The first path is on the host, relative to the Vagrantfile. The second is inside the machine.

Vagrant.configure("2") do |config|
  config.vm.box = "bento/ubuntu-24.04"
  config.vm.synced_folder "./src", "/home/vagrant/app"
end

Run vagrant reload to use the new folder on a running machine.

Turn off the default folder

config.vm.synced_folder ".", "/vagrant", disabled: true

Choose how folders are synced

How the files are shared depends on the provider. VirtualBox uses its own shared folders. You can also choose a type yourself.

  • rsync — copies the files into the machine. Works everywhere but only goes one way, from the host to the guest
  • nfs — fast network sharing on Linux and macOS hosts
  • smb — Windows file sharing, used with Hyper-V
config.vm.synced_folder "./src", "/home/vagrant/app", type: "rsync"

With rsync the files are copied on vagrant up and vagrant reload. To keep copying while you work, run rsync-auto in a separate terminal.

$ vagrant rsync-auto

More about synced folders

  • Set the owner of the files with owner: "www-data", group: "www-data"
  • Files in synced folders are kept when you run vagrant destroy
