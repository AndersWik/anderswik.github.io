Provisioning

Provisioning installs and configures software in the machine automatically. Everyone who starts the machine gets the same setup. The scripts can be kept in version control together with the code.

Provisioning runs the first time you run vagrant up. Later starts skip it. You can trigger it again with the provision parameter.

A short shell script

Small scripts can be written straight into the Vagrantfile. The scripts run as root, so sudo is not needed.

Vagrant.configure("2") do |config|
  config.vm.box = "bento/ubuntu-24.04"
  config.vm.provision "shell", inline: <<-SHELL
    apt-get update
    apt-get install -y apache2
  SHELL
end

A script file

Longer scripts are easier to keep in their own file, for example bootstrap/setup.sh next to the Vagrantfile.

$ mkdir bootstrap
$ nano bootstrap/setup.sh
#!/bin/bash
echo "Vagrant setup"
apt-get update
apt-get install -y apache2
config.vm.provision "shell", path: "bootstrap/setup.sh"

Run provisioning again

After changing a script, run it on the running machine, or restart the machine and run it.

$ vagrant provision
$ vagrant reload --provision

The output of the scripts is shown in the terminal. To run a script every time the machine starts, add run: "always".

config.vm.provision "shell", path: "bootstrap/start.sh", run: "always"

Example: a LAMP server

Linux, Apache, MariaDB and PHP. DEBIAN_FRONTEND=noninteractive stops apt from asking questions while installing.

#!/bin/bash
export DEBIAN_FRONTEND=noninteractive
apt-get update
apt-get install -y apache2 mariadb-server php libapache2-mod-php php-mysql
systemctl restart apache2

Split into several scripts

When the setup grows, put each part in its own script. The provisioners run in the order they are written.

config.vm.provision "shell", path: "bootstrap/apache.sh"
config.vm.provision "shell", path: "bootstrap/mariadb.sh"
config.vm.provision "shell", path: "bootstrap/php.sh"

Give a provisioner a name to run only that one later.

config.vm.provision "php", type: "shell", path: "bootstrap/php.sh"
$ vagrant provision --provision-with php

Copy files

The file provisioner copies a file from the host into the machine.

config.vm.provision "file", source: "~/.gitconfig", destination: ".gitconfig"

Help

--help and -h show all options for provision.

$ vagrant provision --help
$ vagrant provision -h
