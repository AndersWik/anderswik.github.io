Up

vagrant up starts the machine described in the Vagrantfile. Run it in the same folder as the Vagrantfile. The first time, Vagrant downloads the box, creates the machine and runs the provisioning. After that, it just starts the machine again.

Start the machine

$ vagrant up

Choose a provider

$ vagrant up --provider=libvirt

Provisioning

Run the provisioning again, or skip it.

$ vagrant up --provision
$ vagrant up --no-provision

Restart the machine

reload shuts the machine down and starts it again. Use it after changing the Vagrantfile.

$ vagrant reload

Help

--help and -h show all options for up.

$ vagrant up --help
$ vagrant up -h

More about up

  • With several machines, give a name to start only one: vagrant up web
  • Stop the machine again with halt
  • vagrant up in the documentation
