Boxes

A box is a ready made image of an operating system that Vagrant builds new machines from. Boxes are downloaded once and stored on your computer, so every new machine from the same box starts quickly.

Boxes are named owner/name, for example bento/ubuntu-24.04 or debian/bookworm64. You can search for boxes on HashiCorp's box catalog.

List boxes

$ vagrant box list
There are no installed boxes! Use `vagrant box add` to add some.

Add a box

You do not have to add a box before using it, vagrant up downloads it when needed. To download it in advance, use add.

$ vagrant box add bento/ubuntu-24.04

If the box works with several providers, Vagrant asks which one you use. You can also set it on the command line.

$ vagrant box add bento/ubuntu-24.04 --provider virtualbox

Update boxes

Box owners publish new versions. outdated checks if there is a newer version of the box. update downloads it.

$ vagrant box outdated
$ vagrant box outdated --global
$ vagrant box update

Existing machines keep using the old version. The new version is used the next time a machine is created.

Remove boxes

Boxes take up a lot of disk space. remove deletes a box, and prune removes all old versions that are no longer needed.

$ vagrant box remove bento/ubuntu-24.04
$ vagrant box prune

Help

--help and -h list all box subcommands. Add them after a subcommand to see its options.

$ vagrant box --help
$ vagrant box -h
$ vagrant box add -h

More about boxes

  • repackage turns an installed box back into a .box file
  • Build your own boxes with Packer, or from a running machine with vagrant package
