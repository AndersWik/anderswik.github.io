Status

vagrant status shows the state of the machines in the current folder.

$ vagrant status
Current machine states:

default                   running (virtualbox)

Machine states

  • running — the machine is on
  • saved — paused with vagrant suspend
  • poweroff — shut down with vagrant halt
  • not created — never started, or removed with vagrant destroy

Help

--help and -h show all options for status.

$ vagrant status --help
$ vagrant status -h

More about status

  • With several machines, give a name to see only one: vagrant status web
  • See machines in all folders with global-status
  • vagrant status in the documentation
