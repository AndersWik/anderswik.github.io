Providers

A provider is the virtualization software that actually runs the machines. Vagrant gives the same commands for all of them, so you can switch provider without learning a new tool.

Common providers

  • VirtualBox — free, works on Linux, Windows and macOS. Built into Vagrant and used by default
  • Hyper-V — included in Windows. Built into Vagrant
  • Docker — runs containers instead of virtual machines. Built into Vagrant
  • VMware — Workstation and Fusion. Needs a plugin
  • libvirt — KVM on Linux. Needs a plugin
  • Parallels — on macOS. Needs a plugin

Choose a provider

$ vagrant up --provider=hyperv

Or set the default in an environment variable, for example in ~/.bashrc.

export VAGRANT_DEFAULT_PROVIDER=libvirt

The box must be built for the provider. The box catalog shows which providers each box supports.

Provider settings

Each provider has its own settings, such as memory and number of CPUs. Settings for providers you do not use are ignored, so one Vagrantfile can have settings for several.

Vagrant.configure("2") do |config|
  config.vm.box = "bento/ubuntu-24.04"

  config.vm.provider "virtualbox" do |vb|
    vb.name = "dev"
    vb.memory = 2048
    vb.cpus = 2
    vb.gui = false
  end

  config.vm.provider "libvirt" do |lv|
    lv.memory = 2048
    lv.cpus = 2
  end
end
