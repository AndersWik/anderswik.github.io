Math functions

CSS can calculate values. This is useful when units are mixed, or a size should depend on the screen.

calc()

.sidebar-layout main {
  width: calc(100% - 300px);    /* the width of the parent, minus the sidebar */
}

.hero {
  height: calc(100vh - 4rem);   /* the window, minus the header */
}

The + and - need spaces around them: calc(100% - 2rem), not calc(100%-2rem).

min() and max()

min() uses the smallest of the values, and max() the largest:

.content {
  width: min(100%, 800px);      /* 800px, but never wider than the parent */
}

clamp()

clamp(min, preferred, max) keeps a value between a smallest and a largest value. Font sizes that grow with the window, but not too much:

h1 {
  font-size: clamp(1.75rem, 4vw + 1rem, 3rem);
}

Variables

The functions work with variables:

padding: calc(var(--space) * 2);
