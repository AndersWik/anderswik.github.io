Float

float moves an element to the left or right, and lets the text flow around it. Today it is only used for that, an image in a text. For layouts, use flexbox or grid.

.article img {
  float: left;
  width: 200px;
  margin: 0 16px 8px 0;
}
<div class="article">
  <img src="cat.jpg" alt="A cat">
  <p>A long text that flows around the image ...</p>
</div>

Clear

clear makes an element start below the floats before it:

.article h2 {
  clear: both;
}

Contain the floats

A float sticks out below its parent if the parent is shorter. display: flow-root on the parent makes it contain its floats:

.article {
  display: flow-root;
}

This replaces the old "clearfix" trick.
