Grid

Grid places elements in rows and columns. It is the tool for page layouts and galleries.

.cards {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;   /* three equal columns */
  gap: 16px;
}

fr is a part of the free space. 1fr 2fr gives the second column twice the width of the first.

repeat and minmax

grid-template-columns: repeat(4, 1fr);                        /* four equal columns */
grid-template-columns: 250px 1fr;                             /* a sidebar and the rest */
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));  /* as many as fit */

The last line is responsive without a media query: columns at least 200px wide, as many as fit on the screen, sharing the rest of the space.

Span several cells

.featured {
  grid-column: span 2;      /* two columns wide */
}

.header {
  grid-column: 1 / -1;      /* from the first line to the last: the full width */
}

Name the areas

.page {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-areas:
    "header header"
    "nav    main"
    "footer footer";
}

header { grid-area: header; }
nav    { grid-area: nav; }
main   { grid-area: main; }
footer { grid-area: footer; }

Grid or flexbox?

  • Flexbox for one direction: a row of buttons, a menu, items that wrap.
  • Grid for two directions: a page layout, a gallery, a form with labels and fields in columns.
