Display

display decides how an element is placed, and how its children are placed.

a.button { display: inline-block; }
.menu { display: flex; }
.gallery { display: grid; }
.hidden { display: none; }

The values

  • block, starts on a new line and is as wide as the parent. See Block and inline in the HTML notes.
  • inline, flows with the text. width, height and top and bottom margin do nothing.
  • inline-block, flows with the text, but has a width, height and padding like a block. Good for buttons and tags.
  • flex, places the children in a row or a column. See Flexbox.
  • grid, places the children in rows and columns. See Grid.
  • none, the element is removed, as if it was not in the HTML.

Hide an element

.a { display: none; }        /* gone, takes no space, not read by screen readers */
.b { visibility: hidden; }   /* invisible, but still takes its space */
.c { opacity: 0; }           /* invisible, takes space, can still be clicked */

The HTML attribute hidden does the same as display: none.
