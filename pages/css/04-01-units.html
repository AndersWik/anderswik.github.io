Units

Lengths in CSS need a unit: 16px, 1.5rem, 50%. Only 0 can be written without one.

Absolute

  • px, pixels. The most used fixed unit.
  • cm, mm, in and pt are for print, and seldom used on screens.

Relative to the font

  • rem, the font size of the page, the <html> element. Usually 16px, so 1.5rem is 24px.
  • em, the font size of the element itself, or of the parent when used for font-size.
  • ch, the width of the character "0". max-width: 65ch gives lines that are easy to read.

Relative to the screen or the parent

  • %, a part of the parent: width: 50% is half the width of the parent.
  • vw and vh, 1% of the width and height of the window.
  • dvh, 1% of the height of the window without the browser's bars on phones. 100dvh fills the screen exactly.

Which to use?

  • rem for font sizes and spacing. If the user sets a larger text size in the browser, the whole page grows with it.
  • % and fr for widths in a layout.
  • px for borders and small details that should not grow.
