Text

Properties for how text is shown. Most of them are inherited, so they can be set on a parent.

p {
  color: #333;
  line-height: 1.5;           /* 1.5 times the font size, no unit */
  text-align: left;           /* left, right, center, justify */
}

Decoration and case

a { text-decoration: none; }                   /* no underline */
a:hover { text-decoration: underline; }
.old-price { text-decoration: line-through; }
.wavy { text-decoration: underline wavy red; }

h2 { text-transform: uppercase; }              /* capitals, uppercase, lowercase */

Spacing

h1 { letter-spacing: 0.05em; }    /* between letters */
p { word-spacing: 0.1em; }        /* between words */
p { text-indent: 2em; }           /* the first line */

Long text

Cut a long line with ...:

.title {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

Break long words, like addresses, so they don't stick out:

.url { overflow-wrap: anywhere; }

Easy to read

  • line-height between 1.4 and 1.6 for body text.
  • max-width: 65ch keeps lines at about 65 characters.
  • Avoid text-align: justify on narrow screens, it makes holes between the words.
