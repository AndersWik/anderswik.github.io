Colors

Colors are used in color for text, background-color, border-color and many other properties.

color: tomato;                    /* a name */
color: #ff6347;                   /* hex: red, green, blue, 00 to ff */
color: #f63;                      /* short hex: #ff6633 */
color: rgb(255 99 71);            /* red, green, blue, 0 to 255 */
color: hsl(9 100% 64%);           /* hue 0-360, saturation, lightness */

Transparency

A fourth value is the alpha, from 0, invisible, to 1, solid:

background-color: rgb(0 0 0 / 0.5);
background-color: hsl(9 100% 64% / 50%);
background-color: #00000080;
color: transparent;

HSL is easy to change

In HSL, the same hue with another lightness gives a lighter or darker version of the color. This makes it easy to make a set of colors that fit together:

--green: hsl(145 55% 40%);
--green-light: hsl(145 55% 85%);
--green-dark: hsl(145 55% 25%);

currentColor

currentColor is the text color of the element. A border or an SVG icon with currentColor changes color with the text:

.tag {
  color: navy;
  border: 1px solid currentColor;
}

Contrast

Text must have enough contrast to its background to be easy to read. The developer tools show the contrast ratio when you click on a color. Aim for at least 4.5:1 for normal text.

Try colors and convert between the formats with Colorhex.
