Animations

An animation runs by itself, through steps you describe with @keyframes. A transition goes from one state to another, an animation can have many steps and repeat.

@keyframes pulse {
  from { transform: scale(1); }
  50%  { transform: scale(1.1); }
  to   { transform: scale(1); }
}

.heart {
  animation: pulse 1s ease-in-out infinite;
}

The parts

animation: spin 2s linear 0s infinite;   /* name, time, timing, delay, count */
  • animation-iteration-count, a number or infinite.
  • animation-direction: alternate, goes back and forth.
  • animation-fill-mode: forwards, keeps the last step when the animation ends.

A loading spinner

@keyframes spin {
  to { transform: rotate(360deg); }
}

.spinner {
  width: 32px;
  aspect-ratio: 1;
  border: 4px solid #ddd;
  border-top-color: #2e9e5b;
  border-radius: 50%;
  animation: spin 1s linear infinite;
}

Less motion

Some people get dizzy or sick from things that move. Respect the setting in their system:

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
