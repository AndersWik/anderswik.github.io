Position

position takes an element out of the normal flow, and places it with top, right, bottom and left.

Relative

The element is moved from where it would have been. The space it would have used stays empty:

.nudge { position: relative; top: 2px; }

position: relative is mostly used to make an element the reference for absolute children.

Absolute

The element is placed in the nearest parent that has a position, and takes no space:

.card { position: relative; }
.card .badge {
  position: absolute;
  top: 8px;
  right: 8px;
}

Fixed

Placed in the window, and stays there when the page is scrolled. For a button that is always shown:

.back-to-top {
  position: fixed;
  bottom: 16px;
  right: 16px;
}

Sticky

Scrolls with the page until it reaches its top value, then stays. For headers and table heads:

thead th {
  position: sticky;
  top: 0;
  background-color: white;
}

A sticky element stops at the end of its parent, and doesn't stick if a parent has overflow: hidden.

z-index

Positioned elements can cover each other. z-index decides which is on top, a higher number is closer:

.modal { position: fixed; z-index: 100; }

inset: 0 is short for top: 0; right: 0; bottom: 0; left: 0, and fills the parent.
