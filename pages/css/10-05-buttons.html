Buttons

.button {
  display: inline-block;
  padding: 10px 20px;
  font: inherit;
  font-weight: 600;
  color: white;
  background-color: #2e9e5b;
  border: none;
  border-radius: 6px;
  cursor: pointer;
}

.button:hover { background-color: #23824a; }
.button:active { transform: translateY(1px); }
.button:focus-visible { outline: 3px solid #23824a; outline-offset: 2px; }

.button:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}

Outline button

A second, less important button:

.button-outline {
  color: #2e9e5b;
  background-color: transparent;
  border: 2px solid currentColor;
}

A row of buttons

.buttons {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}

Good to know

  • Make buttons at least 44 × 44 pixels on touch screens, so they are easy to hit with a finger.
  • A smooth change on hover: transition: background-color 0.2s. See Transitions.
