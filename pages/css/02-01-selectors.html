Selectors

The selector chooses which elements a rule is for.

p { }              /* type: every <p> */
.note { }          /* class: every element with class="note" */
#menu { }          /* id: the element with id="menu" */
* { }              /* universal: every element */
h1, h2 { }         /* a list: every <h1> and every <h2> */

Combine them

Written together, without a space, the element must match all of them:

p.note { }         /* a <p> with the class note */
.note.important { }/* an element with both classes */

Which to use?

Use classes for almost everything. They can be used on any element, many times, and are easy to override. Use type selectors for general styles, like the font of all paragraphs. Avoid id selectors for styling: they are so strong that they are hard to override. See Cascade and specificity.

Test a selector

document.querySelectorAll() in the browser console uses the same selectors, and shows which elements match:

document.querySelectorAll(".note.important");
