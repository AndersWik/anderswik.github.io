Borders

A border is a line around the padding of an element.

.card {
  border: 1px solid #ccc;      /* width, style, color */
}

Style

solid, dashed, dotted and double are the most used. none removes the border. A border needs a style to be shown: border: 2px red; shows nothing.

One side

h2 {
  border-bottom: 2px solid tomato;
}

.quote {
  border-left: 4px solid #ccc;
  padding-left: 16px;
}

Rounded corners

border-radius rounds the corners, also without a border:

.card { border-radius: 8px; }
.pill { border-radius: 999px; }       /* round ends */
.avatar { border-radius: 50%; }       /* a circle, if the box is square */
