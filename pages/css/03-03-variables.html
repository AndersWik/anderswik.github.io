Variables

Variables, or custom properties, keep a value in one place and use it in many. Their names start with --:

:root {
  --brand: #2e9e5b;
  --space: 16px;
}

.button {
  background-color: var(--brand);
  padding: var(--space);
}

.card {
  border-top: 4px solid var(--brand);
  margin-bottom: var(--space);
}

:root is the <html> element, so variables set there work on the whole page.

Fallback

The second value in var() is used if the variable is not set:

color: var(--text-color, black);

Change in one place

Variables are inherited, so a variable can be changed for a part of the page. Here, a dark theme changes the colors of everything inside it:

:root { --bg: white; --text: #222; }
.dark { --bg: #222; --text: #eee; }

body, .dark {
  background-color: var(--bg);
  color: var(--text);
}

Variables and JavaScript

JavaScript can read and change variables while the page is shown:

document.documentElement.style.setProperty("--brand", "tomato");
getComputedStyle(document.documentElement).getPropertyValue("--brand");
