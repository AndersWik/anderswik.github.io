Width and height

.box {
  width: 300px;
  height: 200px;
}

Block elements are as wide as their parent by default, and as tall as their content. Usually it is best to let the height follow the content, and only set it when you must.

Min and max

max-width is the most useful of them. The element can be narrower on small screens, but never wider than the value:

.content {
  max-width: 800px;
  margin: 0 auto;     /* center it */
}

img {
  max-width: 100%;    /* never wider than the parent */
  height: auto;
}

.hero {
  min-height: 300px;  /* at least 300px, taller if the content needs it */
}

Aspect ratio

aspect-ratio keeps the shape when the width changes:

.video {
  width: 100%;
  aspect-ratio: 16 / 9;
}

Inline elements

width and height do nothing on inline elements like <span> and <a>. Make them display: inline-block or block first.
