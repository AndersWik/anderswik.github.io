Combinators

A combinator selects elements by where they are in relation to other elements.

nav a { }          /* descendant: an <a> anywhere inside a <nav> */
ul > li { }        /* child: an <li> directly inside a <ul> */
h2 + p { }         /* next sibling: the <p> directly after an <h2> */
h2 ~ p { }         /* later siblings: every <p> after an <h2>, same parent */

Descendant or child?

<ul class="menu">
  <li>Home
    <ul>
      <li>Sub page</li>
    </ul>
  </li>
</ul>

.menu li selects both <li>. .menu > li only selects Home, the one directly inside .menu.

Sibling example

The first paragraph after each heading, a bit larger:

h2 + p {
  font-size: 1.1rem;
}

The parent selector

:has() selects an element by what is inside it, which the combinators can't. See Pseudo-classes.
