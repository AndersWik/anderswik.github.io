Shadows

Box shadow

.card {
  box-shadow: 0 2px 8px rgb(0 0 0 / 0.15);
}

The values are: across, down, blur, and the color. A fourth length before the color, the spread, makes the shadow larger:

box-shadow: 0 4px 12px 2px rgb(0 0 0 / 0.2);   /* x y blur spread color */
box-shadow: inset 0 2px 4px rgb(0 0 0 / 0.2);  /* inside the box */
box-shadow: 0 1px 2px rgb(0 0 0 / 0.1), 0 8px 24px rgb(0 0 0 / 0.1);  /* two shadows */

Soft shadows with a light, transparent color look more natural than hard, black ones. The cards on this site use two shadows like the last example.

Text shadow

The same, but for text, and without spread:

h1 {
  text-shadow: 0 2px 4px rgb(0 0 0 / 0.5);
}

A text shadow makes white text on a photo easier to read.
