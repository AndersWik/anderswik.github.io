Box sizing

box-sizing decides what width and height measure.

.content-box {
  box-sizing: content-box;   /* the default: content only */
  width: 200px;
  padding: 16px;             /* the box is 232px wide */
}

.border-box {
  box-sizing: border-box;    /* content, padding and border */
  width: 200px;
  padding: 16px;             /* the box is 200px wide */
}

Use border-box everywhere

With border-box, the width you write is the width you get, and width: 50% with padding still fits two boxes on a row. Most sites set it on every element, at the start of the CSS:

*, *::before, *::after {
  box-sizing: border-box;
}
