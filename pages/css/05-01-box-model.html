Box model

Every element is a box, made of four layers from the inside out:

+--------------------------------+
|             margin             |
|  +--------------------------+  |
|  |          border          |  |
|  |  +--------------------+  |  |
|  |  |      padding       |  |  |
|  |  |  +--------------+  |  |  |
|  |  |  |   content    |  |  |  |
|  |  |  +--------------+  |  |  |
|  |  +--------------------+  |  |
|  +--------------------------+  |
+--------------------------------+
  • Content: the text or image.
  • Padding: space inside the border. It has the element's background.
  • Border: a line around the padding.
  • Margin: space outside the border, between this box and the next. It is always transparent.
.card {
  padding: 16px;
  border: 1px solid #ccc;
  margin: 24px;
}

See the box

Inspect an element in the developer tools. The Layout or Computed tab shows the box with the size of every layer.

How wide is the box?

By default, width is the width of the content only, and padding and border are added to it. A box with width: 200px, padding: 16px and a 1px border is 234px wide on the screen. Box sizing changes that.
