Tables

A table has no lines and little space by default. A simple style:

table {
  width: 100%;
  border-collapse: collapse;   /* one line between cells, not two */
}

th, td {
  padding: 8px 12px;
  border-bottom: 1px solid #ddd;
  text-align: left;
}

th {
  background-color: #f3f3f3;
}

Zebra stripes and hover

tbody tr:nth-child(even) {
  background-color: #fafafa;
}

tbody tr:hover {
  background-color: #eef6ff;
}

Numbers

Numbers are easier to compare when they are aligned to the right, and all digits are the same width:

td.number {
  text-align: right;
  font-variant-numeric: tabular-nums;
}

Wide tables on phones

Let the table scroll sideways inside a wrapper, instead of making the whole page wider. See Overflow.
