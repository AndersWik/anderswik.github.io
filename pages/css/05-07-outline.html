Outline

An outline is a line outside the border. It looks like a border, but takes no space, so it doesn't move anything when it is shown.

.selected {
  outline: 2px solid tomato;
  outline-offset: 4px;     /* space between the element and the outline */
}

Focus

Browsers show an outline around the element that has keyboard focus. Keyboard users need it to see where they are. Never remove it without showing something else:

/* Wrong: keyboard users can't see where they are */
:focus { outline: none; }

/* Right: a clear focus ring, only for keyboard focus */
:focus-visible {
  outline: 3px solid #2e9e5b;
  outline-offset: 2px;
}

:focus-visible shows it for the keyboard, but not when you click with the mouse.
