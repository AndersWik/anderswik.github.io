Links

A link has states, which can be styled with pseudo-classes:

a {
  color: #0b57d0;
  text-decoration-thickness: 1px;
  text-underline-offset: 3px;
}

a:visited { color: #6f42c1; }
a:hover { text-decoration-thickness: 2px; }
a:focus-visible { outline: 2px solid currentColor; outline-offset: 2px; }
a:active { color: tomato; }

:hover must come after :visited, or the visited color wins on hover.

Keep links easy to find

Links in a text should look like links. If you remove the underline, they need another clear difference than only the color, since some people can't see the difference between the colors.

A link that looks like a button

a.button {
  display: inline-block;
  padding: 8px 16px;
  background-color: #2e9e5b;
  color: white;
  text-decoration: none;
  border-radius: 6px;
}

Use this for links that go somewhere, like "Read more". Things that do something on the page should be real <button> elements. See Buttons in the HTML notes.
