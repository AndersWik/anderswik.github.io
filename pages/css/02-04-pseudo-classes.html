Pseudo-classes

A pseudo-class selects elements in a certain state, or at a certain place. It starts with a colon.

States

a:hover { }            /* the mouse is over it */
a:focus-visible { }    /* it has focus from the keyboard */
button:active { }      /* it is being pressed */
input:disabled { }     /* it is disabled */
input:checked { }      /* a checked checkbox or radio button */
input:invalid { }      /* the value is not valid */
a:visited { }          /* a link you have visited */

Place

li:first-child { }     /* the first item */
li:last-child { }      /* the last item */
tr:nth-child(even) { } /* every second row: 2, 4, 6 ... */
li:nth-child(3n+1) { } /* 1, 4, 7 ... */
p:only-child { }       /* the only element in its parent */

Logic

li:not(:last-child) { }        /* all but the last */
:is(h1, h2, h3) a { }          /* a link in any of the headings */
.card:has(img) { }             /* a card that has an image inside */
label:has(+ input:invalid) { } /* a label before an invalid input */

:has() is the "parent selector": it selects an element by what is inside it or after it.
