Padding

Padding is the space inside an element, between its content and its border. The background of the element fills the padding.

.button {
  padding: 8px 16px;
  background-color: navy;
  color: white;
}

Shorthand

The same as for margin, clockwise from the top:

padding: 16px;               /* all four sides */
padding: 8px 16px;           /* top and bottom, left and right */
padding: 8px 16px 12px 16px; /* top, right, bottom, left */
padding-left: 24px;          /* one side */

Padding or margin?

  • Padding for space inside a box, where the background should be. The space between the text and the edge of a button.
  • Margin for space between boxes. The space between two cards.

Padding can't be negative, and doesn't collapse.
