Gradients

A gradient is a smooth change between colors. It is used as a background-image.

Linear

.a { background-image: linear-gradient(white, lightblue); }            /* top to bottom */
.b { background-image: linear-gradient(to right, tomato, gold); }      /* left to right */
.c { background-image: linear-gradient(45deg, navy, purple, tomato); } /* an angle */

Color stops

A position after each color decides where it is. Two colors at the same position give a sharp edge, as in stripes:

.progress {
  background-image: linear-gradient(to right, #2e9e5b 60%, #eee 60%);
}

.stripes {
  background-image: repeating-linear-gradient(45deg, #eee 0 10px, white 10px 20px);
}

Radial

From the center and out, as a circle or an ellipse:

.glow { background-image: radial-gradient(circle, gold, transparent 70%); }

Conic

Around the center, like a pie chart:

.pie {
  width: 120px;
  aspect-ratio: 1;
  border-radius: 50%;
  background-image: conic-gradient(tomato 0 40%, gold 40% 70%, #2e9e5b 70%);
}
