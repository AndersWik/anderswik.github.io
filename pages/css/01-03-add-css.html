Add CSS to a page

There are three ways to add CSS to a page.

A separate file

The best way for almost everything. Link the file in the <head>:

<link rel="stylesheet" href="/css/style.css">

The same file is used by every page, and the browser keeps it in its cache, so the next page loads faster.

A style element

For CSS that only one page needs. It goes in the <head>:

<style>
  .banner { background-color: gold; }
</style>

A style attribute

For one element. Use it for quick tests only, since it is hard to find later and wins over almost everything:

<p style="color: red;">Warning</p>

Several files

A page can link several style sheets. Rules in a later file win over rules in an earlier file, if they are equally specific. So link general styles first, and the page's own styles last:

<link rel="stylesheet" href="/css/base.css">
<link rel="stylesheet" href="/css/contact-page.css">
