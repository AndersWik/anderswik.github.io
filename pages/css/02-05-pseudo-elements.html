Pseudo-elements

A pseudo-element styles a part of an element, or adds content that is not in the HTML. It starts with two colons.

Before and after

::before and ::after add content at the start and end of an element. content is required, even if it is empty:

.required::after {
  content: " *";
  color: red;
}

blockquote::before {
  content: "“";
  font-size: 3rem;
}

Content added this way can't be selected or copied, and is not always read by screen readers. Use it for decoration, not for important text.

Parts of an element

p::first-line { font-weight: bold; }
p::first-letter { font-size: 2em; float: left; }
li::marker { color: tomato; }
input::placeholder { color: #999; }
::selection { background-color: gold; }
