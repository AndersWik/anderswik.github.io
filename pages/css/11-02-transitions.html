Transitions

A transition makes a change happen smoothly over time, instead of at once. It is used for hover effects and things that open and close.

.card {
  transition: transform 0.2s ease, box-shadow 0.2s ease;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 32px rgb(0 0 0 / 0.1);
}

The transition is set on the element itself, not on :hover, so it is smooth both when the mouse comes and when it leaves.

The parts

transition: background-color 0.3s ease-in-out 0.1s;   /* property, time, timing, delay */
  • Property: what to animate. all works, but is slower and can animate things you didn't mean to.
  • Duration: 0.2s to 0.3s feels quick but smooth for small changes.
  • Timing function: ease (the default), linear, ease-in, ease-out or ease-in-out.
  • Delay: wait before it starts.

Not everything can be animated

Colors, sizes, positions, opacity and transforms can be animated. display and height: auto can't in most browsers, so open and close with max-height, opacity or transform instead.
