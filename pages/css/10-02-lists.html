Lists

ul {
  list-style-type: square;    /* disc, circle, square, none */
  padding-left: 1.5rem;
}

ol {
  list-style-type: lower-alpha;   /* decimal, lower-alpha, upper-roman ... */
}

li::marker {
  color: tomato;              /* only the dot or the number */
}

A list without dots

A menu is often a list of links, without dots and in a row:

.menu {
  list-style: none;
  margin: 0;
  padding: 0;
  display: flex;
  gap: 16px;
}

Your own markers

.checklist {
  list-style: none;
  padding-left: 0;
}

.checklist li::before {
  content: "✓ ";
  color: #2e9e5b;
}

Counters

CSS can count elements, for example to number headings:

article { counter-reset: section; }
h2::before {
  counter-increment: section;
  content: counter(section) ". ";
}
