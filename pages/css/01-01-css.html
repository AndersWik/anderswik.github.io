CSS

CSS (Cascading Style Sheets) decides how a web page looks: colors, fonts, sizes, spacing and where things are placed. The HTML says what the content is, and the CSS says how it is shown.

h1 {
  color: navy;
  font-size: 2rem;
}

This makes every <h1> on the page dark blue and twice the normal text size.

Why separate files?

The same CSS file can style every page of a site. Change the color of the headings in one place, and it changes everywhere. The HTML stays clean, and the same HTML can look different on a phone, on a big screen and on paper.

Cascading

"Cascading" means that many rules can apply to the same element, and CSS has clear rules for which one wins. See Cascade and specificity.

Try CSS

Right-click on a page and choose Inspect. The developer tools show the CSS of the element you clicked, and you can change the values and see the result directly.
