Opacity and filters

Opacity

opacity makes the whole element see-through, from 0, invisible, to 1, solid:

.disabled {
  opacity: 0.5;
}

Opacity is for the element and everything inside it. To make only the background see-through, use a color with alpha instead: background-color: rgb(0 0 0 / 0.5).

Filters

filter changes how an element looks, like in a photo program:

img.grey { filter: grayscale(100%); }
img.soft { filter: blur(4px); }
img.dark { filter: brightness(60%); }
img.mix  { filter: contrast(120%) saturate(150%); }

A grey image that gets its colors back on hover:

.logo { filter: grayscale(100%); transition: filter 0.3s; }
.logo:hover { filter: none; }

Backdrop filter

backdrop-filter changes what is behind the element. A menu that blurs the page below it, like frosted glass:

.menu {
  background-color: rgb(255 255 255 / 0.6);
  backdrop-filter: blur(10px);
}
