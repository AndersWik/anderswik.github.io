Attribute selectors

An attribute selector selects elements by their attributes and values, written in square brackets.

[disabled] { }               /* has the attribute */
[type="email"] { }           /* the value is exactly "email" */
a[href^="https"] { }         /* the value starts with "https" */
a[href$=".pdf"] { }          /* ends with ".pdf" */
a[href*="example"] { }       /* contains "example" */
[lang|="en"] { }             /* is "en" or starts with "en-" */

Examples

Mark links to PDF files, and links to other sites:

a[href$=".pdf"]::after {
  content: " (PDF)";
}

a[href^="http"]:not([href*="anderswik.se"])::after {
  content: " ↗";
}

Style the text fields of a form, but not the checkboxes:

input[type="text"],
input[type="email"] {
  border: 1px solid #ccc;
  padding: 6px;
}

Ignore case

Add i before the closing bracket: a[href$=".pdf" i] also matches .PDF.
