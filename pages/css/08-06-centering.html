Centering

The common ways to center things.

Text and inline elements

.title { text-align: center; }

A block with a width

.page {
  max-width: 800px;
  margin: 0 auto;
}

Both ways, with grid

The shortest way to center anything in a box, across and down:

.box {
  display: grid;
  place-items: center;
  min-height: 300px;
}

Both ways, with flexbox

.box {
  display: flex;
  justify-content: center;   /* across */
  align-items: center;       /* down */
  min-height: 300px;
}

Something positioned

.modal {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}

top and left move the corner to the middle, and translate(-50%, -50%) moves the element back by half its own size.
