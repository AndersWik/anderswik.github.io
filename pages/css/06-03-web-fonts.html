Web fonts

A web font is a font file that the browser downloads with the page, so every visitor sees the same font.

Your own font files

Put the files on your site, and describe them with @font-face. Use the woff2 format, it is the smallest:

@font-face {
  font-family: "Ubuntu";
  src: url("/fonts/ubuntu-regular.woff2") format("woff2");
  font-weight: 400;
  font-display: swap;
}

@font-face {
  font-family: "Ubuntu";
  src: url("/fonts/ubuntu-bold.woff2") format("woff2");
  font-weight: 700;
  font-display: swap;
}

body {
  font-family: "Ubuntu", sans-serif;
}

One @font-face per weight and style. With the same font-family name, the browser picks the right file for font-weight: 700.

font-display

font-display: swap shows the text in a fallback font at once, and changes it when the web font has loaded. Without it, the text can be invisible for a while.

Google Fonts

Google Fonts has many free fonts. Choose a font, and copy the <link> they give you to your <head>. Hosting the files yourself is faster, and sends no data about your visitors to Google.

Keep it fast

Every font file is a download. Use few fonts and few weights, two fonts and three weights is plenty.
