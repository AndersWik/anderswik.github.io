Transforms

transform moves, turns, scales or skews an element, without changing the layout around it.

.a { transform: translate(20px, 10px); }   /* move right and down */
.b { transform: rotate(45deg); }           /* turn */
.c { transform: scale(1.2); }              /* 20% larger */
.d { transform: skewX(-10deg); }           /* lean */
.e { transform: translate(-50%, -50%) rotate(10deg); }   /* several, from the right */

A % in translate is a part of the element's own size.

The origin

Transforms happen around the center of the element. transform-origin changes that point:

.door {
  transform-origin: left center;
  transform: rotateY(60deg);
}

3D

.scene {
  perspective: 800px;          /* how far away the viewer is */
}

.card {
  transition: transform 0.6s;
  transform-style: preserve-3d;
}

.scene:hover .card {
  transform: rotateY(180deg);  /* turn the card around */
}

Add backface-visibility: hidden to the front and back sides, and you have a card that flips.

Fast animations

Transforms don't move other elements, so the browser can animate them smoothly. Animate transform and opacity rather than top, left, width or margin.
