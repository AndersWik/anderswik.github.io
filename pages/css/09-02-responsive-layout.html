Responsive layout

A responsive page works on every screen size, from a phone to a large monitor.

Flexible by default

Many layouts need few or no media queries, if the sizes are flexible:

img {
  max-width: 100%;
  height: auto;
}

.content {
  width: min(100% - 2rem, 900px);   /* 1rem space on each side on phones */
  margin-inline: auto;
}

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 1rem;
}

Fluid sizes

clamp() gives sizes that grow with the screen, between a smallest and a largest value:

h1 { font-size: clamp(1.75rem, 3vw + 1rem, 3rem); }
section { padding-block: clamp(2rem, 6vw, 5rem); }

Container queries

A media query asks about the window. A container query asks about the size of the parent, so a component can change its layout wherever it is placed:

.card-list {
  container-type: inline-size;
}

@container (min-width: 500px) {
  .card {
    display: flex;
    gap: 16px;
  }
}

The same card is a column in a narrow sidebar, and a row in the wide main content.

Test it

The developer tools have a device mode (Ctrl + Shift + M in Firefox and Chrome) that shows the page as on a phone or a tablet.
