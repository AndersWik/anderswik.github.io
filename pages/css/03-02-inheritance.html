Inheritance

Some properties are passed on from an element to everything inside it. Set the font once on <body>, and all the text on the page gets it:

body {
  font-family: system-ui, sans-serif;
  color: #222;
  line-height: 1.5;
}

What is inherited?

  • Inherited: properties for text, like color, font-family, font-size, line-height, text-align and visibility.
  • Not inherited: properties for the box, like margin, padding, border, background, width and display. It would be strange if every element inside a box got the same border.

Control it

Every property accepts these values:

button {
  font: inherit;      /* use the value of the parent */
  color: initial;     /* the default value of the property */
  margin: unset;      /* inherit if it is inherited, else initial */
  padding: revert;    /* the browser's own style */
}

font: inherit is useful on buttons and inputs, since browsers give them their own font instead of the page's.
