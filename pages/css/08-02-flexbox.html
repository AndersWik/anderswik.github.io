Flexbox

Flexbox places elements in a row or a column, and shares the space between them. It is the tool for menus, toolbars, cards in a row and centering.

.menu {
  display: flex;
  gap: 16px;                    /* space between the items */
  justify-content: space-between;
  align-items: center;
}
<nav class="menu">
  <a href="/">Logo</a>
  <a href="/about/">About</a>
  <a href="/contact/">Contact</a>
</nav>

display: flex goes on the container. Its children become flex items.

Direction

  • flex-direction: row, the default, places the items across.
  • flex-direction: column places them below each other.

Along the direction: justify-content

flex-start, center, flex-end, space-between (space only between the items) and space-around.

Across the direction: align-items

stretch (the default, as tall as the tallest), center, flex-start, flex-end and baseline.

Wrap

By default, all items stay on one line. flex-wrap: wrap lets them continue on a new line:

.tags {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}

The size of the items

.search input { flex: 1; }       /* take all the free space */
.sidebar { flex: 0 0 250px; }    /* always 250px: don't grow, don't shrink */

flex: 1 on several items shares the space equally between them.
