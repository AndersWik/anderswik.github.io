Margin

Margin is the space outside an element, between it and the elements around it.

p {
  margin-top: 0;
  margin-bottom: 1rem;
}

Shorthand

margin sets all four sides at once, clockwise from the top:

margin: 16px;                /* all four sides */
margin: 16px 24px;           /* top and bottom, left and right */
margin: 16px 24px 8px;       /* top, left and right, bottom */
margin: 16px 24px 8px 0;     /* top, right, bottom, left */

Center a block

auto on both sides takes all the free space and centers a block that has a width:

.page {
  max-width: 900px;
  margin: 0 auto;
}

Margin collapse

When two vertical margins meet, they are not added. The larger one is used:

h2 { margin-bottom: 24px; }
p  { margin-top: 16px; }     /* the space between them is 24px, not 40px */

This only happens to top and bottom margins of block elements, not in flexbox or grid. Many people only set margin-bottom on text elements, which avoids the problem.

Negative margin

A negative margin pulls the element, or the next one, closer. It is allowed, but makes the layout harder to understand.
