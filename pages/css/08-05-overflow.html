Overflow

Overflow is content that doesn't fit in its box. overflow decides what happens to it:

.a { overflow: visible; }  /* the default: it sticks out of the box */
.b { overflow: hidden; }   /* it is cut off */
.c { overflow: scroll; }   /* scroll bars, always */
.d { overflow: auto; }     /* scroll bars, only when needed */

Scroll in one direction

A wide table that can be scrolled sideways on a phone, without the whole page getting wider:

.table-wrap {
  overflow-x: auto;
}
<div class="table-wrap">
  <table>...</table>
</div>

A box with a fixed height that scrolls:

.chat {
  height: 300px;
  overflow-y: auto;
}

Good to know

  • overflow: hidden on a parent stops position: sticky inside it.
  • A page that scrolls sideways on a phone often has one element that is too wide. Look for it with the developer tools instead of hiding it with overflow-x: hidden on body.
