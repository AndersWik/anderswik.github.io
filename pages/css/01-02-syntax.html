Syntax

A CSS rule has a selector, which says which elements it is for, and a block of declarations, which say how they look:

selector {
  property: value;
  property: value;
}
p {
  color: #333;
  line-height: 1.5;
}
  • p is the selector: all paragraphs.
  • color: #333; is a declaration: the property color gets the value #333.
  • Each declaration ends with a semicolon.

Several selectors

A comma gives several selectors the same declarations:

h1, h2, h3 {
  font-family: Georgia, serif;
}

Comments

Comments start with /* and end with */. They can be one line or many:

/* The main heading */
h1 {
  color: navy; /* dark blue */
}

There is no // comment in CSS. A line that starts with // breaks the next rule.

Errors

If the browser doesn't understand a declaration, it skips it and goes on with the next. A misspelled property doesn't break the page, but it does nothing. The developer tools show such lines crossed out.
