Images

Images that never get wider than their parent, and keep their shape:

img {
  max-width: 100%;
  height: auto;
  display: block;   /* removes the small gap below inline images */
}

Fill a box

object-fit decides how an image fills a box with another shape, like background-size for backgrounds:

.thumbnail {
  width: 240px;
  aspect-ratio: 4 / 3;
  object-fit: cover;          /* fill the box, crop the edges */
  object-position: top;       /* keep the top when cropping */
}
  • cover fills the box, and crops what doesn't fit.
  • contain shows the whole image, with empty space if needed.

The thumbnails on this site's index pages use object-fit: cover.

Round images

.avatar {
  width: 64px;
  aspect-ratio: 1;
  border-radius: 50%;
  object-fit: cover;
}

Effects

Grey images, blur and other effects are made with filters.
