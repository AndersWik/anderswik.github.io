Fonts

body {
  font-family: Georgia, "Times New Roman", serif;
  font-size: 1rem;
  font-weight: 400;        /* 400 normal, 700 bold, 100 to 900 */
  font-style: normal;      /* normal or italic */
}

Fallbacks

font-family is a list. The browser uses the first font it has. End the list with a generic family, so there is always something:

  • serif, letters with small feet, like Times.
  • sans-serif, letters without, like Arial.
  • monospace, all letters the same width, for code.
  • system-ui, the font of the operating system.

Names with spaces go in quotes: "Times New Roman".

The system font

The font of the operating system loads instantly, and looks at home on every device:

body {
  font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
}

Font size

Use rem for font sizes, so the page follows the text size the user has chosen in the browser. See Units.

Shorthand

font sets everything in one line. The size and family are required, and must come last:

font: italic 700 1.25rem/1.4 Georgia, serif;   /* style weight size/line-height family */
