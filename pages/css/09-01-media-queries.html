Media queries

A media query applies CSS only when something is true, for example when the screen is at least a certain width.

.cards {
  display: grid;
  gap: 16px;
}

@media (min-width: 600px) {
  .cards { grid-template-columns: 1fr 1fr; }
}

@media (min-width: 1000px) {
  .cards { grid-template-columns: 1fr 1fr 1fr; }
}

One column on phones, two on tablets, three on large screens.

Mobile first

Write the CSS for small screens first, and add to it with min-width queries for larger screens. The simple layout is the default, and the larger screens get more.

Other things to ask about

@media (prefers-color-scheme: dark) {
  body { background-color: #222; color: #eee; }
}

@media (prefers-reduced-motion: reduce) {
  * { animation: none; transition: none; }
}

@media (hover: hover) {
  .card:hover { transform: translateY(-4px); }   /* only on devices with a mouse */
}

@media print {
  nav, footer { display: none; }
}

In the HTML

Media queries need the viewport tag in the HTML. Without it, phones pretend to be about 980px wide.
