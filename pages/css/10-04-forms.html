Forms

Form fields get their own font and size from the browser. A clean start:

input, select, textarea, button {
  font: inherit;               /* the same font as the page */
}

input, select, textarea {
  width: 100%;
  padding: 8px 10px;
  border: 1px solid #bbb;
  border-radius: 6px;
}

input:focus-visible, select:focus-visible, textarea:focus-visible {
  outline: 2px solid #2e9e5b;
  outline-offset: 1px;
  border-color: #2e9e5b;
}

textarea {
  resize: vertical;            /* only taller, not wider */
}

Labels above the fields

label {
  display: block;
  margin: 16px 0 4px;
  font-weight: 600;
}

Checkboxes and radio buttons

accent-color changes the color of checkboxes, radio buttons and range sliders, without rebuilding them:

input[type="checkbox"], input[type="radio"] {
  width: auto;
  accent-color: #2e9e5b;
}

Show errors

:user-invalid matches a field with a wrong value, but only after the user has changed it, not as soon as the page loads:

input:user-invalid {
  border-color: #dc3545;
}
