Backgrounds

.box {
  background-color: #f3f3f3;
}

.hero {
  background-image: url("/images/mountains.jpg");
  background-size: cover;          /* fill the box, crop if needed */
  background-position: center;
  background-repeat: no-repeat;
}

Size

  • cover fills the whole box. Parts of the image may be cut off.
  • contain shows the whole image. Parts of the box may be empty.
  • 100px auto or 50% sets the size directly.

Repeat

By default, a background image is repeated to fill the box. no-repeat shows it once, and repeat-x only repeats it across. A small image that repeats can be a pattern.

Shorthand

background: #222 url("/images/stars.png") center / cover no-repeat;

Several backgrounds

A comma gives several layers. The first is on top. Here, a dark gradient over a photo, to make white text on it easy to read:

.hero {
  background:
    linear-gradient(rgb(0 0 0 / 0.5), rgb(0 0 0 / 0.5)),
    url("/images/mountains.jpg") center / cover;
  color: white;
}

Background or image?

Use background-image for decoration. Images that are part of the content belong in the HTML as <img>, with an alt text.
