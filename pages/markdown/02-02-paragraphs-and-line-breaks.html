Paragraphs and line breaks

Text on lines next to each other becomes one paragraph. A single newline is treated like a space. To start a new paragraph, leave an empty line.

Paragraphs

This is the first paragraph.
This line is part of the same paragraph.

This is the second paragraph.

Line break with two spaces

End a line with two or more spaces to break the line without starting a new paragraph. The spaces are hard to see, so many prefer the other ways below.

Roses are red,␣␣
Violets are blue.

The ␣ marks a space here.

Line break with a backslash

CommonMark and GitHub also accept a \ at the end of the line.

Roses are red,\
Violets are blue.

Line break with HTML

<br> works in every flavor that allows inline HTML.

Roses are red,<br>
Violets are blue.

More about line breaks

  • Do not indent paragraphs. Four spaces at the start of a line turns it into a code block
  • Many editors remove spaces at the end of lines when saving, which removes two space line breaks
  • Some apps, like GitHub comments and many chat apps, keep every newline as a line break
