Markdown

Markdown is a simple way to format plain text. You write normal text with a few symbols, like # for headers and * for emphasis, and a program turns it into HTML. The text is still easy to read even before it is converted.

Markdown is used for README files, documentation, wikis, notes, chat apps and static sites like Jekyll.

Quick example

# My project

This is **bold** and this is *italic*.

* First item
* Second item

[Read more](https://example.com)

File extensions

Markdown files usually end in .md. .markdown also works.

README.md
notes.markdown

Flavors

The original Markdown left many details open, so there are a few versions. Most of the basic syntax works everywhere. The extras, like tables and task lists, depend on the flavor.

  • CommonMark — a strict, well defined standard
  • GitHub Flavored Markdown (GFM) — CommonMark plus tables, task lists, strikethrough and autolinks
  • kramdown — the default in Jekyll, with footnotes, definition lists and attributes
  • Pandoc Markdown — many extras, used to convert to almost any format

Preview

Most editors can show a preview. In VS Code and VSCodium press Ctrl+Shift+V, or Ctrl+K V to open it to the side.

Convert

pandoc converts Markdown to HTML, PDF, Word and more.

$ sudo apt install pandoc
$ pandoc README.md -o README.html
$ pandoc README.md -o README.docx
$ pandoc README.md -o README.pdf

What you will learn

  • Headers, paragraphs and line breaks and emphasis
  • Blockquotes, horizontal rules and escaping characters
  • Lists, task lists and tables
  • Links, images and YouTube videos
  • Code and syntax highlighting
  • Footnotes, definition lists, inline HTML, comments and GitHub extras
