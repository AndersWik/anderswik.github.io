Tables

Tables are made with pipes | between the columns and a row of dashes - under the header. Tables are not in the original Markdown, but GitHub, kramdown, Pandoc and most editors support them.

Table

| Command | Description       |
| ------- | ----------------- |
| ls      | List files        |
| cd      | Change directory  |
| pwd     | Print directory   |

Short form

The columns do not have to line up, and the outer pipes can be left out. Three dashes per column is enough.

Command | Description
--- | ---
ls | List files
cd | Change directory

Align columns

A colon : in the dash row sets the alignment.

| Left | Center | Right |
| :--- | :----: | ----: |
| a    |   b    |     1 |
| aa   |   bb   |    22 |

Formatting in cells

Emphasis, code and links work inside cells. Use \| for a pipe and <br> for a line break.

| Syntax      | Example                       |
| ----------- | ----------------------------- |
| Bold        | **bold**                      |
| Code        | `grep -E "a\|b"`              |
| Link        | [Example](https://example.com)|
| Two lines   | First line<br>Second line    |

More about tables

  • Leave an empty line before the table
  • Lists, headers and code blocks cannot go inside a cell. Use an HTML table for that
  • Cells cannot span several rows or columns in standard Markdown
  • Tables Generator makes a Markdown table from a spreadsheet
