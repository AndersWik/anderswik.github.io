Escaping characters

Put a \ in front of a character to show it as it is, instead of using it as Markdown.

Backslash

\*not italic\*
\# not a header
1986\. A great year
\[not a link\](https://example.com)

Characters you can escape

\   backslash
`   backtick
*   asterisk
_   underscore
{ } curly braces
[ ] square brackets
( ) parentheses
#   hash
+   plus
-   minus
.   dot
!   exclamation mark
|   pipe
< > angle brackets

HTML entities

HTML entities also work, for characters that are hard to type or that would be read as HTML.

&copy;    ©
&nbsp;    non-breaking space
&lt;      <
&gt;      >
&amp;     &

Code

Nothing is formatted inside code, so backticks are another way to show symbols.

Use `*` for a list.

More about escaping

  • 1986. at the start of a line becomes a numbered list, write 1986\.
  • A | inside a table cell must be written \|
