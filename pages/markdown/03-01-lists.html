Lists

Markdown has unordered lists with bullets and ordered lists with numbers. Lists can be nested and can hold paragraphs, code and other lists.

Unordered list

Start each line with *, - or + and a space.

* Apples
* Pears
* Plums

- Apples
- Pears

+ Apples
+ Pears

Ordered list

Start each line with a number and a dot. The first number sets where the list starts. The rest do not matter, so you can write 1. on every line.

1. First
2. Second
3. Third

1. First
1. Second
1. Third

5. Starts at five
6. Six

Nested lists

Indent the inner list so it lines up with the text of the item above, two spaces after * and three after 1.. Four spaces works in most flavors.

* Fruit
  * Apples
  * Pears
* Vegetables
  * Carrots

1. Install
   1. Download
   2. Run the installer
2. Configure
   * Set the language
   * Set the time zone

Paragraphs and code in a list

Indent the content the same as the item text. Leave an empty line before it.

1. Update the package list.

   This can take a minute.

2. Install the package.

   ```bash
   sudo apt install pandoc
   ```

Two lists after each other

Changing the symbol, or putting a comment between them, starts a new list.

* First list
* First list

- Second list
- Second list

More about lists

  • Leave an empty line before and after the list
  • Leaving empty lines between items makes a loose list, with more space between items
  • A line that starts with a number and a dot becomes a list, escape the dot to stop it: 2024\.
  • Lists with checkboxes are task lists
