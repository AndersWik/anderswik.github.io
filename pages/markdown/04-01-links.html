Links

Put the link text in square brackets and the address in parentheses right after it.

Inline link

[Example](https://example.com)

Link with a title

The title is shown when you hover over the link.

[Example](https://example.com "Go to example.com")

Automatic links

Angle brackets turn an address or email into a link. GitHub also links plain addresses that start with www. or https://.

<https://example.com>
<someone@example.com>
https://example.com

Reference links

Reference links keep long addresses out of the text. The definitions can be anywhere in the file and are not shown. The reference is not case sensitive.

Read the [manual][docs] or ask on the [forum][].
Search with [DuckDuckGo][1].

[docs]: https://example.com/docs
[forum]: https://example.com/forum "The forum"
[1]: https://duckduckgo.com

Link to a header

Each header gets an id from its text in lower case, with spaces turned into -.

[Go to Install](#install)
[See the setup guide](setup.md#first-steps)

Relative links

Link to other files in the same project with a path instead of a full address.

[Contributing](CONTRIBUTING.md)
[Docs](docs/index.md)
[Up one folder](../README.md)

Email and phone

[Send an email](mailto:someone@example.com)
[Call us](tel:+46123456789)

More about links

  • Use %20 instead of spaces in addresses, or put the address in angle brackets: [File](<my file.md>)
  • Standard Markdown cannot open links in a new tab. Use HTML, or {:target="_blank"} after the link in kramdown
  • An image inside a link makes a clickable image, see images
