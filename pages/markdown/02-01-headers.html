Headers

Start a line with # to make a header. The number of # sets the level, from <h1> to <h6>. Put a space after the #.

Header levels

# Header 1
## Header 2
### Header 3
#### Header 4
##### Header 5
###### Header 6

Underlined headers

Level 1 and 2 can also be written by underlining the text with = or -.

Header 1
========

Header 2
--------

Closing hashes

You can end the line with # too. They are ignored.

## Header 2 ##

Custom id

Most converters give each header an id made from the text, so ## Get started can be linked with #get-started. Some flavors, like kramdown and Pandoc, let you set the id yourself.

## Get started {#start}

[Jump to Get started](#start)

More about headers

  • Use only one # header per page, as the title
  • Do not skip levels, go from ## to ###
  • Leave an empty line before and after a header
  • Link to a header from another place with links
