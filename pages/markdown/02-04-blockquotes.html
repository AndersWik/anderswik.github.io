Blockquotes

Start a line with > to quote it. Blockquotes are used for quotes, replies in emails and notes that should stand out.

Quote

> Talk is cheap. Show me the code.

Several paragraphs

Put a > on the empty line between the paragraphs too.

> The first paragraph.
>
> The second paragraph.

Lazy quotes

Only the first line of a paragraph needs the >.

> This is a long quote that
continues on the next line.

Nested quotes

> Did you read the manual?
>
> > No, what manual?

Other markup inside

Headers, lists, emphasis and code all work inside a blockquote.

> ### Note
>
> * Back up your files **before** you upgrade.
> * Run `sudo apt update` first.
>
> — The admin

More about blockquotes

  • Leave an empty line before and after the blockquote
  • GitHub turns some blockquotes into colored boxes, see GitHub extras
