Footnotes

A footnote adds a small number in the text that links to a note at the bottom of the page. Footnotes are supported by GitHub, kramdown, Pandoc and most editors, but not by the original Markdown.

Footnote

Write [^name] in the text and the note on its own line with [^name]:. The notes are numbered in the order they are used, whatever the name is.

Linux was first released in 1991.[^1]
Vagrant is made by HashiCorp.[^vagrant]

[^1]: Version 0.01, in September.
[^vagrant]: See vagrantup.com.

Longer footnotes

Indent the following lines to add more paragraphs or code to the note.

Here is a long note.[^long]

[^long]: The first paragraph.

    The second paragraph.

    `some code`

Inline footnotes

Pandoc can write the note directly in the text.

Linux was first released in 1991.^[Version 0.01, in September.]

More about footnotes

  • The names cannot contain spaces
  • The notes are always placed at the end, wherever you write them in the file
