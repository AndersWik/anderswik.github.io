YouTube videos

Markdown cannot play videos. The usual trick is to show the video thumbnail as an image that links to the video. Replace VIDEO_ID with the id from the address, the part after watch?v=.

Thumbnail that links to the video

This works everywhere, including GitHub.

[![Video title](https://img.youtube.com/vi/VIDEO_ID/0.jpg)](https://www.youtube.com/watch?v=VIDEO_ID)

Thumbnail sizes

https://img.youtube.com/vi/VIDEO_ID/0.jpg               # 480x360
https://img.youtube.com/vi/VIDEO_ID/hqdefault.jpg       # 480x360
https://img.youtube.com/vi/VIDEO_ID/mqdefault.jpg       # 320x180
https://img.youtube.com/vi/VIDEO_ID/maxresdefault.jpg   # 1280x720, if available

Embed with an iframe

Where inline HTML is allowed, like Jekyll and most static sites, you can embed the player. Copy the code from Share → Embed on YouTube. GitHub removes iframes.

<iframe width="560" height="315"
  src="https://www.youtube-nocookie.com/embed/VIDEO_ID"
  title="Video title"
  allowfullscreen></iframe>

Video files on GitHub

On GitHub you can drag an .mp4 or .mov file into an issue, pull request or README edit. It is uploaded and shown as a player.

More about videos

  • youtube-nocookie.com does not set tracking cookies until the video is played
  • Add ?start=60 to the embed address to start at 60 seconds
