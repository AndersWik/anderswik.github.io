GitHub extras

GitHub adds a few things on top of GitHub Flavored Markdown. They work in README files, issues, pull requests and wikis. Some editors and sites support them too.

Alerts

A blockquote that starts with an alert type is shown as a colored box.

> [!NOTE]
> Useful information.

> [!TIP]
> A better way to do it.

> [!IMPORTANT]
> Needed to succeed.

> [!WARNING]
> Needs attention right away.

> [!CAUTION]
> Can cause problems.

Emoji

Write the emoji name between colons, or paste the emoji itself.

:smile: :+1: :rocket: :warning: :penguin:

Mentions and references

@username            mention a user
@org/team            mention a team
#42                  link to issue or pull request 42
owner/repo#42        issue in another repository
a1b2c3d              link to a commit

Diagrams

A code block with the language mermaid is drawn as a diagram.

```mermaid
flowchart LR
    A[Write] --> B[Commit] --> C[Push]
```

Math

LaTeX math between dollar signs. One for inline math, two for a block.

The area is $\pi r^2$.

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
