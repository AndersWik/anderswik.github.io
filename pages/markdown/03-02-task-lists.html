Task lists

A task list is a list with checkboxes. Add [ ] or [x] after the list symbol. Task lists are part of GitHub Flavored Markdown and are supported by most editors and kramdown.

Task list

- [x] Write the notes
- [ ] Check the spelling
- [ ] Publish

Nested tasks

- [ ] Release 1.0
  - [x] Fix bugs
  - [ ] Update the README

More about task lists

  • There must be a space inside the empty box, [ ]
  • On GitHub you can tick the boxes in issues and pull requests, and the Markdown is updated
  • A task list in an issue shows the progress, like 1 of 3 tasks
