Inline HTML

Most Markdown converters let you write HTML directly in the file. Use it for things Markdown cannot do, like collapsed sections, keyboard keys or image sizes.

Inline tags

Inline tags like <kbd>, <sub> and <mark> can be mixed with Markdown in a line.

Press <kbd>Ctrl</kbd> + <kbd>C</kbd> to copy.
Water is H<sub>2</sub>O and this is <mark>important</mark>.

Block tags

Leave an empty line before and after block tags like <div> and <table>. Markdown is usually not converted inside them.

Some text.

<table>
  <tr>
    <td>One</td>
    <td>Two</td>
  </tr>
</table>

More text.

Collapsed section

<details> hides content until it is clicked. Leave an empty line after </summary> so the Markdown inside is converted.

<details>
<summary>Show the output</summary>

```
total 8
drwxr-xr-x 2 pengu pengu 4096 Nov  8 12:00 .
```

</details>

Markdown inside HTML in kramdown

In kramdown, add markdown="1" to convert Markdown inside a block tag.

<div class="note" markdown="1">
This is **bold**.
</div>

More about inline HTML

  • GitHub removes <script>, <style>, <iframe> and style attributes, so colors do not work there
  • align="center" still works on GitHub, see images
  • Some apps turn HTML off completely for safety
