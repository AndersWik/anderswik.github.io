Definition lists

A definition list is a list of terms, each followed by its description. It works in kramdown, Pandoc and PHP Markdown Extra, but not on GitHub.

Definition list

Write the term on one line and the definition on the next, starting with : and a space.

Host
: The computer that runs the virtual machine.

Guest
: The virtual machine.
: It has its own operating system.

HTML

Where definition lists are not supported, use HTML.

<dl>
  <dt>Host</dt>
  <dd>The computer that runs the virtual machine.</dd>
</dl>

Abbreviations

kramdown and PHP Markdown Extra also have abbreviations. Every HTML in the page gets the full name as a tooltip.

HTML is used for web pages.

*[HTML]: HyperText Markup Language
