Images

Images are written like links with a ! in front. The text in the square brackets is the alt text, shown if the image cannot be loaded and read by screen readers.

Image

![A penguin](images/penguin.png)
![Logo](https://example.com/logo.png)

Image with a title

![A penguin](images/penguin.png "Tux the penguin")

Reference image

![A penguin][tux]

[tux]: images/penguin.png "Tux the penguin"

Clickable image

Put the image inside the square brackets of a link.

[![A penguin](images/penguin.png)](https://kernel.org)

Size

Markdown cannot set the size of an image. Use HTML, or attributes in kramdown and Pandoc.

<img src="images/penguin.png" alt="A penguin" width="200">

![A penguin](images/penguin.png){: width="200"}     kramdown
![A penguin](images/penguin.png){width=200px}       Pandoc

Center an image

<p align="center">
  <img src="images/penguin.png" alt="A penguin" width="200">
</p>

More about images

  • Always write a short alt text that says what the image shows
  • On GitHub you can paste or drag an image into an issue or comment and the link is added for you
  • Badges in README files are just images inside links
  • Videos cannot be embedded with Markdown, see YouTube videos
