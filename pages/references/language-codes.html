About the codes

  • ISO 639-1 has two letters, like sv for Swedish. Only the larger languages have one. This is the code most used on the web.
  • ISO 639-2/T has three letters, like swe. Many more languages have a three letter code.
  • ISO 639-2/B is an older three letter code, for a few languages. It comes from library catalogues and is based on the English name: German is ger in 639-2/B and deu (from Deutsch) in 639-2/T. Use the T code unless a system asks for B.

Language tags on the web

HTML, browsers and HTTP use language tags (BCP 47). A tag starts with the language code, and can add a country code after a hyphen for a regional version:

<html lang="sv">      Swedish
<html lang="en-GB">   English, as written in the United Kingdom
<html lang="pt-BR">   Portuguese, as written in Brazil

The language is written in small letters and the country in capitals. Use the two letter code when the language has one, and the three letter code only when it hasn't.

Linux and many programming languages write the same thing with an underscore, en_GB. That is called a locale, see Locale codes.

Source: the ISO 639-2 data in the Debian iso-codes package.
