What is a locale?

A locale tells a program which language to use, and how to write dates, times, numbers and money for a place. en_US and en_GB are both English, but the date 20 November 2026 is 11/20/2026 in en_US and 20/11/2026 in en_GB. In sv_SE it is 2026-11-20, and the number 1,234.5 is written 1 234,5.

A locale name has up to four parts:

language_COUNTRY.encoding@modifier

sv_SE.UTF-8
sr_RS@latin
  • language, the language code in small letters, like sv. Two letters when the language has an ISO 639-1 code, else three, like fil for Filipino.
  • COUNTRY, the country code in capitals, like SE.
  • encoding, how the characters are stored, almost always UTF-8.
  • modifier, a variant, usually another script: sr_RS@latin is Serbian written with the Latin alphabet instead of the Cyrillic.

Locale or language tag?

A locale uses an underscore: en_US. Linux, glibc, Python, Java and PHP use this form. A language tag (IETF BCP 47) uses a hyphen: en-US. The web uses this form: <html lang="en-US">, the Accept-Language header and Intl in JavaScript. In a language tag, a script is written as a four letter code before the country, so sr_RS@latin is sr-Latn-RS.

Locales in Linux

$ locale                          # the locale you use now
$ locale -a                       # the locales installed on this computer
$ sudo locale-gen sv_SE.UTF-8     # install a locale
$ LC_TIME=sv_SE.UTF-8 date        # run one command with another locale

LANG sets the locale for everything. The LC_ variables change one part: LC_TIME dates and times, LC_NUMERIC numbers, LC_MONETARY money and LC_COLLATE the sort order. The locale C, or C.UTF-8, is the plain default: English messages, and dates and sorting that are the same on every computer. Scripts often use it so their output doesn't change with the user's locale.

Locales in JavaScript

new Date(2026, 10, 20).toLocaleDateString("sv-SE");   // "2026-11-20"
(1234.5).toLocaleString("de-DE");                      // "1.234,5"

Good to know

  • The list is the locales the GNU C library (glibc) supports, the library that most Linux systems use. Other systems and programs can support more or fewer.
  • glibc also has old @euro locales, like de_DE@euro. They are from before UTF-8, when the euro sign needed its own character set, and are not in the list.

Source: the SUPPORTED list in glibc, and the ISO 639 and ISO 3166-1 data in the Debian iso-codes package.
