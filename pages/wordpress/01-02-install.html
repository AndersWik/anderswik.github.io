Install

WordPress needs a web server (Apache or nginx), PHP and a MySQL or MariaDB database.

Download

$ cd /var/www
$ wget https://wordpress.org/latest.tar.gz
$ tar -xzf latest.tar.gz

This gives a wordpress folder. Point the web server's document root to it, or move the files to the document root.

Create a database

Create a database and a user that only has access to that database. Log in with mysql -u root -p and run:

CREATE DATABASE wordpress CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'wordpress'@'localhost' IDENTIFIED BY 'a-strong-password';
GRANT ALL PRIVILEGES ON wordpress.* TO 'wordpress'@'localhost';
FLUSH PRIVILEGES;

utf8mb4 can store every Unicode character, emoji included.

wp-config.php

Copy the sample file and add the database login.

$ cd wordpress
$ cp wp-config-sample.php wp-config.php
$ nano wp-config.php
define( 'DB_NAME', 'wordpress' );
define( 'DB_USER', 'wordpress' );
define( 'DB_PASSWORD', 'a-strong-password' );
define( 'DB_HOST', 'localhost' );

Replace the eight keys and salts with random values from api.wordpress.org/secret-key/1.1/salt/. They are used to sign the login cookies. Changing them logs out every user.

The table prefix can be changed if several sites share one database.

$table_prefix = 'wp_';

Run the installer

Open the site in a browser. WordPress finds the empty database and asks for the site title, an admin user name and a password. When it is done, log in at /wp-admin/.

File permissions

The web server has to be able to write to wp-content to upload images and install plugins and updates.

$ sudo chown -R www-data:www-data /var/www/wordpress/wp-content
