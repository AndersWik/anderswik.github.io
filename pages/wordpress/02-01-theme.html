Create a theme

A theme is a folder in wp-content/themes. It needs only two files, style.css and index.php.

wp-content/themes/nerdy/
├── style.css
└── index.php

style.css

The comment at the top of style.css is the theme header. WordPress reads it to show the theme under Appearance → Themes in the dashboard. Only Theme Name is required.

/*
Theme Name: Nerdy
Theme URI: https://www.anderswik.se
Author: Anders Wik
Description: A small theme to learn how themes work.
Version: 1.0.0
Requires at least: 6.0
Requires PHP: 8.0
License: GPL-2.0-or-later
Text Domain: nerdy
*/

body {
  font-family: sans-serif;
}

WordPress does not load style.css on the page by itself, see functions.php for how to add it.

index.php

index.php is the template that is used when no other template fits. Start with plain HTML to see that the theme works.

<h1>Hello World</h1>

Go to Appearance → Themes, activate the theme and open the site. Every URL on the site now shows "Hello World", since index.php is the only template. The loop page fills it with real posts.

Screenshot

Add a screenshot.png to the theme folder to show a picture of the theme in the dashboard. The recommended size is 1200 × 900 pixels.

The theme files

A finished classic theme often has these files. Each one is explained in the following pages.

wp-content/themes/nerdy/
├── style.css        # Theme header and styles
├── functions.php    # Setup, styles, scripts, menus
├── index.php        # Fallback template
├── header.php       # Top of every page
├── footer.php       # Bottom of every page
├── sidebar.php      # Widget area
├── front-page.php   # The front page
├── single.php       # One post
├── page.php         # One page
├── archive.php      # Category, tag, author and date archives
├── search.php       # Search results
├── 404.php          # Page not found
└── screenshot.png

Classic and block themes

These notes are about classic themes, where the templates are PHP files. Block themes, used by the default themes since Twenty Twenty-Two, build the templates from blocks in HTML files in a templates folder and are edited in the site editor. The PHP functions here work in both.
