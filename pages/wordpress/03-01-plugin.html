Create a plugin

A plugin is a PHP file, or a folder with a PHP file, in wp-content/plugins. It adds features that should stay when the theme is changed.

The plugin file

wp-content/plugins/nerdy-hello/
└── nerdy-hello.php

The comment at the top is the plugin header. WordPress reads it to list the plugin under Plugins in the dashboard. Only Plugin Name is required.

<?php
/*
Plugin Name: Nerdy Hello
Description: Adds a greeting after every post.
Version: 1.0.0
Author: Anders Wik
License: GPL-2.0-or-later
Text Domain: nerdy-hello
*/

if ( ! defined( 'ABSPATH' ) ) {
  exit; // Stop if the file is opened directly in the browser
}

function nerdy_hello_add_greeting( $content ) {
  if ( is_single() ) {
    $content .= '<p class="greeting">Thanks for reading!</p>';
  }
  return $content;
}

add_filter( 'the_content', 'nerdy_hello_add_greeting' );
  • ABSPATH is defined by WordPress. If it is missing, someone opened the file directly at /wp-content/plugins/nerdy-hello/nerdy-hello.php, and the code should not run.
  • the_content is a filter, see hooks. WordPress sends the content of the post through our function before it is printed, and prints what we return.

Activate the plugin under Plugins and open a post.

Files in the plugin

Use these functions to find other files in the plugin folder. __FILE__ is the main plugin file.

<?php
require_once plugin_dir_path( __FILE__ ) . 'includes/settings.php';  // Path on the server

wp_enqueue_style( 'nerdy-hello', plugin_dir_url( __FILE__ ) . 'css/hello.css' );  // URL

Activate and deactivate

Code that should only run once, like creating a database table or flushing the rewrite rules, goes in the activation hook.

<?php
function nerdy_hello_activate() {
  add_option( 'nerdy_hello_text', 'Thanks for reading!' );
}
register_activation_hook( __FILE__, 'nerdy_hello_activate' );

function nerdy_hello_deactivate() {
  // Stop scheduled events and similar. Keep the data, the plugin may be activated again.
}
register_deactivation_hook( __FILE__, 'nerdy_hello_deactivate' );

To remove the plugin's data when it is deleted, add an uninstall.php file to the plugin folder.

<?php
if ( ! defined( 'WP_UNINSTALL_PLUGIN' ) ) {
  exit;
}

delete_option( 'nerdy_hello_text' );

Must use plugins

PHP files in wp-content/mu-plugins are always loaded and can not be turned off in the dashboard. They are good for code that the site always needs. WordPress only loads the files directly in the folder, not files in sub folders.
