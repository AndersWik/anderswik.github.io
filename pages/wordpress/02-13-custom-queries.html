Custom queries

The main loop shows the posts WordPress found for the URL. To show other posts too, like the three latest news posts on the front page, make a new query with WP_Query.

WP_Query

<?php
$news = new WP_Query( array(
  'post_type'      => 'post',
  'category_name'  => 'news',     // Category slug
  'posts_per_page' => 3,
) );
?>

<?php if ( $news->have_posts() ) : ?>
  <ul>
    <?php while ( $news->have_posts() ) : $news->the_post(); ?>
      <li><a href="<?php the_permalink(); ?>"><?php the_title(); ?></a></li>
    <?php endwhile; ?>
  </ul>
  <?php wp_reset_postdata(); ?>
<?php endif; ?>
  • The loop is the same as the main loop, but have_posts() and the_post() are called on our query object.
  • $news->the_post() changes the global current post. wp_reset_postdata() sets it back to the post of the main loop, so the_title() after our loop shows the right title again.

Common parameters

<?php
$query = new WP_Query( array(
  'post_type'      => array( 'post', 'book' ),
  'posts_per_page' => 10,           // -1 for all
  'orderby'        => 'title',      // date, title, menu_order, rand, meta_value
  'order'          => 'ASC',
  'post__not_in'   => array( get_the_ID() ),  // Leave out the current post
  'tag'            => 'php',
  'author'         => 1,
  's'              => 'theme',      // Search
  'meta_key'       => 'price',      // A custom field
  'meta_value'     => '100',
) );

Change the main query

Do not make a new query to change the posts of the page itself, for example to show 20 posts on the blog page. That runs the database query twice and breaks the pagination. Change the main query before it runs instead, with the pre_get_posts action in functions.php.

<?php
function nerdy_blog_posts( $query ) {
  if ( is_admin() || ! $query->is_main_query() ) {
    return; // Only the main query on the public site
  }

  if ( $query->is_home() ) {
    $query->set( 'posts_per_page', 20 );
  }
}

add_action( 'pre_get_posts', 'nerdy_blog_posts' );

pre_get_posts runs for every query, also the ones in the dashboard, so always check is_main_query() and is_admin().

get_posts()

get_posts() takes the same parameters and returns an array of posts, without a loop. Use it when the template tags are not needed.

<?php
$posts = get_posts( array( 'numberposts' => 5 ) );

foreach ( $posts as $post ) {
  echo esc_html( $post->post_title );
}
