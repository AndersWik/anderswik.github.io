Navigation menus

Menus are built under Appearance → Menus. The theme decides where they can be shown, the menu locations, and prints them with wp_nav_menu().

The simplest menu

<nav>
  <?php wp_nav_menu(); ?>
</nav>

wp_nav_menu() prints the menu itself, it does not need echo. Without parameters it shows the first menu that is created, or a list of all pages if there are no menus.

Menu locations

To let the editor choose which menu goes where, register the locations in functions.php. The key is used in the code, the value is the name shown in the dashboard.

<?php
function nerdy_menus() {
  register_nav_menus( array(
    'primary' => 'Primary menu',
    'footer'  => 'Footer menu',
  ) );
}

add_action( 'after_setup_theme', 'nerdy_menus' );

Then ask for the location in the template, like header.php.

<nav>
  <?php wp_nav_menu( array( 'theme_location' => 'primary' ) ); ?>
</nav>

Under Appearance → Menus → Manage locations a menu can now be set as "Primary menu".

Options

<?php if ( has_nav_menu( 'footer' ) ) : ?>
  <nav class="footer-nav">
    <?php
    wp_nav_menu( array(
      'theme_location' => 'footer',
      'container'      => false,     // No <div> around the <ul>
      'menu_class'     => 'footer-menu',
      'depth'          => 1,         // No sub menus
      'fallback_cb'    => false,     // Print nothing if no menu is set
    ) );
    ?>
  </nav>
<?php endif; ?>

has_nav_menu() checks if a menu is set for the location, so the empty <nav> is not printed.

WordPress adds classes to the menu items. The item for the page we are on gets current-menu-item, which can be used to highlight it.

.current-menu-item > a {
  font-weight: bold;
}
