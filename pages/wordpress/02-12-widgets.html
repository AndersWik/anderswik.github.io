Widgets and sidebars

A sidebar, or widget area, is a place in the theme where the editor can add blocks or widgets, like a search box or a list of the latest posts, under Appearance → Widgets. It does not have to be on the side, a footer with three columns is often three widget areas.

Register a widget area

In functions.php, on the widgets_init action.

<?php
function nerdy_widgets() {
  register_sidebar( array(
    'name'          => 'Sidebar',
    'id'            => 'sidebar-1',
    'description'   => 'Shown next to posts and pages.',
    'before_widget' => '<section id="%1$s" class="widget %2$s">',
    'after_widget'  => '</section>',
    'before_title'  => '<h2 class="widget-title">',
    'after_title'   => '</h2>',
  ) );
}

add_action( 'widgets_init', 'nerdy_widgets' );

before_widget and after_widget is the HTML around each widget. WordPress replaces %1$s with the widget's ID and %2$s with its class.

Show the widget area

Create sidebar.php in the theme. is_active_sidebar() checks that it has any widgets, so an empty <aside> is not printed.

<?php if ( is_active_sidebar( 'sidebar-1' ) ) : ?>
  <aside class="sidebar">
    <?php dynamic_sidebar( 'sidebar-1' ); ?>
  </aside>
<?php endif; ?>

Load it in a template with get_sidebar(), the same way as get_header().

<?php get_header(); ?>
<div class="content">
  <?php while ( have_posts() ) : the_post(); ?>
    <?php the_content(); ?>
  <?php endwhile; ?>
</div>
<?php get_sidebar(); ?>
<?php get_footer(); ?>
