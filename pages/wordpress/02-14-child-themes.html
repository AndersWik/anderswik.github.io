Child themes

Changes made in a theme from someone else are lost when the theme is updated. A child theme is a small theme that uses another theme, the parent, and only contains what we change.

Create a child theme

wp-content/themes/
├── twentytwentyfive/      # The parent
└── nerdy-child/
    ├── style.css
    └── functions.php

Template in the header of style.css is the folder name of the parent theme.

/*
Theme Name: Nerdy Child
Template: twentytwentyfive
Version: 1.0.0
*/

Load the styles

Many parent themes load their own style.css already. If it does not, load it in the child's functions.php, and then the child's style sheet after it, so the child's rules win.

<?php
function nerdy_child_styles() {
  wp_enqueue_style( 'parent-style', get_parent_theme_file_uri( 'style.css' ) );
  wp_enqueue_style( 'child-style', get_stylesheet_uri(), array( 'parent-style' ) );
}

add_action( 'wp_enqueue_scripts', 'nerdy_child_styles' );

The child's functions.php is loaded before the parent's, and both are used.

Change a template

Copy a template from the parent to the same place in the child theme and change it. WordPress looks in the child first and uses the parent's file if the child does not have one.

Paths in a child theme

FunctionReturns
get_stylesheet_directory()Path to the child theme (the active theme)
get_template_directory()Path to the parent theme
get_theme_file_uri( 'js/a.js' )URL of the file in the child, or in the parent if the child does not have it
get_parent_theme_file_uri( 'js/a.js' )URL of the file in the parent

Without a child theme, the stylesheet and template functions return the same folder.
