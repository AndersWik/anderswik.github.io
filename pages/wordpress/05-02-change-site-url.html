Change site URL

When a site moves to a new domain, from a local copy to a server, or from http to https, the URL has to be changed in the database.

home and siteurl

WordPress keeps two URLs in wp_options. home is the address of the site. siteurl is where the WordPress files are. They are the same, unless core is in a subdirectory.

SELECT option_name, option_value FROM wp_options WHERE option_name IN ('home', 'siteurl');

UPDATE wp_options SET option_value = 'https://example.com' WHERE option_name = 'home';
UPDATE wp_options SET option_value = 'https://example.com/wp' WHERE option_name = 'siteurl';

Or set them in wp-config.php, which wins over the database.

define( 'WP_HOME', 'https://example.com' );
define( 'WP_SITEURL', 'https://example.com/wp' );

The URL in the content

Links and images in posts have the old URL written in them too. Change them all with WP-CLI.

$ wp db export before-move.sql
$ wp search-replace 'http://old.example.com' 'https://example.com' --dry-run
$ wp search-replace 'http://old.example.com' 'https://example.com'

--dry-run shows how many changes there would be in each table, without changing anything.

Do not do this with REPLACE() in SQL or a text editor on the SQL file. WordPress and plugins save arrays as serialized PHP strings, where the length of each string is stored too, like s:22:"http://old.example.com". When the URL gets a different length, the length is wrong and the whole setting is lost. wp search-replace understands serialized data and fixes the lengths.
