Conditional tags

Conditional tags are functions that return true or false depending on what page is shown. They are used to show something on some pages only.

One page

is_page() takes the ID, the slug or the title of a page. The ID is shown in the URL when the page is edited, post.php?post=13.

<div>
  <?php if ( is_page( 13 ) ) : ?>
    <p>Special condition</p>
  <?php endif; ?>
</div>

A slug is a string, so it needs quotes.

<div>
  <?php if ( is_page( 'about' ) ) : ?>
    <p>Special condition</p>
  <?php endif; ?>
</div>

An array checks several pages, is_page( array( 13, 'about', 'contact' ) ). Without a parameter, is_page() is true on every page.

Common conditional tags

FunctionTrue on
is_front_page()The front page of the site
is_home()The blog page, the list of latest posts
is_single()A single post, is_single( 'hello-world' ) for one post
is_page()A page
is_singular()A single post, page or custom post
is_archive()Any archive
is_category()A category archive, is_category( 'news' ) for one
is_tag()A tag archive
is_author()An author archive
is_day(), is_month(), is_year()A date archive
is_search()Search results
is_404()Page not found
is_user_logged_in()A logged in visitor
in_category( 'news' )The current post is in the category, used in the loop

If the front page is set to the latest posts, is_front_page() and is_home() are both true there. If a static page is set as the front page under Settings → Reading, is_home() is true on the posts page instead.

A class on the body

For differences in style only, a conditional tag is often not needed. body_class() in the header already adds a class like page-id-13.

.page-id-13 h1 {
  color: crimson;
}
