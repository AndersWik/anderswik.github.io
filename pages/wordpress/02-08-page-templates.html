Page templates

A page template is a template that the editor can choose for any page, in the Template setting in the page editor. Use it for layouts that are needed on several pages, like a full width page or a landing page.

Create a page template

Create a file in the theme, for example template-full-width.php. The comment at the top with Template Name makes it a page template. The comment has to be PHP, inside <?php, otherwise it is printed on the page.

<?php
/*
Template Name: Full width
*/
?>
<?php get_header(); ?>

<div class="full-width">
  <?php while ( have_posts() ) : the_post(); ?>
    <h1><?php the_title(); ?></h1>
    <?php the_content(); ?>
  <?php endwhile; ?>
</div>

<?php get_footer(); ?>

Edit a page, choose "Full width" under Template and save. The template is used instead of page.php.

Do not start the file name with page-. page-something.php is also the template for the page with the slug something, see the template hierarchy. Many themes keep page templates in a folder, like page-templates/full-width.php.

Templates for posts

By default a page template can only be chosen for pages. Template Post Type makes it available for other post types too.

<?php
/*
Template Name: Wide
Template Post Type: post, page, book
*/

Check the template in code

<?php if ( is_page_template( 'template-full-width.php' ) ) : ?>
  <p>This page uses the full width template.</p>
<?php endif; ?>
