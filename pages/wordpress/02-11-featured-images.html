Featured images

A featured image, called a post thumbnail in the code, is one image that represents a post. It is used in lists of posts and at the top of the post.

Turn on featured images

The Featured image box in the editor is only shown if the theme supports it. Add the support in functions.php.

<?php
function nerdy_setup() {
  add_theme_support( 'post-thumbnails' );
}

add_action( 'after_setup_theme', 'nerdy_setup' );

Show the image

In the loop, the_post_thumbnail() prints an <img> with srcset, so the browser can choose the best size. Check with has_post_thumbnail() first, since not every post has an image.

<?php if ( has_post_thumbnail() ) : ?>
  <a href="<?php the_permalink(); ?>">
    <?php the_post_thumbnail( 'medium' ); ?>
  </a>
<?php endif; ?>

Sizes

When an image is uploaded, WordPress saves copies in several sizes. The sizes can be changed under Settings → Media.

<?php
the_post_thumbnail();                    // 'post-thumbnail', or the full image if that size is not set
the_post_thumbnail( 'thumbnail' );       // Thumbnail (default 150 × 150, cropped)
the_post_thumbnail( 'medium' );          // Medium (default 300 × 300 max)
the_post_thumbnail( 'large' );           // Large (default 1024 × 1024 max)
the_post_thumbnail( 'full' );            // The original image
the_post_thumbnail( array( 100, 100 ) ); // The closest size that fits in 100 × 100

Attributes

The second parameter adds attributes to the <img>.

<?php the_post_thumbnail( 'large', array( 'class' => 'hero', 'loading' => 'eager' ) ); ?>

Our own sizes

add_image_size() adds a new size. The last parameter true crops the image to the exact size, false scales it to fit.

<?php
function nerdy_setup() {
  add_theme_support( 'post-thumbnails' );
  add_image_size( 'nerdy-card', 600, 400, true );
}

add_action( 'after_setup_theme', 'nerdy_setup' );
<?php the_post_thumbnail( 'nerdy-card' ); ?>

New sizes are only made for images uploaded after the change. Run wp media regenerate with WP-CLI to make them for the old images too.
