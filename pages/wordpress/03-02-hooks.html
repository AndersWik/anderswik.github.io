Hooks

Hooks are how themes and plugins change WordPress without changing its files. WordPress calls a hook at many places in its code, and every function added to the hook is run there. There are two kinds of hooks, actions and filters.

Actions

An action is a point in time, like "the page head is printed" or "a post was saved". The function does something, and returns nothing.

<?php
function nerdy_add_meta() {
  echo '<meta name="author" content="Anders Wik">';
}

add_action( 'wp_head', 'nerdy_add_meta' );

When the header calls wp_head(), WordPress runs every function added to the wp_head action, ours included.

Filters

A filter gets a value, and returns it, changed or not. The value is passed through all the functions added to the filter, one after the other.

<?php
function nerdy_shout_title( $title ) {
  return strtoupper( $title );
}

add_filter( 'the_title', 'nerdy_shout_title' );

A filter function must always return a value. If it returns nothing, the value is gone and every title is empty.

Priority and arguments

The third parameter is the priority. Lower numbers run first, the default is 10. The fourth is the number of arguments the function takes, the default is 1.

<?php
function nerdy_title_with_id( $title, $post_id ) {
  return $title . ' (' . $post_id . ')';
}

add_filter( 'the_title', 'nerdy_title_with_id', 20, 2 );

Anonymous functions

A hook can take an anonymous function. It is shorter, but it can not be removed with remove_action(), since it has no name.

<?php
add_action( 'wp_footer', function () {
  echo '<!-- Made with WordPress -->';
} );

Remove a hook

To stop a function that WordPress, a theme or a plugin added. The priority has to be the same as when it was added.

<?php
remove_action( 'wp_head', 'wp_generator' );  // Remove the WordPress version from the head

Our own hooks

Add hooks to our own theme or plugin, so others can change it without editing the code.

<?php
// In the theme
do_action( 'nerdy_before_footer' );
$text = apply_filters( 'nerdy_footer_text', 'Made by Anders' );
echo esc_html( $text );

// In a child theme or plugin
add_filter( 'nerdy_footer_text', function ( $text ) {
  return 'Made by Anna';
} );

Common hooks

HookTypeRuns
after_setup_themeActionAfter the theme is loaded, for add_theme_support()
initActionWhen WordPress is loaded, for post types and shortcodes
wp_enqueue_scriptsActionWhen styles and scripts are added
widgets_initActionWhen widget areas are registered
wp_head, wp_footerActionIn the page head and before </body>
save_postActionWhen a post is saved
pre_get_postsActionBefore a query runs
the_content, the_titleFilterBefore the content or title is printed
body_classFilterThe list of classes on <body>
