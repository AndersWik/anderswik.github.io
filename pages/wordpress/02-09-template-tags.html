Template tags

Template tags are the functions that print information about the current post in the loop. Most of them have two forms. the_title() prints the value, get_the_title() returns it.

Title and content

<?php the_title(); ?>      <!-- Title -->
<?php the_content(); ?>    <!-- The whole content -->
<?php the_excerpt(); ?>    <!-- A summary -->
<?php the_permalink(); ?>  <!-- URL of the post -->
<?php the_ID(); ?>         <!-- ID of the post -->

Date and time

the_time() prints when the post was published. It takes a PHP date format.

<?php the_time( 'F j, Y' ); ?>   <!-- November 21, 2026 -->
<?php the_time( 'Y-m-d' ); ?>    <!-- 2026-11-21 -->
<?php the_time( 'H:i' ); ?>      <!-- 14:05 -->
<?php the_time(); ?>             <!-- Time format from Settings → General -->

the_date() looks the same, but it only prints the date for the first of several posts published on the same day. It is made for lists that are grouped by day. To always show the date use the_time() or echo get_the_date();.

A <time> element with a machine readable date:

<time datetime="<?php echo esc_attr( get_the_date( 'c' ) ); ?>">
  <?php echo esc_html( get_the_date() ); ?>
</time>

Author

<?php the_author(); ?>                              <!-- Display name -->
<?php the_author_meta( 'description' ); ?>          <!-- Biographical info -->
<?php echo esc_html( get_the_author_meta( 'user_email' ) ); ?>

get_the_author_meta() returns a field from the author's profile, like ID, display_name, first_name, user_url or description.

A link to the author's archive needs the author's ID:

<?php $author_id = get_the_author_meta( 'ID' ); ?>
<a href="<?php echo esc_url( get_author_posts_url( $author_id ) ); ?>">
  <?php the_author(); ?>
</a>

the_author_posts_link() prints the same link in one call.

Categories

the_category() prints links to the categories of the post, with a separator.

<?php the_category( ', ' ); ?>

For our own HTML, get_the_category() returns an array of category objects, one for each category of the post.

<?php
$categories = get_the_category();

$categories[0]->term_id;  // 4
$categories[0]->name;     // News
$categories[0]->slug;     // news

The objects also have the older names cat_ID and cat_name. A link to the first category:

<?php $categories = get_the_category(); ?>
<?php if ( $categories ) : ?>
  <?php $category = $categories[0]; ?>
  <a href="<?php echo esc_url( get_category_link( $category->term_id ) ); ?>">
    <?php echo esc_html( $category->name ); ?>
  </a>
<?php endif; ?>

A post always has at least one category, but check the array anyway. On a page, or a custom post type without categories, it is empty and $categories[0] gives a warning.

Tags

<?php the_tags( 'Tags: ', ', ' ); ?>   <!-- Tags: php, wordpress -->
<?php $tags = get_the_tags(); ?>       <!-- Array of tags, or false -->

Edit link

edit_post_link() prints a link to edit the post, only for users that are allowed to edit it.

<?php edit_post_link( 'Edit' ); ?>
