Header and footer

The top and bottom of the page are the same on every page. Instead of copying them into every template, they are kept in header.php and footer.php.

get_header() and get_footer()

<?php get_header(); ?>

<?php if ( have_posts() ) : ?>
  <?php while ( have_posts() ) : the_post(); ?>
    <h2><a href="<?php the_permalink(); ?>"><?php the_title(); ?></a></h2>
    <?php the_content(); ?>
  <?php endwhile; ?>
<?php endif; ?>

<?php get_footer(); ?>

get_header() includes header.php from the theme and get_footer() includes footer.php. If the files do not exist, WordPress uses a simple built-in header and footer and shows a deprecation notice when debugging is on. Create the files to get our own.

wp-content/themes/nerdy/
├── header.php
├── footer.php
└── index.php

header.php

The header starts the HTML document. Tags opened here, like <body> and <html>, are closed in the footer. The site name moves from index.php to the header, so it is shown on every page.

<!doctype html>
<html <?php language_attributes(); ?>>
  <head>
    <meta charset="<?php bloginfo( 'charset' ); ?>">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <?php wp_head(); ?>
  </head>
  <body <?php body_class(); ?>>
    <?php wp_body_open(); ?>
    <header>
      <h1>
        <a href="<?php echo esc_url( home_url( '/' ) ); ?>">
          <?php bloginfo( 'name' ); ?>
        </a>
      </h1>
    </header>
    <main>
  • language_attributes() prints the language of the site, like lang="en-US".
  • wp_head() is where WordPress and plugins add their styles, scripts and meta tags. Without it, the styles from functions.php are not loaded. Always put it right before </head>.
  • body_class() adds classes that describe the page, like home, single, page-id-13 or logged-in. Useful to style one kind of page.
  • wp_body_open() lets plugins add code right after <body>.
  • home_url( '/' ) returns the address of the front page.

Title

Instead of writing a <title> ourselves, let WordPress write it. Add theme support for title-tag in functions.php and wp_head() prints a title that fits the page, like "Post title – Site name".

<?php
add_theme_support( 'title-tag' );

footer.php

The footer closes the tags opened in the header. wp_footer() is where scripts loaded in the footer are added, and where the admin bar is printed for logged in users. Put it right before </body>.

    </main>
    <footer>
      <p>&copy; <?php echo esc_html( date( 'Y' ) ); ?> <?php bloginfo( 'name' ); ?></p>
    </footer>
    <?php wp_footer(); ?>
  </body>
</html>

Several headers

A name loads a different file. get_header( 'shop' ) loads header-shop.php, and get_footer( 'shop' ) loads footer-shop.php.

Sidebar and template parts

get_sidebar() loads sidebar.php in the same way, see widgets. For other pieces that are used in many templates, use get_template_part().

<?php
// Loads template-parts/content.php
get_template_part( 'template-parts/content' );

// Loads template-parts/content-page.php, or content.php if it does not exist
get_template_part( 'template-parts/content', 'page' );
