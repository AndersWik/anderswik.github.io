Shortcodes

A shortcode is a code in square brackets that the editor writes in the content, like [year]. WordPress replaces it with what our function returns when the page is shown.

A simple shortcode

<?php
function nerdy_year_shortcode() {
  return date( 'Y' );
}

add_shortcode( 'year', 'nerdy_year_shortcode' );

Write © [year] in a post or in a Shortcode block, and it shows © 2026.

The function must return the HTML, not print it with echo. Printed text ends up at the top of the content instead of where the shortcode is.

Attributes

[button url="/contact/" color="green"]Contact us[/button]

<?php
function nerdy_button_shortcode( $atts, $content = '' ) {
  $atts = shortcode_atts( array(
    'url'   => '#',
    'color' => 'blue',
  ), $atts, 'button' );

  return sprintf(
    '<a class="button button-%s" href="%s">%s</a>',
    esc_attr( $atts['color'] ),
    esc_url( $atts['url'] ),
    esc_html( $content )
  );
}

add_shortcode( 'button', 'nerdy_button_shortcode' );
  • $atts is an array of the attributes the editor wrote.
  • shortcode_atts() fills in the default values for attributes that are missing, and removes attributes we do not know.
  • $content is the text between [button] and [/button].
  • Everything comes from the editor, so escape it before it is printed, see escaping.

Longer HTML

For more HTML it is easier to write it as a template. ob_start() catches everything that is printed, and ob_get_clean() returns it.

<?php
function nerdy_latest_shortcode() {
  $latest = new WP_Query( array( 'posts_per_page' => 3 ) );

  ob_start();
  ?>
  <ul class="latest">
    <?php while ( $latest->have_posts() ) : $latest->the_post(); ?>
      <li><a href="<?php the_permalink(); ?>"><?php the_title(); ?></a></li>
    <?php endwhile; ?>
  </ul>
  <?php
  wp_reset_postdata();
  return ob_get_clean();
}

add_shortcode( 'latest', 'nerdy_latest_shortcode' );

Shortcodes in templates

<?php echo do_shortcode( '[latest]' ); ?>

In our own templates it is better to call the function directly, echo nerdy_latest_shortcode();.
