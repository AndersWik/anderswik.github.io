The loop

When a page is requested, WordPress finds the posts that belong to the URL before the template runs. For the blog page it is the latest posts, for a single post it is that one post. The loop goes through these posts and prints them.

Site name

bloginfo() prints information about the site. Without a parameter it prints the site name, set under Settings → General.

<h1><?php bloginfo( 'name' ); ?></h1>

bloginfo() prints the value itself, so it does not need echo. get_bloginfo() returns the value instead, to use it in PHP.

<?php
$name = get_bloginfo( 'name' );
$description = get_bloginfo( 'description' ); // The tagline

Most template functions come in these two forms: the_title() prints, get_the_title() returns.

The loop

<h1><?php bloginfo( 'name' ); ?></h1>
<?php if ( have_posts() ) : ?>
  <?php while ( have_posts() ) : ?>
    <?php the_post(); ?>
    <h2>
      <a href="<?php the_permalink(); ?>">
        <?php the_title(); ?>
      </a>
    </h2>
    <?php the_content(); ?>
  <?php endwhile; ?>
<?php else : ?>
  <p>No posts found.</p>
<?php endif; ?>
  • have_posts() returns true while there are posts left.
  • the_post() moves to the next post and sets it up, so the functions below know which post to print. Always call it first in the loop.
  • the_permalink() prints the URL of the post.
  • the_title() prints the title.
  • the_content() prints the content, with the filters applied that turn blocks and shortcodes into HTML.

The if (): while (): endwhile; endif; form is PHP's alternative syntax. It is easier to read than curly brackets when PHP and HTML are mixed.

Excerpt

On a list of posts it is often better to show a short summary. the_excerpt() prints the excerpt written in the editor, or the first 55 words of the content, inside a <p>.

<?php while ( have_posts() ) : the_post(); ?>
  <h2><a href="<?php the_permalink(); ?>"><?php the_title(); ?></a></h2>
  <?php the_excerpt(); ?>
<?php endwhile; ?>

Our own HTML around the excerpt

the_excerpt() adds its own <p>. To choose the HTML ourselves use get_the_excerpt(), which returns the text without the tag. It only returns, so it has to be printed with echo. esc_html() makes sure the text can not break the HTML, see escaping.

<div class="post_div">
  <p class="post_excerpt"><?php echo esc_html( get_the_excerpt() ); ?></p>
</div>

Read more link

Link to the post after the excerpt, in the same way as the title.

<div class="post_div">
  <p class="post_excerpt">
    <?php echo esc_html( get_the_excerpt() ); ?>
    <a href="<?php the_permalink(); ?>">(More...)</a>
  </p>
</div>

The length and the […] at the end can be changed with the filters excerpt_length and excerpt_more in functions.php.

<?php
function nerdy_excerpt_length( $length ) {
  return 30; // Words
}
add_filter( 'excerpt_length', 'nerdy_excerpt_length' );

function nerdy_excerpt_more( $more ) {
  return '…';
}
add_filter( 'excerpt_more', 'nerdy_excerpt_more' );
