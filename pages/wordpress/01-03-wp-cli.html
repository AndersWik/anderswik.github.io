WP-CLI

WP-CLI is the command line tool for WordPress. Everything that can be done in the dashboard can be done with the wp command, which makes it good for scripts and servers without a browser.

Install

$ curl -O https://raw.githubusercontent.com/wp-cli/builds/gh-pages/phar/wp-cli.phar
$ php wp-cli.phar --info
$ chmod +x wp-cli.phar
$ sudo mv wp-cli.phar /usr/local/bin/wp
$ wp --info

Run wp from the WordPress folder, or give the folder with --path=/var/www/wordpress.

Install WordPress

The same steps as on the install page. config create writes wp-config.php with new keys and salts.

$ wp core download
$ wp config create --dbname=wordpress --dbuser=wordpress --dbpass=a-strong-password
$ wp core install --url=http://localhost --title="My site" --admin_user=admin --admin_email=admin@example.com --prompt=admin_password

--prompt=admin_password asks for the password, so it does not end up in the shell history.

Common commands

# Update core, plugins and themes
$ wp core update
$ wp plugin update --all
$ wp theme update --all

# Plugins and themes
$ wp plugin list
$ wp plugin install query-monitor --activate
$ wp plugin deactivate query-monitor
$ wp theme activate nerdy

# Users
$ wp user list
$ wp user create anna anna@example.com --role=editor
$ wp user update 1 --user_pass=new-password

# Settings
$ wp option get siteurl
$ wp option update blogname "My site"

# Database
$ wp db export backup.sql
$ wp db import backup.sql
$ wp search-replace 'http://old.example.com' 'https://new.example.com' --dry-run

search-replace is the safe way to change a URL in the whole database, see change site URL.
