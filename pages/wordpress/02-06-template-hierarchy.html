Template hierarchy

For every request WordPress looks for the most specific template in the theme. If it does not exist, it tries the next one in the list, and in the end it uses index.php. This order is called the template hierarchy.

The most common templates

RequestTemplates, most specific first
Front pagefront-page.php, then the blog or page templates below
Blog pagehome.php, index.php
A postsingle-post.php, single.php, singular.php, index.php
A pagepage template, page-about.php (slug), page-13.php (ID), page.php, singular.php, index.php
Categorycategory-news.php (slug), category-4.php (ID), category.php, archive.php, index.php
Tagtag-php.php, tag-7.php, tag.php, archive.php, index.php
Authorauthor-anders.php, author-1.php, author.php, archive.php, index.php
Datedate.php, archive.php, index.php
Searchsearch.php, index.php
Not found404.php, index.php

A good start is to copy index.php to single.php, page.php and archive.php and change them a little at a time.

Pages and posts

page.php is used for pages and single.php for posts. The loop is the same, but a post usually shows the date and the author and a page does not.

<?php get_header(); ?>
<?php while ( have_posts() ) : the_post(); ?>
  <article>
    <h1><?php the_title(); ?></h1>
    <p><?php the_time( 'F j, Y' ); ?> by <?php the_author(); ?></p>
    <?php the_content(); ?>
  </article>
<?php endwhile; ?>
<?php get_footer(); ?>

One special page

Create page-about.php in the theme root and it is used instead of page.php for the page with the slug about. The slug is the last part of the URL, /about/. For a template that the editor can choose for any page, see page templates.

Archives

archive.php is used for the category, tag, author and date archives. The conditional tags tell which kind of archive it is, to print a heading.

<?php get_header(); ?>
<h1>
  <?php
  if ( is_category() ) {
    single_cat_title();               // Category name
  } elseif ( is_tag() ) {
    single_tag_title();               // Tag name
  } elseif ( is_author() ) {
    the_post();                       // Set up the first post to get its author
    echo 'Posts by ' . esc_html( get_the_author() );
    rewind_posts();                   // Start the loop below from the first post again
  } elseif ( is_day() ) {
    echo esc_html( get_the_date() );            // November 21, 2026
  } elseif ( is_month() ) {
    echo esc_html( get_the_date( 'F Y' ) );     // November 2026
  } elseif ( is_year() ) {
    echo esc_html( get_the_date( 'Y' ) );       // 2026
  } else {
    echo 'Archive';
  }
  ?>
</h1>

<?php while ( have_posts() ) : the_post(); ?>
  <h2><a href="<?php the_permalink(); ?>"><?php the_title(); ?></a></h2>
  <?php the_excerpt(); ?>
<?php endwhile; ?>

<?php the_posts_pagination(); ?>
<?php get_footer(); ?>
  • get_the_author() only works inside the loop. On an author archive we are not in the loop when the heading is printed, so the_post() sets up the first post, and rewind_posts() moves back so the loop still starts at the first post.
  • get_the_date() takes a PHP date format. Without one it uses the format from Settings → General.
  • the_posts_pagination() prints links to the next and previous pages of posts.

The whole if can be replaced with the_archive_title(), which prints a title like "Category: News".

<h1><?php the_archive_title(); ?></h1>
<?php the_archive_description(); ?>
