Custom post types

Posts and pages are two post types. A custom post type is our own kind of content, like books, products or events, with its own menu in the dashboard and its own URLs.

Register a post type

Register the post type on the init action, in a plugin, so the content does not disappear from the dashboard when the theme is changed.

<?php
function nerdy_register_book() {
  register_post_type( 'book', array(
    'labels' => array(
      'name'          => 'Books',
      'singular_name' => 'Book',
      'add_new_item'  => 'Add new book',
    ),
    'public'       => true,
    'has_archive'  => true,                 // A list of all books at /books/
    'rewrite'      => array( 'slug' => 'books' ),
    'menu_icon'    => 'dashicons-book',
    'supports'     => array( 'title', 'editor', 'thumbnail', 'excerpt' ),
    'show_in_rest' => true,                 // Use the block editor
  ) );
}

add_action( 'init', 'nerdy_register_book' );
  • The name, book, is saved in the database. It can be at most 20 characters, lower case, without spaces. Do not change it later.
  • supports decides which boxes are shown in the editor.
  • Without show_in_rest the old classic editor is used.

The URLs

WordPress keeps a list of URL patterns, the rewrite rules. The new /books/ URLs are not in it until it is made again. Go to Settings → Permalinks and click Save, or do it when the plugin is activated.

<?php
function nerdy_books_activate() {
  nerdy_register_book();
  flush_rewrite_rules();
}

register_activation_hook( __FILE__, 'nerdy_books_activate' );

Do not call flush_rewrite_rules() on every page load. It is slow.

Templates

The template hierarchy has templates for each post type.

  • single-book.php: one book, then single.php.
  • archive-book.php: the list at /books/, then archive.php.

Books are not shown in the normal blog loop. Use WP_Query with 'post_type' => 'book' to show them on another page.

Taxonomies

Categories and tags are taxonomies. A post type can have its own, like a genre for books.

<?php
function nerdy_register_genre() {
  register_taxonomy( 'genre', 'book', array(
    'labels'       => array( 'name' => 'Genres', 'singular_name' => 'Genre' ),
    'hierarchical' => true,         // Like categories. false is like tags
    'rewrite'      => array( 'slug' => 'genre' ),
    'show_in_rest' => true,
  ) );
}

add_action( 'init', 'nerdy_register_genre' );

The genres of a book are printed with the_terms( get_the_ID(), 'genre', 'Genre: ', ', ' );.
