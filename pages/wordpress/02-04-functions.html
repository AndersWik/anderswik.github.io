functions.php

functions.php in the theme folder is loaded on every request, before the templates. It is where the theme loads its styles and scripts, turns on features and registers menus and widget areas.

Add style.css

Styles are added with wp_enqueue_style(). get_stylesheet_uri() returns the URL of the theme's style.css.

<?php
wp_enqueue_style( 'style', get_stylesheet_uri() );

This works, but it runs too early, before WordPress is ready to print the styles. Put the call in a function and run it on the wp_enqueue_scripts action. WordPress calls the function when it is time to add styles and scripts, and wp_head() in the header prints them.

<?php
function nerdy_add_styles() {
  wp_enqueue_style( 'nerdy-style', get_stylesheet_uri() );
}

add_action( 'wp_enqueue_scripts', 'nerdy_add_styles' );
  • The first parameter is a unique name, the handle. Other styles can use it to say they depend on this one.
  • Start the function name with the theme name, nerdy_. Every theme and plugin shares the same function names, and two functions with the same name is a fatal error.

Read more about actions on the hooks page.

More styles and scripts

get_theme_file_uri() returns the URL of a file in the theme folder.

<?php
function nerdy_add_assets() {
  $version = wp_get_theme()->get( 'Version' );

  wp_enqueue_style( 'nerdy-style', get_stylesheet_uri(), array(), $version );
  wp_enqueue_style( 'nerdy-print', get_theme_file_uri( 'css/print.css' ), array( 'nerdy-style' ), $version, 'print' );

  wp_enqueue_script( 'nerdy-script', get_theme_file_uri( 'js/script.js' ), array(), $version, array( 'in_footer' => true ) );
}

add_action( 'wp_enqueue_scripts', 'nerdy_add_assets' );
  • The third parameter is a list of handles that have to be loaded first.
  • The version is added to the URL, style.css?ver=1.0.0. When it changes, browsers download the file again instead of using the old one from the cache. Here it comes from Version in the theme header.
  • in_footer prints the script in wp_footer() instead of wp_head(), so it does not slow down the page.

Theme setup

Features are turned on with add_theme_support() on the after_setup_theme action, which runs once, when the theme is loaded.

<?php
function nerdy_setup() {
  add_theme_support( 'title-tag' );         // WordPress writes the <title>
  add_theme_support( 'post-thumbnails' );   // Featured images
  add_theme_support( 'html5', array( 'search-form', 'comment-form', 'gallery', 'caption' ) );
  add_theme_support( 'custom-logo' );       // Logo under Appearance → Customize

  register_nav_menus( array(
    'primary' => 'Primary menu',
  ) );
}

add_action( 'after_setup_theme', 'nerdy_setup' );

Featured images and menus have their own pages, featured images and navigation.

A plugin or functions.php

Code in functions.php stops working when the theme is changed. Put things that should stay, like custom post types, in a plugin instead.
