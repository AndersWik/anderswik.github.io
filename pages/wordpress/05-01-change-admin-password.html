Change admin password

If nobody can log in and the "Lost your password?" email does not arrive, the password can be changed on the server.

With WP-CLI

The easiest way, if WP-CLI is installed. Run it in the WordPress folder.

$ wp user list
$ wp user update 1 --user_pass=development1

With MySQL

Log in to MySQL and find the database. The name is DB_NAME in wp-config.php.

$ mysql -u root -p
SHOW DATABASES;
USE wordpress;
SHOW TABLES;

The tables start with the prefix in wp-config.php, $table_prefix. It is wp_ by default, use the right one below. Find the ID of the user.

SELECT ID, user_login, user_email FROM wp_users;

Set an MD5 password

The quickest way is MySQL's MD5() function. WordPress still accepts an MD5 hash, and replaces it with a secure hash the first time the user logs in.

UPDATE wp_users SET user_pass = MD5('{new password}') WHERE ID = {user id};

Example:

UPDATE wp_users SET user_pass = MD5('development1') WHERE ID = 1;

MD5 is not safe for passwords, so log in right after the change to let WordPress replace it.

Set a bcrypt password

A hash made with PHP's password_hash() works too, and is safe from the start. Make the hash on the command line.

$ php -r "echo password_hash('fire33go', PASSWORD_BCRYPT), PHP_EOL;"
$2y$10$...

Copy the output and set it as the password. Use single quotes, the hash contains $.

UPDATE wp_users SET user_pass = '{the hash}' WHERE ID = 1;

Since WordPress 6.8 passwords are stored with bcrypt, and the hashes start with $wp$2y$. Older versions used phpass, with hashes that start with $P$. WordPress can check all of these, and plain MD5.
