List pages

Pages can have a parent page, which makes a tree of pages. These functions print or return pages from the tree.

wp_list_pages()

wp_list_pages() prints a nested list with links to all published pages.

<ul>
  <?php wp_list_pages( array( 'title_li' => '' ) ); ?>
</ul>

By default the list starts with a "Pages" heading inside an extra <li>. 'title_li' => '' removes it, so the items can go in our own <ul>.

<?php
wp_list_pages( array(
  'title_li'    => '',
  'depth'       => 1,                  // Only top level pages
  'exclude'     => '13,42',            // Page IDs to leave out
  'sort_column' => 'menu_order',       // The Order field in the page settings
) );

Sub pages of the current page

A small menu with the sub pages, for example in a sidebar on page.php. If the page has a parent, show the sub pages of the parent instead, so the menu is the same on all pages in the group.

<?php
$parent_id = wp_get_post_parent_id( get_the_ID() ) ?: get_the_ID();

$children = wp_list_pages( array(
  'title_li' => '',
  'child_of' => $parent_id,
  'echo'     => false,        // Return the HTML instead of printing it
) );
?>
<?php if ( $children ) : ?>
  <nav class="sub-pages">
    <h2><?php echo esc_html( get_the_title( $parent_id ) ); ?></h2>
    <ul><?php echo $children; ?></ul>
  </nav>
<?php endif; ?>

With 'echo' => false the function returns the HTML. That way we can check if there are any sub pages before printing the heading.

get_pages()

get_pages() returns the pages as an array of post objects, to build the HTML ourselves.

<?php $pages = get_pages( array( 'parent' => 0, 'sort_column' => 'menu_order' ) ); ?>
<ul>
  <?php foreach ( $pages as $page ) : ?>
    <li>
      <a href="<?php echo esc_url( get_permalink( $page ) ); ?>">
        <?php echo esc_html( $page->post_title ); ?>
      </a>
    </li>
  <?php endforeach; ?>
</ul>

For most menus it is better to use a navigation menu, which the editor can change without code.
