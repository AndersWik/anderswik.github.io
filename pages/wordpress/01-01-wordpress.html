WordPress

WordPress is a content management system (CMS) written in PHP that stores its content in a MySQL or MariaDB database. Editors write posts and pages in the admin area, the dashboard, and WordPress turns them into HTML pages with the help of a theme.

A WordPress site has three parts:

  • Core: WordPress itself. Never edit these files, they are replaced on every update.
  • Themes: decide how the site looks. Only one theme is active at a time.
  • Plugins: add features, like contact forms or SEO. Many plugins can be active at the same time.

Files and folders

wordpress/
├── index.php        # Every request starts here
├── wp-config.php    # Database login, keys and settings
├── wp-admin/        # The dashboard (core)
├── wp-includes/     # The WordPress functions and classes (core)
└── wp-content/      # Everything that is ours
    ├── themes/
    ├── plugins/
    └── uploads/     # Images and files added in the media library

Everything we write goes in wp-content. When WordPress is updated only wp-admin, wp-includes and the files in the root are replaced.

Posts and pages

Posts are dated entries, shown newest first on the blog page and in the category, tag and author archives. Pages are for content that is not part of the timeline, like "About" or "Contact". Pages can have a parent page, posts can not.

The database

Every table starts with the prefix set in wp-config.php, wp_ by default. The most important ones:

  • wp_posts: posts, pages, menu items and attachments. They are all "posts" with a different post_type.
  • wp_postmeta: extra fields for posts.
  • wp_users and wp_usermeta: users.
  • wp_options: site settings, like the site name and URL.
  • wp_terms, wp_term_taxonomy and wp_term_relationships: categories and tags.
