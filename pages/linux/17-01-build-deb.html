Build a .deb package

A .deb file is a package format used in Debian and Debian-based Linux distributions, such as Ubuntu and Linux Mint. This software package contains everything needed for installation: the program's files, details about the software, and scripts to manage the installation process.

Install the build tools

build-essential gives you compilers and make, debhelper helps build Debian packages, dkms builds kernel modules for every installed kernel and git gets the source code.

$ sudo apt install debhelper dh-modaliases dkms git build-essential

Build a package

Many projects include a debian/ directory with the packaging rules. From the project directory, build an unsigned package; the .deb file ends up in the parent directory.

$ dpkg-buildpackage -us -uc -b

Install the package

$ sudo apt install ../package_1.0_amd64.deb
$ dpkg -c ../package_1.0_amd64.deb   # list the files in the package

Help

--help prints a short summary of how to use dpkg-buildpackage and all its options.

$ dpkg-buildpackage --help

Version

--version shows which version of dpkg-buildpackage is installed.

$ dpkg-buildpackage --version
