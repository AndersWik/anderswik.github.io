Mv

mv moves files and directories to another place. Since moving a file to a new name in the same directory is the same as renaming it, mv is also the command used to rename files.

Move or rename

Rename a file.

$ mv old-name.txt new-name.txt

Move files into a directory.

$ mv report.pdf Documents/
$ mv *.jpg Pictures/

Don't overwrite by mistake

By default mv silently overwrites a file with the same name. -i asks before overwriting and -n never overwrites.

$ mv -i notes.txt backup/
$ mv -n notes.txt backup/

Help

--help prints a short summary of how to use mv and all its options.

$ mv --help

Version

--version shows which version of mv is installed. -v does not show the version, it makes mv print what it does (verbose).

$ mv --version

More about mv

  • -v prints each file as it is moved
  • Directories are moved with all their content; no -r flag is needed
  • To rename many files by a pattern, use the rename command
