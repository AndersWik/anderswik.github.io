Package Managers

A package manager installs, updates and removes software on Linux. Instead of downloading programs from websites, you install them from the distribution's repositories, and the package manager takes care of dependencies and updates. Debian and Ubuntu use apt, Fedora uses dnf, and Arch uses pacman.

Apt

apt is package management on Debian and Ubuntu.

$ apt

Update the list of packages and then upgrade the installed ones.

$ sudo apt update
$ sudo apt upgrade

Search, install and remove

$ apt search vlc
$ sudo apt install vlc
$ sudo apt remove vlc

purge also removes the configuration files of the package.

$ sudo apt purge vlc

Information about a package

$ apt show vlc
$ apt list --installed

Install a .deb file

A downloaded .deb file can be installed with apt, which also installs its dependencies.

$ sudo apt install ./package.deb

Help

--help and -h print a short summary of how to use apt and all its options.

$ apt --help
$ apt -h

Version

--version and -v show which version of apt is installed.

$ apt --version
$ apt -v

More about Package Managers

  • apt-get — the older, script friendly version of apt, see Update
  • dpkg — the low level tool that installs single .deb files
  • snap and flatpak — package formats that work across distributions
