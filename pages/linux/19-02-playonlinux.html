Playonlinux

PlayOnLinux is a graphical front end for Wine that makes it easier to install and run Windows programs and games on Linux. Each program gets its own Wine setup, so they don't interfere with each other.

Fix missing asyncore

PlayOnLinux uses the Python module asyncore, which was removed from Python 3.12. On newer distributions, install the package that brings it back.

$ apt install python3-pyasyncore

Install PlayOnLinux

$ sudo apt install playonlinux

More about Playonlinux

  • Steam with Proton and Lutris are other popular ways to run Windows games on Linux
