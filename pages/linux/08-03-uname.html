Uname

uname prints information about the system: the kernel name and version, the machine's host name and the hardware architecture.

Show system information

$ uname

-a prints everything.

$ uname -a

Print one value

$ uname -r    # kernel release, for example 6.8.0-45-generic
$ uname -m    # architecture, for example x86_64 or aarch64
$ uname -n    # host name

Help

--help prints a short summary of how to use uname and all its options.

$ uname --help

Version

--version shows which version of uname is installed. -v does not show the version of uname, it shows when the kernel was built.

$ uname --version

More about uname

  • Use lsb_release -a or cat /etc/os-release to see the distribution, see Linux
  • uname -r is useful when installing kernel modules or headers, for example sudo apt install linux-headers-$(uname -r)
