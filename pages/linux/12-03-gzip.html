Gzip

gzip compresses single files. The compressed file gets the extension .gz and replaces the original. To compress directories, first put them in an archive with tar.

Compress a file

$ gzip
$ gzip access.log         # creates access.log.gz
$ gzip -k access.log      # keep the original file
$ gzip -9 access.log      # best compression

Decompress

$ gunzip access.log.gz
$ gzip -d access.log.gz

Read without decompressing

$ zcat access.log.gz
$ zgrep "404" access.log.gz
$ zless access.log.gz

Help

--help and -h print a short summary of how to use gzip and all its options.

$ gzip --help
$ gzip -h

Version

--version and -V show which version of gzip is installed. -v does not show the version, it makes gzip print what it does (verbose).

$ gzip --version
$ gzip -V

More about gzip

  • -l shows the compression ratio of a file
  • Old log files in /var/log are often gzipped
