Memory

Memory (RAM) is where running programs keep their data. Linux uses memory that programs don't need as a cache for files, which makes the system faster. That is why free memory often looks low; the cache is given back as soon as a program needs it, so "available" memory is the number to watch.

Swap

When RAM runs out, Linux can move memory that hasn't been used for a while to swap, a file or partition on disk. Swap is much slower than RAM, so a system that swaps a lot needs more memory.

$ swapon --show

See memory usage

$ free -h
$ cat /proc/meminfo

To see which programs use the most memory, sort the process list in top with M or use ps.
