tldr

tldr shows short, example based help pages for commands. The name comes from "too long; didn't read". Where a man page describes every flag, a tldr page only shows the most common ways to use a command. The pages are written and maintained by the community.

Install tldr

tldr is usually not installed by default. On Debian and Ubuntu it can be installed with the package manager.

$ sudo apt install tldr

Update the pages

The pages are downloaded to a local cache. Update the cache the first time you use tldr, and now and then to get new and corrected pages.

$ tldr --update

Show a page

Give the name of the command you want examples for.

$ tldr tar

List all pages

$ tldr --list

Pages for another platform

Some commands work differently on other systems. -p shows the page for a specific platform, for example linux, osx or windows.

$ tldr -p osx ls

Help

--help and -h print a short summary of how to use tldr and all its options.

$ tldr --help
$ tldr -h

Version

--version and -v show which version of tldr is installed.

$ tldr --version
$ tldr -v

More about tldr

  • tldr is a good start, but use man when you need all the details
  • The pages can also be read online at tldr.inbrowser.app
  • There are several tldr clients, so the flags can differ a little between them. Check tldr --help

Manual

  • man tldr
