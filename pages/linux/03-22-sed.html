Sed

sed is a stream editor. It reads text line by line, applies editing commands such as search and replace or delete, and prints the result. It is often used in scripts to change configuration files.

Search and replace

$ sed

s/old/new/ replaces the first match on each line; add g to replace every match. The result is printed and the file is not changed.

$ sed 's/cat/dog/' pets.txt
$ sed 's/cat/dog/g' pets.txt

Edit the file in place

-i writes the changes back to the file. -i.bak keeps a backup of the original.

$ sed -i 's/localhost/127.0.0.1/g' config.conf
$ sed -i.bak 's/localhost/127.0.0.1/g' config.conf

Delete and print lines

$ sed '/^#/d' config.conf     # delete comment lines
$ sed '/^$/d' notes.txt       # delete empty lines
$ sed -n '10,20p' notes.txt   # print only lines 10 to 20

Help

--help prints a short summary of how to use sed and all its options.

$ sed --help

Version

--version shows which version of sed is installed.

$ sed --version

More about sed

  • Any character can be used as separator, which helps with paths: sed 's|/usr/local|/opt|g'
  • -E enables extended regular expressions
