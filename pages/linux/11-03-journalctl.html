Journalctl

journalctl reads the logs collected by systemd's journal: messages from services, the kernel and the system since boot.

Show logs

$ journalctl

Logs for a service

-u selects a unit, -f follows new messages and -e jumps to the end.

$ journalctl -u nginx
$ journalctl -u nginx -f
$ journalctl -u ssh -e

Filter by time and boot

$ journalctl -b                    # since the last boot
$ journalctl -b -1                 # the boot before that
$ journalctl --since "1 hour ago"
$ journalctl -p err                # only errors

Clean up old logs

$ journalctl --disk-usage
$ sudo journalctl --vacuum-time=2weeks

Help

--help and -h print a short summary of how to use journalctl and all its options.

$ journalctl --help
$ journalctl -h

Version

--version shows which version of journalctl is installed.

$ journalctl --version

More about journalctl

  • -k shows only kernel messages, like dmesg
  • Some programs still write their own logs to /var/log
