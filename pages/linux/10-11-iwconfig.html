Iwconfig

iwconfig shows and sets the settings of wireless network interfaces, like the network name (ESSID), frequency, bit rate and signal quality.

Show wireless interfaces

$ iwconfig
$ iwconfig wlan0

Change settings

$ sudo iwconfig wlan0 power off    # turn off power saving
$ sudo iwconfig wlan0 txpower 15   # set transmit power in dBm

Help

--help and -h print a short summary of how to use iwconfig and all its options.

$ iwconfig --help
$ iwconfig -h

Version

--version and -v show which version of iwconfig is installed.

$ iwconfig --version
$ iwconfig -v

More about iwconfig

  • iwconfig comes from the wireless-tools package and is deprecated; iw is its replacement, for example iw dev wlan0 link
  • nmcli dev wifi lists and connects to networks with NetworkManager
