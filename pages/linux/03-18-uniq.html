Uniq

uniq removes or reports repeated lines. It only compares lines that are next to each other, so the input is almost always sorted with sort first.

Remove duplicate lines

$ sort names.txt | uniq

Count occurrences

-c puts the number of times each line appears in front of it. Sorting the result again gives a top list.

$ sort names.txt | uniq -c
$ sort names.txt | uniq -c | sort -rn | head

Only duplicates or only unique lines

$ sort names.txt | uniq -d   # lines that appear more than once
$ sort names.txt | uniq -u   # lines that appear only once

Help

--help prints a short summary of how to use uniq and all its options.

$ uniq --help

Version

--version shows which version of uniq is installed.

$ uniq --version

More about uniq

  • sort -u sorts and removes duplicates in one step
  • -i ignores case when comparing lines
