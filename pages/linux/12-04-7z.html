7zip

7z is the command line version of 7-Zip. It creates and extracts .7z archives, which compress well, and can also extract many other formats like zip, rar and iso. Install it with sudo apt install p7zip-full (or 7zip on newer systems).

Extract archives

x extracts with full paths. The quotes make 7z, not the shell, expand the wildcard, so all .7z files in the directory are extracted.

$ 7z x "*.7z"
$ 7z x archive.7z -o/tmp/output   # extract to another directory

Create an archive

$ 7z a archive.7z folder/
$ 7z a -p archive.7z secret/      # protect with a password

List the content

$ 7z l archive.7z

Help

--help and -h print a list of all commands and switches. 7z has no version option, but the version is printed at the top of every output.

$ 7z --help
$ 7z -h
