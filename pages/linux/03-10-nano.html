Nano

nano is a small, easy to use text editor that runs in the terminal. The most important shortcuts are always shown at the bottom of the screen, where ^ means the Ctrl key. It is a good editor to start with.

Open a file

$ nano notes.txt

Options and shortcuts

-c constantly shows the cursor position (line and column) at the bottom of the screen. Ctrl + c shows the current cursor position once, and Ctrl + k cuts the current line.

nano -c [filename]	show line numbers

ctrl + c		display line numbers
ctrl + k 		delete lines

To show real line numbers in the left margin, use -l.

$ nano -l notes.txt

More shortcuts

ctrl + o      save (write out)
ctrl + x      exit
ctrl + w      search
ctrl + \      search and replace
ctrl + u      paste the cut line
ctrl + _      go to line number

Help

--help and -h print a short summary of how to use nano and all its options.

$ nano --help
$ nano -h

Version

--version and -V show which version of nano is installed.

$ nano --version
$ nano -V
