Disc usage

du stands for disk usage. It shows how much space files and directories use, which helps you find what is filling up a disk.

Print disc usage

-h prints sizes in human readable units. Without a path it lists every subdirectory of the current directory.

du -h

Total size of a directory

-s only prints the summary for each argument.

$ du -sh Downloads
$ du -sh *

Find the largest directories

$ du -h --max-depth=1 | sort -hr | head
$ sudo du -xh / --max-depth=1 | sort -hr

Help

--help prints a short summary of how to use du and all its options. -h does not show help, it shows the sizes in human readable form.

$ du --help

Version

--version shows which version of du is installed.

$ du --version

More about du

  • -x stays on one file system and skips other mounted disks
  • ncdu is an interactive alternative (sudo apt install ncdu)
  • For free space per disk use df
