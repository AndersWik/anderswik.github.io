Tail

tail prints the last lines of a file, by default the last 10. It is often used to look at the newest entries in log files, and it can follow a file as new lines are written to it.

Print the last lines

$ tail /var/log/syslog
$ tail -n 50 /var/log/syslog

Follow a file

-f keeps the file open and prints new lines as they are added. Press Ctrl + c to stop.

$ tail -f /var/log/nginx/access.log

Combine with grep to only follow lines you care about.

$ tail -f /var/log/syslog | grep -i error

Help

--help prints a short summary of how to use tail and all its options.

$ tail --help

Version

--version shows which version of tail is installed. -v does not show the version, it prints the file name above the output.

$ tail --version

More about tail

  • tail -n +20 prints everything from line 20 to the end
  • -F keeps following the file even if it is rotated or recreated
  • The opposite command is head
