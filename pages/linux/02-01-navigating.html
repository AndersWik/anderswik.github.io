Navigating

Everything in Linux lives in one big tree of directories that starts at the root, /. There are no drive letters as in Windows; extra disks are mounted somewhere in the tree instead. Navigating means moving around in this tree and looking at what is in it.

Important directories

  • / — the root of the file system
  • /home — the home directories of the users, for example /home/anders
  • /etc — system wide configuration files
  • /var — files that change, such as logs in /var/log
  • /usr — installed programs and libraries
  • /tmp — temporary files, often emptied on reboot

Paths

An absolute path starts at the root, like /home/anders/Documents. A relative path starts where you are right now, like Documents. A few shortcuts are used all the time.

~     # your home directory
.     # the current directory
..    # the parent directory
-     # the previous directory (with cd)

Commands in this chapter

The three commands you need to get around are pwd to see where you are, ls to see what is there and cd to move.

$ pwd
$ ls
$ cd Documents
