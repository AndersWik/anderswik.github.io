Network

Linux has excellent networking tools. This chapter covers how to see your network settings, test connections, download files, connect to other computers and copy files between them.

Basic concepts

  • IP address — the address of a computer on the network, see it with ip addr
  • Gateway — the router that connects the network to the internet
  • DNS — translates names like example.com to IP addresses, set in /etc/resolv.conf
  • Port — a number that identifies a service, for example 22 for SSH and 443 for HTTPS

Quick checks

$ ip addr               # my IP addresses
$ ping -c 4 8.8.8.8     # can I reach the internet?
$ curl ipinfo.io/ip     # my public IP address

Commands in this chapter

  • ip, ping, ss, iwconfig — network settings and testing
  • wget, curl — download and talk to web servers
  • ssh, scp, rsync — remote login and file copy
  • openssl — encryption
  • WireGuard — VPN
