Cat

cat stands for concatenate. It reads one or more files and prints their content to the terminal. It is the quickest way to look at a short file, and it can join several files into one.

Print a file

$ cat notes.txt

Join files

$ cat part1.txt part2.txt > whole.txt

Show line numbers

$ cat -n notes.txt

Write a file from the terminal

cat reads from the keyboard when no file is given. Type the text and finish with Ctrl + d.

$ cat > notes.txt

Help

--help prints a short summary of how to use cat and all its options.

$ cat --help

Version

--version shows which version of cat is installed. -v does not show the version, it makes non-printing characters visible.

$ cat --version

More about cat

  • For long files use less instead, so you can scroll
  • tac prints a file with the lines in reverse order
  • -A shows hidden characters such as tabs and line endings
