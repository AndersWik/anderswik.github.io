Processes

A process is a running program. Every process has a process id (PID), an owner and a parent process that started it. The first process, systemd on most systems, has PID 1 and starts everything else.

Foreground and background

A command normally runs in the foreground and keeps the terminal busy. Add & to run it in the background. Ctrl + z pauses a foreground process, bg continues it in the background and fg brings it back.

$ sleep 300 &
$ jobs
$ fg %1

Signals

Processes are controlled with signals. Ctrl + c sends SIGINT to ask the program to stop, and the kill command can send any signal to a process by its PID.

Commands in this chapter

  • ps — list processes
  • top — watch processes live
  • kill — send a signal to a process by PID
  • killall — send a signal to processes by name
