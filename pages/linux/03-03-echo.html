Echo

echo prints text to the terminal. It is used to show messages in scripts, print the value of variables and, together with redirection, write text into files.

Print text

$ echo "Hello world"
Hello world

Print variables

$ echo $HOME
$ echo "Logged in as $USER"

Single quotes print the text exactly as written, without expanding variables.

$ echo 'Logged in as $USER'

Write to a file

> replaces the content of the file and >> adds a line at the end.

$ echo "first line" > file.txt
$ echo "second line" >> file.txt

Escape sequences

-e interprets escape sequences like \n for a new line and \t for a tab. -n skips the newline at the end.

$ echo -e "one\ntwo"
$ echo -n "no newline"

Help

The echo built into the shell does not understand --help, it just prints the text. Use help echo for the builtin, or call the program /bin/echo from GNU coreutils.

$ help echo
$ /bin/echo --help

Version

The echo built into the shell has no version, but /bin/echo does.

$ /bin/echo --version

More about echo

  • printf gives more control over formatting, for example printf "%s is %d\n" age 42
  • Bash has its own built in echo; help echo shows its documentation
