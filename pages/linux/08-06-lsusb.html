Lsusb

lsusb lists the USB buses and the devices connected to them, such as keyboards, mice, webcams, USB sticks and external disks. It is useful to check that a device is detected when you plug it in.

List devices

$ lsusb

Each line shows the bus, the device number, the vendor and product id (for example 046d:c52b) and a name.

Show as a tree

-t shows how the devices are connected to hubs and ports, and which driver each one uses.

$ lsusb -t

Find a device

$ lsusb | grep -i logitech
$ lsusb -d 046d:          # only devices from vendor id 046d

More details

$ lsusb -v                 # verbose, use sudo to see everything
$ sudo lsusb -v -d 046d:c52b

Help

--help and -h print a short summary of how to use lsusb and all its options.

$ lsusb --help
$ lsusb -h

Version

--version and -V show which version of lsusb is installed. -v does not show the version, it shows more details about each device.

$ lsusb --version
$ lsusb -V

More about lsusb

  • lspci does the same for PCI devices
  • lshw shows a full overview of the hardware
  • dmesg shows kernel messages when a USB device is plugged in
