Wc

wc stands for word count. It counts the lines, words and bytes in files or in the output of another command.

Count lines, words and bytes

$ wc notes.txt
  12  96  540 notes.txt

Count only one thing

$ wc -l notes.txt   # lines
$ wc -w notes.txt   # words
$ wc -c notes.txt   # bytes
$ wc -m notes.txt   # characters

Count the output of a command

$ ls | wc -l                   # number of files in the directory
$ grep "404" access.log | wc -l

Help

--help prints a short summary of how to use wc and all its options.

$ wc --help

Version

--version shows which version of wc is installed.

$ wc --version

More about wc

  • Give several files to get a count for each and a total
  • wc -L prints the length of the longest line
