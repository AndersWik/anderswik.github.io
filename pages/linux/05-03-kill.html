Kill

kill sends a signal to a process, identified by its PID. Despite the name the default signal, SIGTERM, politely asks the process to stop, and the program can clean up before it exits.

Stop a process

Find the PID with ps or pgrep, then send the signal.

$ pgrep firefox
4321
$ kill 4321

Force a process to stop

If the process doesn't react, SIGKILL (9) stops it immediately. The program gets no chance to clean up, so use it as a last resort.

$ kill -9 4321

Other signals

$ kill -l              # list all signals
$ kill -HUP 4321       # many services reload their configuration on HUP

Help

kill is built into the shell, so -h is not help. --help prints a short summary, the same as help kill.

$ kill --help

Version

The kill built into the shell has no version, but the program /bin/kill does.

$ /bin/kill --version

More about kill

  • You can only send signals to your own processes unless you use sudo
  • pkill firefox sends a signal to processes by name
  • See also killall
