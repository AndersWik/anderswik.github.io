Ip

ip shows and changes network settings: interfaces, IP addresses and routes. It replaces the older ifconfig and route commands.

Show IP addresses

$ ip
$ ip addr
$ ip -br addr    # short, one line per interface

Interfaces

$ ip link
$ sudo ip link set wlan0 down
$ sudo ip link set wlan0 up

Routes

The default route shows which gateway the computer uses to reach the internet.

$ ip route

Add an address

$ sudo ip addr add 192.168.1.50/24 dev eth0

Changes made with ip are lost on reboot; permanent settings are made in NetworkManager or netplan.

Help

ip help prints a short summary. Every object has its own help as well, for example ip address help. -h does not show help, it shows numbers in human readable form.

$ ip help
$ ip address help

Version

-V shows which version of ip is installed. ip has no --version.

$ ip -V

More about ip

  • Most subcommands can be shortened: ip a, ip r, ip l
  • ip neigh shows the ARP table of nearby devices
