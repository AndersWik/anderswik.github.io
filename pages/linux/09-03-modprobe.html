Modprobe

modprobe loads and removes kernel modules. It also loads any other modules the module depends on.

Load a module

$ sudo modprobe vboxdrv

Remove a module

$ sudo modprobe -r vboxdrv

Check modules

$ lsmod | grep vbox
$ modinfo vboxdrv

Block a module

To stop a module from loading at boot, blacklist it in a file in /etc/modprobe.d/.

$ echo "blacklist nouveau" | sudo tee /etc/modprobe.d/blacklist-nouveau.conf

Help

--help and -h print a short summary of how to use modprobe and all its options.

$ modprobe --help
$ modprobe -h

Version

--version and -V show which version of modprobe is installed. -v does not show the version, it makes modprobe print what it does (verbose).

$ modprobe --version
$ modprobe -V

More about modprobe

  • Modules to load at boot can be listed in /etc/modules-load.d/
  • With Secure Boot enabled, modules must be signed, see mokutil
