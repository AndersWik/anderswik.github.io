Paste

paste merges files line by line, putting the lines next to each other as columns separated by a tab. It does the opposite of cut: where cut takes columns out of a file, paste joins columns together.

Merge files side by side

paste

Line 1 of the first file is joined with line 1 of the second file, line 2 with line 2, and so on.

$ cat names.txt
Anna
Bertil
$ cat ages.txt
34
51
$ paste names.txt ages.txt
Anna	34
Bertil	51

Choose the delimiter

-d sets the character placed between the columns, for example a comma to create a CSV file.

$ paste -d ',' names.txt ages.txt > people.csv

Join all lines into one

-s (serial) pastes all lines of a file after each other on a single line instead of side by side.

$ paste -s -d ',' names.txt
Anna,Bertil

This is handy for turning the output of a command into a comma separated list.

$ ls *.txt | paste -s -d ','

Split a list into columns

A - reads from standard input. Giving it several times takes one line for each column, so a long list is split into rows.

$ seq 1 6 | paste - - -
1	2	3
4	5	6

Use with cut

Take columns out of a file with cut and put them back together in another order with paste.

$ cut -d ',' -f 1 data.csv > first.txt
$ cut -d ',' -f 3 data.csv > third.txt
$ paste -d ',' third.txt first.txt

Help

--help prints a short summary of how to use paste and all its options.

$ paste --help

Version

--version shows which version of paste is installed.

$ paste --version

More about paste

  • If one file is shorter than the other, its column is left empty for the remaining lines
  • join merges two sorted files on a common field, like a database join
  • column -t lines up the output in neat columns for reading
  • See also cut and awk
