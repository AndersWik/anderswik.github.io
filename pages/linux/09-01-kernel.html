Kernel

The kernel is the core of the operating system. It talks to the hardware, manages memory and processes, and gives programs access to files and the network. Linux itself is really the name of the kernel.

Kernel version

$ uname -r

Kernel modules

Drivers are often built as kernel modules that can be loaded and unloaded while the system runs. lsmod lists the modules that are loaded.

$ lsmod
$ modinfo snd_hda_intel

Commands in this chapter

  • dmesg — read the kernel's messages
  • modprobe — load and remove kernel modules
