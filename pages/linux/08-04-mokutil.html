Mokutil

mokutil manages Machine Owner Keys (MOK) used by Secure Boot on UEFI systems. With Secure Boot enabled, the computer only loads kernels and kernel modules signed with a trusted key. Drivers you build yourself, like Nvidia or VirtualBox modules, must be signed with a key you enroll with mokutil.

Check Secure Boot

Shows whether Secure Boot is enabled.

mokutil --sb-state

List enrolled keys

$ mokutil --list-enrolled

Enroll a key

Enrolling a key asks for a one time password. On the next reboot the blue MOK manager screen appears, where you choose "Enroll MOK" and type the same password.

$ sudo mokutil --import /var/lib/shim-signed/mok/MOK.der

Help

--help and -h print a short summary of how to use mokutil and all its options.

$ mokutil --help
$ mokutil -h

Version

--version and -v show which version of mokutil is installed.

$ mokutil --version
$ mokutil -v
