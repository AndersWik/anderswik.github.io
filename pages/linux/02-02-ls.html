Ls

ls lists the contents of a directory. Without arguments it lists the current directory. Flags control how much information is shown and in which order.

List all files

$ ls

-l uses the long listing format, showing permissions, owner, group, size and modification date for each file.

$ ls -l

Give a file name to only show that file.

$ ls -l file.txt

List all files including hidden

Files whose names start with a dot, like .bashrc, are hidden. -a shows all files, including the hidden ones.

$ ls -la

List all files including hidden with size in human readable form.

$ ls -lah

Sort the list

-t sorts by modification time, newest first, and -S sorts by size, largest first. -r reverses the order.

$ ls -lt
$ ls -lS
$ ls -ltr

List another directory

$ ls /etc
$ ls -R Documents   # list subdirectories recursively

Help

--help prints a short summary of how to use ls and all its options. -h does not show help, it shows sizes in human readable form.

$ ls --help

Version

--version shows which version of ls is installed.

$ ls --version

More about ls

  • ls -1 prints one file per line, which is handy in scripts
  • ls -d */ lists only directories
  • tree shows a directory and its subdirectories as a tree (install it with sudo apt install tree)
