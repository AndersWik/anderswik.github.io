Crontab

crontab edits the table of scheduled jobs that the cron daemon runs. Each line is a schedule and a command, for example to run a backup every night.

Edit your jobs

The first time you will be asked which editor to use.

$ crontab -e
$ crontab -l    # list your jobs

The schedule

Five fields set when the command runs: minute, hour, day of month, month and day of week. * means every.

# m  h  dom mon dow  command
  0  3  *   *   *    /home/anders/backup.sh          # every night at 03:00
 */5 *  *   *   *    /home/anders/check.sh           # every 5 minutes
  0  9  *   *   1-5  /home/anders/report.sh          # weekdays at 09:00
@reboot              /home/anders/start.sh           # at boot

Save the output

Cron has no terminal, so send the output to a log file to see what happened.

0 3 * * * /home/anders/backup.sh >> /home/anders/backup.log 2>&1

More about crontab

  • sudo crontab -e edits root's jobs
  • Cron uses a minimal PATH, so use full paths to commands and scripts
  • Build and explain schedules with the Crontab tool on this site
