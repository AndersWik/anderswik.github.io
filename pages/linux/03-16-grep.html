Grep

grep searches for lines matching a pattern in files or in the output of another command. The pattern can be plain text or a regular expression. It is one of the most used commands on the command line.

Search in a file

grep
$ grep "error" /var/log/syslog

Common flags

$ grep -i "error" app.log    # ignore case
$ grep -n "error" app.log    # show line numbers
$ grep -v "debug" app.log    # lines that do NOT match
$ grep -c "error" app.log    # count matching lines

Search in many files

-r searches recursively through a directory. -l only prints the names of the files that match.

$ grep -r "TODO" src/
$ grep -rl "password" /etc

Filter the output of other commands

$ ps aux | grep nginx
$ history | grep ssh

Regular expressions

-E enables extended regular expressions, for example to match several words.

$ grep -E "error|warning" app.log
$ grep "^#" config.conf      # lines starting with #

Help

--help prints a short summary of how to use grep and all its options. -h does not show help, it hides the file names in the output.

$ grep --help

Version

--version and -V show which version of grep is installed. -v does not show the version, it shows the lines that do not match.

$ grep --version
$ grep -V

More about grep

  • -A 3 and -B 3 print 3 lines after or before each match for context
  • -w only matches whole words
  • ripgrep (rg) is a faster modern alternative
