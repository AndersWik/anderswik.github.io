Chmod

chmod stands for change mode. It changes the permissions of files and directories: who may read (r), write (w) and execute (x) them. Permissions are set for the owner (u), the group (g) and others (o).

Make a file executable

$ chmod +x script.sh
$ ./script.sh

Symbolic mode

$ chmod u+w notes.txt    # give the owner write permission
$ chmod go-r secret.txt  # take away read for group and others
$ chmod a+r public.txt   # everyone can read

Numeric mode

Each permission has a number: read is 4, write is 2 and execute is 1. Add them up for owner, group and others.

$ chmod 755 script.sh   # rwxr-xr-x
$ chmod 644 notes.txt   # rw-r--r--
$ chmod 600 id_rsa      # rw------- only the owner

Change a directory recursively

$ chmod -R 755 public_html

Help

--help prints a short summary of how to use chmod and all its options.

$ chmod --help

Version

--version shows which version of chmod is installed. -v does not show the version, it makes chmod print what it does (verbose).

$ chmod --version

More about chmod

  • chown changes the owner of a file, for example sudo chown anders:anders file.txt
  • ls -l shows the current permissions
  • SSH refuses to use private keys that others can read, so they should be 600
