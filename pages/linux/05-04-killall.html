Killall

killall sends a signal to all processes with a given name. It is handy when you don't want to look up the PID first, or when a program has started many processes.

Stop processes by name

Stop all running node processes, for example a development server that is stuck.

# /usr/local/bin/
$ killall node

Force and confirm

$ killall -9 node        # force stop with SIGKILL
$ killall -i node        # ask before each process
$ killall -u anders node # only processes owned by anders

Help

--help prints a short summary of how to use killall and all its options.

$ killall --help

Version

--version and -V show which version of killall is installed. -v does not show the version, it makes killall print what it does (verbose).

$ killall --version
$ killall -V

More about killall

  • The name must match exactly; pkill matches part of the name
  • On Linux killall comes from the psmisc package
  • See also kill
