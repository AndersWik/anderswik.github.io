System

This chapter is about getting information about the system itself: how long it has been running, which kernel and hardware it has, and how to keep it up to date.

Quick system overview

$ hostnamectl
$ uptime
$ uname -a

Hardware information

$ lscpu        # processor
$ lsblk        # disks
$ lspci        # PCI devices, like graphics and network cards
$ lsusb        # USB devices

Commands in this chapter

  • uptime — how long the system has run and the load
  • uname — kernel and system information
  • Update — keeping the system up to date with apt-get
  • mokutil — Secure Boot and machine owner keys
  • lspci — list PCI devices
  • lsusb — list USB devices
  • lshw — detailed overview of the hardware
