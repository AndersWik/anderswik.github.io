Wireguard

WireGuard is a fast, modern and simple VPN built into the Linux kernel. Each side has a key pair, and the connection settings are kept in a configuration file such as /etc/wireguard/wg0.conf.

Install and create keys

$ sudo apt install wireguard
$ wg genkey | tee privatekey | wg pubkey > publickey

Start the VPN

wg-quick reads the configuration file and brings the interface up.

$ wg-quick up wg0

If a message like the following is shown in this step:

Warning: `/etc/wireguard/wg0.conf' is world accessible

This means that the configuration file permissions are too broad - and they shouldn’t, as there’s a private key in there. This can be fixed with

$ chmod 600 /etc/wireguard/wg0.conf

Status and stop

$ sudo wg show
$ wg-quick down wg0

Start at boot

$ sudo systemctl enable --now wg-quick@wg0

Help

--help and -h print a short summary of how to use wg and all its options. Each subcommand also has its own help, for example wg show --help.

$ wg --help
$ wg -h

Version

--version and -v show which version of wg is installed.

$ wg --version
$ wg -v
