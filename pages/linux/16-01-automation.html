Automation

Automation means letting the computer do repeated tasks for you. On Linux the classic recipe is three parts: a shell script that does the work, cron that runs it on a schedule, and tools like rsync that do the heavy lifting.

  • shell script .sh — see Shell
  • crontab — see Crontab
  • rsync — see Rsync

Example: nightly backup

The script, saved as ~/backup.sh.

#!/bin/bash
set -e
rsync -a --delete ~/Documents/ /media/backup/Documents/
echo "$(date) backup done" >> ~/backup.log

Make it executable and test it.

$ chmod +x ~/backup.sh
$ ~/backup.sh

Then schedule it with crontab -e to run every night at 02:00.

0 2 * * * /home/anders/backup.sh

Other tools

  • systemd timers — an alternative to cron, managed with systemctl
  • Ansible — automates setup of many servers at once
