Ps

ps stands for process status. It prints a snapshot of the running processes. Without options it only shows processes started from the current terminal.

List processes

aux shows all processes from all users, with owner, CPU and memory usage.

$ ps aux

Find a process

$ ps aux | grep nginx
$ pgrep -a nginx

Sort by usage

$ ps aux --sort=-%mem | head    # highest memory usage first
$ ps aux --sort=-%cpu | head    # highest CPU usage first

Show as a tree

$ ps -ef --forest

Help

--help prints a short summary of the options. Add all to see every option. -h does not show help, it hides the header line.

$ ps --help
$ ps --help all

Version

--version and -V show which version of ps is installed.

$ ps --version
$ ps -V

More about ps

  • pstree shows processes as a tree in a more readable way
  • For a live view use top
