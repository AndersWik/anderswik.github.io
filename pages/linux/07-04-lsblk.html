Lsblk

lsblk stands for list block devices. It shows the disks in the computer, the partitions on them, their size and where they are mounted. It is useful to find the name of a USB stick or a new disk, for example /dev/sdb.

List disks and partitions

$ lsblk

Partitions are shown indented under the disk they belong to. The MOUNTPOINTS column shows where each partition is mounted.

Show file systems

-f shows the file system type, label and UUID of each partition.

$ lsblk -f

Choose columns

$ lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS
$ lsblk -d                 # only disks, no partitions

One disk

$ lsblk /dev/sda

Help

--help and -h print a short summary of how to use lsblk and all its options.

$ lsblk --help
$ lsblk -h

Version

--version and -V show which version of lsblk is installed.

$ lsblk --version
$ lsblk -V

More about lsblk

  • df shows how much space is used on mounted file systems
  • du shows how much space files and directories use
