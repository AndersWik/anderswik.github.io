Find

find searches for files and directories in a directory tree. You can search by name, type, size, modification time and more, and run a command on every match.

Find files by name

Search the current directory (.) and everything below it. Quote the pattern so the shell doesn't expand it. -iname ignores case.

$ find . -name "*.txt"
$ find /home -iname "readme*"

Find by type

-type f only matches files and -type d only directories.

$ find . -type d -name "node_modules"

Find by size and time

$ find . -size +100M        # larger than 100 MB
$ find . -mtime -7          # modified in the last 7 days

Run a command on the matches

-exec runs a command for every file found; {} is replaced by the file name. -delete removes the matches, so test the search without it first.

$ find . -name "*.log" -exec ls -lh {} \;
$ find /tmp -name "*.tmp" -delete

Help

--help prints a short summary of how to use find and all its options.

$ find --help

Version

--version shows which version of find is installed.

$ find --version

More about find

  • 2>/dev/null hides "Permission denied" errors, for example find / -name nginx.conf 2>/dev/null
  • locate searches a prebuilt database and is much faster, but may be out of date
  • To search inside files use grep
