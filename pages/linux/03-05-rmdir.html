Rmdir

rmdir stands for remove directory. It deletes one or more directories, but only if they are empty. This makes it a safe way to clean up, since it never removes any files.

Remove a directory

$ rmdir projects
$ rmdir one two three

If the directory is not empty, rmdir refuses and leaves it alone.

$ rmdir projects
rmdir: failed to remove 'projects': Directory not empty

Remove parent directories

-p removes the directory and then each parent in the path, as long as they become empty. It is the opposite of mkdir -p.

$ rmdir -p projects/website/css

Ignore directories that are not empty

--ignore-fail-on-non-empty skips directories that still contain files without printing an error. Useful in scripts.

$ rmdir --ignore-fail-on-non-empty projects

Help

--help prints a short summary of how to use rmdir and all its options.

$ rmdir --help

Version

--version shows which version of rmdir is installed. -v does not show the version, it makes rmdir print what it does (verbose).

$ rmdir --version

More about rmdir

  • -v prints a message for every directory removed
  • Create directories with mkdir
  • To remove a directory and everything in it, use rm with -r
  • Remove all empty directories below the current one with find: find . -type d -empty -delete
