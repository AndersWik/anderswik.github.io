Emacs

emacs is an extensible text editor from the GNU project. It can run in the terminal or as a graphical program, and with its built in Lisp language it can be turned into almost anything: a mail client, a file manager or a full development environment. It is usually not installed by default.

Install and start

$ sudo apt install emacs
emacs

Open a file directly in the terminal, without the graphical window.

$ emacs -nw notes.txt

Keys

In Emacs C- means the Ctrl key and M- means the Alt key.

C-x C-f   open a file
C-x C-s   save
C-x C-c   quit
C-s       search
C-g       cancel the current command
C-x u     undo

Help

--help prints a short summary of how to use emacs and all its options.

$ emacs --help

Version

--version shows which version of emacs is installed.

$ emacs --version
