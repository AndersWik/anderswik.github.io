Cut

cut extracts parts of each line: selected fields separated by a delimiter, or selected characters. It is useful for picking columns out of CSV files and other structured text.

Cut fields

-d sets the delimiter and -f chooses which fields to keep. This prints the user names from /etc/passwd, where fields are separated by :.

$ cut -d ':' -f 1 /etc/passwd

Several fields or a range.

$ cut -d ',' -f 1,3 data.csv
$ cut -d ',' -f 2-4 data.csv

Cut characters

$ cut -c 1-10 notes.txt

Help

--help prints a short summary of how to use cut and all its options.

$ cut --help

Version

--version shows which version of cut is installed.

$ cut --version

More about cut

  • cut only handles a single character delimiter; for columns separated by several spaces use awk
  • paste does the opposite and joins files column by column
