Less

less is a pager. It shows a file one screen at a time and lets you scroll and search in it. It does not load the whole file at once, so it works well even for very large log files. Manual pages are shown with less.

Open a file

$ less /var/log/syslog

Keys

  • Space or Page Down — next page
  • b or Page Up — previous page
  • g / G — go to the start / end of the file
  • /word — search forward, n for the next match, N for the previous
  • q — quit

Read output from a command

$ ps aux | less

Follow a growing file

+F makes less follow the end of the file like tail -f. Press Ctrl + c to stop following and q to quit.

$ less +F /var/log/syslog

Help

--help prints a short summary of how to use less and all its options. -h is not help in less. While a file is open, press h to see all keys.

$ less --help

Version

--version and -V show which version of less is installed.

$ less --version
$ less -V

More about less

  • -N shows line numbers
  • -S turns off line wrapping for wide files
  • more is the older, simpler pager

Manual

  • man less
