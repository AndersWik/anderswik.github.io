Awk

awk is a small programming language for processing text, line by line. Each line is split into fields, $1, $2 and so on, and you can print, filter and calculate with them. It is great for working with columns of data.

Print columns

$ awk

By default fields are separated by spaces. This prints the first and third column.

$ awk '{print $1, $3}' data.txt
$ ls -l | awk '{print $9, $5}'      # file name and size

Set the field separator

$ awk -F ':' '{print $1}' /etc/passwd
$ awk -F ',' '{print $2}' data.csv

Filter lines

A pattern before the braces decides which lines are processed.

$ awk '$3 > 100' data.txt
$ awk '/error/ {print $0}' app.log

Calculate

END runs after all lines are read. This sums the second column.

$ awk '{sum += $2} END {print sum}' data.txt

Help

--help and -h print a short summary of how to use awk and all its options.

$ awk --help
$ awk -h

Version

--version and -V show which version of awk is installed. -v does not show the version, it sets a variable. This is for GNU awk. Some systems use mawk instead, where the version is shown with awk -W version.

$ awk --version
$ awk -V

More about awk

  • NR is the current line number and NF the number of fields on the line
  • On most systems awk is gawk (GNU awk) or mawk
