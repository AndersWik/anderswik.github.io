Vim

vim is a powerful text editor that runs in the terminal and is installed on almost every Linux system, often as vi. It is modal: in normal mode keys are commands, in insert mode you type text, and in command mode you give commands that start with :. It takes a while to learn but makes editing very fast.

Open file

vim <file name>

Insert mode

Press i to start typing text where the cursor is. a starts after the cursor and o opens a new line below.

Command mode

Hit the Esc key to leave insert and enter command mode.

Help

:help

Same as help.

:h

Write

Write (save) the file without quitting. Give a file name to save as a new file.

:w
:w newfile.txt

Quit

Quit if no changes are made. If the document is edited it will give an error. E37: No write since last change (add ! to override)

:quit
:q

If changes are made and you want to quit without saving you can add "!" to suppress the error.

:quit!
:q!

Write and quit

Will write and quit. It will write even if there are no changes to the file. Gives an error if the file does not have write permission.

:wq

Will write and quit. If the file does not have write permission it will try to force the write.

:wq!

Will only write if there are changes made to the file.

:exit

Same as exit.

:x

Quitall

Quit all open windows and files.

:quitall

Same as quitall.

:qa

Common normal mode commands

dd      delete (cut) the current line
yy      copy (yank) the current line
p       paste below the cursor
u       undo
ctrl+r  redo
/word   search for word
gg / G  go to the first / last line

Help

--help and -h print a short summary of how to use vim and all its options.

$ vim --help
$ vim -h

Version

--version shows which version of vim is installed. -v does not show the version, it starts Vim in Vi mode. Inside Vim, :version shows the same information and :help opens the built in help.

$ vim --version
