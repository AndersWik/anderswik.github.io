Shell

The shell is the program that reads the commands you type and runs them. The most common shell is Bash; others are Zsh and Fish. The shell is also a programming language, so commands can be saved in a script and run again.

Which shell am I using?

$ echo $SHELL

Variables

$ name="Anders"
$ echo "Hello $name"
$ export PATH="$HOME/bin:$PATH"

A first script

A script starts with a shebang line that tells which shell should run it. Make it executable with chmod.

#!/bin/bash
echo "Backup started"
tar -czf ~/backup.tar.gz ~/Documents
echo "Backup done"
$ chmod +x backup.sh
$ ./backup.sh

Configuration

Settings and aliases for Bash are kept in ~/.bashrc.

alias ll='ls -lah'
