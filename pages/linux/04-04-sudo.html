Sudo

sudo runs a command as another user, by default as root. It asks for your own password and lets administrators work as a normal user and only use root's powers when needed. Who may use sudo is set in /etc/sudoers.

Run a command as root

$ sudo apt update
$ sudo nano /etc/hosts

Repeat the last command with sudo

$ sudo !!

Open a root shell

-i starts a login shell as root. Type exit to go back.

$ sudo -i

Run as another user

$ sudo -u www-data ls /var/www

Help

--help and -h print a short summary of how to use sudo and all its options.

$ sudo --help
$ sudo -h

Version

--version and -V show which version of sudo is installed. -v does not show the version, it refreshes your cached password so you are not asked again for a while.

$ sudo --version
$ sudo -V

More about sudo

  • sudo -l lists what you are allowed to run
  • Always edit the sudoers file with sudo visudo, which checks the syntax before saving
  • Members of the sudo group (admin on older Ubuntu, wheel on Fedora) may use sudo
