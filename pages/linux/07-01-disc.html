Disc

Disks in Linux show up as device files in /dev, for example /dev/sda or /dev/nvme0n1, and each partition gets its own file like /dev/sda1. To use a partition it is mounted to a directory in the file system tree. Partitions mounted at boot are listed in /etc/fstab.

List disks and partitions

To list disks and partitions use lsblk, and df to see how full they are.

$ lsblk
$ df -h

Mount a disk

$ sudo mount /dev/sdb1 /mnt
$ sudo umount /mnt

Commands in this chapter

  • df — how much space is used and free on each file system
  • du — how much space files and directories use
  • lsblk — list disks and partitions
