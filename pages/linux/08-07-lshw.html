Lshw

lshw stands for list hardware. It shows a detailed overview of the hardware in the computer, such as the motherboard, CPU, memory, disks, network cards and graphics card. Run it with sudo to get complete information.

Show all hardware

$ sudo lshw

Short overview

-short shows one line per device, which is much easier to read.

$ sudo lshw -short

Show one type of hardware

-class (or -C) shows only one class of devices.

$ sudo lshw -C network     # network cards
$ sudo lshw -C display     # graphics cards
$ sudo lshw -C memory      # memory
$ sudo lshw -C disk        # disks

Save as a report

$ sudo lshw -html > hardware.html
$ sudo lshw -json > hardware.json

Help

lshw uses options with a single dash. -help prints a short summary of how to use it.

$ lshw -help

Version

-version shows which version of lshw is installed.

$ lshw -version

More about lshw

  • lspci lists PCI devices
  • lsusb lists USB devices
  • lsblk lists disks and partitions
