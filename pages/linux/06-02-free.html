Free

free shows how much memory and swap is used and free. The available column is an estimate of how much memory can be used by new programs without swapping.

Show memory usage

$ free

-h prints the values in human readable units like MB and GB.

$ free -h
               total        used        free      shared  buff/cache   available
Mem:            15Gi       4.1Gi       6.2Gi       512Mi       5.1Gi        10Gi
Swap:          2.0Gi          0B       2.0Gi

Update continuously

$ free -h -s 2    # print every 2 seconds
$ watch free -h

Help

--help prints a short summary of how to use free and all its options. -h does not show help, it shows the sizes in human readable form.

$ free --help

Version

--version and -V show which version of free is installed.

$ free --version
$ free -V

More about free

  • buff/cache is memory used for caching files; it is freed when programs need it
  • The numbers come from /proc/meminfo
  • vmstat shows memory, swap and CPU activity over time
