Mysql

MySQL is one of the most popular database servers. The server runs as a service, and the mysql command is the client used to connect to it and run SQL.

Start

$ sudo /etc/init.d/mysql start

Stop

$ sudo /etc/init.d/mysql stop

Restart

$ sudo /etc/init.d/mysql restart

Status

$ sudo /etc/init.d/mysql status

On systems with systemd the same can be done with systemctl.

$ sudo systemctl status mysql

Connect

-u gives the user and -p asks for the password.

$ mysql -u root -p
$ mysql -u root -p mydb

Backup and restore

$ mysqldump -u root -p mydb > mydb.sql
$ mysql -u root -p mydb < mydb.sql

Help

--help prints a short summary of how to use mysql and all its options. -h does not show help, it sets the host to connect to.

$ mysql --help

Version

--version and -V show which version of mysql is installed. -v does not show the version, it makes mysql print more details (verbose).

$ mysql --version
$ mysql -V
