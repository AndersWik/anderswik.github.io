OpenSSL

openssl is a toolkit for encryption, certificates and TLS. It can, among many other things, encrypt and decrypt files with a password.

Encrypting file

The basic form is the encryption type, the file to encrypt and the output file. You will be asked for a password.

$ openssl [encryption type] -in [file to encrypt]
$ openssl des3 -in file.txt -out encrypted.txt

DES3 is old. A stronger choice is AES-256 together with -pbkdf2, which makes the password much harder to guess.

$ openssl enc -aes-256-cbc -pbkdf2 -salt -in file.txt -out file.txt.enc

Decrypting files with OpenSSL

-d decrypts. Use the same encryption type and options as when the file was encrypted.

$ openssl des3 -d -in encrypted.txt -out normal.txt
$ openssl enc -d -aes-256-cbc -pbkdf2 -in file.txt.enc -out file.txt

Set md5 on decrypt

Older versions of OpenSSL used MD5 to turn the password into a key, while newer versions use SHA-256. To decrypt a file made with an old version, add this option.

-md md5
$ openssl des3 -d -md md5 -in encrypted.txt -out normal.txt

Other useful commands

$ openssl rand -base64 32                           # random password
$ openssl s_client -connect example.com:443         # test a TLS connection
$ openssl x509 -in cert.pem -noout -dates           # show certificate dates

Help

openssl help lists all subcommands. Each subcommand has its own help with -help.

$ openssl help
$ openssl enc -help

Version

The version is shown with the subcommand version. -a shows more details.

$ openssl version
$ openssl version -a
