Update

Keeping the system updated gives you bug fixes and security patches. On Debian and Ubuntu this is done with apt-get (or apt), and it is a good habit to update regularly.

Fetches the list of available updates

$ sudo apt-get update

Strictly upgrades the current packages

$ sudo apt-get upgrade

Installs updates (new ones). dist-upgrade can also install new dependencies and remove packages when needed, for example for a new kernel.

$ sudo apt-get dist-upgrade

Reboot

$ sudo reboot

Do it all at once

&& runs the next command only if the previous succeeded, and -y answers yes to all questions.

$ sudo apt-get update && sudo apt-get upgrade -y

Check if a reboot is needed

On Ubuntu this file exists when an update requires a reboot.

$ cat /var/run/reboot-required

Clean up

$ sudo apt-get autoremove
$ sudo apt-get autoclean

Help

--help and -h print a short summary of how to use apt-get and all its options.

$ apt-get --help
$ apt-get -h

Version

--version and -v show which version of apt-get is installed.

$ apt-get --version
$ apt-get -v

More about update

  • unattended-upgrades installs security updates automatically, see Automatic Security Updates
  • apt list --upgradable shows which packages have updates
  • See also Package Managers
