Cp

cp copies files and directories. The original stays where it is and a copy is created at the destination.

Copy a file

$ cp notes.txt notes-backup.txt
$ cp notes.txt Documents/

Copy a directory

-r copies a directory recursively, with everything in it.

$ cp -r website website-backup

Keep file attributes

-a (archive) copies recursively and keeps permissions, owners and timestamps. It is a good choice for backups.

$ cp -a /etc/nginx nginx-backup

Don't overwrite by mistake

$ cp -i notes.txt Documents/   # ask before overwriting
$ cp -u *.txt Documents/       # only copy if the source is newer

Help

--help prints a short summary of how to use cp and all its options.

$ cp --help

Version

--version shows which version of cp is installed. -v does not show the version, it makes cp print what it does (verbose).

$ cp --version

More about cp

  • -v prints each file as it is copied
  • For copying to other computers use scp or rsync
