Rsync

rsync copies and synchronizes files, locally or between computers over SSH. It only transfers the parts that have changed, so it is fast for backups and for keeping directories in sync.

Sync a directory

rsync

-a (archive) copies recursively and keeps permissions and timestamps, -v shows the files and -h uses readable sizes.

$ rsync -avh Documents/ /media/backup/Documents/

A trailing / on the source copies the content of the directory; without it the directory itself is copied into the destination.

Sync to a server

-z compresses the data during the transfer and -P shows progress and allows resuming.

$ rsync -avzP website/ user@example.com:/var/www/website/

Mirror and test first

--delete removes files in the destination that no longer exist in the source. Use -n (dry run) to see what would happen first.

$ rsync -avhn --delete Documents/ /media/backup/Documents/
$ rsync -avh --delete Documents/ /media/backup/Documents/

Help

--help and -h print a short summary of how to use rsync and all its options. -h only means help when it is used alone. Together with other options it means human readable sizes.

$ rsync --help
$ rsync -h

Version

--version and -V show which version of rsync is installed. -v does not show the version, it makes rsync print what it does (verbose).

$ rsync --version
$ rsync -V
