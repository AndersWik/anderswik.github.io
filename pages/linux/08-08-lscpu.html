Lscpu

lscpu stands for list CPU. It shows information about the processor: the model, architecture, number of cores and threads, speed, cache sizes and if it supports virtualization. It does not need sudo.

Show CPU information

$ lscpu
Architecture:            x86_64
CPU(s):                  12
Model name:              12th Gen Intel(R) Core(TM) i5-12400F
Thread(s) per core:      2
Core(s) per socket:      6
Socket(s):               1
CPU max MHz:             4400,0000
Virtualization:          VT-x
L3 cache:                18 MiB (1 instance)

CPU(s) is the number of threads the system can run at the same time. It is cores per socket × threads per core × sockets, here 6 × 2 × 1 = 12.

Find one value

$ lscpu | grep "Model name"
$ lscpu | grep Virtualization

One line per CPU

-e shows a table with one line for each CPU, which core and socket it belongs to and its current speed.

$ lscpu -e
CPU NODE SOCKET CORE L1d:L1i:L2:L3 ONLINE    MAXMHZ   MINMHZ      MHZ
  0    0      0    0 0:0:0:0          yes 4400,0000 800,0000 3615.907
  1    0      0    0 0:0:0:0          yes 4400,0000 800,0000 3731.043

Caches

-C shows details about the CPU caches.

$ lscpu -C

JSON output

-J prints the information as JSON, which is useful in scripts.

$ lscpu -J

Help

--help and -h print a short summary of how to use lscpu and all its options.

$ lscpu --help
$ lscpu -h

Version

--version and -V show which version of lscpu is installed.

$ lscpu --version
$ lscpu -V

More about lscpu

  • nproc prints only the number of CPUs
  • The values come from /proc/cpuinfo and /sys
  • In a virtual machine, lscpu shows the virtual CPU, not the real one
  • lshw shows the CPU together with the rest of the hardware
