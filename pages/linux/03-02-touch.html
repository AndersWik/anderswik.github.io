Touch

touch updates the access and modification time of a file. If the file does not exist it creates a new, empty file, which is what it is most often used for.

Create an empty file

$ touch notes.txt

Several files can be created at once.

$ touch one.txt two.txt three.txt
$ touch file{1..5}.txt

Update the timestamp

Running touch on an existing file sets its modification time to now without changing its content. -d sets a specific date instead.

$ touch existing.txt
$ touch -d "2024-01-01 12:00" existing.txt

Help

--help prints a short summary of how to use touch and all its options. -h does not show help, it changes a symbolic link instead of the file it points to.

$ touch --help

Version

--version shows which version of touch is installed.

$ touch --version

More about touch

  • -c only updates existing files and never creates new ones
  • -r other.txt copies the timestamp from another file
  • Use ls -l or stat to see the timestamps of a file
