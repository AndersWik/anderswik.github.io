Linux From Scratch

Linux From Scratch (LFS) is a free book with step by step instructions for building your own Linux system, entirely from source code. Instead of installing a ready made distribution, you compile every part yourself: the compiler, the C library, the shell, the core tools and the kernel. It takes time, but it is one of the best ways to learn how a Linux system really works.

Two editions

The book comes in two versions that differ in how the system starts and manages services. Pick one and follow it all the way.

  • SysVinit — the classic init system with simple shell scripts
  • systemd — the init system used by most distributions today

What you need

  • A working Linux system to build from, called the host. A normal desktop distribution or a virtual machine works fine
  • An empty partition for the new system. The book asks for at least 10 GB, but around 30 GB gives room to grow
  • Basic knowledge of the shell and of commands like tar, cd and sudo
  • Time. A full build takes many hours, and the book measures build times in SBU (Standard Build Unit), the time it takes to build the first package on your machine

Check the host system

The book starts with a small script, version-check.sh, that checks the host has the tools and versions needed, such as gcc, make, bison and python3. Copy it from the book and run it.

$ bash version-check.sh

Prepare the partition

Find the partition with lsblk, create a file system on it and mount it. The book uses the variable LFS for the mount point in every command, so set it in every new shell.

$ export LFS=/mnt/lfs
$ sudo mkfs -v -t ext4 /dev/sdb1
$ sudo mkdir -pv $LFS
$ sudo mount -v -t ext4 /dev/sdb1 $LFS

Make sure /dev/sdb1 is the right partition. mkfs erases everything on it.

Download the sources

The book has a list of all packages and patches. wget downloads them all, and md5sum checks that nothing is broken.

$ sudo mkdir -v $LFS/sources
$ sudo chmod -v a+wt $LFS/sources
$ wget --input-file=wget-list-sysv --continue --directory-prefix=$LFS/sources
$ cd $LFS/sources
$ md5sum -c md5sums

The build steps

The rest of the book is a long list of packages to unpack, configure, compile and install, in a specific order. Most packages follow the same pattern.

$ tar -xf package-1.0.tar.xz
$ cd package-1.0
$ ./configure --prefix=/usr
$ make
$ make install

The work is done in these stages:

  1. Create a user called lfs with a clean environment, so the host's settings do not leak into the build
  2. Build a cross toolchain: binutils, gcc and glibc that compile programs for the new system
  3. Build temporary tools with the cross toolchain
  4. Enter the new system with chroot, so it runs separated from the host
  5. Build the final system, package by package
  6. Configure the system: boot scripts, network, locale and /etc/fstab
  7. Compile the kernel and install the GRUB boot loader
  8. Reboot into your own Linux system

More about Linux From Scratch

  • Read the LFS book online
  • Beyond Linux From Scratch (BLFS) continues where LFS ends, with a graphical desktop, networking tools and much more
  • Automated Linux From Scratch (ALFS) runs the build steps from the book automatically
  • LFS has no help or version command of its own, since it is a book and not a program. Each package you build has its own --help and --version
  • For a smaller build, see Build a .deb package
