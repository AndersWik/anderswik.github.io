Files

In Linux almost everything is a file: documents and programs, but also directories, devices like disks in /dev and even information about running processes in /proc. Most configuration is stored in plain text files, so knowing how to create, read, search and edit files is the most important skill on the command line.

$ file

File names

File names are case sensitive, so notes.txt and Notes.txt are two different files. File extensions are only a convention; Linux looks at the content of a file to decide what it is. Names that start with a dot are hidden.

The file command tells you what kind of content a file has.

$ file notes.txt
notes.txt: ASCII text

Commands in this chapter

The commands below are grouped roughly by what they do:

  • Create and organize: touch, echo, mkdir, mv, cp, rm
  • Read: cat, less, head, tail
  • Edit: nano, vim, emacs
  • Search and process text: find, grep, wc, uniq, cut, awk, sed

Pipes and redirection

Commands can be combined. | sends the output of one command into the next, > writes output to a file and >> appends to it.

$ cat access.log | grep 404 | wc -l
$ ls > files.txt
$ echo "one more line" >> files.txt
