Pwd

pwd stands for print working directory. It prints the absolute path of the directory you are in right now.

Print working directory

$ pwd
/home/anders/Documents

Show the real path

If you have moved into a directory through a symbolic link, pwd shows the path of the link. -P shows the physical path with all links resolved.

$ pwd -P

Help

pwd is built into the shell. --help prints a short summary, the same as help pwd.

$ pwd --help

Version

The pwd built into the shell has no version, but the program /bin/pwd from GNU coreutils does.

$ /bin/pwd --version

More about pwd

  • The current directory is also stored in the $PWD variable, for example echo $PWD
  • The previous directory is stored in $OLDPWD
