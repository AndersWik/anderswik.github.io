Mkdir

mkdir stands for make directory. It creates one or more new directories.

Create a directory

$ mkdir projects
$ mkdir one two three

Create parent directories

-p creates every missing directory in the path, and does not complain if the directory already exists. This makes it safe to use in scripts.

$ mkdir -p projects/website/css

Set permissions

-m sets the permissions of the new directory directly. See chmod.

$ mkdir -m 700 private

Help

--help prints a short summary of how to use mkdir and all its options.

$ mkdir --help

Version

--version shows which version of mkdir is installed. -v does not show the version, it makes mkdir print what it does (verbose).

$ mkdir --version

More about mkdir

  • -v prints a message for every directory created
  • Brace expansion creates many directories at once: mkdir -p src/{css,js,img}
  • Remove empty directories with rmdir, or use rm with -r
