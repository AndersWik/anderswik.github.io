Top

top shows a live, updating view of the running processes and how much CPU and memory they use. The top of the screen shows the uptime, load average and total memory usage.

Start top

$ top

Keys

  • P — sort by CPU usage
  • M — sort by memory usage
  • k — kill a process (asks for the PID)
  • u — only show one user's processes
  • 1 — show every CPU core
  • q — quit

Options

$ top -u anders         # only processes from user anders
$ top -n 1 -b | head    # print one snapshot, useful in scripts

Help

top has no --help. -h prints the version and a short usage line. While top is running, press h to see all keys.

$ top -h

Version

top has no --version. -v shows the version, the same output as -h.

$ top -v

More about top

  • htop is a more colourful and easier to use version (sudo apt install htop)
  • btop is another modern alternative with graphs

Manual

  • man top
