Dmesg

dmesg prints the kernel's message buffer. It shows what the kernel has detected and done since boot: hardware, drivers, disks, USB devices and errors. It is the first place to look when hardware doesn't work.

Show kernel messages

dmesg

On many systems reading the buffer requires root.

$ sudo dmesg

Readable output

$ sudo dmesg -T          # human readable time stamps
$ sudo dmesg -H          # pager and colours
$ sudo dmesg -l err,warn # only errors and warnings

Follow new messages

Run this and plug in a USB device to see how the kernel detects it.

$ sudo dmesg -w

Help

--help and -h print a short summary of how to use dmesg and all its options.

$ dmesg --help
$ dmesg -h

Version

--version and -V show which version of dmesg is installed.

$ dmesg --version
$ dmesg -V
