Head

head prints the first lines of a file, by default the first 10. It is useful to get a quick look at a large file or the start of a command's output.

Print the first lines

$ head notes.txt

-n sets the number of lines.

$ head -n 5 notes.txt

Use with other commands

$ ls -lt | head -n 5     # the five newest files

Help

--help prints a short summary of how to use head and all its options.

$ head --help

Version

--version shows which version of head is installed. -v does not show the version, it prints the file name above the output.

$ head --version

More about head

  • -c 100 prints the first 100 bytes instead of lines
  • head -n -5 prints everything except the last 5 lines
  • The opposite command is tail
