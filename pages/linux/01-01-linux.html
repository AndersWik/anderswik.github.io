Linux

Linux is a free and open source operating system built around the Linux kernel, first released by Linus Torvalds in 1991. It is shipped as distributions such as Ubuntu, Debian, Fedora and Arch, each bundling the kernel with tools, a package manager and often a desktop environment. Most of the work on a Linux server is done in a terminal, by typing commands into a shell.

Every command follows the same basic shape: the name of the program, optional flags that change its behaviour, and the arguments it works on.

$ command -flags arguments
$ ls -l /home

Linux release

To see which distribution and version you are running, use lsb_release. The -a flag prints all information: distributor, description, release number and codename.

$ lsb_release -a

Another way, which works on almost every modern distribution, is to read the os-release file.

$ cat /etc/os-release

Linux update

On Debian based systems like Ubuntu the package manager apt-get keeps the system up to date. First refresh the list of available packages, then upgrade. A reboot is sometimes needed, for example after a kernel update. Read more in Update.

$ sudo apt-get update         # Get list of available updates
$ sudo apt-get upgrade        # Only upgrade the current packages
$ sudo apt-get dist-upgrade   # Installs new updates

$ sudo reboot		              # Reboot

Remove old Kernels

Over time old kernels and cached package files fill up the disk. autoclean removes downloaded package files that can no longer be downloaded, and autoremove removes packages, such as old kernels, that were installed as dependencies and are no longer needed.

$ sudo apt-get autoclean && sudo apt-get autoremove

Truncate a file

Redirecting the empty device /dev/null into a file empties it without deleting it. This is handy for log files that a running program still has open.

$ cat /dev/null > filename

The truncate command does the same thing more explicitly.

$ truncate -s 0 filename
