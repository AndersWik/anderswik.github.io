Lspci

lspci lists the devices connected to the PCI bus, such as graphics cards, network cards, sound cards and USB controllers. It is useful to find out what hardware a computer has and which driver it uses.

List devices

$ lspci

Show drivers

-k shows the kernel driver in use for each device.

$ lspci -k

Find a device

$ lspci | grep -i vga        # graphics card
$ lspci | grep -i network

More details

$ lspci -v     # verbose
$ lspci -nn    # show vendor and device ids, useful when searching for drivers

Help

lspci has no help option, but any option it does not know, for example --help, makes it print a list of all options.

$ lspci --help

Version

--version shows which version of lspci is installed. -v does not show the version, it makes lspci show more details (verbose).

$ lspci --version

More about lspci

  • lsusb does the same for USB devices
  • lshw shows a full overview of the hardware
