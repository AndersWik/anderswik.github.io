Uptime

uptime prints the current time, how long the system has been running, how many users are logged in, and the load average for the last 1, 5 and 15 minutes.

Show uptime

$ uptime
 14:02:11 up 12 days,  3:41,  2 users,  load average: 0.52, 0.48, 0.45

Readable output

$ uptime -p    # up 1 week, 5 days, 3 hours
$ uptime -s    # the time the system started

Load average

The load average is the number of processes running or waiting for the CPU. As a rule of thumb, a load higher than the number of CPU cores (see nproc) means the system is overloaded.

Help

--help and -h print a short summary of how to use uptime and all its options.

$ uptime --help
$ uptime -h

Version

--version and -V show which version of uptime is installed.

$ uptime --version
$ uptime -V

More about uptime

  • The same load numbers are shown at the top of top
  • The values come from /proc/loadavg
