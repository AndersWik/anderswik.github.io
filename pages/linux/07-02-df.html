Df

df can be used to check disk usage. The name stands for disk free, and it reports how much space is used and available on each mounted file system.

Using df

df -H will report how much space is used, available, percentage used, and the mount point of every disk attached to your system. Lower case -h uses powers of 1024 (GiB) and upper case -H uses powers of 1000 (GB).

df -h

Check one disk

Give a path to see the file system it is on.

$ df -h /home
$ df -h .

Show file system type and inodes

$ df -hT       # include the file system type, like ext4
$ df -i        # inode usage; a disk can be "full" when it runs out of inodes

Help

--help prints a short summary of how to use df and all its options. -h does not show help, it shows the sizes in human readable form.

$ df --help

Version

--version shows which version of df is installed.

$ df --version

More about df

  • df shows the totals; use du to find what is using the space
  • ncdu is an interactive tool to explore disk usage

Manual

  • man df
