Info

info reads documentation in the Info format, which is used by the GNU project. Info documents are often longer and more detailed than man pages, and are divided into nodes that link to each other, a bit like web pages. If a program has no Info document, info shows its man page instead.

Read a document

Without arguments info opens the directory of all installed documents. Give a name to open a specific one.

$ info
$ info coreutils

Go to a node

Give more names to jump directly to a node inside a document, for example the section about ls in the coreutils manual.

$ info coreutils ls

Move around

  • Space and Backspace — scroll forward and back
  • n and p — next and previous node
  • u — up to the parent node
  • Tab and Enter — move to a link and follow it
  • l — go back to the last visited node
  • s — search for text
  • h — show help
  • q — quit

Search the documents

-k searches the indexes of all Info documents, similar to man -k.

$ info -k copy

Export a document to a text file

-o writes the document to a file instead of opening it.

$ info coreutils -o coreutils.txt

Help

--help and -h print a short summary of how to use info and all its options.

$ info --help
$ info -h

Version

--version shows which version of info is installed.

$ info --version

More about info

  • Programs from the GNU project, such as bash, grep, sed and coreutils, have the most complete Info documents
  • The GNU manuals can also be read online at gnu.org/manual
  • For short examples, see tldr

Manual

  • man info
