User

Linux is a multi user system. Every file and every running process belongs to a user and a group, and permissions decide who can read, write and run what. The user root is the administrator and can do anything; normal users borrow root's powers with sudo when they need to.

Users and groups

Users are listed in /etc/passwd and groups in /etc/group. A user can be a member of many groups, which is how access to things like Docker or serial ports is given.

$ cat /etc/passwd
$ groups

Add a user

$ sudo adduser anna
$ sudo usermod -aG sudo anna    # give anna sudo rights

Permissions

ls -l shows the permissions of a file as three groups of rwx: for the owner, the group and everyone else.

$ ls -l script.sh
-rwxr-x--- 1 anders staff 120 Jan 1 12:00 script.sh
