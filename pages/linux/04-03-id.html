Id

id prints the user id (uid), group id (gid) and all groups of a user. Without arguments it shows information about the current user.

Show user and groups

$ id
uid=1000(anders) gid=1000(anders) groups=1000(anders),27(sudo)

Show another user.

$ id anna

Print one value

$ id -u    # user id
$ id -gn   # name of the primary group
$ id -Gn   # names of all groups

Help

--help prints a short summary of how to use id and all its options.

$ id --help

Version

--version shows which version of id is installed.

$ id --version

More about id

  • The root user always has uid 0
  • After being added to a new group you have to log out and in again before id shows it
