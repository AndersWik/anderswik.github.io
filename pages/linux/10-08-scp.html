Scp

scp (secure copy) copies files between computers over SSH. It works like cp, but one of the paths can be on another computer, written as user@host:path.

Copy from a server

Download a database dump from the home directory on the server to the current directory.

$ scp username@domain.se:~/domain.se/sqldumpname.sql ./localsqldumpname.sql

Copy to a server

$ scp backup.tar.gz username@domain.se:~/backups/

Copy a directory

$ scp -r website username@domain.se:~/

Other port

Note that scp uses a capital -P for the port.

$ scp -P 2222 file.txt username@domain.se:~/

More about scp

  • Hosts defined in ~/.ssh/config also work with scp, see ssh
  • For large or repeated copies rsync is faster since it only sends changes
