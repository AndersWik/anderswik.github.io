Ss

ss shows socket statistics: open network connections and which ports programs are listening on. It replaces the older netstat.

Show connections

ss

Listening ports

The most used combination. -t TCP, -u UDP, -l listening, -n numeric ports and -p the program using the port (needs sudo for other users' programs).

$ sudo ss -tulpn

Find what uses a port

$ sudo ss -tlpn | grep :80

Established connections

$ ss -tn state established

Help

--help and -h print a short summary of how to use ss and all its options.

$ ss --help
$ ss -h

Version

--version and -V show which version of ss is installed.

$ ss --version
$ ss -V

More about ss

  • ss -s prints a summary of all sockets
  • lsof -i :80 is another way to see what uses a port

  • man ss
