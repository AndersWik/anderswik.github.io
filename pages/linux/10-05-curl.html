Curl

curl transfers data to and from servers. It supports many protocols, but is mostly used to send HTTP requests: download pages, test APIs and look at headers. By default it prints the response to the terminal.

Get ip on server with cUrl

ipinfo.io/ip answers with the public IP address of the computer making the request.

$ curl ipinfo.io/ip

Download a file

-O saves with the remote name and -o with a name you choose. -L follows redirects.

$ curl -LO https://example.com/file.zip
$ curl -L -o page.html https://example.com

Show headers

$ curl -I https://example.com     # only headers
$ curl -v https://example.com     # all details of the request

Send data to an API

$ curl -X POST -H "Content-Type: application/json" \
       -d '{"name": "Anders"}' https://api.example.com/users

Help

--help and -h print a short summary of the most used options. Add all to see every option.

$ curl --help
$ curl -h
$ curl --help all

Version

--version and -V show which version of curl is installed. -v does not show the version, it shows the request and response headers (verbose).

$ curl --version
$ curl -V

More about curl
