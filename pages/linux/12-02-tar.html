Tar

tar (tape archive) bundles files and directories into one archive file and extracts them again. Together with a compression flag it creates compressed archives like .tar.gz.

Create an archive

$ tar

-c creates, -z compresses with gzip, -v lists the files and -f gives the archive name, which must come right after -f.

$ tar -czvf backup.tar.gz Documents/

Extract an archive

$ tar -xzvf backup.tar.gz
$ tar -xzvf backup.tar.gz -C /tmp/restore   # extract to another directory

Modern versions of tar detect the compression by themselves.

$ tar -xf archive.tar.xz

List the content

$ tar -tzvf backup.tar.gz

Help

--help prints a short summary of how to use tar and all its options. -h does not show help, it follows symbolic links.

$ tar --help

Version

--version shows which version of tar is installed. -v does not show the version, it makes tar list the files it handles (verbose).

$ tar --version

More about tar

  • -j uses bzip2 (.tar.bz2) and -J uses xz (.tar.xz)
  • --exclude="node_modules" leaves out files
  • Remember: c = create, x = extract, t = list
