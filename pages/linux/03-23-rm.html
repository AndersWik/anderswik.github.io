Rm

rm removes files and directories. There is no trash can on the command line: removed files are gone, so be careful, especially with wildcards and sudo.

Remove files

$ rm notes.txt
$ rm *.tmp

Remove directories

-r removes a directory and everything in it. -f never asks and ignores missing files. Double check the path before running rm -rf.

$ rm -r old-project
$ rm -rf node_modules

An empty directory can also be removed with rmdir.

$ rmdir empty-dir

Ask before removing

$ rm -i *.txt

Help

--help prints a short summary of how to use rm and all its options.

$ rm --help

Version

--version shows which version of rm is installed. -v does not show the version, it makes rm print what it does (verbose).

$ rm --version

More about rm

  • Run ls with the same pattern first to see what will be removed
  • -v prints each file as it is removed
  • trash-cli (trash-put) moves files to the desktop trash instead of deleting them
