History

history lists the commands you have typed in the shell, each with a number. Bash saves the history in ~/.bash_history, so it is kept between sessions.

Show history

$ history

Only show the last 10 commands.

$ history 10

Search history

Pipe the history to grep to find a command you ran before.

$ history | grep ssh

You can also press Ctrl + r and start typing to search the history interactively. Press Ctrl + r again to step to older matches.

Run a command again

!! runs the previous command again. It is often used to repeat a command with sudo. ! followed by a number runs that line from the history.

$ sudo !!
$ !42

Clear history

$ history -c

Help

history is built into the shell, so it has no -h option. --help prints a short summary, the same as help history.

$ history --help

More about history

  • The size of the history is set by the HISTSIZE and HISTFILESIZE variables in ~/.bashrc
  • history is a shell builtin, so its documentation is also found with help history

Manual

  • man history
