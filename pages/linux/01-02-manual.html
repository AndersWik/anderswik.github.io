Man

man shows the manual page for a command. Almost every program on Linux ships with a manual describing what it does, every flag it accepts and often examples. When you are unsure how a command works, the manual is the first place to look.

Read a manual

Give the name of the command you want to read about. The page opens in a pager, so use the arrow keys or Space to scroll, / to search and q to quit.

$ man
$ man ls

Search the manuals

If you don't remember the name of a command, -k searches the short descriptions of all manual pages. This is the same as the apropos command.

$ man -k copy

Manual sections

The manual is divided into numbered sections, for example 1 for user commands, 5 for file formats and 8 for system administration. If the same name exists in several sections, give the section number first.

$ man 5 crontab

Quick help

Many commands also print a short summary of their flags with --help.

$ ls --help

Export a manual to a text file

A manual page can be saved as plain text. col -bx strips the bold and underline formatting. This is how the pages under Man pages are made.

$ MANWIDTH=80 man mokutil 2>/dev/null | col -bx > mokutil.txt

Help

--help and -h print a short summary of how to use man and all its options.

$ man --help
$ man -h

Version

--version and -V show which version of man is installed.

$ man --version
$ man -V

More about man

  • info — longer GNU documentation for some programs, for example info coreutils
