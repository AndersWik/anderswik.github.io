Databases

A database stores data in an organized way so programs can search and update it quickly. Most websites use one. On Linux the most common databases are MySQL and its fork MariaDB, PostgreSQL, and SQLite, which keeps a whole database in a single file.

Install a database server

$ sudo apt install mariadb-server
$ sudo apt install postgresql

Backups

Database files should not be copied while the server runs. Use the dump tools instead, which write the database as SQL.

$ mysqldump -u root -p mydb > mydb.sql

Commands in this chapter

  • mysql — start, stop and use MySQL
