Ping

ping sends small ICMP packets to another computer and measures how long it takes to get an answer. It is the simplest way to test if a host can be reached.

Ping a host

On Linux ping keeps going until you press Ctrl + c.

$ ping example.com

Send a set number of packets

$ ping -c 4 example.com

Troubleshoot step by step

Ping the router, then an IP on the internet, then a name. If the IP works but the name doesn't, the problem is DNS.

$ ping -c 4 192.168.1.1
$ ping -c 4 8.8.8.8
$ ping -c 4 google.com

Help

ping has no --help. -h prints a short summary of all options.

$ ping -h

Version

-V shows which version of ping is installed. -v does not show the version, it makes ping print more details.

$ ping -V

More about ping

  • -i 0.5 changes the interval between packets
  • Some servers block ping, so no answer doesn't always mean the server is down
  • mtr combines ping and traceroute to show where packets are lost
