Wget

wget downloads files from the web over HTTP, HTTPS and FTP. It works without a user interface, can resume broken downloads and can even download whole websites.

Download a file

The file is saved in the current directory with its original name.

$ wget <url>
$ wget https://www.anderswik.se/assets/images/github.svg

Save with another name

$ wget -O octocat.svg https://www.anderswik.se/assets/images/github.svg

Resume and run in the background

$ wget -c https://example.com/big.iso   # continue a broken download
$ wget -b https://example.com/big.iso   # download in the background

Download many files

Put one URL per line in a file.

$ wget -i urls.txt

Help

--help and -h print a short summary of how to use wget and all its options.

$ wget --help
$ wget -h

Version

--version and -V show which version of wget is installed. -v does not show the version, it makes wget print what it does (verbose).

$ wget --version
$ wget -V

More about wget

  • -q makes wget quiet
  • --mirror downloads a website for offline use
  • For working with APIs, curl is usually a better fit
