Whoami

whoami prints the name of the user you are currently running commands as. It is useful after switching users or inside scripts.

Print the current user

$ whoami
anders
$ sudo whoami
root

Help

--help prints a short summary of how to use whoami and all its options.

$ whoami --help

Version

--version shows which version of whoami is installed.

$ whoami --version

More about whoami

  • The same name is stored in the $USER variable
  • who lists everyone who is logged in to the machine
  • id shows the user together with its groups
