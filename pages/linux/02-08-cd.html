Cd

cd stands for change directory. It moves you to another directory in the file system. Without arguments it takes you to your home directory.

Change directory

Move into a directory with a relative or an absolute path.

$ cd Documents
$ cd /var/log

Move up

.. is the parent directory. They can be chained to move up several levels.

$ cd ..
$ cd ../..

Go home or back

~ is your home directory and - takes you back to the directory you were in before.

$ cd ~
$ cd -

Paths with spaces

Put quotes around a path that contains spaces, or escape each space with a backslash. Press Tab to let the shell complete the name for you.

$ cd "My Documents"
$ cd My\ Documents

Help

cd is built into the shell, so it has no -h option and no version. --help prints a short summary, the same as help cd.

$ cd --help

More about cd

  • cd is built into the shell, so help cd also shows its documentation
  • pushd and popd remember a stack of directories you can jump back to
