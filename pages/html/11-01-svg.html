SVG

SVG (Scalable Vector Graphics) is images made of shapes instead of pixels. They are sharp at every size, and the files are often small. SVG is used for logos, icons and charts.

SVG in the HTML

SVG can be written directly in the page. viewBox is the coordinate system of the drawing, and width and height the size on the page:

<svg width="120" height="120" viewBox="0 0 120 120">
  <rect x="10" y="10" width="100" height="100" rx="12" fill="lightblue" />
  <circle cx="60" cy="60" r="30" fill="tomato" />
  <path d="M30 95 L60 70 L90 95" stroke="navy" stroke-width="4" fill="none" />
</svg>

SVG as an image

An SVG file can be used like any other image:

<img src="logo.svg" alt="My logo" width="200" height="50">

As an <img>, the SVG can't be changed by the page's CSS or JavaScript. Written in the page, every shape is an element that you can style, animate and click.

Icons that follow the text color

currentColor uses the text color, so the icon changes color with the link it is in:

<a href="/">
  <svg width="16" height="16" viewBox="0 0 16 16" aria-hidden="true">
    <path d="M8 1 L15 8 L13 8 L13 15 L3 15 L3 8 L1 8 Z" fill="currentColor" />
  </svg>
  Home
</a>
