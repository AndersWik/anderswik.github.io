File paths

A file path is the address of a file, like an image or another page. It is used in href, src and other attributes.

Absolute address

The full address, with the site. Use it for other sites:

<img src="https://www.example.com/images/cat.jpg" alt="A cat">

From the root of the site

Starts with /. Read from the top folder of the site, wherever the page is:

<img src="/images/cat.jpg" alt="A cat">

From the page

No / at the start. Read from the folder of the page:

<img src="cat.jpg" alt="A cat">           <!-- the same folder -->
<img src="images/cat.jpg" alt="A cat">    <!-- a folder in this folder -->
<img src="../cat.jpg" alt="A cat">        <!-- the folder above -->

Good to know

  • On most web servers, file names are case-sensitive: Cat.jpg and cat.jpg are different files. Use lower case only.
  • Don't use spaces in file names. A space is written %20 in an address, which is easy to get wrong. Use - instead. Url encode / decode shows how other characters are written.
  • / paths don't work when you open the page as a file, without a web server. Use paths from the page then, or start a local web server.
