Charset

The charset (character set, or encoding) tells the browser how the bytes in the file are turned into characters. Always use UTF-8, and write it first in the <head>:

<head>
  <meta charset="utf-8">
  ...
</head>

Why

UTF-8 has every character, in every language: å, ä, ö, é, ß, 中文, emojis. With the wrong charset, the browser shows wrong characters, like Ã¥ instead of å.

Good to know

  • The editor must also save the file as UTF-8. This is the default in VS Code, and is shown at the bottom right of the window.
  • <meta charset> must be in the first 1024 bytes of the file, so put it first in the <head>.
  • With UTF-8, you can type special characters directly instead of writing entities.
