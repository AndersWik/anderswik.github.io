Canvas

<canvas> is an empty area to draw on. Everything in it is drawn with JavaScript. In HTML, it is only the element, its size and a text for browsers that can't show it:

<canvas id="drawing" width="300" height="150">
  A red square.
</canvas>

<script>
  const canvas = document.getElementById("drawing");
  const ctx = canvas.getContext("2d");
  ctx.fillStyle = "red";
  ctx.fillRect(100, 25, 100, 100);
</script>

Width and height

width and height are the number of pixels you draw on, 300 × 150 if they are missing. CSS width and height only stretch the result. A canvas that is only made larger with CSS looks blurry, so set the size with the attributes.

Accessibility

Screen readers can't see what is drawn. Describe it in the text between the tags, or with aria-label.

Canvas or SVG?

  • SVG is shapes as elements. Use it for icons, logos, diagrams and charts that you can style and click.
  • Canvas is pixels. Use it for games, animation and image editing, where thousands of things move and are drawn again many times a second.

Learn to draw on a canvas

The games on this site are drawn on a canvas. The Pong tutorial shows how, step by step: drawing shapes, moving them with requestAnimationFrame, and the keyboard.
