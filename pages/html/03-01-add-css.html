Add CSS

CSS decides how the HTML looks. There are three ways to add it to a page.

In a separate file

The best way. Write the CSS in a file, style.css, and link it in the <head>:

<head>
  <link rel="stylesheet" href="style.css">
</head>
h1 {
  color: navy;
}

The same file can be used by every page of the site, so a change in one place changes them all. The browser also keeps the file in its cache.

In a style element

CSS for one page can be written in a <style> element in the <head>:

<head>
  <style>
    h1 {
      color: navy;
    }
  </style>
</head>

In a style attribute

CSS for one element can be written in its style attribute. Use this for quick tests only. It is hard to find and change later.

<h1 style="color: navy;">Heading</h1>

Which one wins?

If the same thing is set in several places, the style attribute wins. Between the file and the <style> element, the one that comes last in the HTML wins.
