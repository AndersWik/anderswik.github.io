Colors

Colors are set with CSS: color for the text and background-color for the background.

<p style="color: white; background-color: tomato;">White text on red.</p>

Ways to write a color

color: tomato;                  /* a name, there are 148 */
color: #ff6347;                 /* hex: red, green, blue from 00 to ff */
color: #f63;                    /* short hex, the same as #ff6633 */
color: rgb(255 99 71);          /* red, green, blue from 0 to 255 */
color: hsl(9 100% 64%);         /* hue, saturation, lightness */

Transparency

Add a fourth value for the alpha, from 0 (invisible) to 1 (solid):

background-color: rgb(255 99 71 / 0.5);
background-color: #ff634780;    /* 80 in hex is about 0.5 */

Which one to use?

  • Hex is the most common, and what design programs give you.
  • HSL is the easiest to change by hand: change the lightness to get a lighter or darker version of the same color.
  • Names are handy for quick tests.

Try colors and convert between the formats with Colorhex.
