Div and span

<div> and <span> are containers with no meaning of their own. They are used to group content, so it can be styled with CSS or found with JavaScript.

Div

<div> is a block container. Use it to group larger parts of a page:

<div class="card">
  <h2>Card title</h2>
  <p>Some text in the card.</p>
</div>

Span

<span> is the inline version. Use it to mark a few words inside a line of text:

<p>The price is <span class="price">99 kr</span> today.</p>

Use the right element first

Before you use a <div>, check if there is an element that says what the content is: <header>, <nav>, <main>, <article>, <section> or <footer>. The same goes for <span>: <strong>, <em> or <time> may fit better. Screen readers and search engines understand those. See Semantic elements.
