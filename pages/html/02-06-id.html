Id

The id attribute gives an element a name that is unique: only one element on the page may have it.

<section id="contact">
  <h2>Contact</h2>
</section>

What it is used for

  • Bookmarks: <a href="#contact"> jumps to the element. See Bookmarks.
  • Labels: <label for="email"> belongs to the input with id="email".
  • CSS: #contact { ... } styles the element.
  • JavaScript: document.getElementById("contact") finds it.

Id or class?

Use id for one special element, like a part of the page you link to or a form field. Use class for things that can occur many times, like all the cards or all the warnings. In CSS, use classes for styling. An id selector is stronger than a class, which makes it hard to change later.

Names

An id can't have spaces. It is case-sensitive, so Contact and contact are different ids.
