Forms

<form> collects input from the user and sends it to a server:

<form action="/search" method="get">
  <label for="q">Search</label>
  <input type="search" id="q" name="q">
  <button>Search</button>
</form>

When you press the button, the browser goes to /search?q=what+you+typed.

Name

Every field that is sent needs a name. The name and the value are sent as a pair, q=cake. A field without name is not sent.

GET or POST

  • method="get" puts the data in the address, after ?. Use it for searches and filters, so the result can be bookmarked and shared.
  • method="post" sends the data in the request, not in the address. Use it when something is saved or changed, like an order, and for passwords.

Without a server

A form doesn't need a server. JavaScript can listen for the submit event and use the data on the page:

form.addEventListener("submit", function (event) {
  event.preventDefault();          // don't send the form
  const data = new FormData(form);
  console.log(data.get("q"));
});
