Table headers

<th> is a header cell. It describes the other cells in its column or row.

Column and row headers

scope tells which cells the header is for: col for the column below it, row for the row next to it. Screen readers use it to read the header with each cell.

<table>
  <tr>
    <th scope="col">Day</th>
    <th scope="col">Open</th>
    <th scope="col">Close</th>
  </tr>
  <tr>
    <th scope="row">Monday</th>
    <td>08:00</td>
    <td>17:00</td>
  </tr>
  <tr>
    <th scope="row">Saturday</th>
    <td>10:00</td>
    <td>14:00</td>
  </tr>
</table>

Caption

<caption> is the title of the table. It must be the first thing in the <table>:

<table>
  <caption>Opening hours</caption>
  ...
</table>
