Page title

<title> is the name of the page. It goes in the <head>, and every page must have one:

<head>
  <title>Chocolate cake - Recipes - My website</title>
</head>

Where it is shown

  • In the browser tab.
  • As the name of a bookmark.
  • As the link in the results of search engines.
  • Read by screen readers when the page opens.

A good title

  • Say what is on this page, not only the name of the site.
  • Put the most important words first. A tab only has room for the start of the title.
  • Give every page its own title.

JavaScript can change the title with document.title = "New title". The Pomodoro timer shows the time left in the tab this way.
