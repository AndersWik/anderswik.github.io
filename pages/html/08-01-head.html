Head

<head> holds information about the page. It is not shown on the page, but the browser, search engines and social media read it.

<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Recipes - My website</title>
  <meta name="description" content="Simple recipes for every day.">
  <link rel="icon" href="/favicon.svg">
  <link rel="stylesheet" href="/style.css">
  <script src="/script.js" defer></script>
</head>

What goes in the head

  • <meta charset>, the character set. See Charset.
  • <meta name="viewport">, the size on phones. See Viewport.
  • <title>, the name in the tab. See Page title.
  • <meta name="description">, the text search engines often show below the title.
  • <link>, for example the style sheet and the favicon.
  • <style> and <script>.

Scripts

A <script> in the head stops the page from showing until the script has loaded. defer loads it at the same time, and runs it when the page is ready. The other way is to put the <script> at the end of the <body>.
