Links

<a> makes a link. href is where the link goes, and the content is what you click:

<a href="https://www.anderswik.se/">My website</a>

Links to other pages

<a href="https://example.com/">Another site</a>
<a href="/html/">A page on this site</a>
<a href="images.html">A page in the same folder</a>

See File paths for how the address is read.

Open in a new tab

target="_blank" opens the link in a new tab. Use it sparingly, most people prefer to choose for themselves.

<a href="https://example.com/" target="_blank">Opens in a new tab</a>

Email, phone and download

<a href="mailto:name@example.com">Send an email</a>
<a href="tel:+46701234567">Call us</a>
<a href="report.pdf" download>Download the report</a>

Link text

Write link text that says where the link goes. "Read the price list" is better than "click here". Screen reader users often list all the links on a page, without the text around them.
