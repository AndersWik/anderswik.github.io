Paragraphs

<p> is a paragraph of text. The browser adds some space before and after it.

<p>This is the first paragraph.</p>
<p>This is the second paragraph.</p>

White space

The browser shows several spaces and line breaks as one space. These two paragraphs look the same:

<p>One two three.</p>
<p>One
      two
   three.</p>

Line break

<br> breaks the line without starting a new paragraph. Use it where the line break is part of the content, like in a poem or an address. Don't use it to make space, use CSS for that.

<p>Storgatan 1<br>
123 45 Stockholm</p>

Horizontal rule

<hr> is a break between topics. It is shown as a line.

<p>The end of the first part.</p>
<hr>
<p>The second part.</p>

Preformatted text

<pre> keeps all spaces and line breaks, and uses a font where all characters are the same width. It is used for code and text art.

<pre>
  /\_/\
 ( o.o )
</pre>
