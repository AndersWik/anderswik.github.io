Tables

<table> shows data in rows and columns. Each row is a <tr>, and each cell a <td>:

<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Anna</td>
    <td>34</td>
  </tr>
  <tr>
    <td>Erik</td>
    <td>28</td>
  </tr>
</table>

<th> is a header cell, shown in bold. See Table headers.

Head, body and foot

Large tables can be split in three parts:

<table>
  <thead>
    <tr><th>Month</th><th>Sales</th></tr>
  </thead>
  <tbody>
    <tr><td>January</td><td>100</td></tr>
    <tr><td>February</td><td>120</td></tr>
  </tbody>
  <tfoot>
    <tr><td>Total</td><td>220</td></tr>
  </tfoot>
</table>

When a long table is printed, the head and foot are repeated on every page.

Tables are for data

Use tables for data that has rows and columns, like a price list or a timetable. Don't use them to place things on the page, use CSS for that.

A table has no lines between the cells until you add them with CSS:

table { border-collapse: collapse; }
th, td { border: 1px solid #ccc; padding: 4px 8px; }
