Input attributes

Attributes change how an input works, and what values it accepts.

<input type="text" name="username" value="anna" placeholder="Your user name"
       required minlength="3" maxlength="20" autocomplete="username">

Value and help

  • value, the value the field starts with.
  • placeholder, a hint shown when the field is empty. It disappears when you type, so it can't replace the <label>.
  • autocomplete, tells the browser what to fill in, like email, name or new-password.
  • autofocus, puts the cursor in the field when the page opens.

Checks

The browser checks these when the form is sent, and shows a message:

  • required, the field can't be empty.
  • minlength and maxlength, the length of the text.
  • min, max and step, for numbers and dates.
  • pattern, a regular expression the value must match.
<input type="text" name="zip" pattern="[0-9]{3} ?[0-9]{2}" title="Like 123 45">

Always check the values on the server too. Anyone can turn off the checks in the browser.

Disabled or read-only

  • disabled, the field can't be used, and is not sent.
  • readonly, the field can't be changed, but is sent.

A field outside the form

form connects a field to a form by its id, even if the field is somewhere else on the page:

<form id="signup">...</form>
<input type="email" name="email" form="signup">
