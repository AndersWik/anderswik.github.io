Images

<img> shows an image. src is the address of the image file, and alt is a text that describes it:

<img src="cat.jpg" alt="A grey cat sleeping on a sofa" width="600" height="400">

Alt text

alt is read by screen readers, and shown if the image can't load. Describe what the image shows, as you would on the phone. If the image is only decoration, write an empty alt="", so screen readers skip it.

Width and height

Write the size of the image in width and height. Then the browser saves the space before the image has loaded, and the page doesn't jump. CSS can still make it smaller, as long as the shape stays the same.

Load later

loading="lazy" waits with the image until you scroll near it. This makes long pages with many images faster:

<img src="big-photo.jpg" alt="..." width="1200" height="800" loading="lazy">

Image with a caption

<figure>
  <img src="chart.png" alt="Sales went up in March" width="600" height="300">
  <figcaption>Sales in the first quarter.</figcaption>
</figure>

File types

JPEG for photos, PNG for screenshots and images with sharp edges, SVG for logos and icons, and WebP or AVIF for smaller files of both photos and graphics.
