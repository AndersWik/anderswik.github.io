Input types

<input> is a field, and type decides what kind. The browser shows the right keyboard on phones, and checks the value.

<input type="text" name="name">
<input type="email" name="email">
<input type="password" name="password">
<input type="number" name="age" min="0" max="120">
<input type="tel" name="phone">
<input type="url" name="website">
<input type="search" name="q">

Date and time

<input type="date" name="day">
<input type="time" name="start">
<input type="datetime-local" name="meeting">

Choose

<label><input type="checkbox" name="terms"> I accept the terms</label>

<label><input type="radio" name="size" value="s"> Small</label>
<label><input type="radio" name="size" value="l"> Large</label>

Radio buttons with the same name belong together: only one can be checked.

Other types

<input type="range" name="volume" min="0" max="10">
<input type="color" name="color" value="#ff6347">
<input type="file" name="photo" accept="image/*">
<input type="hidden" name="id" value="42">

hidden is not shown, but is sent with the form.
