HTML

HTML (HyperText Markup Language) describes the content of a web page: which text is a heading, which is a paragraph, where a link goes and where an image is. The browser reads the HTML and shows the page.

HTML is written with tags in angle brackets. Most tags come in pairs around the content they describe:

<h1>My first heading</h1>
<p>This is a paragraph with a <a href="/html/">link</a>.</p>

HTML, CSS and JavaScript

A web page is usually made of three languages, each with its own job:

  • HTML is the content and its structure.
  • CSS is how it looks: colors, fonts, sizes and layout.
  • JavaScript is what it does: things that change when you click, type or wait.

These notes are about HTML. They show a little CSS, so you can see how the two work together.

Versions

The HTML used today is often called HTML5. It is a "living standard" from WHATWG: it is updated all the time, and there are no new version numbers. All modern browsers follow it.

View the HTML of a page

Right-click on any web page and choose View Page Source to see its HTML, or press Ctrl + U. Inspect (F12) opens the developer tools, where you can see the HTML as the browser understands it, and change it to try things.
