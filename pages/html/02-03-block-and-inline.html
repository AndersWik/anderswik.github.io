Block and inline

Every element is shown either as a block or inline, and this decides how it is placed on the page.

Block elements

A block element starts on a new line and is as wide as it can be. The next element comes below it.

<h1>Heading</h1>
<p>A paragraph.</p>
<div>A div.</div>

Some block elements: <div>, <p>, <h1> to <h6>, <ul>, <ol>, <li>, <table>, <form>, <header>, <section> and <footer>.

Inline elements

An inline element sits inside a line of text, and is only as wide as its content.

<p>Some <strong>bold</strong> text with a <a href="#">link</a> and an <em>emphasis</em>.</p>

Some inline elements: <span>, <a>, <strong>, <em>, <code>, <img>, <br>, <input> and <button>.

Rules

  • Inline elements go inside block elements, not the other way around.
  • <a> is an exception: it can hold block elements, for example to make a whole card a link.
  • <p> can only hold inline content. A <div> inside a <p> closes the paragraph.

CSS can change how an element is shown with display: block or display: inline, without changing what it means.
