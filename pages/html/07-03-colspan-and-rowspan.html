Colspan and rowspan

A cell can be wider or taller than one cell.

Colspan

colspan makes a cell as wide as several columns:

<table>
  <tr>
    <th colspan="2">Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Anna</td>
    <td>Svensson</td>
    <td>34</td>
  </tr>
</table>

Rowspan

rowspan makes a cell as tall as several rows:

<table>
  <tr>
    <th rowspan="2">Monday</th>
    <td>Swimming</td>
  </tr>
  <tr>
    <td>Football</td>
  </tr>
</table>

The second row has only one <td>, because the first column is already filled by the Monday cell.

Good to know

Count the cells: every row must add up to the same number of columns. If a row has too many cells, they stick out to the right of the table.
