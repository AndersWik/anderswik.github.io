Form attributes

The attributes on <form> decide where and how the form is sent.

<form action="/order" method="post" autocomplete="on">
  ...
</form>
  • action, the address the form is sent to. Without it, the form is sent to the same page.
  • method, get or post. See Forms.
  • target="_blank", opens the answer in a new tab.
  • autocomplete="off", asks the browser not to fill in fields from earlier.
  • novalidate, turns off the browser's checks of the fields, for example when JavaScript does the checks.

Send files

A form with a file field must use POST and enctype="multipart/form-data". Without it, only the file name is sent:

<form action="/upload" method="post" enctype="multipart/form-data">
  <input type="file" name="photo">
  <button>Upload</button>
</form>
