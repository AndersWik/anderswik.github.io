Attributes

Attributes give more information about an element. They are written in the start tag, as name="value":

<a href="https://example.com" title="Go to example.com">Example</a>
<img src="cat.jpg" alt="A cat" width="300">

Quotes

Put the value in double quotes. Single quotes work too, and are useful when the value has a double quote in it. Without quotes, the value can't have spaces, so always using quotes is simplest.

Boolean attributes

Some attributes have no value. If they are there, they are on:

<input type="checkbox" checked>
<button disabled>Send</button>

Global attributes

Some attributes work on every element:

  • id, a unique name for the element. See Id.
  • class, one or more class names. See Classes.
  • style, CSS for this element only. See Add CSS.
  • title, extra information, shown as a tooltip.
  • lang, the language of the content.
  • hidden, hides the element.
