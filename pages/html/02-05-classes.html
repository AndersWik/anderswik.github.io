Classes

The class attribute gives an element one or more names. Many elements can have the same class, and CSS and JavaScript use it to find them.

<p class="note">Remember to save.</p>
<p class="note">The page reloads by itself.</p>

Many classes

An element can have several classes, separated by spaces:

<p class="note important">Don't close the window.</p>

Use a class in CSS

In CSS, a class is written with a dot:

.note {
  background-color: lightyellow;
}

.important {
  font-weight: bold;
}

Use a class in JavaScript

document.querySelectorAll(".note");           // all elements with the class
element.classList.add("important");           // add a class
element.classList.toggle("hidden");           // add or remove

Names

A class name can't have spaces, since a space separates classes. Use names that say what the content is, like warning, not what it looks like, like red-text. Then the name is still right when the color changes.
