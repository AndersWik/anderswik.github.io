Buttons

<button> is a button you can click:

<button type="button">Click me</button>

Types

  • type="submit" sends the form. This is the default for a button in a form.
  • type="reset" clears the form.
  • type="button" does nothing by itself. Use it for buttons that run JavaScript.

A button in a form without a type sends the form, which is a common mistake. Always write type="button" on buttons that are not meant to send the form.

Button or link?

  • A link (<a>) goes to another page or another place.
  • A button does something on the page: opens a menu, saves, plays.

CSS can make them look the same, but keyboard and screen reader users expect them to work differently.

Content

A button can hold more than text, for example an icon. If there is only an icon, describe it with aria-label:

<button type="button" aria-label="Close">✕</button>
