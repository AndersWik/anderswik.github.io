Lists

Unordered list

<ul> is a list where the order doesn't matter. Each item is an <li>, shown with a dot:

<ul>
  <li>Milk</li>
  <li>Bread</li>
  <li>Cheese</li>
</ul>

Ordered list

<ol> is a list where the order matters, like steps. The items get numbers:

<ol>
  <li>Open the box</li>
  <li>Plug in the cable</li>
  <li>Press the button</li>
</ol>

start="5" starts at 5, reversed counts down, and type="a" uses letters instead of numbers.

Lists in lists

A list can be inside an <li>:

<ul>
  <li>Fruit
    <ul>
      <li>Apples</li>
      <li>Pears</li>
    </ul>
  </li>
  <li>Vegetables</li>
</ul>

Description list

<dl> is a list of terms (<dt>) and their descriptions (<dd>), like a glossary:

<dl>
  <dt>HTML</dt>
  <dd>The content and structure of a page.</dd>
  <dt>CSS</dt>
  <dd>How the page looks.</dd>
</dl>

Menus are often made as a <ul> of links, with CSS that removes the dots.
