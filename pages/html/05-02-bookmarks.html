Bookmarks

A link can jump to a part of a page. Give the part an id, and link to it with # and the id:

<a href="#prices">See the prices</a>

...

<h2 id="prices">Prices</h2>

A part of another page

Add # and the id after the address of the page:

<a href="prices.html#cakes">Cake prices</a>

Back to the top

#top always goes to the top of the page, even without an element with that id:

<a href="#top">Back to the top</a>

Good to know

  • The part of an address after # is called a fragment. It is not sent to the server.
  • With CSS scroll-behavior: smooth on html, the page scrolls to the part instead of jumping.
  • If a fixed menu covers the heading, scroll-margin-top on the heading leaves room for it.
