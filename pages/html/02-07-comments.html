Comments

A comment is text in the HTML that is not shown on the page. It starts with <!-- and ends with -->:

<!-- The menu starts here -->
<nav>...</nav>

<!--
  A comment can be
  several lines long.
-->

Comment out code

Put code inside a comment to hide it without removing it:

<!-- <p>This paragraph is hidden for now.</p> -->

Good to know

  • Comments are not shown, but everyone can read them with View Page Source. Never put passwords or secrets in them.
  • A comment can't be inside another comment. The first --> ends it.
  • In VS Code, Ctrl + / comments out the selected lines.
