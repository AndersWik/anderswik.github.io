Iframes

<iframe> shows another web page inside your page. It is mostly used for videos and maps from other sites:

<iframe src="https://www.youtube-nocookie.com/embed/VIDEO_ID"
        title="A video about HTML"
        width="560" height="315"
        allow="fullscreen"
        loading="lazy"></iframe>

Attributes

  • title describes the content for screen readers. Always set it.
  • loading="lazy" waits until you scroll near the frame.
  • allow gives the page in the frame permission to use things like full screen or the camera.
  • sandbox takes permissions away, for example to run scripts. sandbox alone blocks almost everything.

Good to know

  • Many sites don't allow their pages in a frame on other sites. They stop it with a header, and the frame stays empty.
  • A page can only read the content of a frame from the same site. See the frame part of the Page Search tutorial.
