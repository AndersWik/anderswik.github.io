SOAP client

Client

SoapClient calls the functions of a service as if they were functions on a PHP object. Without a WSDL file, location is the address of the server and uri its namespace. Run the client from the terminal while the server is running in another.

<?php
// client.php
$client = new SoapClient(null, [
    'location' => 'http://localhost:8000/server.php',
    'uri' => 'urn:Calculator',
    'connection_timeout' => 10,
    'exceptions' => true,
]);

echo $client->add(2, 3);
// Output: 5

echo $client->__soapCall('subtract', [10, 4]);
// Output: 6

With WSDL

With a WSDL file the client knows all functions and types by itself, so only the address of the WSDL is needed. See WSDL.

<?php
$client = new SoapClient('http://localhost:8000/calculator.wsdl');

print_r($client->__getFunctions());
// Output: Array ( [0] => int add(int $a, int $b) )

echo $client->add(2, 3);
// Output: 5

Errors

Errors from the server and network errors are thrown as a SoapFault.

<?php
try {
    echo $client->divide(1, 0);
} catch (SoapFault $e) {
    echo "Error: " . $e->getMessage();
}

Debug

With trace the client saves the last request and response, which shows the XML that was sent.

<?php
$client = new SoapClient(null, [
    'location' => 'http://localhost:8000/server.php',
    'uri' => 'urn:Calculator',
    'trace' => true,
]);

$client->add(2, 3);
echo $client->__getLastRequest();
echo $client->__getLastResponse();
