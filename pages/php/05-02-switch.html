Switch statements

A switch compares one value with many case values and runs the code for the first one that matches. switch uses loose comparison, like ==.

We can use booleans.

<?php
$val = true;

switch($val) {
  case true:
   echo "Hello.";
  break;
  case false:
   echo "Good bye.";
}
// Output: Hello.

We can use int.

<?php
$val = 2;

switch($val) {
  case 1:
   echo "Hello.";
  break;
  case 2:
   echo "Good bye.";
}
// Output: Good bye.

We can use a string.

<?php
$val = "Two";

switch($val) {
  case "One":
   echo "Option One.";
   break;
  case "Two":
   echo "Option Two.";
   break;
  case "Three":
   echo "Option Three.";
}
// Output: Option Two.

Break

We can omit the breaks from the switch. Then all options after and including the match will be executed.

<?php
$val = "Two";

switch($val) {
  case "One":
   echo "Option One. ";
  case "Two":
   echo "Option Two. ";
  case "Three":
   echo "Option Three.";
}
// Output: Option Two. Option Three.

Default

We can add a default option to a switch. It runs when no case matches.

<?php
$val = "Something else";

switch($val) {
  case "One":
   echo "Option One.";
  break;
  case "Two":
   echo "Option Two.";
  default:
   echo "Default Option.";
}
// Output: Default Option.

Template syntax

There can not be any output, not even whitespace, between switch: and the first case. That is why the PHP tags below start at the beginning of the line.

<html>
 <head>
  <title>Switch</title>
 </head>
 <body>
<?php $val = "One"; ?>
<?php switch($val): ?>
<?php case "One": ?>
   <p>Option One.</p>
<?php break; ?>
<?php case "Two": ?>
  <p>Option Two.</p>
<?php endswitch; ?>
   <?php // Output: Option One. ?>
 </body>
</html>

Match

PHP 8 added match. It returns a value, uses strict comparison (===), needs no break and throws an UnhandledMatchError if nothing matches and there is no default.

<?php
$val = "Two";

echo match($val) {
  "One" => "Option One.",
  "Two", "Three" => "Option Two or Three.",
  default => "Default Option.",
};
// Output: Option Two or Three.
