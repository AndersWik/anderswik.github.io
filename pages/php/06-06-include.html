Include

include reads another PHP file and runs it, as if the code was written where the include is. It is used to split code into files, for example a header and footer that are shared by many pages.

<?php include 'file.php'; ?>

Example

<?php
// header.php
?>
<html>
 <head>
  <title>My site</title>
 </head>
 <body>
<?php include 'header.php'; ?>
  <p>The page content</p>
 </body>
</html>

Relative paths

A relative path is resolved from the include path and the current working directory, not from the file that has the include. Start the path with __DIR__, the folder of the current file, to always get the right file.

<?php
include __DIR__ . '/header.php';

Include once

include_once does not include the file again if it already has been included. Use it for files with functions or classes, which can not be defined twice.

<?php
include_once __DIR__ . '/functions.php';
include_once __DIR__ . '/functions.php'; // Ignored

Include or require

If the file is missing include gives a warning and the script continues. require stops the script with a fatal error. Use require for files the code can not run without.

Never include a file name that comes from the user, like include $_GET['page'];. That lets anyone run or read files on the server.
