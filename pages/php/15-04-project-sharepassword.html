Project: Share password

Sending a password in a chat or an email leaves it there forever. A better way is a link that shows the password once and then stops working. In this tutorial we build the simplest version that is still safe: the secret is encrypted, the key is only in the link, and the secret is deleted the first time it is read or when it expires.

What it does

  • GET / shows a form where you write the secret and choose when it expires
  • POST / encrypts the secret, saves it and shows a link like /s/{id}/{key}
  • GET /s/{id}/{key} asks the recipient to confirm before showing the secret
  • POST /s/{id}/{key} deletes the secret, decrypts it and shows it, once

What makes it safe

  • The secret is encrypted with libsodium before it is saved. The key is only in the link and is never stored, so a copy of the database or a backup does not reveal any secrets
  • The secret is deleted in the same query that reads it, so two people can not read it at the same time
  • Secrets that are not read are deleted when they expire
  • The ids and keys are made with secure random functions and can not be guessed
  • The link first shows a confirm button. Chat programs and email scanners often open links to make previews, and they would otherwise use up the secret before the recipient sees it
  • The pages are never cached and never send the address on as a referrer, since the address contains the key
  • The form has a CSRF token, all queries use prepared statements and all output is escaped

What it does not protect against

Anyone who gets the link before the recipient can read the secret. The recipient then sees that it is gone and knows something is wrong. The server sees the key when the secret is read, so you must trust the server and the logs of the web server. Use HTTPS, always.

Requirements

PHP 8.0 or newer with sodium, mbstring and pdo_sqlite, and SQLite 3.35 or newer, which added RETURNING.

$ php -m | grep -E "sodium|mbstring|pdo_sqlite"
$ php -r 'echo (new PDO("sqlite::memory:"))->query("SELECT sqlite_version()")->fetchColumn(), PHP_EOL;'

Folder structure

sharepassword/
  data/
  public/
    index.php
$ mkdir -p sharepassword/data sharepassword/public
$ cd sharepassword

All code goes into public/index.php. Each step below adds to the end of the file, the <?php line is only written once at the top.

Step 1: Settings

<?php
// public/index.php
declare(strict_types=1);

const BASE_URL = 'http://localhost:8000';
const DB_FILE = __DIR__ . '/../data/secrets.sqlite';
const MAX_SECRET_BYTES = 10000;
const EXPIRY_OPTIONS = ['1h' => 3600, '1d' => 86400, '7d' => 604800];
const EXPIRY_LABELS = ['1h' => '1 hour', '1d' => '1 day', '7d' => '7 days'];

Step 2: The database

Each secret has a random id, the encrypted payload and the time it expires as a Unix timestamp. Every time the database is opened, expired secrets are deleted.

<?php
function db(): PDO
{
    static $pdo = null;

    if ($pdo === null) {
        $pdo = new PDO('sqlite:' . DB_FILE, null, null, [
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        ]);
        $pdo->exec('CREATE TABLE IF NOT EXISTS secrets (
            id TEXT PRIMARY KEY,
            payload TEXT NOT NULL,
            expires_at INTEGER NOT NULL
        )');
        $pdo->prepare('DELETE FROM secrets WHERE expires_at <= :now')->execute(['now' => time()]);
    }

    return $pdo;
}

Step 3: Helpers for HTML and the CSRF token

The same helpers as in Tiny URL, with two more headers. Cache-Control: no-store stops browsers and proxies from saving the pages, and X-Robots-Tag keeps search engines away.

<?php
function e(string $value): string
{
    return htmlspecialchars($value, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}

function render(string $body, int $status = 200): void
{
    http_response_code($status);
    header('Content-Type: text/html; charset=utf-8');
    header("Content-Security-Policy: default-src 'none'; form-action 'self'; base-uri 'none'; frame-ancestors 'none'");
    header('X-Content-Type-Options: nosniff');
    header('Referrer-Policy: no-referrer');
    header('Cache-Control: no-store');
    header('X-Robots-Tag: noindex, nofollow');

    echo '<!doctype html><html lang="en"><head><meta charset="utf-8">'
        . '<meta name="viewport" content="width=device-width, initial-scale=1">'
        . '<title>Share password</title></head><body>' . $body . '</body></html>';
}

function csrfToken(): string
{
    if (session_status() !== PHP_SESSION_ACTIVE) {
        session_start([
            'cookie_httponly' => true,
            'cookie_secure' => str_starts_with(BASE_URL, 'https://'),
            'cookie_samesite' => 'Lax',
            'use_strict_mode' => true,
        ]);
    }

    if (empty($_SESSION['csrf_token'])) {
        $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
    }

    return $_SESSION['csrf_token'];
}

Step 4: Encrypt and save

sodium_crypto_secretbox encrypts and signs the secret with a new random key. The signature means that a changed payload or a wrong key is detected when decrypting. The nonce must be unique for every encryption and is saved in front of the encrypted text.

The key is turned into URL safe base64, 43 characters, and put in the link. It is never written to the database. sodium_memzero wipes the key from memory when it is no longer needed.

<?php
function createSecret(string $secret, int $ttl): string
{
    $key = sodium_crypto_secretbox_keygen();
    $nonce = random_bytes(SODIUM_CRYPTO_SECRETBOX_NONCEBYTES);
    $payload = $nonce . sodium_crypto_secretbox($secret, $nonce, $key);
    $id = bin2hex(random_bytes(16));

    $stmt = db()->prepare('INSERT INTO secrets (id, payload, expires_at) VALUES (:id, :payload, :expires_at)');
    $stmt->execute([
        'id' => $id,
        'payload' => base64_encode($payload),
        'expires_at' => time() + $ttl,
    ]);

    $link = BASE_URL . '/s/' . $id . '/' . sodium_bin2base64($key, SODIUM_BASE64_VARIANT_URLSAFE_NO_PADDING);
    sodium_memzero($key);

    return $link;
}

Step 5: Read once and delete

DELETE ... RETURNING deletes the row and returns it in one step. If two requests come at the same time only one of them gets the row. closeCursor finishes the statement, so the delete is saved at once.

If the key is wrong the secret is still deleted. Nobody can guess an id of 32 random hex characters, so this only happens if the link is damaged, and then it is better that the secret is gone.

<?php
function secretExists(string $id): bool
{
    $stmt = db()->prepare('SELECT 1 FROM secrets WHERE id = :id AND expires_at > :now');
    $stmt->execute(['id' => $id, 'now' => time()]);

    return $stmt->fetchColumn() !== false;
}

function revealSecret(string $id, string $encodedKey): ?string
{
    try {
        $key = sodium_base642bin($encodedKey, SODIUM_BASE64_VARIANT_URLSAFE_NO_PADDING);
    } catch (SodiumException) {
        return null;
    }

    if (strlen($key) !== SODIUM_CRYPTO_SECRETBOX_KEYBYTES) {
        return null;
    }

    $stmt = db()->prepare('DELETE FROM secrets WHERE id = :id RETURNING payload, expires_at');
    $stmt->execute(['id' => $id]);
    $row = $stmt->fetch();
    $stmt->closeCursor();

    if ($row === false || (int) $row['expires_at'] <= time()) {
        return null;
    }

    $payload = base64_decode($row['payload'], true);
    if ($payload === false || strlen($payload) <= SODIUM_CRYPTO_SECRETBOX_NONCEBYTES) {
        return null;
    }

    $nonce = substr($payload, 0, SODIUM_CRYPTO_SECRETBOX_NONCEBYTES);
    $ciphertext = substr($payload, SODIUM_CRYPTO_SECRETBOX_NONCEBYTES);
    $secret = sodium_crypto_secretbox_open($ciphertext, $nonce, $key);
    sodium_memzero($key);

    return $secret === false ? null : $secret;
}

Step 6: The pages

handleCreate checks the CSRF token, that the secret is valid UTF-8 text of at most 10 000 bytes and that the expiry is one of the allowed values. The confirm page has a form without action, so it posts to the same address, with the id and key.

<?php
function formHtml(string $error = ''): string
{
    $options = '';
    foreach (EXPIRY_LABELS as $value => $label) {
        $selected = $value === '1d' ? ' selected' : '';
        $options .= '<option value="' . e($value) . '"' . $selected . '>' . e($label) . '</option>';
    }

    return '<h1>Share a password</h1>'
        . ($error !== '' ? '<p><strong>' . e($error) . '</strong></p>' : '')
        . '<form method="post" action="/" autocomplete="off">'
        . '<input type="hidden" name="csrf_token" value="' . e(csrfToken()) . '">'
        . '<p><label>Secret<br><textarea name="secret" rows="6" cols="50" required maxlength="10000"></textarea></label></p>'
        . '<p><label>Expires after <select name="expiry">' . $options . '</select></label></p>'
        . '<p><button>Create link</button></p>'
        . '</form>';
}

function createdHtml(string $link): string
{
    return '<h1>Your link</h1>'
        . '<p>Send this link to the recipient. It can only be opened once.</p>'
        . '<p><input type="text" readonly size="80" value="' . e($link) . '"></p>'
        . '<p><a href="/">Share another secret</a></p>';
}

function confirmHtml(): string
{
    return '<h1>Someone shared a secret with you</h1>'
        . '<p>The secret can only be shown once. Make sure you are ready to save it.</p>'
        . '<form method="post"><button>Show the secret</button></form>';
}

function secretHtml(string $secret): string
{
    return '<h1>Your secret</h1>'
        . '<p>The secret has now been deleted from the server. Save it somewhere safe.</p>'
        . '<p><textarea readonly rows="6" cols="50">' . e($secret) . '</textarea></p>';
}

function goneHtml(): string
{
    return '<h1>Secret not found</h1>'
        . '<p>The secret has already been viewed, has expired, or the link is not complete.</p>';
}

function handleCreate(): void
{
    $token = $_POST['csrf_token'] ?? '';
    if (!is_string($token) || !hash_equals(csrfToken(), $token)) {
        render(formHtml('The form has expired. Please try again.'), 403);
        return;
    }

    $secret = $_POST['secret'] ?? '';
    if (!is_string($secret) || $secret === '' || strlen($secret) > MAX_SECRET_BYTES || !mb_check_encoding($secret, 'UTF-8')) {
        render(formHtml('Write a secret of at most 10 000 characters.'), 422);
        return;
    }

    $expiry = $_POST['expiry'] ?? '';
    if (!is_string($expiry) || !array_key_exists($expiry, EXPIRY_OPTIONS)) {
        render(formHtml('Choose when the secret should expire.'), 422);
        return;
    }

    render(createdHtml(createSecret($secret, EXPIRY_OPTIONS[$expiry])));
}

The link is shown directly after the form is sent, and not after a redirect. That way the key never has to be saved anywhere on the server, not even in the session.

Step 7: Routing

The id must be 32 hex characters and the key 43 URL safe base64 characters before anything else is done.

<?php
$method = $_SERVER['REQUEST_METHOD'];
$path = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
if (!is_string($path)) {
    $path = '/';
}

try {
    if ($path === '/' && $method === 'GET') {
        render(formHtml());
    } elseif ($path === '/' && $method === 'POST') {
        handleCreate();
    } elseif (preg_match('#^/s/([a-f0-9]{32})/([A-Za-z0-9_-]{43})$#', $path, $matches) === 1) {
        [, $id, $key] = $matches;

        if ($method === 'GET') {
            secretExists($id) ? render(confirmHtml()) : render(goneHtml(), 404);
        } elseif ($method === 'POST') {
            $secret = revealSecret($id, $key);
            $secret === null ? render(goneHtml(), 404) : render(secretHtml($secret));
        } else {
            header('Allow: GET, POST');
            render('<h1>Method not allowed</h1>', 405);
        }
    } else {
        render('<h1>Page not found</h1>', 404);
    }
} catch (Throwable $e) {
    error_log('Share password: ' . $e->getMessage());
    render('<h1>Something went wrong</h1>', 500);
}

Step 8: Run it

$ php -S localhost:8000 -t public public/index.php

Open http://localhost:8000, write a secret and open the link in a private window. Click the button to see the secret, then reload the page. The secret is gone.

Look in the database to see that only encrypted data is stored.

$ sqlite3 data/secrets.sqlite "SELECT id, substr(payload, 1, 30), expires_at FROM secrets;"

Before going public

  • Set BASE_URL to the real address. HTTPS is required, since the key is in the link
  • Point the web server to the public folder, so data can not be downloaded
  • The web server writes every address to its access log, also the key. Turn off the log for /s/, in nginx with location /s/ { access_log off; }
  • Turn off display_errors in php.ini
  • Limit how many secrets an IP address can create

Next steps
