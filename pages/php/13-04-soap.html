SOAP

SOAP is an older standard for web services. The messages are XML documents sent with HTTP POST. A WSDL file describes which functions the service has and which types the parameters have, so a client can be generated from it. SOAP is still common in banks, government and large business systems.

PHP has a SoapClient to call SOAP services and a SoapServer to create them. They are in the soap extension.

$ sudo apt-get install php-soap
$ php -m | grep soap

A SOAP request looks like this.

<?xml version="1.0" encoding="UTF-8"?>
<SOAP-ENV:Envelope xmlns:SOAP-ENV="http://schemas.xmlsoap.org/soap/envelope/" xmlns:ns1="urn:Calculator">
  <SOAP-ENV:Body>
    <ns1:add>
      <a>2</a>
      <b>3</b>
    </ns1:add>
  </SOAP-ENV:Body>
</SOAP-ENV:Envelope>
