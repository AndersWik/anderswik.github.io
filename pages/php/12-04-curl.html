cURL

cURL (Client URL Library) is the most used way to send HTTP requests from PHP. It supports all methods, headers, cookies, timeouts and file uploads. It needs the curl extension.

$ sudo apt-get install php-curl

Get

Init curl and fetch page. This will print the returned value. By default cUrl will use "GET" for the request.

<?php
$url = "https://www.anderswik.se";
$curl = curl_init($url);
curl_exec($curl);

To stop curl from printing the value we can use curl_setopt. Now curl_exec returns the body instead.

<?php
$url = "https://www.anderswik.se";
$curl = curl_init($url);
curl_setopt($curl, CURLOPT_RETURNTRANSFER, 1);
$result = curl_exec($curl);

Status code

With curl_getinfo we can get status code.

<?php
$url = "https://www.anderswik.se";
$curl = curl_init($url);
curl_setopt($curl, CURLOPT_RETURNTRANSFER, 1);
curl_exec($curl);
$httpCode = curl_getinfo($curl, CURLINFO_HTTP_CODE);
echo $httpCode;
// Output: 200

Errors and timeouts

curl_exec returns false if the request failed, for example when the server can not be reached. curl_error tells why. Without a timeout PHP can wait for a very long time. Never turn off CURLOPT_SSL_VERIFYPEER, then anyone between you and the server can read and change the traffic.

<?php
$curl = curl_init("https://www.anderswik.se");
curl_setopt_array($curl, [
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_CONNECTTIMEOUT => 5,
  CURLOPT_TIMEOUT => 10,
  CURLOPT_FOLLOWLOCATION => true,
  CURLOPT_MAXREDIRS => 5,
]);

$result = curl_exec($curl);

if ($result === false) {
  echo "Request failed: " . curl_error($curl);
}

Get and Post

By default cUrl use "GET" for requests. We can also specify "GET" if we set "POST" to false.

Tell cURL that we want to send a GET request.

<?php
curl_setopt($curl, CURLOPT_POST, 0);

Tell cURL that we want to send a POST request. An array in CURLOPT_POSTFIELDS is sent as multipart/form-data, a string from http_build_query as a normal form.

<?php
$url = "https://www.anderswik.se";
$data = http_build_query(["name" => "Anna", "age" => 30]);
$curl = curl_init($url);
curl_setopt($curl, CURLOPT_RETURNTRANSFER, 1);
curl_setopt($curl, CURLOPT_POST, 1);
curl_setopt($curl, CURLOPT_POSTFIELDS, $data);
$result = curl_exec($curl);

Custom request

Tell cURL that we want to send a custom request. Read more in Custom requests.

<?php
$url = "https://www.anderswik.se";
$data = json_encode(["id" => 5]);
$curl = curl_init($url);
curl_setopt($curl, CURLOPT_RETURNTRANSFER, 1);
curl_setopt($curl, CURLOPT_CUSTOMREQUEST, "DELETE");
curl_setopt($curl, CURLOPT_POSTFIELDS, $data);
$result = curl_exec($curl);

Headers

<?php
curl_setopt($curl, CURLOPT_HTTPHEADER, [
  "Content-Type: application/json",
  "Accept: application/json",
]);

Cookies

Receive and send cookies. The cookie jar is a file where curl saves the cookies it gets, and the cookie file is read before the request. Use the same file for both to keep a login between requests.

<?php
$url = "https://www.anderswik.se";
$cookies = "cookies.txt";
$curl = curl_init($url);
curl_setopt($curl, CURLOPT_RETURNTRANSFER, 1);
// Write cookies to file
curl_setopt($curl, CURLOPT_COOKIEJAR, $cookies);
// Read cookies from file
curl_setopt($curl, CURLOPT_COOKIEFILE, $cookies);
$result = curl_exec($curl);

Close

Since PHP 8.0 the handle is closed automatically when the variable is no longer used. curl_close has no effect and is deprecated since PHP 8.5, so it can be left out. Use unset($curl) to close it early.
