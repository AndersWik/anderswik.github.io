MVC model

MVC, Model View Controller, splits an application into three parts.

  • The Model handles the data and the rules for it, usually by talking to a database
  • The View shows the data, usually as HTML
  • The Controller takes the request, asks the model for data and gives it to a view

Each part can then be changed without touching the others. These pages build a small application for notes. It uses the router from the previous page and SQLite, so no database server is needed.

The model

The model is the only class that knows about the database. It uses prepared statements for every value. Creating the table in the constructor keeps the example short, a larger application would use migrations.

<?php
// src/NoteModel.php
class NoteModel {

  public function __construct(private PDO $pdo) {
    $this->pdo->exec('CREATE TABLE IF NOT EXISTS notes (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      title TEXT NOT NULL,
      body TEXT NOT NULL
    )');
  }

  public function all(): array {
    return $this->pdo->query('SELECT id, title FROM notes ORDER BY id DESC')->fetchAll();
  }

  public function find(int $id): ?array {
    $stmt = $this->pdo->prepare('SELECT id, title, body FROM notes WHERE id = :id');
    $stmt->execute(['id' => $id]);
    $note = $stmt->fetch();

    return $note === false ? null : $note;
  }

  public function create(string $title, string $body): int {
    $stmt = $this->pdo->prepare('INSERT INTO notes (title, body) VALUES (:title, :body)');
    $stmt->execute(['title' => $title, 'body' => $body]);

    return (int) $this->pdo->lastInsertId();
  }
}

Use the model

<?php
$pdo = new PDO('sqlite:' . __DIR__ . '/../data/notes.sqlite', null, null, [
  PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
  PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
]);

$notes = new NoteModel($pdo);
$id = $notes->create('First note', 'Hello');
print_r($notes->find($id));
// Output: Array ( [id] => 1 [title] => First note [body] => Hello )
