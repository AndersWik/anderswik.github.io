Databases

Most web applications store their data in a database. PHP talks to SQL databases through PDO (PHP Data Objects), which works the same way for MySQL, SQLite, PostgreSQL and others. Only the connection string changes.

Mysql

MySQL and MariaDB are database servers. They are the most common choice for PHP sites. The extension is called pdo_mysql. Read more in MySQL and in the MySQL notes.

$ sudo apt-get install php-mysql
<?php
$pdo = new PDO("mysql:host=localhost;dbname=mydb;charset=utf8mb4", "myuser", "mypassword");

Sqlite

SQLite stores the whole database in one file and needs no server. It is great for small sites, tests and tools. The file must be stored outside of the public web folder.

$ sudo apt-get install php-sqlite3
<?php
$pdo = new PDO("sqlite:" . __DIR__ . "/data/app.sqlite");

Nosql

NoSQL databases do not use tables and SQL. They store documents, key and value pairs or graphs. Redis is a fast key and value store, often used for caches and sessions.

MongoDb

MongoDB stores JSON like documents. It is used from PHP with the mongodb extension and the mongodb/mongodb library installed with Composer.

$ sudo pecl install mongodb
$ composer require mongodb/mongodb
<?php
require __DIR__ . '/vendor/autoload.php';

$client = new MongoDB\Client("mongodb://localhost:27017");
$collection = $client->mydb->users;

$collection->insertOne(["name" => "Anna", "age" => 30]);
$user = $collection->findOne(["name" => "Anna"]);

PhpUnit

Code that uses the database can be tested with PHPUnit. Since PDO works the same for many databases, the tests can use a SQLite database in memory that is created again for every test.

<?php
$pdo = new PDO("sqlite::memory:");
