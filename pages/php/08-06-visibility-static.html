Visibility static

Visibility static attributes

Static from within class

The same rules apply to static members. From within the class all members are accessible.

<?php
class Foo {

	public static $memberPublic = "Public";
	protected static $memberProtected = "Protected";
	private static $memberPrivate = "Private";

	function getPub() {
		return self::$memberPublic;
	}

	function getPro() {
		return self::$memberProtected;
	}

	function getPriv() {
		return self::$memberPrivate;
	}
}

$foo = new Foo();
<?php
// 1: Foo Public:
echo $foo->getPub();
// Output: Public
// 2: Foo Protected:
echo $foo->getPro();
// Output: Protected
// 3: Foo Private:
echo $foo->getPriv();
// Output: Private

Static from extended class

We create another class and let it extend the foo class.

<?php
class Bar extends Foo {

	function getPub() {
		return self::$memberPublic;
	}

	function getPro() {
		return self::$memberProtected;
	}

	function getPriv() {
		return self::$memberPrivate;
	}
}

$extendsFoo = new Bar();

Once again it is the same, we can access the public and protected variable from the extended class and not the private variable.

<?php
// 1: Foo Extends Public:
echo $extendsFoo->getPub();
// Output: Public
// 2: Foo Extends Protected:
echo $extendsFoo->getPro();
// Output: Protected
// 3: Foo Extends Private:
echo $extendsFoo->getPriv();
// Output: Fatal error: Uncaught Error: Cannot access private property Bar::$memberPrivate

Static functions

Static functions follow the same rules. Only the public function can be called from outside of the class.

<?php
class Foo {

	public static function pub() {
		return "Public";
	}

	protected static function pro() {
		return "Protected";
	}

	private static function pri() {
		return "Private";
	}

	public static function all() {
		return self::pub() . " " . self::pro() . " " . self::pri();
	}
}
<?php
echo Foo::pub();
// Output: Public
echo Foo::pro();
// Output: Fatal error: Uncaught Error: Call to protected method Foo::pro() from global scope
echo Foo::pri();
// Output: Fatal error: Uncaught Error: Call to private method Foo::pri() from global scope
echo Foo::all();
// Output: Public Protected Private

Using Parent Self This

$this is the object, and static variables do not belong to an object. Instead there are three ways to point at a class. self:: is the class where the code is written. parent:: is the parent of that class. static:: is the class that was actually called, which is called late static binding.

Public

<?php
class Foo {

	public static $memberPublic = "Foo";

	public static function getPub() {
		return self::$memberPublic;
	}

	public static function getPubStatic() {
		return static::$memberPublic;
	}
}

class Bar extends Foo {

	public static $memberPublic = "Bar";

	public static function getPubParent() {
		return parent::$memberPublic;
	}

	public static function getPubSelf() {
		return self::$memberPublic;
	}
}

getPub is written in Foo, so self:: is Foo even when it is called as Bar::getPub(). static:: follows the class that was called.

<?php
// 1: Bar Parent:
echo Bar::getPubParent();
// Output: Foo
// 2: Bar Self:
echo Bar::getPubSelf();
// Output: Bar
// 3: Foo Self called on Bar:
echo Bar::getPub();
// Output: Foo
// 4: Foo Static called on Bar:
echo Bar::getPubStatic();
// Output: Bar

Protected

Protected static variables work the same way from inside the classes, but can not be read from outside.

<?php
class Foo {

	protected static $memberProtected = "Foo";

	public static function getProStatic() {
		return static::$memberProtected;
	}
}

class Bar extends Foo {

	protected static $memberProtected = "Bar";

	public static function getProParent() {
		return parent::$memberProtected;
	}

	public static function getProSelf() {
		return self::$memberProtected;
	}
}
<?php
// 1: Bar Parent:
echo Bar::getProParent();
// Output: Foo
// 2: Bar Self:
echo Bar::getProSelf();
// Output: Bar
// 3: Foo Static called on Bar:
echo Bar::getProStatic();
// Output: Bar
// 4: From outside:
echo Bar::$memberProtected;
// Output: Fatal error: Uncaught Error: Cannot access protected property Bar::$memberProtected

Private

A private static variable is only visible in the class that declares it. Each class has its own.

<?php
class Foo {

	private static $memberPrivate = "Foo";

	public static function getPri() {
		return self::$memberPrivate;
	}
}

class Bar extends Foo {

	private static $memberPrivate = "Bar";

	public static function getPriParent() {
		return parent::getPri();
	}

	public static function getPriSelf() {
		return self::$memberPrivate;
	}
}
<?php
// 1: Bar Parent:
echo Bar::getPriParent();
// Output: Foo
// 2: Bar Self:
echo Bar::getPriSelf();
// Output: Bar
