Debug

When something does not work it helps to look at what the variables actually contain. PHP has a few functions for that.

print_r

print_r prints a value in a way that is easy to read. It is good for arrays. With true as the second parameter it returns the text instead of printing it.

<?php
$val = array("one" => 1, "two" => 2);

print_r($val);
// Output: Array ( [one] => 1 [two] => 2 )

$text = print_r($val, true);

var_dump

var_dump also shows the type and length of every value. That makes it the best choice when the difference between 0, "0", false and null matters.

<?php
$val = array("one" => 1, "two" => "2", "three" => false);

var_dump($val);
// Output: array(3) { ["one"]=> int(1) ["two"]=> string(1) "2" ["three"]=> bool(false) }

In a browser the output is easier to read inside <pre> tags.

<?php
echo "<pre>";
var_dump($val);
echo "</pre>";

var_export

var_export prints the value as valid PHP code.

<?php
var_export(array(1, 2));
// Output: array ( 0 => 1, 1 => 2, )

die();

die() stops the script. It can take a message that is printed before stopping. It is handy to stop right after printing a value.

<?php
$val = "Debug me";
var_dump($val);
die();
echo "This line is never run";
<?php
die("Stopped here");
// Output: Stopped here

exit;

exit is the same as die. Given an integer it is used as the exit status of a command line script, where 0 means success.

<?php
exit;
<?php
exit(1);

Show errors

Errors are often hidden on servers. While developing, turn them on at the top of the script. Never show errors to visitors on a public server, they can reveal paths and passwords. Log them instead.

<?php
error_reporting(E_ALL);
ini_set('display_errors', '1');

Log errors

error_log writes a message to the error log of the server, or to the terminal when running the built-in server.

<?php
error_log("Something happened");
