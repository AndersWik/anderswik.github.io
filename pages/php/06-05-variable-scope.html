Variable scope

The scope of a variable is the part of the code where it can be used.

Super Globals

Superglobals like $_GET, $_POST and $_SERVER are available everywhere, also inside functions and classes. Read more in Superglobals.

<?php
function method() {
  return $_SERVER['REQUEST_METHOD'];
}

Globals

A variable created outside of a function is global. It can not be used inside a function unless we use the global keyword or the $GLOBALS array.

<?php
$counter = 1;

function show() {
  global $counter;
  echo $counter;
  echo $GLOBALS['counter'];
}

show();
// Output: 11

Local

A variable created inside a function is local. It only exists while the function runs and can not be used outside.

<?php
function create() {
  $local = "Only in here";
  echo $local;
}

create();
// Output: Only in here

echo $local;
// Output: Warning: Undefined variable $local

Static

A static variable in a function keeps its value between calls.

<?php
function countCalls() {
  static $count = 0;
  $count++;
  return $count;
}

echo countCalls();
// Output: 1
echo countCalls();
// Output: 2
