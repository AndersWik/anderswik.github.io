Project: Tracking pixel

A tracking pixel is a tiny transparent image. When a web page or an email shows the image, the browser asks your server for it, and the server counts the visit. This is how newsletters count how many have opened them. In this tutorial we build the simplest version that is still safe: one PHP file that returns the image and saves the hit, and one command line script that shows the numbers.

What it does

  • pixel.php?c=newsletter-2024-05 returns a 1x1 transparent GIF and saves one hit for the campaign newsletter-2024-05
  • report.php is run in the terminal and lists the number of hits for every campaign

What makes it safe

  • The campaign name is checked against a strict pattern before it is used
  • The database query uses a prepared statement, so it is safe from SQL injection
  • The database is stored outside of the public folder, so nobody can download it
  • No personal data, like IP address, is stored
  • The report is a command line script and is not reachable from the web
  • The image is always returned, even if the database fails, so a broken page or email is never shown

Folder structure

public is the only folder the web server shows. Everything else is out of reach for visitors.

tracker/
  data/
  db.php
  report.php
  public/
    pixel.php
$ mkdir -p tracker/data tracker/public
$ cd tracker

You need PHP with the SQLite driver for PDO. Check that pdo_sqlite is in the list.

$ php -m | grep -i sqlite

Step 1: The database

db.php opens the SQLite database and creates the table the first time. The table has a campaign name and the time of the hit, in UTC.

<?php
// db.php
declare(strict_types=1);

function db(): PDO
{
    $pdo = new PDO('sqlite:' . __DIR__ . '/data/tracker.sqlite', null, null, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    ]);

    $pdo->exec('CREATE TABLE IF NOT EXISTS hits (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        campaign TEXT NOT NULL,
        created_at TEXT NOT NULL
    )');

    return $pdo;
}

Step 2: The pixel

The campaign name comes from the URL, so it can be anything. It must be a string of 1 to 40 lower case letters, numbers and dashes. is_string is needed since ?c[]=x would make it an array. A hit with an invalid name is ignored, but the image is still returned.

The image is the smallest valid transparent GIF, 43 bytes, stored as base64. The cache headers make the browser ask for it again every time, otherwise only the first view would be counted.

<?php
// public/pixel.php
declare(strict_types=1);

require __DIR__ . '/../db.php';

$campaign = $_GET['c'] ?? '';

if (is_string($campaign) && preg_match('/^[a-z0-9-]{1,40}$/', $campaign) === 1) {
    try {
        $stmt = db()->prepare('INSERT INTO hits (campaign, created_at) VALUES (:campaign, :created_at)');
        $stmt->execute([
            'campaign' => $campaign,
            'created_at' => gmdate('Y-m-d H:i:s'),
        ]);
    } catch (PDOException $e) {
        error_log('Tracking pixel: ' . $e->getMessage());
    }
}

$gif = base64_decode('R0lGODlhAQABAIAAAAAAAP///yH5BAEAAAAALAAAAAABAAEAAAIBRAA7');

header('Content-Type: image/gif');
header('Content-Length: ' . strlen($gif));
header('Cache-Control: no-store, no-cache, must-revalidate, max-age=0');
header('Expires: 0');
echo $gif;

Start the built-in server with public as the web root and ask for the pixel with curl.

Step 4: The report

The report counts the hits per campaign. It refuses to run from a web server, so it stays safe even if someone by mistake copies it into public.

<?php
// report.php
declare(strict_types=1);

if (PHP_SAPI !== 'cli') {
    http_response_code(404);
    exit;
}

require __DIR__ . '/db.php';

$rows = db()->query(
    'SELECT campaign, COUNT(*) AS hits, MAX(created_at) AS last_hit
     FROM hits
     GROUP BY campaign
     ORDER BY hits DESC'
)->fetchAll();

if ($rows === []) {
    echo "No hits yet\n";
    exit;
}

printf("%-40s %8s  %s\n", 'Campaign', 'Hits', 'Last hit (UTC)');
foreach ($rows as $row) {
    printf("%-40s %8d  %s\n", $row['campaign'], $row['hits'], $row['last_hit']);
}
$ php report.php
Campaign                                     Hits  Last hit (UTC)
newsletter-2024-05                              1  2024-05-14 08:12:45

Step 5: Use the pixel

Add the image to the HTML of the email or page. The empty alt makes screen readers skip it.

<img src="https://example.com/pixel.php?c=newsletter-2024-05" width="1" height="1" alt="">

Things to know

  • Many email programs block images or load them through a proxy in advance, so the number is an estimate and not an exact count
  • Tracking people may need their consent, for example under GDPR in the EU. Tell your readers what you count in your privacy policy
  • Use HTTPS in production, an http:// image is blocked on https:// pages

Next steps
