XML

PHP has several ways to work with XML. SimpleXML is the easiest for reading, DOMDocument can both read and change a document, and XMLReader and XMLWriter work with big files without loading them into memory.

The examples use this file, books.xml.

<?xml version="1.0" encoding="UTF-8"?>
<books>
  <book id="1">
    <title>PHP</title>
    <price>200</price>
  </book>
  <book id="2">
    <title>MySQL</title>
    <price>150</price>
  </book>
</books>

Simple XML

simplexml_load_file reads a file and simplexml_load_string reads a string. Elements are reached as properties and attributes as array keys.

<?php
$books = simplexml_load_file(__DIR__ . "/books.xml");

foreach ($books->book as $book) {
  echo $book["id"] . ": " . $book->title . " " . $book->price . "\n";
}
// Output: 1: PHP 200
//         2: MySQL 150

echo (int) $books->book[1]->price;
// Output: 150

xpath finds elements with a query.

<?php
foreach ($books->xpath("//book[price > 160]") as $book) {
  echo $book->title;
}
// Output: PHP

The DOMDocument class

DOMDocument builds and changes documents. Text added with createTextNode is escaped, so & becomes &amp;.

<?php
$dom = new DOMDocument("1.0", "UTF-8");
$dom->formatOutput = true;

$books = $dom->createElement("books");
$dom->appendChild($books);

$book = $dom->createElement("book");
$book->setAttribute("id", "1");
$books->appendChild($book);

$title = $dom->createElement("title");
$title->appendChild($dom->createTextNode("PHP & MySQL"));
$book->appendChild($title);

echo $dom->saveXML();
<?xml version="1.0" encoding="UTF-8"?>
<books>
  <book id="1">
    <title>PHP &amp; MySQL</title>
  </book>
</books>

Reading works with getElementsByTagName or DOMXPath.

<?php
$dom = new DOMDocument();
$dom->load(__DIR__ . "/books.xml");

foreach ($dom->getElementsByTagName("title") as $title) {
  echo $title->textContent . "\n";
}

$xpath = new DOMXPath($dom);
echo $xpath->query("//book[@id='2']/title")->item(0)->textContent;
// Output: MySQL

XMLReader

XMLReader reads one node at a time, so files of any size can be read.

<?php
$reader = new XMLReader();
$reader->open(__DIR__ . "/books.xml");

while ($reader->read()) {
  if ($reader->nodeType === XMLReader::ELEMENT && $reader->name === "title") {
    echo $reader->readString() . "\n";
  }
}
$reader->close();
// Output: PHP
//         MySQL

XMLWriter

XMLWriter writes XML piece by piece. writeElement escapes the text.

<?php
$writer = new XMLWriter();
$writer->openMemory();
$writer->setIndent(true);
$writer->startDocument("1.0", "UTF-8");

$writer->startElement("books");
$writer->startElement("book");
$writer->writeAttribute("id", "1");
$writer->writeElement("title", "PHP & MySQL");
$writer->endElement();
$writer->endElement();

$writer->endDocument();
echo $writer->outputMemory();

Security

XML from others can contain external entities that read files from the server (XXE). Since PHP 8 they are not loaded by default. Do not pass the flag LIBXML_NOENT when reading XML you do not trust.
