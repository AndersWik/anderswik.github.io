Array functions

PHP has many functions that work on arrays. These are some of the most useful.

Explode

explode splits a string into an array.

<?php
$val = explode(",", "red,green,blue");
print_r($val);
// Output: Array ( [0] => red [1] => green [2] => blue )

Implode

implode joins the values of an array into a string.

<?php
echo implode(", ", ["red", "green", "blue"]);
// Output: red, green, blue

Array filter

array_filter keeps the values where the function returns true. The keys are kept, so use array_values to number them from 0 again.

<?php
$numbers = [1, 2, 3, 4];

$even = array_filter($numbers, function ($n) {
  return $n % 2 == 0;
});
print_r($even);
// Output: Array ( [1] => 2 [3] => 4 )

print_r(array_values($even));
// Output: Array ( [0] => 2 [1] => 4 )

Without a function array_filter removes all values that are false, like "", 0 and null.

<?php
print_r(array_filter(["a", "", null, "b"]));
// Output: Array ( [0] => a [3] => b )

Array Map

array_map runs a function on every value and returns a new array with the results. Here written with a short arrow function.

<?php
$numbers = [1, 2, 3];

$doubled = array_map(fn($n) => $n * 2, $numbers);
print_r($doubled);
// Output: Array ( [0] => 2 [1] => 4 [2] => 6 )

Array column

array_column picks one column from a list of rows. A third parameter chooses which column to use as keys.

<?php
$users = [
  ["id" => 1, "name" => "Anna"],
  ["id" => 2, "name" => "Bo"],
];

print_r(array_column($users, "name"));
// Output: Array ( [0] => Anna [1] => Bo )

print_r(array_column($users, "name", "id"));
// Output: Array ( [1] => Anna [2] => Bo )

Search

<?php
$colors = ["red", "green", "blue"];

var_dump(in_array("green", $colors, true));
// Output: bool(true)

var_dump(array_search("blue", $colors, true));
// Output: int(2)

var_dump(array_key_exists(1, $colors));
// Output: bool(true)

Give true as the last parameter to in_array and array_search so the types are compared too. Without it in_array("abc", [0]) is true in old versions of PHP.

Keys, values and merge

<?php
$val = ["a" => 1, "b" => 2];

print_r(array_keys($val));
// Output: Array ( [0] => a [1] => b )

print_r(array_values($val));
// Output: Array ( [0] => 1 [1] => 2 )

print_r(array_merge($val, ["c" => 3]));
// Output: Array ( [a] => 1 [b] => 2 [c] => 3 )

Sort

sort sorts the values, rsort in reverse, asort keeps the keys and ksort sorts by key. usort sorts with your own function. The <=> operator returns -1, 0 or 1.

<?php
$users = [
  ["name" => "Bo", "age" => 40],
  ["name" => "Anna", "age" => 30],
];

usort($users, fn($a, $b) => $a["age"] <=> $b["age"]);

echo $users[0]["name"];
// Output: Anna
