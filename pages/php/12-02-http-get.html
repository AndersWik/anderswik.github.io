GET

Client

GET request with file_get_contents. It returns the body of the response, or false if the request failed. Always include https://, without it PHP looks for a local file.

<?php
$url = "https://www.anderswik.se";
$result = file_get_contents($url);
var_dump($result);

Adding parameters to the url. http_build_query encodes the values.

<?php
$parameters = array(
    "option" => "stuff",
    "option2" => "other stuff"
);
$url = "https://www.anderswik.se?".http_build_query($parameters);
$result = file_get_contents($url);

Timeout and status code

A stream context sets options for the request. timeout stops PHP from waiting forever, and ignore_errors returns the body also for 404 and 500. The response headers are returned by http_get_last_response_headers in PHP 8.4, and in the variable $http_response_header in older versions.

<?php
$context = stream_context_create([
  "http" => [
    "timeout" => 10,
    "ignore_errors" => true,
    "header" => "Accept: application/json",
  ],
]);

$result = file_get_contents("https://api.example.com/users/1", false, $context);
$headers = http_get_last_response_headers();

echo $headers[0];
// Output: HTTP/1.1 200 OK

Server

On the server the parameters are in $_GET. Read more in Get.

<?php
var_dump($_GET);
