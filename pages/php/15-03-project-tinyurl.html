Project: Tiny URL

A URL shortener turns a long address into a short one, like http://localhost:8000/k3Hq9Tz. When someone opens the short link the server redirects them to the long address. In this tutorial we build the simplest version that is still safe and correct, in one PHP file with a SQLite database.

What it does

  • GET / shows a form where you paste a long URL
  • POST / checks the URL, saves it with a random code and redirects to a page that shows the short link
  • GET /k3Hq9Tz redirects to the saved URL, or shows 404 if the code does not exist

What makes it safe

  • Only http:// and https:// URLs are accepted. Without this check someone could save a javascript: link
  • All database queries use prepared statements
  • Everything printed on the pages is escaped with htmlspecialchars
  • The form is protected with a CSRF token, so other sites can not create links in the name of your visitors
  • The codes are made with random_int, which is safe for things that must not be guessed
  • The address of the site is a setting, it is not taken from the Host header, which the visitor controls
  • After the form is sent the browser is redirected, so reloading the page does not create another link
  • The database is stored outside of the public folder

Folder structure

tinyurl/
  data/
  public/
    index.php
$ mkdir -p tinyurl/data tinyurl/public
$ cd tinyurl

All code goes into public/index.php. Each step below adds to the end of the file, the <?php line is only written once at the top.

Step 1: Settings

BASE_URL is the address of the site, without a slash at the end. Change it when the site goes public. The alphabet leaves out characters that are easy to mix up, like l, 1, O and 0. 56 characters and 7 places give more than a trillion codes.

<?php
// public/index.php
declare(strict_types=1);

const BASE_URL = 'http://localhost:8000';
const DB_FILE = __DIR__ . '/../data/tinyurl.sqlite';
const CODE_ALPHABET = 'abcdefghijkmnpqrstuvwxyzABCDEFGHJKLMNPQRSTUVWXYZ23456789';
const CODE_LENGTH = 7;
const CODE_PATTERN = '/^[a-zA-Z0-9]{7}$/';

Step 2: The database

code is the primary key, so the database itself makes sure that no two links get the same code. static keeps the connection, so it is only opened once per request.

<?php
function db(): PDO
{
    static $pdo = null;

    if ($pdo === null) {
        $pdo = new PDO('sqlite:' . DB_FILE, null, null, [
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        ]);
        $pdo->exec('CREATE TABLE IF NOT EXISTS links (
            code TEXT PRIMARY KEY,
            url TEXT NOT NULL,
            created_at TEXT NOT NULL
        )');
    }

    return $pdo;
}

Step 3: Helpers for HTML and the CSRF token

e escapes text for HTML. render sends a whole page with a status code and some security headers. The Content Security Policy forbids all scripts, so even if something was missed, injected JavaScript would not run.

The session is only started when the form is used, so people who just follow a short link do not get a cookie.

<?php
function e(string $value): string
{
    return htmlspecialchars($value, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}

function render(string $body, int $status = 200): void
{
    http_response_code($status);
    header('Content-Type: text/html; charset=utf-8');
    header("Content-Security-Policy: default-src 'none'; form-action 'self'; base-uri 'none'; frame-ancestors 'none'");
    header('X-Content-Type-Options: nosniff');
    header('Referrer-Policy: no-referrer');

    echo '<!doctype html><html lang="en"><head><meta charset="utf-8">'
        . '<meta name="viewport" content="width=device-width, initial-scale=1">'
        . '<title>Tiny URL</title></head><body>' . $body . '</body></html>';
}

function csrfToken(): string
{
    if (session_status() !== PHP_SESSION_ACTIVE) {
        session_start([
            'cookie_httponly' => true,
            'cookie_secure' => str_starts_with(BASE_URL, 'https://'),
            'cookie_samesite' => 'Lax',
            'use_strict_mode' => true,
        ]);
    }

    if (empty($_SESSION['csrf_token'])) {
        $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
    }

    return $_SESSION['csrf_token'];
}

Step 4: Validate, create and find links

validUrl accepts at most 2048 characters, a valid URL according to filter_var, the schemes http and https, and not links to the shortener itself, which could create redirect loops.

createLink tries a new random code if the code already exists. The database answers SQLSTATE 23000 when the primary key is taken. Any other error is thrown on.

<?php
function validUrl(string $url): bool
{
    if ($url === '' || strlen($url) > 2048 || filter_var($url, FILTER_VALIDATE_URL) === false) {
        return false;
    }

    $scheme = strtolower((string) parse_url($url, PHP_URL_SCHEME));
    $host = strtolower((string) parse_url($url, PHP_URL_HOST));
    $ownHost = strtolower((string) parse_url(BASE_URL, PHP_URL_HOST));

    return in_array($scheme, ['http', 'https'], true) && $host !== $ownHost;
}

function randomCode(): string
{
    $code = '';
    $max = strlen(CODE_ALPHABET) - 1;

    for ($i = 0; $i < CODE_LENGTH; $i++) {
        $code .= CODE_ALPHABET[random_int(0, $max)];
    }

    return $code;
}

function createLink(string $url): string
{
    $stmt = db()->prepare('INSERT INTO links (code, url, created_at) VALUES (:code, :url, :created_at)');

    for ($attempt = 0; $attempt < 5; $attempt++) {
        $code = randomCode();
        try {
            $stmt->execute([
                'code' => $code,
                'url' => $url,
                'created_at' => gmdate('Y-m-d H:i:s'),
            ]);
            return $code;
        } catch (PDOException $e) {
            if (($e->errorInfo[0] ?? '') !== '23000') {
                throw $e;
            }
        }
    }

    throw new RuntimeException('Could not create a unique code');
}

function findUrl(string $code): ?string
{
    $stmt = db()->prepare('SELECT url FROM links WHERE code = :code');
    $stmt->execute(['code' => $code]);
    $url = $stmt->fetchColumn();

    return $url === false ? null : $url;
}

Step 5: The pages

The form keeps what the visitor typed if there was an error, escaped like everything else.

<?php
function formHtml(string $error = '', string $value = ''): string
{
    $html = '<h1>Tiny URL</h1>';

    if ($error !== '') {
        $html .= '<p><strong>' . e($error) . '</strong></p>';
    }

    return $html
        . '<form method="post" action="/">'
        . '<input type="hidden" name="csrf_token" value="' . e(csrfToken()) . '">'
        . '<p><label>Long URL<br>'
        . '<input type="url" name="url" value="' . e($value) . '" required maxlength="2048" size="50">'
        . '</label></p>'
        . '<p><button>Shorten</button></p>'
        . '</form>';
}

function resultHtml(string $code, string $url): string
{
    $short = BASE_URL . '/' . $code;

    return '<h1>Your short link</h1>'
        . '<p><a href="' . e($short) . '">' . e($short) . '</a></p>'
        . '<p>It goes to ' . e($url) . '</p>'
        . '<p><a href="/">Shorten another link</a></p>';
}

function handleCreate(): void
{
    $token = $_POST['csrf_token'] ?? '';
    if (!is_string($token) || !hash_equals(csrfToken(), $token)) {
        render(formHtml('The form has expired. Please try again.'), 403);
        return;
    }

    $url = is_string($_POST['url'] ?? null) ? trim($_POST['url']) : '';
    if (!validUrl($url)) {
        render(formHtml('Enter a full address that starts with http:// or https://.', $url), 422);
        return;
    }

    $code = createLink($url);
    header('Location: /?created=' . $code, true, 303);
}

Step 6: Routing

The path decides what to do. The code in a short link must match CODE_PATTERN before it is looked up. The redirect uses 302 Found and not 301, since browsers remember a 301 forever, and then the link can never be changed or removed.

Errors are logged, and the visitor only sees a general message.

<?php
$method = $_SERVER['REQUEST_METHOD'];
$path = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
if (!is_string($path)) {
    $path = '/';
}

try {
    if ($path === '/' && $method === 'GET') {
        $created = $_GET['created'] ?? '';
        $url = is_string($created) && preg_match(CODE_PATTERN, $created) === 1 ? findUrl($created) : null;
        render($url !== null ? resultHtml($created, $url) : formHtml());
    } elseif ($path === '/' && $method === 'POST') {
        handleCreate();
    } elseif (($method === 'GET' || $method === 'HEAD') && preg_match('#^/([a-zA-Z0-9]{7})$#', $path, $matches) === 1) {
        $url = findUrl($matches[1]);
        if ($url === null) {
            render('<h1>Link not found</h1>', 404);
        } else {
            header('Location: ' . $url, true, 302);
        }
    } else {
        render('<h1>Page not found</h1>', 404);
    }
} catch (Throwable $e) {
    error_log('Tiny URL: ' . $e->getMessage());
    render('<h1>Something went wrong</h1>', 500);
}

Step 7: Run it

The last argument sends every request to index.php, which works as the router.

$ php -S localhost:8000 -t public public/index.php

Open http://localhost:8000, paste a URL and open the short link. Check the redirect with curl.

$ curl -i http://localhost:8000/k3Hq9Tz
HTTP/1.1 302 Found
Location: https://www.anderswik.se/

Before going public

  • Set BASE_URL to the real address and use HTTPS
  • Point the web server to the public folder, so data can not be downloaded
  • Turn off display_errors in php.ini
  • Open services are used to hide links to phishing and malware. Limit how many links an IP address can create, or require a login
