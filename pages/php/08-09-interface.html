Interfaces

An interface lists functions that a class must have, without any code. It is a contract: every class that implements the interface promises to have those functions. Code that uses the interface does not need to know which class it gets.

<?php
interface Logger {
  public function log(string $message): void;
}

class EchoLogger implements Logger {

  public function log(string $message): void {
    echo $message . PHP_EOL;
  }
}

class FileLogger implements Logger {

  public function __construct(private string $path) {
  }

  public function log(string $message): void {
    file_put_contents($this->path, $message . PHP_EOL, FILE_APPEND | LOCK_EX);
  }
}

function process(Logger $logger): void {
  $logger->log("Processing");
}

process(new EchoLogger());
// Output: Processing

process(new FileLogger(__DIR__ . "/app.log"));
// Writes Processing to app.log

More than one interface

A class can implement many interfaces, separated with commas. An interface can also have constants.

<?php
interface HasName {
  const PREFIX = "Name: ";
  public function getName(): string;
}

interface HasAge {
  public function getAge(): int;
}

class Person implements HasName, HasAge {

  public function getName(): string {
    return self::PREFIX . "Anna";
  }

  public function getAge(): int {
    return 30;
  }
}

instanceof

instanceof checks if an object is of a class or implements an interface.

<?php
$person = new Person();

var_dump($person instanceof HasAge);
// Output: bool(true)
