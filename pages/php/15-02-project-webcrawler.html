Project: Web crawler

A web crawler starts at one page, finds all links on it, visits them and continues with the links on those pages. Search engines use crawlers to find pages. In this tutorial we build a small and polite crawler for the command line that lists the pages of one site with their status code and title.

What it does

$ php crawl.php https://example.com/ 20
200  https://example.com/  Example Domain
200  https://example.com/about  About us
404  https://example.com/old-page
  • Starts at the given URL and visits at most the given number of pages, 20 by default
  • Only follows links on the same host
  • Prints the status code, URL and title of every page

What makes it safe and polite

  • Only http and https URLs are followed, also after redirects, so links like file:// or javascript: are never fetched
  • Every request has a timeout and a maximum size, so a slow or huge page can not hang the crawler
  • It waits one second between requests and stops after a fixed number of pages, so it never overloads a server
  • It reads robots.txt and skips the paths the site asks crawlers to avoid
  • It sends a User-Agent that says what it is
  • Titles from the pages are cleaned of control characters before they are printed, since they could otherwise send escape codes to the terminal
  • SSL certificates are always verified

Requirements

PHP 8.0 or newer with the curl and dom extensions.

$ php -m | grep -E "curl|dom"

Step 1: Settings and fetching a page

All code goes into one file, crawl.php. Each step below adds to the end of the file, the <?php line is only written once at the top. Change the User-Agent to point to a page about your crawler.

fetch downloads one URL with cURL and returns the body, the status code, the content type and the final URL after redirects.

<?php
// crawl.php
declare(strict_types=1);

const USER_AGENT = 'MyCrawler/1.0 (+https://example.com/crawler)';
const DELAY_SECONDS = 1;

function fetch(string $url): array
{
    $curl = curl_init($url);
    curl_setopt_array($curl, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_FOLLOWLOCATION => true,
        CURLOPT_MAXREDIRS => 5,
        CURLOPT_PROTOCOLS => CURLPROTO_HTTP | CURLPROTO_HTTPS,
        CURLOPT_REDIR_PROTOCOLS => CURLPROTO_HTTP | CURLPROTO_HTTPS,
        CURLOPT_CONNECTTIMEOUT => 5,
        CURLOPT_TIMEOUT => 15,
        CURLOPT_MAXFILESIZE => 5_000_000,
        CURLOPT_USERAGENT => USER_AGENT,
    ]);

    $body = curl_exec($curl);

    return [
        'body' => is_string($body) ? $body : '',
        'status' => (int) curl_getinfo($curl, CURLINFO_RESPONSE_CODE),
        'type' => (string) curl_getinfo($curl, CURLINFO_CONTENT_TYPE),
        'url' => (string) curl_getinfo($curl, CURLINFO_EFFECTIVE_URL),
        'error' => curl_error($curl),
    ];
}

Step 2: Turn links into full URLs

Links on a page can be written in many ways: https://example.com/a, //example.com/a, /a, ?page=2 or just a. resolveUrl turns them into full URLs based on the page they were found on. Fragments like #top are removed, since they point to the same page. Links with any other scheme, like mailto:, are skipped.

This handles the common cases. It does not clean up ../ in paths or read a <base> tag, which is fine for a small crawler since every URL is only visited once anyway.

<?php
function resolveUrl(string $href, string $base): ?string
{
    $href = explode('#', trim($href), 2)[0];
    if ($href === '') {
        return null;
    }

    $parts = parse_url($href);
    if ($parts === false) {
        return null;
    }

    if (isset($parts['scheme'])) {
        return in_array(strtolower($parts['scheme']), ['http', 'https'], true) ? $href : null;
    }

    $b = parse_url($base);
    $origin = $b['scheme'] . '://' . $b['host'] . (isset($b['port']) ? ':' . $b['port'] : '');
    $basePath = $b['path'] ?? '/';

    if (str_starts_with($href, '//')) {
        return $b['scheme'] . ':' . $href;
    }
    if (str_starts_with($href, '/')) {
        return $origin . $href;
    }
    if (str_starts_with($href, '?')) {
        return $origin . $basePath . $href;
    }

    $dir = preg_replace('#/[^/]*$#', '/', $basePath);
    return $origin . $dir . $href;
}

Step 3: Read the title and the links

DOMDocument parses the HTML. Real pages are often not valid HTML, so the warnings are turned off. The <?xml encoding> in front tells the parser that the page is UTF-8, which most pages are.

cleanText removes control characters, both the normal ones and the ones from U+0080 to U+009F, and squeezes whitespace.

<?php
function cleanText(string $text): string
{
    $text = preg_replace('/[\x00-\x1F\x7F\x{80}-\x{9F}]+/u', ' ', $text) ?? '';
    return trim(preg_replace('/ {2,}/', ' ', $text) ?? '');
}

function parseHtml(string $html, string $baseUrl): array
{
    if (trim($html) === '') {
        return ['', []];
    }

    $dom = new DOMDocument();
    libxml_use_internal_errors(true);
    $dom->loadHTML('<?xml encoding="UTF-8">' . $html, LIBXML_NONET);
    libxml_clear_errors();

    $titleNode = $dom->getElementsByTagName('title')->item(0);
    $title = $titleNode !== null ? cleanText($titleNode->textContent) : '';

    $links = [];
    foreach ($dom->getElementsByTagName('a') as $a) {
        $link = resolveUrl($a->getAttribute('href'), $baseUrl);
        if ($link !== null) {
            $links[] = $link;
        }
    }

    return [$title, $links];
}

Step 4: Respect robots.txt

robots.txt tells crawlers which paths they should not visit. This simple version reads the Disallow lines in the group for User-agent: *. It does not understand Allow or wildcards, so it is a bit stricter than needed, never less.

<?php
function disallowedPaths(string $origin): array
{
    $response = fetch($origin . '/robots.txt');
    if ($response['status'] !== 200) {
        return [];
    }

    $paths = [];
    $applies = false;
    foreach (preg_split('/\R/', $response['body']) as $line) {
        $line = trim(explode('#', $line, 2)[0]);

        if (stripos($line, 'user-agent:') === 0) {
            $applies = trim(substr($line, 11)) === '*';
        } elseif ($applies && stripos($line, 'disallow:') === 0) {
            $path = trim(substr($line, 9));
            if ($path !== '') {
                $paths[] = $path;
            }
        }
    }

    return $paths;
}

function isAllowed(string $url, array $disallowed): bool
{
    $path = parse_url($url, PHP_URL_PATH);
    if (!is_string($path)) {
        $path = '/';
    }
    foreach ($disallowed as $prefix) {
        if (str_starts_with($path, $prefix)) {
            return false;
        }
    }
    return true;
}

Step 5: The crawl loop

The start URL is validated first. The crawler keeps a queue of URLs to visit and a list of URLs it has already seen, so no page is visited twice. Only pages that are HTML and on the same host are searched for more links. If a redirect leads to another host, the page is not searched.

<?php
if (PHP_SAPI !== 'cli') {
    exit("Run this script from the command line.\n");
}

if ($argc < 2) {
    fwrite(STDERR, "Usage: php crawl.php <url> [max pages]\n");
    exit(1);
}

$start = $argv[1];
$maxPages = isset($argv[2]) ? max(1, (int) $argv[2]) : 20;

$scheme = strtolower((string) parse_url($start, PHP_URL_SCHEME));
if (filter_var($start, FILTER_VALIDATE_URL) === false || !in_array($scheme, ['http', 'https'], true)) {
    fwrite(STDERR, "The start URL must be a full http:// or https:// URL.\n");
    exit(1);
}

$host = strtolower((string) parse_url($start, PHP_URL_HOST));
$port = parse_url($start, PHP_URL_PORT);
$origin = $scheme . '://' . $host . ($port !== null ? ':' . $port : '');

$disallowed = disallowedPaths($origin);
$queue = [$start];
$seen = [$start => true];
$crawled = 0;

while ($queue !== [] && $crawled < $maxPages) {
    $url = array_shift($queue);

    if (!isAllowed($url, $disallowed)) {
        continue;
    }

    sleep(DELAY_SECONDS);
    $crawled++;
    $response = fetch($url);

    if ($response['error'] !== '') {
        printf("ERR  %s  %s\n", $url, cleanText($response['error']));
        continue;
    }

    $isHtml = str_contains(strtolower($response['type']), 'text/html');
    $sameHost = strtolower((string) parse_url($response['url'], PHP_URL_HOST)) === $host;
    [$title, $links] = $isHtml && $sameHost
        ? parseHtml($response['body'], $response['url'])
        : ['', []];

    printf("%d  %s  %s\n", $response['status'], $url, $title);

    if ($response['status'] !== 200) {
        continue;
    }

    foreach ($links as $link) {
        if (strtolower((string) parse_url($link, PHP_URL_HOST)) === $host && !isset($seen[$link])) {
            $seen[$link] = true;
            $queue[] = $link;
        }
    }
}

echo "Crawled $crawled pages\n";

Step 6: Run it

Only crawl sites you own or have permission to crawl.

$ php crawl.php https://example.com/ 10

The output can be saved to a file and opened as a table.

$ php crawl.php https://example.com/ 50 > pages.txt
