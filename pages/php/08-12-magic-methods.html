Magic methods

Magic methods start with two underscores. PHP calls them automatically when something happens to the object, like when it is created, printed or a missing function is called.

<?php
__construct()
__destruct()
__call()
__callStatic()
__get()
__set()
__isset()
__unset()
__sleep()
__wakeup()
__serialize()
__unserialize()
__toString()
__invoke()
__set_state()
__clone()
__debugInfo()
__autoload() // Removed in PHP 8, use spl_autoload_register()

__toString

Called when the object is used as a string.

<?php
class Money {

  public function __construct(private int $cents) {
  }

  public function __toString(): string {
    return number_format($this->cents / 100, 2) . " kr";
  }
}

echo new Money(1250);
// Output: 12.50 kr

__get and __set

Called when reading or writing a variable that does not exist or is not visible.

<?php
class Config {

  private array $data = [];

  public function __get(string $name) {
    return $this->data[$name] ?? null;
  }

  public function __set(string $name, $value): void {
    $this->data[$name] = $value;
  }
}

$config = new Config();
$config->debug = true;
var_dump($config->debug);
// Output: bool(true)

__call

Called when a function that does not exist is called on the object. __callStatic does the same for static calls.

<?php
class Greeter {

  public function __call(string $name, array $arguments) {
    return "You called $name with " . implode(", ", $arguments);
  }
}

echo (new Greeter())->hello("Anna", "Bo");
// Output: You called hello with Anna, Bo

__invoke

Called when the object is used like a function.

<?php
class Multiplier {

  public function __construct(private int $factor) {
  }

  public function __invoke(int $n): int {
    return $n * $this->factor;
  }
}

$double = new Multiplier(2);
echo $double(5);
// Output: 10

__clone

clone makes a copy of an object. __clone runs on the copy, for example to also copy objects inside it.

<?php
class Order {

  public function __construct(public DateTime $date) {
  }

  public function __clone() {
    $this->date = clone $this->date;
  }
}

$a = new Order(new DateTime("2024-01-01"));
$b = clone $a;
$b->date->modify("+1 day");

echo $a->date->format("Y-m-d");
// Output: 2024-01-01
