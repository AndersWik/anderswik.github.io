Superglobals

Superglobals are arrays that PHP fills in for every request. They are available everywhere in the code, also inside functions and classes.

Everything in $_GET, $_POST, $_COOKIE, $_FILES, $_REQUEST and the HTTP_ values in $_SERVER is sent by the visitor. It can contain anything, so always validate it before using it and escape it with htmlspecialchars before printing it.

Global Variables

$GLOBALS contains all global variables. Since PHP 8.1 it is read only as a whole, but single values can still be changed.

<?php
print_r($GLOBALS);
?>

Server Variables

$_SERVER has information about the server and the current request.

<?php
print_r($_SERVER);
?>
  • $_SERVER['DOCUMENT_ROOT'] the root folder of the web site
  • $_SERVER['REMOTE_ADDR'] the IP address of the visitor
  • $_SERVER['REMOTE_PORT'] the port the visitor uses
  • $_SERVER['SERVER_SOFTWARE'] the name of the web server
  • $_SERVER['SERVER_PROTOCOL'] for example HTTP/1.1
  • $_SERVER['SERVER_NAME'] the name of the server
  • $_SERVER['SERVER_PORT'] for example 80 or 443
  • $_SERVER['REQUEST_URI'] the path and query string, for example /page.php?id=1
  • $_SERVER['REQUEST_METHOD'] for example GET or POST
  • $_SERVER['SCRIPT_NAME'] the path of the current script
  • $_SERVER['SCRIPT_FILENAME'] the full path of the current script on disk
  • $_SERVER['PHP_SELF'] the path of the script, can contain extra text from the visitor, escape it before printing
  • $_SERVER['HTTP_HOST'] the host name the visitor asked for, sent by the visitor
  • $_SERVER['HTTP_UPGRADE_INSECURE_REQUESTS']
  • $_SERVER['HTTP_ACCEPT'] which content types the browser accepts
  • $_SERVER['HTTP_USER_AGENT'] the name of the browser, sent by the visitor
  • $_SERVER['HTTP_ACCEPT_LANGUAGE'] which languages the visitor prefers
  • $_SERVER['HTTP_ACCEPT_ENCODING']
  • $_SERVER['HTTP_CONNECTION']
  • $_SERVER['REQUEST_TIME_FLOAT'] when the request started, with microseconds
  • $_SERVER['REQUEST_TIME'] when the request started, as a Unix timestamp
  • $_SERVER['argv'] the arguments to a command line script
  • $_SERVER['argc'] the number of arguments

Get

$_GET contains the parameters in the query string of the URL. Read more in Get.

<?php
print_r($_GET);
?>

Post Variables

$_POST contains the values from a form sent with the POST method. Read more in Post.

<?php
print_r($_POST);
?>

Files Variables

$_FILES contains information about files uploaded with a form.

<?php
print_r($_FILES);
?>

Cookie Variables

$_COOKIE contains the cookies sent by the browser. Read more in Cookies.

<?php
print_r($_COOKIE);
?>

Session Variables

$_SESSION contains the values stored in the session. It is only available after session_start(). Read more in Sessions.

<?php
session_start();
print_r($_SESSION);
?>

Request Variables

$_REQUEST contains $_GET, $_POST and $_COOKIE together. It is better to use the one you expect, so it is clear where the value comes from.

<?php
print_r($_REQUEST);
?>

Environment Variables

$_ENV contains the environment variables. It is often empty, because the variables_order setting in php.ini leaves it out. getenv always works.

<?php
print_r($_ENV);
echo getenv('HOME');
?>
