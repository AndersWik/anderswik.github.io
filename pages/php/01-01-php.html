PHP

PHP stands for PHP: Hypertext Preprocessor. It is a scripting language that runs on the server, most often to build web pages. The web server hands a .php file to PHP, PHP runs the code and sends the result, usually HTML, back to the browser. PHP can also be used to write scripts for the command line.

Install PHP

Debian and Ubuntu

$ sudo apt-get update
$ sudo apt-get install php-cli

macOS

PHP is no longer shipped with macOS. Install it with Homebrew.

$ brew install php

Check the version

To verify you have php installed on your machine open a terminal. Type php -v and the output should look something like the one below.

$ php -v
PHP 7.1.7 (cli) (built: Jul 15 2017 18:08:09) ( NTS )
Copyright (c) 1997-2017 The PHP Group
Zend Engine v3.1.0, Copyright (c) 1998-2017 Zend Technologies

Run PHP

Create a folder and a file called index.php.

$ mkdir php
$ cd php
$ touch index.php
$ nano index.php

All PHP code is written after the opening tag <?php. In a file that only contains PHP the closing tag ?> is left out, so no extra whitespace is sent by mistake.

<?php
echo "Hello World";

Run the file with the php command.

$ php index.php
Hello World

Built-in web server

With PHP 5.4 and newer we can start a local php server. In the php folder run the following command and open http://localhost:8000 in the browser. The built-in server is only meant for development, never use it on a public server.

$ php -S localhost:8000

Change index.php to the page below. phpinfo() prints the version of PHP, the loaded extensions and all settings.

<html>
 <head>
  <title>PHP Info</title>
 </head>
 <body>
  <?php phpinfo(); ?>
 </body>
</html>

PHP in HTML

PHP can be included in a html page. The PHP need to be written between PHP tags. Everything outside of the tags is sent to the browser as it is.

<html>
 <head>
  <title>PHP Basic</title>
 </head>
 <body>
  <p><?php echo 1+1; ?></p>
 </body>
</html>

Show all errors

While developing it helps to see every error, warning and notice. Put this at the top of the script. Read more in Debug.

<?php
error_reporting(E_ALL);
