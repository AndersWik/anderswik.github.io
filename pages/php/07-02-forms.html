Forms

A HTML form sends the values the visitor types to a PHP file. The name of every input becomes the key in $_POST or $_GET, depending on the method of the form.

The page below shows a form. When the form is submitted to the same file, $_POST['input-field'] is set and the page shows what was typed instead.

<html>
 <head>
  <title>PHP Form</title>
 </head>
 <body>
   <?php if(isset($_POST['input-field'])): ?>
     <h1>You submited a form</h1>
     <p>Your input is: <?php echo htmlspecialchars($_POST['input-field']) ?></p>
   <?php else: ?>
     <h1>This is a form</h1>
     <form action="form.php" method="post">
      <p>My Input: <input type="text" name="input-field" /></p>
      <p><input type="submit" /></p>
     </form>
  <?php endif; ?>
 </body>
</html>

Save the file as form.php, start the built-in server and open http://localhost:8000/form.php.

Escape the output

The value is printed with htmlspecialchars. Without it a visitor could type <script> and the browser would run it. This is called cross site scripting (XSS). Escape every value that comes from a visitor or a database when it is printed in HTML.

Validate the input

Check that the value has the type and length you expect before using it. Show the form again with an error if it does not.

<?php
$errors = [];
$name = trim($_POST['name'] ?? '');

if ($name === '') {
  $errors[] = "Name is required.";
} elseif (mb_strlen($name) > 100) {
  $errors[] = "Name can be at most 100 characters.";
}

$age = filter_var($_POST['age'] ?? '', FILTER_VALIDATE_INT, [
  "options" => ["min_range" => 0, "max_range" => 150],
]);

if ($age === false) {
  $errors[] = "Age must be a number between 0 and 150.";
}
