RPC

RPC, remote procedure call, means calling a function on another server as if it was a local function. Instead of resources like in REST, the client sends the name of a method and its parameters. JSON-RPC is a simple version that uses JSON over HTTP POST.

--> {"jsonrpc": "2.0", "method": "add", "params": [2, 3], "id": 1}
<-- {"jsonrpc": "2.0", "result": 5, "id": 1}

Server

The methods that can be called are listed in an array. Never call a function directly from the name the client sends, then the client could call any PHP function. Errors use the codes from the JSON-RPC specification.

<?php
// rpc.php
declare(strict_types=1);

header('Content-Type: application/json');

$methods = [
    'add' => fn(int $a, int $b): int => $a + $b,
    'hello' => fn(string $name): string => "Hello $name",
];

function rpcError(mixed $id, int $code, string $message): never {
    echo json_encode(['jsonrpc' => '2.0', 'error' => ['code' => $code, 'message' => $message], 'id' => $id]);
    exit;
}

$request = json_decode(file_get_contents('php://input'), true);

if (json_last_error() !== JSON_ERROR_NONE) {
    rpcError(null, -32700, 'Parse error');
}

if (!is_array($request) || ($request['jsonrpc'] ?? null) !== '2.0' || !is_string($request['method'] ?? null)) {
    rpcError(null, -32600, 'Invalid Request');
}

$id = $request['id'] ?? null;
$method = $methods[$request['method']] ?? null;
$params = $request['params'] ?? [];

if ($method === null) {
    rpcError($id, -32601, 'Method not found');
}

if (!is_array($params)) {
    rpcError($id, -32602, 'Invalid params');
}

try {
    $result = $method(...$params);
} catch (Error $e) {
    rpcError($id, -32602, 'Invalid params');
}

echo json_encode(['jsonrpc' => '2.0', 'result' => $result, 'id' => $id]);

params can be a list or an object. An object is passed as named arguments, so {"a": 2, "b": 3} also works. Wrong types or missing parameters throw an Error, which is returned as invalid params.

Client

The built-in server only handles one request at a time, so start the server in one terminal and run the client in another.

<?php
// client.php
function rpc(string $method, array $params): mixed {
    static $id = 0;

    $context = stream_context_create([
        'http' => [
            'method' => 'POST',
            'header' => 'Content-Type: application/json',
            'content' => json_encode(['jsonrpc' => '2.0', 'method' => $method, 'params' => $params, 'id' => ++$id]),
            'timeout' => 10,
        ],
    ]);

    $response = json_decode(file_get_contents('http://localhost:8000/rpc.php', false, $context), true);

    if (isset($response['error'])) {
        throw new RuntimeException($response['error']['message'], $response['error']['code']);
    }
    return $response['result'];
}

echo rpc('add', [2, 3]);
// Output: 5

echo rpc('hello', ['name' => 'Anna']);
// Output: Hello Anna
$ php -S localhost:8000
$ php client.php
