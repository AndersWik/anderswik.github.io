Variables

A variable is container that stores a value. All variables start with $ followed with a letter or underscore. The rest of the name can be a letter (a-z/A-Z), number or underscore. Names are case sensitive, so $name and $Name are two different variables.

<?php
$name = "Anders";
$_count = 1;
$value2 = 2.5;

PHP decides the type from the value. The same variable can hold a different type later. The basic types are covered on the next pages: integer, float, boolean and string. gettype tells which type a variable has.

<?php
$val = 123;
echo gettype($val);
// Outputs: integer

$val = "123";
echo gettype($val);
// Outputs: string

Null

A variable can have a Null value. Null is the default value of variables that are not initialized. isset returns false for variables that are not set or are null.

<?php
$value = NULL;

var_dump(isset($value));
// Outputs: bool(false)

Remove variable

unset removes a variable. Using it after that gives a warning and the value NULL.

<?php
$val = "remove me";

unset($val);
var_dump($val);
// Outputs: Warning: Undefined variable $val
// Outputs: NULL

Constants

A constant is like a variable that can not be changed. It has no $ and is written in upper case by convention. Constants can be created with define or with the const keyword.

<?php
define("SITE_NAME", "AndersWik");
const MAX_ITEMS = 10;

echo SITE_NAME;
// Outputs: AndersWik
