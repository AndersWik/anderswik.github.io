Namespaces

Namespaces group classes, functions and constants, like folders for code. Two classes can have the same name if they are in different namespaces. This is how libraries can be used together without name collisions.

Declare a namespace

The namespace is written first in the file. Everything in the file belongs to it.

<?php
namespace MyNameSpace;

class ClassName {
}

echo ClassName::class;
// Output: MyNameSpace\ClassName

A file can have more than one namespace with curly braces. The two styles can not be mixed in the same file. One namespace per file is the normal way.

<?php
namespace MyOtherNameSpace {
    class ClassName {
    }

    echo ClassName::class;
    // Output: MyOtherNameSpace\ClassName
}

Namespaces can have more levels, separated with \. By convention the levels follow the folders of the files, see SPL autoloader.

<?php
namespace App\Models;

class User {
}

Use

use imports a class from another namespace, so we do not have to write the full name. as gives it another name.

<?php
namespace App\Controllers;

use App\Models\User;
use App\Models\User as UserModel;

$user = new User();
$other = new UserModel();
$full = new \App\Models\User();

Global namespace

PHP's own classes are in the global namespace. Inside a namespace, start the name with \ or import it with use.

<?php
namespace App;

$date = new \DateTime();
