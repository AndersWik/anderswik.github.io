Function functions

PHP has functions that work on other functions. They are used to check if a function exists, to call a function by name and to accept any number of parameters.

function_exists

function_exists checks if a function is defined. It is used to write a polyfill, a function that only is defined if PHP does not already have it. boolval was added in PHP 5.5, so older versions get our version.

<?php
if (!function_exists('boolval')) {
 function boolval($val) {
  return (bool) $val;
 }
}

Call a function by name

A function can be called from a string with its name. is_callable checks that it can be called first.

<?php
function hello($name) {
  return "Hello " . $name;
}

$function = "hello";

if (is_callable($function)) {
  echo $function("Anna");
  // Output: Hello Anna

  echo call_user_func($function, "Bo");
  // Output: Hello Bo
}

Never call a function name that comes from a user, like $_GET["action"](). Map the allowed values to functions in an array instead.

Any number of parameters

... in front of the last parameter collects all remaining arguments into an array (variadic function).

<?php
function sum(...$numbers) {
  return array_sum($numbers);
}

echo sum(1, 2, 3, 4);
// Output: 10

The older way is func_get_args, which returns all arguments given to the function.

<?php
function sum() {
  return array_sum(func_get_args());
}

echo sum(1, 2, 3);
// Output: 6

Named arguments

Since PHP 8 arguments can be given by name. Then the order does not matter and default values can be skipped.

<?php
function greet($greeting = "Hello", $name = "Guest") {
  return "$greeting $name";
}

echo greet(name: "Anna");
// Output: Hello Anna
