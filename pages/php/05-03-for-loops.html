For loops

Loops run the same code many times. for is used when we know how many times, foreach to go through every value in an array.

For

A for loop has three parts: a start value, a condition that is checked before every round and a step that runs after every round.

<?php
$array = array("one", "two", "three", "four");

for ($i = 0; $i < count($array); $i++) {

  echo $array[$i]." ";
}
// Output: one two three four

Template syntax

<html>
 <head>
  <title>For</title>
 </head>
 <body>
   <?php $array = array("one", "two", "three", "four"); ?>
   <?php for ($i = 0; $i < count($array); $i++): ?>
     <p><?php echo $array[$i]; ?></p>
   <?php endfor; ?>
   <?php // Output: one two three four ?>
 </body>
</html>

Foreach

<?php
$array = array("one", "two", "three", "four");

foreach ($array as $value) {

  echo $value." ";
}
// Output: one two three four

foreach can also give the key of every value.

<?php
$array = array("one" => "Option One",
            "two" => "Option Two",
            "three" => "Option Three",
            "four" => "Option Four");

foreach ($array as $num => $value) {

  echo $num." : ".$value."\n";
}
// Output: one : Option One
//         two : Option Two
//         three : Option Three
//         four : Option Four

Template syntax

<html>
 <head>
  <title>For</title>
 </head>
 <body>
   <?php $array = array("one", "two", "three", "four"); ?>
   <?php foreach ($array as $value): ?>
     <p><?php echo $value; ?></p>
   <?php endforeach; ?>
   <?php // Output: one two three four ?>
 </body>
</html>

Break and continue

break stops the loop. continue skips the rest of the current round and goes to the next.

<?php
for ($i = 1; $i <= 10; $i++) {
  if ($i == 3) {
    continue;
  }
  if ($i == 6) {
    break;
  }
  echo $i . " ";
}
// Output: 1 2 4 5
