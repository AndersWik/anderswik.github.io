Ternary operators

The ternary operator is a short if else. It has the form condition ? value if true : value if false.

<?php
$val = true;
echo ($val) ? "Val is true" : "Val is false";
// Outputs: Val is true
<?php
$val = true;
echo ($val === true) ? "Val is true" : "Val is false";
// Outputs: Val is true

Nested ternary

We can nest ternary operators in other ternary operator statements. Since PHP 8 the parentheses are required, without them it is an error. Nested ternaries are hard to read, an if is often clearer.

<?php
$val1 = true;
$val2 = false;
echo ($val1) ? ("Val1 is true " . (($val2) ? "Val2 is true" : "Val2 is false")) : "Val1 is false";
// Outputs: Val1 is true Val2 is false

Short ternary

?: returns the left value if it is true, otherwise the right value.

<?php
$name = "";
echo $name ?: "Guest";
// Outputs: Guest

Null coalescing

?? is like ?: but only checks for null and missing values. An empty string is kept. Read more in Comparison operators.

<?php
$name = "";
var_dump($name ?? "Guest");
// Outputs: string(0) ""
