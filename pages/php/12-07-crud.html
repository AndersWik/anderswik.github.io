CRUD

CRUD (Create, Read, Update and Delete) are the four things an application does with data. In HTTP each of them has a method.

  • POST (Create)
  • GET (Read)
  • PUT (Create/Update)
  • DELETE (Delete)

Get (Read)

200 OK

For a get request we use 200 for an accepted request.

<?php
http_response_code(200);
echo json_encode($user);

Post (Create)

201 Created

For a post we use 201 when a new record is created. The Location header has the address of the new record.

<?php
http_response_code(201);
header("Location: /users/" . $id);

Put (Create/Update)

200 OK

For a put we use 200 for an accepted request that updates a existing record.

<?php
http_response_code(200);
echo json_encode($user);

201 Created

For a put we use 201 for an accepted request that creates a new record.

<?php
http_response_code(201);
header("Location: /users/" . $id);

202 Accepted

For a put we use 202 for an accepted request that have not been done processing yet. When processing is finished it might be disallowed.

<?php
http_response_code(202);

204 No Content

For a put we use 204 for an accepted request that updates a record but do not return any content.

<?php
http_response_code(204);

Delete (Delete)

200 OK

For a delete we use 200 for an accepted request that deletes an existing record.

<?php
http_response_code(200);
echo json_encode(["deleted" => $id]);

202 Accepted

For delete we use 202 for an accepted request that have not been done processing yet. When processing is finished it might be disallowed.

<?php
http_response_code(202);

204 No Content

For delete we use 204 for an accepted request that deletes a record but do not return any content.

<?php
http_response_code(204);

Implementation

Client

<?php
$ch = curl_init("http://localhost:8888/");

curl_setopt($ch, CURLOPT_CUSTOMREQUEST, "DELETE");

curl_setopt_array($ch, array(
    CURLOPT_HTTPHEADER  => array('Bazinga: !!!'),
    CURLOPT_RETURNTRANSFER  => 1,
    CURLOPT_VERBOSE     => 1
));

$content = curl_exec($ch);

curl_close($ch);

echo $content;

Server

<?php
switch ($_SERVER['REQUEST_METHOD']) {
  case 'GET':
    $content = "I am in get";
    break;
  case 'POST':
    http_response_code(201);
    $content = "I am in post";
    break;
  case 'PUT':
    $content = "I am in put";
    break;
  case 'DELETE':
    $content = "I am in delete";
    break;
  default:
    http_response_code(405);
    $content = "What is ".htmlspecialchars($_SERVER['REQUEST_METHOD']);
    break;
}

echo $content;
