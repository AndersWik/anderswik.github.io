Files

PHP can read and write files on the server. The examples use the file data/file.txt. The user that runs PHP, often www-data, must have permission to read and write the folder. Never build a path from a value the visitor sends, like $_GET['file'], since ../ would let them read any file on the server.

Check a file

file_exists checks if a file or folder exists.

<?php
$path = "data/file.txt";
$test = file_exists($path);
if($test) {
  echo "File exist";
}

is_readable checks that the file exists and that PHP is allowed to read it.

<?php
$path = "data/file.txt";
$test = is_readable($path);
if($test) {
  echo "File is readable";
}

is_writable checks that PHP is allowed to write to it.

<?php
$path = "data/file.txt";
$test = is_writable($path);
if($test) {
  echo "File is writable";
}

Open, read, write and close

fopen opens a file and returns a handle that the other functions use. The second parameter is the mode: r read, w write and empty the file first, a add to the end and x create a new file, which fails if it exists.

Read the data from a file.

<?php
$path = "data/file.txt";
$file = fopen($path, "r");
$content = fread($file, filesize($path));
var_dump($content);
fclose($file);

Write to a file. fwrite returns the number of bytes written.

<?php
$path = "data/file.txt";
$content = "This is content";
$file = fopen($path, "w");
echo fwrite($file, $content);
fclose($file);

The mode w will truncate the file before writing. While the file is open we can keep calling fwrite(), and each call is added after the last one. To keep what is already in the file, open it with the mode a instead.

fopen returns false if the file can not be opened. or die stops the script with a message in that case.

<?php
$path = "data/file.txt";
$content = "This is content\n";
$file = fopen($path, 'w') or die('Cannot open file:  '.$path);
echo fwrite($file, $content);
echo fwrite($file, $content);
fclose($file);
<?php
$path = "data/file.txt";
$file = fopen($path, 'a') or die('Cannot open file:  '.$path);
fwrite($file, "One more line\n");
fclose($file);

Read a whole file

A simpler way to read from a file.

<?php
$path = "data/file.txt";
$content = file_get_contents($path);
echo $content;

Can also be used to get an url. Read more in GET.

<?php
$url = "https://www.anderswik.se";
$content = file_get_contents($url);
echo $content;

Write a whole file

A simpler way to write to a file.

<?php
$path = "data/file.txt";
$content = "This is content";
file_put_contents($path, $content);

Using file_put_contents will truncate the file before writing. The solution is to use the FILE_APPEND flag. LOCK_EX locks the file while writing, so two visitors writing at the same time do not mix their lines.

<?php
$path = "data/file.txt";
$content = "This is content";
file_put_contents($path, $content, FILE_APPEND);
file_put_contents($path, $content, FILE_APPEND | LOCK_EX);

Read line by line

file returns the file as an array with one row per line. The flags remove the line breaks and skip empty lines.

<?php
$path = "data/file.txt";
$rows = file($path);

foreach($rows as $row)
{
    echo $row;
}
<?php
$rows = file("data/file.txt", FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES);

For big files, read one line at a time with fgets so the whole file is not loaded into memory.

<?php
$file = fopen("data/file.txt", "r");
while (($line = fgets($file)) !== false) {
  echo $line;
}
fclose($file);
