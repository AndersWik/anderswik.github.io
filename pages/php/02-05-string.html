String

A String is a text value. Can be defined in four different ways.

  • Single Quotes
  • Double Quotes
  • Heredoc syntax
  • Nowdoc syntax

Double Quotes

Creating a String using double quotes.

<?php
$val = "ABCDEF";

echo gettype ( $val );
// Output: string

echo is_string ( $val );
// Output: 1

If we create the string with double quotes we can add variables and the value will be added.

<?php
$val = "ABCDEF";

echo "$val";
// Outputs: ABCDEF

If the string continues after the variable name there must be white space between the variable name and the characters. If there are no whitespace the variable need to be enclosed with {}. The older form ${} still works but is deprecated since PHP 8.2.

<?php
$val = "ABCDEF";

echo "$valG";
// Outputs: Warning: Undefined variable $valG

echo "{$val}G";
// Outputs: ABCDEFG

echo "${val}G";
// Outputs: ABCDEFG (Deprecated since PHP 8.2)

Double quotes also understand escape sequences like \n for a new line, \t for a tab and \" for a quote.

<?php
echo "Line 1\nLine 2";

Single Quotes

Creating a String using single quotes. With single quotes the variable name and not the variable value will be printed. Only \' and \\ are escaped.

<?php
$val = 'ABCDEF';

echo gettype ( $val );
//Outputs: string

echo '$val';
//Outputs: $val

Heredoc syntax

We can also create strings with Heredoc syntax. This can be used when creating strings that covers multiple lines.

<?php
$val = <<<EOT
ABCDEF
EOT;

echo gettype( $val );
//Outputs: string

echo $val;
//Outputs: ABCDEF

Heredoc syntax works like double quotes and variable values will be inserted when a variable name is used.

<?php
$val = 'ABCDEF';

echo gettype( $val );
//Outputs: string

echo <<<EOT
ABCDEF $val {$val}
EOT;
//Outputs: ABCDEF ABCDEF ABCDEF

Nowdoc syntax

Nowdoc syntax can also be used when creating strings that covers multiple lines. The name is written in single quotes.

<?php
$val = <<<'EOT'
ABCDEF
EOT;

echo gettype( $val );
//Outputs: string

echo $val;
//Outputs: ABCDEF

Nowdoc syntax works like single quotes and variable values will not be inserted when a variable name is used.

<?php
$val = 'ABCDEF';

echo gettype( $val );
//Outputs: string

echo <<<'EOT'
ABCDEF $val ${val}
EOT;
//Outputs: ABCDEF $val ${val}

String concatenation

Strings are joined with the . operator. .= adds to the end of an existing string.

<?php
$string1 = "String 1";
$string2 = "String 2";

echo $string1 . $string2;
// Outputs: String 1String 2

echo $string1 . "String 2";
// Outputs: String 1String 2

echo $string1 . 'String 2';
// Outputs: String 1String 2

echo "String 1" . "String 2";
// Outputs: String 1String 2

echo "String 1" . 'String 2';
// Outputs: String 1String 2

$string1 .= " and more";
echo $string1;
// Outputs: String 1 and more

Defining Constants

String Constant

<?php
define("STRINGCONSTANT", "Some String");

echo gettype( STRINGCONSTANT );
//Outputs: string

echo STRINGCONSTANT;
//Outputs: Some String
