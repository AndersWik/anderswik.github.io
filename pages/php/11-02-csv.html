CSV

CSV, comma separated values, is a text format for tables. Every line is a row and the values are separated with commas. Values that contain a comma or a quote are written in quotes. PHP handles the quoting with fputcsv and fgetcsv, so never build CSV lines by hand.

The last three parameters are the separator, the quote character and the escape character. Since PHP 8.4 leaving out the escape character gives a deprecation notice. '' turns the old escape character off, which gives standard CSV.

Write CSV

<?php
$users = [
  ["id", "name", "email"],
  [1, "Anna", "anna@example.com"],
  [2, "Bo, Jr", "bo@example.com"],
];

$file = fopen(__DIR__ . "/users.csv", "w");
foreach ($users as $row) {
  fputcsv($file, $row, ",", "\"", "");
}
fclose($file);
id,name,email
1,Anna,anna@example.com
2,"Bo, Jr",bo@example.com

Read CSV

The first row is used as keys with array_combine. An empty line is read as [null] and is skipped.

<?php
$file = fopen(__DIR__ . "/users.csv", "r");
$header = fgetcsv($file, null, ",", "\"", "");

while (($row = fgetcsv($file, null, ",", "\"", "")) !== false) {
  if ($row === [null]) {
    continue;
  }
  $user = array_combine($header, $row);
  echo $user["name"] . "\n";
}
fclose($file);
// Output: Anna
//         Bo, Jr

Parse a CSV string

<?php
print_r(str_getcsv('1,"Bo, Jr",bo@example.com', ",", "\"", ""));
// Output: Array ( [0] => 1 [1] => Bo, Jr [2] => bo@example.com )

Download as CSV

Send headers so the browser saves the file instead of showing it. php://output writes straight to the response.

<?php
header("Content-Type: text/csv; charset=utf-8");
header('Content-Disposition: attachment; filename="users.csv"');

$output = fopen("php://output", "w");
foreach ($users as $row) {
  fputcsv($output, $row, ",", "\"", "");
}
fclose($output);

A value from a visitor that starts with =, +, - or @ can be run as a formula when the file is opened in a spreadsheet. Put a ' in front of such values if the file will be opened in Excel.
