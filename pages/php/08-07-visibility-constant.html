Visibility constant

Visibility constant attributes

Constants from within class

<?php
class Foo {

	const CONSTANTVAR = "Constant Variable";

	function getConstant() {
		return self::CONSTANTVAR;
	}

}

$foo = new Foo();
<?php
// From the class name
echo Foo::CONSTANTVAR;
// Output: Constant Variable
// From an instance
echo $foo->getConstant();
// Output: Constant Variable

Constants from extended class

<?php
class Bar extends Foo {

	function getConstant() {
		return parent::CONSTANTVAR;
	}

}

$extendsFoo = new Bar();

We can access the constant both from within and from an instance of the child class. This since the default visibility is public.

<?php
echo Bar::CONSTANTVAR;
// Output: Constant Variable
echo $extendsFoo->getConstant();
// Output: Constant Variable

Using Parent Self This

As of PHP 7.1 constants can be public, protected or private. The visibility is written before const. A child class can not give an inherited constant a stricter visibility.

Public

Inside the class a constant can be reached with the class name, with self:: or with $this::.

<?php
class Foo {

	public const CONPUB = "Foo";

	function getPub() {
		return Foo::CONPUB;
	}

	function getPubSelf() {
		return self::CONPUB;
	}

	function getPubThis() {
		return $this::CONPUB;
	}

}

$foo = new Foo();
<?php
// 1: Foo Class name:
echo $foo->getPub();
// Output: Foo
// 2: Foo Self:
echo $foo->getPubSelf();
// Output: Foo
// 3: Foo This:
echo $foo->getPubThis();
// Output: Foo

Protected

A child class can override a constant. parent:: gives the value from the parent, self:: and $this:: the value from the child. A protected constant can not be read from outside.

<?php
class Foo {

	protected const CONPRO = "Foo";

}

class Bar extends Foo {

	protected const CONPRO = "Bar";

	function getPro() {
		return parent::CONPRO;
	}

	function getProSelf() {
		return self::CONPRO;
	}

	function getProThis() {
		return $this::CONPRO;
	}

}

$extendsFoo = new Bar();
<?php
// 1: Foo Extends Parent:
echo $extendsFoo->getPro();
// Output: Foo
// 2: Foo Extends Self:
echo $extendsFoo->getProSelf();
// Output: Bar
// 3: Foo Extends This:
echo $extendsFoo->getProThis();
// Output: Bar
// 4: From outside:
echo Bar::CONPRO;
// Output: Fatal error: Uncaught Error: Cannot access protected constant Bar::CONPRO

Private

A private constant is only visible in the class that declares it. When Foo uses $this::CONPRI on a Bar object it finds the private constant of Bar, which Foo is not allowed to see. Use self:: for private constants.

<?php
class Foo {

	private const CONPRI = "Foo";

	function getPri() {
		return self::CONPRI;
	}

	function getPriThis() {
		return $this::CONPRI;
	}

}

class Bar extends Foo {

	private const CONPRI = "Bar";

	function getParPri() {
		return parent::getPri();
	}

	function getParPriSelf() {
		return self::CONPRI;
	}

	function getParPriThis() {
		return parent::getPriThis();
	}

}

$extendsFoo = new Bar();
<?php
// 1: Foo Extends Parent:
echo $extendsFoo->getParPri();
// Output: Foo
// 2: Foo Extends Self:
echo $extendsFoo->getParPriSelf();
// Output: Bar
// 3: Foo Extends This:
echo $extendsFoo->getParPriThis();
// Output: Fatal error: Uncaught Error: Cannot access private constant Bar::CONPRI
