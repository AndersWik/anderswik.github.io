Constructors

Constructor

The constructor is a function called __construct. It runs automatically when an instance is created with new, and is used to give the object its start values.

<?php
class Foo {

  function __construct() {

       echo "Constructor";
   }
}

$foo = new Foo();
// Output: Constructor

Constructor with parameters

The values given to new are passed to the constructor.

<?php
class Foo {

  function __construct($param) {

       echo $param;
   }
}

$foo = new Foo("Hello");
// Output: Hello

Usually the constructor saves the parameters in properties.

<?php
class User {

  private $name;

  function __construct($name) {
    $this->name = $name;
  }

  function getName() {
    return $this->name;
  }
}

$user = new User("Anna");
echo $user->getName();
// Output: Anna

Constructor promotion

Since PHP 8 a visibility in front of a constructor parameter creates the property and sets it. This class does the same as the one above.

<?php
class User {

  function __construct(private string $name) {
  }

  function getName(): string {
    return $this->name;
  }
}

Class with destructor

The destructor __destruct runs when the object is no longer used, or at the latest when the script ends.

<?php
class Foo {

  function __destruct() {

       echo "Destructor";
   }
}

$foo = new Foo();
// Output: Destructor
