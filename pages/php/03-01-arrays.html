Arrays

A array can store multiple values in one variable. Every value has a key. If we do not give the keys PHP numbers them from 0.

Without keys

<?php
$val = array( "one", "two" );

echo $val[0];
// Outputs: one

echo $val[1];
// Outputs: two

Associative Arrays (With keys)

The key of the array must be an Integer or String. Floats and booleans will be cast to an Integer. Strings that contain a whole number, like "8", are also cast to an Integer.

<?php
$val = array(
    "one" => "1",
    "two" => "2"
);

echo $val["one"];
// Outputs: 1

echo $val["two"];
// Outputs: 2

Short style without keys

Short style only works with PHP 5.4 and above. It is the most common way to write arrays today.

<?php
$val = [ "one", "two" ];

echo $val[0];
// Outputs: one

echo $val[1];
// Outputs: two

Short style Associative Arrays (with keys)

<?php
$val = [
    "one" => "1",
    "two" => "2"
];

echo $val["one"];
// Outputs: 1

echo $val["two"];
// Outputs: 2

Array key casting

If the key of the array are of the type float it will be cast to an Integer. The decimals will be removed and all keys below will be stored as 8. Each new value overwrites the one before, so only "c" is left. Since PHP 8.1 this also gives a deprecation notice, because the decimals are lost.

We can see this if we var_dump the array. The array only contains one key and that is eight.

<?php
$val = array(
  8.7 => "a",
  8.8 => "b",
  8.9 => "c"
);

echo $val[8.7];
// Outputs: c

echo $val[8.8];
// Outputs: c

echo $val[8.9];
// Outputs: c

echo $val[8];
// Outputs: c

var_dump($val);
// Outputs: array(1) { [8]=> string(1) "c" }

If the keys of the array are of the type boolean it will be cast to an Integer. True will be stored as 1 and false as 0.

<?php
$val = array(
  true => "a",
  false => "b"
);

echo $val[1];
// Outputs: a

echo $val[true];
// Outputs: a

echo $val[0];
// Outputs: b

echo $val[false];
// Outputs: b

If the key of the array are null it will be stored as "". Newer versions of PHP warn about null keys, so use "" directly.

<?php
$val = array(
  null => "a"
);

echo $val[null];
// Outputs: a

echo $val[""];
// Outputs: a

Appending value to an array

Appending value to an array without key. The new value gets the next free number as key.

<?php
$val = array( );

$val[] = "false";
$val[] = "true";

print_r( $val );
// Outputs: Array ( [0] => false [1] => true )

Appending value to an array with key.

<?php
$val = array( );

$val["false"] = "0";
$val["true"] = "1";

print_r( $val );
// Outputs: Array ( [false] => 0 [true] => 1 )

Check if a key exists

Reading a key that does not exist gives a warning. Check first with isset, or use ?? to give a default value.

<?php
$val = ["one" => "1"];

var_dump(isset($val["two"]));
// Outputs: bool(false)

echo $val["two"] ?? "default";
// Outputs: default

Removing value from an array

With unset we can remove a single value from the array or we can remove the entire array.

<?php
$val = array(
   "true" => "1",
   "false" => "0"
);

unset($val["false"]);
var_dump($val);
// Outputs: array(1) { ["true"]=> string(1) "1" }

unset($val);
var_dump($val);
// Outputs: Warning: Undefined variable $val
// Outputs: NULL

Array Operators

  • + union, adds the keys from the right array that are missing in the left
  • == true if both arrays have the same key and value pairs
  • === true if both arrays have the same key and value pairs in the same order and of the same types
  • != not equal
  • !== not identical
  • <> not equal, same as !=
<?php
$a = ["a" => 1, "b" => 2];
$b = ["b" => 3, "c" => 4];

print_r($a + $b);
// Outputs: Array ( [a] => 1 [b] => 2 [c] => 4 )

var_dump(["1", 2] == [1, 2]);
// Outputs: bool(true)

var_dump(["1", 2] === [1, 2]);
// Outputs: bool(false)

var_dump(["1", 2] != [1, 2]);
// Outputs: bool(false)

var_dump(["1", 2] !== [1, 2]);
// Outputs: bool(true)

var_dump(["1", 2] <> [1, 2]);
// Outputs: bool(false)

Methods

  • count(); returns the number of values
  • sort(); sorts the array, the array itself is changed
  • print_r(); prints the array in a readable way
  • var_dump(); prints the array with types
<?php
$val = [3, 1, 2];

echo count($val);
// Outputs: 3

sort($val);
print_r($val);
// Outputs: Array ( [0] => 1 [1] => 2 [2] => 3 )

var_dump($val);
// Outputs: array(3) { [0]=> int(1) [1]=> int(2) [2]=> int(3) }
