Abstract classes

An abstract class can not be used on its own, only extended. It can have normal functions that are shared by all child classes, and abstract functions that only have a name and parameters. Every child class must write its own version of the abstract functions.

<?php
abstract class Shape {

  abstract public function area(): float;

  public function describe(): string {
    return static::class . " with area " . round($this->area(), 2);
  }
}

class Circle extends Shape {

  public function __construct(private float $radius) {
  }

  public function area(): float {
    return M_PI * $this->radius ** 2;
  }
}

class Square extends Shape {

  public function __construct(private float $side) {
  }

  public function area(): float {
    return $this->side ** 2;
  }
}

echo (new Circle(2))->describe();
// Output: Circle with area 12.57

echo (new Square(3))->describe();
// Output: Square with area 9

Can not be created

<?php
$shape = new Shape();
// Output: Fatal error: Uncaught Error: Cannot instantiate abstract class Shape

Must implement

A child class that does not write the abstract functions gives an error, unless it is also abstract.

<?php
class Triangle extends Shape {
}
// Output: Fatal error: Class Triangle contains 1 abstract method and must therefore be declared abstract or implement the remaining methods (Shape::area)

Abstract class or interface

An abstract class can contain code and variables, but a class can only extend one class. An interface only describes functions, and a class can implement many interfaces.
