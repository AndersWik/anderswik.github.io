Post

$_POST contains the values from a form sent with method="post". The values are sent in the body of the request and not in the URL. Use POST for everything that creates, changes or deletes something.

Check the request method

<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
  $message = trim($_POST['message'] ?? '');
  // Validate and save the message
}

Post, Redirect, Get

If the page shows the result directly after a POST, reloading the page sends the form again. Redirect to a normal page after the form is handled instead. This is called Post/Redirect/Get.

<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
  $message = trim($_POST['message'] ?? '');

  if ($message !== '' && mb_strlen($message) <= 500) {
    file_put_contents(__DIR__ . '/messages.txt', $message . "\n", FILE_APPEND | LOCK_EX);
    header('Location: post.php?saved=1', true, 303);
    exit;
  }
  $error = "Write a message of at most 500 characters.";
}
?>
<html>
 <body>
  <?php if (isset($_GET['saved'])): ?>
    <p>Thank you, the message is saved.</p>
  <?php endif; ?>
  <?php if (isset($error)): ?>
    <p><?php echo htmlspecialchars($error); ?></p>
  <?php endif; ?>
  <form action="post.php" method="post">
    <textarea name="message"></textarea>
    <input type="submit" value="Send">
  </form>
 </body>
</html>

303 See Other tells the browser to follow the redirect with a GET request. Always call exit after a redirect, otherwise the rest of the script still runs.

Cross site request forgery

Another site can make the browser of a logged in visitor send a POST to your site. Protect forms that change data with a secret token stored in the session, and check it when the form is sent.
