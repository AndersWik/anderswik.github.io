If statements

If statements can be written with normal syntax or alternative syntax (template syntax). The first way would be the preferred syntax for code in a class. The alternative syntax is appropriate for template files, where PHP is mixed with HTML.

If

The code inside the curly braces only runs if the condition is true.

<?php
$val = true;

if ($val) {
 echo "Value equals true.";
}
// Outputs: Value equals true.

if ($val == true) {
 echo "Value equals true.";
}
// Outputs: Value equals true.

Template syntax

<html>
 <head>
  <title>If</title>
 </head>
 <body>
   <?php $val = true; ?>
   <?php if ($val == true): ?>
     <p>Value equals true.</p>
   <?php endif; ?>
 </body>
</html>

If else

In an if with an else the else will only run if the if is false. Since $val is true the if in the code below will run and not the else.

<?php
$val = true;

if ($val == true) {
 echo "First value equals true.";
} else {
 echo "First values equals false.";
}
// Outputs: First value equals true.

Template syntax

<html>
 <head>
  <title>If and else</title>
 </head>
 <body>
   <?php $val = true; ?>
   <?php if ($val == true): ?>
     <p>First value equals true.</p>
   <?php else: ?>
     <p>First values equals false.</p>
   <?php endif; ?>
 </body>
</html>

Elseif

In an if with an elseif only the first true statement will be executed. Since the if in the code below is true the elseif will not run. If $val1 were false it would.

<?php
$val1 = true;
$val2 = true;

if ($val1 == true) {
 echo "First value equals true.";
} elseif ($val2== true) {
 echo "Other value equals too true.";
} else {
 echo "Both values equals false.";
}
// Outputs: First value equals true.

Template syntax

<html>
 <head>
  <title>If, elseif and else</title>
 </head>
 <body>
   <?php $val1 = true; ?>
   <?php $val2 = true; ?>
   <?php if ($val1 == true): ?>
     First value equals true.
   <?php elseif ($val2== true): ?>
     Other value equals too true.
   <?php else: ?>
     Both values equals false.
   <?php endif; ?>
 </body>
</html>
