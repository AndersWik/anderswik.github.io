HTTP

HTTP is the protocol browsers and servers use to talk. The client sends a request with a method, a path, headers and sometimes a body. The server answers with a status code, headers and a body.

GET /index.php?id=5 HTTP/1.1
Host: www.anderswik.se
User-Agent: curl/8.5.0
Accept: */*
HTTP/1.1 200 OK
Content-Type: text/html; charset=UTF-8
Content-Length: 1256

<html>...

The curl command shows the full request and response with -v.

$ curl -v https://www.anderswik.se

Methods

  • GET reads a resource
  • POST creates a resource or sends data to be processed
  • PUT replaces a resource
  • PATCH changes a part of a resource
  • DELETE removes a resource
  • HEAD is like GET but only returns the headers

The request in PHP

The method is in $_SERVER['REQUEST_METHOD'], the path in $_SERVER['REQUEST_URI'] and the headers can be read with apache_request_headers.

<?php
$headers = apache_request_headers();

foreach ($headers as $header => $value) {
  echo htmlspecialchars("$header: $value") . "<br>";
}

The response in PHP

The status code is set with http_response_code and headers with header. Both must be called before any output.

<?php
http_response_code(200);
header("Content-Type: text/plain; charset=utf-8");
echo "Hello";
