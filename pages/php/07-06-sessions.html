Sessions

A session stores data on the server between requests. The browser only gets a cookie with a random session id. Sessions are used for things like logins and shopping carts.

Start a session

session_start must be called before any output, on every page that uses the session.

<?php
session_start();

$_SESSION['visits'] = ($_SESSION['visits'] ?? 0) + 1;

echo "You have visited this page " . $_SESSION['visits'] . " times";

Safe cookie settings

<?php
session_start([
  'cookie_httponly' => true,
  'cookie_secure' => true,      // Only over HTTPS, set to false when testing on http://localhost
  'cookie_samesite' => 'Lax',
  'use_strict_mode' => true,
]);

Log in

Give the visitor a new session id when they log in. Otherwise an attacker who knows the old id can use it.

<?php
session_start();

// After the password has been checked with password_verify()
session_regenerate_id(true);
$_SESSION['user_id'] = $userId;

Log out

<?php
session_start();

$_SESSION = [];
session_destroy();
setcookie(session_name(), '', time() - 3600, '/');

CSRF token

A random token in the session protects forms against cross site request forgery. Another site can not read the token, so it can not send a valid form. hash_equals compares the strings in constant time.

<?php
session_start();

if (empty($_SESSION['csrf_token'])) {
  $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
}

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
  $token = $_POST['csrf_token'] ?? '';

  if (!is_string($token) || !hash_equals($_SESSION['csrf_token'], $token)) {
    http_response_code(403);
    exit('Invalid form, reload the page and try again.');
  }
  // Handle the form
}
?>
<form method="post">
  <input type="hidden" name="csrf_token" value="<?php echo htmlspecialchars($_SESSION['csrf_token']); ?>">
  <input type="submit" value="Send">
</form>
