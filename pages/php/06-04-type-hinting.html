Type hinting

Type hinting, or type declarations, tells PHP which type a parameter or return value must have. PHP then checks the type when the function is called. It catches mistakes early and makes the code easier to read.

Parameter types

The type is written before the parameter name.

<?php
function add(int $a, int $b) {
  return $a + $b;
}

echo add(2, 3);
// Output: 5

echo add("abc", 3);
// Output: Fatal error: Uncaught TypeError: add(): Argument #1 ($a) must be of type int, string given

Return types

The return type is written after the parameter list with a colon. void means the function returns nothing.

<?php
function add(int $a, int $b): int {
  return $a + $b;
}

function sayHello(string $name): void {
  echo "Hello " . $name;
}

Strict types

By default PHP converts values when it can, so add("2", "3") works and returns 5. With declare(strict_types=1); at the very top of the file the types must match exactly. Using it in all files is a good habit.

<?php
declare(strict_types=1);

function add(int $a, int $b): int {
  return $a + $b;
}

echo add("2", "3");
// Output: Fatal error: Uncaught TypeError: add(): Argument #1 ($a) must be of type int, string given

Nullable and union types

? in front of a type also allows null. Since PHP 8 | allows more than one type. mixed allows any type.

<?php
function findUser(int $id): ?array {
  return $id === 1 ? ["id" => 1, "name" => "Anna"] : null;
}

function formatId(int|string $id): string {
  return "#" . $id;
}

echo formatId(5);
// Output: #5

Types that can be used

  • int, float, string, bool
  • array, callable, iterable, object, mixed
  • class and interface names, like DateTime
  • self, static, void, never, null, true and false
