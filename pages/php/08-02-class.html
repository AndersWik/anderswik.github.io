Classes

A class can be created with the class keyword followed by a name and brackets. The PHP class name starts with a letter or underscore. The rest of the name can be letters, underscores or numbers. The name can not be a PHP reserved word.

To create an instance of the class use the new keyword followed by the class name and (). We can store an instance of the class in a variable.

<?php
class Foo {

}

$foo = new Foo();

To create an instance of the class with a variable, the variable needs to contain the class name. Use the new keyword followed by the variable name and ().

<?php
class Foo {

}

$name = "Foo";
$foo = new $name();

Class with function

We can add functions to classes. To use these functions we need an instance of the class.

To call a function in the class first create an instance of the class and save it to a variable. Use the variable with the instance followed by -> and then the functions name.

<?php
// Class with function
class Foo {

  function getText() {

    return "Foo";
  }

}

$foo = new Foo();
echo $foo->getText();
// Output: Foo

Class with instance variable

An instance variable is unique to every instance. To access a class variable use the keyword this followed by the -> and the variable name. Note that the $ is omitted from the variable name.

A variable that is created with the var keyword will get the default visibility public. We can also give the variable a visibility (public, protected, private), which is the modern way to write it.

To access an instance variable create an instance of the class.

We can call the instance variable directly. Use the variable with the instance followed by -> and then the instance variables name. Note the $ is omitted from the variable name. This only works if the variable is public.

<?php
class Foo {

 var $variable = "Class Variable";

 function getVariable() {

  return $this->variable;
 }

 function setVariable($value) {

  $this->variable = $value;
 }

}

$foo = new Foo();
echo $foo->variable;
// Output: Class Variable

To set a class variable from within the class we use the keyword this followed by the -> and the variable name. Note the $ is omitted from the variable name.

When changing the value of a class variable from an instance the value only changes for that instance of the class.

<?php
$one = new Foo();
echo $one->getVariable();
// Output: Class Variable

$two = new Foo();
echo $two->getVariable();
// Output: Class Variable

$two->setVariable("Set class variable");

echo $one->getVariable();
// Output: Class Variable
echo $two->getVariable();
// Output: Set class variable

First create instances one and two of class foo. Get and print the value of the class variable from instance one and two. They are the same. Then set the value of the class variable on instance two. Get the value of the class variable from instance one and two again. They are now different. Changing the value on one instance does not change it on other instances.

Class with static variable

A static variable is shared with all instances. Use the static keyword for static variables. To call a static variable we do not need an instance of the class. Use the full class name followed with :: and the variable name.

<?php
class Foo {

 static $staticVariable = "Static Variable";
}

echo Foo::$staticVariable;
// Output: Static Variable

A static function is also shared with all instances. Use the static keyword for static functions. To call a static function we do not need an instance of the class. Use the full class name followed with :: and the function name.

<?php
class Foo {

 public static function getStaticText() {
   return "Static Text";
 }

}

echo Foo::getStaticText();
// Output: Static Text

To get a static variable from inside the class use self:: followed by the variable name. To set a static variable use self:: followed by the variable name.

<?php
class Foo {

 static $staticVariable = "Static Variable";

 function getStatic() {

  return self::$staticVariable;
 }

 function setStatic($value) {

  self::$staticVariable = $value;
 }

}

echo Foo::$staticVariable;
//Output: Static Variable

When changing the value of a static variable from an instance the value changes for all instances of the class.

Get the value of the static variable from instance one. Create instance two of class foo. Set the value of the static variable from instance two. Get and print the value of the static variable from instance one. Our changes to instance two are visible from instance one.

<?php
$one = new Foo();
echo $one->getStatic();
//Output: Static Variable

$two = new Foo();
$two->setStatic("Set static variable");
echo $one->getStatic();
//Output: Set static variable

Class with constant

A constant variable is shared with all instances. The value can not be changed. Use the const keyword for constant variables. To call a constant variable use self:: followed by the variable name. To call a constant variable we do not need an instance of the class. Use the full class name followed with :: and the variable name.

<?php
class Foo {

 const CONSTANT = "Constant";

 function getConstant() {
  return self::CONSTANT;
 }

}

echo Foo::CONSTANT;
// Output: Constant
