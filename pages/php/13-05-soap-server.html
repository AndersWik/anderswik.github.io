SOAP server

Server

SoapServer turns a PHP class into a SOAP service. Without a WSDL file, called non WSDL mode, the option uri is required and is the namespace of the service. All public functions in the class can be called.

<?php
// server.php
class Calculator {

    public function add(int $a, int $b): int {
        return $a + $b;
    }

    public function subtract(int $a, int $b): int {
        return $a - $b;
    }
}

$server = new SoapServer(null, ['uri' => 'urn:Calculator']);
$server->setClass(Calculator::class);
$server->handle();

Run the server

$ php -S localhost:8000

Errors

Throw a SoapFault to send an error to the client. Add this function to the Calculator class.

<?php
class Calculator {

    public function divide(int $a, int $b): float {
        if ($b === 0) {
            throw new SoapFault('Client', 'Can not divide by zero');
        }
        return $a / $b;
    }
}
