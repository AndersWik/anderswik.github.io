Functions

In php we can encapsulate code in functions. A function is written once and can then be called many times.

When defining a function we start with the function keyword. Then the name of the function.

All function names start with a letter or underscore. The rest of the name can be a letter (a-z/A-Z), number or underscore.

The functions code need to be between the curly braces. A function can contain any valid php code.

<?php
function printString() {
  echo "Hello";
}

printString();
// Output: Hello

Parameters

A function can have parameters. These variables can be used inside the function.

<?php
$parameter = "Hello";

function printString($par) {
  echo $par;
}

printString($parameter);
// Output: Hello

If we call a function with parameters without passing any parameters we get an error.

<?php
printString();

// Fatal error: Uncaught ArgumentCountError:
// Too few arguments to function printString()

Default value

We can give a default value to the parameters when defining the function. This allows us to call the function without passing any parameters.

<?php
function printString($par = "Unknown") {
  echo $par;
}

printString();
// Output: Unknown

Return

return sends a value back to the code that called the function and stops the function. It is often better to return a value than to print it, then the caller decides what to do with it.

<?php
function add($a, $b) {
  return $a + $b;
}

$sum = add(2, 3);
echo $sum;
// Output: 5

Scope

The variables in the function have a local scope. In the following function we try to access a global variable.

<?php
$val = "Hello";
function printString() {
  echo $val;
}

printString();
// Output: Warning: Undefined variable $val

The output becomes nothing but a warning, because the variable is not defined in the local scope.

To access a global variable in the function we must use the global key word.

<?php
$val = "Hello";
function printString() {
  global $val;
  echo $val;
}

printString();
// Output: Hello

Note: using the global keyword can make the code unclear. It is better to pass the variables as parameters to the function. Read more in Variable scope.
