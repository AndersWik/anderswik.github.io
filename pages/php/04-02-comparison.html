Comparison operators

Comparison operators compare two values and return true or false.

Loose equals

== compares the values after converting them to the same type. 0 and false are equal.

<?php
if (0 == false) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering the If.

Strict equals

=== also compares the type. 0 is an integer and false is a boolean, so they are not identical. Prefer ===, it avoids many surprises.

<?php
if (0 === false) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering else.
<?php
if (0 === 0) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering the If.

Loose not equals

<?php
if (0 != false) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering else.

Strict not equals

<?php
if (0 !== false) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering the If.
<?php
if (false !== false) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering else.

Loose not equals with <>

<> is the same as !=.

<?php
if (0 <> false) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering else.
<?php
if (0 <> 1) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering the If.

Less than

<?php
if (0 < 1) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering the If.
<?php
if (1 < 0) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering else.

Less than or equals

<?php
if (1 <= 1) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering the If.
<?php
if (1 <= 0) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering else.

More than

<?php
if (1 > 0) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering the If.
<?php
if (1 > 1) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering else.

More than or equals

<?php
if (1 >= 0) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering the If.
<?php
if (0 >= 1) {
  echo "Entering the If.";
} else {
  echo "Entering else.";
}
// Output: Entering else.

Spaceship

<=> returns -1 if the left value is smaller, 0 if they are equal and 1 if the left value is bigger. It is mostly used when sorting.

<?php
echo 1 <=> 2;
// Output: -1

echo 2 <=> 2;
// Output: 0

echo 3 <=> 2;
// Output: 1

Null coalescing

?? returns the left value if it exists and is not null, otherwise the right value. It does not give a warning for missing variables or keys.

<?php
$name = $_GET["name"] ?? "Guest";
echo $name;
// Output: Guest
