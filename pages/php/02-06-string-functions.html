String functions

PHP has a lot of built in functions for working with strings. These are the most used.

Sprintf

sprintf builds a string from a template. %s is replaced with a string, %d with an integer and %.2f with a float with two decimals. printf works the same but prints the result.

<?php
$text = sprintf("%s has %d items that cost %.2f", "Anna", 3, 9.5);
echo $text;
// Output: Anna has 3 items that cost 9.50

printf("%05d", 42);
// Output: 00042

Length

strlen counts bytes. Letters like å, ä and ö use two bytes in UTF-8, so use mb_strlen to count characters.

<?php
echo strlen("Hello");
// Output: 5

echo strlen("Åsa");
// Output: 4

echo mb_strlen("Åsa");
// Output: 3

Upper and lower case

<?php
echo strtoupper("Hello");
// Output: HELLO

echo strtolower("Hello");
// Output: hello

echo ucfirst("hello world");
// Output: Hello world

echo mb_strtoupper("åsa");
// Output: ÅSA

Trim

trim removes whitespace from the start and end. ltrim and rtrim only remove from one side.

<?php
echo "[" . trim("  Hello  ") . "]";
// Output: [Hello]

Replace

<?php
echo str_replace("World", "PHP", "Hello World");
// Output: Hello PHP

Substring

substr returns a part of a string, from a start position and an optional length. A negative start counts from the end.

<?php
echo substr("Hello World", 0, 5);
// Output: Hello

echo substr("Hello World", -5);
// Output: World

Search

strpos returns the position of the first match or false. Always compare the result with !==, since a match at position 0 is also false in a loose comparison. PHP 8 added str_contains, str_starts_with and str_ends_with, which are easier to read.

<?php
var_dump(strpos("Hello World", "World"));
// Output: int(6)

if (strpos("Hello World", "Hello") !== false) {
  echo "Found";
}
// Output: Found

var_dump(str_contains("Hello World", "World"));
// Output: bool(true)

var_dump(str_starts_with("Hello World", "Hello"));
// Output: bool(true)

Repeat and pad

<?php
echo str_repeat("-", 10);
// Output: ----------

echo str_pad("7", 3, "0", STR_PAD_LEFT);
// Output: 007

Escape for HTML

htmlspecialchars turns <, >, & and quotes into HTML entities. Always use it when printing text from a user on a web page, otherwise the user can inject HTML and JavaScript into the page.

<?php
echo htmlspecialchars('<script>alert("Hi")</script>');
// Output: &lt;script&gt;alert(&quot;Hi&quot;)&lt;/script&gt;
