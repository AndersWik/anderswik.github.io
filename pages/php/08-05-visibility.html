Visibility

Visibility of attributes

We can set the visibility on variables and functions.

  • Public can be used from everywhere
  • Protected can be used from the class itself and from classes that extend it
  • Private can only be used from the class itself

From instance

We create a class and make a instance of it.

<?php
class Foo {

	public $memberPublic = "Public";
	protected $memberProtected = "Protected";
	private $memberPrivate = "Private";
}

$foo = new Foo();

We can see that only the public variable is accessible when calling the members from an instance variable.

<?php
// 1: Foo Public:
echo $foo->memberPublic;
// Output: Public
// 2: Foo Protected:
echo $foo->memberProtected;
// Output: Fatal error: Uncaught Error: Cannot access protected property Foo::$memberProtected
// 3: Foo Private:
echo $foo->memberPrivate;
// Output: Fatal error: Uncaught Error: Cannot access private property Foo::$memberPrivate

The same applies to classes that inherit the variables, only public variables can be accessed. The private variable of Foo does not exist at all as seen from outside of Foo, so it gives a warning instead of an error.

<?php
class Bar extends Foo {

}

$extendsFoo = new Bar();
<?php
// 1: Foo Public:
echo $extendsFoo->memberPublic;
// Output: Public
// 2: Foo Protected:
echo $extendsFoo->memberProtected;
// Output: Fatal error: Uncaught Error: Cannot access protected property Bar::$memberProtected
// 3: Foo Private:
echo $extendsFoo->memberPrivate;
// Output: Warning: Undefined property: Bar::$memberPrivate

From within class

To access the non public variables we need to call them from within the class. We can do this if we create functions in the class that return the variables. We make all the functions public. This to enable us to access them from an instance of the class.

<?php
class Foo {

	public $memberPublic = "Public";
	protected $memberProtected = "Protected";
	private $memberPrivate = "Private";

	function getPub() {
		return $this->memberPublic;
	}

	function getPro() {
		return $this->memberProtected;
	}

	function getPriv() {
		return $this->memberPrivate;
	}

}

$foo = new Foo();

Now we can get all the values.

<?php
// 1: Foo Public:
echo $foo->getPub();
// Output: Public
// 2: Foo Protected:
echo $foo->getPro();
// Output: Protected
// 3: Foo Private:
echo $foo->getPriv();
// Output: Private

From extended class

We have the same Foo class as before. We make another class and extend the foo class. Then we make an instance of our new class. We can call all our functions from the instance since they are all public. The call to the variables all happen in the context of the extended class.

<?php
class Bar extends Foo {

	function getPub() {
		return $this->memberPublic;
	}

	function getPro() {
		return $this->memberProtected;
	}

	function getPriv() {
		return $this->memberPrivate;
	}

}

$extendsFoo = new Bar();

From the extended class we can access both the public and protected variable. We can not access the variable that is private.

<?php
// 1: Foo Extends Public:
echo $extendsFoo->getPub();
// Output: Public
// 2: Foo Extends Protected:
echo $extendsFoo->getPro();
// Output: Protected
// 3: Foo Extends Private:
echo $extendsFoo->getPriv();
// Output: Warning: Undefined property: Bar::$memberPrivate

Using Parent Self This

Variables that are not static belong to the object, and $this-> is the only way to reach them. parent:: and self:: can not be used for them, they are used for functions, static variables and constants. What we can do is call the function of the parent with parent:: and see which value it gets.

In our child class we can overshadow the variable in the base class.

Public

The child declares the public variable again with a new value. An object only has one public variable with that name, so all three functions return the value from Bar, even the function that is written in Foo.

<?php
class Foo {

	public $memberPublic = "Foo Public";

	function getPub() {
		return $this->memberPublic;
	}

}

class Bar extends Foo {

	public $memberPublic = "Bar Public";

	function getPubParent() {
		return parent::getPub();
	}

	function getPubSelf() {
		return self::getPub();
	}

	function getPubThis() {
		return $this->memberPublic;
	}

}

$extendsFoo = new Bar();
<?php
// 1: Foo Extends Parent:
echo $extendsFoo->getPubParent();
// Output: Bar Public
// 2: Foo Extends Self:
echo $extendsFoo->getPubSelf();
// Output: Bar Public
// 3: Foo Extends This:
echo $extendsFoo->getPubThis();
// Output: Bar Public

Protected

Protected works the same way as public. The child replaces the value.

<?php
class Foo {

	protected $memberProtected = "Foo Protected";

	function getPro() {
		return $this->memberProtected;
	}

}

class Bar extends Foo {

	protected $memberProtected = "Bar Protected";

	function getProParent() {
		return parent::getPro();
	}

	function getProSelf() {
		return self::getPro();
	}

	function getProThis() {
		return $this->memberProtected;
	}

}

$extendsFoo = new Bar();
<?php
// 1: Foo Extends Parent:
echo $extendsFoo->getProParent();
// Output: Bar Protected
// 2: Foo Extends Self:
echo $extendsFoo->getProSelf();
// Output: Bar Protected
// 3: Foo Extends This:
echo $extendsFoo->getProThis();
// Output: Bar Protected

Private

Private is different. Foo and Bar each get their own private variable, even though they have the same name. The function written in Foo sees the variable from Foo, and the function written in Bar sees the one from Bar. self::getPri() finds the function in Foo, so it also returns the value from Foo.

<?php
class Foo {

	private $memberPrivate = "Foo Private";

	function getPri() {
		return $this->memberPrivate;
	}

}

class Bar extends Foo {

	private $memberPrivate = "Bar Private";

	function getPriParent() {
		return parent::getPri();
	}

	function getPriSelf() {
		return self::getPri();
	}

	function getPriThis() {
		return $this->memberPrivate;
	}

}

$extendsFoo = new Bar();
<?php
// 1: Foo Extends Parent:
echo $extendsFoo->getPriParent();
// Output: Foo Private
// 2: Foo Extends Self:
echo $extendsFoo->getPriSelf();
// Output: Foo Private
// 3: Foo Extends This:
echo $extendsFoo->getPriThis();
// Output: Bar Private
