Boolean

A Boolean can have the value true or false.

<?php
$val = true;

echo gettype( $val );
// Output: boolean

echo is_bool( $val );
// Output: 1

Casting

In php we can cast other variables to booleans. We can cast an integer to a boolean.

<?php
$variable = -1;
var_dump( (bool) $variable );
// Output: bool(true)

$variable = 0;
var_dump( (bool) $variable );
// Output: bool(false)

$variable = 1;
var_dump( (bool) $variable );
// Output: bool(true)

Notice that -1 is cast to true. We can also cast a float to a boolean.

<?php
$variable = -1.0;
var_dump( (bool) $variable );
// Output: bool(true)

$variable = 0.0;
var_dump( (bool) $variable );
// Output: bool(false)

$variable = 1.0;
var_dump( (bool) $variable );
// Output: bool(true)

Notice that -1.0 is cast to true. We can also cast a string to a boolean.

<?php
$variable = "";
var_dump( (bool) $variable );
// Output: bool(false)

$variable = "0";
var_dump( (bool) $variable );
// Output: bool(false)

$variable = "false";
var_dump( (bool) $variable );
// Output: bool(true)

$variable = "False";
var_dump( (bool) $variable );
// Output: bool(true)

$variable = "1";
var_dump( (bool) $variable );
// Output: bool(true)

$variable = "true";
var_dump( (bool) $variable );
// Output: bool(true)

$variable = "True";
var_dump( (bool) $variable );
// Output: bool(true)

Notice that only a empty string and "0" is cast to false. All other strings are cast to true. Even "false" and "False" are cast to true.

All values that are false

  • false
  • 0 and 0.0
  • "" and "0"
  • an empty array []
  • null

Everything else is cast to true.

Defining Constants

Boolean Constant

<?php
define("BOOLEANCONSTANT", true);

echo gettype( BOOLEANCONSTANT );
//Outputs: boolean

echo BOOLEANCONSTANT;
//Outputs: 1
