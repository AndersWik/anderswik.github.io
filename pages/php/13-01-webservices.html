Web services

A web service is an application that other programs talk to over HTTP, instead of people with a browser. The common styles are REST, RPC and SOAP.

Debug requests

When building a web service it helps to see exactly what the client sends. Call this file to save the headers, the parameters and the body of every request to curl.txt. It also sets a cookie, so you can see that the client sends it back on the next request.

Only use it while developing. Put the file outside of the public web folder, or remove it afterwards, since it saves everything that is sent, also passwords.

<?php
$value = rand (1 , 100);
setcookie("CookieMonster", $value, time()+3600);

$my_file = 'curl.txt';
$handle = fopen($my_file, 'w') or die('Cannot open file:  '.$my_file);

fwrite($handle, "============ HEADERS ============\n");

foreach (getallheaders() as $name => $value) {
    fwrite($handle, "$name: $value\n");
}

fwrite($handle, "============ REQUEST ============\n");

$data = print_r($_REQUEST, true);
fwrite($handle, $data);

fwrite($handle, "============ BODY ============\n");

$data = file_get_contents('php://input');
fwrite($handle, $data);

fwrite($handle, "\n============ END ============\n");

fclose($handle);
$ php -S localhost:8000 debug.php
$ curl -X POST -d "name=Anna" http://localhost:8000/
$ cat curl.txt
