Custom requests

Browsers and HTML forms only send GET and POST. Other clients, like curl and JavaScript, can also send PUT, PATCH and DELETE, which are used by REST APIs.

Client with cURL

<?php
$curl = curl_init("http://localhost:8888/users/5");
curl_setopt_array($curl, [
  CURLOPT_CUSTOMREQUEST => "PATCH",
  CURLOPT_POSTFIELDS => json_encode(["name" => "Anna"]),
  CURLOPT_HTTPHEADER => ["Content-Type: application/json"],
  CURLOPT_RETURNTRANSFER => true,
]);
$result = curl_exec($curl);

Client with file_get_contents

<?php
$context = stream_context_create([
  "http" => [
    "method" => "DELETE",
    "ignore_errors" => true,
  ],
]);
$result = file_get_contents("http://localhost:8888/users/5", false, $context);

Server

PHP only fills $_POST for POST requests with form data. For PUT, PATCH and DELETE the body is read from php://input.

<?php
$method = $_SERVER['REQUEST_METHOD'];

if ($method === 'PUT' || $method === 'PATCH') {
  $data = json_decode(file_get_contents('php://input'), true);

  if (!is_array($data)) {
    http_response_code(400);
    exit("Send a JSON object");
  }
  echo "Update with " . htmlspecialchars(implode(", ", array_keys($data)));
} elseif ($method === 'DELETE') {
  http_response_code(204);
}

Method override

An HTML form can send another method in a hidden field. The server then treats the POST as that method. Only allow the methods you expect.

<form method="post" action="/users/5">
  <input type="hidden" name="_method" value="DELETE">
  <button>Delete</button>
</form>
<?php
$method = $_SERVER['REQUEST_METHOD'];

if ($method === 'POST' && in_array($_POST['_method'] ?? '', ['PUT', 'PATCH', 'DELETE'], true)) {
  $method = $_POST['_method'];
}

Test from the command line

$ curl -i -X PUT -H "Content-Type: application/json" -d '{"name":"Anna"}' http://localhost:8888/users/5
$ curl -i -X DELETE http://localhost:8888/users/5
