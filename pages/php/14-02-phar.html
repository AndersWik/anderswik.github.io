Phar

A Phar (PHP Archive) packs a whole PHP application into one file, like a .jar file in Java. It is the common way to share command line tools. Composer itself is shipped as composer.phar.

Run a phar

$ php composer.phar --version

Create a phar

The application is in the folder src and starts in src/index.php.

hello/
  build.php
  src/
    index.php
    Greeter.php
<?php
// src/index.php
require __DIR__ . '/Greeter.php';

echo (new Greeter())->greet($argv[1] ?? 'World') . PHP_EOL;
<?php
// src/Greeter.php
class Greeter {
  public function greet(string $name): string {
    return "Hello $name";
  }
}

build.php creates the archive. The stub is the code that runs first when the phar is started. The shebang line makes it possible to run the file directly.

<?php
// build.php
$file = __DIR__ . '/hello.phar';

if (file_exists($file)) {
  unlink($file);
}

$phar = new Phar($file);
$phar->buildFromDirectory(__DIR__ . '/src');
$phar->setStub("#!/usr/bin/env php\n" . $phar->createDefaultStub('index.php'));

echo "Created $file\n";

Creating phar files is turned off by default with the setting phar.readonly. Turn it off only for the build.

$ php -d phar.readonly=0 build.php
Created /home/user/hello/hello.phar
$ chmod +x hello.phar
$ ./hello.phar Anna
Hello Anna

__DIR__ inside the phar points into the archive, like phar:///home/user/hello/hello.phar, so require works as usual.

List the content

<?php
$phar = new Phar(__DIR__ . '/hello.phar');

foreach (new RecursiveIteratorIterator($phar) as $file) {
  echo $file->getPathname() . "\n";
}

Security

A phar can contain any code. Only run phar files from sources you trust, and check the signature or checksum when it is published.
