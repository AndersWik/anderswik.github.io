Polymorphism

Polymorphism means "many shapes". Different classes have functions with the same name, and the code that calls them does not need to know which class it has. Each object does its own version. In PHP this is done with interfaces, abstract classes or by overriding functions with inheritance.

<?php
interface Shape {
  public function area(): float;
}

class Rectangle implements Shape {

  public function __construct(private float $width, private float $height) {
  }

  public function area(): float {
    return $this->width * $this->height;
  }
}

class Circle implements Shape {

  public function __construct(private float $radius) {
  }

  public function area(): float {
    return M_PI * $this->radius ** 2;
  }
}

$shapes = [new Rectangle(2, 3), new Circle(1)];

$total = 0;
foreach ($shapes as $shape) {
  $total += $shape->area();
}

echo round($total, 2);
// Output: 9.14

The loop only knows that every object is a Shape. Adding a new shape, like a triangle, does not change the loop at all.

Without polymorphism

The same code without polymorphism needs to check the type of every object. Every new shape means another if.

<?php
foreach ($shapes as $shape) {
  if ($shape instanceof Rectangle) {
    // calculate rectangle
  } elseif ($shape instanceof Circle) {
    // calculate circle
  }
}
