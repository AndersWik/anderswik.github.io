JSON

JSON is a text format for data, used by almost every web API. PHP converts between JSON and arrays or objects with json_encode and json_decode.

Json Encode

json_encode turns a PHP value into a JSON string. Arrays with keys become objects and lists become arrays. Letters like Å are escaped by default, JSON_UNESCAPED_UNICODE keeps them as they are.

<?php
$data = ["name" => "Åsa", "age" => 30, "tags" => ["php", "sql"]];

echo json_encode($data);
// Output: {"name":"\u00c5sa","age":30,"tags":["php","sql"]}

echo json_encode($data, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES);
// Output:
// {
//     "name": "Åsa",
//     "age": 30,
//     "tags": [
//         "php",
//         "sql"
//     ]
// }

Json Decode

json_decode turns a JSON string into PHP values. With true as the second parameter objects become arrays, otherwise they become stdClass objects.

<?php
$json = '{"name":"Anna","age":30}';

$array = json_decode($json, true);
echo $array["name"];
// Output: Anna

$object = json_decode($json);
echo $object->name;
// Output: Anna

Errors

json_decode returns null for invalid JSON, which can not be told apart from the JSON null. JSON_THROW_ON_ERROR throws an exception instead.

<?php
try {
  $data = json_decode('{"name":', true, 512, JSON_THROW_ON_ERROR);
} catch (JsonException $e) {
  echo "Invalid JSON: " . $e->getMessage();
}
// Output: Invalid JSON: Syntax error

Send JSON

<?php
header("Content-Type: application/json");
echo json_encode(["ok" => true]);

Json Serializable

A class that implements JsonSerializable decides what json_encode should output for it. Without it only the public variables are included.

<?php
class MyColors implements JsonSerializable {

    private array $colors = ["red" => "#ff0000", "yellow" => "#ffff00"];

    public function jsonSerialize(): mixed {
        return $this->colors;
    }
}

echo json_encode(new MyColors());
// Output: {"red":"#ff0000","yellow":"#ffff00"}
