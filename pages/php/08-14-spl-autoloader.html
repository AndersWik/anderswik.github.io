SPL autoloader

An autoloader loads the file for a class the first time the class is used, so we do not need a require for every class. spl_autoload_register registers a function that PHP calls with the full class name when it finds a class it does not know.

Folder structure

The common way, called PSR-4, is that the namespace follows the folders. The class App\Models\User is in the file src/Models/User.php.

project/
  index.php
  src/
    Models/
      User.php
<?php
// src/Models/User.php
namespace App\Models;

class User {
  public function getName(): string {
    return "Anna";
  }
}

Register an autoloader

<?php
// index.php
spl_autoload_register(function (string $class) {
  $prefix = 'App\\';
  $baseDir = __DIR__ . '/src/';

  if (!str_starts_with($class, $prefix)) {
    return;
  }

  $relative = substr($class, strlen($prefix));
  $file = $baseDir . str_replace('\\', '/', $relative) . '.php';

  if (is_file($file)) {
    require $file;
  }
});

use App\Models\User;

$user = new User();
echo $user->getName();
// Output: Anna

'App\\' is the string App\, the backslash needs to be escaped. Classes from other namespaces are left for other autoloaders.

Composer

In real projects the autoloader is usually created by Composer. Add the namespace to composer.json and run composer dump-autoload.

{
  "autoload": {
    "psr-4": {
      "App\\": "src/"
    }
  }
}
$ composer dump-autoload
<?php
require __DIR__ . '/vendor/autoload.php';

$user = new App\Models\User();
