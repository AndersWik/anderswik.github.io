Multidimensional arrays

A multidimensional array is an array that contains other arrays. Use one pair of brackets for every level.

<?php
$value = array( array("A","B","C"),
            array("D","E","F"),
            array("G","H","I"));

print_r($value[1]);
// Output: Array ( [0] => D [1] => E [2] => F )

echo $value[1][1];
// Output: E

The inner arrays can have keys too.

<?php
$value = array( array("A" => "a","B" => "b","C" => "c"),
            array("D" => "d","E" => "e","F" => "f"),
            array("G" => "g","H" => "h","I" => "i"));

print_r($value[1]);
// Output: Array ( [D] => d [E] => e [F] => f )

echo $value[1]['E'];
// Output: e

A list of records

A common use is a list of rows, like the result from a database. Loop over it with foreach.

<?php
$users = [
  ["id" => 1, "name" => "Anna"],
  ["id" => 2, "name" => "Bo"],
];

foreach ($users as $user) {
  echo $user["id"] . ": " . $user["name"] . "\n";
}
// Output: 1: Anna
//         2: Bo

$users[] = ["id" => 3, "name" => "Cecilia"];
echo count($users);
// Output: 3
