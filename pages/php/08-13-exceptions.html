Exceptions

An exception is thrown when something goes wrong. It stops the normal flow of the code, until it is caught by a try and catch. If it is never caught the script stops with a fatal error.

Try and catch

<?php
function divide(int $a, int $b): float {
  if ($b === 0) {
    throw new InvalidArgumentException("Can not divide by zero");
  }
  return $a / $b;
}

try {
  echo divide(10, 0);
} catch (InvalidArgumentException $e) {
  echo "Error: " . $e->getMessage();
}
// Output: Error: Can not divide by zero

Finally

The code in finally always runs, both when an exception was thrown and when it was not. It is used to clean up, like closing a file.

<?php
$file = fopen(__DIR__ . "/data.txt", "r");

try {
  // Read the file
} finally {
  fclose($file);
}

Catch more than one type

Many catch blocks can follow each other. The first one that matches is used. | catches several types in one block.

<?php
try {
  // Code that can fail
} catch (InvalidArgumentException | LengthException $e) {
  echo "Bad input";
} catch (Exception $e) {
  echo "Something else went wrong";
}

Exception and Error

Exception is for errors the code can expect, like a missing file. Error is thrown by PHP itself for programming errors, like calling a function that does not exist or a TypeError. Both implement Throwable, so catch Throwable to catch everything.

<?php
try {
  undefinedFunction();
} catch (Error $e) {
  echo get_class($e) . ": " . $e->getMessage();
}
// Output: Error: Call to undefined function undefinedFunction()

Custom exception

Extend Exception to create your own type, so it can be caught separately.

<?php
class NotFoundException extends Exception {
}

function findUser(int $id): array {
  throw new NotFoundException("User $id not found");
}

try {
  findUser(5);
} catch (NotFoundException $e) {
  http_response_code(404);
  echo $e->getMessage();
}
// Output: User 5 not found

Do not show the message to visitors

Exception messages can contain paths, SQL or passwords. Log the details with error_log and show a general message on a public site.

<?php
try {
  // Code that can fail
} catch (Throwable $e) {
  error_log($e->getMessage());
  http_response_code(500);
  echo "Something went wrong.";
}
