MVC controller

The controller connects the parts. It reads the request, validates the input, calls the model and renders a view. Each public function is called an action and handles one route.

The controller

<?php
// src/NoteController.php
class NoteController {

  public function __construct(private NoteModel $notes) {
  }

  public function index(string $error = ''): void {
    $this->render('Notes', 'notes/index', [
      'notes' => $this->notes->all(),
      'error' => $error,
    ]);
  }

  public function show(string $id): void {
    $note = ctype_digit($id) ? $this->notes->find((int) $id) : null;

    if ($note === null) {
      http_response_code(404);
      echo 'Note not found';
      return;
    }

    $this->render($note['title'], 'notes/show', ['note' => $note]);
  }

  public function store(): void {
    $title = trim(is_string($_POST['title'] ?? null) ? $_POST['title'] : '');
    $body = trim(is_string($_POST['body'] ?? null) ? $_POST['body'] : '');

    if ($title === '' || $body === '' || mb_strlen($title) > 100) {
      http_response_code(422);
      $this->index('Write a title of at most 100 characters and a note.');
      return;
    }

    $id = $this->notes->create($title, $body);
    header('Location: /notes/' . $id, true, 303);
  }

  private function render(string $title, string $template, array $data): void {
    echo view('layout', [
      'title' => $title,
      'content' => view($template, $data),
    ]);
  }
}

After a note is saved the controller redirects with 303 See Other, so reloading the page does not save it again. Read more in Post.

The front controller

index.php creates the objects and connects the routes to the actions.

<?php
// public/index.php
declare(strict_types=1);

require __DIR__ . '/../src/Router.php';
require __DIR__ . '/../src/NoteModel.php';
require __DIR__ . '/../src/NoteController.php';
require __DIR__ . '/../src/view.php';

$pdo = new PDO('sqlite:' . __DIR__ . '/../data/notes.sqlite', null, null, [
  PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
  PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
]);

$controller = new NoteController(new NoteModel($pdo));

$router = new Router();
$router->get('/', fn() => $controller->index());
$router->get('/notes/{id}', fn(string $id) => $controller->show($id));
$router->post('/notes', fn() => $controller->store());

$router->dispatch($_SERVER['REQUEST_METHOD'], $_SERVER['REQUEST_URI']);

Run it

$ mkdir data
$ php -S localhost:8000 -t public public/index.php

Open http://localhost:8000 and add a note. The form changes data, so a public version should also have a CSRF token, see Sessions.
