Float

A Float value is a number with decimals. gettype calls it double for historical reasons.

<?php
$val = 1.234;

echo gettype( $val );
// Output: double

echo is_float( $val );
// Output: 1

Casting

We can cast other variables to floats. We can cast a boolean to a float.

<?php
$variable = true;
var_dump( (float) $variable );
// Output: float(1)

$variable = false;
var_dump( (float) $variable );
// Output: float(0)

We can also cast a integer to a float.

<?php
$variable = -1;
var_dump( (float) $variable );
// Output: float(-1)

$variable = 0;
var_dump( (float) $variable );
// Output: float(0)

$variable = 1;
var_dump( (float) $variable );
// Output: float(1)

We can also cast a string to a float.

<?php
$variable = "-1.5";
var_dump( (float) $variable );
// Output: float(-1.5)

$variable = "-1";
var_dump( (float) $variable );
// Output: float(-1)

$variable = "0";
var_dump( (float) $variable );
// Output: float(0)

$variable = "1";
var_dump( (float) $variable );
// Output: float(1)

$variable = "1.5";
var_dump( (float) $variable );
// Output: float(1.5)

$variable = "Some string";
var_dump( (float) $variable );
// Output: float(0)

Precision

Floats are stored in binary and can not hold every decimal number exactly. Never compare floats with ==, and never use floats for money. Store money as an integer number of cents instead.

<?php
var_dump(0.1 + 0.2 == 0.3);
// Output: bool(false)

echo round(3.14159, 2);
// Output: 3.14

Defining Constants

Float Constant

<?php
define("FLOATCONSTANT", 123.55);

echo gettype( FLOATCONSTANT );
//Outputs: double

echo FLOATCONSTANT;
//Outputs: 123.55
