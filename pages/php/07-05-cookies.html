Cookies

A cookie is a small value that the server asks the browser to store. The browser sends it back with every request to the same site. Cookies are stored by the visitor, who can read and change them, so never store secrets or trust the value.

Get cookie

To get the value from the cookie we use the COOKIE super global variable. Use ?? in case the cookie is not set.

<?php
echo $_COOKIE['ACookie'] ?? 'No cookie';

Set cookie

setcookie takes a name, a value and the time when it expires as a Unix timestamp. Here one hour from now. It sends a header, so it must be called before any output.

<?php
setcookie("ACookie", 'Testing', time()+3600);

The new cookie is not in $_COOKIE until the next request, when the browser sends it back.

Cookies can be named like an array. They are then read as an array from $_COOKIE['ACookie'].

<?php
setcookie("ACookie[one]", 'Test 1', time()+3600);
setcookie("ACookie[two]", 'Test 2', time()+3600);

Set cookie with options

Since PHP 7.3 the options can be given as an array. httponly hides the cookie from JavaScript, secure only sends it over HTTPS and samesite stops it from being sent with requests from other sites.

<?php
setcookie("ACookie", 'Testing', [
  'expires' => time() + 3600,
  'path' => '/',
  'secure' => true,
  'httponly' => true,
  'samesite' => 'Lax',
]);

Update cookie

When updating a cookie we set the new value to the same cookie name.

<?php
setcookie("ACookie", 'Testing', time()+3600);

Delete cookie

If we want to remove a cookie we set an expiration time that has passed and an empty value. The path must be the same as when the cookie was set.

<?php
setcookie("ACookie", '', time() - 3600);
