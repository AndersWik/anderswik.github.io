MySQL

PDO connects to MySQL with a DSN, a string that has the host, the database name and the character set, and a user name and password.

Connect and select

The example connects, runs a select and prints all rows as objects.

<?php
try {

  $pdo = new PDO("mysql:host=localhost;dbname=laracast","root","root");

} catch(PDOException $e) {

  die($e->getMessage());
}

$query = $pdo->prepare('select * from mytable');
$query->execute();

//var_dump($query->fetchAll());

var_dump($query->fetchAll(PDO::FETCH_OBJ));

fetchAll() returns every row as an array, fetchAll(PDO::FETCH_OBJ) as objects. Do not connect as root in a real application. Create a user that only has access to the database it needs, see MySQL users.

A better connection

charset=utf8mb4 makes sure all characters, also emojis, are stored correctly. The options make PDO throw exceptions on errors, return rows as associative arrays and use real prepared statements. Keep the password in a config file outside of the web folder, or in an environment variable.

<?php
$pdo = new PDO(
  "mysql:host=localhost;dbname=mydb;charset=utf8mb4",
  "myuser",
  getenv("DB_PASSWORD"),
  [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES => false,
  ]
);

Prepared statements

Never put values from a user directly into the SQL string. A value like 1 OR 1=1 would change the query. This is called SQL injection. Use placeholders instead and pass the values to execute. The database then always treats them as values.

<?php
// Wrong, open for SQL injection
$pdo->query("SELECT * FROM users WHERE id = " . $_GET['id']);

// Right
$stmt = $pdo->prepare("SELECT * FROM users WHERE id = :id");
$stmt->execute(["id" => $_GET['id'] ?? 0]);
$user = $stmt->fetch();

if ($user === false) {
  echo "No user found";
}

? can be used as placeholders too, then the values are given in order.

<?php
$stmt = $pdo->prepare("SELECT * FROM users WHERE age > ? AND city = ?");
$stmt->execute([18, "Stockholm"]);

foreach ($stmt as $row) {
  echo htmlspecialchars($row["name"]) . "<br>";
}

Placeholders only work for values. Table and column names can not be placeholders, so choose them from a fixed list in the code.

Insert, update and delete

<?php
$stmt = $pdo->prepare("INSERT INTO users (name, email) VALUES (:name, :email)");
$stmt->execute(["name" => "Anna", "email" => "anna@example.com"]);
$id = $pdo->lastInsertId();

$stmt = $pdo->prepare("UPDATE users SET name = :name WHERE id = :id");
$stmt->execute(["name" => "Anna Svensson", "id" => $id]);
echo $stmt->rowCount();
// Output: 1

$stmt = $pdo->prepare("DELETE FROM users WHERE id = :id");
$stmt->execute(["id" => $id]);

Transactions

A transaction makes several queries succeed or fail together. If something fails, rollBack undoes everything since beginTransaction.

<?php
try {
  $pdo->beginTransaction();

  $pdo->prepare("UPDATE accounts SET balance = balance - 100 WHERE id = 1")->execute();
  $pdo->prepare("UPDATE accounts SET balance = balance + 100 WHERE id = 2")->execute();

  $pdo->commit();
} catch (Throwable $e) {
  $pdo->rollBack();
  throw $e;
}
