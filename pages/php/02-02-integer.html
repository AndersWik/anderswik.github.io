Integer

A Integer value is a number without any decimals.

<?php
$val = 123;

echo gettype( $val );
// Output: integer

echo is_int( $val );
// Output: 1

echo prints true as 1 and false as nothing, which is why is_int prints 1.

Casting

We can cast other variables to integers. We can cast a boolean to a integer.

<?php
$variable = true;
var_dump( (int) $variable );
// Output: int(1)

$variable = false;
var_dump( (int) $variable );
// Output: int(0)

We can also cast a float to a integer.

<?php
$variable = -1.3;
var_dump( (int) $variable );
// Output: int(-1)

$variable = 0.0;
var_dump( (int) $variable );
// Output: int(0)

$variable = 1.6;
var_dump( (int) $variable );
// Output: int(1)

Notice that 1.6 is not rounded up. Instead the decimal is cut off. Use round if the number should be rounded. We can also cast a string to a integer.

<?php
$variable = "-1.5";
var_dump( (int) $variable );
// Output: int(-1)

$variable = "-1";
var_dump( (int) $variable );
// Output: int(-1)

$variable = "0";
var_dump( (int) $variable );
// Output: int(0)

$variable = "1";
var_dump( (int) $variable );
// Output: int(1)

$variable = "1.5";
var_dump( (int) $variable );
// Output: int(1)

$variable = "Some string";
var_dump( (int) $variable );
// Output: int(0)

Defining Constants

Integer Constant

<?php
define("INTEGERCONSTANT", 123);

echo gettype( INTEGERCONSTANT );
//Outputs: integer

echo INTEGERCONSTANT;
//Outputs: 123

More about integer

  • intdiv(7, 2) divides and returns an integer, 3
