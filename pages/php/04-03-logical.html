Logical operators

When assessing a statement we can add multiple conditions that needs to be true or false.

Name "And"

When the and operator is used both the statement to the left and right of and needs to evaluate to true.

<?php
if (true and true) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering the If.
<?php
if (true and false) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering Else.
<?php
if (false and false) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering Else.

The && works the same as the and operator. Both statement needs to evaluate to true. The only difference is that && has greater precedence than and. and even has lower precedence than =, so $a = true and false; sets $a to true. Use && to avoid that.

<?php
if (true && true) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering the If.
<?php
if (false && true) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering Else.
      true false
true  | X | - |
false | - | - |

Name "Or"

When the or operator is used only one of the statements needs to evaluate to true.

<?php
if (true or true) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering the If.
<?php
if (true or false) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering the If.
<?php
if (false or false) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering Else.

The || works the same as the or operator. Only one statement needs to evaluate to true. The only difference is that || has greater precedence than or.

<?php
if (true || false) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering the If.
<?php
if (false || false) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering Else.
      true false
true  | X | X |
false | X | - |

Name "Xor"

When the xor operator is used only one of the statements can be true.

<?php
if (true xor true) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering Else.
<?php
if (true xor false) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering the If.
<?php
if (false xor false) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering Else.
      true false
true  | - | X |
false | X | - |

Name "Not"

When the ! operator is used the statements value is inverted. True equals false and false equals true.

<?php
if (!true) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering Else.
<?php
if (!false) {
  echo "Entering the If.";
} else {
  echo "Entering Else.";
}
// Output: Entering the If.

Short circuit

PHP stops as soon as the answer is known. With && the right side is not run if the left side is false, and with || it is not run if the left side is true. This is often used to check that something exists before using it.

<?php
$user = null;

if ($user !== null && $user["admin"]) {
  echo "Admin";
}
// Output: nothing, and no warning
