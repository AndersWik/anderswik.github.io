Comments

Comments are ignored by PHP. They are used to explain the code to the next person who reads it, often yourself.

Single line

Everything after // until the end of the line is a comment.

<?php
// Single line

Single line shell style

# works the same way as //. // is more common.

<?php
# Single line shell style

Multiline

Everything between /* and */ is a comment, even if it covers many lines. Multiline comments can not be nested.

<?php
/* Multiline
   Multiline
   Multiline */

Phpdoc

A Phpdoc block starts with /** and is written right above a function, class or variable. Editors and documentation tools read it, for example to know the types of the parameters.

<?php
/* Phpdoc
 *
 * Text text text.
 * Text text text.
 */
<?php
/**
 * Adds two numbers.
 *
 * @param int $a The first number
 * @param int $b The second number
 * @return int The sum
 */
function add($a, $b) {
  return $a + $b;
}
