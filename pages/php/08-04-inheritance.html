Inheritance

A class can inherit from another class with extends. The child class gets all public and protected functions and variables of the parent class, and can add its own or override them.

<?php
class Foo {

  function whoAmI() {
    return "I am ".__CLASS__;
  }


}

class Bar extends Foo {

}

$bar = new Bar();
echo $bar->whoAmI();
// Output: I am Foo
?>

__CLASS__ is the name of the class where the code is written, so it is Foo even when called on a Bar.

Override

If the child class has a function with the same name, it replaces the function from the parent.

<?php
class Foo {

  function whoAmI() {
    return "I am ".__CLASS__;
  }


}

class Bar extends Foo {

  function whoAmI() {
    return "I am ".__CLASS__;
  }

}

$bar = new Bar();
echo $bar->whoAmI();
// Output: I am Bar

Parent

It is not possible to call the overridden parent class function from a variable that have a child instance. We can call the parent function from within the child class using the parent keyword.

<?php
class Foo {

  function whoAmI() {
    return "I am ".__CLASS__;
  }


}

class Bar extends Foo {

  function whoAmI() {
    return "I am ".__CLASS__;
  }

  function whoIsMyParent() {
    return parent::whoAmI();
  }

}

$bar = new Bar();
echo $bar->whoIsMyParent();
// Output: I am Foo

Parent constructor

The parent construct is not called by default when the child has its own constructor.

<?php
class Foo {

  function __construct() {

    echo "I am Foo";
  }
}

class Bar extends Foo {

  function __construct() {

    echo "I am Bar";
  }
}

$bar = new Bar();
// Output: I am Bar

If we want the parent construct to be called we need to do it from the child constructor.

<?php
class Foo {

  function __construct() {

    echo "I am Foo";
  }
}

class Bar extends Foo {

  function __construct() {
    parent::__construct();
    echo "I am Bar";
  }
}

$bar = new Bar();
// Output: I am FooI am Bar

Final

A final class can not be extended and a final function can not be overridden.

<?php
final class Foo {
}

class Bar extends Foo {
}
// Output: Fatal error: Class Bar cannot extend final class Foo
