Routers

A router decides which code should handle a request, based on the method and the path of the URL. All requests are sent to one file, the front controller, often public/index.php. Then the URLs can look like /notes/5 instead of /note.php?id=5.

Send all requests to index.php

With the built-in server, give the front controller as the last argument. -t public makes public the web root, so the other folders can not be reached from a browser.

$ php -S localhost:8000 -t public public/index.php

On Apache a .htaccess file in the public folder does the same. Files that exist, like images and CSS, are still served directly.

RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteRule ^ index.php [QSA,L]

A simple router

The routes are listed in an array. The path is compared with a regular expression, and the parts in parentheses are passed on to the function.

<?php
// public/index.php
$routes = [
  'GET' => [
    '#^/$#' => fn() => 'Home page',
    '#^/notes/(\d+)$#' => fn(string $id) => 'Note ' . (int) $id,
  ],
  'POST' => [
    '#^/notes$#' => fn() => 'Create note',
  ],
];

$method = $_SERVER['REQUEST_METHOD'];
$path = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH) ?: '/';

foreach ($routes[$method] ?? [] as $pattern => $handler) {
  if (preg_match($pattern, $path, $matches)) {
    array_shift($matches);
    echo $handler(...$matches);
    exit;
  }
}

http_response_code(404);
echo 'Page not found';

A router class

A small class makes the routes easier to write. {id} in the path is turned into a named group in the regular expression. If the path exists but not for this method the router answers 405 Method Not Allowed.

<?php
// src/Router.php
class Router {

  private array $routes = [];

  public function get(string $path, callable $handler): void {
    $this->add('GET', $path, $handler);
  }

  public function post(string $path, callable $handler): void {
    $this->add('POST', $path, $handler);
  }

  public function add(string $method, string $path, callable $handler): void {
    $regex = '#^' . preg_replace('#\{(\w+)\}#', '(?P<$1>[^/]+)', $path) . '$#';
    $this->routes[] = [$method, $regex, $handler];
  }

  public function dispatch(string $method, string $uri): void {
    $path = parse_url($uri, PHP_URL_PATH);
    if (!is_string($path)) {
      $path = '/';
    }

    $allowed = [];
    foreach ($this->routes as [$routeMethod, $regex, $handler]) {
      if (preg_match($regex, $path, $matches) !== 1) {
        continue;
      }
      if ($routeMethod !== $method) {
        $allowed[] = $routeMethod;
        continue;
      }
      $params = array_filter($matches, 'is_string', ARRAY_FILTER_USE_KEY);
      $handler(...$params);
      return;
    }

    if ($allowed) {
      http_response_code(405);
      header('Allow: ' . implode(', ', array_unique($allowed)));
      echo 'Method not allowed';
      return;
    }

    http_response_code(404);
    echo 'Page not found';
  }
}

Only the named groups are kept, and they are passed as named arguments, which needs PHP 8.1.

<?php
// public/index.php
require __DIR__ . '/../src/Router.php';

$router = new Router();

$router->get('/', function () {
  echo 'Home page';
});

$router->get('/notes/{id}', function (string $id) {
  echo 'Note ' . htmlspecialchars($id);
});

$router->dispatch($_SERVER['REQUEST_METHOD'], $_SERVER['REQUEST_URI']);

The values from the URL are strings from the visitor. Validate them in the handler. The MVC pages build a small notes application on top of this router.
