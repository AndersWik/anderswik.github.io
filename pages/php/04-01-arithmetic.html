Arithmetic operators

Arithmetic operators do math with numbers.

+
-
/
*
%
**
()

Examples

% (modulo) gives the remainder of a division. ** raises to a power. Parentheses decide what is calculated first, otherwise * and / go before + and -.

<?php
echo 5 + 2;
// Output: 7

echo 5 - 2;
// Output: 3

echo 5 / 2;
// Output: 2.5

echo 5 * 2;
// Output: 10

echo 5 % 2;
// Output: 1

echo 5 ** 2;
// Output: 25

echo 2 + 3 * 4;
// Output: 14

echo (2 + 3) * 4;
// Output: 20

Division by zero

Dividing by zero throws a DivisionByZeroError since PHP 8.

<?php
echo 1 / 0;
// Output: Fatal error: Uncaught DivisionByZeroError: Division by zero

Assignment operators

<?php
$val = 10;

$val += 5;  // $val = $val + 5
$val -= 3;  // $val = $val - 3
$val *= 2;  // $val = $val * 2
$val /= 4;  // $val = $val / 4

echo $val;
// Output: 6

Increment and decrement

++ adds one and -- subtracts one. Before the variable it changes the value first, after the variable it returns the old value first.

<?php
$i = 5;

echo $i++;
// Output: 5

echo $i;
// Output: 6

echo ++$i;
// Output: 7
