SPL observer

The observer pattern lets objects subscribe to changes in another object. The subject keeps a list of observers and notifies all of them when something happens. The subject does not need to know what the observers do. PHP has the interfaces SplSubject and SplObserver for this.

Subject

SplObjectStorage stores objects, and every object can only be stored once.

<?php
class Newsletter implements SplSubject {

  private SplObjectStorage $observers;
  public string $lastPost = '';

  public function __construct() {
    $this->observers = new SplObjectStorage();
  }

  public function attach(SplObserver $observer): void {
    $this->observers[$observer] = null;
  }

  public function detach(SplObserver $observer): void {
    unset($this->observers[$observer]);
  }

  public function notify(): void {
    foreach ($this->observers as $observer) {
      $observer->update($this);
    }
  }

  public function publish(string $post): void {
    $this->lastPost = $post;
    $this->notify();
  }
}

Observers

<?php
class EmailSubscriber implements SplObserver {

  public function __construct(private string $email) {
  }

  public function update(SplSubject $subject): void {
    echo "Mail to {$this->email}: {$subject->lastPost}\n";
  }
}

class Logger implements SplObserver {

  public function update(SplSubject $subject): void {
    echo "Log: new post published\n";
  }
}

Use it

<?php
$newsletter = new Newsletter();
$anna = new EmailSubscriber("anna@example.com");

$newsletter->attach($anna);
$newsletter->attach(new Logger());

$newsletter->publish("Hello World");
// Output: Mail to anna@example.com: Hello World
//         Log: new post published

$newsletter->detach($anna);
$newsletter->publish("Second post");
// Output: Log: new post published
