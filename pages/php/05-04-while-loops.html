While loops

While

A while loop will run as long as the condition is true. The condition is checked before every round, so if it is false from the start the loop never runs. Remember to change the value in the loop, otherwise it runs forever.

<?php
$count = 10;
while ($count > 0) {
    echo $count;
    $count--;
}
// Output: 10987654321

Template syntax

<html>
 <head>
  <title>While</title>
 </head>
 <body>
   <?php $count = 0; ?>
   <?php while($count < 5): ?>
     <?php echo $count; $count++; ?>
   <?php endwhile; ?>
   <?php // Output: 0 1 2 3 4 ?>
 </body>
</html>

Do while

The difference between a while loop and a do while loop is that the condition is checked after every round, so it will always run once.

<?php
$count = 10;
do {
  echo $count;
  $count--;
} while ($count > 0);
// Output: 10987654321
<?php
$count = 0;
do {
  echo "Runs once";
} while ($count > 0);
// Output: Runs once
