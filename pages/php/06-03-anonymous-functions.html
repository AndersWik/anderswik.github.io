Anonymous functions

We can store an anonymous function in a variable. A difference when defining a anonymous function is we need to add a semicolon (;) after the closing curly brackets. When we call the function we use the variable name followed by ().

<?php
$anonymous = function() {

  return "hello";
};

echo $anonymous();
// Output: hello

Anonymous functions can have parameters and a return value like a normal function.

<?php
$parameter1 = 20;
$parameter2 = 30;

$anonymous = function($par1, $par2) {

  return $par1 + $par2;
};

echo $anonymous($parameter1, $parameter2);
// Output: 50

Function as a parameter

We can use an anonymous function as a parameter for our normal function. A function that is passed on like this is called a callback.

<?php
$parameter1 = 20;
$parameter2 = 20;

$anonymous = function($par1, $par2) {

  return $par1 + $par2;
};

function printMe($par1, $par2, $par3) {

  echo $par3($par1, $par2);
}

printMe($parameter1, $parameter2, $anonymous );
// Output: 40

We can also use an anonymous function as a parameter for another anonymous function.

<?php
$parameter1 = 30;
$parameter2 = 30;

$anonymous1 = function($par1, $par2) {

  return $par1 + $par2;
};

$anonymous2 = function($par1, $par2, $par3) {

  echo $par3($par1, $par2);
};

$anonymous2($parameter1, $parameter2, $anonymous1 );
// Output: 60

This allow us to dynamically change what function to be used depending on another value. Here the result is either 50 or 600.

<?php
$parameter1 = 20;
$parameter2 = 30;
$parameter3 = null;

$anonymous1 = function($par1, $par2) {

  return $par1 + $par2;
};

$anonymous2 = function($par1, $par2) {

  return $par1 * $par2;
};

$anonymous3 = function($par1, $par2, $par3) {

  echo $par3($par1, $par2);
};

$randomInt = rand(1,10);

if($randomInt <= 5) {

  $parameter3 = $anonymous1;

} else {

  $parameter3 = $anonymous2;
}

$anonymous3($parameter1, $parameter2, $parameter3);

We do not need to store a anonymous function in a variable before passing it to another function. We can create the function in the parameter list.

<?php
$parameter1 = 20;
$parameter2 = 30;

function printString($par1, $par2, $par) {

  echo $par($par1, $par2);
}

printString($parameter1, $parameter2, function($par1, $par2){

  return $par1 + $par2;
});

// Output: 50

Use

An anonymous function can not see variables from outside. use copies them into the function when it is created.

<?php
$greeting = "Hello";

$greet = function($name) use ($greeting) {
  return "$greeting $name";
};

echo $greet("Anna");
// Output: Hello Anna

Arrow functions

PHP 7.4 added arrow functions with fn. They can only contain one expression, which is returned, and they see the outside variables without use.

<?php
$factor = 3;

$multiply = fn($n) => $n * $factor;

echo $multiply(5);
// Output: 15

print_r(array_map(fn($n) => $n * $factor, [1, 2, 3]));
// Output: Array ( [0] => 3 [1] => 6 [2] => 9 )
