Get

$_GET contains the parameters in the query string, the part of the URL after ?. For the URL page.php?id=5&sort=name it contains id and sort. A form with method="get" also sends its values this way.

GET should only be used to read data, like searching or showing a page. It should never change anything, because links are followed by browsers, search engines and link previews. Use POST to create, change or delete.

Read a parameter

All values in $_GET are strings, or arrays if the URL is written like id[]=1. Use ?? to give a default when the parameter is missing.

<?php
// page.php?name=Anna
$name = $_GET['name'] ?? 'Guest';

echo "Hello " . htmlspecialchars($name);
// Output: Hello Anna

Validate a parameter

filter_input reads and validates in one step. It returns false if the value is not valid and null if it is missing.

<?php
// page.php?id=5
$id = filter_input(INPUT_GET, 'id', FILTER_VALIDATE_INT);

if (!$id) {
  http_response_code(400);
  exit("Invalid id");
}

echo $id;
// Output: 5

Build a URL

http_build_query builds a query string and encodes the values, so spaces and & in a value do not break the URL. Use urlencode for a single value.

<?php
$url = "search.php?" . http_build_query(["q" => "fish & chips", "page" => 2]);
echo $url;
// Output: search.php?q=fish+%26+chips&page=2

echo '<a href="' . htmlspecialchars($url) . '">Next page</a>';

A search form

<?php $q = $_GET['q'] ?? ''; ?>
<form action="search.php" method="get">
  <input type="search" name="q" value="<?php echo htmlspecialchars($q); ?>">
  <input type="submit" value="Search">
</form>
<?php if ($q !== ''): ?>
  <p>You searched for <?php echo htmlspecialchars($q); ?></p>
<?php endif; ?>
