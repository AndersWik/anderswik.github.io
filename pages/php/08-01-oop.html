Object oriented PHP

Object oriented programming (OOP) groups data and the code that works on the data into objects. A class is the blueprint, and an object is an instance created from the class. The variables in a class are called properties and the functions are called methods.

<?php
class Dog {

  public $name;

  public function __construct($name) {
    $this->name = $name;
  }

  public function bark() {
    return $this->name . " says woof";
  }
}

$dog = new Dog("Fido");
echo $dog->bark();
// Output: Fido says woof

Why objects

  • Encapsulation, the data is hidden in the object and only changed through its methods, see Visibility
  • Inheritance, a class can reuse and extend another class, see Inheritance
  • Polymorphism, different classes can be used the same way, see Polymorphism
