POST

Client

POST request with file_get_contents and stream_context_create. The content is encoded like a form, and the Content-Type header tells the server that.

<?php
$content = "param1=Parameter1&param2=Parameter2";

$parameters = array(
 'http' => array
 (
   'method' => 'POST',
   'header' => 'Content-Type: application/x-www-form-urlencoded',
   'content' => $content
 )
);

$context = stream_context_create($parameters);
$result = file_get_contents("http://localhost:8888/", false, $context );
echo $result;

http_build_query creates the content from an array and encodes it correctly.

<?php
$content = http_build_query(["param1" => "Parameter 1", "param2" => "Parameter & 2"]);

We can add headers to the request. Headers like Accept-Encoding: gzip and Connection: keep-alive are left out, since file_get_contents does not unpack gzip and closes the connection anyway.

<?php
$content = "param1=Parameter1&param2=Parameter2";
$parameters = array(
  'http' => array
  (
    'method' => 'POST',
    'header'=> [
      'Content-Type: application/x-www-form-urlencoded',
      'User-Agent: Mozilla/5.0 (Macintosh; Intel Mac OS X 10.13; rv:58.0) Gecko/20100101 Firefox/58.0',
      'Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8',
      'Accept-Language: sv-SE,sv;q=0.8,en-US;q=0.5,en;q=0.3',
    ],
    'content' => $content
  )
);

$context = stream_context_create($parameters);
$result = file_get_contents("http://localhost:8888/", false, $context );
echo $result;

Server

First we need a file to POST to. Start it with php -S localhost:8888 in the folder of the file and run the client from another terminal. The values are escaped since they come from the client.

<html>
  <body>
    <h1>POST</h1>
    <p>Parameter 1:<?php echo htmlspecialchars($_POST["param1"] ?? ''); ?></p>
    <p>Parameter 2:<?php echo htmlspecialchars($_POST["param2"] ?? ''); ?></p>
  </body>
</html>

JSON

Client

To send JSON, encode the content with json_encode and set the Content-Type to application/json.

<?php
$content = ["param1" => "Parameter 1", "param2" => "Parameter2"];
$parameters = array(
  'http' => array
  (
    'method' => 'POST',
    'header'=> [
      'Content-Type: application/json',
      'User-Agent: Mozilla/5.0 (Macintosh; Intel Mac OS X 10.13; rv:58.0) Gecko/20100101 Firefox/58.0',
      'Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8',
      'Accept-Language: sv-SE,sv;q=0.8,en-US;q=0.5,en;q=0.3',
    ],
    'content' => json_encode($content)
  )
);

$context = stream_context_create($parameters);
$result = file_get_contents("http://localhost:8888/", false, $context );
echo $result;

Server

Since we no longer are sending normal post parameters we need to change how we get the post content. $_POST is only filled for forms, so the body is read from php://input and decoded.

<html>
  <body>
    <h1>POST</h1>
    <?php $json = file_get_contents('php://input'); ?>
    <?php $result = json_decode($json, true); ?>
    <p>JSON</p>
    <?php if(is_array($result)): ?>
      <p>Parameter 1:<?php echo htmlspecialchars((string) ($result["param1"] ?? '')); ?></p>
      <p>Parameter 2:<?php echo htmlspecialchars((string) ($result["param2"] ?? '')); ?></p>
    <?php endif; ?>
  </body>
</html>
