Require

require works like include but stops the script with a fatal error if the file is missing.

Path to file from the current folder to helper/get_text.php.

<?php
require "helper/get_text.php";

Return a value

If we have a file we require and the file is returning a value we can save it to a variable. This is often used for configuration files.

<?php
// helper/get_text.php
function getText() {
  return "Text from function";
}

return "Helper file";
<?php
$text = require "helper/get_text.php";
echo $text;
// Output: Helper file

echo getText();
// Output: Text from function
<?php
// config.php
return [
  "db_host" => "localhost",
  "db_name" => "mydb",
];
<?php
$config = require __DIR__ . "/config.php";
echo $config["db_name"];
// Output: mydb

Require once

require_once only includes the file the first time. It is the safe choice for files with functions and classes. Today classes are usually loaded with an autoloader instead.

<?php
require_once __DIR__ . "/helper/get_text.php";
require_once __DIR__ . "/helper/get_text.php"; // Ignored
