VSCodium

Community-driven, freely-licensed binary distribution of Microsoft’s editor VS Code.

License

MIT

Website

  • https://vscodium.com

Repository

  • https://github.com/VSCodium/vscodium

Wikipedia

  • https://en.wikipedia.org/wiki/Visual_Studio_Code

Operating system

Windows, macOS, Linux

Install on macOS

$ brew install --cask vscodium

Install on Debian

Add the signing key and the VSCodium repository, then install codium.

$ wget -qO - https://gitlab.com/paulcarroty/vscodium-deb-rpm-repo/raw/master/pub.gpg \
    | gpg --dearmor \
    | sudo dd of=/usr/share/keyrings/vscodium-archive-keyring.gpg
$ echo 'deb [ signed-by=/usr/share/keyrings/vscodium-archive-keyring.gpg ] https://download.vscodium.com/debs vscodium main' \
    | sudo tee /etc/apt/sources.list.d/vscodium.list
$ sudo apt update && sudo apt install codium

Install on Ubuntu

Newer Ubuntu versions use the .sources format for repositories. See also the install instructions on vscodium.com.

$ wget -qO - https://gitlab.com/paulcarroty/vscodium-deb-rpm-repo/raw/master/pub.gpg \
    | gpg --dearmor \
    | sudo dd of=/usr/share/keyrings/vscodium-archive-keyring.gpg
$ echo -e 'Types: deb\nURIs: https://download.vscodium.com/debs\nSuites: vscodium\nComponents: main\nArchitectures: amd64 arm64\nSigned-by: /usr/share/keyrings/vscodium-archive-keyring.gpg' \
    | sudo tee /etc/apt/sources.list.d/vscodium.sources
$ sudo apt update && sudo apt install codium

Install with Snap

$ sudo snap install codium --classic
