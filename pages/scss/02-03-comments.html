Comments

SCSS has two kinds of comments.

// A silent comment. It is never in the CSS.

/* A loud comment. It is in the CSS, unless the style is compressed. */

/*! A comment that is kept even in compressed CSS. */
  • // comments are for the people that read the SCSS. They are removed when it is compiled. They do not exist in plain CSS.
  • /* */ comments are kept in the expanded CSS, and removed with --style=compressed.
  • /*! */ comments are always kept. Use them for licenses and notes like "do not edit, this file is compiled".
/*! DO NOT EDIT THIS FILE :: IT IS COMPILED FROM SCSS :: EDIT scss/style.scss */

// Colors
$color-accent: #e8b455; // Amber, for dark backgrounds

Documentation comments

Three slashes, ///, is a documentation comment. The tool SassDoc can make a web page from them, like the documentation of a library.

@use 'sass:color';

/// Makes a color lighter for hover states.
/// @param {Color} $color - The color to change
/// @return {Color}
@function hover-color($color) {
  @return color.scale($color, $lightness: 20%);
}
