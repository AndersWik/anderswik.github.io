Extend

@extend lets one selector use the styles of another. Instead of copying the declarations like a mixin, Sass adds the selector to the other rule.

.message {
  padding: 1rem;
  border: 1px solid #ccc;
}

.message-error {
  @extend .message;
  border-color: red;
}

.message-success {
  @extend .message;
  border-color: green;
}
.message, .message-error, .message-success {
  padding: 1rem;
  border: 1px solid #ccc;
}

.message-error {
  border-color: red;
}

.message-success {
  border-color: green;
}

Placeholders

A placeholder selector starts with %. It is only printed if something extends it, so it is a group of styles that is meant to be extended and never used in the HTML.

%message {
  padding: 1rem;
  border: 1px solid #ccc;
}

.message-error {
  @extend %message;
  border-color: red;
}
.message-error {
  padding: 1rem;
  border: 1px solid #ccc;
}

.message-error {
  border-color: red;
}

Be careful with extend

  • @extend changes every place the extended selector is used, also in nested rules, like .sidebar .message. That can make many more selectors than expected.
  • It does not work inside a media query on a selector from outside the media query.
  • The order of the CSS can be surprising, since the styles stay where the extended rule is, not where the @extend is.

Most projects use mixins instead, which are easier to follow. Use @extend for real "is a kind of" relationships, like an error message is a kind of message, and prefer placeholders.
