Compile

The sass command reads an .scss file and writes a .css file. The input comes first and the output second.

$ sass scss/style.scss css/style.css

Without an output file the CSS is printed in the terminal, which is handy to see what a piece of SCSS becomes.

$ sass scss/style.scss

Watch

--watch keeps running and compiles the file again every time it, or a file it loads, is saved. Stop it with Ctrl + C.

$ sass --watch scss/style.scss css/style.css

With input:output pairs, several files, or whole folders, can be compiled at once. Files that start with _ are partials and are not compiled to their own CSS file.

$ sass --watch scss/dev.scss:css/dev.css scss/print.scss:css/print.css
$ sass --watch scss:css

Output style

--style decides how the CSS looks. expanded, the default, is easy to read. compressed removes all spaces, line breaks and comments to make the file as small as possible. Use it for the live site.

$ sass --style=compressed scss/style.scss css/style.css
nav a{color:#e8b455}nav a:hover{color:#a86a0c}

Source maps

By default Sass also writes style.css.map, a source map. With it, the browser's developer tools show which line in which .scss file a rule came from, instead of the line in the compiled CSS. Turn it off for the live site with --no-source-map.

The full command

For development, watch with source maps:

$ sass --watch scss/dev.scss:css/dev.css

For the live site, compressed and without a source map:

$ sass --style=compressed --no-source-map scss/dev.scss:css/dev.css

The same with the old Ruby Sass looked like this. Ruby Sass needed --no-cache to not write a .sass-cache folder. Dart Sass has no cache, so the flag is gone.

$ scss --watch --no-cache scss/dev.scss:css/dev.css --style compressed

Load path

--load-path, or -I, adds a folder where @use looks for files, for example to load Bootstrap's SCSS from node_modules.

$ sass --load-path=node_modules scss/style.scss css/style.css

npm scripts

Save the commands in package.json so nobody has to remember them.

{
  "scripts": {
    "watch": "sass --watch scss/dev.scss:css/dev.css",
    "build": "sass --style=compressed --no-source-map scss/dev.scss:css/dev.css"
  }
}
$ npm run watch
$ npm run build
