Install

Install Dart Sass, the current Sass compiler. It gives the command sass.

With npm

With Node.js installed, install Sass for the whole computer:

$ npm install -g sass

Or for one project only, which is better when several people work on it, since everyone gets the same version from package.json.

$ npm install --save-dev sass
$ npx sass --version

Without Node.js

Download the standalone version for Linux, macOS or Windows from the Dart Sass releases, unpack it and put the folder in the PATH.

$ tar -xzf dart-sass-*-linux-x64.tar.gz
$ sudo mv dart-sass /opt/
$ echo 'export PATH="/opt/dart-sass:$PATH"' >> ~/.bashrc
$ source ~/.bashrc

macOS

$ brew install sass/sass/sass

Check the version

$ sass --version
1.83.0

The version should be a number like 1.83.0. If it ends with compiled with dart2js it is the npm version, which works the same but is a little slower.

The old packages

On Debian and Ubuntu, sudo apt install ruby-sass installs Ruby Sass, which has not been updated since 2019. It does not understand @use, math.div() and the other newer features in these notes. Remove it, so its sass command does not hide the new one.

$ sudo apt remove ruby-sass
$ which sass
