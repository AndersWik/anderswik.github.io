Functions

A function takes values, calculates something and returns a value. Unlike a mixin, which adds declarations, a function is used as a value in a declaration.

@function and @return

A function that turns pixels into rem, so sizes can be written in pixels from a design and still follow the user's font size.

@use 'sass:math';

$base-font-size: 16px;

@function rem($px) {
  @return math.div($px, $base-font-size) * 1rem;
}

h1 {
  font-size: rem(32px);   // 2rem
  margin-bottom: rem(24px);   // 1.5rem
}
  • math.div() divides. 16px / 16px is 1, without a unit, and 1 * 1rem is 1rem. Sass keeps track of the units.
  • @return ends the function and gives the value back. A function must return a value.

The PX to EM converter does the same calculation in the browser.

Arguments

Arguments work like in mixins. They can have default values and be given by name.

@use 'sass:math';

@function fluid($min, $max, $min-screen: 400px, $max-screen: 1200px) {
  $slope: math.div($max - $min, $max-screen - $min-screen);
  @return clamp($min, $min - $slope * $min-screen + $slope * 100vw, $max);
}

h1 {
  font-size: fluid(24px, 48px);
}
h1 {
  font-size: clamp(24px, 12px + 3vw, 48px);
}

This returns a CSS clamp(), so the size grows with the screen between 24 and 48 pixels. Sass calculates as much as it can. 12px + 3vw can not be added before the screen width is known, so Sass leaves that part for the browser.

Sass functions and CSS functions

If Sass does not know a function, it prints it as it is for the browser. That is why clamp(), calc() and var() work in SCSS. It also means that a misspelled Sass function gives no error, it just ends up in the CSS. Check the compiled CSS if a value looks wrong.

Built-in functions

Sass comes with many functions for colors, numbers, strings, lists and maps. They are in built-in modules.
