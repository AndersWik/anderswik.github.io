Mixins

A mixin is a group of declarations with a name. @include copies them into a rule. Use mixins for groups of properties that are needed in many places.

@mixin visually-hidden {
  position: absolute;
  width: 1px;
  height: 1px;
  overflow: hidden;
  clip-path: inset(50%);
  white-space: nowrap;
}

.skip-link {
  @include visually-hidden;
}
.skip-link {
  position: absolute;
  width: 1px;
  height: 1px;
  overflow: hidden;
  clip-path: inset(50%);
  white-space: nowrap;
}

Arguments

A mixin can take arguments, like a function. An argument can have a default value, which is used when it is left out.

@mixin card($padding, $radius: 12px) {
  padding: $padding;
  border-radius: $radius;
  box-shadow: 0 1px 2px rgba(0, 0, 0, .04), 0 6px 24px rgba(0, 0, 0, .06);
}

.post {
  @include card(1.5rem);           // radius is 12px
}

.badge {
  @include card(.25rem, 999px);
}

.panel {
  @include card($radius: 0, $padding: 2rem);   // By name, in any order
}

@content

@content in a mixin is replaced with the block written after the @include. It lets a mixin wrap declarations, for example in a media query.

@mixin dark-mode {
  @media (prefers-color-scheme: dark) {
    @content;
  }
}

.card {
  background: white;

  @include dark-mode {
    background: #1b1d21;
  }
}
.card {
  background: white;
}
@media (prefers-color-scheme: dark) {
  .card {
    background: #1b1d21;
  }
}

See breakpoints for a mixin that does the same with screen sizes.

Mixins from other files

Keep mixins in a partial and load it with @use.

@use 'mixins';

.skip-link {
  @include mixins.visually-hidden;
}

Mixin, extend or class

A mixin copies the declarations into every rule that includes it, so the CSS gets bigger the more it is used. For a few lines that is fine, and compression takes care of most of it. If the same group is used on many elements, a class in the HTML, like class="card", can be simpler. See also @extend.
