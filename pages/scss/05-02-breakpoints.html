Breakpoints

Breakpoints are the screen widths where the layout changes. Writing media queries with the pixel values everywhere makes them hard to change. Keep the breakpoints in a map and write the media queries with a mixin.

The mixin

// abstracts/_breakpoints.scss
@use 'sass:map';

$breakpoints: (
  sm: 576px,
  md: 768px,
  lg: 992px,
  xl: 1200px,
);

@mixin up($name) {
  @if not map.has-key($breakpoints, $name) {
    @error "Unknown breakpoint `#{$name}`. Use one of #{map.keys($breakpoints)}.";
  }

  @media (min-width: map.get($breakpoints, $name)) {
    @content;
  }
}
  • @content is replaced with the styles written in the @include.
  • @error stops the build if the name is misspelled, instead of making a media query without a width.

Use it

@use 'abstracts/breakpoints' as bp;

.grid {
  display: grid;
  gap: 1rem;
  grid-template-columns: 1fr;

  @include bp.up(md) {
    grid-template-columns: repeat(2, 1fr);
  }

  @include bp.up(lg) {
    grid-template-columns: repeat(3, 1fr);
  }
}
.grid {
  display: grid;
  gap: 1rem;
  grid-template-columns: 1fr;
}
@media (min-width: 768px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}
@media (min-width: 992px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

Mobile first

The mixin uses min-width. The styles without a media query are for the smallest screens, and each breakpoint adds to them as the screen gets wider. This is called mobile first, and is usually simpler than starting with the big screen and taking things away.

For the few times a style is only for small screens, add a down mixin. The - 0.02px keeps it from overlapping with up at exactly the breakpoint.

@mixin down($name) {
  @media (max-width: map.get($breakpoints, $name) - 0.02px) {
    @content;
  }
}

The same breakpoints as Bootstrap

The values above are the same as in Bootstrap 5, which this site uses, so the classes like col-md-6 and our own media queries change at the same widths.
