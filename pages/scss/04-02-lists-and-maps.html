Lists and maps

Lists

A list is several values, separated by commas or spaces. Many CSS values are already lists, like margin: 0 auto or a font stack.

$sizes: 12px, 16px, 24px, 32px;
$font-stack: 'Ubuntu', system-ui, sans-serif;
$spacing: 0 1rem 2rem;     // A space separated list
@use 'sass:list';

list.length($sizes)          // 4
list.nth($sizes, 1)          // 12px, the first is 1, not 0
list.nth($sizes, -1)         // 32px, the last
list.index($sizes, 24px)     // 3
list.append($sizes, 48px)    // 12px, 16px, 24px, 32px, 48px

Lists can not be changed. list.append() returns a new list, so save it in the variable again: $sizes: list.append($sizes, 48px);.

Maps

A map is a list of keys and values, like an associative array in PHP. It is written in parentheses.

$breakpoints: (
  sm: 576px,
  md: 768px,
  lg: 992px,
  xl: 1200px,
);

$colors: (
  'primary': #e8b455,
  'danger': #d64545,
  'success': #2e9e5b,
);
@use 'sass:map';

map.get($breakpoints, md)          // 768px
map.has-key($breakpoints, xxl)     // false
map.keys($breakpoints)             // sm, md, lg, xl
map.values($breakpoints)           // 576px, 768px, 992px, 1200px
map.merge($breakpoints, (xxl: 1400px))  // A new map with xxl added
map.remove($colors, 'danger')      // A new map without danger

map.get() returns null if the key does not exist, and a declaration with null is not printed at all. Check with map.has-key() and give an @error to catch spelling mistakes.

Maps and loops

Maps are most useful together with @each, to make many rules from one list of values.

@each $name, $color in $colors {
  .text-#{$name} {
    color: $color;
  }
}
.text-primary {
  color: #e8b455;
}
.text-danger {
  color: #d64545;
}
.text-success {
  color: #2e9e5b;
}
