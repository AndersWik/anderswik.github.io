Loops

Loops make many rules from a little code. They are used for utility classes, like a set of spacing or color classes.

@each

@each goes through a list or a map.

$icons: home, search, user;

@each $icon in $icons {
  .icon-#{$icon} {
    background-image: url('/assets/icons/#{$icon}.svg');
  }
}
.icon-home {
  background-image: url("/assets/icons/home.svg");
}
.icon-search {
  background-image: url("/assets/icons/search.svg");
}
.icon-user {
  background-image: url("/assets/icons/user.svg");
}

With a map, @each gets both the key and the value.

$spacers: (0: 0, 1: .25rem, 2: .5rem, 3: 1rem, 4: 1.5rem, 5: 3rem);

@each $key, $size in $spacers {
  .mt-#{$key} { margin-top: $size; }
  .mb-#{$key} { margin-bottom: $size; }
}

This is how Bootstrap makes classes like mt-3 and pb-5, used on this site.

@for

@for counts. through includes the last number, to stops before it.

@use 'sass:math';

@for $i from 1 through 4 {
  .col-#{$i} {
    width: math.percentage(math.div($i, 4));
  }
}
.col-1 {
  width: 25%;
}
.col-2 {
  width: 50%;
}
.col-3 {
  width: 75%;
}
.col-4 {
  width: 100%;
}

@while

@while runs as long as a condition is true. It is rarely needed, @each and @for are easier to read. Make sure the condition becomes false, otherwise Sass never finishes.

$size: 64px;

@while $size > 8px {
  .avatar-#{$size} {
    width: $size;
    height: $size;
  }
  $size: $size * 0.5;
}

Do not make too much CSS

Loops make it easy to make thousands of rules that are never used. Every class ends up in the file the visitor downloads. Only make the classes the site needs.
