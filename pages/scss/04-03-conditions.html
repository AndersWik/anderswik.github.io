@if and @else

@if only adds the styles in its block if the condition is true. It is used in mixins and functions, to do different things depending on the arguments.

@mixin button($style: solid) {
  padding: .5rem 1rem;
  border: 2px solid currentColor;

  @if $style == solid {
    background: #e8b455;
    color: #1f2328;
  } @else if $style == outline {
    background: transparent;
  } @else {
    @error "Unknown button style #{$style}, use solid or outline.";
  }
}

.button {
  @include button;
}

.button-outline {
  @include button(outline);
}

True and false

Only false and null are false. Everything else is true, also 0, an empty string and an empty list. That is different from PHP and JavaScript, where 0 is false.

@mixin shadow($enabled: true) {
  @if $enabled {
    box-shadow: 0 6px 24px rgba(0, 0, 0, .06);
  }
}

@mixin maybe-color($color: null) {
  @if $color {
    color: $color;   // Only when a color is given
  }
}
