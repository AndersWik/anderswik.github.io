@debug, @warn and @error

Sass runs when the CSS is built, so there is no browser console to print to. These three rules print messages in the terminal instead.

@debug

Prints a value while compiling, to see what a variable or a calculation is.

@use 'sass:math';

$width: math.div(960px, 3);
@debug "The width is #{$width}";
$ sass style.scss style.css
style.scss:4 Debug: The width is 320px

@warn

Prints a warning, but the CSS is still built. Use it for things that work but should be changed, like an old argument.

@mixin rounded($radius: 12px) {
  @if $radius == 0 {
    @warn "rounded(0) does nothing, remove the @include instead.";
  }
  border-radius: $radius;
}

@error

Stops the build with an error message. Use it for arguments that can not work, so the mistake is found at once and not later in the browser.

@use 'sass:map';

$breakpoints: (sm: 576px, md: 768px, lg: 992px);

@function breakpoint($name) {
  @if not map.has-key($breakpoints, $name) {
    @error "Unknown breakpoint `#{$name}`. Use one of #{map.keys($breakpoints)}.";
  }
  @return map.get($breakpoints, $name);
}
Error: "Unknown breakpoint `mdd`. Use one of sm, md, lg."
