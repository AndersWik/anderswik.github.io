Variables

A variable starts with $ and stores a value, like a color, a size or a font. Change the value in one place and it changes everywhere it is used.

$color-accent: #e8b455;
$radius: 12px;
$font-text: 'Ubuntu', system-ui, sans-serif;

.button {
  background-color: $color-accent;
  border-radius: $radius;
  font-family: $font-text;
}
.button {
  background-color: #e8b455;
  border-radius: 12px;
  font-family: "Ubuntu", system-ui, sans-serif;
}

The variables themselves are not in the CSS. Sass replaces them with their values when it compiles.

Names

Name a variable after what it is for, not after its value. $color-accent still makes sense when the accent color changes from yellow to green, $yellow does not. In Sass, - and _ are the same, $font-size and $font_size is one variable.

Scope

A variable made at the top of a file can be used everywhere below it. A variable made inside a block, between { and }, only exists in that block.

$size: 16px;

.card {
  $padding: 1rem;      // Only inside .card
  padding: $padding;
  font-size: $size;    // The top level variable works here
}

.box {
  padding: $padding;   // Error: Undefined variable
}

Setting a top level variable inside a block makes a new local variable with the same name. To change the top level one, add !global. It is rarely needed and makes the code hard to follow.

Default values

!default only sets the variable if it does not have a value already. It is used in files that others load, so they can change the value. See partials for how to set it with @use ... with.

// _buttons.scss
$button-color: blue !default;

Sass variables and CSS custom properties

CSS has its own variables, custom properties, like --color-accent. The difference:

  • A Sass variable is replaced when the CSS is built. The browser never sees it.
  • A custom property is in the CSS and can be changed by the browser, for example in a media query, for dark mode or from JavaScript.

They work well together. Keep the values in Sass and print them as custom properties where they need to change in the browser. A Sass variable in a custom property needs interpolation, #{}.

$color-ink: #1f2328;
$color-ink-dark: #e6e6e6;

:root {
  --color-ink: #{$color-ink};
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-ink: #{$color-ink-dark};
  }
}

body {
  color: var(--color-ink);
}
