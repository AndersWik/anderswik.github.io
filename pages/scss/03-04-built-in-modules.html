Built-in modules

Sass's own functions are grouped in modules, loaded with @use and a name that starts with sass:.

@use 'sass:math';
@use 'sass:color';
@use 'sass:map';

sass:math

@use 'sass:math';

math.div(10px, 4)      // 2.5px, division
math.round(2.6px)      // 3px
math.floor(2.6)        // 2
math.ceil(2.1)         // 3
math.max(1px, 4px)     // 4px
math.percentage(0.25)  // 25%
math.$pi               // 3.1415926536

In old code, division is written with /, like $width / 2. Since / also separates values in CSS, like in font: 16px/1.5, Sass has deprecated it for division. Use math.div().

sass:color

Make new colors from a base color, for example a darker version for hover.

@use 'sass:color';

$accent: #e8b455;

.button {
  background: $accent;

  &:hover {
    background: color.scale($accent, $lightness: -20%);   // 20% closer to black
  }

  &:disabled {
    background: color.mix($accent, white, 50%);   // Half accent, half white
  }
}
  • color.scale() changes a value by a percentage of what is left. $lightness: -20% moves the color 20% of the way to black. It is the one to use for lighter and darker versions.
  • color.adjust() adds a fixed amount, color.adjust($accent, $lightness: -10%). It is what the old darken() and lighten() did, and they are deprecated.
  • color.mix() mixes two colors.
  • color.change() sets a value, color.change($accent, $alpha: 0.5).

In the browser, the CSS function color-mix() can do the same with colors and custom properties, for example for dark mode.

sass:string

@use 'sass:string';

string.unquote('Ubuntu')   // Ubuntu
string.quote(Ubuntu)       // "Ubuntu"
string.to-upper-case('a')  // "A"
string.index('hello', 'l') // 3

sass:list and sass:map

For lists and maps, see lists and maps.

@use 'sass:list';
@use 'sass:map';

list.nth((10px, 20px, 30px), 2)       // 20px
map.get((sm: 576px, md: 768px), md)   // 768px

sass:meta

@use 'sass:meta';

meta.type-of(12px)   // number
meta.type-of(red)    // color

Global names

Older code calls the functions without a module, like map-get(), percentage() and darken(). These global names are deprecated since Dart Sass 1.80 and will be removed. Use the module functions, map.get(), math.percentage() and color.adjust().
