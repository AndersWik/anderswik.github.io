Nesting

In SCSS a rule can be written inside another rule. The inner selector only matches elements inside the outer one, the same as a space between two selectors in CSS, a descendant combinator.

nav {
  background: #1b1d21;

  ul {
    list-style: none;
  }

  a {
    color: white;
  }
}
nav {
  background: #1b1d21;
}
nav ul {
  list-style: none;
}
nav a {
  color: white;
}

Other combinators work too, like > li for direct children and + p for the next sibling.

The parent selector &

& is replaced with the outer selector. Without it, Sass adds a space. With it, the selectors are joined. It is used for pseudo-classes and pseudo-elements.

a {
  color: blue;

  &:hover {
    color: red;
  }

  &::after {
    content: ' →';
  }

  &.active {
    font-weight: bold;
  }
}
a {
  color: blue;
}
a:hover {
  color: red;
}
a::after {
  content: " →";
}
a.active {
  font-weight: bold;
}

Without the &, :hover would become a :hover, any hovered element inside a link, which is not what we want.

& at the end

& can be put after a selector, to style the element when it is inside something else.

.button {
  color: black;

  .dark-mode & {
    color: white;    // .dark-mode .button
  }
}

Join class names

& can also be the start of a longer class name. This is used a lot with the BEM naming style.

.card {
  padding: 1rem;

  &__title {
    font-size: 1.25rem;   // .card__title
  }

  &--featured {
    border: 2px solid gold;   // .card--featured
  }
}

Media queries

A media query can be nested inside a rule. Sass moves it out and repeats the selector, so everything about the element is in one place.

.sidebar {
  width: 100%;

  @media (min-width: 768px) {
    width: 300px;
  }
}
.sidebar {
  width: 100%;
}
@media (min-width: 768px) {
  .sidebar {
    width: 300px;
  }
}

Do not nest too deep

Every level makes the selector longer and more specific. .page .content .article .header h2 a is hard to override and breaks when the HTML changes. A rule of thumb is no more than three levels. Nest when the inner element only makes sense inside the outer one, not just because the HTML is nested.

Nesting in CSS

Browsers also support nesting in plain CSS now, with the same &. It is not exactly the same as in Sass. In CSS, &__title does not work, since CSS nesting does not join strings, and the specificity can be different. In an .scss file Sass always does the nesting, so the CSS that reaches the browser has none.
