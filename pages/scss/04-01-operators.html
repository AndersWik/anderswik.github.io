Operators and interpolation

Math

Sass can calculate with numbers, and keeps track of their units.

@use 'sass:math';

$gutter: 16px;

.box {
  padding: $gutter * 2;           // 32px
  margin: $gutter + 4px;          // 20px
  width: 100% - 20%;              // 80%
  height: math.div(600px, 3);     // 200px
}

Numbers with different units that can be converted, like 1in + 6px, are converted. Units that depend on the browser, like 100% - 20px, can not be calculated by Sass and give an error. Use calc(100% - 20px) for those, and the browser does the math.

$sidebar: 300px;

.content {
  width: calc(100% - #{$sidebar});   // calc(100% - 300px)
}

Divide with math.div(), not with /.

Strings

+ joins two strings.

$font: 'Ubuntu' + ' Mono';   // "Ubuntu Mono"

Interpolation

#{} puts the value of an expression into a selector, a property name, a string or a CSS value where Sass would not calculate it otherwise.

$name: 'warning';
$side: 'left';
$breakpoint: 768px;

.alert-#{$name} {                     // .alert-warning
  border-#{$side}: 4px solid orange;  // border-left
}

@media (min-width: #{$breakpoint}) {
  .alert-#{$name} {
    padding: 2rem;
  }
}

.icon::after {
  content: 'Size: #{$breakpoint}';    // "Size: 768px"
}

Interpolation is needed in selectors and property names, inside url() and strings, and in custom properties, --color: #{$color};. In normal values, use the variable directly. width: $width and not width: #{$width}, since interpolation turns the number into a string and Sass can not calculate with it afterwards.
