Common problems

The same few problems come up again and again. Start with DevTools, Application, which shows most of them.

No install button

  • The page is not on HTTPS or localhost. An address like http://192.168.56.35:4000 does not count.
  • The manifest link is missing, or the manifest is not valid JSON. A comma after the last item is enough to break it.
  • An icon is missing or the wrong size. The browser downloads the icons and checks them.
  • The app is already installed. Check chrome://apps.
  • It is Safari or Firefox, which never show the button. See Install.

The worker does not install

If one single file in cache.addAll() fails, the whole install fails. The console shows an error like this:

Uncaught (in promise) TypeError: Failed to execute 'addAll' on 'Cache': Request failed

Open the Network tab and look for a red request with 404. Usually a path with a typo, or a file that was renamed. This is why make-pwa.py checks that every file exists before it writes sw.js.

I changed a file but see the old one

That is the cache doing its job. The cache name in sw.js has to change for the new version to load, see Updates. While working, tick Update on reload in DevTools. On this site, run make-pwa.py again after every change.

It works online but breaks offline

A file the app needs is not in the cache. Tick Offline in DevTools, reload, and look for failed requests in the Network tab. Common ones:

  • A picture or sound loaded by JavaScript later, not in the HTML.
  • A font loaded by a stylesheet, like the Ubuntu fonts in this site's style.css.
  • A file from a CDN that was not in the list.

The worker does not control the page

navigator.serviceWorker.controller is null in the console. Either the page is outside the worker's scope, see Service worker, or it is the first visit: the page that registers a worker is not controlled by it until reload, unless the worker calls clients.claim().

A link opens in the browser

The link leads out of the app's scope. That is often what you want, for example a link back to the site. If not, widen the scope in the manifest, see Manifest.

Hard reload does not help

Ctrl+Shift+R skips the service worker for that one load, but the next normal load uses it again. Use Clear site data to really start over.

The data is gone on iPhone

An installed app on iPhone has its own storage, apart from Safari. See Saving data.
