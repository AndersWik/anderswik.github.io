Progressive Web Apps

A Progressive Web App, or PWA, is a normal web page that can be installed like an app. It gets an icon on the home screen or in the start menu, opens in its own window without the browser's address bar, and keeps working without a network connection.

There is no app store and no special language. A PWA is HTML, CSS and JavaScript, plus two small extra files that tell the browser how to install and run it.

The three parts

  • A page served over HTTPS. Browsers only allow the app features on secure pages. localhost also counts as secure, so you can test on your own computer.
  • A web app manifest. A JSON file with the app's name, icons and colors. It is what makes the page installable.
  • A service worker. A JavaScript file that runs in the background, between the page and the network. It saves the app's files in a cache, so the app starts without a connection.

The page links to the manifest and registers the service worker:

<link rel="manifest" href="manifest.webmanifest">

<script>
  if ("serviceWorker" in navigator) {
    navigator.serviceWorker.register("sw.js");
  }
</script>

Why progressive?

"Progressive" means the page works everywhere and gets better where the browser can do more. A browser without service workers simply shows the normal page. A browser with them adds offline support and an install button. Nothing breaks for anyone, which is why the register code above starts with if ("serviceWorker" in navigator).

PWAs on this site

Most of the games and utilities on this site can be installed. Open for example Coin Flip or the Calculator and click Install as an app below it. These notes go from a Hello World page to how those apps were made, so you can do the same with your own JavaScript app.

What a PWA can not do

  • It can not reach everything a native app can, like contacts or files outside what the user picks.
  • On iPhone and iPad the support is smaller. Installing is done by hand from the Share menu, see Install.
  • Anything that talks to a server, like an API, still needs the network. See My IP.
