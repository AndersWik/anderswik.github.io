Example: Coin Flip

Coin Flip is one of the simplest games on this site: one page, one CSS file, one JavaScript file and two pictures. No network and nothing to save. Here is how it went from a page on the site to an app you can install.

Before: a page on the site

The game is a Jekyll page, pages/games/coin-flip.html. The front matter at the top lists its CSS and JavaScript, and the layout adds the site's header, footer and Bootstrap around it.

{% raw %}---
layout: game
title: Coin Flip
permalink: /games/coin-flip/
css:
  - /assets/coin-flip/coin-flip.css
js:
  - /assets/coin-flip/coin-flip.js
---
<div class="container">
  <h1>Coin Flip</h1>
  <div class="result" id="resultCoinHeads">
    <img src="{{ site.baseurl }}/assets/coin-flip/images/head.svg" alt="Front of bitcoin coin" />
  </div>
  ...
  <button type="button" id="flipCoinBtn">Flip Coin!</button>
</div>
<p class="text-center mt-4"><a href="/tutorials/coin-flip/">How to build this game</a></p>{% endraw %}

The game's own files, coin-flip.js and coin-flip.css, were not changed at all.

app.html

The same HTML as the page, with these changes:

  • A full <head> with the manifest, theme color and icons, since there is no layout to add one.
  • The stylesheets from the front matter, plus Bootstrap and the site's style.css that the layout used to add.
  • {% raw %}{{ site.baseurl }}{% endraw %} removed, so the paths are plain.
  • The link to the tutorial removed, it leads out of the app.
  • A little padding at the top, since there is no header any more.
  • The script tags from the front matter, and the service worker registration, at the end.
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Coin Flip</title>

  <link rel="manifest" href="manifest.webmanifest">
  <meta name="theme-color" content="#1b1d21">
  <link rel="icon" href="images/icon-192.png" type="image/png">
  <link rel="apple-touch-icon" href="images/apple-touch-icon.png">
  <meta name="apple-mobile-web-app-title" content="Coin Flip">

  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
  <link rel="stylesheet" href="/css/style.css">
  <link rel="stylesheet" href="/assets/coin-flip/coin-flip.css">
  <style>
    .game { padding-block: 16px; }
  </style>
</head>
<body>

<script>
  if ("serviceWorker" in navigator) {
    navigator.serviceWorker.register("sw.js");
  }
</script>
</body>
</html>

sw.js

The same worker as in Service worker, with the game's files in the list:

];

The link from the site

Last, the game's page needs to tell people they can install it. On this site that is one line in _data/pwa.yml, which also makes the Install as an app link show up below the game, see Install.

- { slug: coin-flip, page: pages/games/coin-flip.html, short_name: Coin Flip, emoji: "🪙" }
