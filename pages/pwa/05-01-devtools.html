DevTools

Chrome and Edge have a panel just for PWAs. Open the app, press F12 and go to the Application tab.

Manifest

Application, Manifest shows the name, colors and icons the browser read from the manifest. Problems that stop the app from being installed are listed at the top under Installability, like a missing 512 pixel icon.

Service workers

Application, Service workers shows the worker for the page and its state: activated, waiting or redundant.

  • Offline cuts the network for the app, the quickest way to test it offline.
  • Update on reload installs the newest sw.js on every reload. Turn this on while you work on the app, or you will keep seeing the cached version.
  • Unregister removes the worker.
  • Bypass for network lets requests skip the worker.

Cache storage

Application, Cache storage lists every cache, like coin-flip-6f1e…, and the files in it. Check that every file the app needs is there. Right click a cache to delete it.

Start over

Application, Storage, Clear site data removes the worker, the caches and localStorage in one go. The next load is like a first visit.

Test it like a user

  1. Clear site data and reload, so the worker installs from scratch.
  2. Check Cache storage: are all files there?
  3. Tick Offline and reload. Use every part of the app: every button, picture and sound.
  4. Install the app and open it from its icon. Check the name, icon and colors.
  5. Change a file, rebuild, and open the app again. Does the new version show up? See Updates.

Lighthouse

The Lighthouse tab runs a report on the page, with scores for speed, accessibility and best practices. It points out things like a missing theme color or viewport tag.

From the console

The console can also look at the worker and the caches:

// Which worker controls this page?
navigator.serviceWorker.controller

// List all caches
await caches.keys()

// Remove all workers for the site
(await navigator.serviceWorker.getRegistrations()).forEach(r => r.unregister())

Other browsers

  • Firefox about:debugging#/runtime/this-firefox lists all service workers, and DevTools has Application, Manifest.
  • Android Chrome connect the phone with USB and open chrome://inspect on the computer to use DevTools on the phone.
  • iPhone Safari turn on Web Inspector under Settings, Safari, Advanced, connect to a Mac and use Safari's Develop menu.

More about DevTools
