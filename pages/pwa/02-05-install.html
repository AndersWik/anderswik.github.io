Install

When the requirements are met, the browser lets the user install the app. How it looks depends on the device.

Android

Chrome shows an Install app banner or a menu entry under the three dots. The app gets an icon on the home screen and shows up in the app drawer like any other app.

iPhone and iPad

Safari never shows an install button by itself. The user has to do it by hand:

  1. Open the app in Safari.
  2. Tap Share, the square with an arrow.
  3. Tap Add to Home Screen.

Since you can not show a button for this, it is worth writing a short hint in the page for iPhone users.

Desktop

Chrome and Edge show an install icon at the right end of the address bar. The app opens in its own window and can be found in the start menu, launcher or Applications folder. On Mac Safari it is File, Add to Dock.

Our "Install as an app" link

The normal pages on this site show the site's header and footer, which an installed app does not need. So each app has its own clean page, app.html, and the normal page links to it. The link is added by _layouts/default.html for every page listed in _data/pwa.yml:

{% raw %}{% assign pwa_app = site.data.pwa | where: "page", page.path | first %}
{% if pwa_app %}
  <p class="text-center mb-5">
    <a href="{{ '/assets/' | append: pwa_app.slug | append: '/app.html' | relative_url }}">Install as an app</a>
  </p>
{% endif %}{% endraw %}

On app.html the browser sees the manifest and offers to install.

Your own install button

Chrome and Edge fire a beforeinstallprompt event when the app can be installed. Save the event and call prompt() when the user clicks your button. Safari and Firefox do not have this event, so the button stays hidden there.

<button id="install" hidden>Install</button>

<script>
  let installEvent = null;
  const installButton = document.getElementById("install");

  window.addEventListener("beforeinstallprompt", function (event) {
    event.preventDefault();          // Don't show the browser's own banner
    installEvent = event;
    installButton.hidden = false;
  });

  installButton.addEventListener("click", async function () {
    installButton.hidden = true;
    installEvent.prompt();
    const choice = await installEvent.userChoice;
    console.log("The user said", choice.outcome);   // "accepted" or "dismissed"
    installEvent = null;
  });
</script>

Uninstall

  • Android long press the icon and pick Uninstall.
  • iPhone long press the icon and pick Remove App.
  • Desktop Chrome open the app, click the three dots in the title bar and pick Uninstall. Or go to chrome://apps.
