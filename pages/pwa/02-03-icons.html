Icons

An installed app needs an icon for the home screen, the start menu and the splash screen. Give the browser PNG files in a few sizes and it picks the best one.

The sizes you need

  • icon-192.png 192 × 192 pixels, for the home screen
  • icon-512.png 512 × 512 pixels, for the splash screen and install dialog
  • icon-maskable-512.png 512 × 512 pixels, for Android, see below
  • apple-touch-icon.png 180 × 180 pixels, for iPhone and iPad

Maskable icons

Android cuts every icon to its own shape, like a circle or a rounded square. A normal icon then gets its corners cut off, or ends up small on a white tile. A maskable icon fills the whole square with background, and keeps the picture inside the middle 80 percent, the safe zone.

{ "src": "images/icon-512.png",          "sizes": "512x512", "type": "image/png", "purpose": "any" },
{ "src": "images/icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }

Test how a maskable icon looks in every shape with maskable.app.

iPhone and iPad

Safari does not use the icons in the manifest. It reads a link in the page instead. The icon should have no transparency and square corners, iOS rounds them itself.

<link rel="apple-touch-icon" href="images/apple-touch-icon.png">
<meta name="apple-mobile-web-app-title" content="Calculator">

How the icons on this site are made

Drawing four icons for each of 30 apps is a lot of work. Instead _scripts/make-pwa.py draws every app's emoji from _data/pwa.yml on a dark tile, with Python and Pillow. The tile is rounded for the normal icons, and square with a smaller emoji for the maskable and Apple icons.

$ sudo apt install python3-yaml python3-pil fonts-noto-color-emoji
$ python3 _scripts/make-pwa.py calculator

The important part of the script draws the emoji in the only size the color emoji font has, 109, and then scales it to fit the icon:

picture = Image.new("RGBA", (160, 160), (0, 0, 0, 0))
ImageDraw.Draw(picture).text((80, 80), emoji, font=ImageFont.truetype(EMOJI_FONT, 109),
                             embedded_color=True, anchor="mm")

Read more about the script in Many apps at once.

Other ways to make icons

  • Export an SVG to PNG in any size with Inkscape: inkscape icon.svg -w 512 -h 512 -o icon-512.png
  • Resize one big PNG with ImageMagick: convert icon.png -resize 192x192 icon-192.png
  • RealFaviconGenerator makes all sizes from one picture in the browser
