Hello World

The smallest PWA is one folder with a page, a manifest, a service worker and two icons. The finished app is on this site, so you can open the Hello World app and install it.

hello/
├── index.html              # The page
├── manifest.webmanifest    # Name, icons and colors
├── sw.js                   # Service worker, makes it work offline
├── icon-192.png
└── icon-512.png

The page

A normal HTML page. The <link rel="manifest"> line and the small script at the bottom are all that make it a PWA.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Hello PWA</title>
  <link rel="manifest" href="manifest.webmanifest">
  <meta name="theme-color" content="#1b1d21">
  <link rel="icon" href="icon-192.png" type="image/png">
</head>
<body>
  <h1>Hello, world!</h1>

  <script>
    if ("serviceWorker" in navigator) {
      navigator.serviceWorker.register("sw.js");
    }
  </script>
</body>
</html>

The manifest

Tells the browser what the installed app is called, which icon to use and how to open it. Read more in Manifest.

{
  "name": "Hello PWA",
  "short_name": "Hello",
  "start_url": "./",
  "scope": "./",
  "display": "standalone",
  "background_color": "#f3f4f6",
  "theme_color": "#1b1d21",
  "icons": [
    { "src": "icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}

The service worker

On install it saves every file in a cache. On fetch it answers from the cache, and only asks the network for files it does not have. Read more in Service worker.

const CACHE = "hello-v1";

const FILES = [
  "./",
  "./index.html",
  "./manifest.webmanifest",
  "./icon-192.png",
  "./icon-512.png"
];

self.addEventListener("install", function (event) {
  event.waitUntil(
    caches.open(CACHE).then(function (cache) { return cache.addAll(FILES); })
  );
});

self.addEventListener("fetch", function (event) {
  event.respondWith(
    caches.match(event.request).then(function (cached) {
      return cached || fetch(event.request);
    })
  );
});

Try it

$ cd hello
$ python3 -m http.server 8000
  1. Open http://localhost:8000/ in Chrome or Edge.
  2. An install icon shows up at the right end of the address bar. Click it to install.
  3. Stop the server with Ctrl+C and reload the app. It still works, because the files come from the cache.

The icons can be any square PNG. The ones in the example were made with the same script as the rest of the apps on this site, see Icons.
