Strudel

Strudel is a live coding environment for making music with code. You write short patterns of text, and Strudel plays them as drums, notes and sounds. You can change the code while the music plays, and the change is heard on the next beat. This is called live coding.

Strudel is a JavaScript version of Tidal Cycles, a pattern language for music. You don't need to know JavaScript or Tidal to start.

A browser app

Strudel runs in the web browser. Open strudel.cc and you get the REPL: a code editor and a player on the same page. There is nothing to install. The sounds are made in the browser with the Web Audio API, and the samples, like drums and pianos, are downloaded when a pattern uses them.

Strudel is free and open source, under the GNU AGPL v3 license. You can also run your own copy, see Run Strudel locally.

Play your first pattern

Open the REPL, remove the example code and write:

sound("bd sd")

Press Ctrl + Enter to play. You hear a bass drum (bd) and a snare drum (sd), over and over. Change the code to add a clap and a hi-hat, and press Ctrl + Enter again:

sound("bd sd cp hh")

The music changes without stopping. Press Ctrl + . to stop.

Keyboard shortcuts

  • Ctrl + Enter plays the code, or updates it while it plays.
  • Ctrl + . stops the music.

On a Mac you can use Cmd instead of Ctrl. There are also play and update buttons at the top of the REPL. While the music plays, the play button changes to stop.

Cycles

Strudel thinks in cycles, not in beats. A pattern like "bd sd cp hh" is squeezed into one cycle, however many steps it has. By default a cycle is 2 seconds, so four sounds take half a second each, and eight sounds a quarter of a second each. Read more in First sounds.
