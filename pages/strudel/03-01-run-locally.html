Run Strudel locally

Strudel is a web site, so the easiest way to use it is strudel.cc. But Strudel is open source, and you can run your own copy. Then you can try changes to Strudel itself, or use a version that doesn't change while you work on a song.

The source code is on Codeberg, at codeberg.org/uzu/strudel. Strudel needs Node.js 18 or newer and the package manager pnpm.

With Vagrant

The Vagrantfile below makes an Ubuntu virtual machine with everything installed. Strudel starts by itself when the machine starts. You need Vagrant and VirtualBox.

  1. Make a new folder and download the Vagrantfile into it. It is also in the Vagrantfile Maker.
  2. Start the machine. The first time takes several minutes, since it installs Node.js and downloads Strudel.
  3. Open http://localhost:4321/ in your browser.
$ mkdir strudel
$ cd strudel
$ vagrant up

Use localhost, not the IP address of the machine. The browser only lets a page use the audio engine Strudel needs on a secure page: an https:// address, or localhost. The Vagrantfile forwards port 4321 in the machine to port 4321 on your computer, so localhost works.

Stop the machine when you are done, and start it again later. Strudel starts by itself.

$ vagrant halt
$ vagrant up

What the Vagrantfile does

  • Uses the box bento/ubuntu-24.04, with 4 GB of memory and 2 CPUs.
  • Forwards port 4321 to 127.0.0.1, so only your own computer can open it.
  • Installs Node.js 22 from NodeSource, since the Node.js in Ubuntu is too old, and pnpm with npm.
  • Downloads the Strudel source code to /home/vagrant/strudel with git clone, and installs its packages with pnpm install.
  • Makes a systemd service, strudel, that runs pnpm dev every time the machine starts.

The source code is kept inside the machine, not in a synced folder. Strudel has thousands of package files in node_modules, and those are slow and can break in a synced folder.

Look at the server

Log in to the machine with vagrant ssh to see if Strudel runs, read its output, or restart it.

$ vagrant ssh
$ systemctl status strudel        # is it running?
$ journalctl -u strudel -f        # follow the output, Ctrl+C to stop
$ sudo systemctl restart strudel  # restart it

Update Strudel

Download the newest code and packages, and restart the service.

$ vagrant ssh
$ cd ~/strudel
$ git pull
$ pnpm install
$ sudo systemctl restart strudel

Without Vagrant

If Node.js 18 or newer and pnpm are already installed on your computer, you can run Strudel directly. pnpm dev starts a development server, and when it is ready it shows the address, usually http://localhost:4321/.

$ git clone https://codeberg.org/uzu/strudel.git
$ cd strudel
$ pnpm install
$ pnpm dev

pnpm can be installed with npm, which comes with Node.js:

$ npm install -g pnpm

Offline

Your own copy still downloads the samples, like drums and pianos, from the internet when a pattern uses them. So the computer needs a network connection. Synthesizer sounds, like sawtooth, work without one.
