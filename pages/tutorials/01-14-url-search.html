Url Search

We build a tool that searches many web pages at once. You give it a list of addresses and a regular expression, and it downloads every page and shows what it found on each one. It is handy for checking your own site: which pages still link to an old address, which ones mention a product, where an email address is written.

The new ideas are matchAll to find every match, DOMParser to get the text out of HTML, and running await in a loop, one page at a time.

Open the finished page

Read Make Request first. It explains fetch() and CORS.

Which pages can we read?

The same rule as in Make Request: fetch() can read every page on the same site as our tool, but pages on other sites only if the server allows it with CORS. Most websites don't. So the tool is best for searching your own site, and APIs that allow CORS. The Firefox add-on version can read any page.

Step 2: Read the URLs

function readUrls() {
    const urls = [];
    urlList.value.split(/\s+/).forEach(function (part) {
        if (part === "") {
            return;
        }
        try {
            const url = new URL(part, location.href).href;
            if (!urls.includes(url)) {
                urls.push(url);
            }
        } catch (error) {
            // Not a URL, skip it.
        }
    });
    return urls;
}

split(/\s+/) splits on any run of spaces, tabs and newlines, so one per line, or several on a line, both work. new URL(part, location.href) reads the address, and the second argument is the base for addresses without a site: /utils/ becomes https://www.anderswik.se/utils/. It throws an error if the text can't be an address, and then we skip it. includes stops the same page from being searched twice.

Step 3: Text, not HTML

A search for class in the HTML of a page finds hundreds of class="..." attributes. Usually you want to search what the page says. DOMParser turns HTML text into a document, the same kind of object as document, without showing it or running its scripts:

function pageText(html) {
    const doc = new DOMParser().parseFromString(html, "text/html");
    doc.querySelectorAll("script, style, noscript, template").forEach(function (el) {
        el.remove();
    });
    return doc.body.textContent.replace(/\s+/g, " ");
}

textContent is all the text inside an element, without tags. But it includes the code inside <script> and <style>, so we remove those first. HTML is full of line breaks and indentation, so replace(/\s+/g, " ") turns every run of white space into one space. Then Hello<br>\n world can be found with Hello world.

The checkbox lets you search the raw HTML too, to find things like a link to an old address in an href.

Step 4: Find every match

const regex = new RegExp(patternInput.value, "gi");

function findMatches(text, regex) {
    const counts = {};
    let total = 0;
    for (const match of text.matchAll(regex)) {
        counts[match[0]] = (counts[match[0]] || 0) + 1;
        total++;
    }
    return { total: total, counts: counts };
}

new RegExp(text, flags) makes a regular expression from text that the user typed. It throws an error if the text is not a valid expression, like (abc, so search() puts it in a try. The flag i ignores upper and lower case, and g means "global": find every match, not only the first.

matchAll needs the g flag, and gives every match one after the other. match[0] is the text that matched. We count each different text, so the result can say "Test ×3, test ×1" instead of a long list.

Why matchAll and not a loop with regex.exec()? A pattern like a* can match zero characters. An exec loop then finds the same empty match at the same place forever, and the page freezes. matchAll moves on by itself.

Step 5: One page at a time

async function searchPage(url, regex) {
    const response = await fetch(url);
    const html = await response.text();
    const text = searchHtml.checked ? html : pageText(html);
    return findMatches(text, regex);
}

for (let i = 0; i < urls.length; i++) {
    summary.textContent = "Searching " + (i + 1) + " of " + urls.length + "…";
    try {
        const found = await searchPage(urls[i], regex);
        showMatches(rows[i], found);
    } catch (error) {
        showFailed(rows[i]);
    }
}

await inside a for loop waits for each page before it starts the next. That is slower than downloading all of them at once, but kind to the server: a hundred requests at the same moment can look like an attack, and get you blocked.

The try is inside the loop, so one page that fails doesn't stop the rest. The list of results is made before the loop, with "waiting" on every page, so you can see how far it has come.

Step 6: Test it

  • Search https://jsonplaceholder.typicode.com/posts/1 and https://jsonplaceholder.typicode.com/posts/2 for \bsunt\b. That API allows CORS, so it works from anywhere.
  • Add https://example.com/. It fails, since example.com doesn't allow CORS.
  • Put the finished page on a web server with some other pages, and search those with addresses like /index.html.
  • Search for (abc. You get an error message, not a broken page.

<body>
  <h1>Url Search</h1>

  <form id="form">
    <label for="url-list">Pages to search, one per line</label>
    <textarea id="url-list" rows="5" spellcheck="false" placeholder="https://jsonplaceholder.typicode.com/posts/1"></textarea>

    <label for="pattern">Regular expression (ignores case)</label>
    <input id="pattern" type="text" spellcheck="false" placeholder="\bsunt\b">

    <label><input type="checkbox" id="search-html" style="width: auto"> Search the HTML source, not the text</label>

    <button type="submit" id="start">Search</button>
  </form>

  <p id="summary"></p>
  <ul id="results"></ul>

  <script>
    /*
     * Url Search: download a list of pages and search each one for a
     * regular expression.
     *
     * fetch() can only read pages from other sites if they allow it with
     * CORS. Pages on the same site always work.
     */

    // --- Elements on the page ------------------------------------------------

    const form = document.getElementById("form");
    const urlList = document.getElementById("url-list");
    const patternInput = document.getElementById("pattern");
    const searchHtml = document.getElementById("search-html");
    const startButton = document.getElementById("start");
    const summary = document.getElementById("summary");
    const resultsList = document.getElementById("results");

    // --- Reading the input ---------------------------------------------------

    // One URL per line -> a list. Empty lines and duplicates are skipped,
    // and /path is read from this page's address.
    function readUrls() {
        const urls = [];
        urlList.value.split(/\s+/).forEach(function (part) {
            if (part === "") {
                return;
            }
            try {
                const url = new URL(part, location.href).href;
                if (!urls.includes(url)) {
                    urls.push(url);
                }
            } catch (error) {
                // Not a URL, skip it.
            }
        });
        return urls;
    }

    // --- Loading and searching a page ----------------------------------------

    // The words on a page, without tags, scripts and styles.
    function pageText(html) {
        const doc = new DOMParser().parseFromString(html, "text/html");
        doc.querySelectorAll("script, style, noscript, template").forEach(function (el) {
            el.remove();
        });
        return doc.body.textContent.replace(/\s+/g, " ");
    }

    // Count every match: { "Test": 3, "test": 1 }
    function findMatches(text, regex) {
        const counts = {};
        let total = 0;
        for (const match of text.matchAll(regex)) {
            counts[match[0]] = (counts[match[0]] || 0) + 1;
            total++;
        }
        return { total: total, counts: counts };
    }

    async function searchPage(url, regex) {
        const response = await fetch(url);
        const html = await response.text();
        const text = searchHtml.checked ? html : pageText(html);
        return findMatches(text, regex);
    }

    // --- Showing results -----------------------------------------------------

    function addResult(url) {
        const li = document.createElement("li");
        const status = document.createElement("span");
        status.className = "status";
        status.textContent = "waiting";
        li.append(status, document.createTextNode(url));
        resultsList.append(li);
        return li;
    }

    function showMatches(li, found) {
        li.classList.add(found.total > 0 ? "match" : "no-match");
        li.querySelector(".status").textContent =
            found.total === 0 ? "no match" : found.total + " matches";
        for (const text in found.counts) {
            const chip = document.createElement("span");
            chip.className = "found";
            chip.textContent = text + " ×" + found.counts[text];
            li.append(document.createElement("br"), chip);
        }
    }

    function showFailed(li) {
        li.classList.add("failed");
        li.querySelector(".status").textContent = "failed";
        li.title = "Blocked by CORS, or the server could not be reached";
    }

    // --- The search ----------------------------------------------------------

    async function search() {
        let regex;
        try {
            regex = new RegExp(patternInput.value, "gi");
        } catch (error) {
            summary.textContent = "The regular expression is not valid: " + error.message;
            return;
        }
        const urls = readUrls();
        if (urls.length === 0 || patternInput.value === "") {
            summary.textContent = "Write some URLs and a regular expression.";
            return;
        }

        startButton.disabled = true;
        resultsList.textContent = "";
        const rows = urls.map(addResult);
        let withMatches = 0;

        // One page at a time, so we don't flood the server.
        for (let i = 0; i < urls.length; i++) {
            summary.textContent = "Searching " + (i + 1) + " of " + urls.length + "…";
            rows[i].querySelector(".status").textContent = "searching…";
            try {
                const found = await searchPage(urls[i], regex);
                showMatches(rows[i], found);
                if (found.total > 0) {
                    withMatches++;
                }
            } catch (error) {
                showFailed(rows[i]);
            }
        }

        summary.textContent = "Searched " + urls.length + " pages, " + withMatches + " with matches.";
        startButton.disabled = false;
    }

    form.addEventListener("submit", function (event) {
        event.preventDefault();
        search();
    });
  </script>
</body>
</html>

Pages that are made by JavaScript: a frame

fetch() gives you the HTML the server sends. Some pages are almost empty HTML, and JavaScript fills them in when they are shown. To search those, the version on this site can load each page in an <iframe> instead, wait a little, and read what it shows:

loader.onload = function () {
    setTimeout(function () {
        const doc = loader.contentDocument;
        const text = doc.body.innerText;
        // search the text
    }, delay);
};
loader.src = url;

contentDocument is the document inside the frame. But the browser only gives it to you if the page in the frame is from the same site. For any other site it is null, whatever the server says, and CORS doesn't change that. If it didn't work that way, any site could open your webmail in a hidden frame and read it. So the frame only works for your own site, and the tool checks that before loading a page:

if (new URL(url).origin !== location.origin) {
    // can't be read in a frame, use fetch instead
}

An origin is the scheme, host and port together, like https://www.anderswik.se. Note that https://anderswik.se and https://www.anderswik.se are different origins.

The version on this site also has a Stop button, a progress bar, and a button that saves the results as a CSV file you can open in a spreadsheet. The CSV is made the same way as the export in Make Request, with a Blob. Text with a comma, a quote or a line break in it goes inside quotes, with each quote doubled:

function csvCell(text) {
    return /[",\n\r]/.test(text) ? '"' + text.replace(/"/g, '""') + '"' : text;
}

Any site: the Firefox add-on

Like Make Request, Url Search is also a Firefox add-on with permission for every site, and in the add-on fetch() can read any page. The frame still only works for pages from the add-on itself, so in the add-on, always use Download.

  • Search two or three pages at the same time, to make it faster without flooding the server.
