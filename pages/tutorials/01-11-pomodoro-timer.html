Pomodoro timer

The Pomodoro technique is a way to work: focus for 25 minutes, take a 5 minute break, and repeat. We build a timer for it with a ring that fills up as time passes, a play button in the middle, - and + to change the length, and a Focus / Break switch.

The new ideas are a timer that uses the clock instead of counting ticks, and drawing a progress ring with an SVG circle.

Open the finished page

Read the Egg clock first. It explains setInterval and the beep.

The state

const minutes = { focus: 25, break: 5 };  // the length of each mode
let mode = "focus";                       // "focus" or "break"
let msLeft = minutes.focus * 60 * 1000;   // time left, in milliseconds
let endTime = null;                       // when the session ends, null when paused
let timer = null;                         // the id from setInterval, null when paused
let audio = null;                         // for the beep

minutes is an object with one length per mode. minutes[mode] reads the length of the current mode, whichever it is. minutes is a const, but we can still change what is inside it. const only means the name always points to the same object.

The ring is two circles on top of each other: a gray track, and a green progress circle that we draw only part of. The play icon is an SVG <path>. M7 4.5 moves the pen to a point, v15 draws a line 15 down, l13-7.5 draws a line 13 right and 7.5 up, and z closes the shape. That gives a triangle that points right.

The play button has no text, so aria-label tells screen readers what it does. aria-live="polite" on the time lets a screen reader read the new time when it changes.

Circles are just lines here: fill: none leaves the middle empty and stroke-width makes the line thick.

An SVG circle's line starts at 3 o'clock. We turn the whole SVG -90deg so the ring starts filling from 12 o'clock, like a clock. Note the > in .ring > svg: it means only an SVG directly inside .ring. Without it the rule would also turn the play icon, which is an SVG further down, and the triangle would point up.

The play button sits in the middle with a common trick: top: 50%; left: 50% puts its top left corner in the middle, and translate(-50%, -50%) moves it back by half its own size.

The rest of the CSS, for the card, the time row and the Focus / Break pills, is in the complete page at the bottom.

Step 3: The progress ring

Two CSS properties draw part of a line:

  • stroke-dasharray turns the line into dashes. If the dash is as long as the whole line, there is one dash that covers it all.
  • stroke-dashoffset moves the dash along the line. Move it by the whole length and nothing is visible. Move it by half and half the ring is drawn.

The length of the line is the circumference of the circle, 2 × π × radius:

const RING_LENGTH = 2 * Math.PI * 50;   // r="50" in the HTML
progress.style.strokeDasharray = RING_LENGTH;

// done is 0 at the start and 1 when the time is up.
const done = 1 - msLeft / totalMs();
progress.style.strokeDashoffset = RING_LENGTH * (1 - done);

stroke-linecap: round gives the line round ends, which looks nice, but a round end is also drawn when the line has length 0, as a small dot at 12 o'clock. So we hide the progress circle until some time has passed:

progress.style.visibility = done > 0 ? "visible" : "hidden";

Step 4: Use the clock, not the ticks

The egg clock subtracts one second every time setInterval calls it. That is fine for a few minutes in a tab you are looking at. But browsers slow down timers in tabs you are not looking at, to save battery, sometimes to once a minute. A 25 minute timer that counts ticks can then end many minutes late.

Instead we remember when the session ends. Date.now() is the time right now in milliseconds, so:

function start() {
    if (audio === null) {
        audio = new AudioContext();
    }
    endTime = Date.now() + msLeft;
    timer = setInterval(tick, 250);
    render();
}

function tick() {
    msLeft = Math.max(0, endTime - Date.now());
    if (msLeft === 0) {
        pause();
        beep();
        setMode(mode === "focus" ? "break" : "focus");
        return;
    }
    render();
}

However late tick is called, endTime - Date.now() is the right time left. We tick four times a second instead of once, so the display never lags almost a whole second behind.

When the time is up we beep and switch to the other mode, so the next press on play starts the break (or the next focus session).

Step 5: Pause

function pause() {
    msLeft = Math.max(0, endTime - Date.now());
    clearInterval(timer);
    timer = null;
    endTime = null;
    render();
}

function isRunning() {
    return timer !== null;
}

Pause saves the time left, so start() can make a new endTime from it later. The play button calls start() or pause() depending on isRunning(), so one button does both.

Step 6: Show the time

// 90500 ms -> "01:31"
function formatTime(ms) {
    const seconds = Math.ceil(ms / 1000);
    const mm = String(Math.floor(seconds / 60)).padStart(2, "0");
    const ss = String(seconds % 60).padStart(2, "0");
    return mm + ":" + ss;
}

Math.ceil rounds up. With 400 ms left it shows 00:01, not 00:00, so 00:00 only shows when the time is really up.

All the drawing happens in one function, render(), which reads the state and updates the page. It also puts the time in the browser tab with document.title, so you can see it from another tab, and swaps the play triangle for a pause icon while running:

const PLAY_ICON = "M7 4.5v15l13-7.5z";
const PAUSE_ICON = "M6 4h4.5v16H6zM13.5 4H18v16h-4.5z";   // two bars

playIcon.setAttribute("d", isRunning() ? PAUSE_ICON : PLAY_ICON);

Step 7: Change the length and the mode

function changeMinutes(change) {
    if (isRunning()) {
        return;
    }
    minutes[mode] = Math.min(99, Math.max(1, minutes[mode] + change));
    msLeft = totalMs();
    render();
}

function setMode(newMode) {
    if (isRunning()) {
        pause();
    }
    mode = newMode;
    msLeft = totalMs();
    render();
}

The length can't change while the timer runs, so render() also disables - and + then. The Focus and Break buttons use data-mode, like the calculator keys use data-val, so one loop connects both:

modeButtons.forEach(function (button) {
    button.addEventListener("click", function () { setMode(button.dataset.mode); });
});

Step 8: Test it

  • Press - until it shows 01:00 and press play. The ring fills up and it beeps after one minute, then it shows Break and 05:00.
  • Press play, then pause after a few seconds. The time and the ring stop. Press play again and they continue from there.
  • Start a session, switch to another tab for a few minutes, and come back. The time is still right.
  • - and + are grey while it runs, and - stops at 1 minute.
  • Set Focus to 30 minutes, switch to Break and back. Focus is still 30.

  <script>
    /*
     * Pomodoro timer: work in focus sessions with short breaks in between.
     *
     * State:
     *   minutes   the length of each mode, e.g. { focus: 25, break: 5 }
     *   mode      "focus" or "break"
     *   msLeft    time left in milliseconds
     *   endTime   when the session ends (Date.now() milliseconds), null when paused
     *   timer     the id from setInterval, null when paused
     *
     * We don't count ticks. We remember when the session ends and work out
     * the time left from the clock, so the timer stays right even when the
     * browser slows down timers in a background tab.
     */

    // --- State ---------------------------------------------------------------

    const minutes = { focus: 25, break: 5 };
    let mode = "focus";
    let msLeft = minutes.focus * 60 * 1000;
    let endTime = null;
    let timer = null;
    let audio = null;   // made on the first click, see beep()

    const PLAY_ICON = "M7 4.5v15l13-7.5z";
    const PAUSE_ICON = "M6 4h4.5v16H6zM13.5 4H18v16h-4.5z";

    // --- Elements on the page ------------------------------------------------

    const timeText = document.getElementById("time");
    const playButton = document.getElementById("play");
    const playIcon = document.getElementById("play-icon");
    const minusButton = document.getElementById("minus");
    const plusButton = document.getElementById("plus");
    const progress = document.getElementById("progress");
    const modeButtons = document.querySelectorAll(".mode");

    // The length of the ring's line: 2 * pi * radius.
    const RING_LENGTH = 2 * Math.PI * 50;
    progress.style.strokeDasharray = RING_LENGTH;

    // --- Helpers -------------------------------------------------------------

    function totalMs() {
        return minutes[mode] * 60 * 1000;
    }

    function isRunning() {
        return timer !== null;
    }

    // 90500 ms -> "01:31". Round up, so it shows 00:01 until the very end.
    function formatTime(ms) {
        const seconds = Math.ceil(ms / 1000);
        const mm = String(Math.floor(seconds / 60)).padStart(2, "0");
        const ss = String(seconds % 60).padStart(2, "0");
        return mm + ":" + ss;
    }

    // Three short beeps with the Web Audio API.
    function beep() {
        for (let i = 0; i < 3; i++) {
            const start = audio.currentTime + i * 0.35;
            const tone = audio.createOscillator();
            tone.frequency.value = 880;
            tone.connect(audio.destination);
            tone.start(start);
            tone.stop(start + 0.25);
        }
    }

    // --- Drawing -------------------------------------------------------------

    // Draw everything from the state.
    function render() {
        const text = formatTime(msLeft);
        timeText.textContent = text;
        document.title = isRunning() ? text + " - Pomodoro" : "Pomodoro timer";

        // How much of the session is done, from 0 to 1.
        const done = 1 - msLeft / totalMs();
        progress.style.strokeDashoffset = RING_LENGTH * (1 - done);
        // A round line end shows as a dot even at 0, so hide it then.
        progress.style.visibility = done > 0 ? "visible" : "hidden";

        playIcon.setAttribute("d", isRunning() ? PAUSE_ICON : PLAY_ICON);
        playButton.setAttribute("aria-label", isRunning() ? "Pause" : "Start");

        minusButton.disabled = isRunning() || minutes[mode] <= 1;
        plusButton.disabled = isRunning() || minutes[mode] >= 99;

        modeButtons.forEach(function (button) {
            button.classList.toggle("active", button.dataset.mode === mode);
        });
    }

    // --- Actions -------------------------------------------------------------

    function start() {
        // Browsers only allow sound after a click, so make the audio here.
        if (audio === null) {
            audio = new AudioContext();
        }
        endTime = Date.now() + msLeft;
        timer = setInterval(tick, 250);
        render();
    }

    function pause() {
        msLeft = Math.max(0, endTime - Date.now());
        clearInterval(timer);
        timer = null;
        endTime = null;
        render();
    }

    // Called four times a second while running.
    function tick() {
        msLeft = Math.max(0, endTime - Date.now());
        if (msLeft === 0) {
            pause();
            beep();
            // After focus comes a break, after a break comes focus.
            setMode(mode === "focus" ? "break" : "focus");
            return;
        }
        render();
    }

    function setMode(newMode) {
        if (isRunning()) {
            pause();
        }
        mode = newMode;
        msLeft = totalMs();
        render();
    }

    // Add (1) or remove (-1) a minute, between 1 and 99 minutes.
    function changeMinutes(change) {
        if (isRunning()) {
            return;
        }
        minutes[mode] = Math.min(99, Math.max(1, minutes[mode] + change));
        msLeft = totalMs();
        render();
    }

    // --- Connect the buttons -------------------------------------------------

    playButton.addEventListener("click", function () {
        if (isRunning()) {
            pause();
        } else {
            start();
        }
    });

    minusButton.addEventListener("click", function () { changeMinutes(-1); });
    plusButton.addEventListener("click", function () { changeMinutes(1); });

    modeButtons.forEach(function (button) {
        button.addEventListener("click", function () { setMode(button.dataset.mode); });
    });

    render();
  </script>
</body>
</html>
