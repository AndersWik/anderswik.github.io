Connect Four vs computer

The same game as Connect Four, but now yellow can be played by the computer. There are two levels. The easy computer follows three simple rules. The hard one tries every move five moves ahead and picks the best one.

Start from your Connect Four page. Everything from it stays the same. This tutorial only shows what is new: taking turns with the computer, and two ways for the computer to choose a move.

Open the finished game

Step 1: Choosing who to play

Add a drop-down list under the New game button:

<p>
  <label for="mode">Play against:</label>
  <select id="mode">
    <option value="pvp">A friend</option>
    <option value="easy" selected>The computer (easy)</option>
    <option value="hard">The computer (hard)</option>
  </select>
</p>

selected makes the easy computer the default. The code reads the choice with modeSelect.value, which is "pvp", "easy" or "hard". Changing it starts a new game:

modeSelect.addEventListener("change", newGame);

The CSS is the same as before.

Step 2: Whose turn is it?

const HUMAN = 1;
const COMPUTER = 2;

function isComputersTurn() {
    return modeSelect.value !== "pvp" && player === COMPUTER;
}

function showTurn() {
    if (isComputersTurn()) {
        statusText.textContent = NAMES[player] + " is thinking...";
    } else {
        statusText.textContent = NAMES[player] + "'s turn";
    }
}

Use showTurn() where newGame and play used to set the status text. The click on a place now checks whose turn it is first, so you can't play the computer's move for it:

cell.addEventListener("click", function () {
    if (!isComputersTurn()) {
        play(col);
    }
});

In the first version of this game, that check only looked for the easy computer. Against the hard one, you could click while it was thinking and play yellow's move yourself.

Step 3: Letting the computer move

At the end of play, after switching player, start the computer's move if it is its turn:

player = player === 1 ? 2 : 1;
showTurn();
if (isComputersTurn()) {
    computerTimer = setTimeout(computerMove, COMPUTER_DELAY);
}
function computerMove() {
    const col = modeSelect.value === "easy" ? easyMove() : hardMove();
    play(col);
}

The computer could move right away, but then its piece would show up at the same time as yours, and you wouldn't see what it did. Half a second (COMPUTER_DELAY = 500) feels like it is thinking.

The computer calls the same play as a click does. All the rules, the win check and switching player are in one place, and both players use them.

The waiting has one trap. If you press New game during that half second, the computer's move from the old game would land on the new board. So setTimeout gives us a number for the timer, we keep it in computerTimer, and the first thing newGame does is cancel it:

Step 4: Trying a move and taking it back

Both computers need to ask "what if I played here?". The simplest way is to really put the piece in grid, check, and take it out again:

function winsIn(col, who) {
    const row = freeRow(col);
    if (row === -1) {
        return false;
    }
    grid[row][col] = who;
    const wins = findWin(row, col) !== null;
    grid[row][col] = 0;
    return wins;
}

Only grid is changed, not the page, so the player never sees it. It is important to always put it back to 0, also when the move wins. That is why we save the answer in wins first, and return it after cleaning up.

Step 5: The easy computer

const MIDDLE_FIRST = [3, 2, 4, 1, 5, 0, 6];

function easyMove() {
    const open = MIDDLE_FIRST.filter(function (col) {
        return freeRow(col) !== -1;
    });
    const win = open.find(function (col) {
        return winsIn(col, COMPUTER);
    });
    if (win !== undefined) {
        return win;
    }
    const block = open.find(function (col) {
        return winsIn(col, HUMAN);
    });
    if (block !== undefined) {
        return block;
    }
    return open[0];
}
  1. If a move wins, take it.
  2. If the human would win by playing in a column, play there first and block it.
  3. Otherwise, play as near the middle as possible. Pieces in the middle are part of more lines of four than pieces at the edge.

open is the columns that aren't full, middle first. find gives the first column where the test is true, or undefined if there is none. We compare with undefined and not just if (win), because column 0 is a real answer, but 0 counts as false in an if.

Step 6: Looking ahead

The easy computer only looks one move ahead. It can't see a trap, where you make two threats at once and it can only block one of them. To see that, the computer has to think "if I play here, then you play there, then I play here..."

That is what minimax does. Give every board a score: big when it is good for the computer, small when it is good for the human. Then:

  • On the computer's turn, it picks the move with the biggest score.
  • On the human's turn, it expects the human to pick the move with the smallest score, the best move for the human.

To find the score of a move, it tries all the answers to it, and all the answers to those, and so on, a few moves deep. That is a function that calls itself, which is called recursion:

function minimax(row, col, depth) {
    const who = grid[row][col];
    if (findWin(row, col)) {
        return who === COMPUTER ? 1000 + depth : -1000 - depth;
    }
    if (depth === 0) {
        return scoreBoard();
    }

    const next = who === COMPUTER ? HUMAN : COMPUTER;
    let best = next === COMPUTER ? -Infinity : Infinity;
    let anyMove = false;
    for (let c = 0; c < COLS; c++) {
        const r = freeRow(c);
        if (r === -1) {
            continue;
        }
        anyMove = true;
        grid[r][c] = next;
        const score = minimax(r, c, depth - 1);
        grid[r][c] = 0;
        best = next === COMPUTER ? Math.max(best, score) : Math.min(best, score);
    }
    return anyMove ? best : 0;
}

minimax is called right after a piece was put at (row, col). Read it from the top:

  • If that piece won, the game is over, and we know the score: 1000 if the computer won, -1000 if the human did. + depth makes a quick win worth a little more than a slow one, so the computer doesn't wait to win. And a loss far away is a little less bad than one next turn, so it fights on.
  • If depth is 0, we have looked far enough. We don't know who will win, so we make a guess with scoreBoard() (next step).
  • Otherwise it is next's turn. Try each column the same way as in winsIn: put the piece in, ask minimax for the score with one less depth, and take the piece out. Keep the biggest score if it is the computer's turn, the smallest if it is the human's.
  • continue skips the rest of the loop for a full column. If every column is full, the board is full, and a draw scores 0.

Every call has a smaller depth than the one before, so it always ends. hardMove tries each column for the computer and keeps the one with the biggest score:

function hardMove() {
    let bestCol = -1;
    let bestScore = -Infinity;
    for (const col of MIDDLE_FIRST) {
        const row = freeRow(col);
        if (row === -1) {
            continue;
        }
        grid[row][col] = COMPUTER;
        const score = minimax(row, col, DEPTH - 1);
        grid[row][col] = 0;
        if (score > bestScore) {
            bestScore = score;
            bestCol = col;
        }
    }
    return bestCol;
}

It looks at the middle columns first, and only takes a new column if it is strictly better (>). So when two moves are just as good, the one nearer the middle wins.

Step 7: Scoring a board nobody has won

When depth runs out, we need a guess. Every line of four places on the board is a chance to win. A line with only yellow pieces in it is good for the computer, the more the better. A line with both colors in it can never be won by anyone, so it is worth nothing:

function scoreLine(mine, theirs) {
    if (mine > 0 && theirs > 0) {
        return 0;
    }
    if (mine === 3) {
        return 5;
    }
    if (mine === 2) {
        return 2;
    }
    if (theirs === 3) {
        return -5;
    }
    if (theirs === 2) {
        return -2;
    }
    return 0;
}

scoreBoard goes through every place on the board and every direction from DIRECTIONS. If a line of four from there fits on the board, it counts the yellow and red pieces in it, and adds up scoreLine for all of them. The numbers 5 and 2 are just a guess that works well. Try changing them and see if the computer gets better or worse.

Step 8: How deep?

With DEPTH = 5, the computer looks at 7 moves, then 7 answers to each, and so on, five times: 7 × 7 × 7 × 7 × 7 = 16,807 boards. That takes well under a tenth of a second. Each extra move ahead is 7 times more work: depth 7 is over 800,000 boards and you would notice the wait. Five is strong enough to beat most people, and to never miss a simple win or block.

Step 9: Test it

  • Put three red in a row with an empty place at the end. Both computers should block it.
  • Give the computer three in a row and don't block it. It should win, not block something else.
  • Click the board while it says "Yellow is thinking...". Nothing should happen.
  • Press New game right after your move. The computer's move should not show up on the new board.
  • Choose "A friend". Both colors should be played by clicking again.

<body>
  <h1>Connect Four</h1>
  <div id="board"></div>
  <p id="status" aria-live="polite"></p>
  <button type="button" id="restart">New game</button>
  <p>
    <label for="mode">Play against:</label>
    <select id="mode">
      <option value="pvp">A friend</option>
      <option value="easy" selected>The computer (easy)</option>
      <option value="hard">The computer (hard)</option>
    </select>

  <script>
    /*
     * Connect Four against the computer: the same game as Connect Four for two
     * players, but yellow can be played by the computer.
     *
     *   Easy: win if it can, block you if you are about to win, otherwise play
     *         as near the middle as it can.
     *   Hard: tries every move 5 moves ahead (minimax) and picks the best.
     */

    // --- Settings ------------------------------------------------------------

    const ROWS = 6;
    const COLS = 7;
    const NAMES = { 1: "Red", 2: "Yellow" };
    const HUMAN = 1;
    const COMPUTER = 2;
    const DEPTH = 5;                            // moves the hard computer looks ahead
    const COMPUTER_DELAY = 500;                 // ms before the computer moves
    const MIDDLE_FIRST = [3, 2, 4, 1, 5, 0, 6]; // columns, best first

    const DIRECTIONS = [
        [0, 1],   // across
        [1, 0],   // down
        [1, 1],   // diagonal \
        [1, -1]   // diagonal /
    ];

    // --- Elements on the page ------------------------------------------------

    const boardElement = document.getElementById("board");
    const statusText = document.getElementById("status");
    const restartButton = document.getElementById("restart");
    const modeSelect = document.getElementById("mode");

    // --- State ---------------------------------------------------------------

    let grid = [];          // grid[row][col]: 0 = empty, 1 = red, 2 = yellow
    let cells = [];         // cells[row][col]: the <div> for each place
    let player = 1;         // whose turn it is
    let moves = 0;
    let gameOver = false;
    let computerTimer = null;

    // --- The board -----------------------------------------------------------

    function newGame() {
        // A computer move that is waiting to happen belongs to the old game.
        clearTimeout(computerTimer);

        grid = [];
        cells = [];
        boardElement.innerHTML = "";

        // Row 0 is the top row.
        for (let row = 0; row < ROWS; row++) {
            grid.push([]);
            cells.push([]);
            for (let col = 0; col < COLS; col++) {
                const cell = document.createElement("div");
                cell.className = "cell";
                cell.addEventListener("click", function () {
                    if (!isComputersTurn()) {
                        play(col);
                    }
                });
                boardElement.appendChild(cell);
                grid[row].push(0);
                cells[row].push(cell);
            }
        }

        player = 1;
        moves = 0;
        gameOver = false;
        showTurn();
    }

    function isComputersTurn() {
        return modeSelect.value !== "pvp" && player === COMPUTER;
    }

    function showTurn() {
        if (isComputersTurn()) {
            statusText.textContent = NAMES[player] + " is thinking...";
        } else {
            statusText.textContent = NAMES[player] + "'s turn";
        }
    }

    // The lowest empty row in a column, or -1 if the column is full.
    function freeRow(col) {
        for (let row = ROWS - 1; row >= 0; row--) {
            if (grid[row][col] === 0) {
                return row;
            }
        }
        return -1;
    }

    // --- Four in a row -------------------------------------------------------

    // The pieces of the same color in a line from (row, col), one step at a
    // time in the direction (dRow, dCol), not counting the start.
    function lineFrom(row, col, dRow, dCol) {
        const who = grid[row][col];
        const line = [];
        let r = row + dRow;
        let c = col + dCol;
        while (r >= 0 && r < ROWS && c >= 0 && c < COLS && grid[r][c] === who) {
            line.push([r, c]);
            r += dRow;
            c += dCol;
        }
        return line;
    }

    // Does the piece at (row, col) make four in a row? Returns the winning
    // places, or null.
    function findWin(row, col) {
        for (const [dRow, dCol] of DIRECTIONS) {
            // Look both ways from the new piece.
            const line = [[row, col]]
                .concat(lineFrom(row, col, dRow, dCol))
                .concat(lineFrom(row, col, -dRow, -dCol));
            if (line.length >= 4) {
                return line;
            }
        }
        return null;
    }

    // --- Playing -------------------------------------------------------------

    function play(col) {
        if (gameOver) {
            return;
        }
        const row = freeRow(col);
        if (row === -1) {
            return; // the column is full
        }

        grid[row][col] = player;
        cells[row][col].classList.add("player" + player);
        moves++;

        const win = findWin(row, col);
        if (win) {
            win.forEach(function ([r, c]) {
                cells[r][c].classList.add("winning");
            });
            statusText.textContent = NAMES[player] + " wins!";
            gameOver = true;
        } else if (moves === ROWS * COLS) {
            statusText.textContent = "It's a draw!";
            gameOver = true;
        } else {
            player = player === 1 ? 2 : 1;
            showTurn();
            if (isComputersTurn()) {
                computerTimer = setTimeout(computerMove, COMPUTER_DELAY);
            }
        }
    }

    // --- The computer --------------------------------------------------------

    function computerMove() {
        const col = modeSelect.value === "easy" ? easyMove() : hardMove();
        play(col);
    }

    // Would dropping a piece for "who" in this column win? The piece is put in,
    // tested and taken out again.
    function winsIn(col, who) {
        const row = freeRow(col);
        if (row === -1) {
            return false;
        }
        grid[row][col] = who;
        const wins = findWin(row, col) !== null;
        grid[row][col] = 0;
        return wins;
    }

    function easyMove() {
        const open = MIDDLE_FIRST.filter(function (col) {
            return freeRow(col) !== -1;
        });
        // 1. Win if we can.
        const win = open.find(function (col) {
            return winsIn(col, COMPUTER);
        });
        if (win !== undefined) {
            return win;
        }
        // 2. Stop the human from winning.
        const block = open.find(function (col) {
            return winsIn(col, HUMAN);
        });
        if (block !== undefined) {
            return block;
        }
        // 3. As near the middle as possible.
        return open[0];
    }

    function hardMove() {
        let bestCol = -1;
        let bestScore = -Infinity;
        for (const col of MIDDLE_FIRST) {
            const row = freeRow(col);
            if (row === -1) {
                continue;
            }
            grid[row][col] = COMPUTER;
            const score = minimax(row, col, DEPTH - 1);
            grid[row][col] = 0;
            if (score > bestScore) {
                bestScore = score;
                bestCol = col;
            }
        }
        return bestCol;
    }

    // How good is the board for the computer, right after a piece was dropped at
    // (row, col)? Big is good for the computer, small is good for the human.
    // depth is how many more moves to look ahead.
    function minimax(row, col, depth) {
        const who = grid[row][col];
        if (findWin(row, col)) {
            // + depth: a win in fewer moves is better, a loss in more moves is
            // less bad.
            return who === COMPUTER ? 1000 + depth : -1000 - depth;
        }
        if (depth === 0) {
            return scoreBoard();
        }

        // Now it is the other player's turn. The computer picks the biggest
        // score, and expects the human to pick the smallest.
        const next = who === COMPUTER ? HUMAN : COMPUTER;
        let best = next === COMPUTER ? -Infinity : Infinity;
        let anyMove = false;
        for (let c = 0; c < COLS; c++) {
            const r = freeRow(c);
            if (r === -1) {
                continue;
            }
            anyMove = true;
            grid[r][c] = next;
            const score = minimax(r, c, depth - 1);
            grid[r][c] = 0;
            best = next === COMPUTER ? Math.max(best, score) : Math.min(best, score);
        }
        return anyMove ? best : 0; // the board is full: a draw
    }

    // A guess at how good the board is, when nobody has won yet. Look at every
    // line of four places on the board.
    function scoreBoard() {
        let score = 0;
        for (let row = 0; row < ROWS; row++) {
            for (let col = 0; col < COLS; col++) {
                for (const [dRow, dCol] of DIRECTIONS) {
                    const endRow = row + 3 * dRow;
                    const endCol = col + 3 * dCol;
                    if (endRow < 0 || endRow >= ROWS || endCol < 0 || endCol >= COLS) {
                        continue; // the line would go off the board
                    }
                    let mine = 0;
                    let theirs = 0;
                    for (let i = 0; i < 4; i++) {
                        const piece = grid[row + i * dRow][col + i * dCol];
                        if (piece === COMPUTER) {
                            mine++;
                        } else if (piece === HUMAN) {
                            theirs++;
                        }
                    }
                    score += scoreLine(mine, theirs);
                }
            }
        }
        return score;
    }

    function scoreLine(mine, theirs) {
        if (mine > 0 && theirs > 0) {
            return 0; // both colors in it: nobody can win with this line
        }
        if (mine === 3) {
            return 5;
        }
        if (mine === 2) {
            return 2;
        }
        if (theirs === 3) {
            return -5;
        }
        if (theirs === 2) {
            return -2;
        }
        return 0;
    }

    // --- Connect the page ----------------------------------------------------

    restartButton.addEventListener("click", newGame);
    modeSelect.addEventListener("change", newGame);

    newGame();
  </script>
</body>
</html>

Try this

  • Add a choice for who starts, so the computer can play first.
  • Make the easy computer pick a random free column sometimes, so it doesn't play the same way every game.
  • Look up alpha-beta pruning. It skips moves that can't change the answer, and lets the hard computer look a few moves deeper in the same time.
