Chore wheel

Add chores and people, spin the wheel, and the names around it show who does what. The chores are colored slices drawn on a canvas, the wheel spins with a CSS transition, and when it stops each person gets the slice their name points at.

The tricky part is working out which slice ends up under each name. That takes a little maths with angles.

Open the finished game

#wheel-container has position: relative, and the name labels inside it have position: absolute. That means left: 50%; top: 0% is measured from the container's own corner. transform: translate(-50%, -50%) moves each label back by half its size, so the middle of the label is at the point, not its corner.

Step 2: Angles on a screen

On a canvas, and in CSS, 0° points right, and angles go clockwise, because y counts downwards. So 90° points down and -90° points up.

Step 3: Drawing the wheel

Each chore is a slice. With 4 chores, each slice is 360 / 4 = 90°. A slice is drawn as: start in the center, go along the edge with arc, back to the center.

const sliceAngle = 2 * Math.PI / chores.length;

chores.forEach(function (chore, i) {
    ctx.beginPath();
    ctx.moveTo(center, center);
    ctx.arc(center, center, center, i * sliceAngle, (i + 1) * sliceAngle);
    ctx.closePath();
    ctx.fillStyle = COLORS[i % COLORS.length];
    ctx.fill();
    ctx.stroke();
    ...
});

arc uses radians: a whole turn is 2 * Math.PI. i % COLORS.length starts the colors over if there are more chores than colors.

The text is written along the slice. We turn the canvas to the middle of the slice and write from the center outwards, with the end of the text near the edge (textAlign = "right"):

ctx.save();
ctx.translate(center, center);
ctx.rotate(i * sliceAngle + sliceAngle / 2);
ctx.textAlign = "right";
ctx.fillText(chore, center - 30, 5);
ctx.restore();

Step 4: Names around the wheel

The people are spread evenly around the wheel, starting at the top:

function personAngle(index) {
    return index * 360 / people.length - 90;
}

With 3 people that is -90° (top), 30° (lower right) and 150° (lower left). Each name is placed with cos and sin, in percent of the container, so it follows the wheel when the page is narrow:

const radians = personAngle(i) * Math.PI / 180;
label.style.left = (50 + Math.cos(radians) * 57) + "%";
label.style.top = (50 + Math.sin(radians) * 57) + "%";

50% is the center. The wheel's edge is 50% from the center, so 57% puts the names just outside it.

Step 5: Lists that are safe for any text

The lists show what the user typed, with a remove button. We build them with createElement and add the text with append, which always adds text as text:

const li = document.createElement("li");
const button = document.createElement("button");
button.type = "button";
button.className = "remove";
button.textContent = "X";
button.addEventListener("click", function () {
    remove(index);
});
li.append(button, item);

The first version built the list by joining text into HTML: li.innerHTML = "<button>X</button> " + item. Then a chore called <img src=x onerror=alert(1)> would run code on the page. Here it shows up as text.

Step 6: Spinning with CSS

The canvas itself turns with a CSS transform. With a transition, the browser animates the change smoothly, and ease-out makes it slow down at the end, like a real wheel:

const extra = Math.floor(Math.random() * 360);
wheel.style.transition = "transform " + SPIN_TIME + "ms ease-out";
wheel.style.transform = "rotate(" + (rotation + TURNS * 360 + extra) + "deg)";

It turns 10 whole turns plus a random extra angle, starting from where it is now. When it has stopped, we jump to the same angle without the 10 turns, and without a transition. It looks exactly the same, but the numbers stay small:

rotation = (rotation + extra) % 360;
wheel.style.transition = "none";
wheel.style.transform = "rotate(" + rotation + "deg)";

Step 7: Who got what?

The wheel has turned rotation degrees clockwise. A person sits at a fixed angle on the screen. Which part of the wheel is under them now? The part that was rotation degrees before them, counter-clockwise, before the spin. So we turn the person's angle back by the rotation, and see which slice that angle is in:

function choreAt(angle) {
    const sliceSize = 360 / chores.length;
    const onWheel = ((angle - rotation) % 360 + 360) % 360;
    return chores[Math.floor(onWheel / sliceSize)];
}

% 360 keeps the angle within one turn, but in JavaScript % of a negative number is negative: -90 % 360 is -90. Adding 360 and taking % 360 again always gives 0 to 359.

An example with 4 chores (90° each) and the wheel turned 37°: the person at the top is at -90°. -90 - 37 = -127, which is 233° on the wheel, in slice 2 (180°-270°).

resultText.textContent = people.map(function (person, i) {
    return person + ": " + choreAt(personAngle(i));
}).join("\n");

Step 8: Test it

  • Try to spin with no chores or no people.
  • Add four chores and three people, spin, and check that each name's chore in the result is the slice the name points at.
  • Try to add or remove something while it spins. Nothing should change.
  • Add a chore called <b>Dishes</b>. It should show with the tags as text.

  <script>
    /*
     * Chore wheel: add chores and people, spin the wheel, and see who does what.
     *
     * The chores are slices of a wheel drawn on a canvas. The people's names
     * sit around the wheel. The wheel spins with a CSS transition, and when it
     * stops, each person gets the chore their name points at.
     */

    // --- Settings ------------------------------------------------------------

    const COLORS = ["#ff0000", "#ffff00", "#00ff00", "#0000ff", "#ff00ff", "#ffa500", "#a020f0", "#6495ed"];
    const SPIN_TIME = 4000;   // ms, the same as the transition in the CSS
    const TURNS = 10;         // whole turns before it slows down

    // --- Elements on the page ------------------------------------------------

    const wheel = document.getElementById("wheel");
    const ctx = wheel.getContext("2d");
    const namesContainer = document.getElementById("names-container");
    const choreForm = document.getElementById("chore-form");
    const choreInput = document.getElementById("choreInput");
    const personForm = document.getElementById("person-form");
    const personInput = document.getElementById("personInput");
    const spinButton = document.getElementById("spinButton");
    const choreList = document.getElementById("choreList");
    const peopleList = document.getElementById("peopleList");
    const resultText = document.getElementById("result");

    // --- State ---------------------------------------------------------------

    let chores = [];
    let people = [];
    let rotation = 0;      // degrees the wheel is turned, 0-359
    let spinning = false;

    // --- Helpers -------------------------------------------------------------

    // Angles of the people around the wheel, in degrees. The first person is
    // at the top (-90°, because 0° points right and angles go clockwise).
    function personAngle(index) {
        return index * 360 / people.length - 90;
    }

    // Which chore is under the person at this angle when the wheel has turned
    // "rotation" degrees? Turn the angle back by the rotation to find the place
    // on the unturned wheel, then see which slice that is.
    function choreAt(angle) {
        const sliceSize = 360 / chores.length;
        const onWheel = ((angle - rotation) % 360 + 360) % 360; // keep it 0-359
        return chores[Math.floor(onWheel / sliceSize)];
    }

    // --- Drawing -------------------------------------------------------------

    function drawWheel() {
        const center = wheel.width / 2;
        const sliceAngle = 2 * Math.PI / chores.length;

        ctx.clearRect(0, 0, wheel.width, wheel.height);

        chores.forEach(function (chore, i) {
            // A slice: from the center, along the edge, back to the center.
            ctx.beginPath();
            ctx.moveTo(center, center);
            ctx.arc(center, center, center, i * sliceAngle, (i + 1) * sliceAngle);
            ctx.closePath();
            ctx.fillStyle = COLORS[i % COLORS.length];
            ctx.fill();
            ctx.stroke();

            // The text: turn the canvas to the middle of the slice and write
            // it along the radius, ending near the edge.
            ctx.save();
            ctx.translate(center, center);
            ctx.rotate(i * sliceAngle + sliceAngle / 2);
            ctx.textAlign = "right";
            ctx.fillStyle = "black";
            ctx.font = "bold 16px Arial";
            ctx.fillText(chore, center - 30, 5);
            ctx.restore();
        });

        // The names are HTML elements around the wheel. Their positions are in
        // percent, so they follow the wheel when it is shown smaller.
        namesContainer.innerHTML = "";
        people.forEach(function (person, i) {
            const radians = personAngle(i) * Math.PI / 180;
            const label = document.createElement("div");
            label.className = "name-label";
            label.style.left = (50 + Math.cos(radians) * 57) + "%";
            label.style.top = (50 + Math.sin(radians) * 57) + "%";
            label.textContent = person;
            namesContainer.appendChild(label);
        });
    }

    // A list of items, each with a remove button.
    function showList(list, items, remove) {
        list.innerHTML = "";
        items.forEach(function (item, index) {
            const li = document.createElement("li");
            const button = document.createElement("button");
            button.type = "button";
            button.className = "remove";
            button.textContent = "X";
            button.setAttribute("aria-label", "Remove " + item);
            button.addEventListener("click", function () {
                remove(index);
            });
            li.append(button, item);   // append() with text adds it as text, not HTML
            list.appendChild(li);
        });
    }

    function render() {
        showList(choreList, chores, removeChore);
        showList(peopleList, people, removePerson);
        drawWheel();
    }

    // --- Actions -------------------------------------------------------------

    function addItem(event, input, items) {
        event.preventDefault();   // don't let the form reload the page
        const text = input.value.trim();
        if (spinning || text === "") {
            return;
        }
        items.push(text);
        input.value = "";
        resultText.textContent = "";
        render();
    }

    function removeChore(index) {
        if (!spinning) {
            chores.splice(index, 1);
            render();
        }
    }

    function removePerson(index) {
        if (!spinning) {
            people.splice(index, 1);
            render();
        }
    }

    function spinWheel() {
        if (spinning) {
            return;
        }
        if (chores.length === 0 || people.length === 0) {
            resultText.textContent = "Please add at least one chore and one person first!";
            return;
        }

        spinning = true;
        spinButton.disabled = true;
        resultText.textContent = "";

        // Spin from where the wheel is now, many turns plus a random angle.
        // The CSS transition makes the turn smooth and slow down at the end.
        const extra = Math.floor(Math.random() * 360);
        wheel.style.transition = "transform " + SPIN_TIME + "ms ease-out";
        wheel.style.transform = "rotate(" + (rotation + TURNS * 360 + extra) + "deg)";

        setTimeout(function () {
            // Jump back to the same angle without the extra turns, so the
            // numbers don't keep growing. It looks exactly the same.
            rotation = (rotation + extra) % 360;
            wheel.style.transition = "none";
            wheel.style.transform = "rotate(" + rotation + "deg)";

            resultText.textContent = people.map(function (person, i) {
                return person + ": " + choreAt(personAngle(i));
            }).join("\n");

            spinning = false;
            spinButton.disabled = false;
        }, SPIN_TIME);
    }

    // --- Connect the page ----------------------------------------------------

    choreForm.addEventListener("submit", function (event) {
        addItem(event, choreInput, chores);
    });
    personForm.addEventListener("submit", function (event) {
        addItem(event, personInput, people);
    });
    spinButton.addEventListener("click", spinWheel);
  </script>
</body>
</html>
