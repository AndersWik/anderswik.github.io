Dice roller

Choose a die with 4, 6, 8, 10, 12 or 20 sides, the kinds used in board games and role-playing games, and roll it. The die spins, then shows the number.

The interesting part is a bug that is easy to make: the original version of this game could never roll the highest number. We'll see why.

Open the finished game

The pictures

The dice are SVG pictures. Make a folder for the game with the page and a folder called images, and download these into it:

d4.svg, d6.svg, d8.svg, d10.svg, d12.svg, d20.svg

The picture of the die is a background image of the preview box, and there is one CSS rule per die: the class d6 shows d6.svg, and so on. To change the picture, the script only changes the class. It never needs to know where the picture files are.

background-size: contain fits the whole picture in the box. The number is a <span> on top, centered with flexbox.

Step 3: Rolling a die

function roll(sides) {
    return Math.floor(Math.random() * sides) + 1;
}

Step by step for a six-sided die:

  1. Math.random() is from 0 to 0.999...
  2. * 6 makes it 0 to 5.999...
  3. Math.floor rounds down to 0, 1, 2, 3, 4 or 5, each equally likely.
  4. + 1 gives 1 to 6.

The original version wrote Math.floor(Math.random() * (sides - 1) + 1). That gives 1 to 5 on a six-sided die. 6 could never come up. It is an easy mistake, and it is hard to notice by playing, because the missing number just seems unlucky. The way to catch it is to roll many times and look at what comes out:

const seen = new Set();
for (let i = 0; i < 6000; i++) {
    seen.add(roll(6));
}
console.log([...seen].sort());   // [1, 2, 3, 4, 5, 6]

A Set keeps each value only once, so it shows which numbers came up at all.

Step 4: Choosing a die

function chooseDie() {
    const sides = Number(diceSelect.value);
    preview.className = "d" + sides;
    previewText.textContent = sides;
    selectedText.textContent = diceSelect.selectedOptions[0].text + " selected";
    resultText.textContent = "";
}

diceSelect.addEventListener("change", chooseDie);

selectedOptions[0].text is the text of the chosen option, like "D6 (6 sides)". So we don't need a list of names in the script, and the HTML is the only place they are written.

Step 5: Spin, then show

The number is decided right away, but shown when the spin is over, so the answer doesn't appear while the die is still turning:

function rollDie() {
    if (preview.classList.contains("spin")) {
        return; // still rolling
    }
    const result = roll(Number(diceSelect.value));

    resultText.textContent = "";
    preview.classList.add("spin");
    setTimeout(function () {
        preview.classList.remove("spin");
        previewText.textContent = result;
        resultText.textContent = "You rolled " + result;
    }, SPIN_TIME);
}

Here the spin class itself works as the "busy" flag: while it is there, a new roll is ignored.

Step 6: Test it

  • Choose each die and check the picture changes.
  • Roll the D6 until you have seen a 6. Run the Set test above in the console for each kind of die.
  • Click Roll many times quickly. You should get one result per spin.

    /*
     * Dice roller: pick a die with 4, 6, 8, 10, 12 or 20 sides and roll it.

     * The picture of the die is set in the CSS: the preview gets a class like

    // --- Elements on the page ------------------------------------------------

    //   Math.random() * 6 is 0 to 5.999..., Math.floor makes it 0-5, + 1 gives 1-6.
    function roll(sides) {
        return Math.floor(Math.random() * sides) + 1;
    }

    // --- Actions -------------------------------------------------------------

    function chooseDie() {
        const sides = Number(diceSelect.value);
        preview.className = "d" + sides;
        previewText.textContent = sides;
        // The text of the chosen option, e.g. "D6 (6 sides)".
        selectedText.textContent = diceSelect.selectedOptions[0].text + " selected";
        resultText.textContent = "";

    function rollDie() {
        if (preview.classList.contains("spin")) {
            return; // still rolling
        }
        const result = roll(Number(diceSelect.value));

        resultText.textContent = "";
        preview.classList.add("spin");
        setTimeout(function () {
            preview.classList.remove("spin");
            previewText.textContent = result;
            resultText.textContent = "You rolled " + result;
        }, SPIN_TIME);
    }

    // --- Connect the page ----------------------------------------------------

    diceSelect.addEventListener("change", chooseDie);
    rollButton.addEventListener("click", rollDie);

    // --- Start ---------------------------------------------------------------

    chooseDie();
    selectedText.textContent = "Select a die and click Roll!";
  </script>
</body>
</html>
