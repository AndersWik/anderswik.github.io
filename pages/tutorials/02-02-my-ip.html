My IP

This page asks a web service which public IP address you have and shows it. It is the shortest way to learn how a page gets data from another server: fetch, async and await, and JSON.

Open the finished page

What we use

Your computer gets a local address from your router, like 192.168.1.20, but the rest of the internet sees your router's public address. The page can't find that out by itself, so we ask a free service, ipify. When you open this address:

https://api.ipify.org?format=json

it answers with JSON, a text format for data:

{"ip":"81.230.12.34"}

Note that using the page sends a request to ipify, so they see your address. That is the point of the page, but it is worth knowing whenever a page uses someone else's service.

Step 1: The page

Create my-ip.html from the skeleton.

<h1>My IP</h1>
<p id="ip">000.000.000.000</p>
<p>Using the <a href="https://www.ipify.org/">ipify</a> service</p>
body {
    font-family: sans-serif;
    max-width: 800px;
    margin: 40px auto;
    padding: 0 16px;
}

body {
    text-align: center;
}

#ip {
    font-size: 48px;
    overflow-wrap: anywhere;
}

overflow-wrap: anywhere lets a long IPv6 address break onto the next line on a narrow phone screen.

Step 2: fetch, async and await

Getting data from the network takes time, from milliseconds to seconds. JavaScript doesn't stop and wait, because that would freeze the whole page. Instead, fetch() returns a promise, a value that arrives later.

Inside a function marked async, the word await waits for a promise. The rest of the page keeps working in the meantime.

async function showMyIp() {
    ipText.textContent = "Loading...";

    try {
        const response = await fetch("https://api.ipify.org?format=json");

        if (!response.ok) {
            throw new Error("HTTP " + response.status);
        }
        const data = await response.json();
        ipText.textContent = data.ip;
    } catch (error) {
        ipText.textContent = "Could not get your IP";
    }
}

showMyIp();

Step by step:

  1. We show "Loading..." so the user can see something is happening.
  2. await fetch(...) waits for the server to answer.
  3. response.ok is true for status codes 200-299. fetch only throws an error when there is no network at all. If the service answers "503 Service Unavailable", it doesn't throw, so we check the status ourselves and throw to jump to catch.
  4. await response.json() reads the body and turns the JSON text into a JavaScript object. That is also a promise, because the body can arrive in parts.
  5. data.ip is the address.
  6. Anything that goes wrong lands in catch, and we show a message instead of leaving "Loading..." forever.

Step 3: Test it

  • Open the page. You should see your address. Compare it with what ipify.org shows.
  • In the developer tools, the Network tab shows the request to api.ipify.org and its answer.
  • Turn on "Offline" in the Network tab and reload. You should see "Could not get your IP".

The complete page

my-ip.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My IP</title>
  <style>
    body {
        font-family: sans-serif;
        max-width: 800px;
        margin: 40px auto;
        padding: 0 16px;
    }

    body {
        text-align: center;
    }

    #ip {
        font-size: 48px;
        overflow-wrap: anywhere;
    }
  </style>
</head>
<body>
  <h1>My IP</h1>
  <p id="ip">000.000.000.000</p>
  <p>Using the <a href="https://www.ipify.org/">ipify</a> service</p>

  <script>
    /*
     * My IP: ask the ipify service which public IP address we have.
     *
     * fetch() sends a request over the network. It takes a while, so
     * "async" and "await" let us wait for the answer without freezing the page.
     *
     * The answer is JSON text like {"ip":"81.230.12.34"}.
     * response.json() turns it into a JavaScript object.
     */

    // --- Elements on the page ------------------------------------------------

    const ipText = document.getElementById("ip");

    // --- Actions -------------------------------------------------------------

    async function showMyIp() {
        ipText.textContent = "Loading...";

        try {
            const response = await fetch("https://api.ipify.org?format=json");

            // fetch() only throws when there is no network. If the service
            // answers with an error, like 503, we have to check that ourselves.
            if (!response.ok) {
                throw new Error("HTTP " + response.status);
            }
            const data = await response.json();
            ipText.textContent = data.ip;
        } catch (error) {
            // No network, or the service is down.
            ipText.textContent = "Could not get your IP";
        }
    }

    // --- Start ---------------------------------------------------------------

    showMyIp();
  </script>
</body>
</html>

Try this

  • Add a "Copy" button that copies the address with navigator.clipboard.writeText(ipText.textContent).
  • https://api64.ipify.org?format=json gives your IPv6 address if you have one. Show both.
