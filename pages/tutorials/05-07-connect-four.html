Connect Four

Two players take turns dropping a piece into one of the seven columns. The piece falls to the lowest free place in that column. The first to get four in a row, across, down or diagonally, wins.

This is a board game, so the game is a grid: a list of rows, where each row is a list of places. The new parts are making a grid like that, drawing it with CSS grid, and checking for four in a row in every direction with one small function.

  • display: grid with grid-template-columns: repeat(7, 1fr) puts the places in 7 columns of the same width. After the 7th place, the next one starts a new row by itself.
  • aspect-ratio: 1 makes each place as tall as it is wide. Together with 1fr the board shrinks on a small phone and the places stay round.
  • border-radius: 50% turns a square into a circle. An empty place is white, a played place gets the class player1 (red) or player2 (yellow).

Step 2: A grid in JavaScript

const ROWS = 6;
const COLS = 7;
const NAMES = { 1: "Red", 2: "Yellow" };

let grid = [];          // grid[row][col]: 0 = empty, 1 = red, 2 = yellow
let cells = [];         // cells[row][col]: the <div> for each place
let player = 1;         // whose turn it is
let moves = 0;
let gameOver = false;

grid is a list of 6 rows, and each row is a list of 7 numbers. grid[5][3] is row 5 (the bottom row, since row 0 is the top) and column 3 (the middle). A list of lists like this is often called a 2D array.

cells has the same shape, but holds the <div> on the page for each place. With it, we never have to search the page for the place at a row and column: it is just cells[row][col].

Step 3: Building the board

function newGame() {
    grid = [];
    cells = [];
    boardElement.innerHTML = "";

    for (let row = 0; row < ROWS; row++) {
        grid.push([]);
        cells.push([]);
        for (let col = 0; col < COLS; col++) {
            const cell = document.createElement("div");
            cell.className = "cell";
            cell.addEventListener("click", function () {
                play(col);
            });
            boardElement.appendChild(cell);
            grid[row].push(0);
            cells[row].push(cell);
        }
    }

    player = 1;
    moves = 0;
    gameOver = false;
    statusText.textContent = NAMES[player] + "'s turn";
}

One loop inside another: for each row, make a new empty list, then add 7 places to it. The places are added to the page in the same order, row by row, and the CSS grid puts 7 on each line.

Each place calls play(col) when it's clicked. Only the column matters: in Connect Four you choose a column, not a place. let col in the for loop is a new variable each time round, so every place remembers its own column.

newGame resets everything, including moves. In the first version of this game, the move count was never reset. After a few games, it said "It's a draw!" in the middle of a game.

Step 4: Where does the piece land?

function freeRow(col) {
    for (let row = ROWS - 1; row >= 0; row--) {
        if (grid[row][col] === 0) {
            return row;
        }
    }
    return -1;
}

Start at the bottom row and go up. The first empty place is where the piece lands. If there is none, the column is full, and we return -1.

Step 5: Four in a row

A new piece can only win together with the pieces next to it. So we look out from the new piece in a line, one step at a time, for as long as the pieces are the same color:

function lineFrom(row, col, dRow, dCol) {
    const who = grid[row][col];
    const line = [];
    let r = row + dRow;
    let c = col + dCol;
    while (r >= 0 && r < ROWS && c >= 0 && c < COLS && grid[r][c] === who) {
        line.push([r, c]);
        r += dRow;
        c += dCol;
    }
    return line;
}

dRow and dCol are the step: how far to move down and right each time. [0, 1] is one step right, [0, -1] one step left, [1, 1] one step down and right. The loop stops at the edge of the board, or at a place that is empty or the other color.

There are four directions a line can have. Each one goes two ways from the new piece, so we look both ways and add them up:

const DIRECTIONS = [
    [0, 1],   // across
    [1, 0],   // down
    [1, 1],   // diagonal \
    [1, -1]   // diagonal /
];

function findWin(row, col) {
    for (const [dRow, dCol] of DIRECTIONS) {
        const line = [[row, col]]
            .concat(lineFrom(row, col, dRow, dCol))
            .concat(lineFrom(row, col, -dRow, -dCol));
        if (line.length >= 4) {
            return line;
        }
    }
    return null;
}

const [dRow, dCol] of DIRECTIONS takes each pair from the list and puts the two numbers into two variables at once. -dRow, -dCol is the opposite way. The line is the new piece, plus the pieces one way, plus the pieces the other way. If that is 4 or more, we return the places in it, so they can be marked. Otherwise null, which counts as false in an if.

Looking both ways matters. If you drop the piece in the middle of a line, like R R _ R, looking only one way would find 2, not 4.

Step 6: Playing a move

function play(col) {
    if (gameOver) {
        return;
    }
    const row = freeRow(col);
    if (row === -1) {
        return; // the column is full
    }

    grid[row][col] = player;
    cells[row][col].classList.add("player" + player);
    moves++;

    const win = findWin(row, col);
    if (win) {
        win.forEach(function ([r, c]) {
            cells[r][c].classList.add("winning");
        });
        statusText.textContent = NAMES[player] + " wins!";
        gameOver = true;
    } else if (moves === ROWS * COLS) {
        statusText.textContent = "It's a draw!";
        gameOver = true;
    } else {
        player = player === 1 ? 2 : 1;
        statusText.textContent = NAMES[player] + "'s turn";
    }
}

The order is important. We change grid first, then the page. grid is the real game, and the page only shows it. Then we check for a win, then a full board, and only if the game goes on, we switch player. If we switched first, the message would name the wrong winner.

"player" + player makes the class player1 or player2. function ([r, c]) takes each pair of the winning line apart, the same way as in the for loop above.

Step 7: Test it

  • Win across, down, and in both diagonals. The four winning pieces should get a green ring.
  • Win by dropping the piece in the middle of a line, not at the end.
  • Fill a column, then click it again. Nothing should happen, and it should still be the same player's turn.
  • Play a few games in a row. "It's a draw!" should only come when the board is full.

    /*
     * Connect Four: two players take turns dropping a piece into one of the
     * seven columns. It falls to the lowest free row. The first with four in a
     * row (across, down or diagonal) wins.
     */

    // --- Settings ------------------------------------------------------------

    const ROWS = 6;
    const COLS = 7;
    const NAMES = { 1: "Red", 2: "Yellow" };

    const DIRECTIONS = [
        [0, 1],   // across
        [1, 0],   // down
        [1, 1],   // diagonal \
        [1, -1]   // diagonal /
    ];

    // --- Elements on the page ------------------------------------------------

    const boardElement = document.getElementById("board");
    const statusText = document.getElementById("status");
    const restartButton = document.getElementById("restart");

    // --- State ---------------------------------------------------------------

    let grid = [];          // grid[row][col]: 0 = empty, 1 = red, 2 = yellow
    let cells = [];         // cells[row][col]: the <div> for each place
    let player = 1;         // whose turn it is
    let moves = 0;
    let gameOver = false;

    // --- The board -----------------------------------------------------------

    function newGame() {
        grid = [];
        cells = [];
        boardElement.innerHTML = "";

        // Row 0 is the top row.
        for (let row = 0; row < ROWS; row++) {
            grid.push([]);
            cells.push([]);
            for (let col = 0; col < COLS; col++) {
                const cell = document.createElement("div");
                cell.className = "cell";
                cell.addEventListener("click", function () {
                    play(col);
                });
                boardElement.appendChild(cell);
                grid[row].push(0);
                cells[row].push(cell);
            }
        }

        player = 1;
        moves = 0;
        gameOver = false;
        statusText.textContent = NAMES[player] + "'s turn";
    }

    // The lowest empty row in a column, or -1 if the column is full.
    function freeRow(col) {
        for (let row = ROWS - 1; row >= 0; row--) {
            if (grid[row][col] === 0) {
                return row;
            }
        }
        return -1;
    }

    // --- Four in a row -------------------------------------------------------

    // The pieces of the same color in a line from (row, col), one step at a
    // time in the direction (dRow, dCol), not counting the start.
    function lineFrom(row, col, dRow, dCol) {
        const who = grid[row][col];
        const line = [];
        let r = row + dRow;
        let c = col + dCol;
        while (r >= 0 && r < ROWS && c >= 0 && c < COLS && grid[r][c] === who) {
            line.push([r, c]);
            r += dRow;
            c += dCol;
        }
        return line;
    }

    // Does the piece at (row, col) make four in a row? Returns the winning
    // places, or null.
    function findWin(row, col) {
        for (const [dRow, dCol] of DIRECTIONS) {
            // Look both ways from the new piece.
            const line = [[row, col]]
                .concat(lineFrom(row, col, dRow, dCol))
                .concat(lineFrom(row, col, -dRow, -dCol));
            if (line.length >= 4) {
                return line;
            }
        }
        return null;
    }

    // --- Playing -------------------------------------------------------------

    function play(col) {
        if (gameOver) {
            return;
        }
        const row = freeRow(col);
        if (row === -1) {
            return; // the column is full
        }

        grid[row][col] = player;
        cells[row][col].classList.add("player" + player);
        moves++;

        const win = findWin(row, col);
        if (win) {
            win.forEach(function ([r, c]) {
                cells[r][c].classList.add("winning");
            });
            statusText.textContent = NAMES[player] + " wins!";
            gameOver = true;
        } else if (moves === ROWS * COLS) {
            statusText.textContent = "It's a draw!";
            gameOver = true;
        } else {
            player = player === 1 ? 2 : 1;
            statusText.textContent = NAMES[player] + "'s turn";
        }
    }

    // --- Connect the page ----------------------------------------------------

    restartButton.addEventListener("click", newGame);

    newGame();
  </script>
</body>
