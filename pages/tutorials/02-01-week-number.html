Week number

The apps in this chapter are a bit bigger than the utilities, and each one shows a new idea. We start with the smallest: a page that shows today's week number in big digits. It is a good first lesson in how JavaScript handles dates.

Open the finished page

If you haven't built a page from scratch before, read Building a utility page first. It explains the skeleton that every page here starts from.

How week numbers work

Sweden and most of Europe use ISO week numbers:

  • A week starts on Monday.
  • Week 1 is the week with the year's first Thursday in it.

That gives a simple way to find the week of any date:

  1. Find the Thursday in the same Monday-Sunday week.
  2. Count which Thursday of its year that is.

The second rule is why the first days of January can belong to week 52 or 53 of the year before, and the last days of December to week 1 of the next year. The Thursday decides which year the week belongs to.

Step 1: The page

Create week-number.html from the skeleton. The HTML is only a heading, a paragraph for the number and a link:

<h1>Week</h1>
<p id="number">00</p>
<p><a href="https://weeknumber.net/how-to/javascript">How week numbers work</a></p>
body {
    font-family: sans-serif;
    max-width: 800px;
    margin: 40px auto;
    padding: 0 16px;
}

body {
    text-align: center;
}

#number {
    margin: 0;
    font-size: 160px;
}

Step 2: Find the element

const weekNumber = document.getElementById("number");

const DAY_IN_MS = 24 * 60 * 60 * 1000;

JavaScript measures time in milliseconds, so one day is 24 * 60 * 60 * 1000. Constants that never change are often written in capital letters.

Step 3: Find the Thursday

new Date(year, month, day) makes a date at midnight. We use it to copy the date, so we don't change the one we were given:

const thursday = new Date(date.getFullYear(), date.getMonth(), date.getDate());

getDay() gives the day of the week, but it starts on Sunday: Sunday is 0, Monday 1 and Saturday 6. We want Monday as 0 and Sunday as 6. Adding 6 and taking the rest after dividing by 7 (%, modulo) does exactly that:

day      getDay()   + 6   % 7
Monday   1          7     0
Tuesday  2          8     1
Sunday   0          6     6
const dayOfWeek = (thursday.getDay() + 6) % 7;

// Step back to Monday, then forward 3 days to Thursday.
thursday.setDate(thursday.getDate() - dayOfWeek + 3);

setDate() handles going past the start or end of a month by itself. setDate(0) is the last day of the month before, and setDate(32) is a day in the next month.

Step 4: Count the Thursdays

Subtracting two dates gives the time between them in milliseconds. Divided by DAY_IN_MS it is a number of days. We round it, because a day with a summer-time change is 23 or 25 hours long.

const januaryFirst = new Date(thursday.getFullYear(), 0, 1);
const daysIntoYear = Math.round((thursday - januaryFirst) / DAY_IN_MS);

return Math.floor(daysIntoYear / 7) + 1;

The first Thursday of a year is 0-6 days after January 1st, which gives week 1. The next is 7-13 days after, which gives week 2, and so on. We use thursday.getFullYear(), not the year of the date we were given, because the Thursday decides the year.

Step 5: Show it

weekNumber.textContent = getWeekNumber(new Date());

new Date() with nothing inside is right now.

Step 6: Test it

The page always shows today, so test the function in the console with dates where the year and the week year are different. Remember that months start at 0 in JavaScript, so 11 is December.

getWeekNumber(new Date(2026, 0, 1))    // 1   (a Thursday)
getWeekNumber(new Date(2027, 0, 1))    // 53  (2026 has 53 weeks)
getWeekNumber(new Date(2024, 11, 30))  // 1   (Monday of week 1, 2025)
getWeekNumber(new Date(2021, 0, 3))    // 53  (Sunday of week 53, 2020)

The complete page

week-number.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>What week is it?</title>
  <style>
    body {
        font-family: sans-serif;
        max-width: 800px;
        margin: 40px auto;
        padding: 0 16px;
    }

    body {
        text-align: center;
    }

    #number {
        margin: 0;
        font-size: 160px;
    }
  </style>
</head>
<body>
  <h1>Week</h1>
  <p id="number">00</p>
  <p><a href="https://weeknumber.net/how-to/javascript">How week numbers work</a></p>

  <script>
    /*
     * What week is it?
     *
     * Sweden (and most of Europe) uses ISO week numbers:
     *   - weeks start on Monday
     *   - week 1 is the week that has the year's first Thursday in it
     *
     * So the easy way to find the week number of a date is:
     *   1. find the Thursday in the same week (Monday-Sunday)
     *   2. count which Thursday of its year that is
     */

    // --- Elements on the page ------------------------------------------------

    const weekNumber = document.getElementById("number");

    // --- Helpers -------------------------------------------------------------

    const DAY_IN_MS = 24 * 60 * 60 * 1000;

    function getWeekNumber(date) {
        // Copy the date (at midnight) so we don't change the original.
        const thursday = new Date(date.getFullYear(), date.getMonth(), date.getDate());

        // getDay() gives Sunday = 0 ... Saturday = 6.
        // Change it to Monday = 0 ... Sunday = 6.
        const dayOfWeek = (thursday.getDay() + 6) % 7;

        // Step back to Monday, then forward 3 days to Thursday.
        thursday.setDate(thursday.getDate() - dayOfWeek + 3);

        // How many days after January 1st is that Thursday?
        // (Math.round smooths over summer/winter time changes.)
        const januaryFirst = new Date(thursday.getFullYear(), 0, 1);
        const daysIntoYear = Math.round((thursday - januaryFirst) / DAY_IN_MS);

        // Every 7 days is a new week, and we count from 1, not 0.
        return Math.floor(daysIntoYear / 7) + 1;
    }

    // --- Start ---------------------------------------------------------------

    weekNumber.textContent = getWeekNumber(new Date());
  </script>
</body>
</html>
