Unix timestamp converter

We build a Unix timestamp converter. It converts between seconds, milliseconds, a date and time, and ISO 8601, in local time or UTC. It also shows a friendly description like "in 3 hours" and a clock with the current timestamp.

It uses the same two-box idea as the Data size converter, so read that one first.

Open the finished timestamp converter

What a Unix timestamp is

A Unix timestamp is the number of seconds since 1970-01-01 00:00:00 UTC, which is called "the epoch". It is the same number everywhere in the world, so it is a good way to store a moment in time. Time zones only matter when you show it to a person.

0            1970-01-01 00:00:00 UTC
1700000000   2023-11-14 22:13:20 UTC

JavaScript's Date uses milliseconds since the epoch. Date.now() gives the current time in milliseconds.

The idea: go through milliseconds

Just like the data converter goes through bits, this one turns every input into milliseconds, and then turns the milliseconds into the format we want:

seconds        ms = seconds x 1000
milliseconds   ms = milliseconds
date/time      ms = read "2026-11-01 12:00:00" in the chosen time zone
ISO 8601       ms = Date.parse("2026-11-01T11:00:00.000Z")

Step 3: Read a date and time

We read the text with a regular expression. Each pair of brackets ( ) captures a part, \d{4} is four digits, and (?: )? makes a group optional. This one accepts 2026-11-01, 2026-11-01 12:00 and 2026-11-01 12:00:30:

const match = text.match(
    /^(\d{4})-(\d{1,2})-(\d{1,2})(?:[ T](\d{1,2}):(\d{2})(?::(\d{2}))?)?$/
);

match is null if the text doesn't fit. Otherwise match[1] to match[6] are the parts, and undefined for parts that are missing. We turn them into numbers, and missing ones become 0:

const [year, month, day, hour, minute, second] = match
    .slice(1)
    .map((part) => Number(part || 0));

Now we build the date. Months in JavaScript start at 0, so January is 0. That is why we write month - 1. Date.UTC() reads the numbers as UTC, and new Date(...) reads them as local time:

const date = useUtc()
    ? new Date(Date.UTC(year, month - 1, day, hour, minute, second))
    : new Date(year, month - 1, day, hour, minute, second);

Catching impossible dates

Date doesn't complain about impossible dates. It quietly moves them forward: 2026-02-31 becomes March 3, and 24:00 becomes the next day. To catch that, we read the parts back from the date and check that they match what was typed:

const parts = useUtc()
    ? [date.getUTCFullYear(), date.getUTCMonth() + 1, date.getUTCDate(), date.getUTCHours(), date.getUTCMinutes(), date.getUTCSeconds()]
    : [date.getFullYear(), date.getMonth() + 1, date.getDate(), date.getHours(), date.getMinutes(), date.getSeconds()];

if (parts.join() !== [year, month, day, hour, minute, second].join()) {
    return NaN;
}
return date.getTime();

join() turns an array into a string like "2026,2,31,0,0,0", which is an easy way to compare two arrays. The check also catches local times that don't exist because the clocks jump forward an hour for summer time.

Step 4: Any format to milliseconds, and back

A switch picks the code for a format. return leaves the function, so no break is needed:

function toMilliseconds(text, format) {
    switch (format) {
        case "seconds":
            return Number(text) * 1000;
        case "milliseconds":
            return Number(text);
        case "datetime":
            return parseDateTime(text);
        case "iso":
            return Date.parse(text);
    }
}

Going back, fromMilliseconds() builds the date text from getFullYear(), getMonth() + 1 and so on, or the getUTC... versions for UTC. It uses pad() so 7 becomes 07. toISOString() gives ISO 8601, which is always in UTC and ends with Z. The whole function is in the complete script below.

Step 5: "in 3 hours"

Intl.RelativeTimeFormat writes text like "3 hours ago" or "tomorrow" in any language. We only have to pick the biggest unit that fits:

function relativeTime(ms) {
    const units = [
        ["year", 31556926],
        ["month", 2629743],
        ["week", 604800],
        ["day", 86400],
        ["hour", 3600],
        ["minute", 60],
        ["second", 1],
    ];
    const seconds = Math.round((ms - Date.now()) / 1000);
    const formatter = new Intl.RelativeTimeFormat("en", { numeric: "auto" });

    for (const [unit, size] of units) {
        if (Math.abs(seconds) >= size || unit === "second") {
            return formatter.format(Math.round(seconds / size), unit);
        }
    }
}

toLocaleString() with dateStyle: "full" writes the full date. With timeZone: "UTC" it shows UTC, and with undefined it uses the browser's own time zone.

Step 6: Update, and the clock

update() works like in the data converter. It also checks the date, because new Date() can only handle about 275 000 years around 1970:

function update(fromValue, fromFormat, toValue, toFormat) {
    const text = fromValue.value.trim();
    const ms = toMilliseconds(text, fromFormat.value);

    if (text === "" || isNaN(ms) || isNaN(new Date(ms).getTime())) {
        toValue.value = "";
        details.textContent = text === "" ? "–" : "Can't read that value";
        return;
    }

    toValue.value = fromMilliseconds(ms, toFormat.value);
    details.textContent = describe(ms);
}

The clock uses setInterval, which runs a function again and again with a pause between, here 1000 milliseconds:

function tick() {
    nowSeconds.textContent = Math.floor(Date.now() / 1000);
}

tick();
setInterval(tick, 1000);

We call tick() once ourselves too, so the clock shows right away instead of after the first second.

Step 7: Test it

Choose UTC, so the answers are the same for everyone:

  • Seconds 0 to ISO 8601: 1970-01-01T00:00:00.000Z.
  • Date/time 2024-02-29 to seconds: 1709164800 (2024 is a leap year).
  • 2026-02-31 and 2026-01-01 24:00: "Can't read that value".
  • Seconds 2147483647 to date/time: 2038-01-19 03:14:07, the last second a signed 32-bit number can hold.
  • Press Use now, then switch between Local and UTC.

  <script>
    /*
     * Unix timestamp converter: seconds, milliseconds, date/time and ISO 8601.
     *
     * The trick: turn every value into milliseconds since 1970-01-01 00:00:00 UTC
     * first (that is what JavaScript's Date uses), then from milliseconds into
     * the format we want. That way we need one rule per format instead of one
     * rule for every pair of formats.
     *
     *   Unix timestamp (seconds)      = milliseconds / 1000
     *   Unix timestamp (milliseconds) = milliseconds
     *   Date/Time                     = "2026-11-01 12:00:00" in the chosen time zone
     *   ISO 8601                      = "2026-11-01T11:00:00.000Z", always UTC
     *
     * You can type in either field; the other one is updated.
     */

    // --- Elements on the page ------------------------------------------------

    const leftFormat = document.getElementById("input-select");
    const leftValue = document.getElementById("input-field");
    const rightFormat = document.getElementById("output-select");
    const rightValue = document.getElementById("output-field");
    const zoneSelect = document.getElementById("zone-select");
    const localOption = document.getElementById("local-option");
    const details = document.getElementById("details");
    const nowSeconds = document.getElementById("now-seconds");
    const nowButton = document.getElementById("now-button");

    // --- Helpers -------------------------------------------------------------

    function useUtc() {
        return zoneSelect.value === "utc";
    }

    // 7 -> "07"
    function pad(number) {
        return String(number).padStart(2, "0");
    }

    // Read "YYYY-MM-DD", "YYYY-MM-DD HH:MM" or "YYYY-MM-DD HH:MM:SS"
    // in the chosen time zone. Returns milliseconds, or NaN if it can't be read.
    function parseDateTime(text) {
        const match = text.match(
            /^(\d{4})-(\d{1,2})-(\d{1,2})(?:[ T](\d{1,2}):(\d{2})(?::(\d{2}))?)?$/
        );

        if (!match) {
            // Let the browser have a go at other formats, e.g. "Nov 1 2026 12:00"
            return Date.parse(text);
        }

        // Missing time parts become 0; months in JavaScript start at 0
        const [year, month, day, hour, minute, second] = match
            .slice(1)
            .map((part) => Number(part || 0));

        const date = useUtc()
            ? new Date(Date.UTC(year, month - 1, day, hour, minute, second))
            : new Date(year, month - 1, day, hour, minute, second);

        // Date quietly moves impossible values forward: 2026-02-31 becomes
        // 2026-03-03 and 24:00 becomes the next day. Check that we got back
        // what was typed, or say we can't read it.
        const parts = useUtc()
            ? [date.getUTCFullYear(), date.getUTCMonth() + 1, date.getUTCDate(), date.getUTCHours(), date.getUTCMinutes(), date.getUTCSeconds()]
            : [date.getFullYear(), date.getMonth() + 1, date.getDate(), date.getHours(), date.getMinutes(), date.getSeconds()];

        if (parts.join() !== [year, month, day, hour, minute, second].join()) {
            return NaN;
        }
        return date.getTime();
    }

    function toMilliseconds(text, format) {
        switch (format) {
            case "seconds":
                return Number(text) * 1000;
            case "milliseconds":
                return Number(text);
            case "datetime":
                return parseDateTime(text);
            case "iso":
                return Date.parse(text);
        }
    }

    function fromMilliseconds(ms, format) {
        const date = new Date(ms);

        switch (format) {
            case "seconds":
                return String(Math.floor(ms / 1000));
            case "milliseconds":
                return String(ms);
            case "datetime":
                if (useUtc()) {
                    return `${date.getUTCFullYear()}-${pad(date.getUTCMonth() + 1)}-${pad(date.getUTCDate())} ` +
                        `${pad(date.getUTCHours())}:${pad(date.getUTCMinutes())}:${pad(date.getUTCSeconds())}`;
                }
                return `${date.getFullYear()}-${pad(date.getMonth() + 1)}-${pad(date.getDate())} ` +
                    `${pad(date.getHours())}:${pad(date.getMinutes())}:${pad(date.getSeconds())}`;
            case "iso":
                return date.toISOString();
        }
    }

    // "3 hours ago", "in 2 days"...
    function relativeTime(ms) {
        const units = [
            ["year", 31556926],
            ["month", 2629743],
            ["week", 604800],
            ["day", 86400],
            ["hour", 3600],
            ["minute", 60],
            ["second", 1],
        ];
        const seconds = Math.round((ms - Date.now()) / 1000);
        const formatter = new Intl.RelativeTimeFormat("en", { numeric: "auto" });

        for (const [unit, size] of units) {
            if (Math.abs(seconds) >= size || unit === "second") {
                return formatter.format(Math.round(seconds / size), unit);
            }
        }
    }

    // A friendly description under the time zone, e.g.
    // "Sunday, 1 November 2026 at 12:00:00 CET (in 3 hours)"
    function describe(ms) {
        const text = new Date(ms).toLocaleString("en-GB", {
            dateStyle: "full",
            timeStyle: "long",
            timeZone: useUtc() ? "UTC" : undefined,
        });
        return `${text} (${relativeTime(ms)})`;
    }

    // Read the value in one field, convert it, and write it into the other.
    function update(fromValue, fromFormat, toValue, toFormat) {
        const text = fromValue.value.trim();
        const ms = toMilliseconds(text, fromFormat.value);

        // new Date() only handles about ±275 000 years around 1970
        if (text === "" || isNaN(ms) || isNaN(new Date(ms).getTime())) {
            toValue.value = "";
            details.textContent = text === "" ? "–" : "Can't read that value";
            return;
        }

        toValue.value = fromMilliseconds(ms, toFormat.value);
        details.textContent = describe(ms);
    }

    function updateRight() {
        update(leftValue, leftFormat, rightValue, rightFormat);
    }

    function updateLeft() {
        update(rightValue, rightFormat, leftValue, leftFormat);
    }

    // Show the current timestamp, updated every second.
    function tick() {
        nowSeconds.textContent = Math.floor(Date.now() / 1000);
    }

    // --- Connect the page ----------------------------------------------------

    // Show which time zone "Local" is, e.g. "Local (Europe/Stockholm)"
    localOption.textContent = `Local (${Intl.DateTimeFormat().resolvedOptions().timeZone})`;

    // "input" fires on every change: typing, pasting, deleting...
    leftValue.addEventListener("input", updateRight);
    rightValue.addEventListener("input", updateLeft);

    // Changing a format or the time zone keeps the left value and recalculates the right.
    leftFormat.addEventListener("change", updateRight);
    rightFormat.addEventListener("change", updateRight);
    zoneSelect.addEventListener("change", updateRight);

    // Fill the left field with the current time in its format.
    nowButton.addEventListener("click", () => {
        leftValue.value = fromMilliseconds(Date.now(), leftFormat.value);
        updateRight();
    });

    tick();
    setInterval(tick, 1000);
  </script>
</body>
</html>
