Checkers

Checkers, also called draughts: red against black on the dark squares of an 8 by 8 board. Pieces move one step diagonally forward and jump over the other side's pieces to take them. If you can jump, you must, and if you can jump again from where you land, you must carry on. A piece that reaches the far side becomes a king, which moves both ways. Play a friend, or the computer.

It builds on Reversi and Reversi vs computer: the same kind of board, and the same minimax for the computer. The new ideas are finding jumps with several steps with recursion, and alpha-beta pruning, which lets the computer think twice as far in the same time.

Step 2: The board is one list

Instead of 8 rows of 8, the board is one list of 64 squares, row by row. Square i is in row Math.floor(i / 8) and column i % 8. A square is null, or a letter: "r" a red man, "R" a red king, "b" and "B" the same for black. One list is easy to copy with slice(), and the computer will copy it many thousands of times.

function startBoard() {
    const squares = [];
    for (let i = 0; i < SIZE * SIZE; i++) {
        const dark = (row(i) + col(i)) % 2 === 1;
        if (dark && row(i) < 3) {
            squares.push("b");
        } else if (dark && row(i) > 4) {
            squares.push("r");
        } else {
            squares.push(null);
        }
    }
    return squares;
}

A square is dark when its row and column add up to an odd number. Black gets the dark squares in the top three rows, red in the bottom three.

Step 3: Which way a piece may go

function directions(piece) {
    const up = [[-1, -1], [-1, 1]];
    const down = [[1, -1], [1, 1]];
    if (isKing(piece)) {
        return up.concat(down);
    }
    return colorOf(piece) === "red" ? up : down;
}

function stepFrom(i, [dr, dc], n) {
    const r = row(i) + dr * n;
    const c = col(i) + dc * n;
    if (r < 0 || r >= SIZE || c < 0 || c >= SIZE) {
        return -1;
    }
    return r * SIZE + c;
}

Red goes up the board, so its row gets smaller; black goes down. A king may do both. stepFrom gives the square one or two steps away, or -1 if that is off the board, which saves checking the edges everywhere else.

Step 4: Jumps with several steps

This is the hardest part of checkers. After a jump, the same piece may be able to jump again, and again, and sometimes two different ways. Every whole chain of jumps is one move.

A function that calls itself, recursion, fits this well: "find the jumps from here" is the same question after every jump, just from a new square.

function findJumps(squares, piece, path, captured, found) {
    const at = path[path.length - 1];
    let jumped = false;
    directions(piece).forEach(function (direction) {
        const over = stepFrom(at, direction, 1);
        const to = stepFrom(at, direction, 2);
        if (to === -1) {
            return;
        }
        const enemy = colorOf(squares[over]) === other(colorOf(piece));
        // The square it started from is empty now: the piece has left it.
        const free = squares[to] === null || to === path[0];
        if (!enemy || !free || captured.includes(over)) {
            return;
        }
        jumped = true;
        const nextPath = path.concat([to]);
        const nextCaptured = captured.concat([over]);
        if (crowns(piece, to)) {
            found.push({ path: nextPath, captured: nextCaptured });
        } else {
            findJumps(squares, piece, nextPath, nextCaptured, found);
        }
    });
    if (!jumped && captured.length > 0) {
        found.push({ path: path, captured: captured });
    }
}
  • path is the squares the piece has been to so far, and captured the pieces it has jumped.
  • For every direction: is there an enemy next to it, and an empty square behind? Then jump, and ask again from the new square, with the longer path.
  • When no more jumps are possible from a square, the chain is done, and it is a move.
  • A piece may not jump the same piece twice: captured.includes(over). A king could otherwise jump round in a circle for ever.
  • The square the piece started from counts as empty, since the piece has left it. A king can jump round in a square and land where it began.
  • A man that becomes a king in the middle of a chain stops there. That is the rule, and the new king must wait for its next turn.

Step 5: All the legal moves

function legalMoves(squares, who) {
    const jumps = [];
    const steps = [];
    for (let i = 0; i < squares.length; i++) {
        const piece = squares[i];
        if (colorOf(piece) !== who) {
            continue;
        }
        findJumps(squares, piece, [i], [], jumps);
        directions(piece).forEach(function (direction) {
            const to = stepFrom(i, direction, 1);
            if (to !== -1 && squares[to] === null) {
                steps.push({ path: [i, to], captured: [] });
            }
        });
    }
    return jumps.length > 0 ? jumps : steps;
}

Jumping is a must: if any piece can jump, only the jumps are legal. Everything else, the human's clicks, the computer and the end of the game, asks this one function, so the rules are in one place.

A move changes the board, but as a new list; the old one is left as it was. Then the computer can try a move and look at the result, without having to undo it afterwards:

function applyMove(squares, move) {
    const next = squares.slice();
    const from = move.path[0];
    const to = move.path[move.path.length - 1];
    let piece = next[from];
    next[from] = null;
    move.captured.forEach(function (i) {
        next[i] = null;
    });
    if (crowns(piece, to)) {
        piece = piece.toUpperCase();
    }
    next[to] = piece;
    return next;
}

Step 6: Clicking a jump, one square at a time

You click a piece, and dots show where it may go. In a chain of jumps, you click each square in turn. We keep the squares clicked so far in steps, and keep only the moves that start the same way:

function movesInProgress() {
    if (selected === null) {
        return [];
    }
    return legalMoves(board, player).filter(function (move) {
        return move.path[0] === selected && steps.every(function (square, n) {
            return move.path[n + 1] === square;
        });
    });
}

function clickSquare(i) {
    if (gameOver || isComputersTurn()) {
        return;
    }
    // A click on one of your own pieces picks it, if it can move.
    if (colorOf(board[i]) === player && steps.length === 0) {
        const canMove = legalMoves(board, player).some(function (move) { return move.path[0] === i; });
        selected = canMove ? i : null;
        messageText.textContent = canMove ? "" : mustJumpText(i);
        show();
        return;
    }
    // A click on a square the picked piece may go to.
    const fits = movesInProgress().filter(function (move) { return move.path[steps.length + 1] === i; });
    if (fits.length === 0) {
        return;
    }
    steps.push(i);
    const done = fits.find(function (move) { return move.path.length === steps.length + 1; });
    if (done) {
        play(done);
    } else {
        show();   // a jump with more steps: click the next square
    }
}

When a click finishes a move, it is played. Otherwise show() draws the board as it is after the steps so far, with the jumped pieces gone, and dots on the squares where the chain can go on.

Step 7: The computer, with alpha-beta

As in Reversi vs computer, the hard computer uses minimax: try every move, then every answer, and so on, a few moves deep. Then pick the move where the worst that can happen is the best. The number of boards grows very fast: about 8 moves each way, 6 moves deep, is 86, over 250 000 boards.

Alpha-beta pruning skips most of them, without changing the answer:

function alphaBeta(squares, who, depth, alpha, beta) {
    const moves = legalMoves(squares, who);
    if (moves.length === 0) {
        // No moves: "who" has lost. Sooner is better (or worse).
        return who === COMPUTER ? -10000 - depth : 10000 + depth;
    }
    if (depth === 0) {
        return scoreBoard(squares);
    }
    if (who === COMPUTER) {
        let best = -Infinity;
        for (const move of moves) {
            best = Math.max(best, alphaBeta(applyMove(squares, move), HUMAN, depth - 1, alpha, beta));
            alpha = Math.max(alpha, best);
            if (alpha >= beta) {
                break;   // the human would never let it get here
            }
        }
        return best;
    }
    let best = Infinity;
    for (const move of moves) {
        best = Math.min(best, alphaBeta(applyMove(squares, move), COMPUTER, depth - 1, alpha, beta));
        beta = Math.min(beta, best);
        if (alpha >= beta) {
            break;   // the computer would never let it get here
        }
    }
    return best;
}

Say the computer has already found a move where it is sure to keep all its pieces (that is alpha). Now it looks at another move, and the first answer it finds for the human wins a piece. Then the human can do at least that well after this move, so it is worse than the move it already has, and there is no need to look at the human's other answers. That is the break. With good moves found early, it often only has to look at a few thousand boards instead of a quarter of a million. On this site, the computer's first move takes about 30 ms.

At the bottom of the search, the board is given a score:

function scoreBoard(squares) {
    let score = 0;
    squares.forEach(function (piece, i) {
        if (piece === null) {
            return;
        }
        let value = isKing(piece) ? 160 : 100;
        if (piece === "b") {
            value += row(i) * 3 + (row(i) === 0 ? 8 : 0);
        } else if (piece === "r") {
            value += (SIZE - 1 - row(i)) * 3 + (row(i) === SIZE - 1 ? 8 : 0);
        }
        score += colorOf(piece) === COMPUTER ? value : -value;
    });
    return score;
}

Pieces count most. Men that have come far are worth a little more, since they are closer to becoming kings, and so are men left on the back row, which stop the other side from getting kings.

The easy computer doesn't look ahead: it takes as many pieces as it can, else any move. In a test, the hard computer won 6 games out of 6 against the easy one.

Step 8: Test it

  • At the start, red has 7 moves.
  • Make a jump possible. Click a piece that can't jump: it should say you must jump.
  • Set up a double jump, and click both squares. The jumped pieces should go as you click.
  • Get a man to the far side in the middle of a jump. It should become a king and stop.
  • Take all the other side's pieces, or block them so they can't move. You should win.

A good way to set up these tests is in the browser's console: board = startBoard(), change squares with board[i] = "b", and call show().

  <script>
    /*
     * Checkers (English draughts): red against black on the dark squares of
     * an 8 x 8 board. Red is at the bottom and moves first.
     *
     *   - A man moves one step diagonally forward.
     *   - Jump over an opponent's piece to the empty square behind it to take
     *     it. Taking is a must, and a piece that can jump again carries on.
     *   - A man that reaches the far row becomes a king, which moves and
     *     jumps both ways. Becoming a king ends the turn.
     *   - A player who can't move, or has no pieces, loses.
     *
     * The board is a list of 64 squares, row by row. A square is null, or a
     * letter: "r" a red man, "R" a red king, "b" a black man, "B" a black king.
     * A move is { path, captured }: the squares the piece goes through, the
     * first one where it starts, and the squares of the pieces it takes.
     */

    // --- Settings ------------------------------------------------------------

    const SIZE = 8;
    const HUMAN = "red";
    const COMPUTER = "black";
    const NAMES = { red: "Red", black: "Black" };
    const DEPTH = 6;               // moves the hard computer looks ahead
    const COMPUTER_DELAY = 500;    // ms before the computer moves
    const DRAW_MOVES = 80;         // 40 moves each without a capture or a new king

    // --- Elements on the page ------------------------------------------------

    const boardElement = document.getElementById("board");
    const statusText = document.getElementById("status");
    const messageText = document.getElementById("message");
    const restartButton = document.getElementById("restart");
    const modeSelect = document.getElementById("mode");

    // --- State ---------------------------------------------------------------

    let board = [];
    let player = "red";
    let gameOver = false;
    let quietMoves = 0;      // moves since the last capture or new king
    let selected = null;     // the square of the piece the human picked
    let steps = [];          // squares clicked so far in a jump with several steps
    let lastMove = null;     // to show where the last move went
    let squares = [];        // the 64 elements on the page
    let computerTimer = null;

    // --- The board -------------------------------------------------------------

    function row(i) {
        return Math.floor(i / SIZE);
    }

    function col(i) {
        return i % SIZE;
    }

    function colorOf(piece) {
        if (piece === null) {
            return null;
        }
        return piece.toLowerCase() === "r" ? "red" : "black";
    }

    function isKing(piece) {
        return piece === "R" || piece === "B";
    }

    function other(who) {
        return who === "red" ? "black" : "red";
    }

    function startBoard() {
        const squares = [];
        for (let i = 0; i < SIZE * SIZE; i++) {
            const dark = (row(i) + col(i)) % 2 === 1;
            if (dark && row(i) < 3) {
                squares.push("b");
            } else if (dark && row(i) > 4) {
                squares.push("r");
            } else {
                squares.push(null);
            }
        }
        return squares;
    }

    // The ways a piece may go: [rows, columns]. Red goes up the board (row -1),
    // black goes down (row +1), and kings go both ways.
    function directions(piece) {
        const up = [[-1, -1], [-1, 1]];
        const down = [[1, -1], [1, 1]];
        if (isKing(piece)) {
            return up.concat(down);
        }
        return colorOf(piece) === "red" ? up : down;
    }

    // The square n steps away in a direction, or -1 if that is off the board.
    function stepFrom(i, [dr, dc], n) {
        const r = row(i) + dr * n;
        const c = col(i) + dc * n;
        if (r < 0 || r >= SIZE || c < 0 || c >= SIZE) {
            return -1;
        }
        return r * SIZE + c;
    }

    // Does this man become a king on this square?
    function crowns(piece, i) {
        return !isKing(piece) && ((piece === "r" && row(i) === 0) || (piece === "b" && row(i) === SIZE - 1));
    }

    // --- Moves -----------------------------------------------------------------

    // Every move "who" may make. If any piece can jump, only jumps are allowed.
    function legalMoves(squares, who) {
        const jumps = [];
        const steps = [];
        for (let i = 0; i < squares.length; i++) {
            const piece = squares[i];
            if (colorOf(piece) !== who) {
                continue;
            }
            findJumps(squares, piece, [i], [], jumps);
            directions(piece).forEach(function (direction) {
                const to = stepFrom(i, direction, 1);
                if (to !== -1 && squares[to] === null) {
                    steps.push({ path: [i, to], captured: [] });
                }
            });
        }
        return jumps.length > 0 ? jumps : steps;
    }

    // All the jumps a piece can make from the last square of "path", one after
    // the other. A jump with several steps is one move. It ends when no other
    // jump is possible, or when a man becomes a king.
    function findJumps(squares, piece, path, captured, found) {
        const at = path[path.length - 1];
        let jumped = false;
        directions(piece).forEach(function (direction) {
            const over = stepFrom(at, direction, 1);
            const to = stepFrom(at, direction, 2);
            if (to === -1) {
                return;
            }
            const enemy = colorOf(squares[over]) === other(colorOf(piece));
            // The square it started from is empty now: the piece has left it.
            const free = squares[to] === null || to === path[0];
            if (!enemy || !free || captured.includes(over)) {
                return;
            }
            jumped = true;
            const nextPath = path.concat([to]);
            const nextCaptured = captured.concat([over]);
            if (crowns(piece, to)) {
                found.push({ path: nextPath, captured: nextCaptured });
            } else {
                findJumps(squares, piece, nextPath, nextCaptured, found);
            }
        });
        if (!jumped && captured.length > 0) {
            found.push({ path: path, captured: captured });
        }
    }

    // The board after a move, as a new list. The old one is left as it was,
    // so the computer can try moves without undoing them.
    function applyMove(squares, move) {
        const next = squares.slice();
        const from = move.path[0];
        const to = move.path[move.path.length - 1];
        let piece = next[from];
        next[from] = null;
        move.captured.forEach(function (i) {
            next[i] = null;
        });
        if (crowns(piece, to)) {
            piece = piece.toUpperCase();
        }
        next[to] = piece;
        return next;
    }

    function count(squares, who) {
        return squares.filter(function (piece) { return colorOf(piece) === who; }).length;
    }

    // --- Playing a move --------------------------------------------------------

    function play(move) {
        const piece = board[move.path[0]];
        const to = move.path[move.path.length - 1];
        if (move.captured.length > 0 || crowns(piece, to)) {
            quietMoves = 0;
        } else {
            quietMoves++;
        }
        board = applyMove(board, move);
        lastMove = move;
        selected = null;
        steps = [];
        player = other(player);

        if (legalMoves(board, player).length === 0) {
            gameOver = true;
            messageText.textContent = NAMES[other(player)] + " wins! " +
                (count(board, player) === 0 ? NAMES[player] + " has no pieces left." : NAMES[player] + " can't move.");
        } else if (quietMoves >= DRAW_MOVES) {
            gameOver = true;
            messageText.textContent = "It's a draw: 40 moves each without a jump or a new king.";
        }
        show();
        if (!gameOver && isComputersTurn()) {
            computerTimer = setTimeout(computerMove, COMPUTER_DELAY);
        }
    }

    // --- The human: click a piece, then where it goes ---------------------------

    // The moves the human can still make with the selected piece, given the
    // squares clicked so far.
    function movesInProgress() {
        if (selected === null) {
            return [];
        }
        return legalMoves(board, player).filter(function (move) {
            return move.path[0] === selected && steps.every(function (square, n) {
                return move.path[n + 1] === square;
            });
        });
    }

    function clickSquare(i) {
        if (gameOver || isComputersTurn()) {
            return;
        }
        // A click on one of your own pieces picks it, if it can move.
        if (colorOf(board[i]) === player && steps.length === 0) {
            const canMove = legalMoves(board, player).some(function (move) { return move.path[0] === i; });
            selected = canMove ? i : null;
            messageText.textContent = canMove ? "" : mustJumpText(i);
            show();
            return;
        }
        // A click on a square the picked piece may go to.
        const fits = movesInProgress().filter(function (move) { return move.path[steps.length + 1] === i; });
        if (fits.length === 0) {
            return;
        }
        steps.push(i);
        const done = fits.find(function (move) { return move.path.length === steps.length + 1; });
        if (done) {
            play(done);
        } else {
            show();   // a jump with more steps: click the next square
        }
    }

    // Why a piece can't be picked: usually because another piece must jump.
    function mustJumpText(i) {
        const moves = legalMoves(board, player);
        if (moves.length > 0 && moves[0].captured.length > 0) {
            return "You must jump: one of your pieces can take.";
        }
        return "That piece can't move.";
    }

    // --- The computer ------------------------------------------------------------

    function isComputersTurn() {
        return modeSelect.value !== "pvp" && player === COMPUTER;
    }

    function computerMove() {
        const moves = legalMoves(board, COMPUTER);
        let best = [];
        let bestScore = -Infinity;
        moves.forEach(function (move) {
            let score;
            if (modeSelect.value === "easy") {
                // Easy: take as many pieces as it can, else any move.
                score = move.captured.length + Math.random() * 0.5;
            } else {
                score = alphaBeta(applyMove(board, move), HUMAN, DEPTH - 1, -Infinity, Infinity);
            }
            if (score > bestScore) {
                bestScore = score;
                best = [move];
            } else if (score === bestScore) {
                best.push(move);
            }
        });
        // Of the moves that are just as good, pick one at random, so the
        // computer doesn't play the same game every time.
        play(best[Math.floor(Math.random() * best.length)]);
    }

    // Minimax with alpha-beta pruning: how good is this board for the computer,
    // if both sides play their best for "depth" more moves? alpha and beta are
    // the best scores the computer and the human are already sure of; a move
    // that can't beat them doesn't need to be looked at any further.
    function alphaBeta(squares, who, depth, alpha, beta) {
        const moves = legalMoves(squares, who);
        if (moves.length === 0) {
            // No moves: "who" has lost. Sooner is better (or worse).
            return who === COMPUTER ? -10000 - depth : 10000 + depth;
        }
        if (depth === 0) {
            return scoreBoard(squares);
        }
        if (who === COMPUTER) {
            let best = -Infinity;
            for (const move of moves) {
                best = Math.max(best, alphaBeta(applyMove(squares, move), HUMAN, depth - 1, alpha, beta));
                alpha = Math.max(alpha, best);
                if (alpha >= beta) {
                    break;   // the human would never let it get here
                }
            }
            return best;
        }
        let best = Infinity;
        for (const move of moves) {
            best = Math.min(best, alphaBeta(applyMove(squares, move), COMPUTER, depth - 1, alpha, beta));
            beta = Math.min(beta, best);
            if (alpha >= beta) {
                break;   // the computer would never let it get here
            }
        }
        return best;
    }

    // A guess at how good a board is for the computer: a man is worth 100 and
    // a king 160, plus a little for men that have come far, and for keeping
    // the back row, which stops the other side from getting kings.
    function scoreBoard(squares) {
        let score = 0;
        squares.forEach(function (piece, i) {
            if (piece === null) {
                return;
            }
            let value = isKing(piece) ? 160 : 100;
            if (piece === "b") {
                value += row(i) * 3 + (row(i) === 0 ? 8 : 0);
            } else if (piece === "r") {
                value += (SIZE - 1 - row(i)) * 3 + (row(i) === SIZE - 1 ? 8 : 0);
            }
            score += colorOf(piece) === COMPUTER ? value : -value;
        });
        return score;
    }

    // --- Showing the board -------------------------------------------------------

    function show() {
        // While a jump with several steps is under way, show the board as it is
        // after the steps so far.
        let shown = board;
        let at = selected;
        const inProgress = movesInProgress();
        if (steps.length > 0) {
            const partial = { path: [selected].concat(steps), captured: inProgress[0].captured.slice(0, steps.length) };
            shown = applyMove(board, partial);
            at = steps[steps.length - 1];
        }
        const targets = inProgress.map(function (move) { return move.path[steps.length + 1]; });
        // Pieces that may move: when a jump is a must, only those that can jump.
        const movable = gameOver || isComputersTurn() || selected !== null ? [] :
            legalMoves(board, player).map(function (move) { return move.path[0]; });

        squares.forEach(function (element, i) {
            element.className = "square " + ((row(i) + col(i)) % 2 === 1 ? "dark" : "light");
            element.innerHTML = "";
            const piece = shown[i];
            if (piece !== null) {
                const disc = document.createElement("div");
                disc.className = "piece " + colorOf(piece) + (isKing(piece) ? " king" : "");
                if (i === at) {
                    disc.classList.add("selected");
                } else if (movable.includes(i)) {
                    disc.classList.add("movable");
                }
                element.appendChild(disc);
            }
            if (targets.includes(i)) {
                element.classList.add("target");
            }
            if (lastMove !== null && steps.length === 0 && lastMove.path.includes(i)) {
                element.classList.add("last");
            }
        });

        let text = "Red " + count(board, "red") + " - Black " + count(board, "black") + ". ";
        if (gameOver) {
            text += "Game over.";
        } else if (isComputersTurn()) {
            text += NAMES[player] + " is thinking...";
        } else {
            text += NAMES[player] + "'s turn.";
        }
        statusText.textContent = text;
    }

    // --- Starting --------------------------------------------------------------

    function newGame() {
        // A computer move that is waiting to happen belongs to the old game.
        clearTimeout(computerTimer);
        board = startBoard();
        player = "red";
        gameOver = false;
        quietMoves = 0;
        selected = null;
        steps = [];
        lastMove = null;
        messageText.textContent = "";
        show();
    }

    function buildBoard() {
        for (let i = 0; i < SIZE * SIZE; i++) {
            const element = document.createElement("div");
            element.className = "square";
            element.addEventListener("click", function () {
                clickSquare(i);
            });
            boardElement.appendChild(element);
            squares.push(element);
        }
    }

    // --- Connect the page ----------------------------------------------------

    restartButton.addEventListener("click", newGame);
    modeSelect.addEventListener("change", newGame);

    buildBoard();
    newGame();
  </script>
</body>
</html>
