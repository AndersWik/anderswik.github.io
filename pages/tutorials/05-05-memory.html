Memory

All the cards lie face down, and every picture is on two of them. Turn up two cards. If they match, they stay up. If not, they turn back after a moment, and you try to remember where they were. Find all the pairs in as few moves as you can. You can choose how many cards to play with.

The game uses the shuffle from Quiz. The new parts are keeping a card's data and its button together in one object, and making sure the player can only have two cards up at a time.

Step 1: The page

Create memory.html from the skeleton:

<h1>Memory</h1>
<div id="board"></div>
<p id="status" aria-live="polite"></p>
<label for="size">Size:</label>
<select id="size">
  <option value="4">XS (8 cards)</option>
  <option value="6">S (12 cards)</option>
  <option value="8" selected>M (16 cards)</option>
  <option value="10">L (20 cards)</option>
  <option value="12">XL (24 cards)</option>
</select>
<button type="button" id="restart">New game</button>

The value of each size is the number of pairs. The code can use it right away, instead of looking up what "M" means. The first version also had an XL size in the code, but not in the list, so nobody could choose it.

Every card is a button with its picture inside. A card lying face down has the class down. Then the back of the card is shown as the button's background, and the picture is hidden with visibility: hidden. Turning a card is just adding or removing down.

background: black url(...) center / cover no-repeat is a short way to write five background settings at once: the color, the picture, its position, its size (cover fills the whole button) and that it should not repeat.

Step 2: The deck

const IMAGE_FOLDER = "images/";

const PICTURES = [
    "blue-star", "green-star", "purple-star", "yellow-star",
    "blue-triangel", "green-triangel", "purple-triangel", "yellow-triangel",
    "blue-square", "green-square", "purple-square", "yellow-square"
];

const pairs = Number(sizeSelect.value);
const names = PICTURES.slice(0, pairs);
const deck = shuffle(names.concat(names));

Take as many pictures as there are pairs. names.concat(names) puts the list after itself, so every picture is there twice. Then shuffle it with the same shuffle as in Quiz.

sizeSelect.value is always text, like "8", even if it looks like a number. Number() makes it a real number.

Step 3: A card is an object

cards = deck.map(function (name) {
    const element = document.createElement("button");
    element.type = "button";
    element.className = "card down";
    const image = document.createElement("img");
    image.src = IMAGE_FOLDER + name + ".svg";
    image.alt = name.replace("-", " ");
    element.appendChild(image);
    board.appendChild(element);

    const card = { name: name, element: element, up: false };
    element.addEventListener("click", function () {
        turnUp(card);
    });
    return card;
});

For each name in the deck, we make a button with the picture in it, and an object for the card: its name, its button element, and if it is up. map collects the objects into the list cards.

The click handler gets the card object itself, not just the button. The first version kept the data in data- attributes on the buttons, and had to read them back as text all the time. With an object, card.name and card.up are just there.

alt is the text a screen reader reads. "blue-star".replace("-", " ") gives "blue star". A face down card has its picture hidden with visibility, which hides it from screen readers too, so the alt text doesn't give the game away.

Step 4: Turning cards

function turnUp(card) {
    if (open.length === 2 || card.up) {
        return;
    }
    card.up = true;
    card.element.classList.remove("down");
    open.push(card);

    if (open.length === 2) {
        moves++;
        if (open[0].name === open[1].name) {
            pairsFound++;
            open = [];
        } else {
            turnBackTimer = setTimeout(turnBack, TURN_BACK_TIME);
        }
    }
    showStatus();
}

open is the list of cards turned up in this move. The first line is the important one:

  • card.up: a card that is already up can't be turned again. In the first version you could click the same card twice. It then matched itself and counted as a pair.
  • open.length === 2: while two cards that don't match are showing, more clicks are ignored. In the first version, a third click started another timer, and when that timer ran there were no cards to turn back, and the game stopped with an error.

If the two cards match, they just stay up and open is emptied for the next move. If not, turnBack runs after TURN_BACK_TIME (0.8 seconds), so you have time to see them:

function turnBack() {
    open.forEach(function (card) {
        card.up = false;
        card.element.classList.add("down");
    });
    open = [];
}

When pairsFound is half the number of cards, every card has been found, and showStatus shows how many moves it took.

Step 5: A new game

newGame runs when the page loads, when you press New game, and when you choose a new size. It starts with clearTimeout(turnBackTimer), like in Connect Four vs computer. Otherwise a timer from the old game could turn back two cards in the new one.

Step 6: Test it

  • Click the same card twice. It should not count as a pair.
  • Turn up two cards that don't match and quickly click a third. Nothing should happen until the two have turned back.
  • Find all pairs. The message should say how many moves it took.
  • Try every size.

memory.html

<html lang="en">
<head>

  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Memory</title>
  <style>
    body {

        max-width: 800px;

        padding: 0 16px;

    body {
        text-align: center;

    #board {
        display: grid;
        grid-template-columns: repeat(4, 1fr);
        gap: 10px;
        max-width: 440px;
        margin: 0 auto;
    }

    .card {
        aspect-ratio: 1;
        padding: 6px;
        background: #dddddd;
        border: none;
        border-radius: 8px;
        cursor: pointer;
    }

    .card img {
        width: 100%;
        height: 100%;
    }

    .card.down {
        background: black url("images/card.svg") center / cover no-repeat;
    }

    .card.down img {
        visibility: hidden;
    }

    #status {
        font-size: 18px;
    }
  </style>
</head>
<body>
  <h1>Memory</h1>
  <div id="board"></div>
  <p id="status" aria-live="polite"></p>
  <label for="size">Size:</label>
  <select id="size">
    <option value="4">XS (8 cards)</option>
    <option value="6">S (12 cards)</option>
    <option value="8" selected>M (16 cards)</option>
    <option value="10">L (20 cards)</option>
    <option value="12">XL (24 cards)</option>
  </select>
  <button type="button" id="restart">New game</button>

  <script>
    /*
     * Memory: all cards lie face down, and every picture is on two cards.
     * Turn up two cards. If they match, they stay up; if not, they turn back.
     * Find all the pairs in as few moves as you can.
     */

    // --- Settings ------------------------------------------------------------

    // Where the pictures are: a folder called "images" next to this page.
    const IMAGE_FOLDER = "images/";

    const PICTURES = [
        "blue-star", "green-star", "purple-star", "yellow-star",
        "blue-triangel", "green-triangel", "purple-triangel", "yellow-triangel",
        "blue-square", "green-square", "purple-square", "yellow-square"
    ];
    const TURN_BACK_TIME = 800;   // ms to look at two cards that don't match

    // --- Elements on the page ------------------------------------------------

    const board = document.getElementById("board");
    const sizeSelect = document.getElementById("size");
    const statusText = document.getElementById("status");
    const restartButton = document.getElementById("restart");

    // --- State ---------------------------------------------------------------

    let cards = [];        // { name, element, up }
    let open = [];         // the cards turned up this move (0, 1 or 2)
    let moves = 0;
    let pairsFound = 0;
    let turnBackTimer = null;

    // --- Helpers -------------------------------------------------------------

    // A shuffled copy of a list (the Fisher-Yates shuffle).
    function shuffle(list) {
        const copy = list.slice();
        for (let i = copy.length - 1; i > 0; i--) {
            const j = Math.floor(Math.random() * (i + 1));
            const temp = copy[i];
            copy[i] = copy[j];
            copy[j] = temp;
        }
        return copy;
    }

    function showStatus() {
        if (pairsFound === cards.length / 2) {
            statusText.textContent = "You found all the pairs in " + moves + " moves!";
        } else {
            statusText.textContent = "Moves: " + moves;
        }
    }

    // --- The game ------------------------------------------------------------

    function newGame() {
        clearTimeout(turnBackTimer);

        // Two of each picture, in random order.
        const pairs = Number(sizeSelect.value);
        const names = PICTURES.slice(0, pairs);
        const deck = shuffle(names.concat(names));

        board.innerHTML = "";
        cards = deck.map(function (name) {
            const element = document.createElement("button");
            element.type = "button";
            element.className = "card down";
            const image = document.createElement("img");
            image.src = IMAGE_FOLDER + name + ".svg";
            image.alt = name.replace("-", " ");
            element.appendChild(image);
            board.appendChild(element);

            const card = { name: name, element: element, up: false };
            element.addEventListener("click", function () {
                turnUp(card);
            });
            return card;
        });

        open = [];
        moves = 0;
        pairsFound = 0;
        showStatus();
    }

    function turnUp(card) {
        // Not while two cards are showing, and not a card that is already up.
        if (open.length === 2 || card.up) {
            return;
        }
        card.up = true;
        card.element.classList.remove("down");
        open.push(card);

        if (open.length === 2) {
            moves++;
            if (open[0].name === open[1].name) {
                pairsFound++;
                open = [];   // a pair: they stay up
            } else {
                turnBackTimer = setTimeout(turnBack, TURN_BACK_TIME);
            }
        }
        showStatus();
    }

    function turnBack() {
        open.forEach(function (card) {
            card.up = false;
            card.element.classList.add("down");
        });
        open = [];
    }

    // --- Connect the page ----------------------------------------------------

    sizeSelect.addEventListener("change", newGame);
    restartButton.addEventListener("click", newGame);

    newGame();
  </script>
</body>
</html>
