Quiz

Every game has a topic, picked at random: animals, space, the human body, food and drink, around the world, science and inventions, the ocean, or sports and games. You get five questions about it. Click an answer and the page shows at once if it was right: the right answer turns green, and a wrong click turns red. After a moment the next question comes by itself.

The new parts are keeping the questions in a JSON file and loading it with fetch, shuffling a list properly, dealing questions like cards so they don't repeat, and stopping a second click from counting.

Step 2: The questions in a JSON file

400 questions would make the code very long. So they live in their own file, questions.json, and the code only reads it. Download questions.json, or start your own like this:

{
  "topics": [
    {
      "name": "Animals",
      "questions": [
        { "question": "How many years can a snail sleep for?", "answers": ["Five", "One", "Four", "Three"], "correct": 3 },
        { "question": "What is the largest bird in the world?", "answers": ["Ostrich", "Albatross", "Emperor penguin", "Swan"], "correct": 0 },
        ...
      ]
    },
    {
      "name": "Space",
      "questions": [ ... ]
    }
  ]
}

JSON looks like JavaScript objects and lists, with two rules: every name is in double quotes, and there is no comma after the last item. The file has a list of topics, and each topic has a name and a list of questions.

Each question is an object with three parts: the question, a list of answers, and correct, the index of the right answer. 3 is the fourth answer, because lists count from 0. Keeping everything about one question together makes it easy to add more: copy a line and change the text. Then anyone can add questions without touching the code.

Step 3: Loading the file

const QUESTIONS_FILE = "/assets/quiz/questions.json";

async function loadQuestions() {
    questionText.textContent = "Loading the questions...";
    try {
        const response = await fetch(QUESTIONS_FILE);
        if (!response.ok) {
            throw new Error("HTTP " + response.status);
        }
        const data = await response.json();
        topics = data.topics;
        newGame();
    } catch (error) {
        questionText.textContent = "The questions could not be loaded (" + error.message + ").";
    }
}

This is the same fetch, async and await as in My IP, but for a file next to the page instead of a web service. response.json() turns the text of the file into real objects and lists. If the file is missing, response.ok is false, and the page says so instead of showing nothing. On the site the file is at /assets/quiz/questions.json; on a page of your own, set QUESTIONS_FILE to "questions.json".

One catch: browsers don't let fetch read files when a page is opened straight from your disk, with an address that starts with file://. You get "The questions could not be loaded". Start a small web server in the game's folder instead, and open the page from it:

$ cd quiz
$ python3 -m http.server 8000

Then open http://localhost:8000/quiz.html. (Eliza keeps its script in a .js file for this reason, so it also works from disk.)

Step 4: A topic

// A random topic, but not the same as last game.
function pickTopic() {
    const others = topics.filter(function (t) {
        return t !== topic;
    });
    return randomItem(others.length > 0 ? others : topics);
}

filter keeps every topic except the one we just played, and randomItem picks one of them. The very first game has no topic yet, so others is all of them.

Step 5: Shuffling

function shuffle(list) {
    const copy = list.slice();
    for (let i = copy.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1));
        const temp = copy[i];
        copy[i] = copy[j];
        copy[j] = temp;
    }
    return copy;
}

This is the Fisher-Yates shuffle. Start at the last item and swap it with a random item at or before it, maybe itself. Then do the same with the second to last, and so on to the front. Every order is just as likely, which is not true for most home-made ways of shuffling.

The three lines with temp swap two items: save one in temp, copy the other over it, then put temp back in the other's place. list.slice() with nothing between the brackets makes a copy, so the shuffle doesn't mix up the list it was given.

Step 6: Dealing the questions

The first version took five random questions every game. With only a few questions, you saw the same ones again and again. Even with 50, picking at random gives repeats sooner than you'd think. So each topic deals its questions like a deck of cards:

// The next questions from the topic's deck. When the deck runs low, the
// whole topic is shuffled into a new deck.
function dealQuestions(t) {
    if (!decks[t.name] || decks[t.name].length < QUESTIONS_PER_GAME) {
        decks[t.name] = shuffle(t.questions);
    }
    return decks[t.name].splice(0, QUESTIONS_PER_GAME);
}

decks has one pile for each topic, by its name. The first time, or when there are fewer than five left, the whole topic is shuffled into a new pile. splice(0, 5) takes the first five questions out of the pile and gives them back, so the next game gets the next five. You don't see a question again until you have seen all 50 of that topic.

Step 7: Showing a question

function showQuestion() {
    const q = questions[current];
    answered = false;
    progressText.textContent = "Question " + (current + 1) + " of " + questions.length;
    questionText.textContent = q.question;
    showDots();

    // The answers in a new order every time, so the right one moves around.
    // Each button remembers which answer it is with data-index.
    answersBox.innerHTML = "";
    shuffle([0, 1, 2, 3]).forEach(function (index) {
        const button = document.createElement("button");
        button.type = "button";
        button.textContent = q.answers[index];
        button.dataset.index = index;
        button.addEventListener("click", function () {
            answer(index, button);
        });
        answersBox.appendChild(button);
    });
}

In the file, the right answer is always at the same place for a question. Shuffling the numbers 0 to 3 shows the answers in a new order every time. Each button still has to know which answer it is, so it gets it in data-index: button.dataset.index = index sets the attribute, and answer can read it back. Each button also passes itself to answer, so it can be colored red.

Step 8: Answering

function answer(index, clicked) {
    // Only the first click counts.
    if (answered) {
        return;
    }
    answered = true;

    const q = questions[current];
    const right = index === q.correct;
    results[current] = right;

    // Always show the right answer in green. A wrong click goes red.
    answersBox.querySelectorAll("button").forEach(function (button) {
        button.disabled = true;
        if (Number(button.dataset.index) === q.correct) {
            button.classList.add("correct");
        }
    });
    if (right) {
        score++;
        scoreText.textContent = score;
    } else {
        clicked.classList.add("wrong");
    }
    showDots();

    setTimeout(nextQuestion, NEXT_TIME);
}

The page waits NEXT_TIME (1.2 seconds) before the next question, so there is time to see the colors. During that time the buttons are still there, and a fast double click could give two points for one question. So the first click sets answered, and every click after that returns at once. The buttons are also disabled, so they look finished.

The right answer always turns green, also when you clicked a wrong one: the button whose data-index is q.correct. dataset values are always text, so Number() makes it a number before comparing. That way you learn something even when you miss.

Step 9: The dots, and the end

function showDots() {
    dotsBox.innerHTML = "";
    questions.forEach(function (q, index) {
        const dot = document.createElement("span");
        dot.className = "dot";
        if (results[index] === true) {
            dot.classList.add("right");
        } else if (results[index] === false) {
            dot.classList.add("wrong");
        } else if (index === current) {
            dot.classList.add("now");
        }
        dotsBox.appendChild(dot);
    });
}

results has true or false for each question answered, so far. A question not answered yet is undefined, neither true nor false, and its dot stays grey, or gets a ring if it is the question showing now.

When the last question is answered, endGame hides the row with the question number and the score, shows the score big instead, with a few words under it, and shows Play again by setting restartButton.hidden = false. Play again calls newGame, which picks a new topic and deals five new questions.

Step 10: Test it

  • Answer right and wrong. Green and red should show, in the buttons and the dots, and only right answers should count.
  • Double click an answer fast. The score should only go up by one.
  • Play a few games. The topic should change every time, and the answers come in a new order.
  • Rename questions.json for a moment. The page should say that the questions could not be loaded.
  • Add a question of your own to the file, with a mistake like a missing comma. The page can't load it either: JSON is strict.

  <script>
    /*
     * Quiz: every game has a topic picked at random, and five questions about
     * it. Click an answer to see if it was right, and the next question comes
     * by itself.
     *
     * The questions are in questions.json: 8 topics with 50 questions each.
     * Each topic deals its questions like a deck of cards, so you don't get the
     * same question again until you have seen them all.
     */

    // --- Settings ------------------------------------------------------------

    // Where the questions are. On a page of your own: "questions.json".
    const QUESTIONS_FILE = "/assets/quiz/questions.json";
    const QUESTIONS_PER_GAME = 5;
    const NEXT_TIME = 1200;    // ms to show the right answer before going on

    // --- Elements on the page ------------------------------------------------

    const topicText = document.getElementById("topic");
    const statusRow = document.getElementById("status");
    const scoreText = document.getElementById("score");
    const progressText = document.getElementById("progress");
    const dotsBox = document.getElementById("dots");
    const questionText = document.getElementById("question");
    const answersBox = document.getElementById("answers");
    const resultText = document.getElementById("result");
    const restartButton = document.getElementById("restart");

    // --- State ---------------------------------------------------------------

    let topics = [];       // from questions.json: { name, questions }
    let decks = {};        // the questions left to deal, for each topic
    let topic = null;      // the topic of this game
    let questions = [];    // the questions for this game
    let results = [];      // true or false for each question answered
    let current = 0;       // index of the question showing
    let score = 0;
    let answered = false;  // true once the question showing has been answered

    // --- Helpers -------------------------------------------------------------

    // A shuffled copy of a list (the Fisher-Yates shuffle). Go from the end,
    // and swap each item with a random one at or before it.
    function shuffle(list) {
        const copy = list.slice();
        for (let i = copy.length - 1; i > 0; i--) {
            const j = Math.floor(Math.random() * (i + 1));
            const temp = copy[i];
            copy[i] = copy[j];
            copy[j] = temp;
        }
        return copy;
    }

    function randomItem(list) {
        return list[Math.floor(Math.random() * list.length)];
    }

    // --- Loading the questions -----------------------------------------------

    async function loadQuestions() {
        questionText.textContent = "Loading the questions...";
        try {
            const response = await fetch(QUESTIONS_FILE);
            if (!response.ok) {
                throw new Error("HTTP " + response.status);
            }
            const data = await response.json();
            topics = data.topics;
            newGame();
        } catch (error) {
            questionText.textContent = "The questions could not be loaded (" + error.message + ").";
        }
    }

    // --- Topics and questions ------------------------------------------------

    // A random topic, but not the same as last game.
    function pickTopic() {
        const others = topics.filter(function (t) {
            return t !== topic;
        });
        return randomItem(others.length > 0 ? others : topics);
    }

    // The next questions from the topic's deck. When the deck runs low, the
    // whole topic is shuffled into a new deck.
    function dealQuestions(t) {
        if (!decks[t.name] || decks[t.name].length < QUESTIONS_PER_GAME) {
            decks[t.name] = shuffle(t.questions);
        }
        return decks[t.name].splice(0, QUESTIONS_PER_GAME);
    }

    // --- The game ------------------------------------------------------------

    function newGame() {
        topic = pickTopic();
        questions = dealQuestions(topic);
        results = [];
        current = 0;
        score = 0;
        topicText.textContent = topic.name;
        scoreText.textContent = score;
        statusRow.hidden = false;
        resultText.textContent = "";
        restartButton.hidden = true;
        showQuestion();
    }

    function showDots() {
        dotsBox.innerHTML = "";
        questions.forEach(function (q, index) {
            const dot = document.createElement("span");
            dot.className = "dot";
            if (results[index] === true) {
                dot.classList.add("right");
            } else if (results[index] === false) {
                dot.classList.add("wrong");
            } else if (index === current) {
                dot.classList.add("now");
            }
            dotsBox.appendChild(dot);
        });
    }

    function showQuestion() {
        const q = questions[current];
        answered = false;
        progressText.textContent = "Question " + (current + 1) + " of " + questions.length;
        questionText.textContent = q.question;
        showDots();

        // The answers in a new order every time, so the right one moves around.
        // Each button remembers which answer it is with data-index.
        answersBox.innerHTML = "";
        shuffle([0, 1, 2, 3]).forEach(function (index) {
            const button = document.createElement("button");
            button.type = "button";
            button.textContent = q.answers[index];
            button.dataset.index = index;
            button.addEventListener("click", function () {
                answer(index, button);
            });
            answersBox.appendChild(button);
        });
    }

    function answer(index, clicked) {
        // Only the first click counts.
        if (answered) {
            return;
        }
        answered = true;

        const q = questions[current];
        const right = index === q.correct;
        results[current] = right;

        // Always show the right answer in green. A wrong click goes red.
        answersBox.querySelectorAll("button").forEach(function (button) {
            button.disabled = true;
            if (Number(button.dataset.index) === q.correct) {
                button.classList.add("correct");
            }
        });
        if (right) {
            score++;
            scoreText.textContent = score;
        } else {
            clicked.classList.add("wrong");
        }
        showDots();

        setTimeout(nextQuestion, NEXT_TIME);
    }

    function nextQuestion() {
        current++;
        if (current < questions.length) {
            showQuestion();
        } else {
            endGame();
        }
    }

    function endGame() {
        // The score is shown big at the end, so the row with it can go.
        statusRow.hidden = true;
        progressText.textContent = "";
        questionText.textContent = "";
        answersBox.innerHTML = "";
        showDots();

        let words;
        if (score === questions.length) {
            words = "Amazing! All of them right!";
        } else if (score >= questions.length - 2) {
            words = "Well done!";
        } else {
            words = "Better luck with the next topic!";
        }
        // The score big, and the words under it.
        resultText.innerHTML = "";
        const big = document.createElement("span");
        big.className = "big";
        big.textContent = score + " / " + questions.length;
        resultText.append(big, words);
        restartButton.hidden = false;
    }

    // --- Connect the page ----------------------------------------------------

    restartButton.addEventListener("click", newGame);

    loadQuestions();
  </script>
</body>
</html>
