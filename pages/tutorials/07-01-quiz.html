Quiz

Five questions about animals, picked at random from a longer list. Click an answer and the page shows at once if it was right: the right answer turns green, and a wrong click turns red. After a moment the next question comes by itself.

The new parts are keeping the questions as a list of objects, shuffling a list properly, and stopping a second click from counting.

Open the finished game

Step 1: The page

Create quiz.html from the skeleton:

<button type="button" id="restart" hidden>Play again</button>

Step 2: The questions

const QUESTIONS = [
    {
        question: "How many years can a snail sleep for?",
        answers: ["Four", "Five", "Three", "One"],
        correct: 2
    },
    {
        question: "What is the largest bird in the world?",
        answers: ["Swan", "Emperor penguin", "Ostrich", "Albatross"],
        correct: 2
    },
    ...
];

Each question is an object with three parts: the question, a list of answers, and correct, the index of the right answer. 2 is the third answer, because lists count from 0. Keeping everything about one question together makes it easy to add more: copy one object and change the text.

Step 3: Shuffling

To pick five different questions at random, we shuffle the whole list and take the first five:

function shuffle(list) {
    const copy = list.slice();
    for (let i = copy.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1));
        const temp = copy[i];
        copy[i] = copy[j];
        copy[j] = temp;
    }
    return copy;
}

questions = shuffle(QUESTIONS).slice(0, QUESTIONS_PER_GAME);

This is the Fisher-Yates shuffle. Start at the last item and swap it with a random item at or before it, maybe itself. Then do the same with the second to last, and so on to the front. Every order is just as likely, which is not true for most home-made ways of shuffling.

The three lines with temp swap two items: save one in temp, copy the other over it, then put temp back in the other's place.

list.slice() with nothing between the brackets makes a copy, so the shuffle doesn't mix up QUESTIONS itself. slice(0, 5) gives the items from index 0 up to, but not including, 5.

Step 4: Showing a question

function showQuestion() {
    const q = questions[current];
    answered = false;
    progressText.textContent = "Question " + (current + 1) + " of " + questions.length;
    questionText.textContent = q.question;

    answersBox.innerHTML = "";
    q.answers.forEach(function (text, index) {
        const button = document.createElement("button");
        button.type = "button";
        button.textContent = text;
        button.addEventListener("click", function () {
            answer(index);
        });
        answersBox.appendChild(button);
    });
}

current counts from 0, but people count from 1, so the page shows current + 1. The old buttons are thrown away with innerHTML = "", and four new ones are made, like the letter buttons in Hangman. Each one calls answer with its own index.

Step 5: Answering

function answer(index) {
    if (answered) {
        return;
    }
    answered = true;

    const q = questions[current];
    const buttons = answersBox.querySelectorAll("button");
    buttons.forEach(function (button) {
        button.disabled = true;
    });

    buttons[q.correct].classList.add("correct");
    if (index === q.correct) {
        score++;
        scoreText.textContent = score;
    } else {
        buttons[index].classList.add("wrong");
    }

    setTimeout(nextQuestion, NEXT_TIME);
}

The page waits NEXT_TIME (1.2 seconds) before the next question, so there is time to see the colors. During that time the buttons are still there, and a fast double click could give two points for one question. So the first click sets answered, and every click after that returns at once. The buttons are also disabled, so they look finished.

The right answer always turns green, also when you clicked a wrong one. That way you learn something even when you miss.

Step 6: The next question, or the end

function nextQuestion() {
    current++;
    if (current < questions.length) {
        showQuestion();
    } else {
        endGame();
    }
}

endGame clears the question and the buttons, shows the result, and shows Play again by setting restartButton.hidden = false. Play again calls newGame, which shuffles new questions, sets current and score back to 0 and hides the button again.

Step 7: Test it

  • Answer right and wrong. Green and red should show, and only right answers should count.
  • Double click an answer fast. The score should only go up by one.
  • Play two games. The questions should come in a new order.

  <p>Score: <span id="score">0</span></p>

  <p id="result" aria-live="polite"></p>

  <script>
    /*
     * Quiz: five questions about animals, picked at random. Click an answer to
     * see if it was right, and the next question comes by itself.
     */

    // --- Settings ------------------------------------------------------------

    const QUESTIONS = [
        {
            question: "How many years can a snail sleep for?",
            answers: ["Four", "Five", "Three", "One"],
            correct: 2
        },
        {
            question: "What is the largest bird in the world?",
            answers: ["Swan", "Emperor penguin", "Ostrich", "Albatross"],
            correct: 2
        },
        {
            question: "What do you call a group of kangaroos?",
            answers: ["A band", "A troop", "A gang", "A crowd"],
            correct: 1
        },
        {
            question: "What is the largest mammal in the world?",
            answers: ["African elephant", "Blue whale", "Giraffe", "Hippopotamus"],
            correct: 1
        },
        {
            question: "What is the tallest species of penguin?",
            answers: ["King penguin", "Humboldt penguin", "Royal penguin", "Emperor penguin"],
            correct: 3
        },
        {
            question: "How long does it take for a sloth to digest its food?",
            answers: ["30 days", "20 days", "10 days", "40 days"],
            correct: 0
        },
        {
            question: "How many compartments does a cow's stomach have?",
            answers: ["Four", "Three", "Two", "One"],
            correct: 0
        },
        {
            question: "Which mammal has the lowest heart rate?",
            answers: ["Hippopotamus", "Brown bear", "African elephant", "Blue whale"],
            correct: 3
        }
    ];
    const QUESTIONS_PER_GAME = 5;
    const NEXT_TIME = 1200;    // ms to show the right answer before going on

    // --- Elements on the page ------------------------------------------------

    const scoreText = document.getElementById("score");
    const progressText = document.getElementById("progress");
    const questionText = document.getElementById("question");
    const answersBox = document.getElementById("answers");
    const resultText = document.getElementById("result");
    const restartButton = document.getElementById("restart");

    // --- State ---------------------------------------------------------------

    let questions = [];    // the questions for this game
    let current = 0;       // index of the question showing
    let score = 0;
    let answered = false;  // true once the question showing has been answered

    // --- Helpers -------------------------------------------------------------

    // A shuffled copy of a list (the Fisher-Yates shuffle). Go from the end,
    // and swap each item with a random one at or before it.
    function shuffle(list) {
        const copy = list.slice();
        for (let i = copy.length - 1; i > 0; i--) {
            const j = Math.floor(Math.random() * (i + 1));
            const temp = copy[i];
            copy[i] = copy[j];
            copy[j] = temp;
        }
        return copy;
    }

    // --- The game ------------------------------------------------------------

    function newGame() {
        questions = shuffle(QUESTIONS).slice(0, QUESTIONS_PER_GAME);
        current = 0;
        score = 0;
        scoreText.textContent = score;
        resultText.textContent = "";
        restartButton.hidden = true;
        showQuestion();
    }

    function showQuestion() {
        const q = questions[current];
        answered = false;
        progressText.textContent = "Question " + (current + 1) + " of " + questions.length;
        questionText.textContent = q.question;

        answersBox.innerHTML = "";
        q.answers.forEach(function (text, index) {
            const button = document.createElement("button");
            button.type = "button";
            button.textContent = text;
            button.addEventListener("click", function () {
                answer(index);
            });
            answersBox.appendChild(button);
        });
    }

    function answer(index) {
        // Only the first click counts.
        if (answered) {
            return;
        }
        answered = true;

        const q = questions[current];
        const buttons = answersBox.querySelectorAll("button");
        buttons.forEach(function (button) {
            button.disabled = true;
        });

        // Always show the right answer in green. A wrong click goes red.
        buttons[q.correct].classList.add("correct");
        if (index === q.correct) {
            score++;
            scoreText.textContent = score;
        } else {
            buttons[index].classList.add("wrong");
        }

        setTimeout(nextQuestion, NEXT_TIME);
    }

    function nextQuestion() {
        current++;
        if (current < questions.length) {
            showQuestion();
        } else {
            endGame();
        }
    }

    function endGame() {
        progressText.textContent = "";
        questionText.textContent = "";
        answersBox.innerHTML = "";
        if (score === questions.length) {
            resultText.textContent = "Amazing! You got all " + score + " right!";
        } else {
            resultText.textContent = "You got " + score + " of " + questions.length + " right.";
        }
        restartButton.hidden = false;
    }

    // --- Connect the page ----------------------------------------------------

    restartButton.addEventListener("click", newGame);

    newGame();
  </script>
</body>
</html>

Try this

  • Shuffle the answers too, so the right answer isn't always in the same place. (Remember that correct has to follow it.)
  • Add a timer: 10 seconds per question, and a question without an answer counts as wrong.
  • Save the best score in localStorage, so it is still there next time.
