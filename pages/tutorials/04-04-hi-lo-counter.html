Hi-Lo Counter

Practice counting cards, the way blackjack players do. Cards are shown one at a time, and you keep a count in your head. When the cards stop, you say what the count is. Each round has 5 to 10 cards, and after each guess you see every card with its value, so you can find where you went wrong. At the end you see how often you were right.

The cards are the ones from Blackjack, with the same front, back and turning animation. The new parts are showing cards one by one with a timer, a number input with big + and - buttons, and adding up the results.

Open the finished game

The Hi-Lo count

Low cards are good for the dealer and high cards are good for the player. So a card counter adds 1 for every low card that has been played, and takes away 1 for every high card:

CardsCount
2, 3, 4, 5, 6+1
7, 8, 90
10, J, Q, K, A-1

A whole deck has 20 low cards and 20 high cards, so it adds up to 0. When the count is high, more high cards are left in the deck, and the player has a better chance.

The game has two modes. In easy mode every round starts at 0, with a new deck. In hard mode the count keeps running from round to round, like at a real table, and you say the total so far.

Step 2: The value of a card

// The Hi-Lo value of a card: low cards +1, middle cards 0, high cards -1.
function hiLo(card) {
    if (["2", "3", "4", "5", "6"].includes(card.value)) {
        return 1;
    }
    if (["7", "8", "9"].includes(card.value)) {
        return 0;
    }
    return -1;
}

// A count with its sign, like +2, 0 and −1.
function signed(n) {
    if (n > 0) {
        return "+" + n;
    }
    return n < 0 ? "−" + Math.abs(n) : "0";
}

includes asks if the card's value is in the list. A count is shown with its sign, like +2 or −1, because that is how counters say it. Math.abs takes away the minus sign, and a real minus sign (−) is put in its place, which is a little longer than the hyphen on the keyboard.

Step 3: A shuffled deck

// A shuffled deck, made of "decks" full decks (the Fisher-Yates shuffle).
function newDeck(decks) {
    const list = [];
    for (let d = 0; d < decks; d++) {
        for (const suit of SUITS) {
            for (const value of VALUES) {
                list.push({ suit: suit, value: value });
            }
        }
    }
    for (let i = list.length - 1; i > 0; i--) {
        const j = Math.floor(Math.random() * (i + 1));
        [list[i], list[j]] = [list[j], list[i]];
    }
    return list;
}

This is the deck and the Fisher-Yates shuffle from Blackjack, with one change: it can make more than one deck. Easy mode takes a new deck of 52 every round. Hard mode takes two decks, 104 cards, at the start of the game, and never shuffles them again. 10 rounds of at most 10 cards need 100, so the cards never run out.

Step 4: A round

function nextRound() {
    round++;
    if (mode === "easy") {
        deck = newDeck(1);
        count = 0;
    }
    countBefore = count;
    const amount = MIN_CARDS + Math.floor(Math.random() * (MAX_CARDS - MIN_CARDS + 1));
    cards = deck.splice(0, amount);
    cards.forEach(function (card) {
        count += hiLo(card);
    });

    roundText.textContent = "Round " + round + " of " + rounds;
    if (mode === "hard" && round > 1) {
        statusText.textContent = "Keep counting from where you were.";
    } else {
        statusText.textContent = "Count the cards.";
    }
    guessForm.hidden = true;
    reviewBox.hidden = true;
    dealBox.hidden = false;
    dealBox.innerHTML = "";
    showCard(0);
}

The number of cards is random: Math.random() times 6, rounded down, is 0 to 5, so amount is 5 to 10. splice(0, amount) takes the cards off the top of the deck, so in hard mode the next round goes on with the cards that are left. The right count is worked out at once, before any card is shown. countBefore remembers where the round started, for the review.

Step 5: One card at a time

// Show card number "index", and the next one after "speed" seconds. Each
// card takes the place of the one before, so you can't count them again.
function showCard(index) {
    if (index === cards.length) {
        dealBox.innerHTML = "";
        askForCount();
        return;
    }
    const slot = cardElement(cards[index], "big");
    // The card comes in and turns over in under half of its time.
    const animation = Math.min(0.45, speed * 0.4);
    slot.style.animationDuration = animation * 0.4 + "s";
    slot.firstChild.style.animationDuration = animation * 0.6 + "s";
    slot.firstChild.style.animationDelay = animation * 0.4 + "s";
    dealBox.innerHTML = "";
    dealBox.appendChild(slot);
    dealTimer = setTimeout(function () {
        showCard(index + 1);
    }, speed * 1000);
}

showCard shows one card, and asks setTimeout to call it again with the next number after speed seconds. When the number reaches the end of the list, the cards are done, and it is time to guess. Each new card takes the place of the one before, so you can't go back and count them again.

The card comes in and turns over just like in Blackjack. At 0.5 seconds a card, Blackjack's animation would be too slow, so the times are set for each card: never more than 40% of the time the card is shown.

The same card is shown big when it is dealt, and small in the review. Everything on it is measured in em, which means "times the font size", so the font size alone sets the size of the whole card:

Step 6: The guess

function askForCount() {
    statusText.textContent = "";
    dealBox.hidden = true;
    // In hard mode the answer is the running count, so start from the count
    // before this round. The review of the last round showed it.
    guessInput.value = countBefore;
    guessForm.hidden = false;
    guessInput.focus();
}

function changeGuess(step) {
    guessInput.value = (Number(guessInput.value) || 0) + step;
}

The number is an <input type="number">, so you can type it, but on a phone it is much quicker to press the big − and + buttons. Number(guessInput.value) || 0 turns the text in the box into a number, and gives 0 if the box is empty. In hard mode the box starts at the count before the round, so you only have to step it up or down with the new cards.

A form is sent when you press Enter or click its submit button, and normally the browser then loads a new page. event.preventDefault() stops that, so we can check the guess ourselves. Math.round makes sure a guess like 2.5 counts as a whole number.

Step 7: The review

    // The round's cards, small, with the value of each under it.
    reviewCards.innerHTML = "";

        item.className = "review-card";
        item.appendChild(cardElement(card, "small"));

After each guess, all the cards of the round are shown small, with their value under each one. When you were wrong, it is easy to see which card you missed. In hard mode the review also says what the count was before the round.

Step 8: How did you do?

Every guess is saved in history, with the right count. At the end, the results come from that list. The percent is the number of right guesses divided by the number of rounds, times 100. Two more:

    // How far off the guesses were, and the longest run of right answers.
    const totalMiss = history.reduce(function (sum, h) {
        return sum + Math.abs(h.guess - h.count);
    }, 0);
    let streak = 0;
    let bestStreak = 0;
    history.forEach(function (h) {
        streak = h.right ? streak + 1 : 0;
        bestStreak = Math.max(bestStreak, streak);
    });

reduce goes through the list and adds up how far off each guess was. Math.abs makes a miss of -2 count as 2, so misses in both directions add up. The streak counts up for each right guess and starts again at 0 for a wrong one, and bestStreak remembers the highest it got.

Last, a table with one row per round: the number of cards, your guess, the right count, and ✓ or ✗.

Step 9: Test it

  • Count a round right and a round wrong. The review should show each card's value, and they should add up to the count.
  • Play hard mode. The count should go on from round to round, and the guess box should start at the count before the round.
  • Type a number and press Enter, instead of clicking Check.
  • Try every speed. At 0.5 seconds the cards should still turn over before the next one comes.
  • Play 10 rounds and check the percent, the average miss and the best streak by hand.

     *   2 3 4 5 6     +1

    let cards = [];       // the cards of this round
    let countBefore = 0;  // the count when the round started (0 in easy mode)
    let count = 0;        // the right count after this round's cards
    let history = [];     // { guess, count, cards, right } for each round
    let dealTimer = null;

    // --- Cards ---------------------------------------------------------------

    // A shuffled deck, made of "decks" full decks (the Fisher-Yates shuffle).
    function newDeck(decks) {
        const list = [];
        for (let d = 0; d < decks; d++) {
            for (const suit of SUITS) {
                for (const value of VALUES) {
                    list.push({ suit: suit, value: value });
                }
            }
        }
        for (let i = list.length - 1; i > 0; i--) {
            const j = Math.floor(Math.random() * (i + 1));
            [list[i], list[j]] = [list[j], list[i]];
        }
        return list;
    }

    // The Hi-Lo value of a card: low cards +1, middle cards 0, high cards -1.
    function hiLo(card) {
        if (["2", "3", "4", "5", "6"].includes(card.value)) {
            return 1;
        }
        if (["7", "8", "9"].includes(card.value)) {
            return 0;
        }
        return -1;
    }

    // A count with its sign, like +2, 0 and −1.
    function signed(n) {
        if (n > 0) {
            return "+" + n;
        }
        return n < 0 ? "−" + Math.abs(n) : "0";
    }

    // A card with a front and a back, as in Blackjack. It sits in a "slot"
    // that slides it in, and the card itself turns over.
    function cardElement(card, size) {
        const slot = document.createElement("div");
        slot.className = "slot " + size;
        const element = document.createElement("div");
        element.className = "playing-card";
        if (card.suit === "♥" || card.suit === "♦") {
            element.classList.add("red");
        }
        element.setAttribute("role", "img");
        element.setAttribute("aria-label", card.value + " of " + SUIT_NAMES[card.suit]);

        const front = document.createElement("div");
        front.className = "face front";
        front.innerHTML =
            '<span class="corner top">' + card.value + "<br>" + card.suit + "</span>" +
            '<span class="pip">' + card.suit + "</span>" +
            '<span class="corner bottom">' + card.value + "<br>" + card.suit + "</span>";
        const back = document.createElement("div");
        back.className = "face back";
        element.append(front, back);
        slot.appendChild(element);
        return slot;
    }

    // --- The game ------------------------------------------------------------

    function startGame(event) {
        event.preventDefault();
        mode = modeSelect.value;
        rounds = Number(roundsSelect.value);
        speed = Number(speedSelect.value);
        deck = newDeck(mode === "hard" ? HARD_DECKS : 1);
        history = [];
        round = 0;
        count = 0;
        setupForm.hidden = true;
        endBox.hidden = true;
        playBox.hidden = false;
        nextRound();
    }

    function nextRound() {
        round++;
        if (mode === "easy") {
            deck = newDeck(1);
            count = 0;
        }
        countBefore = count;
        const amount = MIN_CARDS + Math.floor(Math.random() * (MAX_CARDS - MIN_CARDS + 1));
        cards = deck.splice(0, amount);
        cards.forEach(function (card) {
            count += hiLo(card);
        });

        roundText.textContent = "Round " + round + " of " + rounds;
        if (mode === "hard" && round > 1) {
            statusText.textContent = "Keep counting from where you were.";
        } else {
            statusText.textContent = "Count the cards.";
        }
        guessForm.hidden = true;
        reviewBox.hidden = true;
        dealBox.hidden = false;
        dealBox.innerHTML = "";
        showCard(0);
    }

    // Show card number "index", and the next one after "speed" seconds. Each
    // card takes the place of the one before, so you can't count them again.
    function showCard(index) {
        if (index === cards.length) {
            dealBox.innerHTML = "";
            askForCount();
            return;
        }
        const slot = cardElement(cards[index], "big");
        // The card comes in and turns over in under half of its time.
        const animation = Math.min(0.45, speed * 0.4);
        slot.style.animationDuration = animation * 0.4 + "s";
        slot.firstChild.style.animationDuration = animation * 0.6 + "s";
        slot.firstChild.style.animationDelay = animation * 0.4 + "s";
        dealBox.innerHTML = "";
        dealBox.appendChild(slot);
        dealTimer = setTimeout(function () {
            showCard(index + 1);
        }, speed * 1000);
    }

    function askForCount() {
        statusText.textContent = "";
        dealBox.hidden = true;
        // In hard mode the answer is the running count, so start from the count
        // before this round. The review of the last round showed it.
        guessInput.value = countBefore;
        guessForm.hidden = false;
        guessInput.focus();
    }

    function changeGuess(step) {
        guessInput.value = (Number(guessInput.value) || 0) + step;
    }

    function checkGuess(event) {
        event.preventDefault();
        const guess = Math.round(Number(guessInput.value) || 0);
        const right = guess === count;
        history.push({ guess: guess, count: count, cards: cards, right: right });

        guessForm.hidden = true;
        if (right) {
            verdictText.textContent = "Right! The count is " + signed(count) + ".";
            verdictText.className = "verdict right";
        } else {
            verdictText.textContent = "Not quite: you said " + signed(guess) + ", the count is " + signed(count) + ".";
            verdictText.className = "verdict wrong";
        }

        // The round's cards, small, with the value of each under it.
        reviewCards.innerHTML = "";
        cards.forEach(function (card) {
            const item = document.createElement("div");
            item.className = "review-card";
            item.appendChild(cardElement(card, "small"));
            const value = document.createElement("span");
            value.className = "value";
            value.textContent = signed(hiLo(card));
            item.appendChild(value);
            reviewCards.appendChild(item);
        });
        if (mode === "hard") {
            reviewCountText.textContent = "The count was " + signed(countBefore) +
                " before this round, and these cards add " + signed(count - countBefore) + ".";
        } else {
            reviewCountText.textContent = "These cards add up to " + signed(count) + ".";
        }
        nextButton.textContent = round < rounds ? "Next round" : "See how you did";
        reviewBox.hidden = false;
        nextButton.focus();
    }

    function next() {
        if (round < rounds) {
            nextRound();
        } else {
            endGame();
        }
    }

    function endGame() {
        playBox.hidden = true;
        endBox.hidden = false;

        const rightCount = history.filter(function (h) { return h.right; }).length;
        const percent = Math.round(rightCount / history.length * 100);
        scoreText.textContent = rightCount + " of " + history.length + " right (" + percent + "%)";

        // How far off the guesses were, and the longest run of right answers.
        const totalMiss = history.reduce(function (sum, h) {
            return sum + Math.abs(h.guess - h.count);
        }, 0);
        let streak = 0;
        let bestStreak = 0;
        history.forEach(function (h) {
            streak = h.right ? streak + 1 : 0;
            bestStreak = Math.max(bestStreak, streak);
        });
        statsList.innerHTML = "";
        [
            "Average miss: " + (totalMiss / history.length).toFixed(1),
            "Best streak: " + bestStreak + " right in a row",
            "Mode: " + (mode === "hard" ? "hard, running count" : "easy, new count every round") +
                ", " + speed + " s a card"
        ].forEach(function (text) {
            const item = document.createElement("li");
            item.textContent = text;
            statsList.appendChild(item);
        });

        roundsTable.innerHTML = "<tr><th>Round</th><th>Cards</th><th>You said</th><th>Count</th><th></th></tr>";
        history.forEach(function (h, index) {
            const row = document.createElement("tr");
            [index + 1, h.cards.length, signed(h.guess), signed(h.count), h.right ? "✓" : "✗"].forEach(function (text) {
                const cell = document.createElement("td");
                cell.textContent = text;
                row.appendChild(cell);
            });
            row.className = h.right ? "right" : "wrong";
            roundsTable.appendChild(row);
        });
        againButton.focus();
    }

    function playAgain() {
        clearTimeout(dealTimer);
        endBox.hidden = true;
        playBox.hidden = true;
        setupForm.hidden = false;
    }

    // --- Connect the page ----------------------------------------------------

    setupForm.addEventListener("submit", startGame);
    guessForm.addEventListener("submit", checkGuess);
    byId("minus").addEventListener("click", function () { changeGuess(-1); });
    byId("plus").addEventListener("click", function () { changeGuess(1); });
    nextButton.addEventListener("click", next);
    againButton.addEventListener("click", playAgain);
  </script>
</body>
</html>
