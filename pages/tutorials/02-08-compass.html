Compass

A compass for your phone: the dial turns so that N always points north, and a marker at the top shows which way you are facing. The new ideas are drawing with SVG from JavaScript, reading the compass that phones report in two different ways, and doing math with angles that go round in a circle.

Open the finished page (on a phone, a computer has no compass)

Read the Bubble level first. It explains the deviceorientation event, asking for permission on iPhone, and smoothing.

The state

const SMOOTHING = 0.2;   // 1 = no smoothing, smaller = calmer but slower
const DIRECTIONS = ["N", "NE", "E", "SE", "S", "SW", "W", "NW"];

let heading = null;      // which way the phone points, 0 to 360
let started = false;
let gotEvent = false;    // the sensor has sent anything
let gotReading = false;  // the sensor has sent a heading we can use

heading starts as null, not 0, because 0 means north. null means "no reading yet".

Step 2: Draw the ticks

36 ticks are a lot to type, so a loop draws them. Every tick is the same short line at the top of the dial, turned round the middle by its angle:

const SVG = "http://www.w3.org/2000/svg";

function drawTicks() {
    for (let degrees = 0; degrees < 360; degrees += 10) {
        const big = degrees % 30 === 0;
        const line = document.createElementNS(SVG, "line");
        line.setAttribute("y1", -96);
        line.setAttribute("y2", big ? -82 : -88);
        line.setAttribute("class", big ? "tick tick-big" : "tick");
        line.setAttribute("transform", `rotate(${degrees})`);
        ticks.appendChild(line);

        // N, E, S and W already have letters.
        if (big && degrees % 90 !== 0) {
            const text = document.createElementNS(SVG, "text");
            text.setAttribute("class", "degrees");
            text.setAttribute("y", -72);
            text.setAttribute("transform", `rotate(${degrees})`);
            text.textContent = degrees;
            ticks.appendChild(text);
        }
    }
}

SVG elements live in their own namespace. document.createElement("line") would make an HTML element called "line", which the browser doesn't know how to draw. createElementNS with the SVG namespace makes a real SVG line. SVG attributes are set with setAttribute, and class too, instead of className.

degrees % 30 === 0 is true for 0, 30, 60 and so on: every third tick is a big one with a number.

Step 3: Where is north?

In the Bubble level we used beta and gamma. A compass needs the third angle, alpha, which way the phone points. But in a normal deviceorientation event, alpha is often counted from wherever the phone pointed when the page started, not from north. And phones give us north in two different ways:

  • iPhone: event.webkitCompassHeading, degrees clockwise from north. It is -1 when the compass isn't ready.
  • Android: a separate deviceorientationabsolute event, where event.absolute is true and alpha is counted from north. But alpha goes counterclockwise, so the heading is 360 - alpha.
function onOrientation(event) {
    gotEvent = true;
    let reading;
    if (typeof event.webkitCompassHeading === "number" && event.webkitCompassHeading >= 0) {
        reading = event.webkitCompassHeading;          // iPhone
    } else if (event.absolute && event.alpha !== null) {
        reading = 360 - event.alpha;                    // Android
    } else {
        return;   // only a tilt, no north
    }
    gotReading = true;

    reading = (reading + screenAngle()) % 360;
    ...
}

When the screen turns to landscape, the top of the screen is one of the phone's sides, which points 90 degrees further round. So we add the screen's angle, and % 360 keeps the result under 360:

function screenAngle() {
    return screen.orientation ? screen.orientation.angle : window.orientation || 0;
}

start() is the same as in the Bubble level, except for which event we listen to. If the browser knows the Android event, we use it:

if ("ondeviceorientationabsolute" in window) {
    window.addEventListener("deviceorientationabsolute", onOrientation);
} else {
    window.addEventListener("deviceorientation", onOrientation);
}

A device can have a tilt sensor but no compass. Then events come, but none has a heading. gotEvent and gotReading tell the two cases apart, so the message after two seconds can say which:

setTimeout(function () {
    if (!gotEvent) {
        message.textContent = "No compass found. Open the page on a phone.";
    } else if (!gotReading) {
        message.textContent = "This device can tell its tilt, but not where north is.";
    }
}, 2000);

Step 4: Smoothing round a circle

The Bubble level smoothed with tilt = tilt + (new - tilt) * 0.2. Try that with a compass pointing almost north: the heading is 359 and the new reading is 1. Then new - tilt is -358, and the dial spins almost all the way round, the long way, through south. The real difference is only +2.

We need the shortest way from one angle to the other:

function angleDifference(from, to) {
    return ((to - from + 540) % 360) - 180;
}

From 359 to 1: (1 - 359 + 540) % 360 - 180 = 182 - 180 = 2. From 10 to 350: (350 - 10 + 540) % 360 - 180 = 160 - 180 = -20. Adding 540 (360 + 180) keeps the number positive before %, because % of a negative number is negative in JavaScript. The answer is always from -180 to 180.

if (heading === null) {
    heading = reading;
} else {
    heading = (heading + angleDifference(heading, reading) * SMOOTHING + 360) % 360;
}
draw();

The first reading is used as it is, so the dial doesn't swing in from north when you press Start. The + 360 and % 360 keep the heading from 0 to 360 when it moves past north.

Step 5: Turn the dial

function directionName(degrees) {
    return DIRECTIONS[Math.round(degrees / 45) % 8];
}

function draw() {
    dial.setAttribute("transform", `rotate(${-heading})`);
    const rounded = Math.round(heading) % 360;
    headingText.textContent = rounded + "°";
    directionText.textContent = directionName(rounded);
}

startButton.addEventListener("click", start);
drawTicks();

If the phone points east (90), north is to the left, so the dial turns the other way: rotate(-90). The number under the gold marker is then 90, the heading.

There are 8 directions, 45 degrees apart. Math.round(degrees / 45) gives the nearest one: 40 / 45 rounds to 1, "NE". 350 / 45 rounds to 8, and % 8 turns that back into 0, "N". Math.round(heading) % 360 does the same for 359.6, which would round to 360 instead of 0.

Step 6: Test it

  • Put the page on a server with https://, or use localhost, and open it on a phone.
  • On a computer, Chrome's developer tools can fake the sensor: More tools, Sensors, Orientation. Change alpha and the dial should turn.
  • Turn round slowly. The heading should go up when you turn right (clockwise).
  • Turn past north. The dial should move a little, not spin round.
  • Turn the phone to landscape. The heading should be the way the top of the screen points.
  • Compare with a real compass or a map app. Keep away from metal, magnets and speakers, they confuse the sensor. If it is wrong, wave the phone in a figure 8 to calibrate it.

The phone's compass finds magnetic north. On a map, north is true north, the North Pole. The difference is a few degrees in most places, and it changes from place to place.

  <script>
    /*
     * Compass: the dial turns so that N always points north, and the gold marker
     * at the top shows which way the phone is pointing.
     *
     * Phones tell us where north is in two different ways:
     *   iPhone   event.webkitCompassHeading, degrees clockwise from north
     *   Android  the "deviceorientationabsolute" event, where event.alpha is
     *            degrees counterclockwise from north, so the heading is 360 - alpha
     */

    // --- Settings --------------------------------------------------------------

    const SMOOTHING = 0.2;   // 1 = no smoothing, smaller = calmer but slower
    const DIRECTIONS = ["N", "NE", "E", "SE", "S", "SW", "W", "NW"];

    // --- State -----------------------------------------------------------------

    let heading = null;      // which way the phone points, 0 to 360
    let started = false;
    let gotEvent = false;    // the sensor has sent anything
    let gotReading = false;  // the sensor has sent a heading we can use

    // --- Elements on the page --------------------------------------------------

    const dial = document.getElementById("dial");
    const ticks = document.getElementById("ticks");
    const headingText = document.getElementById("heading");
    const directionText = document.getElementById("direction");
    const message = document.getElementById("message");
    const startButton = document.getElementById("button-start");

    // --- The dial --------------------------------------------------------------

    // Draw a tick every 10 degrees, a longer one and a number every 30.
    // SVG elements must be made with createElementNS, not createElement.
    const SVG = "http://www.w3.org/2000/svg";

    function drawTicks() {
        for (let degrees = 0; degrees < 360; degrees += 10) {
            const big = degrees % 30 === 0;
            const line = document.createElementNS(SVG, "line");
            line.setAttribute("y1", -96);
            line.setAttribute("y2", big ? -82 : -88);
            line.setAttribute("class", big ? "tick tick-big" : "tick");
            line.setAttribute("transform", `rotate(${degrees})`);
            ticks.appendChild(line);

            // N, E, S and W already have letters.
            if (big && degrees % 90 !== 0) {
                const text = document.createElementNS(SVG, "text");
                text.setAttribute("class", "degrees");
                text.setAttribute("y", -72);
                text.setAttribute("transform", `rotate(${degrees})`);
                text.textContent = degrees;
                ticks.appendChild(text);
            }
        }
    }

    // --- Helpers ---------------------------------------------------------------

    // The shortest way from one angle to another, from -180 to 180.
    // From 350 to 10 is +20, not -340.
    function angleDifference(from, to) {
        return ((to - from + 540) % 360) - 180;
    }

    // How far the screen has turned: 0, 90, 180 or 270.
    function screenAngle() {
        return screen.orientation ? screen.orientation.angle : window.orientation || 0;
    }

    // 0 -> "N", 40 -> "NE", 350 -> "N"
    function directionName(degrees) {
        return DIRECTIONS[Math.round(degrees / 45) % 8];
    }

    // --- Drawing ---------------------------------------------------------------

    function draw() {
        // Turn the dial the other way, so N stays pointing north.
        dial.setAttribute("transform", `rotate(${-heading})`);
        const rounded = Math.round(heading) % 360;
        headingText.textContent = rounded + "°";
        directionText.textContent = directionName(rounded);
    }

    // --- The sensor ------------------------------------------------------------

    function onOrientation(event) {
        gotEvent = true;
        let reading;
        if (typeof event.webkitCompassHeading === "number" && event.webkitCompassHeading >= 0) {
            reading = event.webkitCompassHeading;          // iPhone
        } else if (event.absolute && event.alpha !== null) {
            reading = 360 - event.alpha;                    // Android
        } else {
            return;   // only a tilt, no north
        }
        gotReading = true;

        // When the screen turns to landscape, the top of the screen is a side of the phone.
        reading = (reading + screenAngle()) % 360;

        if (heading === null) {
            heading = reading;
        } else {
            // Smoothing the short way round, so 359 -> 1 doesn't spin past 180.
            heading = (heading + angleDifference(heading, reading) * SMOOTHING + 360) % 360;
        }
        draw();
    }

    async function start() {
        if (started) {
            return;
        }
        if (!window.DeviceOrientationEvent) {
            message.textContent = "This browser has no compass. Open the page on a phone.";
            return;
        }
        // iPhone and iPad ask the user first, and only after a click.
        if (typeof DeviceOrientationEvent.requestPermission === "function") {
            try {
                const answer = await DeviceOrientationEvent.requestPermission();
                if (answer !== "granted") {
                    message.textContent = "No permission to read the compass.";
                    return;
                }
            } catch (error) {
                message.textContent = "Could not ask for the compass: " + error.message;
                return;
            }
        }
        // Android sends the north-based angles in their own event.
        if ("ondeviceorientationabsolute" in window) {
            window.addEventListener("deviceorientationabsolute", onOrientation);
        } else {
            window.addEventListener("deviceorientation", onOrientation);
        }
        started = true;
        startButton.disabled = true;
        message.textContent = "Hold your phone flat, away from metal and magnets.";

        // A computer often has the event but no sensor, so nothing ever comes.
        setTimeout(function () {
            if (!gotEvent) {
                message.textContent = "No compass found. Open the page on a phone.";
            } else if (!gotReading) {
                message.textContent = "This device can tell its tilt, but not where north is.";
            }
        }, 2000);
    }

    // --- Start -----------------------------------------------------------------

    startButton.addEventListener("click", start);
    drawTicks();
  </script>
</body>
</html>
