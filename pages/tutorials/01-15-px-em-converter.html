PX to EM Converter

We build a converter between pixels and em, the CSS unit that is relative to the font size. You type in one field and the other one changes as you type, in both directions. A table shows the common sizes, and a click on a row puts that size in the converter.

The new ideas are two fields that update each other, rounding numbers so they look nice, and one click listener for all the rows of a table.

Open the finished page

px, em and rem

  • px is a fixed size: 24px is always 24 pixels.
  • em is relative to the font size of the parent element. If the parent has font-size: 16px, then 1.5em is 24px.
  • rem is relative to the font size of the whole page, the <html> element. Browsers start with 16px.

The math is the same for all of them. The font size we measure from is the base:

em = px / base    // 24 / 16 = 1.5
px = em * base    // 1.5 * 16 = 24

Step 1: The page

Create px-em-converter.html from the skeleton.

<h1>PX to EM Converter</h1>

<label for="base">Base font size (px)</label>
<input type="number" id="base" value="16" min="1" step="any">

<div class="fields">
  <div>
    <label for="px">Pixels</label>
    <input type="number" id="px" value="24" step="any">
  </div>
  <div>
    <label for="em">EM</label>
    <input type="number" id="em" step="any">
  </div>
</div>

<code id="css-line"></code>
<button type="button" id="copy">Copy</button>

<table>
  <thead>
    <tr><th>Pixels</th><th>EM</th><th>Percent</th></tr>
  </thead>
  <tbody id="sizes"></tbody>
</table>

type="number" gives a field for numbers: the phone shows a number keyboard, and letters can't be typed. step="any" allows decimals. Without it, the browser marks 1.5 as wrong, because the default step is 1.

The table body is empty. JavaScript fills it, since the em values depend on the base.

Step 2: Read the numbers

The value of an input is always text, even with type="number". parseFloat turns text into a number with decimals. If the text is not a number, for example an empty field, it gives NaN, "not a number".

parseFloat("24")     // 24
parseFloat("1.5")    // 1.5
parseFloat("")       // NaN

The base can't be 0, since we divide by it. So a function reads the base and uses 16 if the field is empty or 0:

function base() {
    const value = parseFloat(baseInput.value);
    return value > 0 ? value : 16;
}

NaN > 0 is false, so an empty field also gives 16.

Step 3: Round the numbers

Computers store decimals in binary, so the answers are not always exact. 0.1 * 3 is 0.30000000000000004. And 20px with base 12 is 1.6666666666666667em, which is more digits than anyone needs.

toFixed(4) rounds to 4 decimals, but gives text with zeros at the end: (1.5).toFixed(4) is "1.5000". Turning it into a number and back to text removes them:

function format(number, decimals) {
    return String(Number(number.toFixed(decimals)));
}

format(1.5, 4)                  // "1.5"
format(20 / 12, 4)              // "1.6667"
format(0.30000000000000004, 4)  // "0.3"

Step 4: Two fields that update each other

The input event fires every time the text in a field changes: on each key, and also on paste. So the other field changes as you type, without a Convert button.

function fromPx() {
    const px = parseFloat(pxInput.value);
    emInput.value = isNaN(px) ? "" : format(px / base(), 4);
    showCss();
}

function fromEm() {
    const em = parseFloat(emInput.value);
    pxInput.value = isNaN(em) ? "" : format(em * base(), 2);
    showCss();
}

pxInput.addEventListener("input", fromPx);
emInput.addEventListener("input", fromEm);

Won't this go on forever? fromPx changes the em field, so doesn't that fire input on the em field, which changes the px field, and so on? No: the input event only fires when the user changes a field. Setting value in JavaScript doesn't fire it.

If the field is empty, isNaN is true and the other field is emptied too, instead of showing NaN.

Step 5: A line of CSS

cssLine.textContent = "font-size: " + format(em, 4) + "rem; /* " + format(px, 2) + "px */";

This gives font-size: 1.5rem; /* 24px */, ready to paste into a style sheet. The comment with the pixels makes the CSS easier to read later.

Step 6: The table

The table is made with createElement, one row per size:

function fillTable() {
    sizesBody.textContent = "";
    for (const px of SIZES) {
        const row = document.createElement("tr");
        row.dataset.px = px;
        const texts = [px + "px", format(px / base(), 4) + "em", format(px / base() * 100, 2) + "%"];
        for (const text of texts) {
            const cell = document.createElement("td");
            cell.textContent = text;
            row.append(cell);
        }
        sizesBody.append(row);
    }
}

textContent = "" removes the old rows first, since the table is made again each time the base changes. row.dataset.px = px saves the size on the row as data-px="24", so we can read it when the row is clicked.

Step 7: One listener for all the rows

We could add a click listener to each row. But the rows are removed and made again when the base changes, and then the listeners must be added again too. Instead, one listener on <tbody> handles all of them. A click on a cell bubbles up through the row to the table body:

sizesBody.addEventListener("click", function (event) {
    const row = event.target.closest("tr");
    if (row) {
        pxInput.value = row.dataset.px;
        fromPx();
    }
});

event.target is the element that was clicked, usually a <td>. closest("tr") goes up from there to the nearest <tr>. This is called event delegation.

Setting pxInput.value doesn't fire input, as we saw in step 4, so we call fromPx() ourselves.

Step 8: Remember the base

Most people always use the same base. localStorage keeps it after the page is closed, the same way as in the Checklist:

function onBaseChange() {
    localStorage.setItem("px-em-base", baseInput.value);
    fillTable();
    fromPx();
}

const saved = localStorage.getItem("px-em-base");
if (saved) {
    baseInput.value = saved;
}
onBaseChange();

When the base changes, the pixels stay and the em is calculated again with fromPx(). At the start, onBaseChange() fills the table and the em field for the first time.

Step 9: Copy

copyButton.addEventListener("click", async function () {
    await navigator.clipboard.writeText(cssLine.textContent);
    copyButton.textContent = "Copied";
    setTimeout(function () {
        copyButton.textContent = "Copy";
    }, 1500);
});

navigator.clipboard.writeText puts text on the clipboard. The browser only allows it on a secure page (https:// or localhost) and after a click, so a page can't fill your clipboard on its own. For a short moment the button says "Copied", so you can see that it worked.

Step 10: Test it

  • Type 24 in Pixels. EM shows 1.5.
  • Type 2 in EM. Pixels shows 32.
  • Change the base to 20. The table changes, and 16px is now 0.8em.
  • Reload the page. The base is still 20.
  • Clear the Pixels field. EM is cleared too, and doesn't show NaN.

<body>
  <h1>PX to EM Converter</h1>

  <label for="base">Base font size (px)</label>
  <input type="number" id="base" value="16" min="1" step="any">

  <div class="fields">
    <div>
      <label for="px">Pixels</label>
      <input type="number" id="px" value="24" step="any">
    </div>
    <div>
      <label for="em">EM</label>
      <input type="number" id="em" step="any">
    </div>
  </div>

  <code id="css-line"></code>
  <button type="button" id="copy">Copy</button>

  <table>
    <thead>
      <tr><th>Pixels</th><th>EM</th><th>Percent</th></tr>
    </thead>
    <tbody id="sizes"></tbody>
  </table>

  <script>
    /*
     * PX to EM Converter: em = px / base, px = em * base.
     * Typing in one field updates the other.
     */

    const SIZES = [10, 12, 14, 16, 18, 20, 24, 28, 32, 40, 48, 64];

    // --- Elements on the page ------------------------------------------------

    const baseInput = document.getElementById("base");
    const pxInput = document.getElementById("px");
    const emInput = document.getElementById("em");
    const cssLine = document.getElementById("css-line");
    const copyButton = document.getElementById("copy");
    const sizesBody = document.getElementById("sizes");

    // --- Numbers -------------------------------------------------------------

    // Round, and remove the zeros at the end: 1.5000 -> "1.5"
    function format(number, decimals) {
        return String(Number(number.toFixed(decimals)));
    }

    // The base font size. 16 if the field is empty or 0.
    function base() {
        const value = parseFloat(baseInput.value);
        return value > 0 ? value : 16;
    }

    // --- Converting ----------------------------------------------------------

    function fromPx() {
        const px = parseFloat(pxInput.value);
        emInput.value = isNaN(px) ? "" : format(px / base(), 4);
        showCss();
    }

    function fromEm() {
        const em = parseFloat(emInput.value);
        pxInput.value = isNaN(em) ? "" : format(em * base(), 2);
        showCss();
    }

    function showCss() {
        const px = parseFloat(pxInput.value);
        const em = parseFloat(emInput.value);
        if (isNaN(px) || isNaN(em)) {
            cssLine.textContent = "–";
            return;
        }
        cssLine.textContent = "font-size: " + format(em, 4) + "rem; /* " + format(px, 2) + "px */";

        // Mark the row in the table with the same size.
        for (const row of sizesBody.rows) {
            row.classList.toggle("current", Number(row.dataset.px) === px);
        }
    }

    // --- The table -----------------------------------------------------------

    function fillTable() {
        sizesBody.textContent = "";
        for (const px of SIZES) {
            const row = document.createElement("tr");
            row.dataset.px = px;
            const texts = [px + "px", format(px / base(), 4) + "em", format(px / base() * 100, 2) + "%"];
            for (const text of texts) {
                const cell = document.createElement("td");
                cell.textContent = text;
                row.append(cell);
            }
            sizesBody.append(row);
        }
    }

    // One listener for all the rows.
    sizesBody.addEventListener("click", function (event) {
        const row = event.target.closest("tr");
        if (row) {
            pxInput.value = row.dataset.px;
            fromPx();
        }
    });

    // --- The base font size --------------------------------------------------

    function onBaseChange() {
        localStorage.setItem("px-em-base", baseInput.value);
        fillTable();
        fromPx();
    }

    // --- Copy ----------------------------------------------------------------

    copyButton.addEventListener("click", async function () {
        await navigator.clipboard.writeText(cssLine.textContent);
        copyButton.textContent = "Copied";
        setTimeout(function () {
            copyButton.textContent = "Copy";
        }, 1500);
    });

    // --- Start ---------------------------------------------------------------

    pxInput.addEventListener("input", fromPx);
    emInput.addEventListener("input", fromEm);
    baseInput.addEventListener("input", onBaseChange);

    const saved = localStorage.getItem("px-em-base");
    if (saved) {
        baseInput.value = saved;
    }
    onBaseChange();
  </script>
</body>
</html>
