Hangman

Guess the secret word one letter at a time. Every wrong letter adds a part to the hanging man, and after six wrong letters you lose. You can click the letters on the page or type them on your keyboard.

This chapter starts with a game that needs no canvas and no game loop. Nothing happens until the player does something, so all the code runs from event listeners, like the tools in chapter 1. The new parts are working with the letters of a word, and building the buttons with JavaScript instead of writing them in the HTML.

A <line> goes from the point x1, y1 to x2, y2. In SVG, y grows downwards, so y1="210" is near the bottom. The first four lines are the gallows: the ground, the pole, the beam and the rope. Then come the six parts of the man, in the order they should appear: head, body, two arms and two legs. They all have class="part", so the code can find them.

#keyboard is empty. The code fills it with 26 buttons. aria-live="polite" on the message makes screen readers read it out when it changes.

Step 2: The state

const WORDS = [
    "APPLE", "BANANA", "CHERRY", "COCONUT", "GRAPES", "KIWI", "LEMON",
    "LIME", "MANGO", "MELON", "ORANGE", "PEAR", "PINEAPPLE"
];
const MAX_WRONG = 6;
const LETTERS = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";

let word = "";
let guessed = [];      // every letter guessed so far, right or wrong
let gameOver = false;

That is all the game needs to remember: the secret word and the letters guessed. Everything else can be worked out from those two. We don't keep a separate count of wrong guesses, or a list of the letters found so far, that could get out of step with guessed.

Step 3: Working things out from the guesses

function wrongCount() {
    return guessed.filter(function (letter) {
        return !word.includes(letter);
    }).length;
}

function isSolved() {
    return word.split("").every(function (letter) {
        return guessed.includes(letter);
    });
}
  • word.includes(letter) is true if the letter is somewhere in the word. Strings and lists both have includes.
  • filter keeps the guesses that are not in the word. Their length is the number of wrong guesses.
  • "PEAR".split("") splits the word between every letter: ["P", "E", "A", "R"].
  • every is true if the test is true for every letter. The word is solved when every one of its letters has been guessed. A word with the same letter twice, like APPLE, needs P guessed only once.

Step 4: Showing the game

function show() {
    wordText.textContent = word.split("").map(function (letter) {
        return guessed.includes(letter) ? letter : "_";
    }).join(" ");

    const wrong = wrongCount();
    wrongText.textContent = "Wrong guesses: " + wrong + " of " + MAX_WRONG;

    parts.forEach(function (part, index) {
        part.style.visibility = index < wrong ? "visible" : "hidden";
    });
}

map turns every letter of the word into itself if it has been guessed, and into _ if not. join(" ") puts the list back together with a space between them. For PEAR with E and R guessed, that is _ E _ R.

parts is the six parts of the man, from document.querySelectorAll(".part"), in the order they are in the HTML. With 2 wrong guesses, part 0 (the head) and part 1 (the body) are shown. We use style.visibility instead of hidden here, because the hidden attribute only works on HTML tags, not on the shapes inside an SVG.

Step 5: Building the keyboard

const buttons = {};

LETTERS.split("").forEach(function (letter) {
    const button = document.createElement("button");
    button.type = "button";
    button.textContent = letter;
    button.addEventListener("click", function () {
        guess(letter);
    });
    keyboard.appendChild(button);
    buttons[letter] = button;
});

document.createElement("button") makes a new button that isn't on the page yet. We set it up and then appendChild puts it at the end of #keyboard. Writing 26 buttons by hand in the HTML would work too, but this is shorter and can't have a typo in one of them.

Each button calls guess with its own letter. We also keep the buttons in an object, so buttons["E"] is the E button. We need it to color the button when E is typed on the keyboard instead of clicked.

Step 6: Guessing a letter

function guess(letter) {
    if (gameOver || guessed.includes(letter)) {
        return;
    }
    guessed.push(letter);

    const button = buttons[letter];
    button.disabled = true;
    button.classList.add(word.includes(letter) ? "correct" : "wrong");
    show();

    if (isSolved()) {
        endGame("You win! The word was " + word + ".");
    } else if (wrongCount() >= MAX_WRONG) {
        endGame("Game over! The word was " + word + ".");
    }
}

A letter that is already guessed is ignored. Without that check, typing the same wrong letter six times would lose the game. The button is disabled, so it can't be clicked again, and it gets green or red from the CSS classes.

endGame shows the message, sets gameOver and disables all the buttons.

Step 7: Typing letters

document.addEventListener("keydown", function (event) {
    if (event.ctrlKey || event.metaKey || event.altKey) {
        return;
    }
    const letter = event.key.toUpperCase();
    if (letter.length === 1 && LETTERS.includes(letter)) {
        guess(letter);
    }
});

event.key is the character typed, like "e", or a name like "Enter" or "Shift" for other keys. toUpperCase() makes "e" into "E". "ENTER" is longer than one letter, so it is skipped. We also skip keys pressed with Ctrl, Cmd or Alt, so reloading the page with Ctrl+R doesn't guess R.

Step 8: A new word

function newGame() {
    word = WORDS[Math.floor(Math.random() * WORDS.length)];
    guessed = [];
    gameOver = false;
    messageText.textContent = "";
    LETTERS.split("").forEach(function (letter) {
        buttons[letter].disabled = false;
        buttons[letter].classList.remove("correct", "wrong");
    });
    show();
}

Picking a random item from a list is the same as in 8-ball. The first version of this game reloaded the whole page to start again. Resetting the state ourselves is quicker, and it is the same code that starts the very first game.

Step 9: Test it

  • Guess a letter that is in the word twice, like P in APPLE. Both should show.
  • Click a letter, then type the same letter. Nothing should happen the second time.
  • Make six wrong guesses. The whole man should be shown and the keyboard locked.
  • Press New word in the middle of a game. The man and the colors should go away.

  <script>
    /*
     * Hangman: guess the word one letter at a time. Every wrong letter adds a
     * part to the hanging man. Six wrong letters and you lose.
     *
     * Click the letters, or type them on your keyboard.
     */

    // --- Settings ------------------------------------------------------------

    const WORDS = [
        "APPLE", "BANANA", "CHERRY", "COCONUT", "GRAPES", "KIWI", "LEMON",
        "LIME", "MANGO", "MELON", "ORANGE", "PEAR", "PINEAPPLE"
    ];
    const MAX_WRONG = 6;
    const LETTERS = "ABCDEFGHIJKLMNOPQRSTUVWXYZ";

    // --- Elements on the page ------------------------------------------------

    const wordText = document.getElementById("word");
    const wrongText = document.getElementById("wrong");
    const messageText = document.getElementById("message");
    const keyboard = document.getElementById("keyboard");
    const newWordButton = document.getElementById("newWord");
    const parts = document.querySelectorAll(".part");  // head, body, arms, legs

    // --- State ---------------------------------------------------------------

    let word = "";
    let guessed = [];      // every letter guessed so far, right or wrong
    let gameOver = false;
    const buttons = {};    // the button for each letter, e.g. buttons["A"]

    // --- Helpers -------------------------------------------------------------

    function wrongCount() {
        return guessed.filter(function (letter) {
            return !word.includes(letter);
        }).length;
    }

    function isSolved() {
        return word.split("").every(function (letter) {
            return guessed.includes(letter);
        });
    }

    // --- Showing the game ----------------------------------------------------

    function show() {
        // Guessed letters are shown, the rest are _.
        wordText.textContent = word.split("").map(function (letter) {
            return guessed.includes(letter) ? letter : "_";
        }).join(" ");

        const wrong = wrongCount();
        wrongText.textContent = "Wrong guesses: " + wrong + " of " + MAX_WRONG;

        // One more part of the man for each wrong guess.
        parts.forEach(function (part, index) {
            part.style.visibility = index < wrong ? "visible" : "hidden";
        });
    }

    // --- Actions -------------------------------------------------------------

    function guess(letter) {
        if (gameOver || guessed.includes(letter)) {
            return;
        }
        guessed.push(letter);

        const button = buttons[letter];
        button.disabled = true;
        button.classList.add(word.includes(letter) ? "correct" : "wrong");
        show();

        if (isSolved()) {
            endGame("You win! The word was " + word + ".");
        } else if (wrongCount() >= MAX_WRONG) {
            endGame("Game over! The word was " + word + ".");
        }
    }

    function endGame(text) {
        gameOver = true;
        messageText.textContent = text;
        LETTERS.split("").forEach(function (letter) {
            buttons[letter].disabled = true;
        });
    }

    function newGame() {
        word = WORDS[Math.floor(Math.random() * WORDS.length)];
        guessed = [];
        gameOver = false;
        messageText.textContent = "";
        LETTERS.split("").forEach(function (letter) {
            buttons[letter].disabled = false;
            buttons[letter].classList.remove("correct", "wrong");
        });
        show();
    }

    // --- Connect the page ----------------------------------------------------

    // One button per letter.
    LETTERS.split("").forEach(function (letter) {
        const button = document.createElement("button");
        button.type = "button";
        button.textContent = letter;
        button.addEventListener("click", function () {
            guess(letter);
        });
        keyboard.appendChild(button);
        buttons[letter] = button;
    });

    // Typing a letter works too, but not Ctrl+R and the like.
    document.addEventListener("keydown", function (event) {
        if (event.ctrlKey || event.metaKey || event.altKey) {
            return;
        }
        const letter = event.key.toUpperCase();
        if (letter.length === 1 && LETTERS.includes(letter)) {
            guess(letter);
        }
    });

    newWordButton.addEventListener("click", newGame);

    newGame();
  </script>
</body>
</html>
