Countdown

A countdown to a date, in days, hours, minutes and seconds. The date, a title and an image to show at the end are all read from the address, like this:

countdown.html?to=2026-12-24T15:00&title=Christmas&url=https://example.com/tree.jpg

That way anyone can make a countdown and share it as a link, without a server or a database. A plain HTML form writes the address for us.

Look at the form at the bottom. It has method="get" and no action, so when you press the button, the browser opens the same page again with the fields in the address: ?to=...&title=...&url=.... Each field's name becomes the name in the address. This is plain HTML and needs no JavaScript.

type="datetime-local" shows a date and time picker. It gives text like 2026-12-24T15:00, which is a format new Date() can read. required stops the form from being sent without a date.

The .blink class uses a CSS animation. @keyframes blink says how it changes, from opacity: 1 (visible) to opacity: 0 (gone). animation: blink 400ms infinite alternate runs it every 400 milliseconds, forever, back and forth. JavaScript only has to add the class.

Step 2: Read the address

window.location.search is the part of the address from ?. URLSearchParams reads it, and handles details like %20 for spaces:

const params = new URLSearchParams(window.location.search);
const endDate = new Date(params.get("to"));
const imageUrl = params.get("url");

params.get("to") gives the text, or null if there is no to in the address.

Step 3: Split seconds into days, hours, minutes and seconds

function showTimeLeft(totalSeconds) {
    const days = Math.floor(totalSeconds / (24 * 60 * 60));
    const hours = Math.floor(totalSeconds / (60 * 60)) % 24;
    const minutes = Math.floor(totalSeconds / 60) % 60;
    const seconds = totalSeconds % 60;

    daysText.textContent = twoDigits(days);
    hoursText.textContent = twoDigits(hours);
    minutesText.textContent = twoDigits(minutes);
    secondsText.textContent = twoDigits(seconds);
}

% gives what is left over. For example, Math.floor(totalSeconds / 60) is the total number of minutes, and % 60 keeps only the minutes that don't fill a whole hour. Try showTimeLeft(90061) in the console. That is 1 day, 1 hour, 1 minute and 1 second, so it shows 01 01 01 01.

twoDigits() uses padStart(2, "0") to turn 7 into "07".

Step 4: Tick every second

function tick() {
    const secondsLeft = Math.ceil((endDate - new Date()) / 1000);

    if (secondsLeft <= 0) {
        showTimeLeft(0);
        finish();
    } else {
        showTimeLeft(secondsLeft);
    }
}

Subtracting two dates gives milliseconds. Math.ceil rounds up, so the clock shows 00:01 during the last second and not 00:00.

setInterval(tick, 1000) runs tick every second and returns an id. clearInterval(id) stops it again:

function finish() {
    clearInterval(timer);

    [daysText, hoursText, minutesText, secondsText].forEach(function (element) {
        element.classList.add("blink");
    });

    if (imageUrl) {
        const image = document.createElement("img");
        image.src = imageUrl;
        image.style.width = "100%";
        imageContainer.appendChild(image);
    }
}

Step 5: Start, carefully

Everything in the address comes from whoever made the link, so we treat it with care:

if (params.get("title")) {
    titleText.textContent = params.get("title");
}

if (params.get("to") && isValidDate(endDate)) {
    timer = setInterval(tick, 1000);
    tick();
} else {
    titleText.textContent = "Add a date to the address, e.g. ?to=1999-12-31T23:59:00";
}
  • The title is written with textContent, never innerHTML. Otherwise a link with ?title=<img src=x onerror=...> could run any script on the page. This kind of attack is called cross-site scripting, or XSS.
  • params.get("title") is null if there is no title and "" if the form field was empty. Both count as false, so an empty field keeps the heading "Countdown".
  • new Date("not a date") gives an "Invalid Date" whose time is NaN. isValidDate() checks for that with isNaN(date.getTime()).
  • A trap: new Date(null) is not invalid. It is 1 January 1970. So without the params.get("to") check, a page with no date would show a finished countdown instead of the help text.
  • We call tick() once ourselves, so the numbers show right away and not after the first second.

Step 6: Test it

  • Open the page without anything after .html. You should see the help text in the heading.
  • Fill in the form with a time two minutes from now and an image address. When it reaches zero, the numbers blink and the image shows.
  • Try ?to=nonsense and ?to=2000-01-01T00:00.
  • Try ?to=2099-01-01T00:00&title=<b>hi</b>. The title should show the tags as text.

  <script>
    /*
     * Countdown to a date given in the page address, e.g.
     *
     *   ?to=2026-12-24T15:00:00&title=Christmas&url=https://.../tree.jpg
     *
     * A plain HTML form with method="get" on the page writes the address for us.
     *
     *   to     the date and time to count down to (required)
     *   title  text shown as the heading (optional)
     *   url    an image to show when the countdown is done (optional)
     *
     * Every second we work out how long is left and split it into
     * days, hours, minutes and seconds.
     */

    // --- Elements on the page ------------------------------------------------

    const titleText = document.getElementById("countdown-title");
    const daysText = document.getElementById("output-days");
    const hoursText = document.getElementById("output-hours");
    const minutesText = document.getElementById("output-minutes");
    const secondsText = document.getElementById("output-seconds");
    const imageContainer = document.getElementById("image-container");

    // --- Settings from the address -------------------------------------------

    // URLSearchParams reads the "?to=...&title=..." part of the address.
    const params = new URLSearchParams(window.location.search);
    const endDate = new Date(params.get("to"));
    const imageUrl = params.get("url");

    // --- State ---------------------------------------------------------------

    let timer = null;

    // --- Helpers -------------------------------------------------------------

    // 7 -> "07"
    function twoDigits(number) {
        return String(number).padStart(2, "0");
    }

    // new Date("not a date") gives an "Invalid Date" whose time is NaN.
    function isValidDate(date) {
        return !isNaN(date.getTime());
    }

    // --- Actions -------------------------------------------------------------

    function showTimeLeft(totalSeconds) {
        const days = Math.floor(totalSeconds / (24 * 60 * 60));
        const hours = Math.floor(totalSeconds / (60 * 60)) % 24;
        const minutes = Math.floor(totalSeconds / 60) % 60;
        const seconds = totalSeconds % 60;

        daysText.textContent = twoDigits(days);
        hoursText.textContent = twoDigits(hours);
        minutesText.textContent = twoDigits(minutes);
        secondsText.textContent = twoDigits(seconds);
    }

    function finish() {
        clearInterval(timer);

        // The "blink" class has a CSS animation.
        [daysText, hoursText, minutesText, secondsText].forEach(function (element) {
            element.classList.add("blink");
        });

        if (imageUrl) {
            const image = document.createElement("img");
            image.src = imageUrl;
            image.style.width = "100%";
            imageContainer.appendChild(image);
        }
    }

    // Called once every second.
    function tick() {
        // Subtracting two dates gives the difference in milliseconds.
        const secondsLeft = Math.ceil((endDate - new Date()) / 1000);

        if (secondsLeft <= 0) {
            showTimeLeft(0);
            finish();
        } else {
            showTimeLeft(secondsLeft);
        }
    }

    // --- Start ---------------------------------------------------------------

    // get() gives null when it is missing and "" when the form field was empty.
    if (params.get("title")) {
        // textContent (not innerHTML) so nobody can put HTML or scripts
        // into the page through the address.
        titleText.textContent = params.get("title");
    }

    // Without "to" in the address, new Date(null) is 1970-01-01, which is a
    // valid date. So check that there is a "to" as well.
    if (params.get("to") && isValidDate(endDate)) {
        timer = setInterval(tick, 1000);
        tick(); // show the time right away instead of after one second
    } else {
        titleText.textContent = "Add a date to the address, e.g. ?to=1999-12-31T23:59:00";
    }
  </script>
</body>
</html>
