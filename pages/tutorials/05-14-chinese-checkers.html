Chinese Checkers

Chinese checkers is played on a star with 121 holes, by 2, 3 or 6 players. Each player has ten pieces in one point of the star, and races them to the point on the other side. A piece steps to an empty hole next to it, or jumps over a piece next to it, and may go on jumping as long as it can. Nothing is taken: the pieces of the others are just something to jump over.

It is a board game like Checkers, but the board is very different: the holes are on a hexagonal grid, where every hole has six neighbours. The new ideas are a neat way to number such a grid, finding every hole a piece can reach with a breadth-first search, and drawing the board with SVG.

Step 2: Numbering a hexagonal grid

On a square grid, a square is a row and a column. On a hexagonal grid, the trick is to use three numbers, q, r and s, that always add up to 0. They are called cube coordinates: imagine a stack of cubes, seen from a corner, and you see hexagons.

function hole(q, r) {
    return { q: q, r: r, s: -q - r };
}

function distance(a, b) {
    return (Math.abs(a.q - b.q) + Math.abs(a.r - b.r) + Math.abs(a.s - b.s)) / 2;
}

Since s is always -q - r, we only need to store two of them. With cube coordinates, everything is simple sums:

  • The six neighbours are the six ways to add 1 to one of the numbers and take 1 from another. That is the list DIRECTIONS.
  • The distance between two holes, in steps, is half of the three differences added up.
  • Where to draw a hole is two short sums:
function pixel(h) {
    return { x: SQRT3 * (h.q + h.r / 2), y: 1.5 * h.r };
}

Step 3: A star from two triangles

The star is two big triangles on top of each other: one pointing up and one pointing down. In cube coordinates, a triangle is just "all three numbers at least -4" (or at most 4):

function inStar(h) {
    const up = h.q >= -4 && h.r >= -4 && h.s >= -4;
    const down = h.q <= 4 && h.r <= 4 && h.s <= 4;
    return up || down;
}

Each triangle has 91 holes, and they share a hexagon of 61 in the middle: 91 + 91 - 61 = 121. The six points of the star are where one of the numbers is more than 4, or less than -4, and each has 10 holes. The point on the other side is where the same number is past -4 instead of 4.

Step 4: Every hole a piece can reach

A piece can step to an empty neighbour, or jump. After a jump it may jump again, from where it landed, in any direction. To find every hole at the end of every chain of jumps, we use a breadth-first search, which spreads like water:

function reachable(from, squares) {
    const paths = new Map();
    const isFree = function (h) {
        return onBoard(h) && (squares.get(key(h)) === null || key(h) === key(from));
    };
    DIRECTIONS.forEach(function (direction) {
        const next = add(from, direction, 1);
        if (onBoard(next) && squares.get(key(next)) === null) {
            paths.set(key(next), [from, next]);
        }
    });
    const seen = new Set([key(from)]);
    const queue = [[from]];
    while (queue.length > 0) {
        const path = queue.shift();
        const at = path[path.length - 1];
        DIRECTIONS.forEach(function (direction) {
            const over = add(at, direction, 1);
            const land = add(at, direction, 2);
            const overPiece = onBoard(over) && squares.get(key(over)) !== null && key(over) !== key(from);
            if (overPiece && isFree(land) && !seen.has(key(land))) {
                seen.add(key(land));
                const longer = path.concat([land]);
                if (!paths.has(key(land))) {
                    paths.set(key(land), longer);
                }
                queue.push(longer);
            }
        });
    }
    return paths;
}
  • The queue holds the paths still to look at. We take one from the front with shift(), look at all six jumps from its end, and put every new path at the back with push().
  • seen is a Set of the holes already reached. Without it, two pieces next to each other could be jumped back and forth for ever. A Set answers "have I seen this?" at once, however many holes are in it.
  • The piece itself has left its hole, so that hole counts as empty: another chain may pass through it.
  • Because the search goes one jump at a time, the first path found to a hole is also the shortest. That is the path the piece is shown moving along.

Step 5: The computer

A good measure of how well a player is doing is how far its pieces still have to go: every piece's distance to the tip of its goal, added up.

function distanceLeft(player, squares) {
    const tip = CORNERS[players[player].goal].tip;
    let sum = 0;
    HOLES.forEach(function (h) {
        if (squares.get(key(h)) === player) {
            sum += distance(h, tip);
        }
    });
    return sum;
}

function bestMove(player) {
    const before = distanceLeft(player, board);
    const goal = players[player].goal;
    const tip = CORNERS[goal].tip;
    let best = [];
    let bestScore = -Infinity;
    allMoves(player, board).forEach(function (move) {
        const after = moved(board, move);
        const gain = before - distanceLeft(player, after);
        let next = 0;
        allMoves(player, after).forEach(function (m) {
            next = Math.max(next, distance(m.from, tip) - distance(m.to, tip));
        });
        let score = gain + next * 0.5;
        // Bring up the pieces at the back, so none are left behind...
        score += distance(move.from, tip) * 0.05;
        // ...and don't leave the goal once there.
        if (cornerOf(move.from) === goal && cornerOf(move.to) !== goal) {
            score -= 5;
        }
        if (score > bestScore + 0.001) {
            bestScore = score;
            best = [move];
        } else if (Math.abs(score - bestScore) <= 0.001) {
            best.push(move);
        }
    });
    return best[Math.floor(Math.random() * best.length)];
}

The computer takes the move that brings that sum down the most. That alone is a greedy player, and it plays quite well, because the best moves in Chinese checkers are long chains of jumps. Three small extras help:

  • Each move also gets half the score of the best move it makes possible next time, so the computer likes moves that build a "ladder" for a long jump.
  • A little extra for moving pieces that are far behind, so none are left alone at home.
  • A minus for leaving the goal once there.

In tests, games with only computers always ended, after about 35 moves each. That is about as many as a good player needs.

Step 6: Moving, hop by hop

A long chain of jumps is hard to follow if the piece just appears at the end. So it moves along its path, one hop every 140 ms:

function play(move) {
    busy = true;
    selected = null;
    targets = new Map();
    let step = 0;
    const player = board.get(key(move.from));
    function hop() {
        board.set(key(move.path[step]), null);
        step++;
        board.set(key(move.path[step]), player);
        lastPath = move.path.slice(0, step + 1);
        draw();
        if (step < move.path.length - 1) {
            timer = setTimeout(hop, STEP_TIME);
        } else {
            busy = false;
            endTurn(player);
        }
    }
    hop();
}

hop calls itself with setTimeout until the piece is at the end of its path. While it moves, busy is true, so a click can't start another move.

Step 7: Drawing with SVG

SVG elements are made with createElementNS, as in the Compass. A small helper sets all the attributes at once:

function svgElement(name, attributes) {
    const element = document.createElementNS(SVG_NS, name);
    for (const a in attributes) {
        element.setAttribute(a, attributes[a]);
    }
    return element;
}

Every hole is a group with a dark circle, maybe a colored piece, and maybe a dot where the picked piece may go. The whole board is drawn again after every change. The points of the star where players start and end get their colors, faintly, with an alpha of 55 added to the color: #d32f2f55 is red that you can see through.

  <script>
    /*
     * Chinese Checkers: a star of 121 holes, ten pieces for each player in
     * one point of the star. Move all your pieces to the point on the other
     * side. A piece steps to an empty hole next to it, or jumps over a piece
     * next to it to the empty hole behind, again and again. Nothing is taken.
     *
     * The holes are on a hexagonal grid, so every hole has six neighbours.
     * A hole is written with "cube coordinates": three numbers q, r and s that
     * always add up to 0. The six steps to a neighbour are the six ways to add
     * 1 to one of them and take 1 from another. This makes neighbours,
     * distances and the shape of the star simple sums.
     */

    // --- Settings ------------------------------------------------------------

    const SQRT3 = Math.sqrt(3);
    const STEP_TIME = 140;        // ms for each hop of a moving piece
    const COMPUTER_DELAY = 350;   // ms before a computer moves

    // The six steps to a neighbour, as [q, r]. s is always -q - r.
    const DIRECTIONS = [[1, 0], [1, -1], [0, -1], [-1, 0], [-1, 1], [0, 1]];

    // The six points of the star, clockwise from the bottom. Each is where one
    // of the three numbers is more than 4 (or less than -4). "tip" is the hole
    // at the very end of the point.
    const CORNERS = [
        { name: "bottom", test: function (h) { return h.r > 4; }, tip: hole(-4, 8) },
        { name: "lower left", test: function (h) { return h.q < -4; }, tip: hole(-8, 4) },
        { name: "upper left", test: function (h) { return h.s > 4; }, tip: hole(-4, -4) },
        { name: "top", test: function (h) { return h.r < -4; }, tip: hole(4, -8) },
        { name: "upper right", test: function (h) { return h.q > 4; }, tip: hole(8, -4) },
        { name: "lower right", test: function (h) { return h.s < -4; }, tip: hole(4, 4) }
    ];

    const COLORS = [
        { name: "Red", fill: "#d32f2f" },
        { name: "Purple", fill: "#7b1fa2" },
        { name: "Blue", fill: "#1565c0" },
        { name: "Green", fill: "#2e7d32" },
        { name: "Yellow", fill: "#f9a825" },
        { name: "Orange", fill: "#ef6c00" }
    ];

    // Which points of the star are used, for 2, 3 and 6 players. Opposite
    // points are 3 apart: the bottom (0) plays against the top (3).
    const SEATS = { 2: [0, 3], 3: [0, 2, 4], 6: [0, 1, 2, 3, 4, 5] };

    // --- Elements on the page --------------------------------------------------

    const svg = document.getElementById("board");
    const statusText = document.getElementById("status");
    const restartButton = document.getElementById("restart");
    const playersSelect = document.getElementById("players");

    // --- Holes -----------------------------------------------------------------

    function hole(q, r) {
        return { q: q, r: r, s: -q - r };
    }

    function key(h) {
        return h.q + "," + h.r;
    }

    function add(h, [dq, dr], n) {
        return hole(h.q + dq * n, h.r + dr * n);
    }

    // The number of steps between two holes on a hexagonal grid.
    function distance(a, b) {
        return (Math.abs(a.q - b.q) + Math.abs(a.r - b.r) + Math.abs(a.s - b.s)) / 2;
    }

    // The star is two big triangles on top of each other: one where q, r and s
    // are all at least -4, and one where they are all at most 4.
    function inStar(h) {
        const up = h.q >= -4 && h.r >= -4 && h.s >= -4;
        const down = h.q <= 4 && h.r <= 4 && h.s <= 4;
        return up || down;
    }

    function cornerOf(h) {
        return CORNERS.findIndex(function (corner) { return corner.test(h); });
    }

    // Where a hole is drawn: the usual sums for a hexagonal grid.
    function pixel(h) {
        return { x: SQRT3 * (h.q + h.r / 2), y: 1.5 * h.r };
    }

    // All 121 holes.
    const HOLES = [];
    for (let q = -8; q <= 8; q++) {
        for (let r = -8; r <= 8; r++) {
            if (inStar(hole(q, r))) {
                HOLES.push(hole(q, r));
            }
        }
    }

    // --- State ---------------------------------------------------------------

    let board = new Map();   // key -> the number of the player there, or null
    let players = [];        // { corner, goal, color, human }
    let turn = 0;            // whose turn: a number in players
    let selected = null;     // the hole of the piece the human picked
    let targets = new Map(); // where it may go: key -> the path there
    let lastPath = null;     // the last move, drawn faintly
    let busy = false;        // a piece is moving, or a computer is thinking
    let winner = null;
    let timer = null;

    // --- Moves -----------------------------------------------------------------

    function onBoard(h) {
        return board.has(key(h));
    }

    // Every hole a piece can reach, with the path there. A step goes to an
    // empty neighbour. Jumps are found like water spreading: from every hole
    // the piece can jump to, look for more jumps, but never visit a hole twice.
    function reachable(from, squares) {
        const paths = new Map();
        const isFree = function (h) {
            return onBoard(h) && (squares.get(key(h)) === null || key(h) === key(from));
        };
        DIRECTIONS.forEach(function (direction) {
            const next = add(from, direction, 1);
            if (onBoard(next) && squares.get(key(next)) === null) {
                paths.set(key(next), [from, next]);
            }
        });
        const seen = new Set([key(from)]);
        const queue = [[from]];
        while (queue.length > 0) {
            const path = queue.shift();
            const at = path[path.length - 1];
            DIRECTIONS.forEach(function (direction) {
                const over = add(at, direction, 1);
                const land = add(at, direction, 2);
                const overPiece = onBoard(over) && squares.get(key(over)) !== null && key(over) !== key(from);
                if (overPiece && isFree(land) && !seen.has(key(land))) {
                    seen.add(key(land));
                    const longer = path.concat([land]);
                    if (!paths.has(key(land))) {
                        paths.set(key(land), longer);
                    }
                    queue.push(longer);
                }
            });
        }
        return paths;
    }

    // Every move a player can make: { from, to, path }.
    function allMoves(player, squares) {
        const moves = [];
        HOLES.forEach(function (h) {
            if (squares.get(key(h)) === player) {
                reachable(h, squares).forEach(function (path) {
                    moves.push({ from: h, to: path[path.length - 1], path: path });
                });
            }
        });
        return moves;
    }

    function hasWon(player, squares) {
        const goal = players[player].goal;
        return HOLES.every(function (h) {
            return cornerOf(h) !== goal || squares.get(key(h)) === player;
        });
    }

    // --- The computer ------------------------------------------------------------

    // How far a player's pieces still have to go: every piece's distance to the
    // tip of its goal, added up. Less is better.
    function distanceLeft(player, squares) {
        const tip = CORNERS[players[player].goal].tip;
        let sum = 0;
        HOLES.forEach(function (h) {
            if (squares.get(key(h)) === player) {
                sum += distance(h, tip);
            }
        });
        return sum;
    }

    function moved(squares, move) {
        const next = new Map(squares);
        next.set(key(move.to), next.get(key(move.from)));
        next.set(key(move.from), null);
        return next;
    }

    // The move that brings the pieces furthest. Each move is also given half
    // the score of the best move it makes possible next time, so the computer
    // likes moves that set up a long chain of jumps.
    function bestMove(player) {
        const before = distanceLeft(player, board);
        const goal = players[player].goal;
        const tip = CORNERS[goal].tip;
        let best = [];
        let bestScore = -Infinity;
        allMoves(player, board).forEach(function (move) {
            const after = moved(board, move);
            const gain = before - distanceLeft(player, after);
            let next = 0;
            allMoves(player, after).forEach(function (m) {
                next = Math.max(next, distance(m.from, tip) - distance(m.to, tip));
            });
            let score = gain + next * 0.5;
            // Bring up the pieces at the back, so none are left behind...
            score += distance(move.from, tip) * 0.05;
            // ...and don't leave the goal once there.
            if (cornerOf(move.from) === goal && cornerOf(move.to) !== goal) {
                score -= 5;
            }
            if (score > bestScore + 0.001) {
                bestScore = score;
                best = [move];
            } else if (Math.abs(score - bestScore) <= 0.001) {
                best.push(move);
            }
        });
        return best[Math.floor(Math.random() * best.length)];
    }

    // --- Playing ---------------------------------------------------------------

    // Move a piece along its path, one hop at a time, then end the turn.
    function play(move) {
        busy = true;
        selected = null;
        targets = new Map();
        let step = 0;
        const player = board.get(key(move.from));
        function hop() {
            board.set(key(move.path[step]), null);
            step++;
            board.set(key(move.path[step]), player);
            lastPath = move.path.slice(0, step + 1);
            draw();
            if (step < move.path.length - 1) {
                timer = setTimeout(hop, STEP_TIME);
            } else {
                busy = false;
                endTurn(player);
            }
        }
        hop();
    }

    function endTurn(player) {
        if (hasWon(player, board)) {
            winner = player;
            draw();
            return;
        }
        turn = (turn + 1) % players.length;
        draw();
        if (!players[turn].human) {
            busy = true;
            timer = setTimeout(function () {
                busy = false;
                play(bestMove(turn));
            }, COMPUTER_DELAY);
        }
    }

    function clickHole(h) {
        if (busy || winner !== null || !players[turn].human) {
            return;
        }
        const k = key(h);
        if (board.get(k) === turn) {
            selected = h;
            targets = reachable(h, board);
        } else if (targets.has(k)) {
            const path = targets.get(k);
            play({ from: selected, to: h, path: path });
            return;
        } else {
            selected = null;
            targets = new Map();
        }
        draw();
    }

    // --- Drawing -------------------------------------------------------------

    const SVG_NS = "http://www.w3.org/2000/svg";

    function svgElement(name, attributes) {
        const element = document.createElementNS(SVG_NS, name);
        for (const a in attributes) {
            element.setAttribute(a, attributes[a]);
        }
        return element;
    }

    // The wooden star: the two big triangles, a little bigger than the holes.
    function drawStar() {
        [[2, 4, 0], [3, 1, 5]].forEach(function (three) {
            const points = three.map(function (c) {
                const p = pixel(CORNERS[c].tip);
                return (p.x * 1.13) + "," + (p.y * 1.13);
            });
            svg.appendChild(svgElement("polygon", { points: points.join(" "), class: "star" }));
        });
    }

    function draw() {
        svg.innerHTML = "";
        drawStar();

        // The players' points of the star, faintly in their colors.
        const tint = {};
        players.forEach(function (p) {
            tint[p.corner] = p.color.fill;
            tint[p.goal] = tint[p.goal] || p.color.fill;
        });

        if (lastPath !== null && lastPath.length > 1) {
            const points = lastPath.map(function (h) { const p = pixel(h); return p.x + "," + p.y; });
            svg.appendChild(svgElement("polyline", { points: points.join(" "), class: "path" }));
        }

        HOLES.forEach(function (h) {
            const p = pixel(h);
            const group = svgElement("g", { class: "hole", "data-key": key(h) });
            const corner = cornerOf(h);
            group.appendChild(svgElement("circle", {
                cx: p.x, cy: p.y, r: 0.42, class: "pit",
                style: corner >= 0 && tint[corner] ? "fill: " + tint[corner] + "55" : ""
            }));
            const owner = board.get(key(h));
            if (owner !== null) {
                const piece = svgElement("circle", { cx: p.x, cy: p.y, r: 0.68, class: "piece", fill: players[owner].color.fill });
                if (selected !== null && key(selected) === key(h)) {
                    piece.classList.add("selected");
                }
                group.appendChild(piece);
            }
            if (targets.has(key(h))) {
                group.appendChild(svgElement("circle", { cx: p.x, cy: p.y, r: 0.3, class: "target" }));
            }
            group.addEventListener("click", function () { clickHole(h); });
            svg.appendChild(group);
        });

        const player = players[turn];
        if (winner !== null) {
            const w = players[winner];
            statusText.textContent = w.human && playersSelect.value !== "friend" ? "You win!" : w.color.name + " wins!";
        } else if (player.human) {
            statusText.textContent = playersSelect.value === "friend" ? player.color.name + "'s turn." : "Your turn: you are red.";
        } else {
            statusText.textContent = player.color.name + " is thinking...";
        }
    }

    // --- Starting --------------------------------------------------------------

    function newGame() {
        clearTimeout(timer);
        const choice = playersSelect.value;
        const seats = SEATS[choice === "friend" ? 2 : Number(choice)];
        players = seats.map(function (corner, i) {
            return {
                corner: corner,
                goal: (corner + 3) % 6,
                color: COLORS[corner],
                human: i === 0 || choice === "friend"
            };
        });
        board = new Map();
        HOLES.forEach(function (h) {
            const seat = players.findIndex(function (p) { return p.corner === cornerOf(h); });
            board.set(key(h), seat >= 0 ? seat : null);
        });
        turn = 0;
        selected = null;
        targets = new Map();
        lastPath = null;
        busy = false;
        winner = null;
        draw();
    }

    restartButton.addEventListener("click", newGame);
    playersSelect.addEventListener("change", newGame);

    newGame();
  </script>
</body>
