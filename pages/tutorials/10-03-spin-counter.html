Spin Counter

How many turns can you spin in 10 seconds? Hold your phone tight and spin round on the spot, or lay it flat on a smooth table and spin it. The phone counts every full turn and buzzes, and shows how fast you go. On a computer, you drag round the dial with the mouse.

Steady Hand used the gyroscope to feel a tiny tremble. Here it measures big, fast turns, and two new ideas make it work: adding up the turning speed to know how far the phone has turned, and using gravity to find out which way is "round", however you hold the phone.

Step 2: From speed to distance

The gyroscope doesn't say where the phone points. It says how fast it is turning, in degrees a second, with the devicemotion event, as event.rotationRate. To know how far it has turned, we add up:

degrees turned = degrees a second × seconds since the last reading

It is the same as driving: 60 km an hour for half an hour is 30 km. A reading comes about 60 times a second, and each one adds a small piece. Adding up a speed like this is called integration.

function onMotion(event) {
    const g = event.accelerationIncludingGravity;
    if (screen !== "spinning" && g && g.x !== null) {
        const size = Math.hypot(g.x, g.y, g.z);
        // Only while the phone is fairly still: then all it feels is gravity.
        if (size > 7 && size < 13) {
            axis = smoothAxis(g.x / size, g.y / size, g.z / size);
        }
    }

    const rate = event.rotationRate;
    if (!rate || rate.alpha === null || rate.beta === null || rate.gamma === null) {
        return;
    }
    gyroscope = true;
    if (lastMotion !== null) {
        const seconds = Math.min(0.1, (event.timeStamp - lastMotion) / 1000);
        if (seconds > 0) {
            const round = rate.beta * axis.x + rate.gamma * axis.y + rate.alpha * axis.z;
            turnBy(round * seconds);
        }
    }
    lastMotion = event.timeStamp;
}
  • event.timeStamp is when the reading was made, in milliseconds. The time since the last reading, in seconds, is what we multiply by.
  • If the page was in the background, the gap between two readings can be long. Math.min(0.1, ...) makes sure one old reading can't add a huge turn.
  • Many phone gyroscopes measure up to about 2000 degrees a second. That is more than five turns a second, faster than anyone can spin.

As in Steady Hand, iPhones ask for permission first, and only after a tap, so the Start button calls this before the round starts:

async function startSensor() {
    if (listening || !window.DeviceMotionEvent) {
        return;
    }
    if (typeof DeviceMotionEvent.requestPermission === "function") {
        try {
            if (await DeviceMotionEvent.requestPermission() !== "granted") {
                return;
            }
        } catch (error) {
            return;
        }
    }
    window.addEventListener("devicemotion", onMotion);
    listening = true;
}

Step 3: Which way is round?

rotationRate has three numbers, each one turning round one of the phone's own lines: alpha round the line straight out of the screen, beta round the line from left to right, and gamma round the line from bottom to top.

Which one is "spinning" depends on how you hold the phone. Spin round on the spot with the phone up in front of you, and it turns round its bottom-to-top line: gamma. Spin it flat on a table, and it turns round the line out of the screen: alpha. Hold it at an angle, and it is a bit of both.

What all three have in common: you spin round the line from up to down. And the phone can feel which way that is, because it feels gravity. event.accelerationIncludingGravity is what the accelerometer feels, and when the phone is still, that is only gravity, about 9.8 m/s² along the up and down line. Divided by its length, it is a line 1 long, the axis.

Then the spinning is this line in onMotion:

const round = rate.beta * axis.x + rate.gamma * axis.y + rate.alpha * axis.z;

This is called a dot product: multiply the matching parts and add them up. It takes the part of the turning that goes round the axis, and leaves the rest out. Held upright, the axis is about { x: 0, y: 1, z: 0 }, and round is just gamma. Flat on a table it is { x: 0, y: 0, z: 1 }, and round is alpha.

The axis is only measured while you are not spinning. A spinning phone feels much more than gravity: held out at arm's length, one turn a second pushes outwards more than twice as hard as gravity pulls down. That is why the countdown asks you to hold still, and why a reading that is far from 9.8 is skipped. The axis is also smoothed, as in the Bubble level, by moving a tenth of the way to each new reading:

function smoothAxis(x, y, z) {
    const nx = axis.x + (x - axis.x) * 0.1;
    const ny = axis.y + (y - axis.y) * 0.1;
    const nz = axis.z + (z - axis.z) * 0.1;
    const size = Math.hypot(nx, ny, nz) || 1;
    return { x: nx / size, y: ny / size, z: nz / size };
}

Step 4: Counting turns

Every bit of turning goes to turnBy. It turns the needle, and during the round it adds to spun, the degrees spun so far:

function turnBy(degrees) {
    heading += degrees;
    stepDegrees += degrees;
    if (screen !== "spinning") {
        return;
    }
    const before = Math.floor(Math.abs(spun) / 360);
    spun += degrees;
    if (Math.floor(Math.abs(spun) / 360) > before) {
        flash = 1;
        if (navigator.vibrate) {
            navigator.vibrate(20);
        }
    }
}
  • One way adds degrees and the other way takes them away. So turning back and forth adds up to nothing, and only real spinning counts.
  • The full turns are Math.floor(Math.abs(spun) / 360). When that number goes up, a short buzz tells you without looking at the screen, and the ring glows.

Step 5: The round

The game is in one of four screens: menu, countdown, spinning or done. First 3 seconds to hold still, then 10 to spin:

function update() {
    const seconds = STEP / 1000;
    speed += (stepDegrees / seconds - speed) * SMOOTHING;
    stepDegrees = 0;
    flash = Math.max(0, flash - 0.04);

    if (screen === "countdown") {
        clock += STEP;
        if (clock >= COUNTDOWN) {
            screen = "spinning";
            clock = 0;
            spun = 0;
            message.textContent = "Spin!";
            if (navigator.vibrate) {
                navigator.vibrate(150);
            }
        }
    } else if (screen === "spinning") {
        clock += STEP;
        topSpeed = Math.max(topSpeed, Math.abs(speed));
        if (listening && !gyroscope && spun === 0 && clock > NO_SENSOR_TIME) {
            message.textContent = "No gyroscope found. On a computer, drag round the dial with the mouse.";
        }
        if (clock >= SPIN_TIME) {
            finish();
        }
    }
}

The speed shown is smoothed too. Readings and updates don't come at exactly the same times, so in one update there may be two readings, and in the next none. Moving a tenth of the way each update evens that out. Speed is shown in RPM, revolutions (turns) per minute:

function rpm(degreesPerSecond) {
    return Math.round(Math.abs(degreesPerSecond) / 6);
}

When the time is up, the turns are compared with your best, which is saved in localStorage:

function finish() {
    screen = "done";
    const turns = Math.floor(Math.abs(spun) / 360);
    const newBest = turns > 0 && (best === null || turns > best);
    if (newBest) {
        best = turns;
        try {
            localStorage.setItem(BEST_KEY, String(best));
        } catch (error) {
            // Not saved, but the game still works.
        }
    }
    if (navigator.vibrate) {
        navigator.vibrate([60, 40, 60]);
    }
    startButton.disabled = false;
    startButton.textContent = "Spin again";
    message.textContent = turns + (turns === 1 ? " turn" : " turns") + " in 10 seconds, top speed " +
        rpm(topSpeed) + " RPM." + (newBest ? " A new best!" : "");
}

Step 6: Drawing the dial

The ring fills in gold as you go round, and starts again after every full turn:

// The ring, and in gold how far into the next turn you are. It fills
// the way you spin.
ctx.lineWidth = 18;
ctx.strokeStyle = "#33373e";
ctx.beginPath();
ctx.arc(DIAL.x, DIAL.y, DIAL.r, 0, Math.PI * 2);
ctx.stroke();
const part = (Math.abs(spun) % 360) / 360;
if (part > 0) {
    const top = -Math.PI / 2;
    ctx.strokeStyle = "#e8b455";
    ctx.beginPath();
    ctx.arc(DIAL.x, DIAL.y, DIAL.r, top, top + Math.sign(spun) * part * Math.PI * 2, spun < 0);
    ctx.stroke();
}
  • % is what is left after dividing: 900 degrees is 2 full turns and 180 left, so the ring is half full.
  • On a canvas, angle 0 points right, so the ring starts at -Math.PI / 2, the top, like a clock.
  • The last argument of arc draws the other way round. So the ring fills the way you spin.

The needle is drawn pointing straight up, but first the canvas is turned by heading, so it turns as you spin:

// The needle turns as you spin.
ctx.save();
ctx.translate(DIAL.x, DIAL.y);
ctx.rotate(heading * Math.PI / 180);
ctx.fillStyle = "#e05a47";
ctx.beginPath();
ctx.moveTo(0, -(DIAL.r - 38));
ctx.lineTo(9, -50);
ctx.lineTo(-9, -50);
ctx.closePath();
ctx.fill();
ctx.restore();

Step 7: On a computer

A computer has no gyroscope, so you drag round the dial instead. Math.atan2 gives the angle of the mouse round the middle of the dial:

function pointerAngle(event) {
    const box = canvas.getBoundingClientRect();
    const x = (event.clientX - box.left - canvas.clientLeft) * WIDTH / canvas.clientWidth - DIAL.x;
    const y = (event.clientY - box.top - canvas.clientTop) * HEIGHT / canvas.clientHeight - DIAL.y;
    if (Math.hypot(x, y) < 30) {
        return null;
    }
    return Math.atan2(y, x) * 180 / Math.PI;
}

The canvas may be drawn smaller than its 360 pixels, on a phone, so the mouse position is scaled to canvas pixels first. clientLeft and clientTop are the width of the frame round the canvas. Close to the middle, a tiny move would be a big change in angle, so there it gives null.

canvas.addEventListener("pointermove", function (event) {
    if (gyroscope || !dragging) {
        return;
    }
    const angle = pointerAngle(event);
    if (angle !== null && dragAngle !== null) {
        let change = angle - dragAngle;
        // From 170 to -170 is 20 degrees on, not 340 back.
        if (change > 180) {
            change -= 360;
        } else if (change < -180) {
            change += 360;
        }
        turnBy(change);
    }
    dragAngle = angle;
});

The change in angle goes to the same turnBy as the gyroscope. atan2 jumps from 180 to -180 on the left side of the dial, so a change of more than half a turn is really a small step over that line.

Step 8: Test it

You can test the counting without getting dizzy, by calling onMotion yourself in the browser's console with made-up readings: 60 still readings with gravity along y, as if the phone is held upright, then screen = "spinning" and 150 readings of 360 degrees a second round y, 1/60 second apart. That is 2.5 seconds at one turn a second, so the dial should show 2 turns and a half full ring. It does.

  • Spin round on the spot holding the phone upright, and count the turns yourself. The buzzes should match.
  • Do the same with the phone flat on a table. It should count just as well.
  • Turn the phone back and forth. The count should stay at 0.
  • Reload the page. Your best should still be there.
  • On a computer, drag round the dial with the mouse.

  <script>
    /*
     * Spin Counter: how many turns can you spin in 10 seconds? Hold the phone
     * tight and spin round on the spot, or spin it flat on a smooth table.
     *
     * The gyroscope measures how fast the phone turns, in degrees a second. Its
     * numbers come with the "devicemotion" event, as event.rotationRate. Degrees
     * a second times seconds is degrees, so adding them up tells how far the
     * phone has turned. Which way is "round" depends on how you hold the phone,
     * so the game first finds the line from up to down, from gravity, and only
     * counts turning round that line.
     *
     * On a computer, which has no gyroscope, dragging round the dial does the same.
     */

    // --- Settings ------------------------------------------------------------

    const STEP = 1000 / 60;      // one update, in ms
    const SPIN_TIME = 10000;     // ms to spin
    const COUNTDOWN = 3000;      // ms of "3, 2, 1" to hold still first
    const SMOOTHING = 0.1;       // how fast the speed shown follows the real speed
    const NO_SENSOR_TIME = 1500; // ms without a gyroscope reading before we say there is none
    const BEST_KEY = "spin-counter-best";

    // --- Canvas --------------------------------------------------------------

    const canvas = document.getElementById("gameCanvas");
    const ctx = canvas.getContext("2d");
    const WIDTH = canvas.width;
    const HEIGHT = canvas.height;
    const message = document.getElementById("message");
    const startButton = document.getElementById("start");

    // The dial, in pixels.
    const DIAL = { x: WIDTH / 2, y: 225, r: 130 };

    // --- State ---------------------------------------------------------------

    let screen = "menu";         // menu, countdown, spinning, done
    let clock = 0;               // ms into the countdown or the spin
    let heading = 0;             // where the needle points, in degrees
    let spun = 0;                // degrees spun this round: + one way, - the other
    let stepDegrees = 0;         // degrees turned since the last update
    let speed = 0;               // degrees a second, smoothed
    let topSpeed = 0;            // the fastest this round
    let flash = 0;               // the ring glows for a moment after every full turn
    let best = loadBest();
    let axis = { x: 0, y: 0, z: 1 };   // the line from up to down, seen from the phone
    let lastMotion = null;       // the time of the last gyroscope reading
    let gyroscope = false;       // has a real gyroscope sent anything?
    let listening = false;
    let dragging = false;        // is the mouse button down on the dial?
    let dragAngle = null;        // where the mouse is round the dial

    // --- The gyroscope -------------------------------------------------------

    // rotationRate has three numbers, each round one of the phone's own lines:
    // alpha round z (straight out of the screen), beta round x (left to right),
    // and gamma round y (bottom to top). Spinning round on the spot, holding
    // the phone up in front of you, turns it round y. Spinning it flat on a
    // table turns it round z. To count both, and anything in between, we take
    // the part of the turning that goes round the up and down line.
    function onMotion(event) {
        const g = event.accelerationIncludingGravity;
        if (screen !== "spinning" && g && g.x !== null) {
            const size = Math.hypot(g.x, g.y, g.z);
            // Only while the phone is fairly still: then all it feels is gravity.
            if (size > 7 && size < 13) {
                axis = smoothAxis(g.x / size, g.y / size, g.z / size);
            }
        }

        const rate = event.rotationRate;
        if (!rate || rate.alpha === null || rate.beta === null || rate.gamma === null) {
            return;
        }
        gyroscope = true;
        if (lastMotion !== null) {
            const seconds = Math.min(0.1, (event.timeStamp - lastMotion) / 1000);
            if (seconds > 0) {
                const round = rate.beta * axis.x + rate.gamma * axis.y + rate.alpha * axis.z;
                turnBy(round * seconds);
            }
        }
        lastMotion = event.timeStamp;
    }

    // Move the axis a tenth of the way to the new reading, and keep it 1 long.
    function smoothAxis(x, y, z) {
        const nx = axis.x + (x - axis.x) * 0.1;
        const ny = axis.y + (y - axis.y) * 0.1;
        const nz = axis.z + (z - axis.z) * 0.1;
        const size = Math.hypot(nx, ny, nz) || 1;
        return { x: nx / size, y: ny / size, z: nz / size };
    }

    // iPhones ask first, and only after a tap.
    async function startSensor() {
        if (listening || !window.DeviceMotionEvent) {
            return;
        }
        if (typeof DeviceMotionEvent.requestPermission === "function") {
            try {
                if (await DeviceMotionEvent.requestPermission() !== "granted") {
                    return;
                }
            } catch (error) {
                return;
            }
        }
        window.addEventListener("devicemotion", onMotion);
        listening = true;
    }

    // --- Counting turns ------------------------------------------------------

    function turnBy(degrees) {
        heading += degrees;
        stepDegrees += degrees;
        if (screen !== "spinning") {
            return;
        }
        const before = Math.floor(Math.abs(spun) / 360);
        spun += degrees;
        if (Math.floor(Math.abs(spun) / 360) > before) {
            flash = 1;
            if (navigator.vibrate) {
                navigator.vibrate(20);
            }
        }
    }

    // --- The mouse, on a computer --------------------------------------------

    // The angle of the pointer round the middle of the dial, in degrees, or
    // null when it is too close to the middle to tell.
    function pointerAngle(event) {
        const box = canvas.getBoundingClientRect();
        const x = (event.clientX - box.left - canvas.clientLeft) * WIDTH / canvas.clientWidth - DIAL.x;
        const y = (event.clientY - box.top - canvas.clientTop) * HEIGHT / canvas.clientHeight - DIAL.y;
        if (Math.hypot(x, y) < 30) {
            return null;
        }
        return Math.atan2(y, x) * 180 / Math.PI;
    }

    canvas.addEventListener("pointerdown", function (event) {
        if (gyroscope) {
            return;
        }
        canvas.setPointerCapture(event.pointerId);
        dragging = true;
        dragAngle = pointerAngle(event);
    });

    canvas.addEventListener("pointermove", function (event) {
        if (gyroscope || !dragging) {
            return;
        }
        const angle = pointerAngle(event);
        if (angle !== null && dragAngle !== null) {
            let change = angle - dragAngle;
            // From 170 to -170 is 20 degrees on, not 340 back.
            if (change > 180) {
                change -= 360;
            } else if (change < -180) {
                change += 360;
            }
            turnBy(change);
        }
        dragAngle = angle;
    });

    ["pointerup", "pointercancel"].forEach(function (name) {
        canvas.addEventListener(name, function () {
            dragging = false;
        });
    });
    // --- The game ------------------------------------------------------------

    function startRound() {
        screen = "countdown";
        clock = 0;
        spun = 0;
        topSpeed = 0;
        startButton.disabled = true;
        message.textContent = "Hold still...";
    }

    function update() {
        const seconds = STEP / 1000;
        speed += (stepDegrees / seconds - speed) * SMOOTHING;
        stepDegrees = 0;
        flash = Math.max(0, flash - 0.04);

        if (screen === "countdown") {
            clock += STEP;
            if (clock >= COUNTDOWN) {
                screen = "spinning";
                clock = 0;
                spun = 0;
                message.textContent = "Spin!";
                if (navigator.vibrate) {
                    navigator.vibrate(150);
                }
            }
        } else if (screen === "spinning") {
            clock += STEP;
            topSpeed = Math.max(topSpeed, Math.abs(speed));
            if (listening && !gyroscope && spun === 0 && clock > NO_SENSOR_TIME) {
                message.textContent = "No gyroscope found. On a computer, drag round the dial with the mouse.";
            }
            if (clock >= SPIN_TIME) {
                finish();
            }
        }
    }

    function finish() {
        screen = "done";
        const turns = Math.floor(Math.abs(spun) / 360);
        const newBest = turns > 0 && (best === null || turns > best);
        if (newBest) {
            best = turns;
            try {
                localStorage.setItem(BEST_KEY, String(best));
            } catch (error) {
                // Not saved, but the game still works.
            }
        }
        if (navigator.vibrate) {
            navigator.vibrate([60, 40, 60]);
        }
        startButton.disabled = false;
        startButton.textContent = "Spin again";
        message.textContent = turns + (turns === 1 ? " turn" : " turns") + " in 10 seconds, top speed " +
            rpm(topSpeed) + " RPM." + (newBest ? " A new best!" : "");
    }

    // Degrees a second to turns a minute: 360 degrees a second is 60 RPM.
    function rpm(degreesPerSecond) {
        return Math.round(Math.abs(degreesPerSecond) / 6);
    }

    function loadBest() {
        try {
            const saved = Number(localStorage.getItem(BEST_KEY));
            return saved > 0 ? saved : null;
        } catch (error) {
            return null;
        }
    }

    // --- Drawing -------------------------------------------------------------

    function draw() {
        ctx.fillStyle = "#1b1d21";
        ctx.fillRect(0, 0, WIDTH, HEIGHT);

        // The ring, and in gold how far into the next turn you are. It fills
        // the way you spin.
        ctx.lineWidth = 18;
        ctx.strokeStyle = "#33373e";
        ctx.beginPath();
        ctx.arc(DIAL.x, DIAL.y, DIAL.r, 0, Math.PI * 2);
        ctx.stroke();
        const part = (Math.abs(spun) % 360) / 360;
        if (part > 0) {
            const top = -Math.PI / 2;
            ctx.strokeStyle = "#e8b455";
            ctx.beginPath();
            ctx.arc(DIAL.x, DIAL.y, DIAL.r, top, top + Math.sign(spun) * part * Math.PI * 2, spun < 0);
            ctx.stroke();
        }
        // A glow after every full turn.
        if (flash > 0) {
            ctx.strokeStyle = "rgba(232, 180, 85, " + flash + ")";
            ctx.lineWidth = 6;
            ctx.beginPath();
            ctx.arc(DIAL.x, DIAL.y, DIAL.r + 16 + (1 - flash) * 12, 0, Math.PI * 2);
            ctx.stroke();
        }

        // Twelve ticks, like a clock.
        ctx.strokeStyle = "#5c616b";
        ctx.lineWidth = 3;
        for (let i = 0; i < 12; i++) {
            const a = i * Math.PI / 6;
            ctx.beginPath();
            ctx.moveTo(DIAL.x + Math.cos(a) * (DIAL.r - 22), DIAL.y + Math.sin(a) * (DIAL.r - 22));
            ctx.lineTo(DIAL.x + Math.cos(a) * (DIAL.r - 32), DIAL.y + Math.sin(a) * (DIAL.r - 32));
            ctx.stroke();
        }

        // The needle turns as you spin.
        ctx.save();
        ctx.translate(DIAL.x, DIAL.y);
        ctx.rotate(heading * Math.PI / 180);
        ctx.fillStyle = "#e05a47";
        ctx.beginPath();
        ctx.moveTo(0, -(DIAL.r - 38));
        ctx.lineTo(9, -50);
        ctx.lineTo(-9, -50);
        ctx.closePath();
        ctx.fill();
        ctx.restore();

        // The hub: the countdown, or the turns.
        ctx.fillStyle = "#2a2e35";
        ctx.beginPath();
        ctx.arc(DIAL.x, DIAL.y, 52, 0, Math.PI * 2);
        ctx.fill();
        ctx.textAlign = "center";
        ctx.textBaseline = "middle";
        if (screen === "countdown") {
            ctx.fillStyle = "#e8b455";
            ctx.font = "bold 48px Arial";
            ctx.fillText(String(Math.ceil((COUNTDOWN - clock) / 1000)), DIAL.x, DIAL.y);
        } else {
            const turns = Math.floor(Math.abs(spun) / 360);
            ctx.fillStyle = "#ffffff";
            ctx.font = "bold 44px Arial";
            ctx.fillText(String(turns), DIAL.x, DIAL.y - 6);
            ctx.font = "13px Arial";
            ctx.fillStyle = "#9aa0a8";
            ctx.fillText(turns === 1 ? "turn" : "turns", DIAL.x, DIAL.y + 26);
        }

        // The speed under the dial.
        ctx.fillStyle = "#ffffff";
        ctx.font = "bold 22px Arial";
        ctx.fillText(rpm(speed) + " RPM", DIAL.x, DIAL.y + DIAL.r + 42);

        // Time left, as a bar.
        let left = 1;
        if (screen === "spinning") {
            left = 1 - clock / SPIN_TIME;
        } else if (screen === "done") {
            left = 0;
        }
        ctx.fillStyle = "#33373e";
        ctx.fillRect(30, HEIGHT - 34, WIDTH - 60, 12);
        ctx.fillStyle = "#e8b455";
        ctx.fillRect(30, HEIGHT - 34, (WIDTH - 60) * left, 12);

        // Best at the top.
        ctx.textBaseline = "alphabetic";
        ctx.fillStyle = "#9aa0a8";
        ctx.font = "bold 16px Arial";
        ctx.textAlign = "left";
        ctx.fillText(screen === "spinning" ? ((SPIN_TIME - clock) / 1000).toFixed(1) + " s" : "", 14, 28);
        ctx.textAlign = "right";
        ctx.fillText(best ? "Best: " + best + (best === 1 ? " turn" : " turns") : "", WIDTH - 14, 28);
    }

    // --- The loop ------------------------------------------------------------

    let lastTime = performance.now();
    let leftover = 0;

    function gameLoop(now) {
        leftover += Math.min(now - lastTime, 250);
        lastTime = now;
        while (leftover >= STEP) {
            update();
            leftover -= STEP;
        }
        draw();
        requestAnimationFrame(gameLoop);
    }

    // --- Start ---------------------------------------------------------------

    startButton.addEventListener("click", async function () {
        await startSensor();
        startRound();
    });

    requestAnimationFrame(gameLoop);
  </script>
