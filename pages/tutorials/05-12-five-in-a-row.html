Five in a Row

Two players, black and white, take turns placing a stone where the lines cross on a 15 by 15 board. The first to get five or more in a row, across, down or diagonally, wins. The game is also called Gomoku, and in Sweden luffarschack, where it is played with X and O on squared paper. 15 by 15 is the standard board.

It is Tic Tac Toe on a big board, and the check for a row is the same as in Connect Four, just with five. The new parts are drawing a board where the stones go on the lines, not in the squares, and a computer for a board too big to look ahead on.

Step 2: Stones on the lines

In Connect Four every piece sat in a square. Here the stones go where the lines cross. The trick: make a grid of 15 by 15 points as usual, and let every point draw a short line across and a short line down through its middle. Side by side, the short lines join up into the board's lines, and they cross exactly in the middle of each point, where the stone goes.

.point {

    aspect-ratio: 1;
    display: flex;
    align-items: center;
    justify-content: center;
    cursor: pointer;
}

.point::before,
.point::after {
    content: "";
    position: absolute;
    background-color: #5a4320;
}

/* The line across... */
.point::before {
    top: 50%;
    left: 0;
    right: 0;
    height: 1px;
}

/* ...and the line down. */
.point::after {
    left: 50%;
    top: 0;
    bottom: 0;
    width: 1px;
}

::before and ::after are two extra boxes CSS can add to any element, without any HTML. With content: "" they are empty, and position: absolute places them inside the point.

At the edge of the board, the lines must stop in the middle of the point, not go on to its edge. nth-child finds the points at the edges by their place among the 225:

.point:nth-child(15n + 1)::before { left: 50%; }
.point:nth-child(15n)::before { right: 50%; }
.point:nth-child(-n + 15)::after { top: 50%; }
.point:nth-last-child(-n + 15)::after { bottom: 50%; }

15n + 1 is 1, 16, 31...: the first point of every row, the left edge. 15n is 15, 30, 45...: the right edge. -n + 15 is 15, 14, 13... down to 1: the top row. nth-last-child counts from the end instead, so nth-last-child(-n + 15) is the bottom row.

The five small dots, like on a Go board, are a radial-gradient that is dark in the very middle of the point:

.point.star {
    background-image: radial-gradient(circle, #5a4320 0 14%, transparent 16%);
}

Step 4: Five in a row

This is the check from Connect Four. lineFrom walks from a point in one direction as long as the stones are the same color. findWin looks both ways in each of the four directions:

function findWin(row, col, who) {
    for (const [dRow, dCol] of DIRECTIONS) {
        // Look both ways from the new stone.
        const line = [[row, col]]
            .concat(lineFrom(row, col, dRow, dCol, who))
            .concat(lineFrom(row, col, -dRow, -dCol, who));
        if (line.length >= WIN) {
            return line;
        }
    }
    return null;
}

One change: lineFrom and findWin now get who, the color to look for, instead of reading it from the board. Then the computer can ask "would a black stone here make five?" for a point that is still empty.

Step 5: Where to look

The board has 225 points. A stone far away from all the others does nothing, so the computer only looks at free points near a stone:

function candidates(distance) {
    const list = [];
    for (let row = 0; row < SIZE; row++) {
        for (let col = 0; col < SIZE; col++) {
            if (grid[row][col] === 0 && hasNeighbor(row, col, distance)) {
                list.push([row, col]);
            }
        }
    }
    // The first stone goes in the middle.
    return list.length > 0 ? list : [[7, 7]];
}

Step 6: The easy computer

function easyMove() {
    const choices = candidates(1);
    const win = choices.find(function ([r, c]) { return findWin(r, c, COMPUTER); });
    if (win) {
        return win;
    }
    const block = choices.find(function ([r, c]) { return findWin(r, c, HUMAN); });
    if (block) {
        return block;
    }
    return randomItem(choices);
}

The same three rules as the easy computer in Connect Four vs computer: win if you can, block if the human is about to win, otherwise play somewhere next to a stone. It only sees a five when it is one move away, so it is easy to beat with a row of three that is open at both ends.

Step 7: Open ends

In Connect Four the hard computer looked five moves ahead with minimax. Here there are often 50 or more points to choose from, so five moves ahead would be hundreds of millions of boards. Instead the hard computer gives every point a score, and the secret is in the ends of a line.

Four in a row with both ends free can't be stopped: block one end, and the other player plays the other. Four with one end blocked is only a threat that you must answer. And a line blocked at both ends can never become five, so it is worth nothing:

function lineScore(length, openEnds) {
    if (length >= WIN) {
        return 100000;
    }
    if (openEnds === 0) {
        return 0;                // blocked at both ends, it can never be five
    }
    const scores = {
        4: [1000, 10000],        // four: one open end, two open ends
        3: [100, 1000],
        2: [10, 100],
        1: [1, 10]
    };
    return scores[length][openEnds - 1];
}

An open three scores the same as a closed four: both force the other player to answer.

Step 8: Scoring a point

function scorePoint(row, col, who) {
    let score = 0;
    for (const [dRow, dCol] of DIRECTIONS) {
        const forward = lineFrom(row, col, dRow, dCol, who);
        const back = lineFrom(row, col, -dRow, -dCol, who);
        const length = 1 + forward.length + back.length;
        // An end is open if the point after the line is free.
        const openEnds = isOpen(row + (forward.length + 1) * dRow, col + (forward.length + 1) * dCol)
            + isOpen(row - (back.length + 1) * dRow, col - (back.length + 1) * dCol);
        score += lineScore(length, openEnds);
    }
    return score;
}

For each direction: imagine a stone on the point, count the line it would be part of, and look at the point just past each end. isOpen gives 1 or 0, so adding them up gives 0, 1 or 2 open ends. A point that makes two open threes at once gets 2000, more than one open three. That is a "fork", and it usually wins.

A good point is good for two reasons: the lines it makes for the computer, and the lines it takes away from the human. So the hard computer scores each point both ways:

// Making your own lines is a little better than stopping theirs,
// so a win always comes before a block.
const score = scorePoint(row, col, COMPUTER) + 0.9 * scorePoint(row, col, HUMAN);

If several points get the same score, it picks one of them at random, so it doesn't play the same game every time. Every move takes about a millisecond. In tests, the hard computer beat the easy one in every game.

Step 9: Test it

  • Make an open three against the easy computer, and win.
  • Try the same against the hard computer: it blocks it.
  • Make four with one end blocked, and see the computer block the other end.
  • Get five in a row at the edge of the board and in a corner.
  • Get six in a row by filling the gap between a two and a three. It should count.
  • Press New game while the computer is thinking.

  <script>
    /*
     * Five in a Row (Gomoku, or luffarschack in Swedish): two players take turns
     * placing a stone on a free point of a 15 x 15 board. Black starts. The
     * first to get five or more of their stones in a row, across, down or
     * diagonally, wins.
     *
     * White can be played by the computer:
     *
     *   Easy: wins if it can, blocks you if you are about to get five,
     *         otherwise plays next to a stone that is already there.
     *   Hard: gives every free point a score for the lines it would make for
     *         itself, and the lines it would stop for you, and picks the best.
     */

    // --- Settings ------------------------------------------------------------

    const SIZE = 15;              // the board is 15 by 15 points
    const WIN = 5;                // stones in a row to win
    const NAMES = { 1: "Black", 2: "White" };
    const HUMAN = 1;
    const COMPUTER = 2;
    const COMPUTER_DELAY = 500;   // ms before the computer moves

    // The four directions a line can go. The other four are the same, backwards.
    const DIRECTIONS = [
        [0, 1],   // across
        [1, 0],   // down
        [1, 1],   // diagonal \
        [1, -1]   // diagonal /
    ];

    // The small dots on the board, as on a Go board.
    const STAR_POINTS = ["3,3", "3,11", "7,7", "11,3", "11,11"];

    // --- Elements on the page ------------------------------------------------

    const boardElement = document.getElementById("board");
    const statusText = document.getElementById("status");
    const restartButton = document.getElementById("restart");
    const modeSelect = document.getElementById("mode");

    // --- State ---------------------------------------------------------------

    let grid = [];          // grid[row][col]: 0 = empty, 1 = black, 2 = white
    let points = [];        // points[row][col]: the <div> for each point
    let player = 1;         // whose turn it is
    let moves = 0;
    let lastMove = null;    // [row, col] of the last stone, to mark it
    let gameOver = false;
    let computerTimer = null;

    // --- The board -----------------------------------------------------------

    function newGame() {
        // A computer move that is waiting to happen belongs to the old game.
        clearTimeout(computerTimer);

        grid = [];
        points = [];
        boardElement.innerHTML = "";
        for (let row = 0; row < SIZE; row++) {
            grid.push([]);
            points.push([]);
            for (let col = 0; col < SIZE; col++) {
                const point = document.createElement("div");
                point.className = "point";
                if (STAR_POINTS.includes(row + "," + col)) {
                    point.classList.add("star");
                }
                point.addEventListener("click", function () {
                    if (!isComputersTurn()) {
                        play(row, col);
                    }
                });
                boardElement.appendChild(point);
                grid[row].push(0);
                points[row].push(point);
            }
        }

        player = 1;
        moves = 0;
        lastMove = null;
        gameOver = false;
        showTurn();
    }

    function isInside(row, col) {
        return row >= 0 && row < SIZE && col >= 0 && col < SIZE;
    }

    function isComputersTurn() {
        return modeSelect.value !== "pvp" && player === COMPUTER;
    }

    function showTurn() {
        if (isComputersTurn()) {
            statusText.textContent = NAMES[player] + " is thinking...";
        } else {
            statusText.textContent = NAMES[player] + "'s turn.";
        }
    }

    // --- Five in a row -------------------------------------------------------

    // The stones of the same color in a line from (row, col), one step at a
    // time in the direction (dRow, dCol), not counting the start.
    function lineFrom(row, col, dRow, dCol, who) {
        const line = [];
        let r = row + dRow;
        let c = col + dCol;
        while (isInside(r, c) && grid[r][c] === who) {
            line.push([r, c]);
            r += dRow;
            c += dCol;
        }
        return line;
    }

    // Does a stone of "who" at (row, col) make five or more in a row? Returns
    // the stones in the row, or null.
    function findWin(row, col, who) {
        for (const [dRow, dCol] of DIRECTIONS) {
            // Look both ways from the new stone.
            const line = [[row, col]]
                .concat(lineFrom(row, col, dRow, dCol, who))
                .concat(lineFrom(row, col, -dRow, -dCol, who));
            if (line.length >= WIN) {
                return line;
            }
        }
        return null;
    }

    // --- Playing -------------------------------------------------------------

    function play(row, col) {
        if (gameOver || grid[row][col] !== 0) {
            return;
        }
        grid[row][col] = player;
        moves++;

        // Draw the stone, and move the "last move" mark to it.
        if (lastMove) {
            points[lastMove[0]][lastMove[1]].firstChild.classList.remove("last");
        }
        const stone = document.createElement("div");
        stone.className = "stone " + (player === 1 ? "black" : "white") + " last";
        points[row][col].appendChild(stone);
        lastMove = [row, col];

        const line = findWin(row, col, player);
        if (line) {
            line.forEach(function ([r, c]) {
                points[r][c].firstChild.classList.add("winning");
            });
            gameOver = true;
            statusText.textContent = NAMES[player] + " wins!";
        } else if (moves === SIZE * SIZE) {
            gameOver = true;
            statusText.textContent = "The board is full. It's a draw!";
        } else {
            player = player === 1 ? 2 : 1;
            showTurn();
            if (isComputersTurn()) {
                computerTimer = setTimeout(computerMove, COMPUTER_DELAY);
            }
        }
    }

    // --- The computer --------------------------------------------------------

    function computerMove() {
        const [row, col] = modeSelect.value === "easy" ? easyMove() : hardMove();
        play(row, col);
    }

    // The free points within "distance" of a stone. Far away from all stones a
    // move does nothing, so there is no need to look there.
    function candidates(distance) {
        const list = [];
        for (let row = 0; row < SIZE; row++) {
            for (let col = 0; col < SIZE; col++) {
                if (grid[row][col] === 0 && hasNeighbor(row, col, distance)) {
                    list.push([row, col]);
                }
            }
        }
        // The first stone goes in the middle.
        return list.length > 0 ? list : [[7, 7]];
    }

    function hasNeighbor(row, col, distance) {
        for (let r = row - distance; r <= row + distance; r++) {
            for (let c = col - distance; c <= col + distance; c++) {
                if (isInside(r, c) && grid[r][c] !== 0) {
                    return true;
                }
            }
        }
        return false;
    }

    function randomItem(list) {
        return list[Math.floor(Math.random() * list.length)];
    }

    function easyMove() {
        const choices = candidates(1);
        const win = choices.find(function ([r, c]) { return findWin(r, c, COMPUTER); });
        if (win) {
            return win;
        }
        const block = choices.find(function ([r, c]) { return findWin(r, c, HUMAN); });
        if (block) {
            return block;
        }
        return randomItem(choices);
    }

    function hardMove() {
        let best = [];
        let bestScore = -Infinity;
        candidates(2).forEach(function ([row, col]) {
            // Making your own lines is a little better than stopping theirs,
            // so a win always comes before a block.
            const score = scorePoint(row, col, COMPUTER) + 0.9 * scorePoint(row, col, HUMAN);
            if (score > bestScore) {
                bestScore = score;
                best = [[row, col]];
            } else if (score === bestScore) {
                best.push([row, col]);
            }
        });
        return randomItem(best);
    }

    // How good a stone of "who" at the free point (row, col) would be: the sum
    // of the lines it makes in the four directions.
    function scorePoint(row, col, who) {
        let score = 0;
        for (const [dRow, dCol] of DIRECTIONS) {
            const forward = lineFrom(row, col, dRow, dCol, who);
            const back = lineFrom(row, col, -dRow, -dCol, who);
            const length = 1 + forward.length + back.length;
            // An end is open if the point after the line is free.
            const openEnds = isOpen(row + (forward.length + 1) * dRow, col + (forward.length + 1) * dCol)
                + isOpen(row - (back.length + 1) * dRow, col - (back.length + 1) * dCol);
            score += lineScore(length, openEnds);
        }
        return score;
    }

    function isOpen(row, col) {
        return isInside(row, col) && grid[row][col] === 0 ? 1 : 0;
    }

    // A line with both ends open is much stronger than one with one end open:
    // the other player can only block one end at a time.
    function lineScore(length, openEnds) {
        if (length >= WIN) {
            return 100000;
        }
        if (openEnds === 0) {
            return 0;                // blocked at both ends, it can never be five
        }
        const scores = {
            4: [1000, 10000],        // four: one open end, two open ends
            3: [100, 1000],
            2: [10, 100],
            1: [1, 10]
        };
        return scores[length][openEnds - 1];
    }

    // --- Connect the page ----------------------------------------------------

    restartButton.addEventListener("click", newGame);
    modeSelect.addEventListener("change", newGame);

    newGame();
  </script>
</body>

Try this

  • Lines with a gap, like two stones, a free point and two more, are just as dangerous as four. Teach scorePoint to see them.
  • Black has an advantage from playing first. In the game Renju, black may not make two open threes at once. Add that rule.
  • Play with X and O on squared paper instead, like luffarschack: the stones in the squares, as in Tic Tac Toe.
  • Let the hard computer look two moves ahead: for its best few points, what is the human's best answer?
