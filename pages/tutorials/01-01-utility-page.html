Building a utility page

In these tutorials we build small tools, like a calculator and a color picker. Each tool is one HTML file, with a little CSS and the JavaScript inside it. You don't need a server or a framework. You make a file and open it in your browser.

This first tutorial shows the shape every tool has, by building a very small one: a word counter.

Open the finished word counter

What you need

  • A text editor.
  • A browser with developer tools. Press F12 to open them. The Console tab shows errors from your JavaScript, and you can type JavaScript there to try things out.

The skeleton

Every tool starts from this skeleton. Create a file called word-counter.html and paste it in:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Word counter</title>
  <style>
    /* CSS goes here */
  </style>
</head>
<body>
  <!-- HTML goes here -->

  <script>
    // JavaScript goes here
  </script>
</body>
</html>

What the parts do:

  • <!DOCTYPE html> tells the browser this is a modern HTML page.
  • <meta charset="utf-8"> makes characters like åäö and emojis show up correctly.
  • <meta name="viewport" ...> makes the page fit the screen on a phone.
  • <style> holds the CSS, which decides how things look.
  • The <script> is the last thing in the body. A script runs as soon as the browser reaches it, so when it comes after the HTML, every element on the page already exists when our code looks for it. If the script were at the top, getElementById() would find nothing.

Open the file in your browser by double-clicking it, or by dragging it into a browser window. After every change, save and reload the page with F5.

Step 1: The HTML

Put this in the body, where the comment says "HTML goes here":

<h1>Word counter</h1>

<label for="text">Text</label>
<textarea id="text"></textarea>

<p>Words: <span id="count">0</span></p>

Every element the script needs gets an id, and an id must be unique on the page. The for on a label points to the id of its text box, so clicking the label puts the cursor in the box.

Step 2: The CSS

Keep the CSS small. This makes the page readable and stops the text box from being tiny:

body {
    font-family: sans-serif;
    max-width: 800px;
    margin: 40px auto;
    padding: 0 16px;
}

label {
    display: block;
    margin-top: 16px;
}

textarea {
    width: 100%;
    height: 120px;
    box-sizing: border-box;
}

max-width and margin: 40px auto keep the text in a column in the middle of the screen. box-sizing: border-box makes width: 100% include the border, so the box doesn't stick out on the right.

Step 3: The JavaScript

All the scripts in these tutorials follow the same order, with a comment line before each part. Once you know the order, it is easy to find your way in any of them.

  1. A comment at the top that explains what the tool does.
  2. Elements on the page: find the elements with document.getElementById() and keep them in constants.
  3. Helpers: small functions that only do calculations. They don't touch the page, so they are easy to test in the console.
  4. What the page does: functions that read from the page, use the helpers and write the answer back.
  5. Connect the page: addEventListener() tells the browser which function to run when something happens.
  6. Start: anything that should run once when the page loads.
/*
 * Word counter: count the words in a text while you type.
 */

// --- Elements on the page ------------------------------------------------

const textInput = document.getElementById("text");
const countText = document.getElementById("count");

// --- Helpers -------------------------------------------------------------

// "hello  big world " -> 3
function countWords(text) {
    // trim() removes spaces at the start and end. split(/\s+/) splits on
    // one or more spaces, tabs or new lines.
    const words = text.trim().split(/\s+/);

    // "".split() gives [""], one empty word, so handle that on its own.
    if (words[0] === "") {
        return 0;
    }
    return words.length;
}

// --- What the page does --------------------------------------------------

function update() {
    countText.textContent = countWords(textInput.value);
}

// --- Connect the page ----------------------------------------------------

// "input" fires on every change: typing, pasting, deleting...
textInput.addEventListener("input", update);

Some things to notice:

  • textInput.value is what is typed in a form field. For other elements we use textContent.
  • We pass the function update to addEventListener without brackets. With brackets, update() would run once right away, and the browser would get its return value instead of the function.
  • We write text with textContent, not innerHTML. textContent always shows text as text, so nothing the user types can turn into HTML on the page.

Step 4: Test it

Reload the page. Type a few words, then try an empty box, only spaces, and text over several lines. If nothing happens, look in the Console tab for a red error. The most common one is Cannot read properties of null. It means getElementById didn't find the element, usually because the id in the HTML and in the script are spelled differently.

You can also call the helpers directly in the console:

countWords("  one two\nthree ")   // 3
