Data size converter

We build a data size converter. It converts between bit, byte, KB, MB, GB and TB, with either 1000 or 1024 as the step. You can type in either box, and the other one updates while you type.

Open the finished data size converter

The idea: convert through one base unit

With six units there are 30 pairs, like KB to MB or bit to GB. Writing a rule for every pair would be long and easy to get wrong. Instead we turn every value into bits first, and then turn the bits into the unit we want. That needs one rule per unit:

1 bit  = 1 bit
1 byte = 8 bits
1 KB   = 8 x 1000 bits        (or 8 x 1024)
1 MB   = 8 x 1000 x 1000 bits (or 8 x 1024 x 1024)
...

The pattern is 8 x base to the power of the number of steps from byte: KB is 1 step, MB is 2, GB is 3 and TB is 4. The same idea works for any unit converter: lengths go through metres, and times through seconds.

The script starts by finding the elements:

const leftValue = document.getElementById("input-field");

Step 2: How many bits in a unit

An object works as a lookup table. steps["MB"] gives 2:

const steps = {
    byte: 0,
    KB: 1,
    MB: 2,
    GB: 3,
    TB: 4
};

function bitsIn(unit) {
    if (unit === "bit") {
        return 1;
    }
    const base = baseSelect.value === "binary" ? 1024 : 1000;
    return 8 * base ** steps[unit];
}

a ? b : c is a short if/else: if a is true the answer is b, otherwise c. ** means "to the power of", so 1000 ** 2 is a million. Try bitsIn("KB") in the console. It should give 8000.

Step 3: Convert

function convert(value, fromUnit, toUnit) {
    const bits = value * bitsIn(fromUnit);
    return bits / bitsIn(toUnit);
}

Step 4: Hide floating point noise

Computers store decimal numbers in binary, and most decimals can't be stored exactly. That is why 0.1 + 0.2 gives 0.30000000000000004 in JavaScript, and in almost every other language too. toPrecision(12) rounds to 12 significant digits, and Number() turns the result back into a number, which drops trailing zeros:

function tidy(number) {
    return Number(number.toPrecision(12));
}

We round to significant digits instead of decimals, so very small numbers like 0.000000125 don't round to 0.

Step 5: Update the other box

Both boxes work the same way, so we write one function that takes which value and unit to read from, and which to write to. Then each direction is one short line:

function update(fromValue, fromUnit, toValue, toUnit) {
    const value = Number(fromValue.value);

    if (fromValue.value === "" || isNaN(value)) {
        toValue.value = "";
        return;
    }

    toValue.value = tidy(convert(value, fromUnit.value, toUnit.value));
}

function updateRight() {
    update(leftValue, leftUnit, rightValue, rightUnit);
}

function updateLeft() {
    update(rightValue, rightUnit, leftValue, leftUnit);
}

Number("abc") gives NaN, "not a number", and isNaN() checks for it. We also check for the empty string, because Number("") is 0, and an empty box should give an empty answer, not 0.

Step 6: Connect the page

A text box fires "input" on every change. A select fires "change" when you pick something new.

leftValue.addEventListener("input", updateRight);
rightValue.addEventListener("input", updateLeft);

leftUnit.addEventListener("change", updateRight);
rightUnit.addEventListener("change", updateRight);
baseSelect.addEventListener("change", updateRight);

When a unit or the base changes, we keep the left value and recalculate the right one.

Step 7: Test it

  • 1 KB to bit: 8000 with decimal, 8192 with binary.
  • Type 16384 in the right box with bit to KB and binary: the left box shows 2.
  • 1 bit to TB: 1.25e-13. JavaScript writes very small and very big numbers like this. It means 1.25 times 10 to the power of -13.
  • Type abc: the other box is cleared.

  <script>
    /*
     * Data size converter: bit, byte, KB, MB, GB and TB.
     *
     * The trick: turn every value into bits first, then from bits into the
     * unit we want. That way we need one rule per unit instead of one rule
     * for every pair of units.
     *
     *   1 byte = 8 bits
     *   1 KB   = 1000 bytes (decimal) or 1024 bytes (binary)
     *   1 MB   = 1000 KB or 1024 KB, and so on.
     *
     * You can type in either field; the other one is updated.
     */

    // --- Elements on the page ------------------------------------------------

    const leftUnit = document.getElementById("input-select");
    const leftValue = document.getElementById("input-field");
    const rightUnit = document.getElementById("output-select");
    const rightValue = document.getElementById("output-field");
    const baseSelect = document.getElementById("base-select");

    // --- Helpers -------------------------------------------------------------

    // How many times we multiply by 1000 (or 1024) to get from bytes to the unit.
    const steps = {
        byte: 0,
        KB: 1,
        MB: 2,
        GB: 3,
        TB: 4
    };

    // How many bits there are in one of the unit, e.g. "KB" -> 8000.
    function bitsIn(unit) {
        if (unit === "bit") {
            return 1;
        }
        const base = baseSelect.value === "binary" ? 1024 : 1000;
        return 8 * base ** steps[unit];  // "**" means "to the power of"
    }

    function convert(value, fromUnit, toUnit) {
        const bits = value * bitsIn(fromUnit);
        return bits / bitsIn(toUnit);
    }

    // Hide floating point noise like 0.30000000000000004,
    // but keep very small and very large numbers.
    function tidy(number) {
        return Number(number.toPrecision(12));
    }

    // Read the value in one field, convert it, and write it into the other.
    function update(fromValue, fromUnit, toValue, toUnit) {
        const value = Number(fromValue.value);

        if (fromValue.value === "" || isNaN(value)) {
            toValue.value = "";
            return;
        }

        toValue.value = tidy(convert(value, fromUnit.value, toUnit.value));
    }

    function updateRight() {
        update(leftValue, leftUnit, rightValue, rightUnit);
    }

    function updateLeft() {
        update(rightValue, rightUnit, leftValue, leftUnit);
    }

    // --- Connect the page ----------------------------------------------------

    // "input" fires on every change: typing, pasting, deleting...
    leftValue.addEventListener("input", updateRight);
    rightValue.addEventListener("input", updateLeft);

    // Changing a unit or the base keeps the left value and recalculates the right.
    leftUnit.addEventListener("change", updateRight);
    rightUnit.addEventListener("change", updateRight);
    baseSelect.addEventListener("change", updateRight);
  </script>
</body>
</html>
