Minesweeper

Some squares on the field hide a mine. Dig up all the other squares to win. When you dig a square, a number tells how many mines there are in the 8 squares around it, and from the numbers you can work out where the mines are. Flag a square where you think there is a mine, so you don't dig it by mistake.

The field is a grid of buttons, like Tic Tac Toe on a bigger board. The new parts are looking at all the neighbors of a square, opening a whole empty area at once (a flood fill), the right mouse button, a timer, and drawing a flag and a mine with CSS only.

The field starts empty: the code makes one button for every square. There are three sizes:

const LEVELS = {

About one square in six to eight is a mine. The classic expert field is 30 squares wide, but that doesn't fit on a phone, so the biggest here is 16 by 16.

The number of columns changes with the size, so the CSS gets it from a CSS variable, --cols. The code sets it when a game starts:

    // The CSS makes this many columns, and sizes the numbers to fit.
    boardElement.style.setProperty("--cols", level.cols);

repeat(var(--cols), 1fr) then makes that many columns of the same width. The numbers must fit in a square, small or big. container-type: inline-size on the board lets everything inside it measure the board: 100cqw is the board's width. Divided by the number of columns, that is the width of one square, and the numbers are 60% of it.

Each square is an object that knows if it has a mine, if it is open (dug up), if it has a flag, its count of mines around it, and its button. Every other square gets the class light: when row + col is even. That gives a checker pattern, like a lawn that has been mowed in stripes.

Step 4: The neighbors

// The squares around (row, col): up to 8 of them, fewer at the edges.
function neighbors(row, col) {
    const list = [];
    for (let r = row - 1; r <= row + 1; r++) {
        for (let c = col - 1; c <= col + 1; c++) {
            if ((r !== row || c !== col) && r >= 0 && r < level.rows && c >= 0 && c < level.cols) {
                list.push(grid[r][c]);
            }
        }
    }
    return list;
}

The squares around a square are one row up, the same row and one row down, and one column left, the same and one right: 9 squares, minus the square itself. At the edges some of them are outside the field, so the if leaves those out. A square in a corner has only 3 neighbors.

Step 5: The mines

// Put the mines anywhere but on the first square dug or next to it, and
// count the mines around every square.
function placeMines(safeRow, safeCol) {
    const safe = neighbors(safeRow, safeCol).concat([grid[safeRow][safeCol]]);
    const places = grid.flat().filter(function (square) {
        return !safe.includes(square);
    });
    for (let i = 0; i < level.mines; i++) {
        const index = Math.floor(Math.random() * places.length);
        places[index].mine = true;
        places.splice(index, 1);   // so no square gets two mines
    }
    for (let row = 0; row < level.rows; row++) {
        for (let col = 0; col < level.cols; col++) {
            grid[row][col].count = neighbors(row, col).filter(function (square) {
                return square.mine;
            }).length;
        }
    }
    minesPlaced = true;
}

Nothing is more annoying than losing on the very first click. So the mines are placed after the first dig, and never on that square or next to it. That square then has no mines around it, and always opens up a bit of the field.

places is every square where a mine may go. Pick one at random, give it a mine, and take it out of the list with splice, so it can't be picked again. Then every square counts the mines around it, with neighbors and filter.

Step 6: Digging

function dig(row, col) {
    const square = grid[row][col];
    if (square.flag || square.open) {
        return;
    }
    if (!minesPlaced) {
        placeMines(row, col);
        startTimer();
        statusText.textContent = "";
    }
    if (square.mine) {
        lose(square);
        return;
    }
    openFrom(row, col);
    if (opened === level.rows * level.cols - level.mines) {
        win();
    }
}

A flagged square can't be dug. The first dig places the mines and starts the clock. A mine ends the game. Otherwise the square opens, and when the number of open squares is the number of squares without a mine, the field is cleared.

Step 7: Opening an empty area

A square with no mines around it shows nothing. All its neighbors are safe, so the game opens them for you. And if one of those has no mines around it either, its neighbors open too, and so on. This is called a flood fill, like paint flowing out until it hits the numbers around the edge.

// Open a square. If there are no mines around it, its neighbors are safe
// too, so open them, and go on from every neighbor that is also a 0. A list
// of squares still to open keeps track, instead of a function calling itself.
function openFrom(row, col) {
    const todo = [[row, col]];
    while (todo.length > 0) {
        const [r, c] = todo.pop();
        const square = grid[r][c];
        if (square.open || square.flag) {
            continue;
        }
        square.open = true;
        opened++;
        showSquare(square);
        if (square.count === 0) {
            for (let nr = r - 1; nr <= r + 1; nr++) {
                for (let nc = c - 1; nc <= c + 1; nc++) {
                    if (nr >= 0 && nr < level.rows && nc >= 0 && nc < level.cols && !grid[nr][nc].open) {
                        todo.push([nr, nc]);
                    }
                }
            }
        }
    }
}

todo is a list of squares still to open. Take one off with pop, open it, and if its count is 0, put all its neighbors on the list. The continue at the top skips a square that is already open, so every square is only opened once, and the loop ends when the list is empty.

It could also be written as a function that calls itself for every neighbor. But on a big empty field that is thousands of calls inside each other, and the browser can run out of room for them. A list can be as long as it needs to be.

Step 8: Flags and the right mouse button

            button.addEventListener("contextmenu", function (event) {
                event.preventDefault();   // no browser menu on a right-click
                toggleFlag(row, col);
            });

A right-click sends a contextmenu event, because it normally opens the browser's menu. preventDefault() stops the menu, and the square gets a flag instead.

A phone has no right button. So there is a button above the field that switches between Dig and Flag, and every click looks at it:

function clickSquare(row, col) {
    const square = grid[row][col];
    if (gameOver) {
        return;
    }
    if (square.open) {
        openAround(row, col);
    } else if (flagTool) {
        toggleFlag(row, col);
    } else {
        dig(row, col);
    }
}

The button has aria-pressed, set to true or false by the code. That tells a screen reader that it is a switch, and if it is on.

Step 9: Opening around a number

// A click on a number with as many flags around it as its number digs all
// the other squares around it. (If a flag is wrong, that digs up a mine.)
function openAround(row, col) {
    const square = grid[row][col];
    const around = neighbors(row, col);
    const flagged = around.filter(function (s) { return s.flag; }).length;
    if (square.count === 0 || flagged !== square.count) {
        return;
    }
    for (let r = row - 1; r <= row + 1; r++) {
        for (let c = col - 1; c <= col + 1; c++) {
            if (r >= 0 && r < level.rows && c >= 0 && c < level.cols && !gameOver) {
                dig(r, c);
            }
        }
    }
}

When you have flagged all the mines around a number, the other squares around it are safe. Clicking the number digs them all at once. That saves a lot of clicks. But if one of the flags was wrong, it digs up a mine, so it has to be used with care.

Step 10: Winning and losing

function win() {
    gameOver = true;
    clearInterval(timer);
    // Every mine left is now known: flag them all.
    grid.flat().forEach(function (square) {
        if (square.mine && !square.flag) {
            square.flag = true;
            flags++;
            showSquare(square);
        }
    });
    showCounters();
    ...
}

function lose(hit) {
    gameOver = true;
    clearInterval(timer);
    hit.boom = true;
    // Show every mine, and the flags that were wrong.
    grid.flat().forEach(function (square) {
        if (square.mine || square.flag) {
            square.shown = true;
            showSquare(square);
        }
    });
    ...
}

When you win, every mine left must be where you didn't dig, so the game flags them for you, and the field turns gold. When you lose, every mine is shown, the one you dug is red, and a flag where there was no mine is crossed out, so you can see what went wrong.

function startTimer() {
    clearInterval(timer);
    timer = setInterval(function () {
        seconds++;
        showCounters();
    }, 1000);
}

setInterval calls the function again and again, once a second, until clearInterval stops it: when you win, when you lose, and when a new game starts.

Step 11: A flag and a mine in CSS

The flag and the mine are not pictures. Each square has two pseudo-elements, ::before and ::after, and they are enough:

.cell.flag::before {
    content: "";
    position: absolute;
    left: 36%;
    top: 18%;
    width: 7%;
    height: 64%;
    background-color: #3b2a1a;
}

.cell.flag::after {
    content: "";
    position: absolute;
    left: 42%;
    top: 18%;
    border-left: calc(100cqw / var(--cols) * 0.32) solid #d93a3a;
    border-top: calc(100cqw / var(--cols) * 0.16) solid transparent;
    border-bottom: calc(100cqw / var(--cols) * 0.16) solid transparent;
}

.cell.mine::before {
    content: "";
    position: absolute;
    inset: 24%;
    border-radius: 50%;
    background-image: radial-gradient(circle at 35% 35%, #888888, #111111 60%);
    box-shadow: 0 0 0 2px rgba(17, 17, 17, 0.25);
}
  • The pole is a thin dark box.
  • The flag is a CSS triangle: a box with no size, and thick borders. Where two borders meet they are cut at an angle. Make the top and bottom borders transparent and the left one red, and only a red triangle pointing right is left.
  • The mine is a circle with a radial-gradient, light up to the left and dark at the edge, so it looks like a ball.

Their sizes are in percent, or in the same 100cqw / var(--cols) as the numbers, so they fit squares of every size.

Step 12: Test it

  • Dig anywhere. The first dig should always open an area.
  • Check a few numbers by counting the mines around them when you lose.
  • Flag with a right-click, and with the Dig / Flag button.
  • Flag all the mines around a number and click the number.
  • Win a game. Every mine should get a flag, and the clock should stop.
  • Put a flag where there is no mine, and lose. The flag should be crossed out.
  • Try the hard size on a narrow window. The numbers should get smaller with the squares.

    /*
     * Minesweeper: some squares hide a mine. Dig up all the other squares to
     * win. A number tells how many mines there are in the 8 squares around it.
     *
     *   - The mines are placed after the first dig, never on it or next to it,
     *     so the first dig always opens up a bit of the field.
     *   - Squares with no mines around them open their neighbors by themselves.
     *   - Flag a square with a right-click, or with the Dig / Flag button.
     *   - Click a number with as many flags around it as its number, and all
     *     the other squares around it are dug.
     */

    // --- Settings ------------------------------------------------------------

    const LEVELS = {
        easy: { rows: 9, cols: 9, mines: 10 },
        medium: { rows: 12, cols: 12, mines: 25 },
        hard: { rows: 16, cols: 16, mines: 40 }
    };

    // --- Elements on the page ------------------------------------------------

    const boardElement = document.getElementById("board");
    const minesLeftText = document.getElementById("mines-left");
    const timeText = document.getElementById("time");
    const statusText = document.getElementById("status");
    const toolButton = document.getElementById("tool");
    const levelSelect = document.getElementById("level");
    const restartButton = document.getElementById("restart");

    // --- State ---------------------------------------------------------------

    let level = LEVELS.easy;
    let grid = [];          // grid[row][col]: { mine, open, flag, count, button }
    let minesPlaced = false;
    let gameOver = false;
    let flags = 0;
    let opened = 0;         // squares dug up so far
    let flagTool = false;   // true when a click flags instead of digs
    let seconds = 0;
    let timer = null;

    // --- The field -----------------------------------------------------------

    function newGame() {
        clearInterval(timer);
        level = LEVELS[levelSelect.value];
        grid = [];
        minesPlaced = false;
        gameOver = false;
        flags = 0;
        opened = 0;
        seconds = 0;
        boardElement.innerHTML = "";
        // The CSS makes this many columns, and sizes the numbers to fit.
        boardElement.style.setProperty("--cols", level.cols);
        boardElement.classList.remove("won", "lost");

        for (let row = 0; row < level.rows; row++) {
            grid.push([]);
            for (let col = 0; col < level.cols; col++) {
                const button = document.createElement("button");
                button.type = "button";
                // A checker pattern, like a lawn that has been mowed.
                button.className = "cell" + ((row + col) % 2 === 0 ? " light" : "");
                button.addEventListener("click", function () {
                    clickSquare(row, col);
                });
                button.addEventListener("contextmenu", function (event) {
                    event.preventDefault();   // no browser menu on a right-click
                    toggleFlag(row, col);
                });
                boardElement.appendChild(button);
                grid[row].push({ mine: false, open: false, flag: false, count: 0, button: button });
            }
        }
        statusText.textContent = "Dig anywhere to start.";
        showCounters();
    }

    // The squares around (row, col): up to 8 of them, fewer at the edges.
    function neighbors(row, col) {
        const list = [];
        for (let r = row - 1; r <= row + 1; r++) {
            for (let c = col - 1; c <= col + 1; c++) {
                if ((r !== row || c !== col) && r >= 0 && r < level.rows && c >= 0 && c < level.cols) {
                    list.push(grid[r][c]);
                }
            }
        }
        return list;
    }

    // Put the mines anywhere but on the first square dug or next to it, and
    // count the mines around every square.
    function placeMines(safeRow, safeCol) {
        const safe = neighbors(safeRow, safeCol).concat([grid[safeRow][safeCol]]);
        const places = grid.flat().filter(function (square) {
            return !safe.includes(square);
        });
        for (let i = 0; i < level.mines; i++) {
            const index = Math.floor(Math.random() * places.length);
            places[index].mine = true;
            places.splice(index, 1);   // so no square gets two mines
        }
        for (let row = 0; row < level.rows; row++) {
            for (let col = 0; col < level.cols; col++) {
                grid[row][col].count = neighbors(row, col).filter(function (square) {
                    return square.mine;
                }).length;
            }
        }
        minesPlaced = true;
    }

    // --- Playing -------------------------------------------------------------

    function clickSquare(row, col) {
        const square = grid[row][col];
        if (gameOver) {
            return;
        }
        if (square.open) {
            openAround(row, col);
        } else if (flagTool) {
            toggleFlag(row, col);
        } else {
            dig(row, col);
        }
    }

    function dig(row, col) {
        const square = grid[row][col];
        if (square.flag || square.open) {
            return;
        }
        if (!minesPlaced) {
            placeMines(row, col);
            startTimer();
            statusText.textContent = "";
        }
        if (square.mine) {
            lose(square);
            return;
        }
        openFrom(row, col);
        if (opened === level.rows * level.cols - level.mines) {
            win();
        }
    }

    // Open a square. If there are no mines around it, its neighbors are safe
    // too, so open them, and go on from every neighbor that is also a 0. A list
    // of squares still to open keeps track, instead of a function calling itself.
    function openFrom(row, col) {
        const todo = [[row, col]];
        while (todo.length > 0) {
            const [r, c] = todo.pop();
            const square = grid[r][c];
            if (square.open || square.flag) {
                continue;
            }
            square.open = true;
            opened++;
            showSquare(square);
            if (square.count === 0) {
                for (let nr = r - 1; nr <= r + 1; nr++) {
                    for (let nc = c - 1; nc <= c + 1; nc++) {
                        if (nr >= 0 && nr < level.rows && nc >= 0 && nc < level.cols && !grid[nr][nc].open) {
                            todo.push([nr, nc]);
                        }
                    }
                }
            }
        }
    }

    // A click on a number with as many flags around it as its number digs all
    // the other squares around it. (If a flag is wrong, that digs up a mine.)
    function openAround(row, col) {
        const square = grid[row][col];
        const around = neighbors(row, col);
        const flagged = around.filter(function (s) { return s.flag; }).length;
        if (square.count === 0 || flagged !== square.count) {
            return;
        }
        for (let r = row - 1; r <= row + 1; r++) {
            for (let c = col - 1; c <= col + 1; c++) {
                if (r >= 0 && r < level.rows && c >= 0 && c < level.cols && !gameOver) {
                    dig(r, c);
                }
            }
        }
    }

    function toggleFlag(row, col) {
        const square = grid[row][col];
        if (gameOver || square.open) {
            return;
        }
        square.flag = !square.flag;
        flags += square.flag ? 1 : -1;
        showSquare(square);
        showCounters();
    }

    function setTool(flag) {
        flagTool = flag;
        toolButton.textContent = flag ? "Flag" : "Dig";
        toolButton.setAttribute("aria-pressed", flag);
        toolButton.classList.toggle("flag", flag);
    }

    // --- Winning and losing --------------------------------------------------

    function win() {
        gameOver = true;
        clearInterval(timer);
        // Every mine left is now known: flag them all.
        grid.flat().forEach(function (square) {
            if (square.mine && !square.flag) {
                square.flag = true;
                flags++;
                showSquare(square);
            }
        });
        showCounters();
        boardElement.classList.add("won");
        statusText.textContent = "You cleared the field in " + seconds + " seconds!";
    }

    function lose(hit) {
        gameOver = true;
        clearInterval(timer);
        hit.boom = true;
        // Show every mine, and the flags that were wrong.
        grid.flat().forEach(function (square) {
            if (square.mine || square.flag) {
                square.shown = true;
                showSquare(square);
            }
        });
        boardElement.classList.add("lost");
        statusText.textContent = "Boom! You dug up a mine.";
    }

    // --- Showing -------------------------------------------------------------

    function showSquare(square) {
        const button = square.button;
        button.classList.remove("flag", "mine", "boom", "wrong");
        button.textContent = "";
        if (square.open) {
            button.classList.add("open");
            if (square.count > 0) {
                button.textContent = square.count;
                button.classList.add("n" + square.count);
            }
            button.setAttribute("aria-label", square.count > 0 ? square.count + " mines around" : "empty");
        } else if (square.shown && square.mine && !square.flag) {
            button.classList.add("mine");
            if (square.boom) {
                button.classList.add("boom");
            }
            button.setAttribute("aria-label", "mine");
        } else if (square.flag) {
            button.classList.add("flag");
            if (square.shown && !square.mine) {
                button.classList.add("wrong");   // a flag where there was no mine
            }
            button.setAttribute("aria-label", "flag");
        } else {
            button.setAttribute("aria-label", "hidden");
        }
    }

    function showCounters() {
        minesLeftText.textContent = level.mines - flags;
        timeText.textContent = seconds;
    }

    function startTimer() {
        clearInterval(timer);
        timer = setInterval(function () {
            seconds++;
            showCounters();
        }, 1000);
    }

    // --- Connect the page ----------------------------------------------------

    toolButton.addEventListener("click", function () {
        setTool(!flagTool);
    });
    levelSelect.addEventListener("change", newGame);
    restartButton.addEventListener("click", newGame);

    newGame();
  </script>
</body>
</html>
