Eliza

ELIZA was written by Joseph Weizenbaum at MIT between 1964 and 1966. It was one of the first programs you could have a conversation with. Running a script called DOCTOR, it acts like a therapist who turns what you say back into questions:

> MEN ARE ALL ALIKE.
IN WHAT WAY
> THEY'RE ALWAYS BUGGING US ABOUT SOMETHING OR OTHER.
CAN YOU THINK OF A SPECIFIC EXAMPLE
> WELL, MY BOYFRIEND MADE ME COME HERE.
YOUR BOYFRIEND MADE YOU COME HERE

The program doesn't understand anything. It looks for keywords, matches simple patterns and rearranges your words. This tutorial builds it the way Weizenbaum described it in his 1966 paper, running his original DOCTOR script. It is the biggest tutorial in the series, but each part is small.

Open the finished page

The three parts

  1. The script: the DOCTOR rules, written as text, exactly as published in 1966.
  2. The program: reads the script and uses it to answer. It knows nothing about therapy. With another script it would be another character.
  3. The page: shows the conversation and sends what you type to the program.

Step 2: The script

The script is written as nested lists in brackets, the style of the Lisp language. Here are three entries:

(SORRY ((0) (PLEASE DON'T APOLIGIZE)
    (APOLOGIES ARE NOT NECESSARY) (WHAT FEELINGS
    DO YOU HAVE WHEN YOU APOLOGIZE) (I'VE TOLD YOU
    THAT APOLOGIES ARE NOT REQUIRED)))
(DONT = DON'T)
(REMEMBER 5
    ((0 YOU REMEMBER 0) (DO YOU OFTEN THINK OF 4)
        (DOES THINKING OF 4 BRING ANYTHING ELSE TO MIND)
        ...)

Each entry starts with a word:

  • (DONT = DON'T) only swaps a word. That is also how I becomes YOU and MY becomes YOUR.
  • (REMEMBER 5 ...) is a keyword with rank 5. A higher rank wins when a sentence has several keywords.
  • After that come rules. Each rule is a pattern, followed by answers to use in turn.

In a pattern, 0 means "any number of words" and other numbers mean "exactly that many words". Patterns are matched after the words have been swapped. So if you type I remember my dog, ELIZA matches YOU REMEMBER YOUR DOG, and (0 YOU REMEMBER 0) gives these parts:

part 1:              (0, here no words)
part 2: YOU
part 3: REMEMBER
part 4: YOUR DOG     (0)

In an answer, a number puts that part back in, so (DO YOU OFTEN THINK OF 4) becomes DO YOU OFTEN THINK OF YOUR DOG.

A few special forms:

  • (*WANT NEED) matches one of the listed words.
  • (/FAMILY) matches any word tagged FAMILY, like MOTHER or FATHER.
  • The answer (=WHAT) means "use the rules of WHAT instead".
  • (NEWKEY) means "try the next keyword".

The whole script is a text in doctor.js, inside backticks so it can span many lines:

const DOCTOR_SCRIPT = `
(HOW DO YOU DO.  PLEASE TELL ME YOUR PROBLEM)

START

(SORRY ((0) (PLEASE DON'T APOLIGIZE)
...
`;

"APOLIGIZE" is a typo in the original 1966 script. We keep it as it was. The script is in a .js file and not a .txt file, because browsers don't let fetch read local files from a page opened from disk.

Step 3: Reading the lists

First we turn the text into JavaScript arrays. We put spaces around each bracket and split on spaces, so every bracket and word becomes a token:

"(DONT = DON'T)"  ->  ["(", "DONT", "=", "DON'T", ")"]

Then readOne() reads one item. If the token is a word, it is the item. If it is (, the item is a list, and readOne() calls itself to read each thing inside, until it reaches ). A function that calls itself is called recursive. It is the natural way to read lists inside lists, however deep they go.

function readOne() {
    const token = tokens[pos];
    pos++;

    if (token === ")") {
        throw new Error('ELIZA script: unexpected ")"');
    }
    if (token !== "(") {
        return token;
    }
    const list = [];
    while (tokens[pos] !== ")") {
        if (pos >= tokens.length) {
            throw new Error('ELIZA script: missing ")"');
        }
        list.push(readOne());
    }
    pos++; // skip the ")"
    return list;
}

pos is shared by every call, so each call goes on from where the last one stopped. Try it in the console:

readLists("(A (B C) D)")   // [["A", ["B", "C"], "D"]]

Step 4: Understanding the entries

parsePattern() turns a pattern list into objects that are easy to match:

0        { any: true }                    any number of words
2        { count: 2 }                     exactly 2 words
YOU      { word: "YOU" }                  this word
(* A B)  { alternatives: ["A", "B"] }     one of these words
(/FAM)   { tags: ["FAM"] }                a word tagged FAM

parseEntry() reads one keyword. It takes the parts that are there, = SUBSTITUTE, a rank and DLIST(/TAGS), in order, and moves i forward past each one. Everything after that is rules. Each rule remembers next, the answer to use next time:

entry.rules.push({
    pattern: parsePattern(isLink ? ["0"] : rule[0]),
    answers: isLink ? [rule] : rule.slice(1),
    next: 0
});

parseScript() puts it together. The first list is the greeting, and the keywords go into an object, so entries["SORRY"] finds an entry right away.

Step 5: Matching a pattern

This is the heart of ELIZA. The hard part is 0, because we don't know how many words it should take. In (0 YOU ARE 0) the first 0 must take exactly the words before YOU ARE, and we only know how many when the rest of the pattern has matched.

The solution is to try. Give the 0 no words, and see if the rest matches. If not, give it one word, then two, and so on. When something doesn't fit, we go back and try the next choice. This is called backtracking.

function matchFrom(p, w) {
    if (p === pattern.length) {
        return w === words.length; // done only if all words are used
    }
    const part = pattern[p];

    if (part.any) {
        for (let n = 0; w + n <= words.length; n++) {
            parts[p] = words.slice(w, w + n);
            if (matchFrom(p + 1, w + n)) {
                return true;
            }
        }
        return false;
    }
    ...
}

p is the position in the pattern and w the position in the words. When the whole pattern is used up, it was a match only if all the words were used too. The other kinds of part are simpler. count takes exactly that many words, and the rest match exactly one word. Each part's words are saved in parts, so the answer can use them.

match([{any:true}, {word:"YOU"}, {word:"ARE"}, {any:true}], ["I","THINK","YOU","ARE","NICE"], tagsOf)
// [["I","THINK"], ["YOU"], ["ARE"], ["NICE"]]

Step 6: Building the answer

reassemble() goes through the answer. Words are copied, and numbers are replaced with that part of the match. ... spreads an array into separate items, so push adds each word:

function reassemble(answer, parts) {
    const words = [];
    for (const atom of answer) {
        if (/^\d+$/.test(atom)) {
            words.push(...(parts[Number(atom) - 1] || []));
        } else {
            words.push(atom);
        }
    }
    return words;
}

Step 7: Responding

respond() follows Weizenbaum's steps:

  1. Make the input upper case and turn punctuation into words of its own.
  2. Read the words. Swap words that have a substitute, like MY to YOUR. Put keywords on the keystack: one with a higher rank than the top goes first, the others go last.
  3. A comma, period or BUT ends the sentence if a keyword has been found. If not, the words so far are thrown away, so ELIZA answers the part of what you said that has a keyword in it.
  4. Try the top keyword's rules with transform(). The first rule whose pattern matches gives the answer. Then next moves on, so the same rule gives a different answer next time.
  5. If a rule says (=KEY), try KEY's rules. If it says (NEWKEY), try the next keyword on the stack.
  6. If nothing works, use the rules of the special keyword NONE, like I AM NOT SURE I UNDERSTAND YOU FULLY.
let entry = keystack.shift();
for (let guard = 0; entry && guard < 100; guard++) {
    const result = this.transform(entry, words);
    if (result.reply) {
        return result.reply;
    }
    if (result.pre) {
        words = result.pre;
    }
    entry = result.link ? entries[result.link] : keystack.shift();
}

guard stops the loop after 100 rounds, in case two rules point to each other forever.

Step 8: Memory

When the top keyword is MY, ELIZA also saves a changed copy of the sentence, using the MEMORY rules in the script. Later, when you say something without a keyword, it may bring that back:

> WELL, MY BOYFRIEND MADE ME COME HERE.
...
> BULLIES.
LETS DISCUSS FURTHER WHY YOUR BOYFRIEND MADE YOU COME HERE

The original only used a memory every fourth answer. this.limit counts 1, 2, 3, 4, 1... and memories are used when it is 4. This is part of what made ELIZA feel like it was listening.

Step 9: The class

The program is a class. A class is a template for objects that have both data and functions. new Eliza(DOCTOR_SCRIPT) runs the constructor and gives an object with its own memory and rule counters:

class Eliza {
    constructor(scriptText) {
        this.script = parseScript(scriptText);
        this.memory = [];
        this.limit = 1;
    }

    greeting() {
        return this.script.greeting;
    }

    respond(input) {
        ...
    }
}

Inside the class, this is the object itself. Two new Eliza(...) objects would have two separate conversations.

Step 10: The page script

const eliza = new Eliza(DOCTOR_SCRIPT);

function say(text, who) {
    const line = document.createElement("p");
    line.className = "line " + who;
    line.textContent = text;
    log.appendChild(line);
    log.scrollTop = log.scrollHeight;
}

function send(event) {
    event.preventDefault();

    const text = input.value.trim();
    if (text === "") {
        return;
    }
    input.value = "";
    say(text.toUpperCase(), "user");

    setTimeout(function () {
        say(eliza.respond(text), "eliza");
    }, 300);
}

form.addEventListener("submit", send);
say(eliza.greeting(), "eliza");

Setting scrollTop to scrollHeight scrolls to the bottom, so the newest line can be seen. The answer waits 300 milliseconds with setTimeout. It isn't needed, but it makes it feel like a conversation.

The scripts go into the page in this order: the script text, then the program, then the page script. Each one uses things from the one before.

Step 11: Test it

Type the start of Weizenbaum's famous conversation from the paper. You should get these answers:

Men are all alike.                                   IN WHAT WAY
They're always bugging us about something or other.  CAN YOU THINK OF A SPECIFIC EXAMPLE
Well, my boyfriend made me come here.                YOUR BOYFRIEND MADE YOU COME HERE
He says I'm depressed much of the time.              I AM SORRY TO HEAR YOU ARE DEPRESSED
It's true. I am unhappy.                             DO YOU THINK COMING HERE WILL HELP YOU NOT TO BE UNHAPPY

Then try your own sentences, and find a keyword in doctor.js to see which rule answered. Try the same sentence three times. The answers take turns.

    (BECAUSE ((0) (IS THAT THE REAL REASON) (DON'T ANY OTHER REASONS
        COME TO MIND) (DOES THAT REASON SEEM TO EXPLAIN ANYTHING ELSE)
        (WHAT OTHER REASONS MIGHT THERE BE)))
    (WHY ((0 WHY DON'T I 0) (DO YOU BELIEVE I DON'T 5) (PERHAPS I
            WILL 5 IN GOOD TIME) (SHOULD YOU 5 YOURSELF) (YOU WANT ME
            TO 5) (=WHAT))
        ((0 WHY CAN'T YOU 0) (DO YOU THINK YOU SHOULD BE ABLE TO 5)
            (DO YOU WANT TO BE ABLE TO 5) (DO YOU BELIEVE THIS WILL HELP
            YOU TO 5) (HAVE YOU ANY IDEA WHY YOU CAN'T 5) (=WHAT))
        (=WHAT))
    (EVERYONE 2 ((0 (* EVERYONE EVERYBODY NOBODY NOONE) 0)
        (REALLY, 2) (SURELY NOT 2) (CAN YOU THINK OF
            ANYONE IN PARTICULAR) (WHO, FOR EXAMPLE) (YOU ARE THINKING OF A
            VERY SPECIAL PERSON) (WHO, MAY I ASK) (SOMEONE SPECIAL
            PERHAPS) (YOU HAVE A PARTICULAR PERSON IN MIND, DON'T YOU)
            (WHO DO YOU THINK YOU'RE TALKING ABOUT)))
    (EVERYBODY 2 (= EVERYONE))
    (NOBODY 2 (= EVERYONE))
    (NOONE 2 (= EVERYONE))
    (ALWAYS 1 ((0) (CAN YOU THINK OF A SPECIFIC EXAMPLE) (WHEN)
        (WHAT INCIDENT ARE YOU THINKING OF) (REALLY, ALWAYS)))
    (LIKE 10 ((0 (*AM IS ARE WAS) 0 LIKE 0) (=DIT))
        ((0) (NEWKEY)))
    (DIT ((0) (IN WHAT WAY) (WHAT RESEMBLANCE DO YOU SEE)
        (WHAT DOES THAT SIMILARITY SUGGEST TO YOU)
        (WHAT OTHER CONNECTIONS DO YOU SEE)
        (WHAT DO YOU SUPPOSE THAT RESEMBLANCE MEANS)
        (WHAT IS THE CONNECTION, DO YOU SUPPOSE)
        (COULD THERE REALLY BE SOME CONNECTION)
        (HOW)))

    `;

    /*
     * ELIZA - a JavaScript version of Joseph Weizenbaum's program (MIT, 1966).
     * It follows the algorithm in his paper in Communications of the ACM:
     *
     *  1. The input is read word by word. A word that is in the script may be
     *     swapped for another (I -> YOU, MY -> YOUR), and if it is a keyword it
     *     goes on the "keystack", the most important (highest rank) first.
     *  2. A comma, period or BUT ends the sentence if a keyword has been found.
     *     If not, the words before it are thrown away and reading goes on.
     *  3. The rules of the top keyword are tried in order. The first pattern
     *     that matches picks an answer. The answers are used in turn, so ELIZA
     *     doesn't say the same thing twice in a row.
     *  4. When the top keyword is MY, a changed copy of the input is also saved.
     *     Later, when an input has no keyword, ELIZA may bring it back:
     *     "EARLIER YOU SAID YOUR ...".
     *  5. With no keyword at all, the NONE rules are used.
     *
     * The program knows nothing about therapy. All of that is in the script
     * (doctor.js), which is given to the constructor as text.
     */

    // --- Reading the script ---------------------------------------------------
    //
    // The script is written as nested lists in brackets, like Lisp:
    //   (SORRY ((0) (PLEASE DON'T APOLOGIZE) (APOLOGIES ARE NOT NECESSARY)))
    // readLists() turns that text into JavaScript arrays:
    //   ["SORRY", [["0"], ["PLEASE", "DON'T", "APOLOGIZE"], [...]]]

    function readLists(text) {
        // Put spaces around brackets so they become words of their own.
        const tokens = text.replace(/\(/g, " ( ").replace(/\)/g, " ) ").split(/\s+/).filter(Boolean);
        let pos = 0;

        // Read one word, or one whole (...) list with everything inside it.
        // It calls itself for lists inside lists: that is called recursion.
        function readOne() {
            const token = tokens[pos];
            pos++;

            if (token === ")") {
                throw new Error('ELIZA script: unexpected ")"');
            }
            if (token !== "(") {
                return token;
            }
            const list = [];
            while (tokens[pos] !== ")") {
                if (pos >= tokens.length) {
                    throw new Error('ELIZA script: missing ")"');
                }
                list.push(readOne());
            }
            pos++; // skip the ")"
            return list;
        }

        const items = [];
        while (pos < tokens.length) {
            items.push(readOne());
        }
        return items;
    }

    // (=KEY) or (= KEY) means "use the rules of KEY". Returns "KEY", or null.
    function linkTarget(list) {
        if (!Array.isArray(list) || typeof list[0] !== "string" || list[0][0] !== "=") {
            return null;
        }
        return list[0] === "=" ? list[1] : list[0].slice(1);
    }

    // A pattern like (0 YOU (* WANT NEED) 0) becomes a list of parts:
    //   0        { any: true }                    any number of words
    //   2        { count: 2 }                     exactly 2 words
    //   YOU      { word: "YOU" }                  this word
    //   (* A B)  { alternatives: ["A", "B"] }     one of these words
    //   (/FAM)   { tags: ["FAM"] }                a word tagged FAM, like MOTHER
    function parsePattern(list) {
        return list.map(function (part) {
            if (Array.isArray(part)) {
                const words = part.join(" ");
                if (words[0] === "*") {
                    return { alternatives: words.slice(1).split(" ").filter(Boolean) };
                }
                if (words[0] === "/") {
                    return { tags: words.slice(1).split(" ").filter(Boolean) };
                }
                throw new Error("ELIZA script: bad pattern (" + words + ")");
            }
            if (part === "0") {
                return { any: true };
            }
            if (/^\d+$/.test(part)) {
                return { count: Number(part) };
            }
            return { word: part };
        });
    }

    // One keyword: (WORD [= SUBSTITUTE] [RANK] [DLIST(/TAGS)] rules...)
    function parseEntry(list) {
        const entry = { word: list[0], substitute: null, rank: 0, tags: [], rules: [] };
        let i = 1;

        if (list[i] === "=") {
            entry.substitute = list[i + 1];
            i += 2;
        }
        if (/^\d+$/.test(list[i])) {
            entry.rank = Number(list[i]);
            i++;
        }
        if (list[i] === "DLIST") {
            entry.tags = list[i + 1].join(" ").replace(/\//g, " ").split(" ").filter(Boolean);
            i += 2;
        }

        // Each rule is (pattern answer answer ...). A rule that is only (=KEY)
        // means "for anything else, use KEY's rules".
        for (; i < list.length; i++) {
            const rule = list[i];
            const isLink = linkTarget(rule) !== null;
            entry.rules.push({
                pattern: parsePattern(isLink ? ["0"] : rule[0]),
                answers: isLink ? [rule] : rule.slice(1),
                next: 0  // which answer to use next time
            });
        }
        return entry;
    }

    // (MEMORY MY (0 YOUR 0 = LETS DISCUSS FURTHER WHY YOUR 3) ...)
    function parseMemory(list) {
        return {
            keyword: list[1],
            rules: list.slice(2).map(function (rule) {
                const equals = rule.indexOf("=");
                return {
                    pattern: parsePattern(rule.slice(0, equals)),
                    answer: rule.slice(equals + 1)
                };
            })
        };
    }

    function parseScript(text) {
        const items = readLists(text.toUpperCase());
        const script = { greeting: items[0].join(" "), entries: {}, memory: null };

        for (const item of items.slice(1)) {
            // Skip the word START and the empty () at the end.
            if (!Array.isArray(item) || item.length === 0) {
                continue;
            }
            if (item[0] === "MEMORY") {
                script.memory = parseMemory(item);
            } else {
                script.entries[item[0]] = parseEntry(item);
            }
        }
        if (!script.entries.NONE) {
            throw new Error("ELIZA script: no NONE entry");
        }
        return script;
    }

    // --- Matching -------------------------------------------------------------

    // Match words against a pattern. Returns one array of words per pattern
    // part, or null if it doesn't match:
    //   pattern (0 YOU ARE 0), words I THINK YOU ARE NICE
    //   -> [["I", "THINK"], ["YOU"], ["ARE"], ["NICE"]]
    function match(pattern, words, tagsOf) {
        const parts = [];

        // Try to match pattern part p and everything after it, starting at
        // word w. A 0 can take any number of words, so we try 0 words, then
        // 1, then 2... until the rest of the pattern also matches.
        function matchFrom(p, w) {
            if (p === pattern.length) {
                return w === words.length; // done only if all words are used
            }
            const part = pattern[p];

            if (part.any) {
                for (let n = 0; w + n <= words.length; n++) {
                    parts[p] = words.slice(w, w + n);
                    if (matchFrom(p + 1, w + n)) {
                        return true;
                    }
                }
                return false;
            }
            if (part.count) {
                if (w + part.count > words.length) {
                    return false;
                }
                parts[p] = words.slice(w, w + part.count);
                return matchFrom(p + 1, w + part.count);
            }

            // The other parts match exactly one word.
            const word = words[w];
            if (word === undefined) {
                return false;
            }
            let ok;
            if (part.word) {
                ok = word === part.word;
            } else if (part.alternatives) {
                ok = part.alternatives.includes(word);
            } else {
                ok = part.tags.some(function (tag) {
                    return tagsOf(word).includes(tag);
                });
            }
            if (!ok) {
                return false;
            }
            parts[p] = [word];
            return matchFrom(p + 1, w + 1);
        }

        return matchFrom(0, 0) ? parts : null;
    }

    // Build an answer. Numbers in it are replaced by that part of the match:
    //   (WHAT MAKES YOU THINK I AM 4) with part 4 = ["NICE"]
    //   -> ["WHAT", "MAKES", "YOU", "THINK", "I", "AM", "NICE"]
    function reassemble(answer, parts) {
        const words = [];
        for (const atom of answer) {
            if (/^\d+$/.test(atom)) {
                words.push(...(parts[Number(atom) - 1] || []));
            } else {
                words.push(atom);
            }
        }
        return words;
    }

    // ["WHY", "SO", ","] -> "WHY SO,"
    function format(words) {
        return words.join(" ").replace(/ ,/g, ",").replace(/ \./g, ".");
    }

    // A number made from a word, always the same for the same word.
    // Used to pick a memory rule, like the original did.
    function hash(word) {
        let h = 0;
        for (let i = 0; i < word.length; i++) {
            h = (h * 31 + word.charCodeAt(i)) >>> 0; // >>> 0 keeps it a positive 32-bit number
        }
        return h;
    }

    // --- The program ------------------------------------------------------------

    class Eliza {
        constructor(scriptText) {
            this.script = parseScript(scriptText);
            this.memory = [];  // saved sentences to bring back later
            this.limit = 1;    // counts 1-4; memories are only used on 4
        }

        greeting() {
            return this.script.greeting;
        }

        // The tags of a word, e.g. MOTHER -> ["FAMILY"].
        tagsOf(word) {
            const entry = this.script.entries[word];
            return entry ? entry.tags : [];
        }

        respond(input) {
            const entries = this.script.entries;
            this.limit = this.limit % 4 + 1;

            // Upper case, and punctuation as words of their own.
            const tokens = input.toUpperCase()
                .replace(/[‘’]/g, "'")
                .replace(/,/g, " , ")
                .replace(/[.?!;:]/g, " . ")
                .replace(/[^A-Z0-9',. ]/g, " ")
                .split(/\s+/)
                .filter(Boolean);

            // Step 1 and 2: find keywords and swap words.
            const keystack = [];
            let words = [];
            for (const token of tokens) {
                if (token === "," || token === "." || token === "BUT") {
                    if (keystack.length > 0) {
                        break;      // we have a keyword: ignore the rest
                    }
                    words = [];     // no keyword yet: forget this part
                    continue;
                }
                const entry = entries[token];
                if (entry && entry.rules.length > 0) {
                    if (keystack.length === 0 || entry.rank > keystack[0].rank) {
                        keystack.unshift(entry);  // most important: first
                    } else {
                        keystack.push(entry);
                    }
                }
                words.push(entry && entry.substitute ? entry.substitute : token);
            }

            // Step 4: remember sentences about MY ...
            const memory = this.script.memory;
            if (keystack.length > 0 && memory && keystack[0].word === memory.keyword) {
                this.remember(words);
            }

            // Step 3: try the keywords until one gives an answer. A rule can
            // also point to another keyword. The guard stops endless loops.
            let entry = keystack.shift();
            for (let guard = 0; entry && guard < 100; guard++) {
                const result = this.transform(entry, words);
                if (result.reply) {
                    return result.reply;
                }
                if (result.pre) {
                    words = result.pre;
                }
                entry = result.link ? entries[result.link] : keystack.shift();
            }

            // Step 5: no keyword helped.
            if (this.limit === 4 && this.memory.length > 0) {
                return this.memory.shift();
            }
            return this.transform(entries.NONE, words).reply;
        }

        // Try one keyword's rules. Returns one of:
        //   { reply }       an answer
        //   { link }        use another keyword's rules
        //   { pre, link }   change the words, then use another keyword
        //   {}              try the next keyword (NEWKEY, or nothing matched)
        transform(entry, words) {
            const tagsOf = this.tagsOf.bind(this);

            for (const rule of entry.rules) {
                const parts = match(rule.pattern, words, tagsOf);
                if (!parts) {
                    continue;
                }
                const answer = rule.answers[rule.next];
                rule.next = (rule.next + 1) % rule.answers.length;

                const link = linkTarget(answer);
                if (link) {
                    return { link: link };
                }
                if (answer.length === 1 && answer[0] === "NEWKEY") {
                    return {};
                }
                if (answer[0] === "PRE") {
                    return { pre: reassemble(answer[1], parts), link: linkTarget(answer[2]) };
                }
                return { reply: format(reassemble(answer, parts)) };
            }
            return {};
        }

        remember(words) {
            const rules = this.script.memory.rules;
            const rule = rules[hash(words[words.length - 1] || "") % rules.length];
            const parts = match(rule.pattern, words, this.tagsOf.bind(this));
            if (parts) {
                this.memory.push(format(reassemble(rule.answer, parts)));
            }
        }
    }

    /*
     * The Eliza page: show the conversation and send what the user types to
     * the Eliza program (eliza.js) running the DOCTOR script (doctor.js).
     */

    // --- Elements on the page ------------------------------------------------

    const log = document.getElementById("log");
    const form = document.getElementById("form");
    const input = document.getElementById("input");

    // --- The program ---------------------------------------------------------

    const eliza = new Eliza(DOCTOR_SCRIPT);

    // --- Actions -------------------------------------------------------------

    // Add one line to the conversation. "who" is "eliza" or "user".
    function say(text, who) {
        const line = document.createElement("p");
        line.className = "line " + who;
        line.textContent = text;
        log.appendChild(line);

        // Scroll down so the newest line can be seen.
        log.scrollTop = log.scrollHeight;
    }

    function send(event) {
        // Don't let the form reload the page.
        event.preventDefault();

        const text = input.value.trim();
        if (text === "") {
            return;
        }
        input.value = "";
        say(text.toUpperCase(), "user");

        // Wait a moment before answering, so it feels like a conversation.
        setTimeout(function () {
            say(eliza.respond(text), "eliza");
        }, 300);
    }

    // --- Connect the page ----------------------------------------------------

    form.addEventListener("submit", send);

    // --- Start ---------------------------------------------------------------

    say(eliza.greeting(), "eliza");
  </script>
