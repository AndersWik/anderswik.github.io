Page Search

We build a tool that searches many web pages at once. You give it a regular expression and a list of pages, and it downloads every page and shows what it found on each one. The list you can write yourself, or read from the site's sitemap. It is handy for checking your own site: which pages still link to an old address, which ones mention a product, where an email address is written.

The new ideas are matchAll to find every match, DOMParser to get the text out of HTML and to read XML, and running await in a loop, one page at a time.

Read Make Request first. It explains fetch() and CORS.

Which pages can we read?

The same rule as in Make Request: fetch() can read every page on the same site as our tool, but pages on other sites only if the server allows it with CORS. Most websites don't. So the tool is best for searching your own site, and APIs that allow CORS. The Firefox add-on version can read any page.

function source() {

form.addEventListener("change", function () {

form.elements.source is the group of radio buttons named source, and its value is the value of the one that is checked. The change event bubbles up from every field to the form, so one listener on the form is enough. Setting hidden to true or false hides or shows an element.

Step 3: Read a list of URLs

function readUrls(text) {
    const urls = [];
    text.split(/\s+/).forEach(function (part) {
        if (part === "") {
            return;
        }
        try {
            const url = new URL(part, location.href).href;
            if (!urls.includes(url)) {
                urls.push(url);
            }
        } catch (error) {
            // Not a URL, skip it.
        }
    });
    return urls;
}

split(/\s+/) splits on any run of spaces, tabs and newlines, so one per line, or several on a line, both work. new URL(part, location.href) reads the address, and the second argument is the base for addresses without a site: /tools/ becomes https://www.anderswik.se/tools/. It throws an error if the text can't be an address, and then we skip it. includes stops the same page from being searched twice.

Step 4: What is a sitemap?

Most sites already have a list of their pages: the sitemap. It is there so search engines can find every page. It is usually at /sitemap.xml, and the address is often written in /robots.txt. It is XML, a format that looks like HTML but where you make up the tag names yourself:

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://example.com/</loc>
    <lastmod>2026-11-01</lastmod>
  </url>
  <url>
    <loc>https://example.com/about/</loc>
  </url>
</urlset>

Every page is a <loc> (location) inside a <url>. A sitemap may only have 50,000 pages, so a big site has a sitemap index instead: a list of sitemaps, with the same <loc> tag:

<sitemapindex xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <sitemap><loc>https://example.com/sitemap-pages.xml</loc></sitemap>
  <sitemap><loc>https://example.com/sitemap-posts.xml</loc></sitemap>
</sitemapindex>

Step 5: Read the sitemap

DOMParser turns text into a document, the same kind of object as document. With "application/xml" it reads XML:

function parseSitemap(xml) {
    const doc = new DOMParser().parseFromString(xml, "application/xml");
    if (doc.querySelector("parsererror")) {
        throw new Error("This is not valid XML.");
    }
    const locs = [];
    for (const loc of doc.getElementsByTagName("loc")) {
        locs.push(loc.textContent.trim());
    }
    if (doc.documentElement.localName === "sitemapindex") {
        return { urls: [], sitemaps: locs };
    }
    return { urls: locs, sitemaps: [] };
}

HTML is forgiving: the browser fixes a missing end tag and carries on. XML is strict, one mistake and the whole file is wrong. parseFromString doesn't throw an error then. It gives back a document with a <parsererror> element that describes the problem, so that is what we look for.

getElementsByTagName("loc") finds every <loc>, wherever it is. documentElement is the outermost element, so its name tells if this is a urlset or a sitemapindex. We use localName, the name without a namespace prefix, since some sitemaps write <sm:sitemapindex>.

To read an index, we download each sitemap in it and add its pages:

async function download(url) {
    const response = await fetch(url);
    if (!response.ok) {
        throw new Error("HTTP " + response.status);
    }
    return response.text();
}

async function sitemapUrls(xml) {
    const parsed = parseSitemap(xml);
    let urls = parsed.urls;
    for (const address of parsed.sitemaps) {
        const inner = parseSitemap(await download(address));
        urls = urls.concat(inner.urls);
    }
    return urls;
}

For a normal sitemap, the loop does nothing and we get the pages. concat joins two lists into a new one.

Remember that a 404 is not an error to fetch(), see Make Request. Without the response.ok check, a missing sitemap would give us the text of a "Not found" page, which is not valid XML, and a confusing message. We use download for the pages too, so a missing page shows as failed.

The sitemap is downloaded with fetch(), so CORS applies to it as well: the sitemap of your own site works, other sites' sitemaps only if they allow it. You can always open a sitemap in the browser, copy it, and paste it into the text area. The pages in it still have to be readable, of course.

Step 6: Text, not HTML

A search for class in the HTML of a page finds hundreds of class="..." attributes. Usually you want to search what the page says. DOMParser with "text/html" reads HTML, without showing it or running its scripts:

function pageText(html) {
    const doc = new DOMParser().parseFromString(html, "text/html");
    doc.querySelectorAll("script, style, noscript, template").forEach(function (el) {
        el.remove();
    });
    return doc.body.textContent.replace(/\s+/g, " ");
}

textContent is all the text inside an element, without tags. But it includes the code inside <script> and <style>, so we remove those first. HTML is full of line breaks and indentation, so replace(/\s+/g, " ") turns every run of white space into one space. Then Hello<br>\n world can be found with Hello world.

The checkbox lets you search the raw HTML too, to find things like a link to an old address in an href.

Step 7: Find every match

const regex = new RegExp(patternInput.value, "gi");

function findMatches(text, regex) {
    const counts = {};
    let total = 0;
    for (const match of text.matchAll(regex)) {
        counts[match[0]] = (counts[match[0]] || 0) + 1;
        total++;
    }
    return { total: total, counts: counts };
}

new RegExp(text, flags) makes a regular expression from text that the user typed. It throws an error if the text is not a valid expression, like (abc, so search() puts it in a try. The flag i ignores upper and lower case, and g means "global": find every match, not only the first.

matchAll needs the g flag, and gives every match one after the other. match[0] is the text that matched. We count each different text, so the result can say "Test ×3, test ×1" instead of a long list.

Why matchAll and not a loop with regex.exec()? A pattern like a* can match zero characters. An exec loop then finds the same empty match at the same place forever, and the page freezes. matchAll moves on by itself.

Step 8: One page at a time

First we get the list of pages, from the text area or from the sitemap. Reading a sitemap can fail, so it goes in a try:

let urls;
try {
    urls = source() === "list" ? readUrls(urlList.value) : await sitemapUrls(sitemapInput.value);
} catch (error) {
    summary.textContent = "Could not read the sitemap: " + error.message;
    return;
}

From here on it doesn't matter where the list came from:

async function searchPage(url, regex) {
    const html = await download(url);
    const text = searchHtml.checked ? html : pageText(html);
    return findMatches(text, regex);
}

for (let i = 0; i < urls.length; i++) {
    summary.textContent = "Searching " + (i + 1) + " of " + urls.length + "…";
    try {
        const found = await searchPage(urls[i], regex);
        showMatches(rows[i], found);
    } catch (error) {
        showFailed(rows[i], error);
    }
}

await inside a for loop waits for each page before it starts the next. That is slower than downloading all of them at once, but kind to the server: a hundred requests at the same moment can look like an attack, and get you blocked.

The try is inside the loop, so one page that fails doesn't stop the rest. The list of results is made before the loop, with "waiting" on every page, so you can see how far it has come.

Step 9: Test it

  • Search https://jsonplaceholder.typicode.com/posts/1 and https://jsonplaceholder.typicode.com/posts/2 for \bsunt\b. That API allows CORS, so it works from anywhere.
  • Add https://example.com/. It fails, since example.com doesn't allow CORS.
  • Switch to sitemap, paste this, and search for \bsunt\b again. It finds the same matches: 
    <urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url><loc>https://jsonplaceholder.typicode.com/posts/1</loc></url>
  <url><loc>https://jsonplaceholder.typicode.com/posts/2</loc></url>
</urlset>
  • Remove the last >. The count says it is not valid XML.
  • Put the finished page on a web server with some other pages, a sitemap index and two sitemaps, and load the index. Both sitemaps are read.
  • Search for (abc. You get an error message, not a broken page.

  <script>
    /*
     * Page Search: download many pages and search each one for a regular
     * expression. The pages come from a list of URLs or from a sitemap.
     *
     * fetch() can only read pages from other sites if they allow it with
     * CORS. Pages on the same site always work.
     */

    // --- Elements on the page ------------------------------------------------

    const form = document.getElementById("form");
    const listPart = document.getElementById("list-part");
    const sitemapPart = document.getElementById("sitemap-part");
    const urlList = document.getElementById("url-list");
    const sitemapUrl = document.getElementById("sitemap-url");
    const loadButton = document.getElementById("load");
    const sitemapInput = document.getElementById("sitemap");
    const count = document.getElementById("count");
    const patternInput = document.getElementById("pattern");
    const searchHtml = document.getElementById("search-html");
    const startButton = document.getElementById("start");
    const summary = document.getElementById("summary");
    const resultsList = document.getElementById("results");

    // "list" or "sitemap"
    function source() {
        return form.elements.source.value;
    }

    // Show the part of the form for the chosen source.
    form.addEventListener("change", function () {
        listPart.hidden = source() !== "list";
        sitemapPart.hidden = source() !== "sitemap";
    });

    // --- A list of URLs ------------------------------------------------------

    // Text with one URL per line -> a list. Empty lines and duplicates are
    // skipped, and /path is read from this page's address.
    function readUrls(text) {
        const urls = [];
        text.split(/\s+/).forEach(function (part) {
            if (part === "") {
                return;
            }
            try {
                const url = new URL(part, location.href).href;
                if (!urls.includes(url)) {
                    urls.push(url);
                }
            } catch (error) {
                // Not a URL, skip it.
            }
        });
        return urls;
    }

    // --- A sitemap -----------------------------------------------------------

    // XML text -> { urls, sitemaps }
    function parseSitemap(xml) {
        const doc = new DOMParser().parseFromString(xml, "application/xml");
        if (doc.querySelector("parsererror")) {
            throw new Error("This is not valid XML.");
        }
        const locs = [];
        for (const loc of doc.getElementsByTagName("loc")) {
            locs.push(loc.textContent.trim());
        }
        if (doc.documentElement.localName === "sitemapindex") {
            return { urls: [], sitemaps: locs };
        }
        return { urls: locs, sitemaps: [] };
    }

    async function download(url) {
        const response = await fetch(url);
        if (!response.ok) {
            throw new Error("HTTP " + response.status);
        }
        return response.text();
    }

    // Every page in the sitemap. For a sitemap index, read each sitemap in it.
    async function sitemapUrls(xml) {
        const parsed = parseSitemap(xml);
        let urls = parsed.urls;
        for (const address of parsed.sitemaps) {
            const inner = parseSitemap(await download(address));
            urls = urls.concat(inner.urls);
        }
        return urls;
    }

    function showCount() {
        try {
            const parsed = parseSitemap(sitemapInput.value);
            count.textContent = parsed.sitemaps.length > 0
                ? "A sitemap index with " + parsed.sitemaps.length + " sitemaps."
                : parsed.urls.length + " pages.";
        } catch (error) {
            count.textContent = sitemapInput.value.trim() === "" ? "" : error.message;
        }
    }

    loadButton.addEventListener("click", async function () {
        try {
            sitemapInput.value = await download(sitemapUrl.value.trim());
            showCount();
        } catch (error) {
            count.textContent = "Could not load the sitemap. Is the address right, and does the server allow CORS?";
        }
    });

    sitemapInput.addEventListener("input", showCount);

    // --- Loading and searching a page ----------------------------------------

    // The words on a page, without tags, scripts and styles.
    function pageText(html) {
        const doc = new DOMParser().parseFromString(html, "text/html");
        doc.querySelectorAll("script, style, noscript, template").forEach(function (el) {
            el.remove();
        });
        return doc.body.textContent.replace(/\s+/g, " ");
    }

    // Count every match: { "Test": 3, "test": 1 }
    function findMatches(text, regex) {
        const counts = {};
        let total = 0;
        for (const match of text.matchAll(regex)) {
            counts[match[0]] = (counts[match[0]] || 0) + 1;
            total++;
        }
        return { total: total, counts: counts };
    }

    async function searchPage(url, regex) {
        const html = await download(url);
        const text = searchHtml.checked ? html : pageText(html);
        return findMatches(text, regex);
    }

    // --- Showing results -----------------------------------------------------

    function addResult(url) {
        const li = document.createElement("li");
        const status = document.createElement("span");
        status.className = "status";
        status.textContent = "waiting";
        li.append(status, document.createTextNode(url));
        resultsList.append(li);
        return li;
    }

    function showMatches(li, found) {
        li.classList.add(found.total > 0 ? "match" : "no-match");
        li.querySelector(".status").textContent =
            found.total === 0 ? "no match" : found.total + " matches";
        for (const text in found.counts) {
            const chip = document.createElement("span");
            chip.className = "found";
            chip.textContent = text + " ×" + found.counts[text];
            li.append(document.createElement("br"), chip);
        }
    }

    function showFailed(li, error) {
        li.classList.add("failed");
        li.querySelector(".status").textContent = "failed";
        li.title = error instanceof TypeError
            ? "Blocked by CORS, or the server could not be reached"
            : error.message;
    }

    // --- The search ----------------------------------------------------------

    async function search() {
        let regex;
        try {
            regex = new RegExp(patternInput.value, "gi");
        } catch (error) {
            summary.textContent = "The regular expression is not valid: " + error.message;
            return;
        }
        if (patternInput.value === "") {
            summary.textContent = "Write a regular expression.";
            return;
        }

        let urls;
        try {
            urls = source() === "list" ? readUrls(urlList.value) : await sitemapUrls(sitemapInput.value);
        } catch (error) {
            summary.textContent = "Could not read the sitemap: " + error.message;
            return;
        }
        if (urls.length === 0) {
            summary.textContent = "There are no pages to search.";
            return;
        }

        startButton.disabled = true;
        resultsList.textContent = "";
        const rows = urls.map(addResult);
        let withMatches = 0;

        // One page at a time, so we don't flood the server.
        for (let i = 0; i < urls.length; i++) {
            summary.textContent = "Searching " + (i + 1) + " of " + urls.length + "…";
            rows[i].querySelector(".status").textContent = "searching…";
            try {
                const found = await searchPage(urls[i], regex);
                showMatches(rows[i], found);
                if (found.total > 0) {
                    withMatches++;
                }
            } catch (error) {
                showFailed(rows[i], error);
            }
        }

        summary.textContent = "Searched " + urls.length + " pages, " + withMatches + " with matches.";
        startButton.disabled = false;
    }

    form.addEventListener("submit", function (event) {
        event.preventDefault();
        search();
    });
  </script>
</body>
</html>

Pages that are made by JavaScript: a frame

fetch() gives you the HTML the server sends. Some pages are almost empty HTML, and JavaScript fills them in when they are shown. To search those, the version on this site can load each page in an <iframe> instead, wait a little, and read what it shows:

loader.onload = function () {
    setTimeout(function () {
        const doc = loader.contentDocument;
        const text = doc.body.innerText;
        // search the text
    }, delay);
};
loader.src = url;

contentDocument is the document inside the frame. But the browser only gives it to you if the page in the frame is from the same site. For any other site it is null, whatever the server says, and CORS doesn't change that. If it didn't work that way, any site could open your webmail in a hidden frame and read it. So the frame only works for your own site, and the tool checks that before loading a page:

if (new URL(url).origin !== location.origin) {
    // can't be read in a frame, use fetch instead
}

An origin is the scheme, host and port together, like https://www.anderswik.se. Note that https://anderswik.se and https://www.anderswik.se are different origins.

The version on this site

Page Search on this site also:

  • Has a Stop button and a progress bar.
  • Takes flags for the regular expression, so you can turn off "ignore case".
  • Loads the sitemap by itself if you press Search with only an address.
  • Skips sitemaps in an index that can't be read, and says which, instead of stopping. It reads at most 50 sitemaps from an index, so a huge site doesn't take forever.
  • Has a limit, so you can try your search on the first 10 pages before you search them all.
  • Remembers the form in localStorage, the same way as Checklist.
  • Saves the results as a CSV file you can open in a spreadsheet.

The CSV is made the same way as the export in Make Request, with a Blob. Text with a comma, a quote or a line break in it goes inside quotes, with each quote doubled:

function csvCell(text) {
    return /[",\n\r]/.test(text) ? '"' + text.replace(/"/g, '""') + '"' : text;
}

Any site: the Firefox add-on

Like Make Request, Page Search is also a Firefox add-on with permission for every site, and in the add-on fetch() can read any page and sitemap. The frame still only works for pages from the add-on itself, so in the add-on, always use Download.

Try this

  • Show a little of the text around each match, like a search engine does. match.index is where the match starts.
  • Search two or three pages at the same time, to make it faster without flooding the server.
  • Read <lastmod> from the sitemap too, and only search pages changed after a date.
  • Find the sitemap by itself: download /robots.txt and look for a line that starts with Sitemap:.
  • Follow the links on each page, to search a whole site from just its front page.
