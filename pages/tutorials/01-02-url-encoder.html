URL encoder

We build a URL encoder: type text, press Encode, and get text that is safe to put in a URL. Press Decode to go back. As a bonus it builds a piece of CSS that puts an SVG image straight into a stylesheet.

Open the finished URL encoder

What URL encoding is

A URL may only contain some characters. Others, like spaces, åäö and quotes, are written as % and a code. Some characters, like &, =, ? and /, have a meaning in a URL. If they are part of a value, they must be encoded too, or the browser reads them as part of the URL itself.

fish & chips     ->  fish%20%26%20chips
https://site/?q=fish%20%26%20chips    q is "fish & chips"
https://site/?q=fish & chips          q is "fish ", then a broken parameter

JavaScript has these functions built in:

  • encodeURIComponent(text) encodes everything that isn't a letter, a digit or one of - _ . ! ~ * ' ( ). Use it for one part of a URL, like a search word.
  • decodeURIComponent(text) turns every % code back into a character.
  • encodeURI(text) encodes less. It leaves / : ? & = # alone so a whole URL stays a URL. We use it for the SVG.

Step 1: The page

Create url-encoder.html from the skeleton in Building a utility page. The page has three text boxes and two buttons. The ids are what the script uses.

<textarea id="decoded-text"></textarea>

<button type="button" id="decode-btn">Decode</button>

The buttons have type="button". A button inside a form submits the form by default. type="button" makes it a plain button that only runs our code. It is a good habit even when there is no form.

Step 4: Encode

Reading a text box is .value, and writing to it is also .value:

function encode() {
    encodedText.value = encodeURIComponent(plainText.value);
}

encodeButton.addEventListener("click", encode);

Save, reload, type fish & chips and press Encode. You should get fish%20%26%20chips.

Step 5: Decode, and handle bad input

decodeURIComponent throws an error when the text has a broken code, like %E0%A4%A. An error that isn't caught stops the function, and the user just sees nothing happen. try and catch let us catch the error and show a message instead:

function decode() {
    try {
        plainText.value = decodeURIComponent(encodedText.value);
    } catch (error) {
        plainText.value = "That is not a valid URL encoded text.";
    }
}

decodeButton.addEventListener("click", decode);

Test with fish%20%26%20chips (gives fish & chips) and with %E0%A4%A (gives the message).

Step 6: The SVG in CSS

An SVG image is text, so it can go straight into CSS as a data URL: url("data:image/svg+xml;charset=US-ASCII,...") followed by the encoded SVG. We use encodeURI here because it leaves / : = alone, which keeps the SVG readable. It also leaves # alone, and in a URL # starts the fragment, so a color like #f00 would cut the image short. So we replace # with its code, %23, ourselves:

function encodeForSvg(text) {
    return encodeURI(text).replaceAll("#", "%23");
}

function buildCss(encodedSvg) {
    return ".myImage:before {\n" +
        "    background-image: url(\"data:image/svg+xml;charset=US-ASCII," + encodedSvg + "\");\n" +
        "    background-size: 100% 100%;\n" +
        "    background-repeat: no-repeat;\n" +
        "}";
}

\n is a new line and \" is a quote inside a string. Now encode() fills both boxes:

function encode() {
    encodedText.value = encodeURIComponent(plainText.value);
    cssText.value = buildCss(encodeForSvg(plainText.value));
}

Test with <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 10 10"><circle cx="5" cy="5" r="5" fill="#f00"/></svg>. The CSS box should contain fill=%22%23f00%22.

<body>
  <h1>URL encoder</h1>

  <label for="decoded-text">Text</label>
  <textarea id="decoded-text"></textarea>

  <label for="encoded-text">URL encoded text</label>
  <textarea id="encoded-text"></textarea>

  <button type="button" id="encode-btn">Encode</button>
  <button type="button" id="decode-btn">Decode</button>

  <label for="escaped-css">CSS for an SVG</label>
  <textarea id="escaped-css"></textarea>

  <script>
    /*
     * URL encode / decode.
     *
     * Some characters (spaces, åäö, quotes, < >...) are not allowed in a URL.
     * URL encoding replaces each of them with "%" and a code:
     *
     *   "hello world"  ->  "hello%20world"
     *
     * encodeURIComponent() also encodes characters that have a meaning in a
     * URL, like "&", "=", "?" and "/", so the text can safely be put inside
     * one part of a URL, e.g. "?q=" + encodeURIComponent("fish & chips").
     *
     * The page also builds a CSS snippet that puts an SVG image straight into
     * the CSS as a "data URL", which is a common use for URL encoding.
     */

    // --- Elements on the page ------------------------------------------------

    const plainText = document.getElementById("decoded-text");
    const encodedText = document.getElementById("encoded-text");
    const cssText = document.getElementById("escaped-css");
    const encodeButton = document.getElementById("encode-btn");
    const decodeButton = document.getElementById("decode-btn");

    // --- Helpers -------------------------------------------------------------

    // For the SVG we use encodeURI(), which leaves "/", ":" and "=" alone so
    // the SVG stays readable. It also leaves "#" alone, but in a data URL "#"
    // would cut the image short, so we encode that one ourselves.
    function encodeForSvg(text) {
        return encodeURI(text).replaceAll("#", "%23");
    }

    function buildCss(encodedSvg) {
        return ".myImage:before {\n" +
            "    background-image: url(\"data:image/svg+xml;charset=US-ASCII," + encodedSvg + "\");\n" +
            "    background-size: 100% 100%;\n" +
            "    background-repeat: no-repeat;\n" +
            "}";
    }

    // --- What the buttons do -------------------------------------------------

    function encode() {
        encodedText.value = encodeURIComponent(plainText.value);
        cssText.value = buildCss(encodeForSvg(plainText.value));
    }

    function decode() {
        // decodeURIComponent() decodes every "%" code, including "%23".
        // It throws an error on broken codes like "%E0%A4%A", so catch that.
        try {
            plainText.value = decodeURIComponent(encodedText.value);
        } catch (error) {
            plainText.value = "That is not a valid URL encoded text.";
        }
    }

    // --- Connect the buttons -------------------------------------------------

    encodeButton.addEventListener("click", encode);
    decodeButton.addEventListener("click", decode);
  </script>
</body>
</html>

Try this

  • Encode text as you type: listen for "input" on the text box instead of "click" on the button.
  • Add a button that copies the result with navigator.clipboard.writeText(encodedText.value).
