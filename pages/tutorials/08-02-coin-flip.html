Coin flip

Flip a coin: it spins for two seconds, lands on heads or tails, and the page counts how many of each you have had. It is a small game, but it shows two useful things: drawing pictures with SVG right in the HTML, and making sure a button can't be pressed again while something is still going on.

Open the finished game

Step 1: The page, with pictures made of SVG

Create coin-flip.html from the skeleton.

<h1>Coin flip</h1>

<div id="resultCoinHeads">
  <svg viewBox="0 0 200 200" role="img" aria-label="Heads">
    <circle cx="100" cy="100" r="95" fill="#f7931a" stroke="#d67e00" stroke-width="5"/>
    <text x="100" y="140" font-size="120" font-weight="bold" font-family="Arial" fill="white" text-anchor="middle">₿</text>
  </svg>
</div>
<div id="resultCoinTails" hidden>
  <svg viewBox="0 0 200 200" role="img" aria-label="Tails">
    <circle cx="100" cy="100" r="95" fill="#f7931a" stroke="#d67e00" stroke-width="5"/>
    <rect x="50" y="50" width="100" height="100" fill="none" stroke="white" stroke-width="3"/>
    <circle cx="100" cy="100" r="20" fill="none" stroke="white" stroke-width="3"/>

<button type="button" id="flipCoinBtn">Flip coin!</button>
<p id="resultHeads">Heads: 0</p>
<p id="resultTails">Tails: 0</p>

The two sides of the coin are SVG: pictures described with tags, right in the HTML. viewBox="0 0 200 200" sets up a 200 x 200 drawing area. Then:

  • <circle cx="100" cy="100" r="95"> is a circle in the middle.
  • <text> writes the ₿ sign. text-anchor="middle" centers it.
  • <rect> is a rectangle. fill="none" draws only the outline.

SVG pictures stay sharp at any size, and since they are part of the page there are no files to keep track of. role="img" and aria-label tell screen readers what the picture shows.

Step 2: Showing one side

function showSide(isHeads) {
    headsSide.hidden = !isHeads;
    tailsSide.hidden = isHeads;
}

! turns true into false and false into true. One of the two sides is always hidden.

Step 3: Spinning

While the coin spins, we switch sides every 150 milliseconds with setInterval. After two seconds, setTimeout stops the switching with clearInterval and picks the real result:

let showingHeads = true;
const spin = setInterval(function () {
    showingHeads = !showingHeads;
    showSide(showingHeads);
}, SWITCH_TIME);

setTimeout(function () {
    clearInterval(spin);

    const isHeads = Math.random() < 0.5;
    ...
}, FLIP_TIME);

The switching is only for show. The result is decided at the end: Math.random() is below 0.5 exactly half of the time.

Step 4: One flip at a time

What happens if you click twice quickly? Without a check, two flips would run at the same time, two intervals would fight over the picture, and the counter would go up by two. A flipping flag stops that, and disabling the button shows it:

function flipCoin() {
    if (flipping) {
        return;
    }
    flipping = true;
    flipButton.disabled = true;
    ...
    // when the flip is done:
    flipping = false;
    flipButton.disabled = false;
}

The flag is the real protection. A disabled button can't be clicked, but the function could still be called in other ways, for example from the console.

Step 5: Test it

  • Flip ten times and check that heads plus tails is 10.
  • Click the button many times quickly. It should still count only one flip at a time.
  • In the console, Math.random = () => 0.2 makes every flip heads. Reload the page to undo it.

<body>
  <h1>Coin flip</h1>

  <div id="resultCoinHeads">
    <svg viewBox="0 0 200 200" role="img" aria-label="Heads">
      <circle cx="100" cy="100" r="95" fill="#f7931a" stroke="#d67e00" stroke-width="5"/>
      <text x="100" y="140" font-size="120" font-weight="bold" font-family="Arial" fill="white" text-anchor="middle">₿</text>
    </svg>
  </div>
  <div id="resultCoinTails" hidden>
    <svg viewBox="0 0 200 200" role="img" aria-label="Tails">
      <circle cx="100" cy="100" r="95" fill="#f7931a" stroke="#d67e00" stroke-width="5"/>
      <rect x="50" y="50" width="100" height="100" fill="none" stroke="white" stroke-width="3"/>
      <circle cx="100" cy="100" r="20" fill="none" stroke="white" stroke-width="3"/>
    </svg>
  </div>

  <button type="button" id="flipCoinBtn">Flip coin!</button>
  <p id="resultHeads">Heads: 0</p>
  <p id="resultTails">Tails: 0</p>

  <script>
    /*
     * Coin flip: the coin switches between heads and tails for a while, then
     * lands on one side at random. The page counts heads and tails.
     */

    // --- Elements on the page ------------------------------------------------

    const headsSide = document.getElementById("resultCoinHeads");
    const tailsSide = document.getElementById("resultCoinTails");
    const flipButton = document.getElementById("flipCoinBtn");
    const headsText = document.getElementById("resultHeads");
    const tailsText = document.getElementById("resultTails");

    // --- State ---------------------------------------------------------------

    let headsCount = 0;
    let tailsCount = 0;
    let flipping = false;

    const FLIP_TIME = 2000;   // ms the coin spins
    const SWITCH_TIME = 150;  // ms between showing heads and tails while it spins

    // --- Helpers -------------------------------------------------------------

    function showSide(isHeads) {
        headsSide.hidden = !isHeads;
        tailsSide.hidden = isHeads;
    }

    // --- Actions -------------------------------------------------------------

    function flipCoin() {
        // One flip at a time; otherwise a fast double click counts twice.
        if (flipping) {
            return;
        }
        flipping = true;
        flipButton.disabled = true;

        // Switch sides quickly so it looks like the coin is spinning.
        let showingHeads = true;
        const spin = setInterval(function () {
            showingHeads = !showingHeads;
            showSide(showingHeads);
        }, SWITCH_TIME);

        setTimeout(function () {
            clearInterval(spin);

            // Math.random() is below 0.5 half of the time.
            const isHeads = Math.random() < 0.5;
            if (isHeads) {
                headsCount++;
            } else {
                tailsCount++;
            }
            showSide(isHeads);
            headsText.textContent = "Heads: " + headsCount;
            tailsText.textContent = "Tails: " + tailsCount;

            flipping = false;
            flipButton.disabled = false;
        }, FLIP_TIME);
    }

    // --- Connect the page ----------------------------------------------------

    flipButton.addEventListener("click", flipCoin);
  </script>
</body>
</html>
