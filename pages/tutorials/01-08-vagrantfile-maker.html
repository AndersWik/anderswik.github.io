Vagrantfile maker

We build a Vagrantfile maker. You pick a template, type an IP and a host name, and download a finished Vagrantfile. The new ideas are loading a file with fetch, and letting the user download text as a file.

Open the finished Vagrantfile maker

The plan

  1. The templates are ordinary files in a templates folder next to the page. In them, the IP is written as vagrantip and the host name as vagranturl.
  2. When a template is picked, the script loads it with fetch.
  3. While the user types, the script replaces the placeholders and shows the result.
  4. The Download file button saves the result as a file called Vagrantfile.

Step 1: The templates

Make a folder for the tool with the page and a templates folder in it:

vagrantfile-maker/
    vagrantfile-maker.html
    templates/
        basic.Vagrantfile
        web.Vagrantfile

Each template is a normal Vagrantfile with the placeholders in it:

basic.Vagrantfile

Vagrant.configure("2") do |config|
  config.vm.box = "ubuntu/jammy64"
  config.vm.network "private_network", ip: "vagrantip"
  config.vm.hostname = "vagranturl"
end

web.Vagrantfile

Vagrant.configure("2") do |config|
  config.vm.box = "ubuntu/jammy64"
  config.vm.network "private_network", ip: "vagrantip"
  config.vm.hostname = "vagranturl"

  config.vm.provision "shell", inline: <<-SHELL
    apt-get update
    apt-get install -y apache2
    echo "<h1>Hello from vagranturl</h1>" > /var/www/html/index.html
  SHELL
end

Pick placeholder words that can't appear anywhere else in the file, because every copy is replaced. In the web template the host name is used twice, and both are filled in.

Step 3: Load a template with fetch

fetch(url) asks the server for a file. The network takes time, so fetch doesn't return the file right away. It returns a promise, a value that will arrive later. Inside a function marked async, await waits for the promise without freezing the page:

let template = "";

async function loadTemplate() {
    fileText.value = "Loading...";

    try {
        const response = await fetch(templateSelect.value);

        if (!response.ok) {
            throw new Error("HTTP " + response.status);
        }
        template = await response.text();
        showFile();
    } catch (error) {
        fileText.value = "Could not load the Vagrantfile.";
    }
}

fetch only throws an error when there is no network at all. If the file is missing, the server still answers, with status 404 and an error page. Without the response.ok check, that error page would end up in the Vagrantfile. response.ok is true for status 200-299. throw jumps straight to catch, so both kinds of problem show the same message.

We keep the template exactly as downloaded, with the placeholders still in it. Then every time the user types, we can fill it in again from the start.

Step 4: Fill in the placeholders

function showFile() {
    let content = template;

    if (ipInput.value !== "") {
        content = content.replaceAll("vagrantip", ipInput.value);
    }
    if (urlInput.value !== "") {
        content = content.replaceAll("vagranturl", urlInput.value);
    }

    fileText.value = content;
}

replace() only changes the first match, and replaceAll() changes every match. While a box is empty, the placeholder stays, so you can see where the value will go.

Step 5: Download the text as a file

A data URL holds the content of a file in the link itself: data:text/plain;charset=utf-8, followed by the URL encoded text. You can read more about URL encoding in the URL encoder tutorial. The download attribute on a link tells the browser to save the file instead of opening it, with that name. We put the data URL in the hidden link and click it from code:

function downloadFile() {
    downloadLink.href = "data:text/plain;charset=utf-8," + encodeURIComponent(fileText.value);
    downloadLink.click();
}

We download fileText.value, the text box, and not the template. So if the user edits the text by hand before downloading, the changes are kept.

Step 6: Connect and start

ipInput.addEventListener("input", showFile);
urlInput.addEventListener("input", showFile);
templateSelect.addEventListener("change", loadTemplate);
downloadButton.addEventListener("click", downloadFile);

loadTemplate();

The last line loads the first template as soon as the page opens.

Step 7: Test it

For safety, browsers don't let fetch read files when a page is opened straight from disk (the address starts with file://). So this page needs a small web server. Python has one built in. Run this in the vagrantfile-maker folder:

$ python3 -m http.server 8000

Then open http://localhost:8000/vagrantfile-maker.html. Press Ctrl+C in the terminal to stop the server when you are done.

  • Type 192.168.56.10 and dev.local. Both appear in the text while you type.
  • Change the template. The new one is filled in with the same values.
  • Press Download file and open the file. It should match the text box.
  • In the developer tools, change one option's value to a file that doesn't exist and pick it. You should see "Could not load the Vagrantfile."

</head>
<body>
  <h1>Vagrantfile maker</h1>

  <label for="vagrant-ip">IP</label>
  <input type="text" id="vagrant-ip" placeholder="192.168.56.10">

  <label for="vagrant-url">Host name</label>
  <input type="text" id="vagrant-url" placeholder="dev.local">

  <label for="vagrant-file-select">Template</label>
  <select id="vagrant-file-select">
    <option value="templates/basic.Vagrantfile">Basic</option>
    <option value="templates/web.Vagrantfile">Web server</option>
  </select>

  <button type="button" id="download">Download file</button>
  <a href="#" id="download-content" download="Vagrantfile" hidden></a>

  <textarea id="vagrant-file" rows="20" aria-label="Vagrantfile"></textarea>

  <script>
    /*
     * Vagrantfile maker.
     *
     * The Vagrantfile templates on the server contain two placeholders:
     *
     *   vagrantip   replaced with the IP the user types
     *   vagranturl  replaced with the URL the user types
     *
     * Steps:
     *   1. Download the template the user picked (fetch).
     *   2. Replace the placeholders and show the result.
     *   3. Let the user download the result as a file.
     */

    // --- State ---------------------------------------------------------------

    // The template exactly as downloaded, with the placeholders still in it.
    let template = "";

    // --- Elements on the page ------------------------------------------------

    const templateSelect = document.getElementById("vagrant-file-select");
    const ipInput = document.getElementById("vagrant-ip");
    const urlInput = document.getElementById("vagrant-url");
    const fileText = document.getElementById("vagrant-file");
    const downloadButton = document.getElementById("download");
    const downloadLink = document.getElementById("download-content");

    // --- Actions -------------------------------------------------------------

    // Download the chosen template. "async" lets us use "await", which waits
    // for the network without freezing the page.
    async function loadTemplate() {
        fileText.value = "Loading...";

        try {
            const response = await fetch(templateSelect.value);

            // fetch() only throws when there is no network. A missing file
            // still "works" and gives an error page, so check the status.
            if (!response.ok) {
                throw new Error("HTTP " + response.status);
            }
            template = await response.text();
            showFile();
        } catch (error) {
            fileText.value = "Could not load the Vagrantfile.";
        }
    }

    // Fill in the placeholders and show the finished file.
    function showFile() {
        let content = template;

        if (ipInput.value !== "") {
            content = content.replaceAll("vagrantip", ipInput.value);
        }
        if (urlInput.value !== "") {
            content = content.replaceAll("vagranturl", urlInput.value);
        }

        fileText.value = content;
    }

    // Put the text into the hidden <a download="Vagrantfile"> link and click it.
    // A "data:" URL holds the file's content in the link itself.
    function downloadFile() {
        downloadLink.href = "data:text/plain;charset=utf-8," + encodeURIComponent(fileText.value);
        downloadLink.click();
    }

    // --- Connect the page ----------------------------------------------------

    // "input" fires on every change: typing, pasting, deleting...
    ipInput.addEventListener("input", showFile);
    urlInput.addEventListener("input", showFile);
    templateSelect.addEventListener("change", loadTemplate);
    downloadButton.addEventListener("click", downloadFile);

    // --- Start ---------------------------------------------------------------

    loadTemplate();
  </script>
</body>
</html>
