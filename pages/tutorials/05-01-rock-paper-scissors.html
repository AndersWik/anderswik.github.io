Rock Paper Scissors

Choose rock, paper or scissors. The computer chooses at random. Rock beats scissors, scissors beat paper, and paper beats rock. The page keeps score.

A short game to start the chapter. The new part is writing the rules of a game as data, in an object, instead of as a long if.

Open the finished game

The pictures

Make a folder for the game, with the page and a folder called images. Download these into images (right-click a link and save it):

Rock.svg, Paper.svg, Scissors.svg

The names start with a capital letter, the same as the choices in the code, so the code can make the file name from the choice.

Step 1: The page

Create rock-paper-scissors.html from the skeleton:

<h1>Rock Paper Scissors</h1>
<div class="score">
  <div id="player">
    <p>You</p>
    <p id="playerScore">0</p>
    <img id="playerImage" src="images/Rock.svg" alt="Rock">
    <p id="playerChoice">Rock</p>
  </div>
  <div id="cpu">
    <p>Computer</p>
    <p id="computerScore">0</p>
    <img id="computerImage" src="images/Scissors.svg" alt="Scissors">
    <p id="computerChoice">Scissors</p>
  </div>
</div>
<p id="result" aria-live="polite">Make your choice!</p>
<div class="choices">
  <button type="button" data-choice="Rock">Rock</button>
  <button type="button" data-choice="Paper">Paper</button>
  <button type="button" data-choice="Scissors">Scissors</button>
</div>

Each button has a data-choice attribute. Attributes that start with data- are for your own use: the browser ignores them, and the code reads them with button.dataset.choice.

The pictures are hands pointing right. transform: scaleX(-1) flips the computer's hand, so the two hands face each other.

Step 2: The rules as data

const CHOICES = ["Rock", "Paper", "Scissors"];

const BEATS = { Rock: "Scissors", Paper: "Rock", Scissors: "Paper" };

BEATS says what each choice beats: BEATS["Rock"] is "Scissors". Now "does the player win?" is one question: is the computer's choice the one the player's choice beats?

if (playerChoice === computerChoice) {
    resultText.textContent = "It's a draw!";
} else if (BEATS[playerChoice] === computerChoice) {
    playerScore++;
    resultText.textContent = playerChoice + " beats " + computerChoice + ". You win!";
} else {
    computerScore++;
    resultText.textContent = computerChoice + " beats " + playerChoice + ". The computer wins!";
}

If it isn't a draw and the player didn't win, the computer did. The first version wrote out all three winning pairs in one long if with ||. Both work, but the object is easier to read and to change. To play Rock Paper Scissors Lizard Spock, each choice would beat two others, and BEATS could hold a list for each.

Step 3: Showing a choice

const IMAGE_FOLDER = "images/";

function showChoice(choice, image, text) {
    image.src = IMAGE_FOLDER + choice + ".svg";
    image.alt = choice;
    text.textContent = choice;
}

The same function shows the player's and the computer's choice. We just pass it different elements. "images/" + "Paper" + ".svg" is "images/Paper.svg". That is why the file names match the choices exactly.

Step 4: Connecting the buttons

document.querySelectorAll("[data-choice]").forEach(function (button) {
    button.addEventListener("click", function () {
        play(button.dataset.choice);
    });
});

[data-choice] finds every element that has that attribute. One loop connects all three buttons, and each button tells play its own choice. The first version had a variable and a listener for each button. To add a choice now, you only add a button.

Step 5: Test it

  • Play until you have seen a win, a loss and a draw with each choice.
  • Check that the right score goes up, and that a draw changes nothing.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Rock Paper Scissors</title>
  <style>
    body {
        font-family: sans-serif;
        max-width: 800px;
        margin: 40px auto;
        padding: 0 16px;
    }

    body {
        text-align: center;
    }

    .score {
        display: grid;
        grid-template-columns: 1fr 1fr;
        gap: 16px;
        max-width: 450px;
        margin: 0 auto;
        font-size: 22px;
    }

    .score img {
        width: 100%;
    }

    #cpu img {
        transform: scaleX(-1);
    }

    #result {
        font-size: 22px;
        font-weight: bold;
    }

    .choices button {
        padding: 12px 20px;
        font-size: 18px;
    }
  </style>
</head>
<body>
  <h1>Rock Paper Scissors</h1>
  <div class="score">
    <div id="player">
      <p>You</p>
      <p id="playerScore">0</p>
      <img id="playerImage" src="images/Rock.svg" alt="Rock">
      <p id="playerChoice">Rock</p>
    </div>
    <div id="cpu">
      <p>Computer</p>
      <p id="computerScore">0</p>
      <img id="computerImage" src="images/Scissors.svg" alt="Scissors">
      <p id="computerChoice">Scissors</p>
    </div>
  </div>
  <p id="result" aria-live="polite">Make your choice!</p>
  <div class="choices">
    <button type="button" data-choice="Rock">Rock</button>
    <button type="button" data-choice="Paper">Paper</button>
    <button type="button" data-choice="Scissors">Scissors</button>
  </div>

  <script>
    /*
     * Rock Paper Scissors against the computer. Rock beats scissors, scissors
     * beat paper, and paper beats rock. The computer picks at random.
     */

    // --- Settings ------------------------------------------------------------

    // Where the pictures are: a folder called "images" next to this page.
    const IMAGE_FOLDER = "images/";

    const CHOICES = ["Rock", "Paper", "Scissors"];

    // What each choice beats.
    const BEATS = { Rock: "Scissors", Paper: "Rock", Scissors: "Paper" };

    // --- Elements on the page ------------------------------------------------

    const playerImage = document.getElementById("playerImage");
    const playerChoiceText = document.getElementById("playerChoice");
    const playerScoreText = document.getElementById("playerScore");
    const computerImage = document.getElementById("computerImage");
    const computerChoiceText = document.getElementById("computerChoice");
    const computerScoreText = document.getElementById("computerScore");
    const resultText = document.getElementById("result");

    // --- State ---------------------------------------------------------------

    let playerScore = 0;
    let computerScore = 0;

    // --- The game ------------------------------------------------------------

    function showChoice(choice, image, text) {
        image.src = IMAGE_FOLDER + choice + ".svg";
        image.alt = choice;
        text.textContent = choice;
    }

    function play(playerChoice) {
        const computerChoice = CHOICES[Math.floor(Math.random() * CHOICES.length)];
        showChoice(playerChoice, playerImage, playerChoiceText);
        showChoice(computerChoice, computerImage, computerChoiceText);

        if (playerChoice === computerChoice) {
            resultText.textContent = "It's a draw!";
        } else if (BEATS[playerChoice] === computerChoice) {
            playerScore++;
            resultText.textContent = playerChoice + " beats " + computerChoice + ". You win!";
        } else {
            computerScore++;
            resultText.textContent = computerChoice + " beats " + playerChoice + ". The computer wins!";
        }
        playerScoreText.textContent = playerScore;
        computerScoreText.textContent = computerScore;
    }

    // --- Connect the page ----------------------------------------------------

    // One button for each choice: <button data-choice="Rock">.
    document.querySelectorAll("[data-choice]").forEach(function (button) {
        button.addEventListener("click", function () {
            play(button.dataset.choice);
        });
    });
  </script>
</body>
</html>

Try this

  • Play best of five: stop when someone has three wins, and show a New game button.
  • Make the computer a little smarter: remember what the player picks most often, and pick what beats it.
  • Add Lizard and Spock. (Rock crushes lizard, lizard poisons Spock, Spock smashes scissors, scissors decapitate lizard, lizard eats paper, paper disproves Spock, Spock vaporizes rock.)
