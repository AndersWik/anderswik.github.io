Bubble level

A bubble level for your phone: lay it on a table and the bubble floats to the high side, just like the air bubble in a real level. The new ideas are reading the phone's tilt sensor with the deviceorientation event, asking for permission on iPhone, and smoothing a shaky signal.

Open the finished page (on a phone, a computer has no tilt sensor)

Read the Egg clock first. It explains keeping state in variables.

The state

const MAX_ANGLE = 10;     // the bubble touches the edge at this many degrees
const LEVEL_ANGLE = 0.5;  // closer to flat than this counts as level
const SMOOTHING = 0.2;    // 1 = no smoothing, smaller = calmer but slower
const STORAGE_KEY = "bubble-level-offset";

let tiltX = 0;            // the tilt, smoothed, in degrees
let tiltY = 0;
let offsetX = 0;          // the tilt saved by Calibrate
let offsetY = 0;
let started = false;      // true once the sensor is on
let wasLevel = false;     // so we only buzz once when it gets level
let gotReading = false;   // true when the sensor has sent anything

h1::after adds a short line under the heading without any extra HTML. A ::after element needs content, even an empty one, to show up.

aspect-ratio: 1 makes the height the same as the width, and border-radius: 50% makes the square a circle. left: 50%; top: 50% puts the ring's and the bubble's top left corner in the middle. The ring moves back by half its size with transform. The bubble does the same with a negative margin, because we will use its transform to move it around. A percentage margin is a percentage of the width, which here is also the height.

Step 2: Read the tilt

A phone sends a deviceorientation event many times a second. It has three angles in degrees:

  • beta: tilt from front to back. Positive when the top edge is up. 90 when the phone stands up.
  • gamma: tilt from left to right. Positive when the right edge is down.
  • alpha: which way the phone points, like a compass. A level doesn't need it.
function onOrientation(event) {
    if (event.beta === null || event.gamma === null) {
        return;
    }
    gotReading = true;
    tiltX = tiltX + (event.gamma - tiltX) * SMOOTHING;
    tiltY = tiltY + (event.beta - tiltY) * SMOOTHING;
    draw();
}

So tiltX and tiltY point to the low side: right and down on the screen are positive, the same way as screen coordinates.

The sensor is noisy, and a bubble that jumps a little on every reading is hard to read. Smoothing fixes that: instead of jumping to the new reading, we only move a fifth of the way there. A few readings later we are almost there, but the small shakes cancel out. This is called a low-pass filter. Try SMOOTHING = 1 to see the difference.

Step 3: Ask for the sensor

On iPhone and iPad a page must ask before it can read the sensor, and it may only ask after a click. DeviceOrientationEvent.requestPermission only exists there, so we check for it first:

async function start() {
    if (started) {
        return;
    }
    if (!window.DeviceOrientationEvent) {
        message.textContent = "This browser has no tilt sensor. Open the page on a phone.";
        return;
    }
    if (typeof DeviceOrientationEvent.requestPermission === "function") {
        try {
            const answer = await DeviceOrientationEvent.requestPermission();
            if (answer !== "granted") {
                message.textContent = "No permission to read the tilt sensor.";
                return;
            }
        } catch (error) {
            message.textContent = "Could not ask for the tilt sensor: " + error.message;
            return;
        }
    }
    window.addEventListener("deviceorientation", onOrientation);
    started = true;
    startButton.disabled = true;
    message.textContent = "Lay your phone on a surface.";

    setTimeout(function () {
        if (!gotReading) {
            message.textContent = "No tilt sensor found. Open the page on a phone.";
        }
    }, 2000);
}

requestPermission() shows a question to the user, and the answer comes later. It returns a promise. await waits for the answer without freezing the page, and a function that uses await must be marked async. If something goes wrong, await throws an error, so it is inside try and catch.

Many computers have DeviceOrientationEvent but no sensor, so the event never comes. The setTimeout tells the user after two seconds of silence.

The sensor only works on a page served over https:// (or localhost). Opened as a file, the page can't read it.

Step 4: Move the bubble

function draw() {
    const tilt = toScreen(tiltX - offsetX, tiltY - offsetY);

    // The bubble goes to the high side: the other way from the tilt.
    let bx = -tilt.x / MAX_ANGLE;
    let by = -tilt.y / MAX_ANGLE;

    // Keep the bubble inside the circle.
    const distance = Math.hypot(bx, by);
    if (distance > 1) {
        bx = bx / distance;
        by = by / distance;
    }

    const room = (vial.clientWidth - bubble.offsetWidth) / 2;
    bubble.style.transform = `translate(${bx * room}px, ${by * room}px)`;

    angleXText.textContent = tilt.x.toFixed(1) + "°";
    angleYText.textContent = tilt.y.toFixed(1) + "°";
}

Dividing by MAX_ANGLE gives a number from -1 to 1 when the tilt is within 10 degrees. Then we multiply it by room, how far the bubble can move from the middle in pixels.

If we only limited bx and by to -1 and 1 each, the bubble could go into the corners of a square, outside the circle. Math.hypot(bx, by) is the distance from the middle (Pythagoras). If it is more than 1, we divide both by it, which keeps the direction but puts the bubble right at the edge.

Step 5: When the screen turns

beta and gamma are measured on the phone, not on the screen. When the phone turns to landscape, the screen turns but the phone's left-right is now the screen's up-down. screen.orientation.angle says how far the screen has turned (0, 90, 180 or 270), and we turn the tilt back by that much:

function toScreen(x, y) {
    const angle = (screen.orientation ? screen.orientation.angle : window.orientation || 0) * Math.PI / 180;
    return {
        x: x * Math.cos(angle) + y * Math.sin(angle),
        y: -x * Math.sin(angle) + y * Math.cos(angle)
    };
}

This is the usual formula for turning a point around the middle. Math.cos and Math.sin want radians, so degrees are multiplied by Math.PI / 180. At 90 degrees it gives x = y and y = -x. Older iPhones have no screen.orientation, but have window.orientation instead.

Step 6: Show when it is level

Add this to the end of draw():

const level = Math.abs(tilt.x) < LEVEL_ANGLE && Math.abs(tilt.y) < LEVEL_ANGLE;
vial.classList.toggle("level", level);
if (level && !wasLevel && navigator.vibrate) {
    navigator.vibrate(40);
}
wasLevel = level;

classList.toggle("level", level) adds the class when level is true and removes it when it is false, so the border turns green. navigator.vibrate(40) buzzes for 40 milliseconds on phones that can. wasLevel makes it buzz once when it gets level, not on every reading while it stays level.

Step 7: Calibrate

A phone with a camera bump doesn't lie flat on its back. Calibrate saves the current tilt as "flat", and draw() subtracts it from every reading. localStorage remembers it until next time:

function calibrate() {
    offsetX = tiltX;
    offsetY = tiltY;
    saveOffset();
    draw();
}

function reset() {
    offsetX = 0;
    offsetY = 0;
    saveOffset();
    draw();
}

function saveOffset() {
    try {
        localStorage.setItem(STORAGE_KEY, JSON.stringify({ x: offsetX, y: offsetY }));
    } catch (error) {
        // Not saved, but the level still works.
    }
}

function loadOffset() {
    try {
        const saved = JSON.parse(localStorage.getItem(STORAGE_KEY));
        if (saved) {
            offsetX = saved.x;
            offsetY = saved.y;
        }
    } catch (error) {
        // Nothing saved, start from 0.
    }
}

startButton.addEventListener("click", start);
calibrateButton.addEventListener("click", calibrate);
resetButton.addEventListener("click", reset);

loadOffset();

localStorage only stores text, so JSON.stringify turns the object into text and JSON.parse turns it back. In a private window localStorage can throw an error, so it is inside try.

To calibrate well: lay the phone on a surface and press Calibrate. Then turn the phone around 180 degrees on the same spot. If the bubble is still in the middle, the surface is level.

Step 8: Test it

  • Put the page on a server with https://, or use localhost, and open it on a phone.
  • On a computer, Chrome's developer tools can fake the sensor: More tools, Sensors, Orientation.
  • Lift the top edge of the phone. The bubble should go up, to the high side.
  • Lift the right edge. The bubble should go right.
  • Turn the phone to landscape and do the same. The bubble should still go to the high side.
  • Tilt it a lot. The bubble stops at the edge of the circle, also in the diagonals.
  • Press Calibrate, reload the page and press Start. The bubble should be in the middle again.

  <script>
    /*
     * Bubble level: lay the phone on a surface and the bubble shows which way it
     * tilts. The bubble floats to the high side, like the air bubble in a real level.
     *
     * The phone tells us how it is tilted with the "deviceorientation" event:
     *   beta   tilt front to back, in degrees (positive when the top edge is up)
     *   gamma  tilt left to right, in degrees (positive when the right edge is down)
     */

    // --- Settings --------------------------------------------------------------

    const MAX_ANGLE = 10;     // the bubble touches the edge at this many degrees
    const LEVEL_ANGLE = 0.5;  // closer to flat than this counts as level
    const SMOOTHING = 0.2;    // 1 = no smoothing, smaller = calmer but slower
    const STORAGE_KEY = "bubble-level-offset";

    // --- State -----------------------------------------------------------------

    let tiltX = 0;
    let tiltY = 0;
    let offsetX = 0;
    let offsetY = 0;
    let started = false;
    let wasLevel = false;
    let gotReading = false;

    // --- Elements on the page --------------------------------------------------

    const vial = document.getElementById("vial");
    const bubble = document.getElementById("bubble");
    const angleXText = document.getElementById("angle-x");
    const angleYText = document.getElementById("angle-y");
    const message = document.getElementById("message");
    const startButton = document.getElementById("button-start");
    const calibrateButton = document.getElementById("button-calibrate");
    const resetButton = document.getElementById("button-reset");

    // --- Helpers ---------------------------------------------------------------

    // Turn the phone's tilt into the tilt on the screen. When the screen turns
    // to landscape, the phone's left-right is the screen's up-down.
    function toScreen(x, y) {
        const angle = (screen.orientation ? screen.orientation.angle : window.orientation || 0) * Math.PI / 180;
        return {
            x: x * Math.cos(angle) + y * Math.sin(angle),
            y: -x * Math.sin(angle) + y * Math.cos(angle)
        };
    }

    // --- Drawing ---------------------------------------------------------------

    function draw() {
        const tilt = toScreen(tiltX - offsetX, tiltY - offsetY);

        // The bubble goes to the high side: the other way from the tilt.
        let bx = -tilt.x / MAX_ANGLE;
        let by = -tilt.y / MAX_ANGLE;

        // Keep the bubble inside the circle: if it is too far out, scale it back.
        const distance = Math.hypot(bx, by);
        if (distance > 1) {
            bx = bx / distance;
            by = by / distance;
        }

        const room = (vial.clientWidth - bubble.offsetWidth) / 2;
        bubble.style.transform = `translate(${bx * room}px, ${by * room}px)`;

        angleXText.textContent = tilt.x.toFixed(1) + "°";
        angleYText.textContent = tilt.y.toFixed(1) + "°";

        const level = Math.abs(tilt.x) < LEVEL_ANGLE && Math.abs(tilt.y) < LEVEL_ANGLE;
        vial.classList.toggle("level", level);
        if (level && !wasLevel && navigator.vibrate) {
            navigator.vibrate(40);
        }
        wasLevel = level;
    }

    // --- The sensor ------------------------------------------------------------

    function onOrientation(event) {
        if (event.beta === null || event.gamma === null) {
            return;
        }
        gotReading = true;
        // Smoothing: move only part of the way to the new reading.
        tiltX = tiltX + (event.gamma - tiltX) * SMOOTHING;
        tiltY = tiltY + (event.beta - tiltY) * SMOOTHING;
        draw();
    }

    async function start() {
        if (started) {
            return;
        }
        if (!window.DeviceOrientationEvent) {
            message.textContent = "This browser has no tilt sensor. Open the page on a phone.";
            return;
        }
        // iPhone and iPad ask the user first, and only after a click.
        if (typeof DeviceOrientationEvent.requestPermission === "function") {
            try {
                const answer = await DeviceOrientationEvent.requestPermission();
                if (answer !== "granted") {
                    message.textContent = "No permission to read the tilt sensor.";
                    return;
                }
            } catch (error) {
                message.textContent = "Could not ask for the tilt sensor: " + error.message;
                return;
            }
        }
        window.addEventListener("deviceorientation", onOrientation);
        started = true;
        startButton.disabled = true;
        message.textContent = "Lay your phone on a surface.";

        // A computer often has the event but no sensor, so nothing ever comes.
        setTimeout(function () {
            if (!gotReading) {
                message.textContent = "No tilt sensor found. Open the page on a phone.";
            }
        }, 2000);
    }

    // --- Calibration -----------------------------------------------------------

    function calibrate() {
        offsetX = tiltX;
        offsetY = tiltY;
        saveOffset();
        draw();
    }

    function reset() {
        offsetX = 0;
        offsetY = 0;
        saveOffset();
        draw();
    }

    function saveOffset() {
        try {
            localStorage.setItem(STORAGE_KEY, JSON.stringify({ x: offsetX, y: offsetY }));
        } catch (error) {
            // Not saved, but the level still works.
        }
    }

    function loadOffset() {
        try {
            const saved = JSON.parse(localStorage.getItem(STORAGE_KEY));
            if (saved) {
                offsetX = saved.x;
                offsetY = saved.y;
            }
        } catch (error) {
            // Nothing saved, start from 0.
        }
    }

    calibrateButton.addEventListener("click", calibrate);
    resetButton.addEventListener("click", reset);

    loadOffset();
  </script>

Try this

  • Add a tube level for when the phone stands on its edge, against a wall or a picture frame. Then gamma is the tilt to read.
  • Make the bubble move more when it is close to the middle, so small tilts are easier to see: try Math.sign(x) * Math.sqrt(Math.abs(x)).
  • Make a short beep with the Web Audio API from the Egg clock when it gets level.
