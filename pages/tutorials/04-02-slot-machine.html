Slot machine

A spin costs one coin. The three reels spin, and stop one after the other. Press Stop to stop the next reel at once. Three of the same symbol is a jackpot of 10 coins. When your coins run out, you can start again.

The reels are moved by a timer that ticks every 60 milliseconds, like the spinning coin in Coin flip. The new part is one timer that controls several things that stop at different times.

The three reels have the class slot. The code finds them with document.querySelectorAll(".slot"), so you could add a fourth reel in the HTML and the code would use it. The card symbols ♠ ♥ ♦ ♣ are normal text characters.

A CSS animation makes the title blink after a jackpot. @keyframes blink says what the animation does: halfway (50%) the color is gold, and at the start and end it is the normal red. animation: blink 0.5s infinite plays it every half second, forever, for as long as the title has the class jackpot.

line-height: 90px, the same as the height, puts the symbol in the middle of the reel from top to bottom.

Step 2: Starting a spin

function spin() {
    if (spinTimer !== null || coins === 0) {
        return;
    }
    coins--;
    ticks = 0;
    stopAt = [];
    reels.forEach(function (reel, index) {
        stopAt.push(FIRST_STOP + index * NEXT_STOP);
    });
    messageText.textContent = "Spinning...";
    titleText.classList.remove("jackpot");
    spinTimer = setInterval(tick, TICK);
    showButtons();
}

spinTimer is null when the reels stand still, and the timer's number while they spin. So it tells us if we are spinning, and we need it to stop the timer later.

Each reel gets the tick it stops at: stopAt is [15, 23, 31]. With 60 ms ticks, the first reel stops after 0.9 seconds, then one more every half second.

Step 3: Ticking

function tick() {
    ticks++;
    let spinning = 0;
    reels.forEach(function (reel, index) {
        if (ticks <= stopAt[index]) {
            results[index] = randomSymbol();
            showReel(index, results[index]);
            spinning++;
        }
    });
    if (spinning === 0) {
        clearInterval(spinTimer);
        spinTimer = null;
        checkWin();
        showButtons();
    }
}

Every tick, each reel that hasn't reached its stop shows a new random symbol. The last symbol it shows is its result. When no reel is spinning any more, the timer is stopped and we check for a win.

The first version made a list of the results before spinning, and then never used it. The result was read back from the page text afterwards. Here the results are kept in results as they happen.

function showReel(index, symbol) {
    reels[index].textContent = symbol;
    reels[index].classList.toggle("red", RED_SYMBOLS.includes(symbol));
}

classList.toggle("red", true) adds the class and toggle("red", false) removes it. One line instead of an if with add and remove.

Step 4: Stop!

function stopNext() {
    const next = stopAt.findIndex(function (stop) {
        return stop > ticks;
    });
    if (next !== -1) {
        stopAt[next] = ticks;
    }
}

The Stop button doesn't stop the timer. It just moves the stop of the next spinning reel to now. findIndex gives the index of the first reel whose stop is still to come, or -1 if there is none. The timer does the rest as usual. In the first version, Stop stopped everything at once, and pressing it when nothing was spinning checked the old result again.

Step 5: Buttons that fit the moment

function showButtons() {
    spinButton.disabled = spinTimer !== null || coins === 0;
    stopButton.disabled = spinTimer === null;
    restartButton.hidden = spinTimer !== null || coins > 0;
    coinsText.textContent = coins;
}

One function sets every button from the state: Spin works when we are not spinning and have coins, Stop only while spinning, and New game only shows when the coins are gone. It is called after every change. That is simpler than turning each button on and off in many places, and the buttons can't end up wrong.

Step 6: Test it

  • Spin and wait. The reels should stop left to right, and the coins go down by one.
  • Spin and press Stop three times quickly. Each press should stop one reel.
  • Press Spin again while spinning. Nothing should happen, and no extra coin should be taken.
  • Spin until the coins run out, then press New game.

  <script>
    /*
     * Slot machine: a spin costs one coin. The three reels spin, and stop one
     * after the other. Press Stop to stop the next reel at once. Three of the
     * same symbol is a jackpot of 10 coins.
     */

    // --- Settings ------------------------------------------------------------

    const SYMBOLS = ["♣", "♦", "♥", "♠"];
    const RED_SYMBOLS = ["♦", "♥"];
    const START_COINS = 20;
    const JACKPOT = 10;
    const TICK = 60;            // ms between symbol changes while spinning
    const FIRST_STOP = 15;      // ticks before the first reel stops...
    const NEXT_STOP = 8;        // ...and between the next ones

    // --- Elements on the page ------------------------------------------------

    const reels = document.querySelectorAll(".slot");
    const coinsText = document.getElementById("coins");
    const messageText = document.getElementById("slot-message");
    const titleText = document.getElementById("machine-title");
    const spinButton = document.getElementById("start");
    const stopButton = document.getElementById("stop");
    const restartButton = document.getElementById("restart");

    // --- State ---------------------------------------------------------------

    let coins = START_COINS;
    let results = [];       // the symbol showing on each reel
    let stopAt = [];        // the tick each reel stops at
    let ticks = 0;
    let spinTimer = null;   // null when the reels are standing still

    // --- Helpers -------------------------------------------------------------

    function randomSymbol() {
        return SYMBOLS[Math.floor(Math.random() * SYMBOLS.length)];
    }

    function showReel(index, symbol) {
        reels[index].textContent = symbol;
        reels[index].classList.toggle("red", RED_SYMBOLS.includes(symbol));
    }

    function showButtons() {
        spinButton.disabled = spinTimer !== null || coins === 0;
        stopButton.disabled = spinTimer === null;
        restartButton.hidden = spinTimer !== null || coins > 0;
        coinsText.textContent = coins;
    }

    // --- Spinning ------------------------------------------------------------

    function spin() {
        if (spinTimer !== null || coins === 0) {
            return;
        }
        coins--;
        ticks = 0;
        stopAt = [];
        reels.forEach(function (reel, index) {
            stopAt.push(FIRST_STOP + index * NEXT_STOP);
        });
        messageText.textContent = "Spinning...";
        titleText.classList.remove("jackpot");
        spinTimer = setInterval(tick, TICK);
        showButtons();
    }

    // Every tick, each reel that is still spinning shows a new random symbol.
    // The symbol it shows when it stops is the result.
    function tick() {
        ticks++;
        let spinning = 0;
        reels.forEach(function (reel, index) {
            if (ticks <= stopAt[index]) {
                results[index] = randomSymbol();
                showReel(index, results[index]);
                spinning++;
            }
        });
        if (spinning === 0) {
            clearInterval(spinTimer);
            spinTimer = null;
            checkWin();
            showButtons();
        }
    }

    // Stop the next reel that is still spinning, right now.
    function stopNext() {
        const next = stopAt.findIndex(function (stop) {
            return stop > ticks;
        });
        if (next !== -1) {
            stopAt[next] = ticks;
        }
    }

    function checkWin() {
        const allSame = results.every(function (symbol) {
            return symbol === results[0];
        });
        if (allSame) {
            coins += JACKPOT;
            messageText.textContent = "Jackpot! +" + JACKPOT + " coins";
            titleText.classList.add("jackpot");
        } else if (coins === 0) {
            messageText.textContent = "No coins left!";
        } else {
            messageText.textContent = "Try again!";
        }
    }

    function newGame() {
        coins = START_COINS;
        messageText.textContent = "Try your luck!";
        showButtons();
    }

    // --- Connect the page ----------------------------------------------------

    spinButton.addEventListener("click", spin);
    stopButton.addEventListener("click", stopNext);
    restartButton.addEventListener("click", newGame);

    showButtons();
  </script>
</body>
</html>

Try this

  • Pay 2 coins for two of the same symbol.
  • Add a rare 7 symbol that pays 50 coins. (Put it in SYMBOLS just once, and the other symbols several times, to make it rare.)
  • Make each reel slow down before it stops, by making the tick longer near the end.
