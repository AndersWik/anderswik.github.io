Temporary add-on

Normal Firefox only installs extensions that Mozilla has signed. If you try to install your own zip, Firefox says it could not be verified and refuses. While building, load it as a temporary add-on instead. That skips the signing check.

Load it

  1. Open about:debugging#/runtime/this-firefox in Firefox.
  2. Click Load Temporary Add-on…
  3. Pick the manifest.json in the extension's folder, not the zip, for example _extensions/8-ball/manifest.json.
  4. The extension's button shows up in the toolbar. If it does not, click the puzzle piece icon, Extensions, and pin it.

A temporary add-on stays until Firefox is restarted. Then it has to be loaded again. To keep it installed, see Signing.

Reload after a change

Firefox does not see changed files by itself. After changing the game, build again and click Reload next to the extension in about:debugging.

$ python3 _scripts/make-extension.py 8-ball

A popup is loaded fresh every time it opens, so for a change in the popup's own files, closing and opening it is often enough. Changes to manifest.json or the background script always need Reload.

Inspect

Click Inspect next to the extension in about:debugging. It opens DevTools for the extension, with a console for errors and console.log() from the background script.

Debug a popup

The popup closes as soon as DevTools gets focus, which makes it hard to look at. In the DevTools window, open the ⋯ menu at the top right and turn on Disable Popup Auto-Hide. Now open the popup, and pick it in the frame list, the icon that looks like a page, at the top of DevTools.

Open the page in a tab

A popup page can also be opened in a normal tab, which is easier to inspect. In the DevTools console of the extension:

browser.tabs.create({ url: browser.runtime.getURL("index.html") });

A checklist

  1. Load the extension. Any error in manifest.json is shown right away in about:debugging.
  2. Click the button. Does the popup or tab open, with the right size?
  3. Use every part of the app: every button, picture and sound.
  4. Click Inspect and check the console for red errors, especially Content-Security-Policy, see Content Security Policy.
  5. Turn off the network and try again. Only apps like My IP should need it.

Firefox for Android

Firefox for Android also runs extensions. Test with web-ext run --target=firefox-android, see web-ext.
