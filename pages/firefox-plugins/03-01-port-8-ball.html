Port the 8-ball

The Magic 8 Ball is a good first app to port: one form, one picture and a random answer. No network, nothing to save, no keyboard. Here it is turned into an extension by hand, step by step. Later the script does all of this, see Many apps at once.

What we start with

The game is a Jekyll page, pages/games/8-ball.html, with its files in assets/8-ball/. The layout adds the site's header, footer and Bootstrap around it.

{% raw %}---
layout: game
title: 8-Ball
permalink: /games/8-ball/
nonav: true
css:
  - /assets/8-ball/8-ball.css
js:
  - /assets/8-ball/8-ball.js
---
<div class="container">
  <h1>Magic 8 Ball</h1>
  <img id="eightball" src="{{ site.baseurl }}/assets/8-ball/images/eightball.svg" alt="A magic 8 ball" />
  <form id="ask-form" autocomplete="off">
    <input type="text" id="question" placeholder="Ask your question..." aria-label="Your question" />
    <button type="submit">Shake the Ball</button>
  </form>
  <div id="result" aria-live="polite"></div>
</div>{% endraw %}

1. Check the JavaScript

Open assets/8-ball/8-ball.js and look for things an extension does not allow, see Content Security Policy:

  • No eval() or new Function().
  • No onclick="..." in the HTML. The game uses addEventListener. ✓
  • No scripts loaded from other sites.
// A form lets the user press Enter as well as click the button.
form.addEventListener("submit", shake);

The 8-ball passes, so 8-ball.js and 8-ball.css are used as they are.

2. Make the folder

Copy the game's files into a new folder. Keep the same paths as on the site, then /assets/8-ball/8-ball.js works without any change, since / in an extension means the top of the extension's own folder.

$ mkdir -p 8-ball-extension/assets/8-ball/images 8-ball-extension/css
$ cp assets/8-ball/8-ball.{css,js} 8-ball-extension/assets/8-ball/
$ cp assets/8-ball/images/eightball.svg 8-ball-extension/assets/8-ball/images/
$ cp css/style.css 8-ball-extension/css/
$ cp -r assets/fonts 8-ball-extension/assets/        # style.css loads the Ubuntu font

3. Bootstrap

The site loads Bootstrap from a CDN. An extension must have all its code and styles in the zip, so download it into the folder.

$ mkdir 8-ball-extension/vendor
$ wget -P 8-ball-extension/vendor https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css

4. The page

Write index.html: a full head that the layout used to give, the game's HTML with {% raw %}{{ site.baseurl }}{% endraw %} removed, and the scripts at the end. No service worker and no inline script.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Magic 8 Ball</title>
  <link rel="stylesheet" href="/vendor/bootstrap.min.css">
  <link rel="stylesheet" href="/css/style.css">
  <link rel="stylesheet" href="/assets/8-ball/8-ball.css">
  <style>
    .game { padding-block: 16px; }
    /* A popup is as big as its content, so give it a width. */
    body { width: 360px; }
  </style>
</head>
<body>
<div class="game">
<div class="container">
  <h1>Magic 8 Ball</h1>
  <img id="eightball" src="/assets/8-ball/images/eightball.svg" alt="A magic 8 ball" />
  <form id="ask-form" autocomplete="off">
    <input type="text" id="question" placeholder="Ask your question..." aria-label="Your question" />
    <button type="submit">Shake the Ball</button>
  </form>
  <div id="result" aria-live="polite"></div>
</div>
</div>

<script src="/assets/8-ball/8-ball.js"></script>
</body>
</html>

An inline <style> is fine, only scripts are blocked.

5. Icons

Add icons/icon-16.png, -32, -48, -96 and -128, see Icons.

6. The manifest

The same as in Hello World, with the 8-ball's name, id and "default_popup": "index.html". The full file is in Manifest.

The finished folder

8-ball-extension/
├── manifest.json
├── index.html
├── assets/
│   ├── 8-ball/
│   │   ├── 8-ball.css
│   │   ├── 8-ball.js
│   │   └── images/eightball.svg
│   └── fonts/Ubuntu/...
├── css/style.css
├── vendor/bootstrap.min.css
└── icons/icon-16.png ... icon-128.png

7. Test it

Load manifest.json in about:debugging, see Temporary add-on. Ask a question and shake the ball.
