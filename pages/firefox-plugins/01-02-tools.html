Tools

All you really need is Firefox and a text editor. A few more tools make the work faster.

Firefox

Normal Firefox is enough to build and test, using a temporary add-on, see Temporary add-on. Check which version you have:

$ firefox --version
Mozilla Firefox 160.0

Firefox Developer Edition and Nightly can also install extensions that are not signed, see Developer Edition.

about:debugging

Type about:debugging#/runtime/this-firefox in the address bar. This page loads extensions from a folder, reloads them, and opens DevTools for them. It is where you will spend most of the testing time.

web-ext

web-ext is Mozilla's command line tool for extensions. It starts a clean Firefox with the extension loaded and reloads it when a file changes, checks the extension for problems, builds the zip and sends it for signing. It needs Node.js.

$ sudo apt install nodejs npm
$ npm install --global web-ext
$ web-ext --version

Or run it without installing, with npx web-ext. Read more in web-ext.

Icons

An extension needs PNG icons in a few small sizes. Any image editor works. The icons for this site's extensions are drawn from an emoji by Python and Pillow, the same way as the PWA icons.

$ sudo apt install python3-yaml python3-pil fonts-noto-color-emoji

Folder layout

An extension is a folder with manifest.json at the top. The rest can be laid out any way you like.

hello-world/
├── manifest.json     # Required, always at the top
├── popup.html
├── popup.css
├── popup.js
└── icons/
    ├── icon-16.png
    ├── icon-32.png
    ├── icon-48.png
    └── icon-96.png
