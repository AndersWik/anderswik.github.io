Signing

Release Firefox only installs extensions that Mozilla has signed. Signing is free and done on addons.mozilla.org, AMO for short. You do not have to publish the extension to get it signed.

Two ways to distribute

  • On this site, listed: the extension gets a public page on addons.mozilla.org where anyone can find and install it. A person at Mozilla may review it. See Publish on addons.mozilla.org.
  • On your own, unlisted: Mozilla signs it, usually within minutes, and you download a signed .xpi file. It is not shown anywhere. Install it yourself, or share the file.

For trying an extension on your own computers, or sharing it with a few friends, unlisted is the quick way.

Make an account

  1. Go to addons.mozilla.org/developers and log in with a Mozilla account.
  2. Accept the developer agreement the first time.

Upload for signing

  1. Build the zip: python3 _scripts/make-extension.py 8-ball.
  2. On the developer hub, click Submit a New Add-on.
  3. Pick On your own.
  4. Upload _extensions/8-ball.zip. AMO runs the same checks as web-ext lint and shows any errors.
  5. Answer if the extension uses code that is minified or made by a tool. Our apps are plain JavaScript; the only minified file is vendor/bootstrap.min.css, a copy of a known library, which you can say in the notes to the reviewer.
  6. When it is signed, download the .xpi.

Install the signed file

Drag the .xpi into a Firefox window, or open the add-ons manager, about:addons, click the gear and pick Install Add-on From File…. It stays installed after a restart, like any other extension.

A new version

Every upload must have a higher version than the one before. For our apps it is set in _data/extensions.yml:

- { slug: 8-ball, page: pages/games/8-ball.html, name: Magic 8 Ball, emoji: "🎱", version: "1.1" }
$ python3 _scripts/make-extension.py 8-ball

On the developer hub, open the extension and click Upload New Version. Keep the same id, or Firefox sees a new extension.

From the command line

web-ext sign does the upload and download for you, see web-ext. It needs API keys from the developer hub, under Tools, Manage API Keys.

$ cd _extensions/8-ball
$ web-ext sign --channel=unlisted --api-key=$AMO_JWT_ISSUER --api-secret=$AMO_JWT_SECRET
