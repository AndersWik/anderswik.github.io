Hello World

The smallest useful extension is a toolbar button that opens a popup. It needs a manifest, a page for the popup, and a few icons. The finished example is in _extensions/hello-world/ in this site's repository.

hello-world/
├── manifest.json
├── popup.html
├── popup.css
├── popup.js
└── icons/
    ├── icon-16.png
    ├── icon-32.png
    ├── icon-48.png
    └── icon-96.png

manifest.json

Tells Firefox the name and version, which icons to use, and that the toolbar button opens popup.html. Read more in Manifest.

{
  "manifest_version": 3,
  "name": "Hello World",
  "version": "1.0",
  "description": "My first Firefox extension.",
  "icons": {
    "48": "icons/icon-48.png",
    "96": "icons/icon-96.png"
  },
  "action": {
    "default_title": "Hello World",
    "default_icon": {
      "16": "icons/icon-16.png",
      "32": "icons/icon-32.png"
    },
    "default_popup": "popup.html"
  },
  "browser_specific_settings": {
    "gecko": {
      "id": "hello-world@anderswik.se",
      "strict_min_version": "140.0",
      "data_collection_permissions": {
        "required": ["none"]
      }
    }
  }
}

popup.html

A normal HTML page. The script is in its own file, since extensions do not run inline scripts.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Hello World</title>
  <link rel="stylesheet" href="popup.css">
</head>
<body>
  <h1>Hello, world!</h1>
  <button type="button" id="hello">Click me</button>
  <p id="clicks">0 clicks</p>

  <!-- No inline scripts in an extension, the code is in its own file. -->
  <script src="popup.js"></script>
</body>
</html>

popup.css

A popup grows to fit its content, so give the body a width.

body {
  width: 240px;
  padding: 16px;
  font-family: system-ui, sans-serif;
  text-align: center;
}

popup.js

// Count the clicks on the button.
const button = document.getElementById("hello");
const clicksText = document.getElementById("clicks");
let clicks = 0;

button.addEventListener("click", function () {
    clicks++;
    clicksText.textContent = clicks + (clicks === 1 ? " click" : " clicks");
});

Icons

Any square PNG files work. See Icons for the sizes and how ours are made.

Try it

  1. Open about:debugging#/runtime/this-firefox in Firefox.
  2. Click Load Temporary Add-on… and pick hello-world/manifest.json.
  3. The 👋 button shows up in the toolbar. If not, click the puzzle piece icon and pin it.
  4. Click it, and click the button in the popup.

Close the popup and open it again: the count is back at 0. A popup is a new page every time it opens. To remember something, save it, see Popup.
