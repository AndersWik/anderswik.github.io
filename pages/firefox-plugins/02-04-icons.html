Icons

An extension uses icons in two places: the toolbar button, and the add-ons manager and store page.

The sizes

  • action.default_icon the toolbar button: 16 and 32 pixels, for normal and high resolution screens.
  • icons the add-ons manager and addons.mozilla.org: 48 and 96 pixels. Chrome also wants 128.
"icons": {
  "48": "icons/icon-48.png",
  "96": "icons/icon-96.png",
  "128": "icons/icon-128.png"
},
"action": {
  "default_icon": {
    "16": "icons/icon-16.png",
    "32": "icons/icon-32.png"
  }
}

Firefox picks the best size for the screen and scales it if one is missing. Firefox also accepts SVG icons, which look sharp in every size, but Chrome does not.

Small icons need big pictures

At 16 pixels there is no room for detail. Use one simple shape that fills most of the icon. A thin outline or small text disappears.

How ours are made

_scripts/make-extension.py draws every app's emoji from _data/extensions.yml on a dark tile, using the icon code from make-pwa.py, see PWA icons. For the two smallest sizes the emoji is made bigger, and the optional label under it, like "AI" or "64", is left out since it can not be read.

for size in ICON_SIZES:                     # 16, 32, 48, 96, 128
    # The smallest toolbar icons get a bigger emoji, or it can't be seen.
    scale = 0.78 if size <= 32 else 0.62
    pwa.make_icon(app["emoji"], None if size <= 32 else app.get("label"), size, True, scale) \
        .save(folder / f"icons/icon-{size}.png", optimize=True)

Dark and light toolbars

The toolbar can be light or dark depending on the theme. An icon on its own tile, like ours, looks the same on both. A transparent icon with a dark picture can disappear on a dark theme. Firefox can use different icons per theme with theme_icons in action.
