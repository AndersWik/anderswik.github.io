Common problems

"This add-on could not be installed because it has not been verified"

Normal Firefox only installs extensions signed by Mozilla, and your own zip is not. While testing, load it as a temporary add-on. To keep it installed, get it signed, or use Developer Edition.

"This add-on could not be installed because it appears to be corrupt"

  • manifest.json is not at the top of the zip. Zip the contents of the folder, not the folder itself.
  • The manifest is not valid JSON. Check it with python3 -m json.tool manifest.json.

"There was an error during the temporary add-on installation"

about:debugging shows the reason under the button, for example a missing file or a field with the wrong type. A common one is a missing icon: the paths in the manifest must match the files exactly, also upper and lower case.

The popup is blank or tiny

  • There is no width on body, and the content is only as wide as the text. Set a width, see Popup.
  • A path is wrong. Remember that / is the top of the extension, not the website.

The popup shows but nothing happens

Almost always a script that was blocked. Click Inspect in about:debugging and look for Content-Security-Policy errors in the console. See Content Security Policy.

A game stops when I click outside

A popup closes when it loses focus, and the page is thrown away. Use open: tab in _data/extensions.yml, see Open in a tab.

My change does not show up

  • Run make-extension.py again. The extension uses copies of the site's files.
  • Click Reload in about:debugging.

"Duplicate add-on ID found" when uploading

Someone else already uses that id, or you uploaded it before as a different add-on. The id must be unique, use your own domain, like 8-ball@anderswik.se.

"Version already exists" when uploading

Every upload needs a higher version. Raise it in _data/extensions.yml and build again, see Signing.
