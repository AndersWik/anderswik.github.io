Popup

A popup is the small window that opens under the toolbar button. It is a normal HTML page from the extension, set with default_popup in the manifest.

"action": {
  "default_title": "Magic 8 Ball",
  "default_popup": "index.html"
}

Size

A popup grows to fit its content, up to 800 × 600 pixels. Anything bigger gets scroll bars. Set a width on body, or the popup may end up very narrow.

/* A popup is as big as its content, so give it a width. */
body { width: 360px; }

Our apps are made for phones, so most of them fit in 360 pixels. A few needed more:

  • Color Hex got width: 560, since its labels ran into each other.
  • ASCII table has a wide table, so it opens in a tab instead.
  • The keyboard games draw on an 800 pixel wide canvas, too big for a popup, so they open in a tab too. See Open in a tab.

A popup closes when it loses focus

Click anywhere outside the popup and it closes. The page is thrown away, with all its variables and timers. Next time it opens, it starts from the beginning.

  • Short games, like the 8-ball or a coin flip, do not mind.
  • A timer, like the Egg Clock and Countdown, stops when the popup closes. Those open in a tab.
  • Anything worth keeping must be saved, see below.

Save the state

localStorage works in an extension page just like on a web page, and is kept between openings. The Discgolf score card already saves after every change, so a round survives the popup closing.

localStorage.setItem("discgolf-scorecard", JSON.stringify(state));

Extensions also have their own browser.storage.local, which the background script can use too and which can sync between computers with storage.sync. It needs the "storage" permission.

await browser.storage.local.set({ clicks: 3 });
const { clicks } = await browser.storage.local.get("clicks");

Links in a popup

A normal link opens inside the tiny popup. To open a web page in a tab instead, add target="_blank".
