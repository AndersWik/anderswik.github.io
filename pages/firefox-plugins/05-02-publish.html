Publish on addons.mozilla.org

A listed extension gets its own page on addons.mozilla.org, shows up in search, and Firefox updates it for everyone by itself when you upload a new version.

Submit

  1. Build the zip and run web-ext lint on the folder, see web-ext.
  2. On the developer hub, click Submit a New Add-on and pick On this site.
  3. Upload the zip. Pick which platforms it is for, desktop and Android.
  4. Fill in the listing, see below, and submit.

The listing

  • Name and summary taken from the manifest, and can be changed. The summary is the first thing people read, so say what it does in one sentence.
  • Description a longer text. How to use it, and that it works offline and collects nothing.
  • Categories like Games & Entertainment or Other.
  • Screenshots 1280 × 800 pixels look best. Take them with the app open in a tab.
  • License the license of your code, for example MIT.
  • Privacy policy only needed if the extension collects or sends data. My IP sends a request to ipify, so say that in its description.
  • Homepage link to the game's page on this site.

Review

Every listed extension is checked automatically, and may also be reviewed by a person, before or after it goes public. Reviews are faster when:

  • The code is plain and not minified, or the source is attached.
  • It asks for as few permissions as possible. Our games ask for none.
  • There is no code from other sites, see Content Security Policy.

Many extensions or one?

Publishing 45 small extensions means 45 listings to keep up. Mozilla's policies also say an extension should do something useful on its own, and many near copies can be seen as spam. Two ways to think about it:

  • Publish the few that stand on their own, like the Magic 8 Ball, the Discgolf score card or the Unix timestamp converter, and keep the rest unlisted.
  • Or make one extension, a games collection, with a menu that opens each game.

Chrome and Edge

The same zip loads in Chrome and Edge, which ignore browser_specific_settings. They have their own stores: the Chrome Web Store, with a one time fee, and Microsoft Edge Add-ons. Test in Chrome first with chrome://extensions, Developer mode, Load unpacked.
