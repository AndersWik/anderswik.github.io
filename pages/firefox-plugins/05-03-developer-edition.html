Developer Edition

Firefox Developer Edition, Nightly and the ESR builds without branding can install extensions that are not signed. That is handy for keeping your own extensions installed while you work on them, without uploading every version to addons.mozilla.org.

This does not work in normal Firefox. There the setting below is ignored, and only signed extensions can be installed.

Install Developer Edition

Download it from mozilla.org/firefox/developer. It installs next to normal Firefox, with its own profile.

Turn off the signing check

  1. Open about:config and accept the warning.
  2. Search for xpinstall.signatures.required.
  3. Click the toggle to set it to false.

Install the zip

  1. Open about:addons.
  2. Click the gear and pick Install Add-on From File…
  3. Pick the zip, for example _extensions/8-ball.zip.

Unlike a temporary add-on, it stays after a restart. The extension needs an id in browser_specific_settings for this, which all of ours have.

Update it

Build again, raise the version, and install the new zip the same way. Firefox replaces the old one, since the id is the same.

Which way to choose

  • Building and testing: temporary add-on or web-ext run.
  • Keep it installed on your own computer: Developer Edition, or an unlisted signed copy.
  • Share it with others: an unlisted signed .xpi, or publish it.
