Firefox extensions

A Firefox extension, or add-on, is a small program that runs inside the browser. It can add a button to the toolbar, change web pages, or open its own pages. Like a web page it is written in HTML, CSS and JavaScript, and it is packed as a zip file with a manifest.json that tells Firefox what it is.

Plugin, add-on or extension?

The words get mixed up. Plugins used to be programs like Flash and Java that the browser loaded from the computer, and Firefox removed support for them in 2021. Today Firefox calls everything you install from addons.mozilla.org an add-on, and the kind you build with JavaScript an extension. These notes use "extension".

WebExtensions

Firefox, Chrome, Edge and Safari all use nearly the same system for extensions, called WebExtensions. An extension built for Firefox usually loads in Chrome and Edge with no or few changes. Firefox has the API under the name browser, Chrome calls it chrome, and Firefox accepts both.

Manifest V3

The manifest has a version number, "manifest_version": 3. Version 3 is the current one. It is stricter than version 2: an extension may not run code from other sites, may not use inline scripts or eval(), and all its code has to be in the zip, so it can be reviewed. See Content Security Policy.

What an extension can do

  • A toolbar button that opens a small popup window. This is what our games use.
  • Its own pages, opened in a tab, like an options page or a bigger app.
  • Background scripts that react to events, like a click on the toolbar button.
  • Content scripts that run inside web pages and can read or change them.
  • Browser APIs for tabs, bookmarks, downloads, storage and much more, each behind a permission the user has to accept.

Extensions from this site

Every game and app on this site can be built as an extension with one script, see Many apps at once. These notes start with a Hello World button and then port the Magic 8 Ball by hand, step by step, so you can see what the script does.

Extension or PWA?

A Progressive Web App is the same app installed from a web page. It works on phones and needs no review, but it can only do what a web page can. An extension lives in the browser's toolbar, can use the browser APIs, works on desktop Firefox and Firefox for Android, and has to be signed by Mozilla.
