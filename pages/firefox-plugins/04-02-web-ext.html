web-ext

web-ext is Mozilla's command line tool for extensions. It does the same things as about:debugging and addons.mozilla.org, but from the terminal.

Install

$ sudo apt install nodejs npm
$ npm install --global web-ext
$ web-ext --version

Or run it once without installing, with npx web-ext .... Every command below is run in the extension's folder, or given --source-dir.

Run

Starts a new Firefox with a clean profile and the extension loaded. When a file changes, the extension is reloaded by itself.

$ cd _extensions/8-ball
$ web-ext run
$ web-ext run --firefox=firefoxdeveloperedition       # Another Firefox
$ web-ext run --start-url about:debugging             # Open a page at start

With make-extension.py the folder is replaced on every build, so run the script and web-ext run picks up the new files.

Lint

Checks the extension the same way addons.mozilla.org does when you upload: a broken manifest, missing files, unsafe code, inline scripts. Run it before every upload.

$ web-ext lint
Validation Summary:
errors          0
notices         0
warnings        0

Build

Makes the zip for upload into web-ext-artifacts/. Our script already makes _extensions/<slug>.zip, so this is only needed for extensions made by hand.

$ web-ext build

Sign

Uploads the extension to addons.mozilla.org for signing and downloads the signed .xpi. It needs API keys from addons.mozilla.org, Manage API Keys. See Signing.

$ web-ext sign --channel=unlisted --api-key=$AMO_JWT_ISSUER --api-secret=$AMO_JWT_SECRET

Keep the keys out of git. Put them in environment variables, not in a file in the repository.

Firefox for Android

Turn on USB debugging on the phone, connect it, and in Firefox for Android turn on Settings, Remote debugging via USB. Then:

$ sudo apt install adb
$ adb devices                                           # Find the device id
$ web-ext run --target=firefox-android --android-device=<id>
