em, rem and px

  • px is a fixed size. 16px is always 16 pixels.
  • rem is relative to the font size of the page, the <html> element. Browsers start with 16px, so 1.5rem is 24px. If the user sets a larger text size in the browser, everything in rem grows with it.
  • em is relative to the font size of the element's parent. Inside a box with font-size: 20px, 1.5em is 30px. Em inside em multiplies, so nested elements can grow or shrink more than you expect.

The math is the same for both: em = px / base and px = em × base. For rem, use the font size of the page as the base, usually 16px. For em, use the font size of the parent.
