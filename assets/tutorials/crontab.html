Crontab checker

minute

  • 0-59 0 is the first minute of the hour
  • * every value
  • a-b a range, like 4-6
  • a~b a random value in a range, like 4~6
  • a,b,c a list, like 3,5,7 or 3-5,7-9
  • /step a step after * or a range, like */15 or 1-10/2

hour

  • 0-23 0 is midnight
  • * every value
  • a-b a range, like 4-6
  • a~b a random value in a range, like 4~6
  • a,b,c a list, like 3,5,7 or 3-5,7-9
  • /step a step after * or a range, like */15 or 1-10/2

day (month)

  • 1-31 1 is the first day of the month
  • * every value
  • a-b a range, like 4-6
  • a~b a random value in a range, like 4~6
  • a,b,c a list, like 3,5,7 or 3-5,7-9
  • /step a step after * or a range, like */15 or 1-10/2
  • ? any day, when day (week) is set
  • L the last day of the month, L-1 the day before
  • 15W the weekday closest to the 15th, LW the last weekday

month

  • 1-12 or JAN-DEC
  • * every value
  • a-b a range, like 4-6
  • a~b a random value in a range, like 4~6
  • a,b,c a list, like 3,5,7 or 3-5,7-9
  • /step a step after * or a range, like */15 or 1-10/2

day (week)

  • 0-7 or SUN-SAT, both 0 and 7 are Sunday
  • * every value
  • a-b a range, like 4-6
  • a~b a random value in a range, like 4~6
  • a,b,c a list, like 3,5,7 or 3-5,7-9
  • /step a step after * or a range, like */15 or 1-10/2
  • ? any day, when day (month) is set
  • 5L the last Friday of the month
  • 1#3 the third Monday of the month
